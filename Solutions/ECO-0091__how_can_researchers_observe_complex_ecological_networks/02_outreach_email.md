**Subject:** One claim about detecting hidden ecological interactions, and what would refute it

> Hi [name],
>
> I have one specific output I would like you to check against what you already know about ecological network observation. I am not asking you to read any theory first, and I am not asking you to agree with me. I am asking what you would count as a failure of the claim. If it does not survive, there is nothing else to look at.
>
> **The output (`specified`, not `grounded`).** The observer's error is indexed per interaction slot, that is, per species pair under an interaction type. A study can report high overall detection coverage and still miss a single pollinator or predator link, because the live slot disappears into the average. Three named reasons a slot fails to register are not one problem:
>
> 1. **Rare:** the link has been seen, just seldom. More sampling, distributed across independent searchers, is the right remedy. Adding a new method here adds an atom that was not needed.
> 2. **Hidden:** the link has never registered on the current instrument at any resolution. More of the same search cannot find it. An instrument from a different method frame is owed, with a record of where it came from and an explanation of the gap it closes.
> 3. **Hard to measure:** the link registers but costs a whole field budget per detection. Description cost and action cost are two different currencies; a sensitivity number prices only one of them.
>
> These three overlap. One method clears the region where only one condition holds and leaves the intersections standing, so the verdicts should be kept separate, not averaged into one network-completeness score.
>
> **What I am not claiming:** that any named method, metabarcoding, camera trapping, stable isotopes, or a particular sampler, is the answer. The framework returns a shape, not a name. Which instrument fills a slot is open until a ground settles it. A list of "the interactions that matter" is also not claimed: interactions are read off the habitat and enumerated outward, including second-order effects, rather than taken from a standing catalogue.
>
> **What would refute the shape claim, written before this message:**
> 1. showing that one global coverage number preserves every live slot, so no interaction can hide in an average;
> 2. resolving a hidden interaction by search alone with no imported instrument, or building an instrument from a pure description with no prior worse instrument returning anything;
> 3. demonstrating a partition of rare, hidden, and hard-to-measure with no residual compound at their intersections;
> 4. showing that agreement among methods sharing one sample or one detection threshold changes the interaction web rather than just the report;
> 5. recovering a network property losslessly from per-slot detections, so the round-trip gap is zero.
>
> If any one holds, that part of the claim is withdrawn. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** the sources are below. The figures, not my summary of them, are the authority.
> - Verbatim figure text with line numbers (local extract): `FRAMEWORK/reference/03-FIGURES_TEXT.md`
> - Canonical usage rule (local copy): `FRAMEWORK/reference/FIGURES_README_canonical.md`
> - Public verified method overviews: see the links list in `04_links_and_distribution.md`
>
> **If you want to use the machinery:** the formula is in the local figures folder. Run it on a network you know well and can check against a ground. Write down what would refute your result *before* you run it. A reported failure is more useful to me than a reported success.
