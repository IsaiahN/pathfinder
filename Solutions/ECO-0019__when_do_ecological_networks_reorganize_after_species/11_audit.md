Symmetry: species loss is a subtraction; which actor goes changes the result, so importance cannot be intrinsic. Scale: first order to third order in contact, and immediate to delayed in time. - **Domain 2, maintained habitat.** Actors: a seat plus the habitat. Currency: introduction, not exclusion. Anchor: the ground still decides. Question type: prescriptive about work, not a one-off state.
- **Domain 3, the network as composition.** Actors: species as atoms, interaction bonds. Currency: composition within the closure of remaining actors. Anchor: a function assay. Question type: a mint/reach question per slot.

Order by dependency: enumerate contact before scoring topology; measure per slot before aggregating; settle remaining atoms before judging composition; describe the residual before naming a frame.
