## 1. A shape is a constraint, not a filler

The canonical figures README (local copy, read this session) states the limit: the framework reports *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13 records that the system *"can say the answer is out of reach with the library as it stands... It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*, opened this session: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can claim to have settled it. It constrains; it does not fill. For HIS-0059, the shape is: a union of slots with different anchors, a refusal owed where a held term is false, and no returned number or dominant name. A list of "the five reasons controversies persist" is a name, not a shape.

## 4. The source-discrimination problem

*The Hard Problem is About Source*, carried, gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*; one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

A persistent controversy is a reading of the same kind: several different slots (closure, pool, stake, channel, refusal) can produce the same visible outcome, continued disagreement. Without a discriminator that ranges each slot separately against the ground, picking one as "the cause" is the metamerism error. The world sources reflect this: attitude polarisation, manufactured doubt and false balance all predict continued disagreement from different mechanisms, and no single one of them can be selected from the outcome alone.

## 5. Correction to my own reading of section 1

I initially wrote "shape, not a name" as if it forbade naming any mechanism in any slot. That overstates the rule. The README's phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a primitive not held in Γ. A mechanism already available in a neighbouring frame (a shared evidence pool, a decayed channel, a surviving stake) is not a missing primitive. Naming one is a **binding with provenance**, which is allowed, not the invention of a seventh term. What remains forbidden is:
- inventing a new primitive to fill a slot;
- claiming the binding moves the wall (Fig 6 :21: *"MINT composes inside the closure and can never add an atom."*);
- presenting the binding as though the framework derived it.

The correction is kept visible rather than silently applied, consistent with the retraction log in `01` section 6.

## 6. Two consequences for this question

**Agreement is not validation.** *The Recursive Self-Improvement Trap*, opened: *"Prestige must never be allowed to validate an action directly"* and *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A claim that many historians agree on a cause is a budget to try it, not a settlement. The same essay: *"You may all agree and be wrong... You need ground truth to define where you stand."*

**This audit is a simulation, not a ground reading.** Same essay, opened: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` and this file are simulated derivations checked for internal consistency against the figures. They are not a test of any historical case and cannot settle anything they report on.
