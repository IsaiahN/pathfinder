## 1. A shape is a constraint, not a filler

The canonical figures README (local copy, opened this session) states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32, *"you get a kind of thing, never the answer itself."* Fig 13 :133, *"what it returns is a shape rather than a name."* Fig 13 :134 makes the companion point: *"Unreachable is a verdict here, not a silence"*.

From *The Library of Babel* (carried): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- A shape would be: *the four conditions under which a story about the past can generate an expectation about the future, plus the conditions under which that generation is a mirror rather than a correction*.
- A name would be: *"the linear model of innovation is what causes funders to expect short horizons"*. That names a specific narrative and a specific effect size. The figures do not return either.

The separator in `01` section 5 is a shape. "Whig history is the culprit" is a name and is not asserted.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5, *"SETTLE, the ground settles it. Verified only by what pays. A gate is not the ground."* The canonical README (opened this session): the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."* For this question the instrument is not yet run: vary the story a decision room reads, hold evidence constant, range allocations against outcomes that do not update on the story.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. A finding from cognitive psychology or innovation studies can be imported into the historiographical frame, but only with its provenance and a stated gap it explains.

## 4. Why "naming the narrative" is not the same error as "naming a missing primitive"

This is the correction from the exemplar's own §5b, retained and applied here.

The canonical README's phrase is about what a **missing** thing would look like. It governs a primitive not held in Γ. A historical narrative in this derivation is not a missing primitive; it is an already-held composition of atoms and bonds in a community's library. Naming one (the linear model, the Whig story, a Kuhnian story) is therefore a **binding from the history-of-science frame onto composition already available**, not the invention of a seventh primitive. What is forbidden is claiming that the binding moves the wall: Fig 6 :22, *"NOVEL means novel relative to atoms, not to the world. IMPORT adds an atom, and the added atom is what expands the closure."* Naming a held narrative adds no atom.

**What remains wrong if a name is asserted without provenance?** The exemplar's metamerism point, kept here. *The Hard Problem is About Source* (carried) gives the mechanism: an instrument reads green and *"cannot comment on the source"*, and *"If several paths create the same behavior, then behavior is a projection with lossy information."* Reading an expectation off a community and naming its source as "the linear model" is the same metamerism error if several stories could have produced the same expectation. What is owed is a discriminator, not a name. So naming is permitted only as a candidate binding with provenance, never as the settled source of a reading.

## 5. ANSWERED: what would license naming a specific narrative as the cause?

Nothing in the framework. The framework returns a shape. A specific narrative is licensed only by the ground settling a minted term, or by a provenanced import with a shadow test. ## 7. Shape for this question, one paragraph

The shape returned here is a four-condition separator with a named failure mode and a declared blind spot. A narrative shapes a present expectation when it supplies the atoms and the progress-bond from which the expectation is composed, when that bond selects the direction of the forecast, when the story travels through rooms that compound agreement unless the next room differs and matches the surfaced residual, and when it changes the community's habitat and therefore its contact. The failure mode is a reference that updates on the story, turning triangulation into coherent drift. The blind spot is which narrative dominates in a given institution and by how much; no figure line returns that, and the instrument that would is described but not run. What is offered is the shape any candidate answer must have, six refuters written in advance, and the lineage of the route. The slot for the dominant narrative stays open.
