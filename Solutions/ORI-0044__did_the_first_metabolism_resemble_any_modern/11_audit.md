**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down to a concrete yes or no:

Conversely, one thing survives cleanly: a seed does not contain the scaled-down tree, so no defensible answer treats the origin network as a miniature modern pathway. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints.
