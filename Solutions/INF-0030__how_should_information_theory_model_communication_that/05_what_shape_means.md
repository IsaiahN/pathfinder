## 1. A shape is a constraint you can state before you can name the mechanism

The canonical limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*.

From *The Library of Babel*: *"This means that you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For INF-0030 a **shape** is a list of constraints any adequate model must satisfy, stated before a specific functional form is chosen:

1. the anchor is an observed effect at the ground, not fidelity at the channel;
2. the effect is indexed by participant, never averaged;
3. the message is an import into a receiver frame, gated by support, reachability and novelty;
4. the effect is carried by the bond (framing, order, relation), not just the symbol set;
5. agreement about a code and evidence about the world are two quantities;
6. the answer stops where instruments cannot discriminate, and records the lineage.

A specific formula for "persuasive information" would be a **name**. The shape is the constraint set above.

## 2. How the shape was obtained here

- *Library of Babel*: use the vocabulary closest to the thing and correlate it with recurring new terms. *"With each new term gained, you narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* The residual was therefore described as an effect (what changed in a participant), not as a cause (entropy reduction).
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is why the packet leads with a checkable effect description.
- *Library of Babel* on stopping: *"You will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better."* Here: the search stops when the six constraints are stated and the instruments that would name a measure are identified.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* A per-participant behavioral instrument would name the effect measure.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :50-52).

*The Hard Problem is About Source* gives the mechanism of why an argument is not enough: *"The Problem: You can have several underlying causes that create identical readings but the definition of the output would be read as the same."* And: *"If several paths create the same behavior, then behavior is a projection with lossy information"*. The essay's resolution is instrumental: *"It was proven wrong not by argument, but by the arrival of a better instrument."* Applied here: a behavior reading alone cannot say whether a belief changed because of the message or because of the receiver's history and `w`. The discriminating instrument is what is owed, not another definition of information.

*They're Scanning Books* adds the provenance limit: *"Declaring the primitives does not make them neutral. It makes the choice visible, which is worth a great deal, because a visible choice can be revised and an emergent one cannot."* A chosen measure of belief change must be labelled as a choice.

## 4. Agreement: the distinction that decides this question

*Decoding Tacit Knowledge* states the exact rule the question needs:

> *"Shared pretext is good for one thing and ruins another. Agreement is the whole point when you're settling what words mean. It's worthless for settling what's true when both sides learned from the same sources."*

This is Fig 2 :39-41 in prose, written about conversation. It is the single most relevant sentence in the eight essays for INF-0030. Communication is partly a convention, and high agreement about a shared code is the product; the same agreement is disqualifying when used as evidence about the world.

The same essay names the dynamic that produces echo chambers: *"Long, close contact pulls the frames together, so the process that makes communication easy slowly uses up that extra reach."* And on drift: *"Context, subtext and pretext decide what a message means to you. None of them decides whether it is true. Only the ground does that."*

*How Intelligence Actually Works* gives the room-scale version: *"if you are just going off of what is present in your heads, then eventually, the room will be swayed by negotiation which is persuasion, or by coherent drift (both of you found a middle ground to agree on). The problem is that the room session only produces an outcome that you agree on... It does not mean that the output was objective truth."*

*How a Society of Agents Would Work*: *"A group is only worth having while its members stay different"* and *"the group's agreement is never the verdict."*

## 5. Why this audit is a simulation, not a ground reading

*The Recursive Self-Improvement Trap*: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too. However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* The same essay: LLM output is described as *"simulacra"*.

Also from that essay, the prestige rule that governs outreach: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* Gathering notable names to endorse this answer would be the named collapse, not corroboration.

*Arrival of the Fittest*: *"Because it is a metatheory, it cannot be validated, nor can it validate itself."* So `01` through `09` are checked for internal consistency against the figures; nothing in them is asserted as settled by experiment.

## 5b. Correction to my own first reading

I initially wrote the shape as *"add a semantic term to the Shannon pipeline so that mutual information tracks belief change"*. That is wrong for two reasons and the retraction is kept visible.

1. Mutual information between a sender's code and a receiver's decoding is highest when the message is predictable. A predictable message is exactly the one that is already in the receiver's library, so NOVELTY is zero and the message is inert (Fig 5 :25, Fig 6 :23). Increasing that quantity can reduce effect.
2. The phrase "shape, not a name" governs a missing primitive. Semantic content is not a missing primitive here; it is a binding onto atoms the receiver already holds. So the framework does not forbid naming semantic content, but it does forbid presenting the binding as a derivation or as an import that moves a wall (Fig 6 :22).

Both the earlier reading and this correction are recorded so neither is quietly lost. The corrected shape is the six-item constraint set in section 1.

## 6. Consequences for this solution

- **The output is a shape and a route.** It says what any adequate model must do; it does not supply coefficients, a specific belief metric, or a fitted law.
- **What would name it:** a source-discriminating instrument (section 3) that separates message-driven change from receiver-history-driven change, plus a ground settled measure of the effect.
- **What is deliberately not here:** no ranking of potential recipients by likely agreement, no request for trust, and no pooling of later agreement as corroboration. *"Alignment is triangulation, not negotiation. A mirror cannot correct you"* (Fig 2 :35).
