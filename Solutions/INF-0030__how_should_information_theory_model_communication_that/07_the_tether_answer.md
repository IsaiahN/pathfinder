# The Tether's answer: how information theory should model belief-changing communication

**Mode: `general` for the shape, `specified` for the testable predictions, not `grounded`.** This is a shape and a route, not a result. Simulated derivation checked for internal consistency against the figures (`05_what_shape_means.md` section 5), not a ground reading.

## 1. The residual it answers

An information-theoretic model of communication normally asks whether the receiver reproduced the message the sender selected. That residual is settled by fidelity. The question asks for a model of communication that changes the beliefs or behavior of its participants, where fidelity is neither necessary nor sufficient: a perfectly copied message can change nothing, and a garbled one can move a market. The residual under the question is `R_s`, the gap between the effect predicted for participant `s` and the effect observed at a ground that neither sender nor receiver can move.

This is a **union compound**, not one hard problem. Faithful transmission and belief change overlap: they are separate conditions with an intersection, and a single lever (improve the channel) clears only the transmission-only region. Per Fig 9 :55-58 it must be unbundled before it is searched, and the compound gets its own loop and its own ground.

## 2. The shape

1. **Change the anchor.** Fig 1 :23: *"The ground enters as the only metric."* Fig 2 :29 defines an anchor as whatever settles the question and does not change its answer because of what any frame thinks. For the symbol layer the sent message is the anchor; for the effect layer the anchor is an observed action, decision or outcome. Keep the first for coding, add the second for effect. Do not substitute one for the other.
2. **Measure per participant.** Fig 1 :19: *"The residual is indexed by object slot, not aggregated."* A campaign average near zero can hide one live slot. Report the distribution, not the mean.
3. **Treat the receiver as a frame.** Symbols table :20-26: the belief `b` is *"Formed from its own history and from what it inherited, mixed by w"*, and *"Two frames with identical architecture diverge because their histories and their w diverge."* A message is an attempted import into the receiver's `Γ`, gated by a product: SUPPORT (a live residual), REACHABILITY (it composes with what is held), NOVELTY (it is not already held). Any factor at zero and the message is inert (Fig 5, Fig 6 :23).
4. **Include the bond in the message.** Fig 12 :5: *"A set of ingredients is not one. The bond is the rest of the information, and it is the half nothing was recording."* Framing, order and relation carry the effect. Same atoms under a different bond are isomers (Fig 12 :117), not variants.
5. **Carry two quantities, never one.** Fig 2 :39-41: *"Correlation has valence."* Agreement about a shared code is the product of communication (*"efficient for a convention"*); agreement about the world is disqualifying as a verdict when the frames share an evidence pool (*"disqualifying for a verdict"*). A model that maximizes one and reports it as the other has destroyed the distinction. Fig 7 :13: *"agreement compounds, evidence does not"*.
6. **Price in two currencies.** Fig 12 :125-126: *"Bits price the description. Actions price finding out whether it holds."* Do not sum them into a single "information delivered" scalar.
7. **Stop where instruments cannot discriminate.** *The Hard Problem is About Source*: an instrument that reads green *"cannot comment on the source"*; the spectrometer, not an argument, resolved it. The model returns a shape; the discriminating instrument names the measure.

## 3. What it explicitly does not say

- Not a new formula for semantic or persuasive information. No coefficients are fitted and no law is claimed.
- Not that mutual information is wrong. It is the right measure for the code layer (D3), where shared meaning is the product. It is the wrong measure for the effect layer (D2) when used as a verdict.
- Not that belief change is always desirable or always a "good". Valence is relative to the residual (Fig 11 :49-50); the same message is a benefactor to one goal and a malfactor to another.
- Not that a message alone determines an effect. Capability is a property of message-and-habitat (Fig 11 :39); receiver history and surrounding frames matter.
- Not that a high-fidelity channel is unnecessary. It is necessary for the code layer and insufficient for the effect layer.
- Not grounded. No instrument measuring belief or behavior change was run for this derivation.

## 4. What would settle it - the ground

A source-discriminating instrument, not a further argument. The corresponding questions are:

- **Effect readout:** does the participant's action or decision change in a way that neither sender nor receiver can move by agreement? (Fig 2 :29-30)
- **Source discrimination:** does the change track the message's novel, reachable import, or the participant's prior `w` and habitat? A discriminating design is needed; a behavior reading alone cannot separate them (`The Hard Problem is About Source`).
- **Framing test:** under a controlled manipulation with identical atoms and different bond, does a per-participant ground measure move? (Fig 12 :117)
- **Standing falsifiers from `01`:** an already-held message with no live residual that still moves behavior; a shared-evidence pool that outperforms a low-overlap frame at tracking a movable ground; flat per-person effects with a large aggregate; an agreeing chain that tracks the ground better than any single frame.

## 5. The honest stop

**Unreached, not unreachable.** The instruments exist in behavioral science (grounding experiments, framing studies, crowd-influence experiments); this run did not operate them. The missing piece is not a new primitive but a re-anchoring and a binding of the shape to a measured effect. Importing a new information primitive against this budget would add an atom that was not needed (Fig 8 :42).

The framework itself states its limit: *"Because it is a metatheory, it cannot be validated, nor can it validate itself"* (*Arrival of the Fittest*). The answer stops at what the available instruments can distinguish and records the lineage so the stop is checkable. *"Indiscernibility is not identity."*

## 6. One-paragraph version for outreach

> Information theory should not try to make mutual information measure persuasion. It should keep the Shannon channel for the symbol layer and add a second channel whose anchor is what actually changed in each participant, settled by something neither sender nor receiver can move by agreement. The effect is measured per person, never as a campaign average. A message changes a receiver only if three conditions all hold: the receiver has a live unresolved question, the message can be built from what the receiver already holds, and the message is not already there. The effect is carried by the framing and order, not just the facts: the same facts under a different bond are different messages. And two things must never be pooled: agreement about a shared code is the product of communication, while agreement about the world is not a verdict when both sides learned from the same sources. That is a shape any adequate model must have, not a formula; the instrument that would name the measure is still owed.
