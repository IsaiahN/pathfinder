# What "shape" means for this question

**Sources read this run:** the canonical figure text
(`FRAMEWORK/reference/03-FIGURES_TEXT.md`), the canonical figures README
(`FRAMEWORK/reference/FIGURES_README_canonical.md`), `THE_FORMULA.md`, and two of the eight essays:

*The Recursive Self-Improvement Trap* (Isaiah N, 2026-11-19, opened 2026-11-23). The other six

the figures README and the figure text, which are primary. The exemplar

## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look
like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13
:134-135: *"Unreachable is a verdict here, not a silence, It cannot say which primitive is missing,
because naming it would mean already holding it."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small
and descriptive enough that it provides a general shape of the answer that satisfies your
question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains;
it does not fill. For this question:

- `PRE-LUCA(???)` is a shape.
- "an anaerobic thermophile in a hydrothermal vent", "a mesotrophic heterotroph in a hot spring",
  and "the successor to LACA and LBCA with metallic catalysts" are names.

The three names are live in the literature and mutually incompatible in places (recorded in `01` F5
and in `04`). That is exactly the condition under which a shape is the honest output: the readings
do not discriminate the sources.

## 2. How the shape is obtained

- *The Library of Babel* on method: *"use the existing vocabulary you do know that is closest to the
  words that you wish to describe and grasp the shape of."* Then: *"With each new term gained, you
  narrow the space and deepen your vocabulary."* Here the closest held vocabulary is the six-term
  set, the cross-kind composition rule, and the no-maintainer habitat.
- Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause"*. The
  effect here is a boundary that keeps a gradient, an order that survives division, and a
  population whose ancestry starts web-like. The causes (which vent, which lipid, which genome)
  are what the ground has not settled.
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast
  it in effect terms."* This is why the outreach packet in `08` describes the residual in ordinary
  language before it shows any glyph.
- *The Library of Babel* on stopping: *"the finish line will also be the starting place"*, because
  by then *"you have already composed the answer through the process of locating it."* For this
  question the stop is not a finished reconstruction; it is the point at which further searching
  inside the same evidence pool returns the same three incompatible names.

## 3. What would license a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."*
   The README: the framework *"stops at the limit of what the available instruments can
   distinguish, and records the lineage so the stop is honest."* Here that means an instrument that
   discriminates among the three settings against the shared genomic reading.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a
   source gate and a shadow test. A laboratory protocell result is such an import only if it
   explains a gap in the pre-LUCA record and carries its provenance; it does not by itself name the
   historical first cell.

A third thing that **does not** license a name: agreement among reviews that cite the same genomes.
Fig 2 :40: *"disqualifying for a verdict: agreement about the world is worthless when the agreeing
frames share an evidence pool"*. The Wikipedia articles on LUCA, pre-cells, the Darwinian threshold
and FUCA cross-reference one another, so their agreement is one pool talking.

## 4. The metamerism point, narrowed

The exemplar's essay *The Hard Problem is About Source* (not re-opened this run) gives the mechanism
called metamerism: a reading cannot comment on its source. That mechanism is at work here. The
shared genetic core is a reading; several different historical sources could produce it. Weiss et
al., Berkemer and McGlynn, and Martin et al. are three attempts to name the source from the reading,
and they disagree. What is owed is a discriminator, not a choice among them. I record this as a
**narrowed** claim: the reason the setting is withheld is the missing discriminator, not a blanket
ban on naming anything. The six settings and atoms are already held in domain 2; naming one is a
binding that needs provenance and a shadow test.

## 5. Prestige and simulation, the two standing constraints

From *The Recursive Self-Improvement Trap*, read this run:

- *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an
  action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list
  of famous origin-of-life researchers who agree with the shape is the named collapse, not
  corroboration. The legitimate ask is the opposite: give the claim a budget to be tried.
- *"LLMs can quickly simulate an approximate answer/output with the formula found in the
  architecture post... However, the truly testable output would need to be derived from the real
  architecture or working the formula yourself."* So `01` and the rest of this folder are a
  simulated derivation checked for internal consistency against the figures. They are **not** a
  test of the claim and must be labelled as such. They cannot settle anything they report on.
- *"Natural selection is what the loop looks like when there is no one maintaining the ground. When
  there is no one in the Ground Maintainer seat, the environment is the only selector."* This is
  the sentence that makes the pre-LUCA regime derivable rather than merely plausible: no seat, so
  selection ran, and a label like "intelligent" does no work there (Fig 11 :36).

## 6. Answer to the only question that matters here

**What licenses a particular first cell?** Nothing in the framework. The framework returns a shape:
a cross-kind composition, in an unmaintained habitat, web-like before tree-like, with a threshold
rather than an individual. A particular setting or anatomy is licensed only by a ground settling a
minted term, or by a provenanced import with a shadow test. Until one of those, the name is the
searcher's own contribution and must be recorded as such.

**Does this folder commit the forbidden error?** It would if it named a vent, a genome or an
individual. It does not. `01` F5 records the conflict and withholds the name; `07` and `08` repeat
the refusal. What remains open is not silence: it is the enumerated set of instruments that would
close it (Fig 13 :134, *"Unreachable is a verdict here, not a silence"*).
