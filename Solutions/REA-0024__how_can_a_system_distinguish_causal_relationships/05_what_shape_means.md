## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework reports *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :135: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For REA-0024, a **shape** is the form an answer must have before any real pair is decided: a causal relation is an **ordered** bond whose direction is settled by a change of contact, while a merely predictive correlation is a **symmetric** co-variation settled only inside the frame. The shape constrains; it does not name A or B for a real dataset. Saying "A causes B" for a specific pair is a name backed by a ground reading, not a shape.

## 2. How the shape is obtained

- *Library of Babel*: bootstrap vocabulary by proximity. *"With each new term gained, you narrow the space and deepen your vocabulary."* Here the starting vocabulary is "predicts well", and the recurring new term that overlaps it is "would change under a setting".
- Fig 6 :30: *"outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30 to :31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*: when contact is not possible, send a plain description of what you would expect to see, because anyone can check it against the world. This is why the outreach states the intervention prediction, not the theory.
- *Library of Babel* on stopping: *"the finish line will also be the starting place"*, because by then the answer has been composed through the process of locating it.

## 3. What licenses a name

Only two things, both outside the shape itself.

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* The README says the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50 to :52), with a source gate and a shadow test.

*They're Scanning Books* sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

For this question, "smoking causes lung cancer" is a name licensed by a long history of ground contact (interventions, natural experiments, mechanism, triangulation). The Tether shape does not produce it and does not need to. It says what any such name must look like.

## 4. Why a predictive score cannot name the source

*The Hard Problem is About Source* gives the mechanism. Metamerism: the instrument reads green and *"the instrument is speaking only about what it measured, it cannot comment on the source."* One green light, or yellow plus blue, or RGB, or CMYK, all give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information"*; the full set of ways to produce a reading is not known to be closed. *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the **spectrometer**, not an argument, that resolved it.

A predictive score is exactly this kind of reading. It is green. It does not say whether the source is a direct effect, a common cause, or a scheme not yet considered. What is owed is a discriminating instrument, not a name read off the projection. The framework's own limit applies: *"Indiscernibility is not identity."*

## 5. Q: Does "shape, not a name" forbid naming the production bond? ANSWERED with a correction

**Answer: no.** The README's phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a primitive or atom not held in the library. The ordered production bond `⇒` is already in the operator set (Operators table, Fig 12), as are the symmetric bonds. Selecting `⇒` to model a causal relation is a **binding from the causal-inference frame onto a held operator**, not the invention of a new one. What remains forbidden is claiming the framework derived that binding from the observational data alone; that would be an import with no source gate (Fig 6 :14, Fig 8 :50 to :52).

**Correction to my own first reading.** I initially wrote that the framework could not say "ordered production bond, not conjunction", treating that as a name where only a shape is allowed. That overstated the rule. The corrected position: the framework can state the bond-type distinction (shape over held operators); it cannot name the variables or certify the direction for a real pair without ground contact. Both claims are now recorded so neither is quietly lost. Triangulated (README + Fig 12 + Operators table).

## 6. Two consequences for this solution

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of well-known researchers assembled to agree with the shape claim is the named collapse, not corroboration. The legitimate ask is to give the claim a budget to be tried and let an intervention settle it.

**This audit is a simulation, not a ground reading.** Same essay: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* And: *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` and this file are simulated derivations checked for internal consistency against the figures. They are **not** tests of the causal question and must be labelled as such. They cannot settle anything they report on.

## 7. One-paragraph reading of "shape" for REA-0024

> The shape is not an answer about any dataset. It is the form a checkable answer must take: a co-variation is written with a symmetric bond, a causal relation with an ordered production bond whose effect was absent before the cause fired; the score a model produces for itself is a filter and not a witness; and the direction is settled only when an instrument changes contact with the ground and the ground returns a residual against a prediction committed in advance. Naming a real pair as cause and effect is a further step that requires that ground reading. Until then the framework returns the kind of thing, never the answer itself.
