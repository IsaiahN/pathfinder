## 1. The claim, in one paragraph

The question "what information-processing features distinguish intelligence from sophisticated pattern recognition?" is refused as posed and replaced. The verbatim figure text calls it *"the wrong question"* and says the answerable question is what makes a system capable, where capability is a property of agent and habitat, never of the agent alone. The replacement shape has five necessary conditions: the system ranges against an anchor that does not update on the system's own account of itself; it carries negation, so it can refuse a held regularity; it keeps the residual per case rather than in a global average; it can import from a frame whose closure differs; and it produces methods that cross up rather than replays. A benchmark is a substituted habitat, so a synthetic solve proves wiring and never capability. None of the five is sufficient alone, and the literal question remains `gap` until a ground settles it.

## 3. What is explicitly not claimed

- Not a definition of intelligence, and not a sufficient feature list. Every surviving condition is necessary; none is sufficient.
- Not that pattern recognition is absent from capable systems. It is a substrate and a component.
- Not that accuracy, compression, coverage or prediction score measures capability. Those are frame-internal (Fig 1 :27).
- Not that the Turing test or any benchmark settles the question. *Decoding Tacit Knowledge* calls the Turing test *"a test of fluency, not of accuracy."*
- Not an external validation of the framework's central claim. The architecture essay lists *"capability is a property of agent-and-habitat, never of the agent alone"* among claims with no prior citation.
- Not `grounded`. Nothing here is asserted as settled by experiment.
