# The Tether's answer on intelligence versus pattern recognition

**Mode: `specified` on the substantive claims, `general` on the structural shape, not `grounded`.** This is a shape and a route, not a definition or a measurement. Simulated derivation checked against the figures (`05_what_shape_means.md` §6), not a ground reading.

## 1. The residual it answers

The question asks for an information-processing feature that separates intelligence from sophisticated pattern recognition. Stated as an effect: we want an instrument that changes a decision about a system, not a label. The residual is a discriminability gap. Accuracy, compression, coverage and prediction score are quantities a frame produces about itself, and Fig 1 :27 says *"A frame cannot score itself with a quantity it also produces."* Fig 11 :35 says *"The wrong question, and this figure is the replacement for it."* So the literal question is refused and the replacement is supplied. It is a **union compound**, not one hard question (`01` §1, `06` Q1).

## 2. The shape

1. **Capability is not a property of the agent alone.** Fig 11 :39: *"So the answerable question is not what intelligence is, but what makes a system capable. And capability is a property of agent-and-habitat, never of the agent alone."* Fig 11 :40: *"An improvement that does not change contact changes nothing, however much it improves."* The discriminator is a contact relation, not an internal scalar.
2. **The system must range against something immovable.** Fig 2 :29-30: *"An anchor is whatever settles the question and does not change its answer because of what any frame thinks."* Fig 2 :35: *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* A system that scores itself is a mirror, however sophisticated its patterns.
3. **It must be able to refuse.** Fig 12 :140: *"A vocabulary that cannot refuse can only accumulate."* Operators table :58: *"a refutation is a negation, which is why a vocabulary without it can only accumulate."* This is the one narrow internal feature that survives, but it is necessary and not sufficient.
4. **It must keep the residual per case, not in a global average.** Fig 1 :19: *"The residual is indexed by object slot, not aggregated."* Fig 1 :22: *"Aggregating across slots is how a live signal disappears into an average."* The honest cost is that "intelligence" cannot be a single score. This is a prediction, not a convenience.
5. **It must be able to import from a closure that differs.** Fig 6 :23: *"No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs."* Fig 8 :32: *"no search, however long, adds an atom."* Fig 4 :22: *"Only methods cross up. Only head starts come down."* A pattern recognizer searches inside a fixed closure; a capable system's reach moves only on contact.
6. **The test bench is not the ground.** Fig 11 :70: *"A test harness is a substituted habitat. Which is why a synthetic solve proves wiring and never capability."* Turing's *viva voce* test for *"learnt it parrot fashion"* (1950) is the low-overlap, pre-figural version of the same point.
7. **The answer is a shape, not a definition.** The canonical README: *"what a missing thing would have to look like (**a shape, not a name**)."* No figure line and no essay supplies a sufficient internal feature. The literal question is recorded as `gap`; the replacement shape is `specified` and survives with its refuters.

## 3. What it explicitly does not say

- Not a definition of intelligence. The substrate question dissolves; the contact question does not (Fig 11 :41).
- Not that pattern recognition is absent from intelligence. It is a component and a necessary substrate, not the whole.
- Not that a benchmark score, accuracy figure or compression ratio measures capability. Those are frame-internal (Fig 1 :27).
- Not a sufficient condition. Every surviving feature is necessary; none is sufficient alone; nothing here is averaged into a single criterion (Fig 1 :22).
- Not `grounded`. No measurement at any scale settles `left(R,φ)` for this shape.
- Not that the framework's central claim is externally validated. The architecture essay lists *"capability is a property of agent-and-habitat, never of the agent alone"* among claims with no prior citation, and says *"Absence of a citation is not a claim of originality."*

## 4. What would settle it - the ground

A source-discriminating instrument, not a further argument. From *The Hard Problem is About Source*: an instrument that reads green *"cannot comment on the source"*, and the case was closed *"not by argument, but by the arrival of a better instrument."* Here:

- **Agent-only test:** apply an internal improvement while holding contact fixed. If the improvement moves the ground, the capability claim fails (Fig 11 :71-72: *"an agent-only improvement that moved the ground would refute the capability claim."*).
- **Refusal test:** find a system with no negation operator that settles a novel residual against an immovable ground, with no import and no habitat change. If found, refusal is not the discriminator.
- **Self-score test:** find a frame scoring itself with a quantity it also produces whose score settles a verdict against an immovable ground. If found, Fig 1 :27 fails.
- **Transfer test:** find a synthetic solve that transfers to an unenumerated habitat without new contact. If found, Fig 11 :70 fails.
- **Search test:** find an atom added by search inside a fixed closure. If found, Fig 8 :32 fails.

## 5. The honest stop

**Unreached, not unreachable.** The discriminability gap is not closed by more searching inside one's own vocabulary (Fig 8 :39: *"So a search that finds nothing is never a proof of absence."*). The answer stops at the limit of the available instruments and records the lineage so the stop is checkable. The central claim is a framework claim with weak outside corroboration. Two low-overlap sources corroborate the **form** of the answer independently. Turing (1950) replaces "Can machines think?" because a Gallup poll of word usage is *"absurd."* Shapiro, Spaulding and Dove (2026, SEP) hold that *"Mental processes are not, or not only, computational processes"* and that perceptual processes involve *"the whole organism as it moves about its environment."* Neither endorses the Tether; both make the replacement question plausible from outside the frame. That is corroboration of a direction, not of a result.

## 6. One-paragraph version for outreach

> The Tether does not define intelligence, and it does not claim a feature that separates intelligent systems from pattern recognizers in one score. The verbatim figure text calls that question the wrong one and replaces it: capability is a property of agent and habitat, not of the agent alone, and an improvement that does not change contact changes nothing. What survives as a shape is this: the system ranges against something immovable that does not update on its own account of itself; it can refuse a held regularity rather than only accumulate fitted ones; it tracks a residual per case rather than folding it into a global accuracy number; it can import from a frame whose closure differs; and it produces methods rather than replays. A test harness is a substituted habitat, so a benchmark solve proves wiring and never capability. Each of these is stated with a refuter written in advance, and the literal question stays open until a ground settles it. The result is a shape and a route, not a definition, and it is not claimed to be grounded.
