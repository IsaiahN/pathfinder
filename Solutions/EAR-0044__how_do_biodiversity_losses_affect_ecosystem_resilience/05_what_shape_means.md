## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence". Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

*The Library of Babel* (OPENED): "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For this question a **shape** is the separator we can state before we can name a number: which rooms must be available, which rooms must differ, which anchors must not update, and which instrument would settle each branch. A shape is not "biodiversity loss reduces function by 20 percent". That is a name with a number attached, and the framework does not return it.

The same essay gives the rule for a bundled question: "Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually to find their answers and then combine them in a satisfactory way." That is F1 of `01_figure_grounded_audit.md`, written in the essay's own vocabulary.

## 2. How a shape is obtained

- *Library of Babel* (OPENED): use the vocabulary already held that is closest to the sought thing, then "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary." Here the closest held vocabulary is response diversity, asynchronicity, functional group and habitat enumeration, all of which come from the world literature, not from the framework.
- Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause". We describe the residual as "a disturbance surfaces a changed condition and no remaining response type matches it", not as "functional redundancy declines".
- *Decoding Tacit Knowledge* (CARRIED): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *Library of Babel* (OPENED) on stopping: "you will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better." For this question the stop is not a number; it is the point where the three branches have different instruments and no figure line moves any of them further.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." A measured function, inventory or trajectory licenses a number for that site and date.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. Hong and Page 2004 and Ashby 1956 are such imports here; they license the shape, not the ecological fact.

*They're Scanning Books* (CARRIED): "The real import is not a new term in the existing space. It is a new dimension of the space." And: "Declaring the primitives does not make them neutral. It makes the choice visible."

The six-term set is a visible guess, not nature's own list. Naming one term as *the* mechanism of biodiversity loss would turn a visible choice into an invisible one. This is why the derivation keeps "response diversity" as a binding from the ecology frame onto the held network atom, provenanced as such, and not as a seventh primitive.

## 4. The source problem: why a diversity index cannot comment on its cause

*The Hard Problem is About Source* (CARRIED) gives the mechanism. An instrument reads green and "cannot comment on the source"; one green light, or yellow plus blue, or RGB, or CMYK can all produce the same reading. "If several paths create the same behavior, then behavior is a projection with lossy information." The spectrometer, not an argument, resolved it.

A species count is such a reading. Many different community structures produce the same richness number: one with high response diversity, one with a chain of mirrors, one with a single dominant and many rare species with the same response. The reading cannot comment on the source. This is the metamerism error named in F2 and F5 of `01`. What is owed is a discriminator (response diversity, functional group identity, measured variance through a perturbation), not a richer index.

*How Intelligence Actually Works* (CARRIED) places this in the derivation: the vocabulary must be able to name the route, not only the ingredients. Fig 12 :111 says the same thing: "A vocabulary without bonds can name a state and cannot name a route to one." A richness list names ingredients; response diversity and functional groups name bonds.

## 5. Correction to my own reading of the "shape, not a name" rule

I initially wrote as if the rule forbade naming response diversity or functional groups. That overstates it. The README's phrase is "what a **missing** thing would have to look like (a shape, not a name)." The subject is a primitive not held in Γ. Response diversity and functional groups are bindings from the ecology frame onto the network and bond atoms already held in Fig 13; they add no new primitive and do not move the wall (Fig 6: "IMPORT adds an atom" - this one adds none).

What remains wrong is the reverse move: taking a richness or carbon reading and naming its source without a discriminator. That is the metamerism error of section 4. Both claims are recorded here so neither is quietly lost. This correction is the same one made in the exemplar's `05_what_shape_means.md` section 5b and in the BUS pilots; it is carried forward as a method, not as a previous answer.

## 6. Prestige is not action

*The Recursive Self-Improvement Trap* (OPENED) states it directly: "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

A campaign that gathers famous ecologists to agree with the separator is the named collapse, not corroboration. The legitimate ask gives the claim a budget to be tried and lets a ground (a perturbation experiment, an inventory, a trajectory) settle it. Fig 7 :13: "agreement compounds, evidence does not."

## 7. My own audit is a simulation, not a ground reading

Same essay (OPENED): "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too (intelligence is essentially arrangement). However, the truly testable output would need to be derived from the real architecture or working the formula yourself."

So `01_figure_grounded_audit.md`, `06_isomers_and_order.md`, `07_the_tether_answer.md` and `09_watson_answer.md` are simulated derivations checked for internal consistency against the figures. They are **not** tests of the ecological claim and must be labelled as such. They cannot settle anything they report on. A real check requires a ground that this agent did not touch: measured function through a perturbation, carbon inventory with declared pools and dates, and a recovery trajectory against a declared reference.
