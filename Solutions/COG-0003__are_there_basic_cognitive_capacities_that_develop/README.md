# Solution COG-0003

**Question:** Are there basic cognitive capacities that develop similarly everywhere but are used differently across cultures?

**Source:** cognitive science.txt line 6

**Section:** 1. Universals and cultural variation

**Mode:** `general` on the structural shape, `specified` on the per-domain verdicts, nothing `grounded`.

**Status:** done

**Registry status:** pending

**Boundary and standing of this package.** Work was confined to this folder. The figures were read from the local canonical extract, `FRAMEWORK/reference/03-FIGURES_TEXT.md`, and cited as `Fig N :line`. No claim below is a ground reading. This is a simulated derivation checked for internal consistency against the figures, in the sense of *The Recursive Self-Improvement Trap*: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." It cannot settle the question it reports on. World sources are secondary corroboration only, opened and recorded in `10_source_ledger.csv`.

**Residual in effect terms.** The observed pair is (i) a stable, widely shared sequence in early cognitive development and (ii) substantial cross-cultural variation in which capacities get elaborated and what they are used for. A frame that explains (i) by a fixed inventory inside the child fails (ii); a frame that explains (ii) by local learning alone fails (i). What is owed is an account in which the shared part and the varying part are different quantities, not competing answers to one quantity.
