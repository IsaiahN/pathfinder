## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (**a shape, not a name**)."* Fig 9 :32 says *"you get a kind of thing, never the answer itself"*. Fig 13 :135 says *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel* (carried quote): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For this question a **shape** is the boundary condition any answer must satisfy before it names a medium: what crosses from an occasion into a record, what must cross with it, and what would show the crossing failed. "More knowledge was preserved" is not a shape; it is an aggregate that hides the live slot. "A bond and a reader must cross with the item, per slot" is a shape. It constrains; it does not fill.

## 2. How a shape is obtained

- *Library of Babel* (carried): use the vocabulary closest to the thing, look for recurring new terms that overlap with it, recurse: *"With each new term gained, you narrow the space and deepen your vocabulary."* For HIS-0070 the starting vocabulary is the residual (what failed to cross), not a list of media.
- Fig 6 :30: *"outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30: *"your words are borrowed too, so describe the effect rather than the cause"*.
- *Decoding Tacit Knowledge* (carried): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is why the outreach email starts with a checkable failure condition.
- *Library of Babel* (carried) on stopping: the answer is reached when *"the finish line will also be the starting place"* and by then you have *"composed the answer through the process of locating it."* Here that means the boundary condition is known when you can state the refuter without knowing which technology won.

## 3. What licenses a name

Two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* The canonical README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."* A historical case can settle whether a particular medium preserved a particular slot. A global ranking of media cannot be settled this way.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51), with a source gate and a shadow test: *"Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them, and the surplus lives only where the closures differ."*

*They're Scanning Books* (carried) sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

### Correction to my own reading (kept visible)

I initially read "shape, not a name" as forbidding the naming of any technology. That overstates it. The README's phrase governs a **missing** primitive, one not held in Γ. Writing, print, photography and digital storage are bindings from the world frame onto atoms and bonds already held; they are candidates with provenance, not invented primitives and not imports that add a member to the six. What is forbidden is claiming the framework selected them, or treating a binding as a derivation. The same correction appears in the exemplar's `05` section 5b and is standard across this project's solutions.

## 4. The source error this question is prone to

*The Hard Problem is About Source* (carried) gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*, one green light or yellow plus blue or RGB or CMYK or a scheme not yet discovered. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

The same error is endemic in the history of preservation. A preserved document is a reading. Its source (an observation, a decision, a correction, an oral performance) is not determined by the reading. A historian who names the source from the artifact commits the metamerism error. What is owed is a discriminator: a dated method, a chain of custody, a second frame that reached the same content independently. This is also why the world source on W3C PROV-O matters: it makes derivation and primary source explicit relations instead of leaving them to inference.

*The Recursive Self-Improvement Trap* (carried): *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* An archive's own catalogue cannot certify the archive's completeness.

## 5. The shape for HIS-0070, stated

An answer to this question has the following shape, and nothing more:

1. **Per slot.** For each kind of content, ask whether the medium extends an instrument already returning something, imports from a differing closure, or decays the reader channel. No single preservation score.
2. **Bond and lineage travel or the item is not knowledge.** Atoms alone are half the term.
3. **The anchor must not update.** A fixed reading can ground later frames; a living feed is a frame.
4. **Capability stays agent-and-habitat.** A recording changes the habitat; it does not by itself preserve the skill.
5. **The transform is lossy.** Report the round-trip gap rather than claiming nothing was lost.
6. **A name is a binding, not a derivation.** Which medium won a given historical case is owed to the ground.

The literal "how much more knowledge" is a `gap`: a shape with no number. Fig 8 :39 says *"So a search that finds nothing is never a proof of absence."* Here the search did find shape lines; it found no line that returns a quantity.

## 6. Two consequences for the work

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried): *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous historians who agree with the shape is the named collapse. The legitimate ask is a budget to try the refuter.

**This audit is a simulation, not a ground reading.** Same essay (carried): *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* LLM output is *"simulacra"*. So `01` is a simulated derivation checked for internal consistency against the figures. It is not a historical test and must be labelled as such. It cannot settle anything it reports on.
