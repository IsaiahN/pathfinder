# Solution COG-0005

**Question:** Do people in different societies categorize the world using fundamentally different mental structures, or mainly different learned categories?

**Source:** cognitive science.txt line 8

**Section:** 1. Universals and cultural variation

**Mode:** `general` on the structural shape, `specified` on the per-domain verdicts, not `grounded`. Every substantive file states that this is a simulated derivation checked for internal consistency against the figures, not a ground reading, so it cannot settle the question it reports on.

**Status:** done

**Registry status:** pending (registry files are outside this folder and were not modified)

**Question restated as an effect.** What would have to be observed to tell "different mental structures" from "different learned categories"? If the *mechanism* of categorization (the atoms it composes, the bonds it uses, the way a residual drives a new term, the price a term must pay) differs between societies, then the same task with a non-updating anchor should show different invariants and no shared low-dimensional structure. If only the *bindings* differ, then the mechanism and its invariants should be shared, and variation should appear in which items group together and where boundaries fall. The two options are treated as an effect claim, not as a vocabulary preference.

**What an answer would look like (Direction, made an ordinary term).** A finished answer would (1) name the shared mechanism and its invariants, (2) name the variable bindings and say what selects them locally, (3) keep a verdict per category domain and society rather than one global percentage, (4) name the instrument that would decide a disputed slot, and (5) state what would refute each part. The sought-for shape is written down here before the run so it can accrue a residual like any other term.

## What is deliberately not here

- No personal emails of named individuals.
- No ranking of people by how likely they are to agree with the verdict.
- No bulk-send plan. "High correlation is disqualifying for a verdict and efficient for a convention" (Seat Map :163) is the structural reason; selecting recipients for receptiveness manufactures the correlation that would make their agreement worthless.
