## 1. A shape is a constraint, not a filler

The canonical usage rule: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134-135: *"Unreachable is a verdict here, not a silence,"* and *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel* (opened): *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For this question a **shape** is the form any answer must have before we can name which categories a particular society uses:

- an invariant mechanism, residual-driven and priced, shared across societies;
- a bond grammar, so that bindings can be compared;
- per-slot indexing, so that a colour result does not stand in for a kinship result;
- a non-updating anchor, so that a difference is not a mirror;
- an open feature list, because the framework cannot name primitives.

The shape is not "all humans have the same categories" and not "every society has a different mind." Both of those are names with no discriminator behind them.

## 2. How the shape is obtained

- *Library of Babel*: start with the vocabulary closest to the thing, note recurring new terms that overlap or correlate with it, and recurse. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30 *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31 *"your words are borrowed too, so describe the effect rather than the cause."* This is why section 0 of `01` states the two options as predictions under a common task, not as anthropological slogans.
- *Decoding Tacit Knowledge* (carried from the exemplar): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* That is the outreach form of the non-updating anchor.
- *Library of Babel* on stopping: the answer is reached when *"the finish line will also be the starting place"*, with the paradox that you have *"composed the answer through the process of locating it."* Here that means the discriminator you would need to settle a slot is the same thing the shape tells you to build.
- The same essay also says a malformed question may be *"a bundle or conflation of several problems masquerading as one"* and must be searched individually. That is Fig 9 :54 for the present either/or.

## 3. What licenses a name

Two things, both outside the shape:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays."* In this question, a non-updating anchor measurement in a named domain.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :51-52). A cross-cultural dataset is not automatically an import; it is one only if it supplies an atom the first frame did not hold.

*They're Scanning Books* (carried): *"The real import is not a new term in the existing space. It is a new dimension of the space."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."* Kay and Regier (2003) are the worked instance: the universal they found was not declared from a WEIRD sample but measured against a fixed 330-chip array across 110 unwritten languages. The instrument, not the authority, named it.

## 4. Why the question's own either/or is the forbidden error

*The Hard Problem is About Source* (opened): *"If several paths create the same behavior, then behavior is a projection with lossy information"*; and the instrument that cannot distinguish the sources *"demonstrates its own inadequacy."*

A cross-cultural sorting difference is a projection. Several sources can produce it: a different learned binding, a different mechanism, a translation gap, a sampling artifact, a different local ground. Asking "which of the two offered answers is it?" treats the projection as if it determined the source. Fig 9 :30-31 requires describing the effect rather than the cause, and `THE_FORMULA.md` step 2 assigns the REFUTED case its own bin: what is owed may be a refusal of the question's framing, not an explanation inside it.

The spectrometer resolved the green case; no argument did. The corresponding instrument here is a per-domain task with a fixed stimulus array, an independent second frame, and a failure condition written in advance.

## 5. Correction to my own section 3 (kept visible)

**First reading.** I wrote that the framework forbids naming any specific category, because it returns *"a shape, not a name."*

**Correction.** The canonical phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a primitive not held in the library. Colour foci, taxonomic and thematic relations, classifiers and generics are not missing primitives; they are bindings onto capacities that human learners already have (Fig 4 :19-20, Fig 11). Naming one is a provenanced binding from the psychology frame, not the invention of a seventh term and not an import that moves the wall: Fig 6 :22 *"IMPORT adds an atom"*, and this adds none. What remains forbidden is claiming that the framework itself *derives* which binding is universal, or naming a new primitive set. Both the first reading and the correction are recorded so neither is silently lost. This mirrors the correction in the exemplar's `05` section 5b.

## 6. Two consequences for this question

**Prestige is not action.** *The Recursive Self-Improvement Trap* (opened): *"Prestige must never be allowed to validate an action directly. ... Someone let prestige stand in for proof. ... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* A universal claimed because a famous anthropologist asserted it, or a variation claimed because it is fashionable, is the same collapse. The ask in `02` is for a refutation, not an endorsement.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output ... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01`, `06`, `07`, `09` and `11` are simulated derivations checked for internal consistency against the figures. They are **not** tests of the universals question and must be labelled as such. They cannot settle anything they report on. Fig 2 :35 *"Alignment is triangulation, not negotiation. A mirror cannot correct you."*

## 7. One-paragraph version of the shape

The shape is this: categorization is a residual-driven, priced mechanism that human societies share, and the differences between societies are bindings over that shared set, related to one another as isomers rather than as different kinds of mind. The feature list stays open, because the framework returns a kind of thing and never the answer itself. A cross-cultural difference is a reading that cannot name its own source, so the shape also requires a non-updating anchor and an independent frame in every domain before any difference is counted. What is owed next is not a verdict but instruments: a per-domain task that would show a mechanism difference, a shared-atom test that could break the isomer mapping, and a second frame that does not share the first frame's evidence pool.
