## 1. A shape is a constraint, not a filler

The local canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13: *"It can say the answer is out of reach with the library as it stands... It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel* (verified this session): *"This means that you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So for ECO-0038 a **shape** is the form of an answer we can state before we can name the number. It has four parts: disturbance valence is relative to a residual; the residual is per slot; the sign is decided by a threshold comparison between two quantities; and effects cascade across scales. What it does not have is the value of the threshold, the identity of the disturbance regime, or the identity of the community. `Disturb every N years` is a name. `The sign flips where the return interval crosses the recovery time for the slowest limiting slot` is a shape.

## 2. How a shape is obtained

- *Library of Babel* (verified): use the vocabulary already closest to the thing, then look for recurring new terms that overlap or correlate with it. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge* (carried): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping (verified): *"You will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better."*

For this question the effect-term description is deliberately not "biodiversity" as a single thing. It is: which species slot is declining, after how many disturbance returns, at what scale, and which slower variable (seed bank, soil carbon, mutualist) has not recovered. That is checkable against the world in a way that "intermediate disturbance is good" is not.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."* Here that means a measured before/after trajectory or a controlled disturbance experiment, not a citation count.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. Connell's 1978 hump is an import from the ecology frame. It may be used, but its provenance must travel with it; it is not a figure-derived primitive.

*They're Scanning Books When They Should* (carried) sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

## 4. Why "one diversity number" is the forbidden error here

*The Hard Problem is About Source* (verified this session) gives the mechanism. Metamerism: an instrument that reads green *"cannot comment on the source."* The same reading can come from one green light, yellow plus blue, RGB, CMYK, or a scheme not yet discovered. The paper states: *"If several paths create the same behavior, then behavior is a projection with lossy information"* and *"The answer is unreached until a better instrument exists."* It was the spectrometer, not an argument, that resolved it.

A Shannon index is a projection of a species-abundance distribution. It can stay flat while one rare species disappears and a dominant becomes more even. Fig 1 :22: *"Aggregating across slots is how a live signal disappears into an average."* Svensson et al. 2012 found precisely this in the literature: richness and evenness disagree about the IDH in over 75 percent of studies that used both. What is owed is a better instrument (per-slot, abundance-distribution-aware measurement), not a single preferred index argued into place.

## 5. Q: does the framework return the disturbance threshold?

**No.** The framework returns the form of the relation: a threshold comparison between two quantities, with the sign depending on which side is larger, a residual measured per slot, and effects that cascade. It does not return the number. A number is licensed only by a ground settlement (a measured trajectory) or a provenanced import (a specific ecosystem study), and must be labelled as such.

**Does the ecological literature commit the error the README forbids?** Partly. When a review reports "the IDH holds" as a single verdict across systems, it reads one projection (a compound diversity index, often at one scale) and names a source ("intermediate disturbance maintains diversity") where several sources could produce that reading. Svensson et al. 2012 and Dornelas 2010 each show multiple mechanisms generating the same hump. The correct form is the unbundled shape plus provenance for whichever binding is being claimed.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried): *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A campaign that gathers famous ecologists to agree with the IDH is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay (carried): *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* LLM output is *"simulacra."* So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the ecological claim and must be labelled as such. It cannot settle anything it reports on.
