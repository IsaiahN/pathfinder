## 1. A shape is a constraint, not a filler

The canonical usage rule states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13 :135: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

The exemplar's local 05 file records the Library of Babel formulation (as quoted there, not re-verified): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- `BEFORE(???)` is a shape: it records that an ordering is owed and that its referent is not held.
- "a smooth pre-inflationary time before inflation" is a name: it fills the slot from outside the derivation.

The distinction matters because the question asks for the meaning of a phrase, and the honest answer to a phrase whose referent is unavailable is the shape of the referent, not a referent.

## 2. How a shape is obtained

- Describe the residual in effect terms, not the cause: Fig 9 :30 *"your words are borrowed too, so describe the effect rather than the cause"* and Fig 9 :27 *"describe it before you go looking, or any frame you pick will seem to fit"*.
- Cast it so the description travels: Fig 6 :30 *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."*
- Enumerate the habitat rather than composing it: the exemplar's local 05 file records the tacit-knowledge essay (as quoted there, not re-verified): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- Stop where instruments can no longer distinguish, and record the lineage. The canonical rule says the framework returns a shape and then *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest"*. *"Indiscernibility is not identity."*

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* For "before inflation" this would be an instrument returning a discriminant that orders pre-inflationary configurations with respect to inflation. Hawking's *"there's no way one could measure what happened at them"* and Keating's *"If there isn't a discriminant you can measure, you're doing metaphysics with equations"* both say we do not have one.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :50-52). The no-boundary proposal is such a candidate import, but it carries live internal disagreement (Quanta, Scientific American), so it is a candidate, not a settlement.

The exemplar's local 05 file records the source-discrimination essay (as quoted there, not re-verified): an instrument that reads green *"cannot comment on the source"*, and *"If several paths create the same behavior, then behavior is a projection with lossy information."* Applied here: observing an inflationary universe does not determine whether there was a temporal before, a structural before, or no referent at all. Several sources give the same projection.

## 4. The two specific errors this question must refuse

1. **Reification.** Turning the boundary marker into a time or a primitive. Fig 13 :135 forbids naming a primitive the frame does not hold. Time is held, but its referent at the boundary regime is not settled, so a named "pre-inflationary time" is an import without a source gate.
2. **A verdict of absence.** Saying there was nothing before inflation. Fig 8 :39: *"a search that finds nothing is never a proof of absence"*. Hawking's "meaningless" is a claim about the availability of a referent, not a claim that the world was empty.

Both errors convert a shape into a name. Both must be recorded as refusals.

## 5. Does "shape, not a name" forbid speaking of time here? ANSWERED, with a correction to my own first reading

**First reading (retracted).** I initially applied the rule to time itself and concluded that the framework forbids any temporal language at the origin. That was wrong.

**Corrected reading.** The canonical phrase is *"what a **missing** thing would have to look like (a shape, not a name)"*. The subject is a primitive not held in Γ. Time is one of the six held states (Fig 13 :11-12). So the rule does not forbid naming held atoms. What it forbids here is filling the referent of the **ordering** at a regime where the held atom has not settled. The shape restriction applies to `BEFORE(???)`, not to the word "time".

This correction is kept visible in `01_figure_grounded_audit.md` section 6 and is derived the same way the exemplar derived its own correction in `06_isomers_and_order.md` Q1.

**The residual shape answer:** a structure of precedence is owed; operational and structural precedence survive; the temporal referent is unreachable with the current library; and the honest report of the unreachability is a verdict, not a silence (Fig 13 :134).
