## VERDICT (from the figures)

The question has no single yes/no. Per slot: many low-mass galaxy centers do **not** match the dense collisionless cusp (an inner mass deficit or core is inferred), while more massive dwarfs and some ultra-diffuse galaxies **do** match it. The cusp prediction is correct inside the dark-matter-only closure, and no search inside that closure produces a core (D1, `triangulated`). The measurement channel is a live strain because profiles are inferred from rotation curves with a documented reconstruction failure (D2, `triangulated` for the distribution, `single-source` for the channel). A core-forming atom exists in a different closure and is an import with provenance, not a derivation, and it does not close every reported deficit (D3, `single-source` for the atom, `gap` for the correct mechanism). Agreement inside one evidence pool has zero corroboration weight (D4, `triangulated`). This is a `specified`, ungrounded, candidate result. The shape any answer must have is: less central mass at fixed V_max in the low-mass slots. Which mechanism realizes it is not returned by the framework.

- **cost if wrong:** bounded and locatable. If we call the residual a model failure when it is an inference failure, we discard a working model and point instruments at the wrong quantity. If we call it a match by averaging slots, we hide the live signal (Fig 1 :22). Fig 2 :42 prices the response: *"Buy independence in proportion to the cost of being wrong."* The cost is reduced by leading with the per-slot claim and its four refuters.
- **undoable:** yes. No atom is deleted. The per-slot verdicts, the import provenance and the channel strain are recorded separately, so a new independent mass measurement or a convergence-tested simulation can revise any one of them without disturbing the others. A sent claim can be superseded by a corrected packet.
- **reversed by:** a ground reading, not agreement. An independent mass probe showing NFW-consistent slopes in the low-mass slots refutes the cored-slot reading; agreement between that probe and gas-kinematics profiles in the same objects closes the channel strain; a hydrodynamical simulation reproducing the deficits from observed star-formation histories with reported convergence tests closes the import question; a demonstration that the residual is a partition rather than a union forces a re-census. If the channel and import tests fail to close every slot, the fifth kind applies and a negation of the held collisionless binding is owed. Until one of these fires, the verdict stands as `candidate`.
