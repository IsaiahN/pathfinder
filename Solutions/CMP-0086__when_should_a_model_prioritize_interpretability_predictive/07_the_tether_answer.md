# The Tether's answer on model priorities

**Mode: `specified` - not `grounded`.** This is a shape and a route, not a result. It is a simulated derivation checked against the figures (`05_what_shape_means.md` section 6), not a ground reading.

## 1. The residual it answers

A model predicts Γ(b,a); the world returns o′; R = |Γ(b,a) − o′| is indexed per slot (Fig 1 :19). The four objectives are four anchors against which a slot's residual can be ranged. The live residual is the slot where one anchor says "settled" and another says "not settled." The question "which objective is first" is a single lever on what Fig 9 :55 calls *"a union of overlapping conditions, not a list of separate ones."*

## 2. The shape: a four-row assignment, not a ranking

> **Fig 9 :56** "A single lever clears the region where only one condition holds and leaves the intersections standing, because the second condition still binds."

1. **Predictive accuracy first when the live residual is on the validation ground and no second condition binds.** Accuracy is the only metric for the prediction question: *"The ground enters as the only metric."* (Fig 1 :23). It is necessary and never sufficient. It is a filter for what gets tried, not a witness for the other three (Fig 9 :60).
2. **Interpretability first when the question is constitutively about a person reading, checking or contesting a decision.** Fig 2 :37: *"Human judgment is the right anchor for is this a good answer for a person, because the question is about people."* For "is this code correct," the same passage says human judgment is only an instrument. Interpretability is also a dependency prerequisite: a vocabulary without bonds cannot name a route (Fig 12 :111), so a readable feature list is not automatically an intervention guide.
3. **Mechanistic realism first when there is a source-discriminating instrument and the live residual is at the generator.** Otherwise the honest output is a shape and a gap: *"you get a kind of thing, never the answer itself"* (Fig 9 :32). Where nothing registers, there is no edge to extend from (Fig 6 :34-35). A mechanism is invariance under intervention, not a fit to a reading.
4. **Usefulness for intervention first when the model will be used to act and the binding constraint is contact with the habitat.** Fig 11 :39: *"capability is a property of agent-and-habitat, never of the agent alone."* Fig 11 :40: *"An improvement that does not change contact changes nothing, however much it improves."*

**Ordering rule.** Among the four rows, work lowest unreached link first (Fig 3 :19-20). Representation and vocabulary precede the objective; the objective precedes planning. Accuracy grounds all of them but does not authorize any of them. Keep bits and actions in separate ledgers (Fig 12 :125-130). When conditions overlap, unbundle and run a loop per condition; the intersection is a new compound, not a harder single case (Fig 9 :57).

**Independence rule.** Buy checks in proportion to the cost of being wrong (Fig 2 :42). Agreement from one evidence pool is one witness (Fig 2 :40).

## 3. What it explicitly does not say

- Not a universal first objective, and not a total order of the four words.
- Not a single summed model-quality score. Bits and actions do not add.
- Not that human judgment settles code correctness, and not that a benchmark settles contestability.
- Not that a mechanism has been named where no discriminating instrument exists. That is a `gap`, and unreachable is a verdict here, not a silence (Fig 13 :134).
- Not that a model is useful for intervention because it is accurate on a held-out set.
- Not `grounded`. No measurement in this derivation settles which condition binds in any particular deployment.

## 4. What would settle it - the ground

A ground reading, not a further argument. For each row:

1. **Accuracy:** a held-out measurement that stays small on new slots, not just on the training distribution. An instrument already exists; the question is whether it is being ranged against the right habitat.
2. **Interpretability:** an application-grounded test with real people doing the real task (Doshi-Velez and Kim's taxonomy), not a sparsity proxy. The proxy is a filter, not a witness.
3. **Mechanism:** a design or instrument that discriminates among candidate sources, as the spectrometer did in the metamerism case. Until then, report the shape and the gap.
4. **Intervention:** a deployment test that changes contact and measures the outcome, including a habitat substitution. Lipton's pneumonia/asthma case is the standing counterexample to accuracy-only reasoning.
5. **The union:** a case where all four bind and disagree, followed by an intervention that clears the compound without a second lever. If such a lever exists and survives, F1 is refuted.

Standing falsifiers are the eight in `01_figure_grounded_audit.md` section 4, written before this answer.

## 5. The honest stop

**Unreached, not unreachable.** The four objectives are a visible choice of evaluation axes, not nature's own list. The framework returns the shape any acceptable answer must have, the refuters written in advance, and the instruments that would close each row. It does not return a winner. The stop is recorded with its lineage so a later reader can locate the error. Indiscernibility is not identity.

## 6. One-paragraph version for outreach

> The figures do not rank interpretability, accuracy, mechanistic realism and intervention usefulness. They say the four are a union of overlapping conditions, not a list of levers, and that a single quality score clears the easy cases while leaving the compound cases standing. Priority is therefore per case and dependency-ordered: accuracy is the only metric for the prediction slot; interpretability is a genuine anchor only when the question is about a person's ability to understand and contest a decision; mechanistic realism is a shape until a source-discriminating instrument exists; and usefulness for intervention is a property of model and habitat, so accuracy without changed contact does not improve it. Bits and actions are two currencies and do not add. What the framework offers is the four-row shape any answer must have, falsifiers written in advance, and the tests that would close each row. The compound case stays open until a ground settles it.
