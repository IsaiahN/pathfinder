**Subject:** Check one shape about model evaluation before you decide whether the framework is worth reading

> Hi [name],
>
> I have one specific output I would like you to check against what you already know about model evaluation. I am not asking you to read the framework first, and I am not asking you to agree with it. If the output does not survive, there is nothing else to look at.
>
> **The question as I have stated it (`specified`, not `grounded`):** when a model is deployed, four things can be binding at once: predictive accuracy, interpretability, mechanistic realism, and usefulness for intervention. The shape claim is that these are not a ranking. They are a union of overlapping conditions, and each one is legitimate only against the anchor its own question is constitutively about. The residual is indexed per case, not averaged (Fig 1 :19). A single quality score clears the cases where only one condition holds and leaves the compound cases standing.
>
> The four rows I would ask you to check:
>
> 1. **Accuracy** is the only metric for "does it predict," ranged against a held-out measurement. It is necessary and not sufficient.
> 2. **Interpretability** is a genuine anchor for "can this person understand and contest this decision," because that question is about people. It is only an instrument for "is this code correct."
> 3. **Mechanistic realism** is settled only by an instrument that discriminates among sources. Where none exists, the honest output is a shape and a declared gap, not a named mechanism.
> 4. **Intervention usefulness** is a property of model and habitat, not of the model alone. Better held-out accuracy with no change of contact does not make a model more useful to act on.
>
> **What I am not claiming:** that one of the four always comes first, that a single number can balance them, that an interpretable model is always accurate, or that a mechanism has been identified where no discriminating instrument exists. Bits and actions are two currencies and do not add, so I keep them in separate ledgers rather than publishing a summed score.
>
> **What would refute the shape:**
> 1. a single scalar model-quality objective that preserves all four per-case residuals and resolves their intersections without a second lever;
> 2. human judgment shown to settle "is this code correct" without an instrument, or a metric shown to settle contestability without a person;
> 3. a model with no ordered structure shown to guide a novel intervention reliably against a ground;
> 4. intervention capability gained through held-out accuracy alone, with no change of contact, sustained across a habitat substitution.
>
> I wrote these down before sending this. If any one holds, the shape is wrong and I will retract it. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** the sources are below. The figures are the authority, not my summary of them.
> - The canonical figures README (public): https://github.com/IsaiahN/tether/blob/general-agent/figures/README.md
> - The formula and figures for direct download (branch `general-agent`): https://github.com/IsaiahN/tether/tree/general-agent/figures
> - The two-stage evaluation taxonomy: https://arxiv.org/abs/1702.08608
>
> **If you want to use the machinery:** the formula is in the figures link. Run it on an evaluation problem you know well and can check against a ground. Write down what would refute your result *before* you run it. The write-up warns that outputs can be contrived to fit the formula, so a reported failure is more useful to me than a reported success.
>
> — [name]
