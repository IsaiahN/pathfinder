## 1. The claim, in one paragraph

A set of object slots that returns no electromagnetic light cannot, from inside the electromagnetic frame, distinguish an empty slot from a non-luminous occupant. More exposure is idempotent, so the null is a channel reading and the ground is elsewhere. The question therefore has the shape of a second-frame question: an instrument whose currency and anchor differ (here strain and coincident detector strain) must range the same residual, and a black-hole population is a distribution inferred from resolved slots rather than a number read off the sky. The framework returns that shape and refuses to name the population; a mass peak or formation channel is a provenanced import from the astronomy frame, not a derivation.

## 3. What is explicitly not claimed

- Not that the framework discovered, derived or predicted any specific black-hole population.
