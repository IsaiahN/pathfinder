## 0. The residual in effect terms

Let `R` be the gap produced when an electromagnetic instrument looks at a set of object slots and returns null, while population synthesis, stellar evolution or general relativity says something should occupy those slots. In effect terms, not instrument terms:

- **What failed to resolve:** whether a null reading is a fact about the population or a fact about the channel. Both produce the same observed string of zeros.
- **Per slot, not per average:** the null lives on individual slots. Fig 1 :19 *"The residual is indexed by object slot, not aggregated."* Seat Map :20 names the exact channel failure: *"The anchor does not decay. - **Option A:** read the null as absence. There is no population. Stop looking. This treats the electromagnetic closure as though it were the ground.
- **Option B:** read the null as depth. Something is there that this closure cannot represent. Range the residual against an instrument whose currency and anchor differ. This treats the null as a channel fact and keeps the ground elsewhere.

Binding this shape as an ordinary term is the formula's "Direction" discipline, so the preference becomes refusable.
