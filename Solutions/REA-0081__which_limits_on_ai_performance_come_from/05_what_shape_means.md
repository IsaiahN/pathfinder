## 1. A shape is a constraint that can be stated before the cause can be named

The canonical statement in `FIGURES_README_canonical.md` is that the framework returns "what a missing thing would have to look like (a shape, not a name)," then stops at the limit of the available instruments and records the lineage. "Indiscernibility is not identity."

Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence."

From *The Library of Babel*: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For this question, the shape is **the decision procedure**: underivable (architecture wall, import required), unreachable-at-budget (resources, more search required), unfound-at-same-reach (more of the same space), and contact-limited (habitat, not agent). That is a shape because it constrains what any answer must distinguish before it can name a cause in a real system. Naming a specific cause in GPT-4, or in any model, would be a name, and requires a ground reading this folder does not have.

## 2. How the shape is obtained: proximity and narrowing

*The Library of Babel*: "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary." The searcher uses known vocabulary closest to the unknown thing, watches for new terms that overlap or correlate, and recurses.

Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."

That is why the residual in `01_figure_grounded_audit.md` is stated as an effect ("a shortfall that more budget may or may not close") before any figure line is chosen. Picking "architecture" or "compute" first would be echo without shadow: the frame would fit whatever it was given.

*The Library of Babel* on stopping: "You will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better." Here the stop is the point at which the four verdicts no longer move under more search, not the point at which a cause name feels satisfying.

## 3. What licenses a name

Two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The canonical README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23; Fig 8).

*The Hard Problem is About Source* gives the discriminator. Metamerism: an instrument reads green and "cannot comment on the source." The essay's general form: "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it. The essay states the upgrade rule directly: "The answer is unreached until a better instrument exists."

Applied here: a single loss curve is a projection. Architecture, budget, and habitat can produce the same curve. The instrument owed is a discriminating intervention (fixed-closure budget sweep, architecture swap at fixed budget, or a real-habitat test), not another argument about which cause "really" explains scaling.

## 4. Why the verdict cannot be a single averaged number

Fig 1 :22: "Aggregating across slots is how a live signal disappears into an average." Fig 1 :27: "They are frame-internal. A frame cannot score itself with a quantity it also produces."

Fig 9 :60: "Use filters for the budget and witnesses for the verdict. Never let a filter hand you a verdict."

A single "scaling score" combines bits (data) and actions (compute, energy), which Fig 12 :125 says "do not add." Averaging the four domains would throw away the live residual that says which cause is active. So `07_the_tether_answer.md` reports four verdicts and never merges them.

## 5. Q answered: what does "shape" forbid and permit here?

**Forbids:** naming a cause for a particular observed limit without a ground test; summing data, compute, and energy into one quantity; treating a benchmark solve as capability; concluding from one performance curve that a cause is architectural.

**Permits:** stating the four-way decision procedure; saying which condition would have to hold for each verdict; reporting "unreachable with the library as it stands" when no discriminating instrument exists; writing the refuter before the run.

**Correction to my own §3:** "shape, not a name" governs a *missing* primitive, not the use of ordinary words. "Architecture" and "resource" are ordinary terms bound to effects in this folder, not claimed new primitives of the framework. What would be forbidden is declaring a seventh kind to explain an AI limit. No such declaration is made here.

## 6. Prestige is not action, and this is a simulation

*The Recursive Self-Improvement Trap*: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A list of famous researchers who agree with the distinction would fund a trial; it would not verify the distinction.

Same essay: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." And: "the truly testable output would need to be derived from the real architecture or working the formula yourself."

So `01_figure_grounded_audit.md` is a **simulated derivation**, checked for internal consistency against the figures. It is "simulacra" in the essay's word, not a test of any AI system. It cannot settle the question it reports on. This is stated on every substantive file in the folder.

## 7. Contact, effect terms, and the two-stage offer

*Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." That is the whole method behind `02_outreach_email.md`: send the effect description and its refuter first, and only offer the framework after the reader has recorded a verdict. The essay also quotes Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."

The essay's drift warning applies to any follow-up: two readers who share one evidence pool are "one frame wearing two names," so later agreement is never pooled as corroboration.
