## 0. The residual, stated as an effect

The question asks for a discriminator between two classes: A, a system that pursues goals; B, a system that follows instructions. The residual R is the observed ambiguity. The same outward sequence of percepts and actions is compatible with both descriptions, so behaviour alone does not partition the two.

State the candidate answers as effects:

- **Essence answer (A intrinsic):** the system has a goal state, desire, or intention inside it. What it leads to: a classification by interior that no outside checker can measure, and a name that varies by field (an economist's "agent" is a tool-like delegate; an AI engineer's "agent" includes a thermostat).
- **Source answer (B extrinsic):** the aim is supplied by an instructor. What it leads to: a classification by provenance of the aim, which is checkable in principle but collapses the two classes whenever an instructor supplies an aim that the system also holds and maintains.
- **Contact answer (derived below):** the discriminator is a property of agent-and-habitat, not of the agent alone. Ask two questions: can the system say what would count as progress in its own terms, and does its channel to the ground survive the removal of the instruction stream? What it leads to: a shape with a falsifiable operational test, and an honest stop when no instrument can read the interior.

Bind the sought-for shape as an ordinary term before continuing (Formula, "Direction"): **an answer would look like a checkable relation between a held aim, a maintained channel, and a ground, stated in effect terms and refusing to name an inner essence.** That binding is the thing the refuter will test.

## 1. Domain census

Describe R by arity, symmetry and scale, then one line per domain with actors, currency and anchor. No nameable anchor means it is not yet a domain.

**R (arity / symmetry / scale).** Arity: two conditions that co-occur (a system can follow instructions while pursuing a goal), so this is a **union compound**, not a partition. Symmetry: asymmetric; a goal is a comparison (⋛) and progress is a subtraction (−), both ordered bonds, so swapping the two classes does not preserve the relation. Scale: one scale for the loop's internal links (Fig 3 steps 1 to 5), one membrane for agent and habitat (Fig 4, Fig 11).

**Partition or union.** D1 is a genuine partition boundary (a vocabulary either contains the comparison term or it does not). D2 is a union compound (contact and system co-produce capability). The overall split is a union, so it must be unbundled before search: Fig 9 :54 "when the split lands on a union rather than a partition, unbundle before you search again"; Fig 9 :57 "a case in two conditions is not a harder case of either". The three domains are distinct loops, not one average.

**Order by dependency (Fig 3).** Settle D3 first (if the question is the wrong shape, answering it directly is a category error), then D1 (the objective link), then D2 (contact). Fig 3 :29-30: "Before asking whether a system is good, ask which link it currently stops at, and whether the answer was measured or assumed." ## 3. Findings

### F1 — The objective link is the internal discriminator (triangulated, `general`)

Fig 3 :10, the third link of the dependency chain:

> **"it can say what would count as progress here, in its own terms"**

Fig 12 :111-112:

> **"A vocabulary without bonds can name a state and cannot name a route to one."**
> **"A plan is a sequence. A goal is a comparison. Progress is a subtraction."**

Operators table :52:

> **"a goal is a comparison, which is why a vocabulary without it cannot state one"**

A tool can be driven by a residual whose comparison lives in the instructor's vocabulary. Its own Γ need not contain a bound "what counts as progress" term; the instructor supplies the ⋛ and the −. An agent, on this reading, is a system whose Γ contains the comparison and the subtraction as bound, predicting terms, so the aim is in its own closure and survives when the instruction stream stops. Fig 3 :25-27 is the reason this link is the discriminator: perception and planning have instruments, but "having terms for what a situation offers and being able to say what would count as progress" has neither, so it attracts the least attention. A link with no instrument is not a link that works; it is a link nobody has looked at.

Verdict: **triangulated** across Fig 3 and Fig 12 plus the Operators table (low overlap: one is the dependency chain, the other the composition theory). Mode `general`, structural. Refuter: exhibit a system that genuinely pursues a goal while holding no comparison term in its own vocabulary, with the comparison entirely in an external instruction stream that is demonstrably doing the aiming. If that exists, F1 fails.

### F2 — Capability is agent-and-habitat, not agent alone (triangulated, `general`)

Fig 11 :39-40:

> **"capability is a property of agent-and-habitat, never of the agent alone."**
> **"A system cannot be made more capable by improving the agent in isolation. An improvement that does not change contact changes nothing, however much it improves."**

Fig 10 :24:

> **"the ground does not decay, the channel does"**

The tool/agent binary is therefore not a property of an interior. It is a fact about a compound. A tool's contact with the ground is mediated by an instructor; cut that channel and the loop has no ground to range against. An agent maintains its own channel. Fig 11 :36 supplies the consequence for the word "agent": "intelligence is a label applied afterwards to a lineage that met its ground". The label is retrospective and contact-derived, not a declaration.

Verdict: **triangulated** across Fig 11 and Fig 10 (different figures, different offices: habitat and ground maintainer). Mode `general`. Refuter: the figure names its own, at Fig 11 :72: "an agent-only improvement that moved the ground would refute the capability claim." If an isolated interior change moves the ground, F2 fails.

### F3 — The question itself is a substrate question (triangulated, `general`)

Fig 11 :34-35:

> **"What is intelligence?"**
> **"The wrong question, and this figure is the replacement for it."**

Fig 11 :41:

> **"asking what generates lift rather than whether a thing is a bird"**

The question "what distinguishes an agent from a tool" belongs to the "what is intelligence" family. It asks for a substrate boundary. Fig 11 replaces it with the contact question: what makes a system capable. The answerable form of the user's question is therefore: what contact and vocabulary make a system capable of holding an aim. Applying Fig 2 :36, "An anchor is legitimate when the question is constitutively about it", the ground is the right anchor for this question because the question is constitutively about what the system does in contact with a world, not about what observers call it.

Verdict: **triangulated** across Fig 11 and Fig 2. Mode `general`. Refuter: produce a single, stable, cross-field definition of "agent" that makes the label itself do the classificatory work, with a ground that pays for it. If that exists, the dissolution is unnecessary. World sources below show the opposite: engineering counts a thermostat as an agent while economics defines an agent as a delegate acting for a principal.

### F4 — The operational discriminator: cut the channel (specified, single-source for the test)

Fig 1 :19 and :22:

> **"The residual is indexed by object slot, not aggregated."**
> **"Aggregating across slots is how a live signal disappears into an average."**

Fig 1 :23:

> **"The ground enters as the only metric."**

Symbols table :39-40: "It is the aim, not only the error signal". A tool can drive the instructor's residual toward zero on the instructed slot while a live slot remains unaddressed; aggregation hides exactly this (Fig 1 :13: "a global R near zero with one live slot residual is a legal state"). The operational test follows: remove the external instruction stream and ask whether a live slot residual persists and is treated as the aim for the next action. If the aim collapses with the channel, the system was a tool. If a live slot remains and steers the next bet, the aim was held in the system's own vocabulary.

This finding is deliberately narrower than F1 to F3. Per-slot R is a property of any well-run loop, so it cannot by itself divide the classes. It works only as the channel-cut test, which is why its mode is `specified` and its status is **single-source** (Fig 1 plus the Symbols definition, which overlap as framework primaries). Refuter: show a case where cutting the instruction stream leaves a live slot residual that is then treated as aim, yet the system is correctly classified as a pure tool on independent grounds. That would break the test.

### F5 — Agreement cannot settle the classification (triangulated, `general`)

Fig 2 :35:

> **"Alignment is triangulation, not negotiation. A mirror cannot correct you."**

Fig 7 :35:

> **"A room's agreement is variation, not a verdict. Selection between rooms is where the ground votes."**

Fig 10 :59: "an interest in the outcome is unavoidable, an interest in the reading is disqualifying". A panel of specialists who agree that a system "has goals" is one room. If they share an evidence pool, Fig 2 :40 applies: "agreement about the world is worthless when the agreeing frames share an evidence pool". This is not a side objection; it determines the outreach order in `02` and `08`.

Verdict: **triangulated** across Fig 2, Fig 7, Fig 10. Mode `general`. Refuter: exhibit a classification that becomes settled by voting alone, with a ground that pays for the vote. None is claimed here.

### F6 — No new primitive is owed (single-source, `general`)

Fig 13 :115: "The set is closed. The arrangements are not. That gap is why import exists." Fig 6 :23: "No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs." The discriminator uses terms already held: ⋛ for the aim, − for progress, → for the plan, R for the residual, and the habitat for contact. No seventh term is minted, and no import that moves the wall is claimed. What the world sources contribute is location, not machinery: they tell us where the name "agent" is used differently, which supports F3 without adding a primitive.

Verdict: **single-source** for the closure claim (Fig 13 with Fig 6 as a near neighbour). Mode `general`. Refuter: show the discriminator requires a primitive not in the six plus eight operators.

## 4. Pre-registered refuter

Required before any outreach: a falsifier written before the run is a design instrument. Written here before the conclusion of this audit and before `07` and `08` were drafted.

The shape claim is refuted if any of the following holds:

1. A system is shown to pursue a goal while holding no comparison term in its own vocabulary, with the comparison demonstrably external (breaks F1).
2. An improvement to the agent in isolation is shown to move the ground, with contact unchanged (the figure's own refuter, breaks F2).
3. A single stable cross-field definition of "agent" is produced that makes the label itself the classifier, with a ground that pays for it (breaks F3).
4. A system classified as a pure tool on independent grounds retains a live slot residual treated as aim after the instruction stream is cut (breaks F4).
5. A classification is settled by expert agreement alone with no ground reading (breaks F5).

Until one is run, no part of this may be labelled `grounded`. The circuit in F4 is the cheapest to run and should be tried first, because F1 and F2 presuppose a working test for where the aim lives.
