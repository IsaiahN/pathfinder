## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence," and Fig 13 :135 says it cannot say which primitive is missing, because naming it would mean already holding it.

From *The Library of Babel*: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- `SPACE(???)TIME` is a shape. The structure slot is marked unknown.
- `SPACE(network)TIME` or "spacetime is a QECC" is a name or a binding.

The difference matters because the question itself asks for a name ("quantum error correction"). The framework's honest contribution is the shape any answer must have, plus a written account of what would license a name.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: *"the finish line will also be the starting place"* and the paradox that by then you have *"composed the answer through the process of locating it."*

Applied here: the effect description is not "code" or "geometry" but "a structure must sit between space and time, and continuity is a leftover of the composition." That is checkable by anyone who reads the figure lines, whatever their priors about QEC.

## 3. What licenses a name

Two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with source gate and shadow test.

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source."* The paper's own line: *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"The answer is unreached until a better instrument exists."* It was the spectrometer, not an argument, that resolved it. *"An instrument that can't distinguish these cases demonstrates its own inadequacy."*

For this question, reading area-law entanglement off a boundary theory and naming its source as "QEC" is exactly the metamerism error: several source structures (network, functional group, entropy gradient) could yield the same geometric reading. What is owed is a source-discriminating instrument, not a name. This is the deepest reason F5 in `01_figure_grounded_audit.md` is a `gap` on the identification.

*They're Scanning Books* sharpens the import rule: *"The real import is not a new term in the existing space. It is a new dimension of the space."* Also: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Declaring the six *"does not make them neutral. It makes the choice visible."*

## 4. Q1 ANSWERED: does the framework name QEC as the structure of spacetime?

**No.** Nothing in the framework selects QEC for the structure slot. A particular occupant is licensed only by a ground reading that discriminates it, or by a provenanced import with a shadow test. Until one of those, the name is the searcher's contribution and must be recorded as such. The code literature supplies a shadow test in one direction (W1 to W4 in `04_links_and_distribution.md`), so QEC is a serious candidate. It does not supply the discriminating ground.

The three-layer answer for this question:

| layer | shape the framework gives | what is not given |
|---|---|---|
| composition | a structure between space and time (Fig 13 :75) | which structure |
| leftover | smoothness and continuity are what a composition leaves (Fig 13 :43, :124) | a continuum as an ingredient |
| settlement | a source-discriminating instrument is owed (metamerism) | the reading that decides QEC vs alternative |

## 5. Correction to my own §3 (carried from the exemplar's method)

I initially wrote the "shape, not a name" rule as a blanket ban on naming QEC. That overstates it. The README's phrase governs a **missing** primitive, one not held in Γ. Network, spectrum and gradient are all already among the six (Fig 13). Naming one of them is a **binding** from the physics or QI frame onto an atom already held, not the invention of a seventh atom. What remains wrong in the slogan "spacetime is a QECC" is not that it names a held atom, but that:

- it presents the binding as a derivation (Fig 8 :50-52);
- it claims the binding adds an atom or moves the wall, when Fig 6 :25 says *"An import adds no atom to the world"*;
- it names the source of a reading without an instrument that discriminates among sources (§3 above).

Both the original point and this narrowing are recorded here so neither is quietly lost.

## 6. Prestige is not action

From *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* And the same essay: *"The catch is that the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."*

A campaign that gathers famous names to agree that QEC explains spacetime is the named collapse, not corroboration. The legitimate ask is the opposite: give the claim a budget to be tried, and let the ground settle it. *Decoding Tacit Knowledge* adds: *"Shared pretext is good for one thing and ruins another. Agreement is the whole point when you're settling what words mean. It's worthless for settling what's true when both sides learned from the same sources."* The holographic QEC community is one evidence pool (W1 to W4), so its internal agreement is one witness.

## 7. My own audit is a simulation, not a ground reading

Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post"* but *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* And: *"I am not claiming that the Tether is a self-validating axiom system. Metatheories cannot validate themselves."* So `01_figure_grounded_audit.md` is a simulated derivation, checked for internal consistency against the figures. It is not a test of the QEC-spacetime claim and must be labelled as such. It cannot settle anything it reports on.
