## DERIVATION

### Q1 — Are both accounts first-order molecules?

- Fig 13 :75: "Two states never bond directly. It is not space-time but space, a structure, time; and two structures join only through a state."
- A first-order molecule is `state - structure - state`, one cross-kind passage.
- Geometric account: `Space - structure - Time`. Legal, with the structure slot open (`SPACE(???)TIME`).
- Code-side account: a code is defined over a subsystem structure with a recoverability condition; written at first order it is `state - structure - state` in its own frame. The network atom is defined as Fig 13 :24, "that entities relate, and influence travels." Spectrum (ordering) is also present in the entropy ordered by area (W2, W4).
- Both are first-order. This is `triangulated` for legality (Fig 13 :74-75 plus the cross-kind rule); `single-source` for the specific code-side mapping. Refuter: either account cannot be written as `state - structure - state` without adding a seventh atom.

### Q2 — Isomers or functional group?

- Fig 12 :117: "isomer. Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."
- Fig 12 :123: "functional group. A substructure whose presence fixes the outcome. The group says what kind; the qualifier says which member."
- As the two accounts are usually written, they do not share a full atom set: the geometric account names Space, Time and an open structure; the code account names subsystems, a code subspace and a reconstruction map. They share the cross-kind motif, not all six atoms. By Fig 12's definition they are therefore **not isomers as written**. They are two members of the same **functional group**: `state - structure - state`.
- The stronger form: if both are rewritten over the full shared atom set `{Space, Time, Energy, Spectrum, Gradient, Network}`, differing only in which structure mediates which state pair, then they **are** isomers: same atoms, different arrangement, different substance. That is the checkable structural claim worth testing.
- Falsifier, written before the run: if one account requires an atom the other does not (for example a code account with no Time, or a geometric account with no Network), the isomer claim fails and the functional-group claim stands.

### Q3 — What order and what bond is "explains"?

- Fig 12 :104: "A settled molecule becomes an atom for whatever composes over it."
- Both first-order molecules are settled in their own frames. Each can serve as an atom at the next level. So a code account that "explains" a geometric account is a **second-order composition**, legal only because both settled.
- The operator distinction decides the bond. The Operators table defines production as *"A produces B; B did not exist before"* and identity as *"two names, one referent."* "QEC explains spacetime" is a production claim (⇒), not an identity (≡). The slogan "spacetime is a QECC" collapses the two and is therefore mistyped even if the underlying composition is sound.
- Fig 12 :111: "A vocabulary without bonds can name a state and cannot name a route to one." Naming qubits without naming the code and reconstruction map names an ingredient set and not the route. This is F7's flat-formula finding.
- Strained-for-now: whether a settled molecule counts as a "quantity" at second order is not decided by the figure. Recorded, not hidden.

## CONCLUSION

Both accounts are first-order `state - structure - state` molecules. As written they share a functional group, not a full atom set, so the isomer claim holds only in the stronger form where both are written over all six terms. "Explains" is second-order production (⇒), not identity (≡), and is legal because both first-order molecules settled. The Fig 12 analogues (catalyst, cycle, functional group) corroborate the mechanism shape but do not select QEC for the structure slot. The one strain is the operand type of production at second order, named rather than smoothed.

## FALSIFIER (written before the run)

If either account cannot be written as `state - structure - state` at first order; or if one requires an atom the other does not, killing the isomer claim in favour of the functional-group claim; or if no bond can be specified for the code side, making the flat-formula finding decisive; or if a settled molecule cannot serve as an atom at second order, the whole second-order "explains" reading fails. Any firing is recorded in `01_figure_grounded_audit.md` §6 rather than erased.
