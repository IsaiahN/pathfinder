## QUESTION

Why did the modern genetic code arise, and could alternative codes have worked? Restated in effect terms: given a closed set of parts (four bases, twenty amino acids, translation components), why this particular arrangement, and which other arrangements would also work? Option A: the code is a pure frozen accident, an arbitrary convention. Option B: the code is a unique ground-driven optimum. What each leads to: A predicts no assignment is privileged and universality is mere descent; B predicts one assignment is uniquely best and universality is evidence of that. The figure-derived third option refuses both single causes and records a union: the code is a settled convention over a closed set, retained by a lineage, with alternatives being isomers whose workability is ground-decided. The historical assignment is a name and stays `gap`. R is indexed per codon slot, not aggregated (Fig 1 :19).

## VERDICT (from the figures)

The figure-derived verdict, kept per domain and never averaged: the modern code is a settled convention over a closed molecular set, retained by a lineage, with alternatives being isomers over that set whose workability is a ground question. Universality is a handoff chain, not evidence of optimality; selection ran, but it is a special case of the loop, not the whole answer; and the specific historical assignment is `gap`, because the figures return a shape and not a name. The "pure frozen accident" and "unique optimum" answers are both refused. Mode `specified`, ungrounded, candidate. The world sources corroborate the shape from separate fields where available; where they share a pool (Koonin), they count once.

- **Reversed by:** a ground reading, not agreement.
