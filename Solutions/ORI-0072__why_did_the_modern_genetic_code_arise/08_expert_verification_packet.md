# Expert verification packet - the Tether on the origin of the genetic code

**What this is:** a claim in a form a genetic-code researcher can check. Mode, derivation and refuters are stated before the conclusion, so a reader knows what to look for and what would settle it.

**Mode: `specified` - not `grounded`.** No measurement of a primordial assignment is claimed. This is a shape and a route, not a result.

## 1. The claim, in one paragraph

The modern genetic code is best described as a settled convention over a closed set of molecular parts, retained through a lineage, with alternatives being isomers over the same closed set whose workability is a ground question. The code is a bond, not an ingredient list: the same twenty amino acids and sixty-four codons under a different assignment are a different substance (an isomer). The set is closed but the arrangements are not, so alternatives are generically possible. The code is a convention, but because the assignments change error load and fitness it is not a pure frozen accident. Its near-universality is a handoff chain of common descent plus horizontal gene transfer, not evidence of optimality. The framework returns the shape any workable code must have; it does not name which codon got which amino acid, and that stays `gap`.

## 2. Three checkable sub-claims

### C1 - framework-internal; checkable by reading Figure 12 and Figure 13
- **Statement:** alternative codes are isomers, not different ingredient lists, because the mapping is a typed bond over a closed set of atoms.
- **Source, verbatim:** Fig 12 :117 - *"Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."* Also Fig 12 :94 - *"The arrangement is the substance."* And Fig 13 :115 - *"The set is closed. The arrangements are not. That gap is why import exists."*
- **What to check:** do the figure definitions actually make a codon reassignment an isomer (same atoms, different bond), and is the atomic set the thing that is closed while the arrangement space is open? The figure's own example is silver fulminate versus silver cyanate.
- **Refuter:** a workable code that needs a genuinely new molecular kind (21st primordial amino acid, different alphabet, non-canonical backbone) is an import, not a rearrangement; the isomer claim fails.

### C2 - convention versus ground; checkable against error-load data
- **Statement:** the code is a convention, but not a *pure* convention, because its assignments change error load and fitness.
- **Source, verbatim:** Fig 2 :41 - *"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"*; and Fig 2 :43 - *"Guard, from Figure 10: a convention that decides an outcome has stopped being one."* Also Fig 10 :18 - *"a declared meaning is not a grounded one"*.
- **What to check:** is the code a shared meaning between encoder and decoder (convention), and do the assignments measurably change fitness (error minimization, reassignment cost)? If both are true, the pure-convention reading fails by the figure's own guard.
- **Refuter:** all assignments shown fitness-equivalent (making it a pure convention), **or** exactly one assignment shown viable (collapsing the arrangement space to a singleton). Either removes the compound and kills the claim.

### C3 - universality; checkable against phylogenetics and recoding
- **Statement:** near-universality is a chain of mirrors, not evidence that the standard code is the best.
- **Source, verbatim:** Fig 7 :12 - *"same closure, handed along;"* and Fig 7 :13 - *"agreement compounds, evidence does not"*; with Fig 2 :40 - *"agreement about the world is worthless when the agreeing frames share an evidence pool"*.
- **What to check:** does the observed pattern of variant codes fit a descent chain with horizontal gene transfer, as Koonin and colleagues argue, rather than many independent re-derivations of the same optimum?
- **Refuter:** independent origins with different closures converging on the identical assignment would promote universality to corroboration at maximum independence (Fig 8 :50). No such case is established.

## 3. What is explicitly not claimed

- Not "frozen accident, full stop". It is a component of the shape, not the verdict.
- Not a unique optimal code. The arrangement space is open and more robust codes exist.
- Not that stereochemistry, coevolution or error minimization individually *caused* the code. They are union components, ordered by dependency.
- Not a derivation of triplet length. The figures license sequence, not the number three; that is declared `gap`.
- Not `grounded`. No primordial assignment is asserted as settled by an instrument in this packet.
- Not a name for the historical assignment. The framework returns a shape, not a name.

## 5. What would settle it

A source-discriminating instrument, not a further argument. From *The Hard Problem is About Source*: an instrument that reads green *"cannot comment on the source"*; the spectrometer resolved it. Here:

1. **Isomer viability:** does a cell with a reassigned code over the same atomic set translate a proteome and persist? Whole-genome recoding is the instrument; viability with repairable fitness costs has been shown, which supports the shape without settling the historical question.
2. **Source discrimination:** do triplet binding affinities, precursor relationships and error-load scores distinguish the rival explanations? Aptamer and phylogenetic reconstruction are the instruments.
3. **Universality:** does the variant-code pattern fit one descent chain with HGT, or convergence? Phylogenetics is the instrument.

## 6. What an expert can check in twenty minutes

1. Read Fig 12 :94, :117 and Fig 13 :115, three short passages. Are alternative codes isomers under those definitions?
2. Check C2 against the error-minimization literature: do the assignments measurably change fitness? If yes, the pure-convention reading fails.
3. Name one instrument that would distinguish a descent chain from convergent origin for the code's universality, or say why none is possible.
4. Send the refutation. A failure is more useful than an endorsement.
