## 1. A shape is a constraint, not a filler

The canonical rule states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"* (`FIGURES_README_canonical.md`). Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13: *"It can say the answer is out of reach with the library as it stands... It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- *"the modern code is a typed bond over a closed set, settled against a ground, shared as a convention"* is a **shape**.
- *"codon AUG was assigned methionine because of stereochemical affinity at time t"* is a **name** and is not licensed by the figures.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* Here the effect is "a mapping that must be shared, error-tolerant and heritable", described before naming stereochemistry, coevolution, error minimization or frozen accident.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: *"you will know that you are done because the finish line will also be the starting place"*, with the paradox that by then you have *"composed the answer through the process of locating it."*
- The same essay names this question's exact trap: *"Perhaps your problem was a bundle or conflation of several problems masquerading as one?"* That is the four-rival-explanations union diagnosed in `01_figure_grounded_audit.md` section 1.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The canonical rule: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

*They're Scanning Books* sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

For the genetic code, the four bases and twenty amino acids are a visible choice of atomic set, not nature's own list. Naming one rival explanation as *the* cause turns a visible choice into an invisible one.

## 4. Why "which assignment won" is the forbidden error here

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and *"the instrument is speaking only about what it measured, it cannot comment on the source."* Several sources (one green light, yellow plus blue, RGB, CMYK, or an undiscovered scheme) give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"The answer is unreached until a better instrument exists."* It was the spectrometer, not an argument, that resolved it.

Applied here: reading the modern code table and naming its source as "frozen accident" (or as "error minimization") is the metamerism error. Several historical paths can produce the same table. What is owed is a source-discriminating instrument (binding assays, recoding experiments, phylogenetic reconstruction), not a name. *"An instrument that can't distinguish these cases demonstrates its own inadequacy, it cannot claim anything substantial about what is being measured or what causes it."*

*The Recursive Self-Improvement Trap*: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."*

## 5. Why selection is not the whole "why"

The same essay supplies the key distinction for an origins question: *"Natural selection is not the whole answer. It is a special case. The full answer is the loop itself."* Selection is what the loop looks like with no one in the maintainer seat. So "the code arose by selection" is a true but partial answer. The full shape names the loop: available atoms, a mapping bond, a bargain that pays, settlement against a ground, and a lineage that carries it. This is why the verdict keeps four domains separate instead of collapsing them into "evolution did it".

## 6. Q: does the framework license any specific codon assignment? Answered, no further question needed

**Nothing in the figures.** The framework returns a shape. A specific codon-to-amino-acid assignment is licensed only by the ground settling a minted term, or by a provenanced import with a shadow test. Until one of those, the name is the searcher's own contribution and must be recorded as such. The verdict declares this sub-question `gap`, and Fig 13 :134 gives the wording: *"Unreachable is a verdict here, not a silence,"* and Fig 8 :39: *"So a search that finds nothing is never a proof of absence."*

## 7. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A campaign that gathers famous names to agree with the code claim is the named collapse, not corroboration. The legitimate ask is to give the claim a budget to be tried and let the ground (a recoding experiment, a binding assay, a phylogenetic test) settle it.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` is a simulated derivation, checked for internal consistency against the figures. It is **not** a test of the code question and must be labelled as such. It cannot settle anything it reports on.
