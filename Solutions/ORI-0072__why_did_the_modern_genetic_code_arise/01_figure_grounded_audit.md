## 0. The residual in effect terms

The given is a near-universal mapping from 64 nucleotide triplets to 20 amino acids plus stop. The residual R is not "which chemical is the code made of" (that is given) but "why this arrangement, and which other arrangements would have worked."

R by arity, symmetry and scale (Formula step 7 and Fig 9 :22):

- **Arity:** the code is a binary typed relation (codon -> amino acid), and it is many-to-one, so degenerate. The "why" question compares four rival causes, which is a union of conditions (Fig 9 :55), not one hard question.
- **Symmetry:** codons are read in a fixed 5' to 3' direction, so the mapping is an **ordered** bond. Sequence matters (Fig 12 :73: *"swap them. Does it become a different thing? Yes."*). Third-base degeneracy reintroduces identity (*"two names, one referent"*, Operators table :25) locally.
- **Scale:** molecular (codon and anticodon), translational (tRNA, aaRS, ribosome), proteomic (proteins), population (universality). Each boundary is a lossy membrane (Fig 4 :27).

An answer would look like: a shape stating what any workable code must be, plus an instrument that discriminates the four rival explanations. The specific historical assignment is a name and is left open.

## 2. Findings F1 to F9 (verbatim figure lines before conclusion)

### F1 - The code is a bond, not a list of ingredients (decisive for "alternative codes")

Fig 12 :94: **"The arrangement is the substance."**
Fig 12 :95: **"Two entries with an identical ingredient set are not variants of one thing. They are different things whose notation cannot tell them apart, and the difference is"**
Fig 12 :97: **"This is not an analogy. Chemistry hit it first: silver fulminate and silver cyanate have the same composition and different properties, which is what forced"**
Fig 12 :117: **"Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."**

Reading. Two codes using the same 20 amino acids and the same 64 triplets but assigning them differently are **isomers** in the figure's exact sense: same atoms, different bond, different substance (proteome). The figure's own example is chemistry (silver fulminate and silver cyanate), so the analogy to a chemical mapping is the framework's, not an imported flourish. "Could alternative codes have worked?" is therefore not a question about different ingredients; it is a question about different arrangements over the same closed set. Mode `general` for the definition, `specified` for the genetic-code application. Status `triangulated` (Fig 12 definition plus Fig 13 rearrangement, low overlap: one defines the bond, the other bounds the arrangement space).

**Refuter:** if a workable code required a genuinely new molecular kind (a 21st encoded amino acid in the primordial set, a different alphabet, or a non-canonical backbone), it would be a new atom, not a rearrangement of the held set (Fig 6 and Fig 13 :116). The isomer claim would fail and the question would become an import question.

### F2 - The set is closed; the arrangements are not (decisive for "could alternatives work")

Fig 13 :115: **"The set is closed. The arrangements are not. That gap is why import exists."**
Fig 13 :116: **"Six members, and no amount of arranging produces a seventh: a new member would have to be a new kind, and composition only ever"**
Fig 8 :32: **"Closure is idempotent. Composing inside a closed set never leaves it, so no search, however long, adds an atom."**

Reading. Over the fixed atomic set (4 bases, 20 amino acids, the translation components), the space of assignments is open-ended. The world literature puts the number above 10^84 (Koonin, opened this session). So alternatives are not marginal curiosities; they are the generic case, and the modern code is one draw from a vast arrangement space. But "writable" is not "workable": Formula step 5 says *"the ground settles it. Verified only by what pays. A gate is not the ground."* Whether an arrangement works is a ground question, not a combinatorial one. Mode `general` for the closure/arrangement split, `specified` for the code. Status `triangulated` (Fig 13 plus Fig 8, different figures, low overlap).

**Refuter:** a demonstration that exactly one assignment over the 20-amino-acid set yields viable translation would close the arrangement space to a singleton and collapse the question. No such proof exists; recoding experiments (section 4) point the other way.

### F3 - Universality is a chain of mirrors, not evidence of optimality (decisive for the common "why" mistake)

Fig 7 :12: **"same closure, handed along;"** ; Fig 7 :13: **"agreement compounds, evidence does not"**
Fig 2 :40: **"agreement about the world is worthless when the agreeing frames share an evidence pool"**

Reading. The near-universality of the code is explained by common descent plus horizontal gene transfer: a handoff chain. Every lineage inherited the same closure, so the agreement is the pool talking, not many frames independently confirming an optimum. Using universality as evidence that the code is the best is exactly the collapse Fig 2 names. Koonin and Novozhilov (opened) reach the same substantive conclusion from a different evidence pool: universality stems from frozen accident plus the inhibitory effect of code changes on HGT. Mode `specified`. Status `triangulated` (Fig 7 plus Fig 2 plus the world source, with the warning that the world source is a different field, not a second figure).

**Refuter:** independent origins with genuinely different closures converging on the identical assignment would promote universality from a chain of mirrors to corroboration at maximum independence (Fig 8 :50). No such case is established.

### F4 - The code is a convention, but a convention that decides an outcome has stopped being one (strain resolved by re-census)

Fig 2 :41: **"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"**
Fig 2 :43: **"Guard, from Figure 10: a convention that decides an outcome has stopped being one."**
Fig 10 :18: **"a declared meaning is not a grounded one"**

Reading. The code has two faces. It is a **convention**: encoder and decoder must agree, and shared meaning is the product, not a corruption (Fig 2 :41). But the specific assignments change error load and fitness, so they partly decide outcomes. By Fig 2 :43 and Fig 10 :18, a convention that decides outcomes has stopped being a pure convention; it is partly ground-governed. Therefore the textbook "frozen accident = arbitrary convention, full stop" reading **strains** against Fig 2 :43. Per the strain test, this is not smoothed over; it sends the residual back to the census. Re-census result: D4 is a **compound** (convention + ground), not a pure convention. Mode `specified`. Status `triangulated` (Fig 2 and Fig 10, distinct figures) plus world corroboration (Freeland and Hurst, opened: fewer than four per 100,000 alternative codes beat the natural one on error load).

**Refuter:** if all assignments over the held set were fitness-equivalent (zero error-load difference), the code would be a pure convention and Fig 2 :43 would not bite. The error-minimization measurements refute that, so the compound reading stands.

### F5 - No maintainer; selection ran (the "why did it arise" answer at the habitat level)

Fig 11 :36: **"Where nothing maintains anything, intelligence is a label applied afterwards to a lineage that met its ground. Nothing was intelligent; selection ran. The word does no work there."**
Fig 11 :40: **"A system cannot be made more capable by improving the agent in isolation. An improvement that does not change contact changes nothing, however much it improves."**

Reading. The code did not need a designer. In the unmaintained habitat nothing selects on behalf of a plan; what survived is what the ground kept. Capability is a property of the translation system and its chemical habitat together, not of a molecule alone. The essay puts it plainly: "Natural selection is not the whole answer. It is a special case. The full answer is the loop itself." (`05_what_shape_means.md` section 5). Mode `general` for the selection claim, `specified` for the code. Status `triangulated` (Fig 11 plus the essay; note the essay shares the author, so it is not an independent witness).

**Refuter:** a demonstrated directed maintainer of the primordial code would break this reading. None is in evidence, and any proposed maintainer would itself need a ground.

### F6 - Each codon is a slot; optimality must be read per slot

Fig 1 :19: **"The residual is indexed by object slot, not aggregated."**
Fig 1 :22: **"Aggregating across slots is how a live signal disappears into an average."**

Reading. Error-minimization scores average over the whole code table. The live residual may sit in one codon slot (for example a stop codon or a rare arginine codon that is costly to reassign, as the recoding work shows). "The code is nearly optimal" is an average statement and can hide a per-slot live signal. Mode `specified`. Status `single-source` for the figure principle (Fig 1), corroborated at a different stratum by the recoding experiments, which found specific loci rather than a uniform cost.

**Refuter:** a code whose per-slot residuals were all near zero while the global average stayed high would contradict this reading. Unlikely, but stated.

### F7 - Settlement needs an instrument; a gate is not the ground (why "could work" is empirical)

Fig 5 :42: **"The acceptance test is a bargain, not a threshold."**
Fig 9 :32: **"you get a kind of thing, never the answer itself"**

Reading. The framework returns the shape (alternatives are isomers over a closed set; workability is a ground question), not the verdict. Whether a specific alternative code actually works must be tested by an instrument. The recoding literature is that instrument: whole-genome recoded organisms with 61, 57 and compressed codes are viable but pay fitness costs that directed evolution partly repairs (Nyerges et al., Nature Communications 2026, opened). Mode `specified`. Status `triangulated` (Fig 5 plus Fig 9 plus the engineering field, with the field as corroboration only).

**Refuter:** a purely formal proof that a given alternative is viable, with no ground reading, would move the claim toward `grounded`. That would be a feature of the framework, not a bug, but it is not currently available.

### F8 - Shape not a name: the figures cannot say which assignment won historically

Fig 9 :27: **"describe it before you go looking, or"** ; Fig 9 :28: **"any frame you pick will seem to fit"**
Fig 13 :134: **"Unreachable is a verdict here, not a silence,"**
Fig 8 :39: **"So a search that finds nothing is never a proof of absence."**

Reading. The particular codon-to-amino-acid assignment is a **name**; the shape any answer must have is a typed bond over a closed set, settled against a ground, shared as a convention. Picking stereochemistry, coevolution, error minimization or frozen accident before describing the residual would be apophenia (Fig 9 :27-28). After a genuine re-census no figure line determines a specific assignment, so that sub-question is declared `gap`/unreached, with the honest wording "Unreachable is a verdict here, not a silence." Mode `general` for the limit, `specified` for the declaration. Status `triangulated` (Fig 9 plus Fig 13 plus Fig 8).

**Refuter:** a figure re-census that produced a line naming a specific codon-amino-acid assignment would break this limit. None was found.

### F9 - The triplet/ordered nature is figure-licensed as structure, not as history

Fig 12 :92: **"Symmetry is what decides whether an arrangement is a new thing."**
Operators table :34 (attributed to the table, not a figure line): *"the only bond a flat chain can express, so every term today is a sequence whether or not it should be"*

Reading. The code reads codons as ordered triplets (sequence bond), so permutations are different terms. That is a structural fact the figures license. Why triplets rather than doublets or quadruplets is a ground question about the number of amino acids to be encoded, not something the six-term set decides. A `specified` claim about *structure* must not be smuggled into a `grounded` claim about *history*. Status `single-source` (Fig 12 symmetry plus Operators table), with the history half declared `gap`.

**Refuter:** a figure line that derived triplet length from the bond set would close the gap. None exists after re-census.

## 3. Pre-registered refuter (written before the conclusion)

The shape claim is: the modern genetic code is a settled convention over a closed molecular set, retained through a lineage, with alternatives being isomers whose workability is ground-decided, while the specific historical assignment is `gap`. It is refuted if any of the following holds:

1. A workable code requires a genuinely new molecular kind (21st primordial amino acid, different alphabet, non-canonical backbone), making it an import rather than an isomer over the held set.
2. All assignments over the held set are shown to be fitness-equivalent (pure convention, removing the ground component), **or** exactly one assignment is shown viable (arrangement space collapses to a singleton).
3. Universality is shown to arise by independent convergence of multiple origins with different closures onto the identical assignment (promoting universality from chain of mirrors to corroboration).
4. A figure re-census produces a line that names a specific codon-amino-acid assignment (breaking the shape-not-a-name limit).
5. A directed maintainer of the primordial code is demonstrated (breaking selection-ran at Fig 11 :36).

Any of these fires, the shape is withdrawn or re-censused. Until one is run, nothing here is `grounded`.

- Freeland and Hurst, *Load minimization of the genetic code: history does not explain the pattern*, Proc R Soc B 1998: *"fewer than four per 100,000 alternative codes are better than the natural code."* Corroborates F4 (the code partly decides outcomes). Independent group and method.
- Nyerges et al., *Probing the limits of genetic recoding using multi-omics-guided evolution*, Nature Communications 2026: *"we develop a multi-omics-guided evolution strategy that rapidly restores fitness, enabling genome synthesis with radical changes."* Corroborates F7: alternatives can work, with repairable fitness costs. Different field (synthetic biology/engineering).
- Zürcher et al., *Refactored genetic codes enable bidirectional genetic isolation*, Science 2022: refactored codes in E. coli block mobile elements. Engineering witness for F1/F7.
- M. et al., *Organisms with alternative genetic codes resolve unassigned codons via mistranslation and ribosomal rescue*, eLife 2018: recoded organisms resolve unassigned codons via near-cognate suppression and tmRNA rescue. Corroborates F6 (specific slots are live).

No world source conflicts with the figure verdict. The four rival explanations (stereochemical, coevolution, error minimization, frozen accident) are treated as **union components**, never averaged into a single winner. A conflict would return the derivation to the census, not flip the verdict.
