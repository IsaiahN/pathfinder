# Are alternative genetic codes isomers, and why is the code ordered?

**Mode: `specified`.** This is a simulated derivation checked against the figures, not a ground reading (see `05_what_shape_means.md` section 7).

## RESIDUAL

Two supporting questions are owed by the main audit. (1) In what exact sense are alternative genetic codes "isomers" under Fig 12's definition, and does that survive a counterfactual where the alphabet changes? (2) Why is the mapping an **ordered** bond, and does the framework license triplet length or only sequence? A falsifier is stated for each.

## DERIVATION

### Q1 - In what sense are alternative codes isomers?

- Fig 12 :117: **"Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."**
- Fig 12 :95: **"Two entries with an identical ingredient set are not variants of one thing. They are different things whose notation cannot tell them apart, and the difference is"**
- Fig 12 :97-98: **"This is not an analogy. Chemistry hit it first: silver fulminate and silver cyanate have the same composition and different properties"**

Reading. Take code C1 (the standard table) and code C2 (the same twenty amino acids and sixty-four triplets under a different assignment). They have the same atoms. The difference is carried entirely by the **bond**, the typed codon-to-amino-acid relation. They are not variants of one thing; they are different things whose ingredient list cannot tell apart. Under the figure's own chemistry example they are isomers in the literal, not metaphorical, sense.

- **Falsifier, written before the run:** if C2 requires an atom C1 lacks (a 21st encoded amino acid, a different alphabet, a quadruplet decoder as a new kind rather than a rearrangement), then they are not isomers over the held set. The claim fails and the question becomes one of import instead. The engineered quadruplet codes in the literature are exactly this boundary case.

### Q2 - Why is the code an ordered bond?

- Fig 12 :92: **"Symmetry is what decides whether an arrangement is a new thing."**
- Operators table :34 (table, not a figure line): *"the only bond a flat chain can express, so every term today is a sequence whether or not it should be"*
- Fig 12 :59 (the swap test for sequence): *"swap the operands. Does the meaning change? No."* is the symmetric case; sequence is the **no** case (Operators table :33, *"swap them. Does it become a different thing? Yes."*).

Reading. Codons are read 5' to 3'. AUG and GUA use the same three bases in a different order and are different codons. So the mapping bond is ordered (sequence), and charging for order is correct, not an overcharge. Symmetry reappears locally as third-base degeneracy, which is identity: *"two names, one referent"* (Operators table :25). The code is therefore a **mixed** structure: an ordered triplet spine with local identity classes over the third base.

- **Falsifier:** a demonstration that the decoder treats a codon and its permutation as the same term (a genuinely symmetric reading at the first two positions) would break the ordered-bond claim. All known translation systems read directionally, so the claim stands as `specified`, ungrounded by any figure measurement.

### Q3 - Does the framework license triplet length?

- Fig 13 :115: **"The set is closed. The arrangements are not. That gap is why import exists."**
- Fig 9 :32: **"you get a kind of thing, never the answer itself"**

Reading. The six-term set and the bond set give **sequence** (an ordering) but do not give the number three. Triplet length is a fact about how many amino acids must be distinguished (4^2 = 16 is too few for twenty; 4^3 = 64 is enough), which is a ground fact about the atomic set available, not a figure derivation. The framework can say that *some* ordered length is required; the specific length is a name, marked `gap` in `01_figure_grounded_audit.md` F9.

- **Falsifier:** a figure line deriving the triplet count directly from the bond vocabulary would close the gap. None exists after re-census. Conversely, an organism with a stable quadruplet code would show length is not fixed by chemistry alone, which the engineered quadruplet work hints at but does not settle in a lineage.

### Q4 - What order is the union of explanations?

- Fig 9 :55: **"A bundled problem is usually a union of overlapping conditions, not a list of separate ones."**
- Fig 9 :57: **"What remains is smaller and it is also categorically different: a case in two conditions is not a harder case of either."**
- Fig 3 :20: **"The chain is ordered by dependency, not by importance."**

Reading. The four rival explanations (stereochemical affinity, coevolution with biosynthesis, error minimization, frozen accident) are not four candidates for a single slot. They are four conditions in a union. Dependency order: chemical availability (D1) precedes which amino acids can be encoded; the closed set and its arrangements (D2) precede the bargain that pays; the lineage and HGT (D3) precede universality; the shared convention (D4) is the product of encoder and decoder agreeing. Effort spent "above the break", for example refining an error-minimization score, cannot rescue a missing chemical or translational link (Fig 3 :19).

- **Falsifier:** one intervention that restores all four conditions at once, leaving no categorically different residue, would collapse the union back into a single problem. That has not been shown; recoding experiments fix translation but do not recreate the historical chemical onset.

## CONCLUSION

Alternative codes are **isomers** under Fig 12's definition when they use the same atoms and differ only in the mapping bond. The code is an **ordered** bond with local identity classes over the third base, and the framework licenses sequence but not triplet length. The four rival explanations form a **union** ordered by dependency, not a contest with one winner. Each claim carries its falsifier above.

This framing keeps what is defensible (isomers, ordered bond, union structure) without importing what is not (a figure-derived triplet count, a named historical cause). Whether any particular alternative code works remains a ground question for recoding experiments, exactly as `07_the_tether_answer.md` states.
