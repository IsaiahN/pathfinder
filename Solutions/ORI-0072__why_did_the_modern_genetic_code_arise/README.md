## The question restated as an effect

What is being decided is not the *chemical identity* of the code (4 bases, 20 amino acids, 64 triplets are given) but the *arrangement* of the mapping and the *reason it was retained*. In effect terms: a translation system must map a 4-letter nucleic-acid alphabet to a 20-letter protein alphabet so that (a) encoder and decoder agree, (b) reading errors are tolerable, and (c) the mapping is heritable and stable. R = |Gamma(b,a) - o'| is indexed per codon slot and per generation, never aggregated (Fig 1 :19, Fig 1 :22).

- Option A, "the code is a frozen accident, an arbitrary convention": leads to the prediction that no assignment is privileged and universality is only common descent.
- Option B, "the code is a ground-driven optimum": leads to the prediction that one assignment is uniquely best and universality is evidence of that optimum.
- What an answer would look like, written down and bound as an ordinary term before the run (Formula, "Direction"): a *shape* that says what any workable code must be (a typed bond over a closed set of atoms, settled against a ground, with a convention between encoder and decoder), plus an instrument that would discriminate the four rival explanations (stereochemical affinity, coevolution, error minimization, frozen accident). The specific historical assignment is a name, not a shape, and is left open.

The verdict recorded in `09_watson_answer.md` refuses both A and B as single causes. It records a **union**: the modern code is a settled convention over a closed molecular set, retained through a lineage, whose near-universality is a handoff chain rather than corroboration of an optimum. Alternative codes are isomers over the same closed set and are generically possible; whether a given one works is a ground question. Kept per domain and never averaged.

## What is deliberately not here

- No personal emails of named individuals.
- No ranking of people by how likely they are to agree.
- No bulk-send plan.
- No claim that this derivation is `grounded`, no claim that it settles which codon assignment won historically, and no claim that the framework is the only true account of the genetic code.

Three figure-grounded reasons, plus one practical one:

1. A room is not an anchor. *"same closure, handed along;"* and *"agreement compounds, evidence does not"* (Fig 7 :12-13). Gathering agreeable readers manufactures the correlation that disqualifies a verdict (Fig 2 :40).
2. Correlation has valence. *"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"* (Fig 2 :41), but *"disqualifying for a verdict: agreement about the world is worthless when the agreeing frames share an evidence pool"* (Fig 2 :40). A shared code is a convention (the first), not evidence of an optimum (the second).
3. A verifier must be outside the interior. *"A verifier that can reconstruct the claim cannot verify it."* (Fig 10 :42). The first contact therefore carries the residual and its refuter, not the framework.
4. Legally, unsolicited bulk email to scraped addresses breaches GDPR and CAN-SPAM style rules in many jurisdictions and gets the sending domain blacklisted. Public opt-in routes avoid that failure as well as the structural one.
