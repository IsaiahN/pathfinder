## What this answer does

It states the residual in effect terms, runs a domain census before choosing any figure line, quotes the governing figure lines verbatim, keeps per-domain verdicts separate, writes the refuter before the conclusion, and refuses to name a single winning theory where the figures return only a shape. The one formal principle the figures name outright is minimum description length. The corrections the figures impose on any candidate account are per-slot residuals, the three-guard minting bargain, two non-additive currencies (bits and actions), and the distinction between unreachable-at-budget and underivable-in-principle.

## Boundary

Nothing in this folder was written from a summary of the figures. Figure quotes were taken from `FRAMEWORK/reference/03-FIGURES_TEXT.md` and checked against the verbatim lines. Local framework files are recorded as `local:` paths in `10_source_ledger.csv`. World sources are real URLs opened on 2026-11-23. No file outside this solution folder was modified.

The derivation is a **simulation**, not a ground reading. Per *The Recursive Self-Improvement Trap*, which was opened this session: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* This package cannot settle the question it reports on. It can only state the shape an answer must have and the refuters that would break it.

## What is deliberately not here

- No personal emails of named individuals, and no ranking of people by how likely they are to believe the claim.
- No bulk-send plan.
- No claim that this derivation was checked against a real learning system or dataset in this run.

Three reasons, from the figures: *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* (Fig 2 :35); *"disqualifying for a verdict: agreement about the world is worthless when the agreeing frames share an evidence pool"* (Fig 2 :40); and *"A verifier that can reconstruct the claim cannot verify it."* (Fig 10 :42). Selecting recipients for receptiveness manufactures the disqualifying correlation, and sending the full theory before asking for a verdict spends the recipient's independence.
