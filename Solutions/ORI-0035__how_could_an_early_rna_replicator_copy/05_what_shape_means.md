## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (**a shape, not a name**)."* Fig 9 :32: **"→ you get a kind of thing, never the answer itself"**. Fig 13 :134-135: *"Unreachable is a verdict here, not a silence, It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For ORI-0035 this means the deliverable is **a band with two failure edges**, plus the rule that progress per handoff is a product of fidelity and selection pressure. It is not a critical mutation rate. `SPACE(???)`-style honesty applies: the slot where a number would go stays marked until a ground settles it. A shape constrains: any acceptable answer must name both failure modes, must keep per-site residuals visible, and must identify the ground that votes between variants. It does not fill in the value of μ_c.

- Fig 9 :27-28: **"describe it before you go looking, or any frame you pick will seem to fit"**. The residual was described in effect terms (two-sided loss of information and loss of variation) before quasispecies theory was admitted as Domain 4 in `01`.
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. ## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"SETTLE the ground settles it. Verified only by what pays. A gate is not the ground."* A serial-transfer experiment with measured per-site fidelity and an actual habitat would name the band's edges for a real system. Nothing in this folder provides that measurement.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. The critical mutation rate is such an import from quasispecies theory. When it is used, the use must say where it came from and what gap it explains. Fig 8 :51-52: *"Only the record of where each came from separates them, and the surplus lives only where the closures differ."*

An important narrowing, recorded as a correction to an easy overreading: "shape, not a name" governs a **missing primitive**, not every term selected from what is already held. Here the two failure edges are not new primitives; they are arrangement facts about a channel, a population and a habitat. Naming them is licensed as a binding, provided the binding is not presented as a derivation of a number. This is the analogue of the exemplar's correction about naming Gradient: the prohibition was narrower than it first appeared.

## 4. The ground and the source problem

*The Hard Problem is About Source* gives the mechanism. Metamerism: a color instrument reads green and *"cannot comment on the source"*; one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered can give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

Applied here: a measured mutation rate per nucleotide is a reading, not a source. Several distinct mechanisms (misincorporation, template slippage, base modification, selective loss of variants) can yield the same observed rate. A single number does not tell you which one is operating, and several sources could give the same fidelity. What is owed is a discriminator, not a name. The figure version is Fig 13 :16 and :26: something must name what is being measured, and something must decide what the measurement would mean; neither does it alone.

There is a second source problem at the population level. Wilke (2005, opened 2026-11-23) shows that the sharp error threshold exists only for landscapes without lethal genotypes. So the same observed delocalisation can arise from a sharp threshold in one landscape or from meltdown in another. The reading does not determine the source. The world qualification is kept in `01` F9 rather than being smoothed away.

## 5. Answer to the shape question

**What shape is being sought here?** A band with two failure edges, governed by a two-factor product at the handoff, measured per site, with a ground that votes between variants.

**What licenses the specific width of that band?** Nothing in the figures. It requires either a ground measurement or a provenanced import from quasispecies theory, and even then the landscape conditionality must be stated. Until then the number is a preference held as a term, not a term with a residual.

**Does this package commit the forbidden error?** Not if it refuses to convert the shape into a number. It would commit the error if it wrote *"the threshold is μ_c ≈ ln(s)/L"* as a figure result, or if it named one molecule as *the* replicator that occupied the band. Neither claim is made. The one place a number appears in the wider literature (`04`) is explicitly labelled an import and a landscape-conditional model result.

## 6. Consequences for contact

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous origins-of-life researchers who agree with the band is the named collapse, not corroboration. The legitimate ask is the opposite: give the claim a budget to be tried, and let an experiment settle it.
