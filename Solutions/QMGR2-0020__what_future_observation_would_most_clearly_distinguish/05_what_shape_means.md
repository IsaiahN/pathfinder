## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*, opened directly: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question, "a measurement that registers the source of the expansion reading" is a shape. "Use Euclid at 5 sigma" is a name.

## 2. How a shape is obtained

- *The Library of Babel* (opened directly): when you lack the right terms, use "the existing vocabulary you do know that is closest to the words that you wish to describe and grasp the shape of", then recurse on recurring new terms. "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :31: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge* (carried from exemplar): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *The Library of Babel* on stopping (opened directly): "you will know that you are done because the finish line will also be the starting place." The paradox is that "you have already composed the answer through the process of locating it."

Applied here: describe the residual in effect terms first. The residual is not "we need a better fit"; it is "the reading cannot comment on the source." That description alone selects the habitat of candidate instruments (differential redshift measurements, growth channels) before any mission name is mentioned (Fig 9 :27-28).

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "SETTLE the ground settles it. Verified only by what pays. A gate is not the ground." Symbols :104: the ground is "Whatever settles the question and does not change its answer because of what any frame thinks."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

*They're Scanning Books* (carried from exemplar): "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "Declaring the primitives does not make them neutral. It makes the choice visible." A choice of probe or representation must be recorded as a choice, not smuggled in as a discovery.

## 4. This question is a metamerism case, and the instrument is the answer type

*The Hard Problem is About Source*, opened directly this run, is the governing essay. In it the color instrument "is speaking only about what it measured, it cannot comment on the source." Several sources (one green light; yellow plus blue; RGB; CMYK; a scheme not yet discovered) produce the same green reading. The key sentences:

- "If several paths create the same behavior, then behavior is a projection with lossy information"
- "The answer is unreached until a better instrument exists."
- "It was proven wrong not by argument, but by the arrival of a better instrument."
- "An instrument that can't distinguish these cases demonstrates its own inadequacy"

The mapping to this question is exact. Lambda and changing dark energy are the several paths; the integrated distance curve is the green reading; the current probes are the eye; the source-discriminating observation is the spectrometer. So the honest answer has the form "what the better instrument must be able to do", not "which source is real." Fig 6 :32: "An instrument is not built from a description. It is improved from a worse instrument already returning something." The worse instrument is already returning a reading that fails to resolve (the 2.8 to 4.2 sigma DESI hint), which is why this is `unreached` and not `unreachable`.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried from exemplar): "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A campaign gathering famous names to agree with the discriminator shape is the named collapse, not corroboration. A reference to a large collaboration's sigma value is the same hazard: it funds a try, it does not settle the source.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." LLM output is "simulacra." So `01` is a simulated derivation, checked for internal consistency against the figures. It is **not** a test of any cosmological model and must be labelled as such. It cannot settle anything it reports on.
