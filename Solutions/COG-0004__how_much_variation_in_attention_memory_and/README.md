## The question restated as an effect

The question asks for one number: the share of variation in attention, memory and reasoning attributable to cultural learning rather than biological differences. Two readings are possible. Option A: a single population-level variance decomposition exists and the figures can say roughly what the split is. Option B: the question bundles a union of capacities, the measured quantity is indexed per slot and never aggregated, and the two named sources are an agent-and-habitat pair whose interaction is not a separable remainder. Option A leads to a percentage that discards the per-slot signal. Option B leads to a shape and a set of ground tests. What an answer would look like is bound in `01` section 0 before any figure line is chosen, so the preference can accrue a residual like any other term.

## The verdict in one line

The figures refuse the single aggregate percentage and supply the shape instead: keep the capacities separate, keep each residual per slot, treat biology and culture as agent-and-habitat rather than two buckets, and let measurement settle each slot. The numeric apportionment is `gap`, stated plainly, not silence. `Unreachable is a verdict here, not a silence` (Fig 13 :134).
