**Subject:** One shape claim about biodiversity and ecosystem function, with its refuter

> Hi [name],
>
> I have one specific output I would like you to check against what you already know. I am not asking you to read any theory first, and I am not asking you to agree. If the output does not survive, there is nothing else to look at.
>
> **The output (`specified`, not `grounded`):** the question "can biodiversity preserve ecosystem function when species identities and interactions keep changing" splits into two different things. The function reading is the thing that settles the question: a measured flux per function and per site, which does not move because we reclassify which species matter. The species and the interactions are the habitat, which the question itself says updates. A result about the habitat cannot be reported as a result about the ground.
>
> What survives turnover is not a list of names. Fig 11 states that no standing list of good actors survives a change of residual, and it also states that an actor's value is relative to the residual, so mutualism and parasitism are relations rather than kinds. The preserving thing is an arrangement: a functional group whose presence fixes the outcome, with the qualifier saying which member fills the slot. Members can turn over while the group and its bonds hold. This is a shape, not a species list, and the framework does not name the member.
>
> The verdict is per function and per site. A pooled number across several functions can report preservation while one of them collapses. "Biodiversity" as a species count is a filter for where to look, not a witness for what closes the question. If a manager is involved, this is permanent work: an actor can be introduced and the habitat cannot be subtracted.
>
> **What I am not claiming:** that a named species or trait preserves a given function in your system. That is a `gap` in this derivation. It would need a measurement at your site, not another review. I am also not claiming a single universal yes or no, because the mechanisms overlap and a single lever leaves the intersections standing.
>
> **What would refute the shape (written before this run):**
> 1. a universal list of named species that preserves a given function across residual changes at several sites;
> 2. a case where function survives turnover with no repeated functional group and no repeated bond structure, and no stable dominant or outside subsidy explains it;
> 3. a case where the function verdict changes when the set of "important" species is reclassified but the measured flux does not change;
> 4. a case where a pooled multifunctionality index and every per-function reading agree even through a function failure;
> 5. a single intervention that restores function where two or more conditions were absent and leaves no categorically different residue.
>
> A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed. If you do reply, I would like your verdict on the shape first, before showing you where the shape came from.
>

## One-to-one constraint

Each message goes to one person or one public submission channel. There is no list ranked by likely agreement, no personal email harvested from a paper header, and no bulk send. Reviews of the same grassland experiments count as one evidence pool (Fig 2 :40), so a campaign that gathers ten agreeable ecologists produces a convention, not a second witness. A failure is the useful reply.
