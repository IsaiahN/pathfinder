## 1. A shape is a constraint, not a filler

The canonical limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"* (figures README). Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :132: "A system with a closure can answer that before it searches, and what it returns is a shape rather than a name."

From *The Library of Babel*: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For this question a **shape** is the form a causal representation must have before we can name the latent variable or the algorithm: it must carry an ordered bond, it must be capable of refusal, it must be reachable only through an import in a closed frame, and its usefulness must be settled at a ground. It constrains four slots; it fills none of them. Naming a specific latent as "the cause" is a name, not a shape.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for new terms that overlap or correlate with it, recurse. "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary." The stopping rule: "the finish line will also be the starting place", and the paradox is that by then "you have already composed the answer through the process of locating it".
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause". For a causal question this is almost literal: describe the effect you would expect under an intervention rather than the cause you claim to have found.
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *How Intelligence Actually Works*: "The mapping is not a means to intelligence; the mapping is the intelligence." A representation is the mapping itself, not a report about it.
- *How a Society of Agents Would Work*: "capability is a property of agent-and-habitat, never of the agent alone." A representation cannot be judged apart from the channel that settles it.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." *Arrival of the Fittest*: "something, somewhere, already paid it."
2. **A provenanced import from a frame whose closure differs** (Fig 6, Fig 8), with a source gate and a shadow test, debited against independence.

*They're Scanning Books When They Should*: "The real import is not a new term in the existing space. It is a new dimension of the space." And: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Also: "Declaring the primitives does not make them neutral. It makes the choice visible."

So declaring that a model has a causal variable is a visible choice, not a discovery of the world's own list. The concrete name carries the searcher's contribution and must be recorded as such. This is why all four imports in `01` §F4 need provenance: environment labels, auxiliary variables, interventions and time order are axes imported from a frame outside the closed observational set.

## 4. The ground and the source problem

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and "cannot comment on the source": one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. The reading does not determine the source. "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

The same error here: a model fits a joint distribution (the reading) and a researcher names the source as a directed causal structure. But observationally equivalent DAGs produce the same reading. What is owed is a source-discriminating instrument, an intervention, not a name. "The answer is unreached until a better instrument exists."

*The Recursive Self-Improvement Trap*: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself. An external validator, or ground, is always needed to tether the veracity of the output to reality. Anything else is drift." And: "Metatheories cannot validate themselves." And: "Prestige must never be allowed to validate an action directly."

*How a Society of Agents Would Work*: the multi-agent version of the same rule, "Ten copies watching the same thing are one opinion said ten times", and "the ground sits under all three" stores.

## 5. Answer to the shape question

**What shape does a causal representation have, before any name is attached?**

1. It is a molecule, not an ingredient list: variables joined by ordered bonds, with a unary refusal operator available (Fig 12, Operators table). This is the representability slot.
2. In a closed frame fed only passive observations, its direction atom is unreachable; the frame can report that it lacks something but cannot name it (Fig 6, Fig 13 :134). This is the identification slot.
3. Its usefulness is not a number the model produces; it is something an outside ground pays for (Fig 1, Fig 2, Fig 11). This is the settlement slot.
4. The wall moves only on import, and the import is characterized in effect terms and provenanced (Fig 6, Fig 8). This is the route slot.

**Does this answer the yes/no question?** No, and that is the honest result. It returns a shape and a boundary. The word "alone" decides which half of the boundary you are on: with no import and no ground contact, no; with a provenanced import and an intervention ground, yes under conditions. Which concrete latent variable is causal is not returned: that is a name, and names are paid for by the ground.

## 5b. Correction to my own reading of "shape, not a name"

I initially wrote that "shape, not a name" forbids saying any causal variable is identified. That overstates it. The README phrase governs a **missing** primitive, one not held in Γ. Binding an already-held atom to a domain variable is a **binding from another frame**, not the invention of a new primitive. What remains wrong in such a binding is calling it a derivation, or claiming it moves the wall without a source gate (Fig 6: "IMPORT adds an atom" applies to the frame, not the world). Both forms are recorded so neither is quietly lost. The name still carries zero verdict weight until the ground pays.

## 6. Consequences for contact

**Prestige is not action.** *The Recursive Self-Improvement Trap*: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A list of people chosen for likely agreement is the named collapse. The legitimate ask is the opposite: give the shape a budget to be tried and let the ground refuse it.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post ... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." The architecture post is blunter: outputs "could never be verified if the solutions presented were not contrived to fit the formula", and they are "simulacra". So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.
