## 1. A shape is a constraint, not a filler

The canonical rule: the framework returns "what a missing thing would have to look like (a shape, not a name)". `Fig 9 :32` "you get a kind of thing, never the answer itself". The figure text adds: "It cannot say which primitive is missing, because naming it would mean already holding it" (`Fig 13 :135`).

From *The Library of Babel*, read this session: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For this question a **shape** is therefore not "machines can" or "machines cannot". It is the four-part constraint written down in `README.md`: a non-moving ground, separate per-slot verdicts, a stated contact or closure result, and a named reversal measurement. It constrains; it does not fill. "The coordination outcome is the anchor" is a shape. "The system needs a Theory of Mind module" is a name.

## 2. How a shape is obtained for this question

- *Library of Babel*: use the vocabulary already held that is closest to the thing, look for recurring terms that overlap or correlate with it, recurse. "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary." Here the near vocabulary is implicature, speech act, joint attention, false belief, coordination, contact.
- `Fig 6 :30` "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." `Fig 9 :30-31` "your words are borrowed too, so describe the effect rather than the cause." So describe "the interpretation the hearer acted on", not "the module that produced it".
- *Decoding Tacit Knowledge*, read this session: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." This is why the outreach email leads with a description of outcomes.
- *Library of Babel* on bundles: "Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually." This is the essay-level source for F1 in the audit.
- *Library of Babel* on stopping: "You will know that you are done because the finish line will also be the starting place." The shape stops registering against the ground when the refuters cannot be made to fire.

## 3. What licenses a name here

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." Here that means an instrument that discriminates "recovered the intended meaning" from "produced a fluent guess" and that does not move when a lab pushes on it.
2. **A provenanced import from a frame whose closure differs** (`Fig 6 :23`, `Fig 8 :50-52`), with a source gate and a shadow test. In this question the different closure is the social habitat: shared attention, turn-taking, correction, culture. What is imported is contact with that habitat, recorded as provenance, not a named primitive.

*The Hard Problem is About Source*, read this session, gives the instrument rule: "If several paths create the same behavior, then behavior is a projection with lossy information", and "An instrument that can't distinguish these cases demonstrates its own inadequacy". A fluent answer and a recovered intention can produce the same text; a text-only reading cannot tell them apart. That is the metamerism error applied to this question. **Correction to my own earlier step:** the missing thing here is not a new primitive to be named. It is a discriminator that would tell the sources apart. Naming a module (ToM, embodiment, world model) would repeat the error the essay names.

## 4. Why "understands social context well enough" is the forbidden form

`THE_FORMULA.md` step 2: "a frame searching for an answer of a given SHAPE holds that shape as a PREFERENCE, not a term. Unbound, predicting nothing, no residual - so nothing above can see it." Step 2 also says the checks run on the mechanism and not on "the DIRECTION OF THE QUESTION".

"Well enough" is exactly such a preference. No threshold is stated, so it predicts nothing and accrues no residual. Asking a benchmark to certify it is a frame certifying the direction of its own question. The remedy is the discipline in `THE_FORMULA.md` Direction: "make the sought-for shape an ORDINARY TERM - write down what an answer would look like, bind it, and let it accrue a residual like anything else." That binding is in `README.md` and is the first item in the outreach email.

## 5. Does the framework ban talking about minds at all?

No. This is a correction to an over-reading I considered and refused. The ban is narrower than it looks:

- `Fig 13 :135` bars **naming a missing primitive**. It does not bar using a term already held in a frame as a description of an effect.
- Theory of mind is a term held in the human social-cognition frame, with a public checkable record (false-belief tasks, joint attention). Using it as an effect description is a provenanced binding from that frame, not an invention of a seventh term.
- What remains forbidden is the stronger move: saying the framework derives that a machine must have it, or that the framework names it as the required import. That would be a name where the framework returns a shape.

Both readings are recorded so neither is quietly lost. Refuter: a derivation that produces the required primitive from the six-term substrate plus text alone would collapse the distinction.

## 6. Prestige is not action

From *The Recursive Self-Improvement Trap*, read this session: "Prestige must never be allowed to validate an action directly." And: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."

For this question, a list of famous endorsers of a position on machine understanding is a prestige loop. It can get the claim heard. It cannot decide whether a machine recovered an indirect request. The legitimate ask is the opposite: give the shape a budget to be tried against a ground, and report the failure.

## 7. My own audit is a simulation, not a ground reading

Same essay: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post" and "the truly testable output would need to be derived from the real architecture or working the formula yourself." This document, and every other file in this folder, is a simulated derivation checked for internal consistency against the figures. It is **not** a test of whether any real machine understands social context, and it cannot settle the question it reports on. `Fig 2 :35`: "Alignment is triangulation, not negotiation. A mirror cannot correct you." An outside reader against a ground is what is owed, not more agreement from the same pool.
