## The residual, restated as an effect

Given a learner whose library, instruments and weighting are what they are, what changes when a maintained transmission channel (formal education) sends something across into that library? The question names three observables (abstraction, statistics, hypothetical reasoning) and an ordered delta (change). Stated as an ordinary term before the run: an answer would say which transmission changes which capacity, at which slot, through which instrument, and what would count as a failure of that claim. The framework returns that shape, not an effect size.
