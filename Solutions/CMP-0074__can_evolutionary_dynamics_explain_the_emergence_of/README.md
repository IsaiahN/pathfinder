## Residual in effect terms

A one-shot payoff model predicts `defect` at each cooperation slot (temptation payoff above mutual cooperation). Observation returns cooperation present and stable in networked populations. `R = |Γ(b,a) − o′|` has positive mass at the cooperation slots. The question asks whether the frame named evolutionary dynamics (selection, replication, mutation, drift over generations on a network) can close that residual, and what an answer would have to look like if it did. The answer is bound as an ordinary term at `THE_FORMULA.md` step "Direction": an explanation is a term that composes from held atoms, is not already in the library, pays the minimum-description-length bargain, and is settled by a non-updating ground.

## What the derivation concludes

The question arrives frame first: it names evolutionary dynamics before describing the residual (Fig 9 :27-28, Fig 8 :53). After a re-census the residual is a union of overlapping conditions, not one hard question (Fig 9 :54-58): the short-term payoff environment, the network habitat, the selection dynamics, and the measurement of emergence. Verdicts are kept separate per domain and never averaged.

What survives is a shape with four structural requirements: cooperation is a relation with residual-relative valence, not an actor kind (Fig 11 :49-51); capability lives in the agent-and-habitat, so changing a strategy without changing contact changes nothing (Fig 11 :39-40); the one-shot defection result is a chain and cooperation requires a cycle in which the output re-enters as input (Fig 12 :121); and the closing term must be indexed per slot (Fig 1 :19, :22) and settled by a ground that does not update (Fig 2 :29, :35). Which mechanism fills the slot, kin selection, direct or indirect reciprocity, network reciprocity, group selection, punishment, or a yet unnamed mechanism, and which parameter value closes a given network, is a declared `gap` (Fig 9 :32, Fig 13 :134-135). That is a verdict, not silence.

An important conditional is recorded visibly: the import verdict holds only when the one-shot payoff frame lacks the network and cycle atoms. The world literature shows that evolutionary game theory on graphs already holds them (Szabo and Fath 2007), so for that frame no import is owed. The earlier unqualified "import is owed" reading is retracted in `01_figure_grounded_audit.md` section 7 and preserved there.
