## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13 :133: *"what it returns is a shape rather than a name."*

From *The Library of Babel* (fetched 2026-11-23): *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name or measure it. It constrains; it does not fill. For this question:

- **Shape, held:** the classification is a threshold comparison between measured couplings and a critical surface; the decay is a rate per spacetime volume; the catastrophe is the sign of a loop.
- **Not the shape:** the number ~10^9 to 10^11 GeV, the exponent in a lifetime ~10^100 to 10^655, the name of a specific Planck-scale operator. Those are world results or gaps.

Writing `λ(μ) ⋛ 0` is a shape. Writing `μ_instability = 9.92e9 GeV` is a name from the world literature.

## 4. The source problem is live in this question, not just an analogy

*The Hard Problem is About Source* (fetched 2026-11-23) gives the mechanism. An instrument that reads green *"cannot comment on the source"*. Several sources can create the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"The answer is unreached until a better instrument exists."* It was the spectrometer, not an argument, that resolved the case.

This is directly relevant to D1. The top-quark mass that feeds the stability calculation is itself a reading obtained by comparing reconstructed decay products with Monte Carlo simulations. The 2014 Degrassi paper notes that the extracted parameter *"cannot be directly identified with the pole mass"* and that a short-distance mass determination gives *"a value that translated in terms of pole mass gives for M_t^pole a central value very close to that obtained via the decay products but a much larger error"*. That is a metamerism problem: one reading, several possible sources, and the reading does not by itself determine which stability region we are in. What is owed is a source-discriminating instrument (a better mass determination), not a name for the source.

Note the limit of the analogy: unlike the green-light case, here an instrument does exist and is improving; the missing thing is precision and a decision about Planck-scale operators, not an entirely new sense.

## 5. Prestige is not action

From *The Recursive Self-Improvement Trap* (fetched 2026-11-23): *"Prestige must never be allowed to validate an action directly."* And: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."*

A campaign that gathers well-known names to agree that the vacuum is safe, or dangerous, is the named collapse. The legitimate ask is the opposite: give the claim a budget to be tried (a check, a calculation, a measurement), and let the ground settle it.

## 7. The specific error this question invites

From *How Intelligence Actually Works* and *How a Society of Agents Would Work* (via local exemplar): the framework applies recursively and the same rules govern every stratum. The tempting move here is to treat "the vacuum decays catastrophically" as one more instance of a generic decay rule and let the analogy supply the number. That is the error the "shape, not a name" rule forbids. Fig 9 :32 applies: the framework returns the kind of thing (a threshold and a sign), never the answer itself.

The second tempting move is to read the shape off the artefact. *The Hard Problem is About Source* supplies the warning: the measured masses are a projection with information loss; the lineage, not the artefact, is what makes the answer checkable. Fig 13 :127 states it in the figures: *"The array cannot be checked by inspection, so the record is what makes it verifiable."*
