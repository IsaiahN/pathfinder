# The Tether's answer: how should AI systems combine neural learning with symbolic reasoning, search, memory, and tools?

**Mode: `specified` on the per-domain shape and the dependency order, `general` on the structural rules. Not `grounded`.** Simulated derivation checked against the figures (`05_what_shape_means.md` §6), not a ground reading. No experiment settles which arrangement wins.

## 2. The shape, per domain, never averaged

1. **Unbundle before answering.** Fig 9 :54: *"And when the split lands on a union rather than a partition, unbundle before you search again."* Five roles, five loops, one dependency order. No single "combine" lever.

2. **The bonds are the answer, not the ingredient list.** Fig 12 :5: *"A set of ingredients is not one. The bond is the rest of the information, and it is the half nothing was recording."* Fig 12 :94: *"The arrangement is the substance."* Say which bond holds between adjacent roles and price it; do not only list modules.

3. **The ground is the only metric and the residual stays per slot.** Fig 1 :23: *"The ground enters as the only metric."* Fig 1 :22: *"Aggregating across slots is how a live signal disappears into an average."* A symbolic consistency check run by the same system is one frame grading itself, not an outside verdict (Fig 10 :42).

4. **Order by dependency, not by importance.** Fig 3 :20: *"The chain is ordered by dependency, not by importance."* The binding is instruments and tools (perception) → symbolic vocabulary → ground and comparison (objective) → search (planning) → memory (learn and carry). Fig 3 :19: *"Optimising a link that already works cannot rescue one that does not."* The middle vocabulary-to-goal link has no instrument and is where hybrids usually break (Fig 3 :27).

5. **Search is SEARCHED at the same reach.** Fig 8 :32: *"Closure is idempotent. Composing inside a closed set never leaves it, so no search, however long, adds an atom. This one is definitional: it is what closure means."* Fig 6 :50: *"Fails by spending budget on a region already swept. Distribute the search, and keep the searchers independent."* To move a wall, import from a frame whose closure differs; budget is a filter, never a witness (Fig 9 :60).

6. **Memory: record and reach are different quantities.** Fig 5 :72: *"and a library that grows is not a reach that grows."* Fig 6 :42: *"What is recorded only grows. What is reachable is derived, and it can fall."* The symbolic part must carry negation so the system can refuse, because *"a refutation is a negation, which is why a vocabulary without it can only accumulate"* (Operators table, unary negation).

7. **Tools are imports and instruments, not agent parts.** Fig 11 :40: *"A system cannot be made more capable by improving the agent in isolation. An improvement that does not change contact changes nothing, however much it improves."* Fig 6 :32: *"An instrument is not built from a description. It is improved from a worse instrument already returning something."* Provenance and a shadow test are owed for every tool import.

8. **The loop must be a cycle, not a stack.** Fig 12 :121: *"cycle. The output re-enters as input. The sign of the loop decides whether it closes, and a chain cannot close by construction."* A linear pipeline of five modules is the degenerate chain case and cannot close on its residual.

9. **The slot for the winning architecture stays open.** Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :135: *"It cannot say which primitive is missing, because naming it would mean already holding it."* Anything that returns a name is a binding from the engineering frame, provenanced as such, not a derivation. Fig 8 :39: *"So a search that finds nothing is never a proof of absence."*

## 3. What it explicitly does not say

- Not that any named architecture wins. No neuro-symbolic integration type is asserted as the answer.
- Not that neural and symbolic are two atoms to bond directly. They are roles (controller and grammar) bound onto held framework terms, not new primitives.
- Not that more search or more parameters add capability by themselves. Reach changes only by import or refusal.
- Not that an aggregate benchmark score scores the combination. The residual is per slot.
- Not that a self-consistency check is an outside verifier. The verifier must be unable to reconstruct the claim (Fig 10 :42).
- Not `grounded`. Nothing here is asserted as settled by measurement.

## 4. What would settle it, the ground

A source-discriminating instrument, not a further argument. *The Hard Problem is About Source* shows an instrument that reads one value *"cannot comment on the source"*, and the case was resolved *"not by argument, but by the arrival of a better instrument."* Concretely:

- **Per-slot discriminator:** an instrument that reports the residual on each object slot under each bond arrangement, so aggregation can no longer hide a live slot.
- **Bond-swap test:** swap one bond type between two roles and measure whether per-slot residuals and probe outcomes change. No change would refute the bond-price claim.
- **Middle-link instrument:** build an instrument for the vocabulary-to-goal link that Fig 3 :27 says is currently unlooked-at.
- **Reach test:** distinguish record growth from reach growth by checking derivability under everything currently held after a refusal; a fall caused by an added term is the signature Fig 6 :42 predicts.
- **Contact test:** an agent-only change held against a fixed habitat; if it moves the ground, the capability claim fails.
- **Standing falsifiers** from `01` §3: derive a substrate term from the other five; admit an unrefusable same-kind bond; add an atom by search inside a closed set; restore all five conditions with one lever; obtain an independent ground verdict from a verifier that reconstructs the claim.

## 5. The honest stop

**Unreached, not unreachable.** The slot is open because no instrument held can discriminate the sources behind an aggregate score. The structured neuro-symbolic review itself says *"we do not believe there are enough results to draw definitive conclusions"* (Hamilton et al., 2024, opened 2026-11-24). The answer stops where instruments stop and records the lineage: five roles unbundled, bonds priced, search bounded, memory split into record and reach, tools imported, ground installed. *"Indiscernibility is not identity"* (canonical README). Two architectures indiscernible on one benchmark are not thereby the same architecture.

## 6. One-paragraph version for outreach

> The Tether does not name a winning hybrid AI architecture. It unbundles the question: neural learning, symbolic reasoning, search, memory and tools are ingredients, and the answer is the typed bonds among them plus the ground that settles them. Five consequences follow from the figures: the residual must stay indexed per object slot because an average hides where to look; the ground is the only metric, so a symbolic self-check is not an outside verdict; search visits the same closure and buys reach only through an import or a refusal; a growing memory is not a growing reach and needs negation to refuse; and tools are instruments that change contact, so capability belongs to agent and habitat together. The roles sit in a dependency order, instruments to vocabulary to goal to search to carry, and the whole is a cycle rather than a stack. The slot for the specific winning architecture stays open, the falsifiers are written in advance, and a source-discriminating instrument, not a benchmark argument, would close it.
