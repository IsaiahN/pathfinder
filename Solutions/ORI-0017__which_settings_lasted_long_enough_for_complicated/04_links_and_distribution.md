## The two-stage offer

1. **Stage 1:** validate the shape against the ground (rock, dating, concentration assay). Record the verdict before showing any framework material.
2. **Stage 2, opt-in:** if curious, offer the figure text and formula. A later agreement is never pooled as corroboration.
3. **Stage 3:** offer the formula as a method to reuse, with the instruction that each user writes their own refuter and states their own mode.

**Hard precondition:** stages 1 to 3 work only if the stage-1 output survives. As currently drafted it is a shape, not a list, and that is deliberate. If a reviewer demands a named winner, the honest answer is that the figure layer returns a gap and the ground must fill it. Sending a winner would be a `general`-mode verdict with no ground, which the Figures and the mode rule forbid.
