## Question as effect

The residual is not "what is the right observable in quantum gravity". It is: when a description may not lean on a fixed background, what must a quantity be so that two frames related by a symmetry agree on a reading, and what must the frame itself supply for that reading to exist? Option A: define observables as fields on a background grid (a convention promoted to a ground). Option B: define them as relations between a physical reference subsystem and the system, invariant under the symmetry, with the frame's pose recorded as part of the description. A leads to a quantity that changes when the coordinate convention changes; B leads to a relational quantity whose value is invariant and whose frame dependence is explicit.

## What an answer would look like (bound as an ordinary term)

A candidate answer is a three-part shape: (1) an anchor that does not update on what any frame thinks, (2) a quantity indexed per slot and defined as a bond between at least two physical systems so it is invariant under the relevant symmetry, and (3) a transform between frame descriptions that names the pose of the frame. This term is bound before the run so the pre-registered refuter can bite it (Formula "Direction").
