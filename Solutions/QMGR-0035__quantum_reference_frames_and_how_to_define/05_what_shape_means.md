## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32 *"you get a kind of thing, never the answer itself"*. Fig 13 :134-135: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. For this question the shape is: non-updating anchor, per-slot relational bond between at least two physical systems, explicit pose, recorded lineage for the frame choice. A particular clock, symmetry group or observable is a **name**. The shape constrains; it does not fill.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary already closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 6 :30: *"outward: does another frame already hold it? The description travels."* Fig 9 :30 *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: the answer is reached when *"the finish line will also be the starting place"*, and the paradox is that by then you have *"composed the answer through the process of locating it."*

Here the effect was described first in `01` section 0 (two descriptions related by a symmetry disagreeing on a reading), and only then were the frames searched. If the theory had been named first, any frame would have seemed to fit (Fig 9 :27-28).

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with source gate and shadow test.

*They're Scanning Books* sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

So naming a particular reference subsystem as the clock is a choice made visible, not a discovery of nature's own clock. It must carry its provenance: which frame supplied it, which symmetry it respects, which reading it grounds.

## 4. Why the record's "one true observable" would be the forbidden error

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*; one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. The reading does not determine the source. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

Applied here: a set of measurement outcomes does not by itself identify which subsystem played the reference role, or which group element connected the frames. Several choices of clock and relational coordinate can yield the same predicted coincidence. What is owed is an instrument and a provenance record, not an assertion that one observable is *the* observable.

*The Recursive Self-Improvement Trap*: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."*

## 5. Q: what licenses a reference subsystem? ANSWERED at shape level

**What the framework gives:** a reference system must be physical and in contact (Fig 11 :39-40), it must supply a pose for the frame transform (Symbols table `F`), and the quantity relating it to the system must be invariant under the symmetry (F2 of `01`). That is a shape.

**What the framework does not give:** which subsystem, which group, which relational coordinate, or the transform for a superposition of poses. Those are bindings from the physics frame, provenanced as such, or they are a declared `gap`. Naming one is not forbidden, but asserting it is the unique answer is a verdict in `general` mode with no ground reading, which is the named output-layer defect.

## 6. Correction to my own §3 and §4

I initially treated *"shape, not a name"* as forbidding the naming of any reference subsystem or clock. That overstates the rule. The README's phrase governs a **missing** primitive, one not held in the library. A reference subsystem is a physical system already inside the universe; it is a binding onto atoms already held, not a seventh primitive. Fig 13 :134-135 confirms: the system *"cannot say which primitive is missing, because naming it would mean already holding it."*

So naming a clock is permitted as provenanced binding. What remains forbidden is: (a) claiming the binding moves the closure wall (Fig 6 :21 *"MINT composes inside the closure and can never add an atom."*), and (b) reading the source of a measurement off a projection when several sources would give the same reading (the metamerism point in section 4, not retracted). Both claims are now recorded so neither is quietly lost.
