## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134 *"Unreachable is a verdict here, not a silence,"* and :135 *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*, read this session: *"This means that you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- Shape: *the decision procedure*, that is, index the residual per link and per node; refuse constant adjacency where the link residual persists and does not trend down; unbundle the union of causes; measure the round-trip gap across the process/topology membrane; let an edge-revealing anchor settle it.
- Name, which is withheld: a universal number for when to switch, a named mechanism for a particular network, or a claim that a given observed adjacency is "the" topology.

`SPACE(???)TIME` is the exemplar's shape; `held link slot versus live link slot` is this question's shape.

## 3. What licenses a name or a number

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The canonical README says the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50), with a source gate and a shadow test.

For this question, the nearest thing to a name is a system-specific timescale threshold. Two world sources supply one in effect: Gross and Blasius describe the timescale-separation regime, and de Meijere et al. find an endogenous aggregation scale that depends on burstiness, degree heterogeneity and openness. Both are bindings from the network-science frame, recorded with provenance in `10_source_ledger.csv`. Neither is a figure line and neither is universal, so the threshold stays `specified` and the universal version stays a `gap`.

## 4. The ground and the source problem

*The Hard Problem is About Source*, read this session, gives the mechanism that matters most here. An instrument reads green and *"it cannot comment on the source"*; the source might be green light, yellow plus blue, RGB, CMYK, or a scheme not yet discovered. *"If several paths create the same behavior, then behavior is a projection with lossy information (it cannot define consciousness in full)."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy"*; *"The answer is unreached until a better instrument exists."*

Apply that to network topology inference: a node time series read as "the graph is like this" is a projection. Several adjacency histories can generate the same observed state sequence. Naming one as the source, from a single reading, is the metamerism error. What is owed is a source-discriminating instrument (a direct edge observation, a perturbation), not a cleverer reading of the same projection. This is the world-side echo of Fig 2 :29: *"An anchor is whatever settles the question and does not change its answer because of what any frame thinks."*

## 5. Answer to the shape question

**What licenses a particular fixed-or-dynamic decision for a particular network?** Nothing in the framework. The framework returns the decision shape. A particular decision is licensed only by the ground settling a term, that is by a time-resolved edge observation plus a measured round-trip gap on held-out predictions, or by a provenanced import with a shadow test. Until one of those exists, the choice is the searcher's own contribution and must be recorded as such.

**Does this derivation commit the error the README forbids?** It would if it named a universal threshold or asserted a specific network's regime. It does not. It records both as gaps and names the missing instrument in effect terms: an observation that returns edge identity through time at a resolution where the process residual is already small.

## 6. Consequences for contact

**Prestige is not action.** From *The Recursive Self-Improvement Trap*, read this session: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* The same essay: *"You may all agree and be wrong."* A list of readers chosen for likely agreement produces a convention, not corroboration (Fig 2 :40).

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post."* and *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the decision shape and must be labelled as such. It cannot settle anything it reports on. *"Metatheories cannot validate themselves."*
