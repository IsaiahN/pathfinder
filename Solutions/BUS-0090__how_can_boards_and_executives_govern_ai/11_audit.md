## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

3. **Concretisation (T_E):** a board dashboard with one AI risk score, an internal audit using management's metrics, and a green checklist gate that releases deployments.

**R_T is nonzero.** Five things the shorthand holds do not survive the trip back down:

- **per-slot indexing** is collapsed into one enterprise average;

- **negation** is lost when the gate releases rather than refuses;
- **the filter/witness distinction** is lost when the score becomes the decision;
- **the habitat cascade** is lost when only the model is enumerated.

One thing survives cleanly: the need for a reference that does not update and for a seat able to refuse. That is the residue worth sending. R_T was **not** measured numerically, because no board measurement exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a recorded gap, which is what `06` Q7 and `09` now state.
