## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel* (**carried**): "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So for this question a **shape** is the form any computational description of spacetime must have, statable before a class or an algorithm can be named. It constrains: cross-kind composition, two prices, an open slot, a provenanced class. It does not fill: it does not say "cellular automaton" or "BQP".

## 2. How a shape is obtained

- *Library of Babel* (**carried**): use the vocabulary already closest to the thing, look for recurring new terms that overlap it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge* (**carried**): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *Library of Babel* on stopping (**carried**): the answer is reached when "the finish line will also be the starting place", and the paradox is that by then you have "composed the answer through the process of locating it."

Applied here: describe the residual as an effect (a finite description whose bit price and settling price are both bounded, with a class binding), then go looking for a frame that predicts its shape. Complexity theory (D2) is that frame. It was not chosen because it sounds like quantum gravity; it was chosen after the residual was described (Fig 8 :53).

## 3. What licenses a name or a class

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays." The README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest." For this question that would be a Planck-scale discriminating instrument or a proof of the exact class, not a bound and not a duality conjecture.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. A class name (BQP, NP-hard, undecidable) is licensed this way, and only with provenance recorded.

*They're Scanning Books* (**carried**) sharpens this: "The real import is not a new term in the existing space. It is a new dimension of the space." And: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Also: "Declaring the primitives does not make them neutral. It makes the choice visible."

The six are a visible guess, not a discovery of nature's own list. This matters more here than in most questions: saying "spacetime is a computation" quietly declares computation to be one of reality's compression axes. The figures require that declaration to be visible and refused, not smuggled in.

## 4. Why "spacetime is a computation" is the specific forbidden error

*The Hard Problem is About Source* (opened 2026-11-23) gives the mechanism. Metamerism: an instrument reads green and "cannot comment on the source"; one green light, or yellow and blue, or RGB, or CMYK, or a scheme not yet discovered. "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

Here the reading is the success of a discrete simulation or a holographic complexity correspondence, and the claimed source is "spacetime is computation". Several sources can give the same reading: a fundamental discreteness, an emergent coarse graining, a gauge dual, or a model that merely reproduces known results (Fig 11 :70: "A test harness is a substituted habitat. Which is why a synthetic solve proves wiring and never capability."). Naming computation as the source from the reading is the metamerism error. What is owed is a discriminator, not a name.

*The Recursive Self-Improvement Trap* (opened 2026-11-23): "The catch is that the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." A simulation cannot certify that it is the ground.

## 5. Q2 of this question: what licenses a class? ANSWERED

**What licenses a particular complexity class for quantum gravity? Nothing in the framework.** The framework returns a shape. A class is licensed only by the ground settling a claim (a proof of the exact class, not a bound) or by a provenanced import with a shadow test. Until one of those, the class name is the searcher's own contribution and must be recorded as such.

**Does the question commit the error the README forbids?** Yes, as posed. It asks for "the computational complexity of quantum gravity" as if the framework returned a class and as if the reading (a successful computational model) determined the source (a computational ground). The correct form is the bound description-cost plus settling-cost, with the class slot marked open.

## 5b. Correction to my own sections 3 and 4, kept visible

I overstated the "shape, not a name" rule in the first pass. The README's phrase is about a **missing** primitive, one not held in Γ. Computation is not a new primitive under the framework at all: it is a composition over ordering, directedness and relation, which are held structures (spectrum, gradient, network), acting on held states. Naming a circuit or a lattice update as a binding onto held atoms is therefore **not** forbidden. What is forbidden is:

- treating that binding as a derivation from the six (it is provenance, Fig 8 :50-52);
- claiming it moves the wall (Fig 6 :21: "MINT composes inside the closure and can never add an atom.");
- adding computation to the six as a seventh member (Fig 13 :43-44).

My section 4 metamerism point is **not** retracted. The record still names the source of a reading without an instrument that discriminates among sources. But the reason is the missing discriminator, not a ban on naming held atoms. Both claims are kept so neither is quietly lost. This is the same correction the validated exemplar records in its `05` section 5b and `06` Q1.

## 6. Prestige is not action

From *The Recursive Self-Improvement Trap* (opened 2026-11-23): "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof. Someone let reputation substitute for result. Someone let the trusted name validate the untested claim." And: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

For this field the temptation is acute: citing a famous complexity result or a famous physicist to settle whether spacetime is computational is exactly the named collapse. The legitimate ask is to give the claim a budget to be tried and let a ground settle it.

## 8. One-paragraph version

A shape is the constrained form of an answer you can state before you can name it. For this question it is: any computational description of spacetime must compose across the six-term set's two kinds, computation is a composition rather than a seventh primitive, the word complexity names two prices that do not add (bits for description, actions for settling), and a named class is a provenanced import whose slot stays open until a proof or an instrument pays for it. The framework does not say spacetime is a computation, does not return a class, and refuses the theory-of-everything reading. What it offers is a refusable shape and the discriminator that would close it. That is what this folder derives, in simulation only.
