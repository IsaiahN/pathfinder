## VERDICT (from the figures)

The shape survives; the literal question's implied answer does not. The question is a union of conditions with different anchors. Computation is a molecule over the six-term set, not a seventh primitive, and any computational description must compose across the two kinds. "Complexity" names two prices that do not add, bits for the description and actions for settling it, and a single number is the named flat-formula error. A class (BQP, NP-hard, undecidable) is a provenanced import with a shadow test and is not derived by the framework. Undecidability limits what any frame can certify about itself; it does not say whether spacetime is computational. No ground settles the class at this scale, so the status is `specified`, ungrounded, candidate. "Spacetime is a computation" and "quantum gravity is in class X" are refused as written. The strongest outreach point is canonical: there is no last room, so no theory of everything.

- **cost if wrong:** bounded and locatable. The packet is mode-labelled, states six refuters before the conclusion and records the import lineage, so an error is findable rather than invisible. The real cost is spending the independence of outside readers by sending a name where a shape is owed, which Fig 2 :42 prices: "Buy independence in proportion to the cost of being wrong." That cost is avoidable by leading with the union split, the shape claim and its refuter.
- **undoable:** yes. The refused elements are removable without touching the derivation: `07_the_tether_answer.md` and `08_expert_verification_packet.md` already remove them. A sent class claim can be superseded by the corrected packet, and no primitive has to be withdrawn. A wrong imported class can be replaced because the record of where it came from is kept (Fig 8 :50-52).
- **reversed by:** a ground reading, not agreement. A source-discriminating instrument at the relevant scale that names the slot, or a proof of the exact class rather than a bound, would move the claim to `grounded`. Deriving computation as an indivisible seventh primitive, deriving a class from the six alone, showing both conditions share one anchor, or showing a frame certifying its own limit would break the shape claim outright. A figure re-census admitting that settled molecules count as quantities at second order would clear the live operand-type strain. Until one of these fires, the verdict stands as `candidate`.
