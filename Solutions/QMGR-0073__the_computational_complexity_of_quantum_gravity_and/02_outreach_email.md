**Use:** one-to-one, or as a cover letter attached to a submission through the public venues in `03_public_contact_points.csv`. **Not** for bulk send. The field is computational complexity of quantum gravity research.

**Hard precondition:** do not send until the residual and the six refuter conditions in `01_figure_grounded_audit.md` sections 0 and 4 are intact in the message. The output must survive validation or the two-stage offer collapses on contact.

**Subject:** Check one output on the complexity of a physical description before you decide anything else

> Hi [name],
>
> I have one specific output about the question "what is the computational complexity of quantum gravity, and does spacetime have a computational description?" I am not asking you to read a framework first, and I am not asking you to agree with anything. If the output does not survive, there is nothing else to look at.
>
> **The output (`specified`, not `grounded`):** the question is a union of three conditions, not one question. Asking whether a description exists, asking what class it falls in, and asking what could settle either claim have different anchors. The framework's six-term set has states (space, time, energy) and structures (spectrum, gradient, network), with the rule that composition runs across the two kinds and never within one. From that it follows that computation cannot be a seventh primitive. A continuum was removed from the set for exactly that reason: a generating set must not contain what its own members produce. An algorithm is an ordering, a directed update and a relation composed over states, so it is a molecule, not a new kind.
>
> What the framework returns is a shape, not a name or a class: any computational description must compose across the two kinds; "complexity" has two prices that do not add, bits for the description and actions for finding out whether it holds; and a named class (BQP, NP-hard, undecidable) is a binding imported from computational complexity theory, with a source gate and a shadow test, not something the six derived.
>
> **What I am not claiming:** that spacetime *is* a computation, that quantum gravity is in any named complexity class, that a holographic complexity duality settles a Planck-scale question, or that this output is `grounded`. Those are bindings and conjectures from other frames. Until provenance is shown and a ground pays, they carry no evidentiary weight here. I am also not claiming a theory of everything: the framework's own rule is that there is no last room.
>
> **What would refute the output, written before this message:**
> 1. deriving computation as an indivisible seventh primitive that is load-bearing in an established law;
> 2. showing description bits and settling actions are one quantity, or add in one unit without loss;
> 3. deriving a specific class from the six-term set alone with no imported complexity primitive;
> 4. naming a real instrument at the relevant scale that returns a discriminating reading, or a proof that fixes the exact class rather than a bound;
> 5. showing the existence and complexity conditions share one anchor and one instrument, so the union split is wrong;
> 6. showing a frame can certify its own limit, or that a search finding nothing proves absence.
>
> If any one holds, the shape claim is wrong and I will retract it. A one-line "this fails because..." is more useful than agreement. If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** the sources are below. The figures are the authority, not my summary of them.

## Two-stage discipline

1. **Stage 1:** send the residual, the shape claim and the six refuters. Record the recipient's verdict before showing any theory. Ask what they would count as a failure.
2. **Stage 2, opt-in only:** if they are curious, offer the four links. Their later agreement is never pooled as corroboration (Fig 2 :40).
3. **Stage 3:** offer the formula as a generator to reuse, with the instruction that each user states their own ground, mode and refuter.

No personal emails, no receptiveness rank, no bulk send. Fig 2 :42: "Buy independence in proportion to the cost of being wrong."
