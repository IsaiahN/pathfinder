## The question restated as an effect

The sentence asks two linked decisions, not one.

1. **Existence:** does the dynamics of spacetime admit a computational description at all? Option A names one (a Turing machine, a cellular automaton, a quantum circuit, a tensor network). Option B keeps the shape and leaves the specific description open.
2. **Cost:** if a description exists, what is its computational complexity? Option A assigns a class (P, NP, BQP, QMA, undecidable). Option B treats the class as a provenanced binding from the complexity frame, and treats "complexity" itself as at least two non-additive prices.

What each option leads to: A names a slot the framework says it cannot name, proposes a seventh member or a binding presented as a derivation, and asserts a class with no ground at the Planck scale to settle it. B returns the constraint any answer must satisfy, records what would have to be imported, and stops as `candidate` until an instrument or a proof pays for the claim.

**Ordinary-term binding (Formula, "Direction").** To make the sought-for shape refusable, I bind it now as an ordinary term: *a computational description of a physical theory is a finite composition over states and structures whose description cost in bits and whose settling cost in actions are both bounded, and whose complexity class is a provenanced binding from a frame whose closure differs.* That term accrues a residual like anything else and is refused in `01_figure_grounded_audit.md` F2 to F6. Writing the shape down before the run is what keeps the preference from hiding outside the check.

## Headline result

The question is a **union of conditions**, not one hard question with two halves. The figures return a shape: any computational description must compose across the two kinds and never within one; computation cannot be a seventh primitive because it is itself a composition; "complexity" prices in two currencies that do not add (bits for description, actions for settling); a specific complexity class is an import that needs a source gate and a shadow test; and underivability and unreachability look the same from inside a frame. No figure line returns a class, and no ground settles the class at this scale. The verdict is `candidate`, `specified`, ungrounded. World sources (spectral-gap undecidability, limit on NP computation by physical systems, holographic complexity, computational irreducibility, algorithmic information theory, BQP) corroborate the mechanism shape at low overlap but never decide the figure verdict.

## What is deliberately not here

- No personal emails of named individuals.
- No ranking of people by how likely they are to agree.
- No bulk-send plan.

Reasons, in the figures' own words:

1. **Agreement is not an anchor.** Fig 2 :35: "Alignment is triangulation, not negotiation. A mirror cannot correct you." Fig 7 :13: "agreement compounds, evidence does not".
2. **Correlation disqualifies a verdict.** Fig 2 :40: "disqualifying for a verdict: agreement about the world is worthless when the agreeing frames share an evidence pool". Selecting recipients for receptiveness manufactures the correlation that voids their agreement.
3. **A verifier must not hold the interiors.** Fig 10 :42: "A verifier that can reconstruct the claim cannot verify it." The first contact carries the residual and its refuter, never the framework.

Legally: public, opt-in institutional submission routes avoid GDPR and CAN-SPAM style failures that personal-email lists create. The venues in `03_public_contact_points.csv` are institutional and opt-in only.
