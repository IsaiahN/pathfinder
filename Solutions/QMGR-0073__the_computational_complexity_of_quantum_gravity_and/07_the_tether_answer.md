# The Tether's answer on the computational complexity of quantum gravity

**Mode: `specified` on the shape claims, `general` on the structural split, not `grounded`.** This is a shape and a route, not a result. Simulated derivation checked against the figures (`05_what_shape_means.md` section 7), not a ground reading.

## 1. The residual it answers

The question bundles existence (does spacetime admit a computational description?), price (what does that description cost in bits and in actions?), and class (which complexity class applies?). These have different anchors, so it is a **union compound**, not one hard question. Fig 9 :57: "a case in two conditions is not a harder case of either". The contact failure is that physics has no settled description of the Planck regime and complexity theory has no ground connection to it. A proof of a class does not establish a computational ground, and a composable description does not yield a class.

## 2. The shape

1. **The question is a union, not a number.** Three conditions with different anchors. Fig 9 :55: "A bundled problem is usually a union of overlapping conditions, not a list of separate ones." Verdicts stay separate; they are never averaged into one "complexity of quantum gravity" figure.

2. **Computation is a composition, not a seventh primitive.** Fig 13 :43: "A continuum was the seventh and was removed for failing exactly this". Fig 13 :74: "Everything else is a composition across the two kinds, never within one." An algorithm is an ordering, a directed update and a relation over states, so it is a molecule built from the six. Asking whether spacetime has a computational description is asking whether such a molecule composes and settles, not whether a new kind must be added.

3. **Any computational description must compose across the two kinds.** Fig 13 :75: "Two states never bond directly. It is not space-time but space, a structure, time; and two structures join only through a state." A first-order description reads `state - structure - state`. The slot structure is constrained; which structure occupies it is not.

4. **"Complexity" names two prices that do not add.** Fig 12 :125: "A composition costs in two currencies, and they do not add." Fig 12 :126: "Bits price the description. Actions price finding out whether it holds." Fig 12 :130: "Summing them into one figure is the error this names, not the fix for it." A short algorithm can be expensive to verify; a long one can be refuted in a step. Fig 5 :45 places description length inside the framework: "This is minimum description length, Rissanen 1978, which is itself a composition of Kolmogorov complexity and Shannon coding put to work on model selection."

5. **The framework does not name the description or the class.** Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it." A name (circuit, automaton, tensor network) or a class (BQP, NP-hard, undecidable) is a binding imported from the complexity frame with a source gate and a shadow test, not a derivation from the six.

6. **Undecidability is a limit, not an answer.** Fig 8 :37: "A frame cannot certify its own limit. Chaitin: beyond a fixed constant, no system proves that any object exceeds its own complexity." Fig 8 :39: "So a search that finds nothing is never a proof of absence." Underivable-in-principle and unreachable-at-this-budget are different facts and issue different instructions (Fig 8 :40-41). A search for a class that finds nothing does not prove that no class applies.

7. **The class question is second order.** A settled first-order description becomes an atom for the next level: Fig 12 :104: "A settled molecule becomes an atom for whatever composes over it. So irreducible is a fact about a level and never about the world." The class is `(settled description) ⋛ (resource bound)`, a structural relation, not a new field. The operand type is an open strain: comparison is "a threshold relation between two quantities" (Operators :48), and whether settled molecules count as quantities at that level needs an instrument.

8. **No ground settles it here.** Fig 2 :29: "An anchor is whatever settles the question and does not change its answer because of what any frame thinks." Fig 6 :34: "Where nothing is, there is no edge to extend from, and the search for a proto-instrument is a search for one that is already there." World sources give bounds (Lloyd: no more than 10^120 ops on 10^90 bits) and conjectures (Brown et al.: complexity dual to a Wheeler-DeWitt patch action), not a settlement. Status: `candidate`.

## 3. What it explicitly does not say

- Not that spacetime *is* a computation, and not that the universe is a quantum computer. A simulation proves wiring, not capability (Fig 11 :70).
- Not that quantum gravity is in BQP, NP, NP-hard, QMA or undecidable. No figure line returns a class.
- Not that a holographic complexity duality settles a Planck-scale question. It is a conjecture from a differing frame.
- Not that complexity is one number. Bits and actions are different units.
- Not a theory of everything. Fig 7 :6: "the limit: no last room".
- Not `grounded`. Nothing here is asserted as settled by experiment or proof.

## 4. What would settle it: the ground

A discriminator, not a further argument. *The Hard Problem is About Source* (opened 2026-11-23): an instrument that reads green "cannot comment on the source"; the spectrometer resolved it. Here:

- **Source discriminator:** an instrument at the relevant scale that distinguishes an ordering-like metric (spectrum-like) from a directedness-like connection (gradient-like), or that distinguishes fundamental discreteness from an emergent coarse graining. Fig 6 :34 applies: no such reading currently returns anything that fails to resolve.
- **Proof of class:** a proof of the exact class, not an upper bound, not a duality conjecture, and with a dated provenance and a shadow test (Fig 8 :50-52).
- **Currency test:** a single measure that prices description bits and settling actions in one unit without loss; failing that, the two-price shape stands (Fig 12 :130).
- **Standing refuters from `01` section 4:** derive computation as a seventh primitive; derive a class from the six alone; show both conditions share one anchor; show a frame can certify its own limit.

## 5. The honest stop

**Unreached, not unreachable.** The six-term set is "a human's careful guess at reality's compression axes" (essay, carried), not nature's own list. Another sensorium's minimum set need not be these six. The canonical README says the framework returns "a shape, not a name" and stops at the limit of what the available instruments distinguish, recording the lineage so the stop is checkable. Indiscernibility is not identity. Fig 13 :131: "Unreachable is a verdict here, not a silence".

## 6. One-paragraph version for outreach

> The Tether does not say that spacetime is a computation and does not return a complexity class. It says the question is a union of conditions with different anchors, not one number; that computation is a composition over the six-term set, not a seventh primitive; that any computational description must cross from states through a structure to states; that "complexity" names two prices that do not add, bits for the description and actions for settling it; that a class is a binding imported from complexity theory with provenance, not a derivation; and that undecidability is a limit on what any frame can certify about itself. The slot and the class stay open until an instrument or a proof pays for them. What it offers is the shape any candidate answer must have, six refuters written in advance, and the discriminator that would close it.
