## The residual in effect terms

Two candidate prerequisites are offered for the same origin: (A) a self-maintaining reaction network that supplies monomers, and (B) an inheritable polymer that supplies catalytic function and sequence information. Option A ends with building blocks synthesized abiotically before polymers. Option B ends with a replicating polymer before network-level metabolism. The question assumes a linear ordering (one came first). The derivation asks whether that ordering is a chain at all, and what shape any answer must have.
