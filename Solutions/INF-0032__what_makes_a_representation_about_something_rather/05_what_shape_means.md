## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel* (opened): *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name an instance. It constrains; it does not fill. For this question the shape is the three-condition separator (typed bond, non-updating anchor plus refusal, source discriminator), not a list saying which token is about which object.

## 2. How the shape is obtained

- *Library of Babel* (opened): use the vocabulary already known that is *closest* to the thing, then look for new terms that overlap or correlate with it, recursively. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30: *"your words are borrowed too"*; Fig 9 :31: *"describe the effect rather than the cause"*
- *Decoding Tacit Knowledge* (opened): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is the operational definition of an effect description, and it is why the outreach email sends a refuter rather than a theory.
- *Library of Babel* (opened) on stopping: *"You will know that you are done because the finish line will also be the starting place"*, and the paradox is that by then you have *"composed the answer through the process of locating it."*

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README says the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50), with a source gate and a shadow test.

*They're Scanning Books When They Should* (carried): *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"Declaring the primitives does not make them neutral. It makes the choice visible."* So the six-term set is a visible guess at reality's compression axes, not nature's own list. Naming one as *the* object of a representation would turn a visible choice into an invisible one.

## 4. Why "source" is the governing essay for this question

*The Hard Problem is About Source* (opened) is the closest world-side match to Fig 6's instrument rule. Metamerism: a spectrometer reads green and *"cannot comment on the source"*. One green light, yellow plus blue, RGB, CMYK, or a scheme not yet discovered can all produce the reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."*

Applied here: a correlation between R and O is a projection that does not determine that O is the source of R. The error is not that the correlation is weak; it is that the instrument cannot discriminate sources. What is owed is a discriminator, not a name. The resolution in the essay came *"not by argument, but by the arrival of a better instrument."*

## 5. What this question can and cannot get from the framework

**Can:** a shape. The separator says what any candidate aboutness condition must look like: a typed bond rather than co-presence, a non-updating ground with a refusal path, and a discriminator, indexed per object-slot.

**Cannot:** a per-token object list, and cannot certify that a given discriminator is absent in principle rather than merely unreached at this budget (Fig 6 :27 *"from inside the frame the two look the same"*). So the answer to "what makes a representation about something" is a structural separator; the answer to "what is this token about" is a world task for an instrument.

## 6. Correction to my own §3 and to a tempting reading (kept visible)

I initially overstated the "shape, not a name" rule as a ban on naming anything. The README phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a primitive not held in Γ. A ground contact, a bond and a discriminator are not missing primitives: they are already available vocabulary in the framework (Fig 12 defines the bonds; Fig 2 defines the anchor; Fig 6 defines the instrument). Naming them is a binding from this question's frame onto held terms, provenance to be recorded, not an invented seventh term and not an import that moves the wall (Fig 6 :21 *"MINT composes inside the closure and can never add an atom."*).

What remains forbidden is naming the specific object of a token from the correlation reading alone. That is the metamerism error of section 4: a source named from a projection. Both claims are kept visible so neither is quietly lost.

## 7. Two consequences for outreach and for this folder's status

**Prestige is not action.** *The Recursive Self-Improvement Trap* (opened): *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous names who agree with the separator is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay (opened): *"LLMs can quickly simulate an approximate answer/output"* but *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01_figure_grounded_audit.md` and every other substantive file here are simulated derivations checked for internal consistency against the figures. They cannot settle the aboutness question they report on.
