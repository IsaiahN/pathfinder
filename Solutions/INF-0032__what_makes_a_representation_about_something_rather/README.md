## The residual in effect terms

Two things can co-vary and still differ in a way that matters: a thermometer reading co-varies with temperature (and is *about* temperature), while smoke co-varies with fire (and, on the standard philosophical example, merely carries information about it). The residual is the unexplained extra: what is added when we pass from "R correlates with O" to "R is about O"? Stated as an effect, the question asks what must be present for the credit to be paid by the ground rather than only by a convention among interpreters.

## What an answer would look like (bound as an ordinary term)

An answer is a separator, not a definition: a set of conditions such that, where they hold, "about O" is a verdict that can be refused by a non-updating ground, and where they fail, "about O" is only a shared-meaning convention over a correlation. The sought-for shape is written down and bound before the run (formula step "Direction"), so it can accrue a residual and be refused like any other term.
