# Outreach draft: check the method before you decide about the claim

**Use:** one to one, or as a cover note attached to a submission through a public venue in `03_public_contact_points.csv`. **Not** for bulk send.

**Hard precondition:** this offer is only coherent if the recipient records a verdict on stage 1 before seeing any theory or links. Do not put the links in the first message.

---

**Subject:** One checkable claim about testing black-hole theories from outside the horizon

> Hi [name],
>
> I have one specific output I would like you to check against what you already know. I am not asking you to read a theory first, and I am not asking you to agree with anything. If the output does not survive, there is nothing else to look at.
>
> **The output (`specified`, not `grounded`):** "test a black-hole theory without observing the interior" is not one hard question. It is a union of separate conditions, a horizon boundary condition, exterior multipole structure, a dynamical ringdown spectrum, and thermodynamic behaviour. The method that follows from this is: state the residual per observable slot, never as one global verdict; range each candidate theory separately against an instrument reading that does not change when the theory changes; keep cross-messenger independence explicit, since two reductions of the same data set are one witness wearing two names; unbundle the conditions before searching; then run three distinct questions in order, is the answer already in the exterior data, can an instrument already returning a residual be sharpened, and can a frame with a different closure be imported with provenance. The interior itself stays an open slot. Unreachable is reported as a verdict, not as silence, and no search that finds nothing is promoted into proof of absence.
>
> **What I am not claiming:** that any particular alternative to Kerr is right, that laboratory Hawking analogues directly read an astrophysical interior, or that a null result closes the interior. The analogues test a mechanism in a different closure. They are imports with a source gate and a shadow test, not corroboration from the same evidence pool.
>
> **What would refute this output, written before I sent this:**
> 1. An exterior observable whose prediction depends only on interior structure, with no exterior-composable quantity, while still being measurable from outside.
> 2. Two probes held independent shown to draw on a single calibration, prior or data product, so the triangulation collapses.
> 3. A probe that returns nothing at any resolution used as a constraint on the interior.
> 4. A null result promoted into a proof that no alternative interior exists.
> 5. The per-slot residual table shown to be one parameter in disguise, so the partition is false.
>
> If any one holds, the method is wrong at that point and I will withdraw it. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **What I would like from you at this stage:** only your answer to one question. What would you count as a failure of this shape claim, at which slot? Please record that before I send anything else. Your verdict on this output is the only thing I am asking for.
>
> **If it survives, and only then:** I will send the sources. The figures are the authority, not my summary of them.
>
> **If you want to use the machinery:** I can send the formula and the method as a generator. Run it on a problem you know well and can check against a ground. Write down what would refute your result before you run it, and label the mode of what you get. A reported failure is more useful to me than a reported success.

## Why the order is this way

| the move | figure-grounded reason |
|---|---|
| Output first, theory second | Fig 10 :52: *"Bring a characterised residual, never the source."* A recipient who has absorbed a frame before being asked for a verdict has joined the frame being checked. |
| Ask for a failure, not agreement | Fig 2 :35: *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* |
| Verdict recorded before theory is shown | Seat 4 must not hold the interiors. Later agreement is never pooled as corroboration (Fig 2 :40). |
| Five pre-registered refuters | A falsifier written before the run is a design instrument, not only an honesty device. |
| Mode stated on every claim | `THE_FORMULA.md`: *"Mode. general · specified · grounded. State which."* |
| Per-slot residuals, no global score | Fig 1 :19: *"The residual is indexed by object slot, not aggregated."* |
| Independence explicit | Fig 2 :42: *"Buy independence in proportion to the cost of being wrong."* |
| Union unbundled before search | Fig 9 :54: *"And when the split lands on a union rather than a partition, unbundle before you search again."* |
| Interior left open | Fig 13 :134: *"Unreachable is a verdict here, not a silence"* |
| Null result not promoted | Fig 8 :39: *"So a search that finds nothing is never a proof of absence."* |
| Links only after stage 1 | Fig 4 :22: *"Only methods cross up. Only head starts come down."* A recording sent before a residual is described is a description of one occasion, not a generator. |
| No prestige ask | Prestige can fund a trial and cannot settle it. The ask gives the claim a budget to be tried; it does not ask for endorsement. |
| No personal emails, no bulk send | Public opt-in channels avoid the selection correlation and the legal failure together. |
