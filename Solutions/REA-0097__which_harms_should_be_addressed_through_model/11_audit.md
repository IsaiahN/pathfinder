## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed zero. I ran the round trip on the condensation this folder actually uses.

2. **Abstraction (T_A):** the shorthand carried in `07` and `08`: a three-way decision procedure (design, habitat, compound), anchor first, channel repair before blame, no standing harm list.
3. **Concretisation (T_E):** a named harm assigned to a named lever in a real deployment, for example assigning hiring discrimination wholly to law or wholly to training data.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down.

- **The per-slot anchor.** The shorthand says name the anchor; the concrete case must specify which outcome settles which group's harm, at which time. A pooled metric drops the signal (Fig 1 :22).
- **The compound's two levers.** The shorthand says compound cases have two levers; the concrete case must run two instruments and keep the verdicts separate. Collapsing them into one blended harm score loses the diagnostic.
- **The source discrimination.** No figure line names which lever works for a named harm. That step needs an instrument the folder does not hold. Treating the procedure as if it were the assignment would set R_T to zero and commit the dead-reckoning error Fig 4 :30 names.

One thing survives cleanly: a structure that changes contact is the lever; an improvement that does not change contact changes nothing (Fig 11 :40). That is the residue worth sending. R_T was **not** measured numerically, because no per-slot ground reading exists. It is recorded qualitatively as the enumerated set of dropped constraints.
