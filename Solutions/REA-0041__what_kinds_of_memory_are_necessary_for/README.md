## What an answer would look like (bound as an ordinary term)

Before the run, the sought-for shape is made an ordinary term so it can accrue a residual. Here it is: *a small set of memory functions that are each load-bearing (remove one and the loop stops), that are kept as separate quantities rather than averaged, that are ordered by dependency, and that are named only as a shape until a ground discriminates among candidate taxonomies.* That term is what the derivation tests, not a conclusion smuggled in.
