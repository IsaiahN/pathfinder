## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (**a shape, not a name**)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134–135: *"Unreachable is a verdict here, not a silence. It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question, *"a record that only grows and a reach that can fall, with methods kept apart from occasion-records"* is a shape. *"The human episodic/semantic/procedural triad is exactly the necessary taxonomy"* is a name, and the framework does not license it.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap with it, recurse. *"With each new term gained, you narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30–31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: *"the finish line will also be the starting place"* and the paradox that by then you have *"composed the answer through the process of locating it."*

## 3. Why arrangement, not inventory, is the shape here

*They're Scanning Books* states it plainly: *"A corpus is the compressed output of human minds; the capacity that produced it is a generator, and outputs do not contain their generator."* And: *"The corpus contains the problems evolution already solved and someone wrote down. It does not contain the capacity to solve new ones, because that capacity lives in the living process, the mind generating, not in the text it generated."*

*How Intelligence Actually Works* echoes this in the provenance thought experiment: a video frame and a photograph *"carry different warrants... And nothing in the image records which."* Hence *"the lineage has to be kept even when the copy is perfect."*

This is the figure-side Fig 4 :25 — *"A recording carried upward looks like knowledge and is a description of one occasion"* — in world vocabulary. It is the reason the answer to "what kinds of memory" is a shape about *arrangement* (generators versus instances, record versus reach, lineage kept) rather than a list of storage bins.

## 4. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8), with a source gate and a shadow test.

*They're Scanning Books* sharpens the second: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

For memory research this matters: a proposed taxonomy is a visible guess about the compression axes of a mind, not nature's own list. Naming it as settled turns a visible choice into an invisible one.

## 5. Why "more memory" is not the answer

*They're Scanning Books*: *"Adding data and parameters to a fixed architecture is the whale strategy: more units, same structure, diminishing returns. The escape is not more of the same substrate. It is a change of structure."* Fig 5 :72 agrees at the framework level: *"a library that grows is not a reach that grows."*

*The Hard Problem is About Source* supplies the instrument criterion: when several underlying causes create identical readings, *"behavior is a projection with lossy information,"* and the case is resolved *"not by argument, but by the arrival of a better instrument"* (the spectrometer for metamerism). Applied here: a memory benchmark that reads "accuracy" cannot comment on the source of that accuracy. What is owed is a source-discriminating instrument, not another score.

## 6. Pretext is the memory a learner brings

*Decoding Tacit Knowledge* is the most directly relevant essay to this question: *"Pretext is the history ('the library'): the experience and assumptions the listener brings before the words arrive."* And: *"Settling compresses the description and not what it cost to establish"* (Fig 12 :107 quoted there). So the cost of building a memory does not travel with the compressed term; the learner rebuilds it through contact, and *"Only methods cross up. Only head starts come down"* (Fig 4 :22, quoted there).

This corroborates the figure verdict that the transmissible, organizing unit is the method, not the record, and that the record itself (the pretext) is what the learner must carry.

## 7. Why this audit is a simulation, not a ground reading

*The Recursive Self-Improvement Trap*: *"The output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* And: *"LLMs can quickly simulate an approximate answer/output with the formula... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."*

So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the memory claim and must be labelled as such. It cannot settle anything it reports on. Fig 2 :45 — *"Frames range against the ground. They do not negotiate with it."*

## 8. Correction to my own reading

I initially wrote that "the framework returns a shape, not a name" forbids using any cognitive-science label for the memory kinds. That overstates it. The README's phrase governs a **missing** primitive, one not held in Γ. The figure governing memory (Fig 4, Fig 10 :68) distinguishes *generator* from *instance*, and "method" and "record" are ordinary terms for that distinction, not newly invented primitives.

What remains forbidden is claiming the framework *derives* the human episodic/semantic/procedural taxonomy, or that a benchmark *names* which memory system a score came from. Both claims are retracted. The shape stands; the taxonomy is not licensed. This correction is kept visible rather than silently erased.
