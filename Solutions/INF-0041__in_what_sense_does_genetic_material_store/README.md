## Restatement as an effect

Two uses of the word "information" are being run together. One is a coding quantity: a low-cost arrangement over a small alphabet, measurable as description length or Shannon bits. The other is a semantic quantity: aboutness, function, "meaning". An answer that picks one and calls it the other fails at the seam. What an answer would look like is a partition of the two quantities with an anchor for each, plus a statement of the relation between them that does not require either to be renamed. Bind that description as an ordinary term and let it accrue a residual like anything else (Formula, "Direction").

- Option A: meaning is intrinsic to the nucleotide sequence, so the sequence is a self-contained store.
- Option B: the sequence stores a coding quantity, and biological meaning is a relation among the sequence, an interpreter, and a ground that pays.
- What each leads to: A makes the sequence its own metaframe, which Fig 8 :34 forbids, and turns a declared code table into a ground (Fig 10 :18). B returns a shape (sequence, reader, ground) and names no physical locus, so it owes a discriminator instrument and records a `gap` rather than a name.
