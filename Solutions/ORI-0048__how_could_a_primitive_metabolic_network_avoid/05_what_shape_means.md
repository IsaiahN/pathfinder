## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32 "you get a kind of thing, never the answer itself". Fig 13 :134 "Unreachable is a verdict here, not a silence," and the README adds "Indiscernibility is not identity."

For this question, a **shape** is the narrowed form an answer can take before a chemical name is licensed. It constrains; it does not fill.

- Shape: "the reactions that matter sit in closing loops, overlap functionally over shared molecules, and the network stays open to import."
- Name: "the rTCA cycle was the first self-maintaining network" or "mineral X catalysed the essential step."

The first is checkable as a structural claim. The second is a binding from the chemistry frame and needs a ground reading plus a provenance record.

*The Library of Babel* (carried quote): "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question." The response to ORI-0048 is exactly that: a small set of structural constraints, not a filled pathway.

## 2. How the shape is obtained

- *Library of Babel* (carried quote): use the vocabulary closest to the thing, look for recurring new terms that overlap with it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30 "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30 "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge* (carried quote): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." For this question: what would you expect to see if closure, overlap and import were the mechanism? Answer: catalyst regeneration after loss, multiple paths over the same metabolites, and a dependence on external feeds.
- Fig 11 :43 "The habitat is enumerated, never composed." For this question the shape is obtained by reading off actors, conditions and relations, not by composing a mechanism from preferred chemistry.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** THE_FORMULA.md step 5: "SETTLE the ground settles it. Verified only by what pays. A gate is not the ground." The README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test. Fig 6 :23 "No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs." Fig 8 :51 "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them."

*They're Scanning Books* (carried quote): "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "Declaring the primitives does not make them neutral. It makes the choice visible." So naming a particular mineral or pathway as the answer turns a visible choice into an invisible one.

## 4. The source error, and why it matters here

*The Hard Problem is About Source* (carried quote): an instrument reads green and "cannot comment on the source"; "If several paths create the same behavior, then behavior is a projection with lossy information." The spectrometer, not an argument, resolved it.

For ORI-0048 the corresponding temptation is to observe that a network persists after a perturbation and name the cause (a catalyst, a cycle, a membrane) from that single reading. Several mechanisms can produce the same persistence curve. What is owed is an instrument that discriminates sources, for example one that distinguishes catalyst regeneration from external replenishment, not a name. Fig 8 :39 "So a search that finds nothing is never a proof of absence." An unresolved source is an open slot, not a failed search.

*The Recursive Self-Improvement Trap* (carried quote): "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."

## 5. The shape for this question, stated as an ordinary term

Binding the sought-for shape per THE_FORMULA.md "Direction" makes it refusable:

> **Sought shape S:** a primitive metabolic network retains its self-maintaining function under a habitat change iff (a) the reactions carrying that function sit in at least one closing loop that regenerates its catalysts, (b) there exists functional overlap over the same molecular inventory so one arrangement can cover a failed one, and (c) the network is open to an import when the required atom is absent from its closure.

S is an ordinary term in this derivation. It accrues a residual and can be refused by the four refuters in `01_figure_grounded_audit.md` section 4. What S explicitly does not contain: a molecule name, a pathway name, a habitat name, or a claim that any actual early network satisfied it.

- Grounded reading of S: none. No measurement distinguishes (a), (b) and (c) in a prebiotic setting.
- Specified reading: S follows structurally from Fig 12 :119, :121, :117, :124, Fig 6 :14, :21 and Fig 11 :39, :43.
- General reading: preservation is a function of a network-plus-habitat system, never of the network alone (Fig 11 :39).

## 6. Prestige is not action

From *The Recursive Self-Improvement Trap* (carried quote): "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

A list of famous origin-of-life researchers who agree with S is the named collapse, not corroboration. The legitimate ask gives the shape a budget to be tried: run the refuter, or name an instrument that would discriminate the sources. Fig 2 :42 "Buy independence in proportion to the cost of being wrong."

## 7. My own audit is a simulation, not a ground reading

Same essay (carried quote): "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." LLM output is "simulacra". So `01_figure_grounded_audit.md` and this file are simulated derivations, checked for internal consistency against the figures. They are **not** tests of the claim. They cannot settle the question they report on.
