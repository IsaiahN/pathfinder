## Independent domain census

I redid the census from the residual line alone, before relying on the primary's conclusions, using the WATSON order: R by arity, symmetry, scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** A receptor reading underdetermines its source. Arity: at least two, reading and source, so the problem is a **union compound** (Fig 9 :4-5): four overlapping conditions, not four separate questions. Symmetry: false positive and false negative cost differently, so the discriminating relation is a threshold, not a symmetric join. Scale: molecular event, cellular decision, population settlement, with two membrane crossings.
- **Domain 1, molecular sensing frame.** Actors: receptors, ligands, fluctuations. Currency: occupancy. Anchor: none internally, because a reading cannot name its source. This domain cannot decide the residual by itself.
- **Domain 2, environmental ground.** Actors: conditions and consequences. Currency: what the response pays. Anchor: the environment, which does not change its answer because of what the cell thinks. A ground that moves independently is still an anchor; a ground the cell moves is a new domain.
- **Domain 3, population / evolution.** Actors: variants and lineages. Currency: differential survival. Anchor: the ground via selection. New receptor specificity is an import, not a mint.
- **Domain 4, maintenance / channel.** Actors: the resetting apparatus. Currency: channel integrity. Anchor: the ground, never agreement.

Order by dependency: describe the residual before naming a mechanism (Fig 8 :53 *"Residual first, frame second."*); resolve perception before objective (Fig 3 :5); settle each discriminator before asking which persists (Fig 12 :104 *"A settled molecule becomes an atom for whatever composes over it. So irreducible is a fact about a level and never about the world."*); refuse before mint (Formula step 2).

## Round trip gap R_T

Conversely, one thing survives cleanly: a receptor reading underdetermines its source, so detection must be per slot and must range against something that does not move with the frame. That is the residue worth sending. R_T was not measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
