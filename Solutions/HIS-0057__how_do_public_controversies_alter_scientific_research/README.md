## What an answer would look like (bound as an ordinary term)

An answer is a two-part shape plus a route:

1. **Agenda part.** A public controversy changes *which object slots carry live residual*, by changing the habitat in contact with the residual (new actors, new funding, new instruments, new audiences). The slots are never averaged into one global "public pressure" number.
2. **Proof part.** A public controversy changes *what counts as settlement* only in one of three ways: (a) an honest refutation lowers the reach, (b) a convention about shared meaning is renegotiated, or (c) the anchor is moved by agreement, which is the failure the figures name. A controversy that merely adds voices does not change the ground.
3. **Route.** Describe the residual first, then enumerate the habitat, then ask which figure governs. Verdicts are kept per domain and never averaged.

This shape is bound before the run so it can accrue a residual like anything else (Formula, "Direction"; Fig 5 :65-66).
