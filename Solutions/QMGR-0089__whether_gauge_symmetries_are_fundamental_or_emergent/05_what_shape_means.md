## 1. A shape is a constraint, not a filler

The canonical usage rule states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13 :134-135: *"Unreachable is a verdict here, not a silence, It cannot say which primitive is missing, because naming it would mean already holding it."*

From The Library of Babel, opened and verified: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- "Symmetry is derived, not primitive" is a shape.
- "The gauge group is SU(3) x SU(2) x U(1) because the substrate says so" is a name, and the framework does not license it.

The four refuters in `01` section 4 are part of the shape. A claim that cannot state what would break it is not yet a shape; it is a preference.

## 2. How the shape is obtained

- **Proximity bootstrapping (Library of Babel).** Use the vocabulary already held that is closest to the thing, then recurse on new terms that overlap with it: *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- **Describe the effect, not the cause.** Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause"*. Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Applied here: describe "irreducible at level n, dissolved above level m", not "the gauge principle is a law of nature".
- **The question is the tether (Library of Babel).** *"This anchor is provided by your own question: If the question is answered by your present collection of books from your search you know whether to stop or continue and which direction to turn next."* The bound Direction sentence in `01` section 0 is that tether made explicit.
- **Stop at the shape (Library of Babel).** *"you will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better."* Here the stop is reached when the question splits: F1, F2 and F3 close; F6 does not, and that is the stopping point.

## 3. When a name is licensed

Two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* In this question that means an instrument, not a further interpretation of the Aharonov-Bohm effect.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :14, Fig 8 :9-13). If a physicist can show that a gauge atom must be imported to explain a residual that no arrangement of the six can hold, that is licensed. It is not licensed by declaring the gauge principle fundamental.

They're Scanning Books (not opened this run, so not quoted here) is listed in the canonical set as the essay that distinguishes a new term from a new dimension of the space. I do not rely on it in this folder.

The important consequence is that the six-term set is a visible choice, not nature's own list. Declaring it does not make it neutral. Naming one structure as *the* basic gauge structure would turn a visible choice into an invisible one.

## 4. Source discrimination is the live failure mode here

The Hard Problem is About Source, opened and verified, gives the mechanism. An instrument reads green and *"the instrument is speaking only about what it measured, it cannot comment on the source."* Several sources can produce the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information"*. And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy"*. It was the spectrometer, not an argument, that resolved the case.

That is exactly F6. A gauge-invariant instrument reads the same value whether the gauge structure is fundamental or effective at that level, because gauge equivalence is defined as sameness of the reading. Naming one source from that reading is the metamerism error. What is owed is a better instrument, not a sharper interpretation. The honest report is `gap`: *"The answer is unreached until a better instrument exists."* (The Hard Problem is About Source.)

## 5. Answer to the question this file exists to answer

**What does "shape" mean for "fundamental or emergent"?** It means the level-indexed constraint stated in `01` F7: gauge equivalence is identity among descriptions; its irreducibility is level-relative; there is no bottom and no top; and a same-level discrimination needs an instrument that gauge invariance itself withholds. That is the form any answer must take. It is not an answer to which option is true, and this file does not claim one.

**Does the framework name the basic gauge group?** No. It cannot name a missing primitive without already holding it (Fig 13 :134-135), and it cannot pick among atoms it already holds from the six alone. A specific group is a binding from the physics frame, provenanced as such.
