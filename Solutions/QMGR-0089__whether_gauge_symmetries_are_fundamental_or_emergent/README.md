## Restatement as an effect

The question asks where a gauge symmetry sits. If it is **fundamental**, it is an atom of the description: it cannot be composed away, it must be posited before the dynamics, and removing it removes physics. If it is **emergent**, it is a molecule composed from more primitive terms: it holds only below some scale, it dissolves above that scale, and positing it as basic freezes an effective description into an axiom. An answer would look like a statement of the level at which the symmetry is irreducible, the atom set it composes from, and an instrument that would discriminate the two readings. That shape is bound as an ordinary term in `01_figure_grounded_audit.md` section 0 so it can accrue a residual like anything else.

## Key verdict, in one line

The figures refuse the binary as posed. They return a shape: symmetry is a derived quantity and never a substrate member (Fig 13 :124-125), gauge equivalence is an identity relation among spellings of one state (Fig 12 :67, :69), and irreducibility is a fact about a level and never about the world (Fig 12 :104), with no bottom and no top (Fig 12 :104, Fig 4 :33). So a gauge symmetry can be emergent at one level and an atom at the next without contradiction. The same-level discrimination of fundamental from emergent is a `gap`, not a silence, because gauge-equivalent configurations are empirically identical by definition and no gauge-invariant instrument can separate them.

## What is deliberately not here

3. **A prepared reader cannot check.** Fig 10 :42: *"A verifier that can reconstruct the claim cannot verify it."* The outside frame must meet the residual before the interior.
