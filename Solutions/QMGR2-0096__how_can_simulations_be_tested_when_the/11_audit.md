## Independent domain census

I redid the census from the residual line alone, before comparing with the primary's conclusions. I used the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The gap between a simulation's prediction and each observation of the universe. Arity: many slots (CMB spectra, BBN abundances, BAO, large-scale structure, numerical convergence), never one global average. Symmetry: asymmetric, because the observation does not update on the model. Scale: microphysical inputs to emergent outputs across a lossy transform. I read this as a **union compound**, because "cannot recreate" bundles at least three conditions: no manipulation of the subject, limited access, and coarse-graining.
- **Domain 1, the simulation frame.** Actors: laws, initial conditions, numerical scheme, parameters. Currency: prediction and residual. Anchor: none inside; a closure cannot supply its own ground. Partition against the ground.
- **Domain 2, the observational ground.** Actors: photons, nuclei, galaxies, instruments. Currency: measurements that do not move when the model changes. Anchor: the universe as observed, legitimate because the question is constitutively about it. Not a party to a vote.
- **Domain 3, the analogue / harness.** Actors: fluids, condensates, lab reactions, test suites. Currency: wiring checks. Anchor: the apparatus, but it is a substituted habitat. **Union** with Domain 1, not a partition, because it shares laws and machinery.
- **Domain 4, the instrument chain.** Actors: existing and sharpened probes. Currency: readings. Anchor: whatever already returns something.

Order by dependency: keep the anchor reachable; describe R before choosing a frame; settle first-order slots before composed ones; treat the harness as wiring; import last.
