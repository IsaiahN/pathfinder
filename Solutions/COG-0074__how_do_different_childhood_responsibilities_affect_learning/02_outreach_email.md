**Subject:** One checkable claim about childhood responsibilities and three outcomes

> Hi [name],
>
> I have one specific output I would like you to check against what you already know. I am not asking you to read the framework first, and I am not asking you to agree with it. If the output does not survive, there is nothing else to look at.
>
> **The residual, in effect terms (`general` shape, not `grounded`):** a childhood responsibility (a chore, caring for a sibling, managing a resource) changes what a child contacts: new actors, new conditions, new relations. The question is how that change registers in three separate slots, learning, independence and cooperation. The output is that the effect is (1) through contact, not through the child in isolation: if nothing about the child's contact changes, nothing changes; (2) read per slot, never as one "maturity" score, because the slots have different currencies; (3) routed through a dependency chain, so a responsibility only builds skill if the child can perceive the affordance, has terms for it, can say what counts as doing it well, and can carry what worked; (4) relative to the residual, so no responsibility is inherently good or bad; and (5) a union compound, so a child with high responsibility and high support is a specific case, not "more of each."
>
> This is a shape any answer must have. It is not a measurement, and it does not name which responsibility produces which effect size. That is `unreached` here, and I say so.
>
> **What I am not claiming:** that any particular chore causes independence; that more responsibility is always better; that the three outcomes can be added into one score; or that this framework settles a decades-old developmental question. Convergent derivation and adopted import look identical in the contents and only the record separates them, so anything I borrow from developmental psychology is provenanced as a borrow, not presented as a derivation.
>
> **What would refute the shape claim.** I wrote these down before sending this:
> 1. a responsibility that demonstrably changes no contact still changes one of the three slots;
> 2. a single global "development" score predicts each slot as well as separate scores with no loss of signal;
> 3. adding responsibility above a demonstrably broken dependency-chain link still produces competent action;
> 4. the same responsibility is shown to have a fixed, residual-independent valence across all three slots in every arrangement.
>
> If any one holds, the relevant finding is withdrawn and I redo the census. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** the sources are below. The figures are the authority, not my summary of them.
> - Verbatim figure text with line numbers (local framework file): `FRAMEWORK/reference/03-FIGURES_TEXT.md`. Read Fig 1 :19, Fig 3 :27, Fig 9 :32, Fig 11 :40, Fig 12 :112.
> - The canonical usage rule (local framework file): `FRAMEWORK/reference/FIGURES_README_canonical.md`.
> - The eight-step loop and mode rule (local framework file): `FRAMEWORK/figures/THE_FORMULA.md`.
>
> **If you want to use the machinery:** the formula is in the figures link. Run it on a problem you know well and can check against a ground. Write down what would refute your result *before* you run it, and label the mode of what you get. The framework's own limit is that a loop cannot check the direction of its own question, so a reported failure is more useful to me than a reported success.
