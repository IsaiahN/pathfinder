## What is being decided, in effect terms

A child is a bounded system with a library (skills, terms for what tasks afford, norms). Responsibilities (chores, caregiving of siblings, household work, self-care, paid work) are changes to what that system contacts. The question asks what changes in three outcome slots: learning, independence, cooperation. Option A treats "responsibility" as a single lever that adds a trait called maturity. Option B treats responsibilities as habitat changes whose effect must be read per slot, through the dependency chain, relative to each residual. A averages three different signals into one score and loses the signal (Fig 1 :22). B keeps the slots separate and stays checkable.
