## 1. A shape is a constraint, not a filler

The local figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13: *"It can say the answer is out of reach with the library as it stands... It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** here is the narrowed form of a property you can state before you can fix its exact standard. It constrains; it does not fill. For this question:

- **Shape:** misleadingness is a receiver-indexed relation over a union of an objective accuracy condition and a receiver-uptake condition.
- **Not the shape:** a particular threshold, a particular "reasonable consumer", a particular fact-checking protocol. Those are names, to be supplied by a ground or a declared convention.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*: when contact is not possible, the best you can send is a plain description of what you would expect to see, because anyone can check that against the world.
- *Library of Babel* on stopping: the finish line becomes the starting place, and the searcher *"composes the answer through the process of locating it."*

Applied here: the effect term is "the verdict moves when the receiver or context moves." That is checkable by anyone with a headline and two audiences, without reading a framework.

## 3. What licenses a name

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* For this question, an experiment showing a message-only metric that tracks actual belief divergence across independent audiences would license a name.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. The FTC's "reasonable consumer" is such an import from law; it is licensed *as a convention* within that closure, not as the ground for the whole question.

*They're Scanning Books* sharpens this: the real import is a new dimension of the space, not a new term in the existing space, and declaring the primitives does not make them neutral. So the "reasonable consumer" is a visible choice, not nature's own list.

## 4. The source problem: why a message reading cannot name its own source

*The Hard Problem is About Source* gives the mechanism. Metamerism: a color instrument reads green and *"cannot comment on the source."* One green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered, all give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* What resolved it was **the spectrometer, not an argument**: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."*

For this question the reading is "this message is misleading" and the possible sources are: false content, true content under a misleading implicature, true content removed from context, a receiver's prior, a source-credibility cue, repetition. A message-only instrument cannot comment on which source produced the reading. Naming "the message" as the source is the metamerism error. What is owed is a discriminating instrument, not a name.

## 5. Correction to my own reading of §1

I initially treated "shape, not a name" as if it forbade naming any standard at all. The canonical phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* It governs a primitive not held in Γ. Here the receiver and the facts are held in the habitat (Fig 11), and "reasonable consumer" is a convention from another frame. So naming a reference audience is not forbidden; **claiming the framework derives it** is. The figure returns the relational shape. A specific standard is a convention or a ground reading, provenanced as such.

This correction does not retract §4: the metamerism point stands, but its reason is the missing discriminator among sources, not a ban on naming held things.

## 6. Two consequences for this question

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous experts who agree that a message is misleading is the named collapse, not corroboration. In misinformation research this matters acutely: the "expert" whose judgment is cited must be ranged against the ground separately, never used as the ground.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the claim, cannot settle it, and must be labelled as such. The same caution applies to *The Library of Babel*'s warning about a search that returns a flattering answer: a shape written after the run is not a pre-registered shape.
