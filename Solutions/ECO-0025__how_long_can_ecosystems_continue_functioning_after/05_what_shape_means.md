## 1. A shape is a constraint you can state before you can name the answer

The figures README says the framework reports *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: **"you get a kind of thing, never the answer itself"**. Fig 13 :134: **"Unreachable is a verdict here, not a silence"**.

From *The Library of Babel*, opened: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For ECO-0025 the shape is: **a duration attached to a named function, in a named habitat, under a named perturbation, with an instrument that reports when the function crosses its threshold, and a refuter that would break the estimate.** This is not a filler waiting for a number. It constrains any acceptable answer: if it has no slot, no threshold, no cascade and no instrument, it is not the kind of thing the framework returns.

The bare question "how long?" is a name request aimed at a slot the framework leaves open. `SPACE(???)TIME` in the exemplar is the analogous case. Here the analogous notation is `FUNCTION(slot) ⋛ THRESHOLD at time t(???)`, with the duration left marked.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary already held that is closest to the thing, look for recurring new terms that overlap with it, and recurse. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: **"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."** Fig 9 :30-31: **"your words are borrowed too, so describe the effect rather than the cause"**. So instead of asking for "relaxation time" (a borrowed term from a particular model), describe the effect: the reading stays high after the contact has changed.
- *Decoding Tacit Knowledge*, opened: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* For this question: expect adult plants to persist while juvenile recruitment collapses, expect a guild average to stay flat while one functional group disappears, expect a long-lived stage to keep a reading alive after reproduction stops.
- *Library of Babel* on stopping: the answer is reached when *"the finish line will also be the starting place"*, because the searcher has *"composed the answer through the process of locating it."* Here the starting place is the effect description of a channel that keeps reading after contact has moved; the stop is the same description with slots and refuters attached.

## 3. What would license a name (a number of years)

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5 (local): *"the ground settles it. Verified only by what pays. A gate is not the ground."* A prospective, non-updating function assay would settle a duration for a named slot. Fitting a half-life to a presence record does not, because the presence record is not the function.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23; Fig 8 :50-52), with a source gate and a shadow test. A generation time from population biology can be imported into a slot, but it must be declared as an import with provenance, not presented as a duration the framework derived.

From the mapping carried from the exemplar, *They're Scanning Books When They Should*: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"Declaring the primitives does not make them neutral. It makes the choice visible."* In ecology this matters because the choice of which function counts is a human choice about what to measure. Making it visible is the honest move; hiding it inside "ecosystem functioning" is not.

## 4. The specific forbidden error here: reading the source off a projection

*The Hard Problem is About Source*, opened, gives the mechanism. A spectrometer reads green but *"cannot comment on the source"*: green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. *"If several paths create the same behavior, then behavior is a projection with lossy information."* It was the instrument, the spectrometer, that resolved it, not an argument. *"An instrument that can't distinguish these cases demonstrates its own inadequacy."*

Applied here: a species-presence record and a function reading can agree while their sources differ. A site can read "functioning" because the pollinator is still present, because a substitute guild member is doing the work, because long-lived adults have not yet died, or because the metric is saturated. These are metamer(s): several sources, one reading. Naming "the species is still there, therefore function persists" reads the source off the projection. What is owed is a discriminator, not a story.

Ridding et al. 2021 (opened, reduced weight) sharpen this: the detection and magnitude of a debt vary with method, habitat and specialization, and the most data-intensive method found debts where cheaper ones did not. That is the instrument's inadequacy showing up as disagreement between readings.

## 5. The answer to "does the framework return a number?"

**No.** The framework returns the shape and the refuter, then stops at the limit of the available instruments. Tilman et al. 1994 gave a model in which extinctions occur *"generations after fragmentation"*; Halley et al. 2016 report timescales *"from a few years to thousands of years"* and power-law decay spread across timescales; Haddad et al. 2015 report function loss of 30% after one year and 80% after a decade in small isolated fragments. These are measurements under particular conditions, not a duration returned by the framework. Reporting any of them as *the* answer would be a name where a shape is owed.

The honest line is Fig 13 :134: **"Unreachable is a verdict here, not a silence"**, with the caveat from §6 below that this is a shape-not-a-name gap, not a proof of underivability in principle.

## 6. Correction to my own §3 (kept visible)

I first wrote the rule as "the framework returns a shape, not a name, so naming which species is key is forbidden". That overstates it. The figures README scopes the phrase to a **missing** thing: what a missing primitive would have to look like. Pollinator guilds, long-lived stages, dormant propagules and redundancy are all already available bindings, not new primitives. Naming one is a **binding from the ecology frame** onto an atom the framework already holds, which is provenance, not a forbidden invention and not an import that moves a wall (Fig 6 :21: *"MINT composes inside the closure and can never add an atom."*).

Two things remain wrong and are not retracted:

- Treating that binding as if the framework derived it. It did not; it is a recorded choice.
- Reading the source of a function reading off the projection (§4). That is the metamerism error, and the reason is the missing discriminator, not a ban on naming held atoms.

Both readings are kept so neither is quietly lost.
