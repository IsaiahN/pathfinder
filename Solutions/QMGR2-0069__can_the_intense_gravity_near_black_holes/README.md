## What this solution actually decides

The question is an effect question, not a theory question. In effect terms: GR is a frame that predicts observables for strong-field systems; instruments near black holes return observations; the residual is the gap between prediction and observation, measured per observable slot. The question asks whether that gap can register a departure, and whether any departure actually exists.

What survives the figure census is a **design claim**: yes, in principle, because the near-black-hole measurement is an anchor that does not update on GR's opinion and the residual is per slot; and an **honest stop**: whether a departure exists is unreached by the figures and is settled only by that ground. No detection so far is corroboration of GR under this reading, not proof of it.
