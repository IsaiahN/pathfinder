# Outreach draft: check the separator before you decide about the theory

**Use:** one-to-one, or as a cover letter attached to a submission through a public venue in `03_public_contact_points.csv`. **Not** for bulk send.

**Hard precondition:** do not send until the boundary term in `01_figure_grounded_audit.md` section 0 is written down in the recipient's own words and the seven refuters in section 4 are on the table. If the output cannot survive that, the two-stage offer collapses on contact.

---

**Subject:** One checkable separator about perceptual compression, before any theory

> Hi [name],
>
> I have one specific output I would like you to check against what you already know. I am not asking you to read the framework first, and I am not asking you to agree with it. I am asking for a failure if there is one. If the output does not survive, there is nothing else to look at.
>
> **The residual, in effect terms.** A perceptual system maps a signal to a coarser description. The same act is called efficient in some settings and systematically distorting in others. I will not use bits saved as the verdict. The figures say that compression achieved is *"frame-internal"* and that *"A frame cannot score itself with a quantity it also produces."* So I treat the ratio as a budget filter and look for a ground-paid witness instead.
>
> **The output (`specified`, not `grounded`).** Compression supports cognition when all four of these hold: (1) the residual stays indexed per object slot, not averaged into a global reconstruction error; (2) the round trip from the signal to the compressed description and back is measured, so the gap `R_T` is reported rather than assumed to be zero; (3) the compressed description passes the description-length bargain, meaning its cost plus what it leaves unexplained is less than the uncompressed residual, and fitting one occasion perfectly does not count; (4) the typed relations between features survive, or their loss is recorded as a known loss rather than silently treated as a representation. Compression produces systematic distortion when the description shrinks and one of those is lost without any signal that it was lost.
>
> One consequence is worth stating plainly: a compressed percept can be perfectly coherent from the inside and still have lost touch with the ground. A mirror cannot correct you. So the check has to come from a frame with separate contact, not from more readers of the same compressed record.
>
> **What I am not claiming:** that a particular coding scheme is the answer, that there is a universal ratio, that a fixed feature list is worth keeping in every task, or that this is settled. The framework returns a shape, not a name. Naming sparse coding, predictive coding or any other scheme is a binding from the neuroscience frame with provenance owed, not a derivation.
>
> **What would refute it, written before this message:**
> 1. A frame can settle whether its compression helps using only its own bits-saved score, with no ground reading.
> 2. A global pooled readout locates the failing slot as well as a per-slot readout after the same compression.
> 3. A lossy transform across the perceptual membrane is reversible at the slot, so the round-trip gap is zero.
> 4. Keeping the feature list but dropping the typed relations behaves identically to keeping both, on a task where the relation matters at the ground.
> 5. Repeated search inside the same compressed closure recovers the dropped atom and pays at the ground.
> 6. A channel with dropped transients and pooled readings still delivers a ground-paid verdict at the affected slot at the same rate as an intact channel.
> 7. Two frames drawing on the same compressed source count as independent witnesses.
>
> If any one holds, I withdraw the separator. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **What I would like from you, in this order:** (a) which of the four conditions you think is wrong or missing; (b) what you would count as a failure in your own preparation; (c) whether you know of an instrument that already returns something at the slot but fails to resolve it. Please send that before looking at the sources below. I want your verdict recorded before you hold any of the theory.
>
> **If it survives, and only then:** here are the sources. The figures are the authority, not my summary of them.
> - Figures and formula for direct download, branch `general-agent`: https://github.com/IsaiahN/tether/tree/general-agent/figures
> - The architecture article, with the 13 figures: https://medium.com/@IsaiahNwukor/arrival-of-the-fittest-the-tether-architecture-1de7edf641ec
> - Worked narrative and the six-term derivation: https://adventuresinml.substack.com/p/how-intelligence-actually-works
>
> **If you want to use the machinery:** the formula is in the figures link. Run it on a problem you know well and can check against a ground. Write down what would refute your result *before* you run it, and state the mode of what you get. A reported failure is more useful to me than a reported success.
>
> — [name]

## Why this version is ordered this way

| the move | figure-grounded reason |
|---|---|
| Residual and refuter first, theory second | Fig 10 :52 *"Bring a characterised residual, never the source."* The recipient checks the output without holding the framework interior. |
| Do not ask for agreement | Fig 2 :35 *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* Selecting for likely agreement manufactures the disqualifying correlation. |
| Seven pre-registered refuters | `THE_FORMULA.md` "Direction": commit the prediction before the run so the preference becomes refusable. A falsifier written before the run is a design instrument. |
| Mode on the claim | `THE_FORMULA.md`: *"Mode. general · specified · grounded. State which."* Nothing here is labelled accepted. |
| Ratio moved to the budget column | Fig 1 :25 and :27: compression achieved is frame-internal; Fig 9 :60: *"Use filters for the budget and witnesses for the verdict."* |
| No coding scheme named as the answer | Fig 9 :32 *"you get a kind of thing, never the answer itself"*; canonical usage: a shape, not a name. |
| Ask for the instrument, not the endorsement | Fig 6 :32 *"An instrument is not built from a description. It is improved from a worse instrument already returning something."* |
| Independent frame required | Fig 2 :31 *"Independence, between two frames, is how little they draw on the same evidence."* |
| Offer the formula as a method to reuse | Fig 4 :22 *"Only methods cross up. Only head starts come down."* Giving away a generator does not give away an answer. |
| No request for trust or prestige | *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* The ask gives the claim a budget to be tried; it does not ask anyone to endorse it. |
| Links last, opt-in only | Fig 10 :42 *"A verifier that can reconstruct the claim cannot verify it."* A reader who has absorbed the whole frame before judging has joined the frame being checked. |
