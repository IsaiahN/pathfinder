## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :132: *"what it returns is a shape rather than a name."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question, *"the residual is per slot and a channel fault is distinguishable from a model fault by a discriminator"* is a shape. *"The fault is the Cepheid crowding correction"* is a name.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- The essays' tacit-knowledge rule (as recorded in the exemplar, not re-opened here): when contact is not possible, the best you can send is a plain description of what you would expect to see, because anyone can check that against the world.
- *Library of Babel* on bundling: the final book may fail because *"your problem was a bundle or conflation of several problems masquerading as one?"* This is exactly the Hubble-tension question as posed. Fig 9 :54-56 gives the figure form of the same rule.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

For this question, naming a specific bad rung requires either a per-rung measurement that pays, or an import from an instrument frame with a provenance record. The figures alone cannot do it. Fig 13 :134: *"Unreachable is a verdict here, not a silence"*; Fig 13 :135: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

## 4. Why "we found no systematics" is the metamerism error in reverse

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and *"cannot comment on the source"*: one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

Applied here: a single H0 value is a projection. Many different combinations of zero-point error, crowding, dust, metallicity and model assumption can produce the same reading. A statement about the reading cannot name the source. What is owed is a source-discriminating instrument, not another fit. The same essay supplies the framework's own boundary: *"the truly testable output would need to be derived from the real architecture or working the formula yourself."*

## 5. The answer to "could it be calibration?"

**Yes as a shape, not as a name.** The figures license the following, and nothing stronger:

- A channel can decay while the ground does not (Fig 10 :24). So calibration error is a structurally live explanation for a persistent residual.
- A genuine anchor does not move when pushed (Fig 2 :29-30). So the ladder zero point is testable, and the test is checkable by an outside reader.
- A search that finds nothing is never a proof of absence (Fig 8 :39). So "no systematics found among the variants considered" does not close the calibration option.
- The question is a bundle and must be split (Fig 9 :4-5, :54-56).

They do **not** license: "the tension is caused by calibration," "the tension is caused by new physics," or "the culprit is rung X." Those are names, and no ground reading in this folder pays for them.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* The number of teams endorsing one explanation is a budget to try it, not a verdict.

**This folder is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` is a simulated derivation, checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle anything it reports on.
