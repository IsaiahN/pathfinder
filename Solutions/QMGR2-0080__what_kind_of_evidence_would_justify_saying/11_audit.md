## Independent domain census

I redid the census from the residual line alone, before relying on the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is: what would license attributing a reading to life. Arity three: reading, candidate sources, settling ground. Symmetry: broken, because a reading underdetermines a source while a source does not underdetermine the reading in the same way. Scale: instrument/object, interpretation, community verification. Arity and scale are enough to stop this being one question.
- **Domain 1, measurement.** Actors: instrument, sample, control, object slot. Currency: residual per slot and signal above the control. Anchor: the observation. Question type: partition across objects. Without a nameable object there is no slot and no residual.
- **Domain 2, interpretation.** Actors: biology hypothesis, abiotic mechanisms, contamination, environment. Currency: which hypothesis survives refusal. Anchor: the same observation. Question type: **union**, because two mechanisms can produce the same reading. This is the domain where a single lever fails.
- **Domain 3, verification.** Actors: other instruments, other teams, the community. Currency: agreement and residual. Anchor: the ground, never the agreement. Question type: triangulation, low overlap required. In this simulated run all three domains draw on one evidence pool, so the domain's independence is zero.

Order by dependency: controls and perception first, then a vocabulary of alternatives, then the last-resort objective, then the plan for disjoint lines, then context and lineage (Fig 3 :20). I reached this from Fig 3's dependency rule and Fig 9's leave/arrive sequence. The primary reached it from the same figures plus Fig 7 and the seat map. Different starting figures, same domain boundaries: weak agreement within one pool, not corroboration.
