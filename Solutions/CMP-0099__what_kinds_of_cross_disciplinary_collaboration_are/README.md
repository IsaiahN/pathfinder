## The residual, in effect terms

A model that holds only network topology (nodes, edges, degree, motifs, communities) cannot by itself predict an institutional rule change, a species loss cascade, or a behaviour cascade. A model that holds only the process cannot say how structure channels it. What is owed is the thing that crosses between the structural frame and each process frame, and a description of what makes that crossing count as a check rather than as agreement. Stated as an effect: the residual is the gap between a structural description and a process outcome that neither frame can close from inside its own closure. Fig 8 :19 puts the condition: "closures differ, so a surplus exists"; Fig 8 :21 adds "nothing was aimed; the union is mute".

## Verdict in one line

The undirected interdisciplinary mix is the wrong kind, Fig 8 :7 calls it "interdisciplinarity, no mint"; what is needed is residual-first, low-overlap triangulation with an imported atom, a shared unmoving ground, a maintained seat, and methods rather than recordings crossing between frames. Because the three process domains form a union compound, there is no single uniform kind of collaboration; each domain and each intersection keeps its own verdict.
