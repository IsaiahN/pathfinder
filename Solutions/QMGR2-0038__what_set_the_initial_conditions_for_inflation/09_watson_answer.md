## QUESTION

Option A: inflation is self-starting from generic data, so no external boundary condition is owed. The question is a union of at least three overlapping conditions, not one lever. The candidate imports are isomers over a shared atom set. The figures return the shape and refuse the name; Domain B has no settled anchor, so the slot stays open. This is a `general` structural result and a `specified` shape, ungrounded and candidate. What would close it is a source-discriminating observation, not more agreement.
