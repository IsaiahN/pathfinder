# WATSON answer: when does targeting a few influential nodes beat distributed intervention?

**Mode: `specified`, not `grounded`.** Figures are primary and decide. World sources are secondary, corroborate but never overrule, and a conflict returns the derivation to the domain census. This is a simulated derivation checked for internal consistency against the figures, not a ground reading.

## QUESTION

When does targeting a small number of influential nodes outperform broad, distributed intervention?

Restated as an effect: when is `R_T = |Γ(b,a_T) − o′|` smaller than `R_D = |Γ(b,a_D) − o′|`, measured per system and per node, never averaged? Option A says influence is intrinsic to a few nodes, so targeting always wins. Option B says influence is a role relative to a residual, so targeting wins only under stated conditions. What each leads to: A gives a universal rule that flips between tasks and spends the independence of the people checking it; B gives a conjunction of conditions, an instrument for each, and five refuters written in advance. Anchor: the measured post-intervention outcome, named in Fig 2 :29 as a measurement or counter, not a centrality score and not cost.

## DOMAIN CENSUS

Arity: a three-place relation among model Γ, action a and outcome o′, indexed by node slot and ordered by time, carrying an ordered bond (intervention then outcome) and a comparison bond for "outperform" (Fig 12 :87). Symmetry: not symmetric under swapping policies; "influential" is a threshold relative to a residual, not a carried property (Fig 11 :49). Scale: node, network topology and habitat, with a lossy membrane between them (Fig 4).

## VERDICT (from the figures)

**The figure-derived verdict:** targeted intervention outperforms distributed intervention when four conditions jointly hold and is lost when any one fails. C1: live residual mass is concentrated rather than diffuse, so there is a small set with support. C2: the influence map is a faithful bracket to the measured outcome, and the ground presses the cascade. C3: the habitat holds, including effects several steps out, so the identified influence persists. C4: the target is reachable from a closure that contains the needed structure. "Influential" flips with the goal. The two strategies are arrangements of one ingredient set and can be isomers. Cost is a budget filter, not a witness. The specific node set is a declared `gap`. The verdict is the union kept separate per domain, never averaged. Mode `specified`. The one world conflict (Albert versus Liu) was returned to the census and resolved as task-dependence; it did not flip the verdict.

- **cost if wrong:** misdirected intervention. A system failing C2 would get more centralities, or a system failing C3 would get more targeting, and a single lever would be applied to a union needing four instruments. In outreach terms, an expert's twenty minutes would be spent refuting a shape that was never the right shape. The cost is real but bounded and reversible because the falsifiers are written down.
- **undoable:** yes. Nothing is deleted if the claim fails; a refutation is added and the reach falls because *"something was added rather than because anything was deleted"* (Fig 6 :42). The shape and its eight falsifiers are in a provenance trail so a later reader can locate the error (Fig 10 :62).
- **reversed by:** a ground reading, not agreement. A source-discriminating instrument showing concentration or its absence per node would close C1; a prospective bracket test would close C2; a cascade-depth measurement would close C3; a phase measurement would close C4. Any of the eight pre-registered refuters would break the shape. A genuinely different evidence pool showing one target set optimal across attack, immunization and control with concentration held fixed would also reverse it. Until one fires, the verdict stands as `candidate`.
