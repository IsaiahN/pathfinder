- **Mathematics / dynamical systems.** Wikipedia contributors, *Attractor*, Wikipedia, 2026: "an attractor is a set of states toward which a system tends to evolve, for a wide variety of starting conditions of the system. System values that get close enough to the attractor values remain close even if slightly disturbed." Predicts that robustness is defined by convergence from many starting states, measured at the ground; corroborates the shape and the anchor rule. The same page notes that some points "may lie in a different basin of attraction and map asymptotically into a different attractor", which corroborates the union split.

Predicts that no general rule guaranteeing robust emergence is known; corroborates the shape-not-a-name limit. ## VERDICT (from the figures)

The shape survives; the demand for a list of rule types does not. Robustness is a property of rule and habitat together, so a rule-only answer hides the choice doing the work. The question is a union of order formation and initial-condition invariance and must be unbundled. The shape of an invariant rule is a closing feedback loop with a maintained regulator that damps its per-slot remainder, with amplification licensed only when the loop feeds on a ground-discriminated difference. Invariance is measured per slot and per starting state, never averaged. No rule type is named by the framework; negative feedback, majority rule and topological neighbourhood are bindings from CAS research onto the shape, licensed by a per-slot measurement or a provenanced import. The selector is the ground, not agreement among modellers. This is a `specified`, ungrounded result and remains `candidate`.

- **cost if wrong:** bounded and locatable. The packet states mode, four refuters and provenance before the conclusion, so an error is findable rather than invisible. The real cost is spending the independence of outside readers by sending a rule list instead of a generator, which Fig 2 :42 prices: "Buy independence in proportion to the cost of being wrong." That cost is avoidable by leading with the shape claim and its refuter.
- **undoable:** yes. The naming error is removed without touching the derivation; `07_the_tether_answer.md` and `08_expert_verification_packet.md` already remove it. A sent list can be superseded by the corrected packet, and no primitive has to be withdrawn.
- **reversed by:** a ground reading, not agreement. A per-slot invariance metric that licenses one rule class in a stated habitat; a demonstration that a closing-loop ruled system with an amplifying remainder still gives invariance; a rule robust in every habitat; a stable cross-residual list of robust rules; or a re-census that admits a figure-given name. Until one of these fires, the verdict stands as `candidate`.
