## 1. Independent domain census, written from the residual line alone

I redid the census before reading the primary's conclusions, using the WATSON order. The residual line given to me was: "Which types of local rules produce robust collective behavior across different initial conditions?" I converted it to effect terms first: a rule class maps, with a habitat and a family of starting states, to either one macro pattern or many; we want the property that makes the image invariant to the second factor.

- **R (arity / symmetry / scale).** Arity three or more: rule, habitat, initial condition. Symmetry: the macro outcome is interchangeable across starting states in the robust case, so those states are one report. Scale: step, cycle, level, and lineage if agents adapt. This is not a one-field or two-reader seam; it is a multi-factor map.
- **Domain 1, the rule.** Actors: agents, neighborhoods, the rule. Currency: per-slot residuals and state updates. Anchor: measured behavior under a run. This is a partition question about which compositions are legal across the two substrate kinds.
- **Domain 2, the macro pattern.** Actors: attractors, basins, order parameters. Currency: persistence. Anchor: the macro configuration actually returned. Selection, not negotiation.
- **Domain 3, the initial conditions and habitat.** Actors: starting configurations, coupling, perturbation. Currency: variation. Anchor: the invariant that survives. This overlaps Domain 2, so the pair is a union compound.
- **Domain 4, verification.** Actors: modellers, instruments, simulations. Currency: agreement and residual. Anchor: the ground, never agreement. In this simulated run its independence is zero.

Order by dependency: measure the pattern, get terms for what a rule affords, define the invariance objective, search rules, then carry verified classes. My starting figures were Fig 9 (union and describe-before-looking) and Fig 3 (dependency order), whereas the primary started from Fig 11 (habitat) and Fig 4 (scale invariance). Different starting figures, same domain boundaries: low overlap between routes, so the agreement is weak but not circular within the framework. It is still one evidence pool.

## 4. Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

2. **Abstraction (T_A):** the shorthand carried in `07` and `08`, namely "robustness is rule plus habitat; the shape is a closing loop with a maintained regulator and a damped per-slot remainder; no rule type is named".
3. **Concretisation (T_E):** the concrete question as a user would put it, "which types of local rules produce robust collective behavior across different initial conditions", and the tempting answer "negative feedback rules are robust".

**R_T is nonzero.** Four things the shorthand holds do not survive the trip back down:

- the **habitat dependence** (F1), which the concrete question silently drops by naming only the rule;
- the **union split** (F2), which the concrete question merges into one "robustness" property;
- the **shape-not-a-name limit** (F5), which the concrete answer breaches by naming negative feedback;
- the **per-slot measurement requirement** (F3 and F7), which a single robustness score would discard.

Conversely, one thing survives cleanly: a structure must close its loop and damp its per-slot remainder if its macro outcome is to be invariant. That is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a measured gap, which `09_watson_answer.md` now states.
