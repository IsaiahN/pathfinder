## Independent domain census

I redid the census from the residual line alone, before using the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the persistent per-society difference in outcome under an identical written design. Arity: four-place (design, slot, action, observation), and two societies reading one rule form a seam. Symmetry: the text is exchangeable between societies, the outcome is not, so the symmetry is broken by something outside the text. Scale: step, cycle, society, population, lineage. This is the isomer condition and a union of two conditions, not one hard question.
- **Domain 1, the written design.** Actors: rules, clauses, imported models. Currency: legality and description length. Anchor: the text, which is a declaration until installed so it can be violated. Question type: convention versus ground.
- **Domain 2, the receiving habitat.** Actors: officials, citizens, networks, informal norms, conditions. Currency: contact, valence, cascade. Anchor: the realized outcome. Question type: agent-and-habitat capability and actor valence relative to the residual.
- **Domain 3, inherited belief.** Actors: priors, private history, framing. Currency: the weighting w. Anchor: the outcome. Question type: divergence of identical architecture under different histories.
- **Domain 4, enforcement channel.** Actors: courts, inspectors, metrics. Currency: contact fidelity. Anchor: the ground, never agreement. Question type: channel decay versus an unmoving ground.
- **Domain 5, comparison frame.** Actors: researchers, rooms. Currency: agreement versus residual. Anchor: the ground. Question type: triangulation versus negotiation. In this simulated run all five domains draw on one evidence pool, so this domain's independence is zero.
- **Rejected:** design quality as a free-floating property (no nameable anchor), culture as a solo cause (absorbed), geography and disease as solo causes (absorbed into the first-order habitat enumeration).

Order by dependency: describe the residual before selecting a frame (Fig 9 :27-28), enumerate the habitat before importing (Fig 11 :43-44), refuse before mint (Formula step 2), settle before composing over a result (Formula step 5).
