## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134-135:

> **"Unreachable is a verdict here, not a silence"**
> **"It cannot say which primitive is missing, because naming it would mean already holding it."**

From *The Library of Babel* (carried mapping): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- "a system must have some bounded unit to which selection attaches" is a shape;
- "the first life had a lipid membrane" is a name;
- "a spendable directed difference must be in contact with the selected unit" is a shape;
- "the first life ran the reverse TCA cycle" is a name;
- "a carried term must make the next round cheaper" is a shape;
- "the first life had DNA genes" is a name.

The whole derivation stays on the left-hand column.

## 2. How a shape is obtained

- *Library of Babel* (carried mapping): use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge* (carried mapping): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- Fig 9 :27-28: *"describe it before you go looking, or any frame you pick will seem to fit."* In this question that is the exact failure the field makes when it picks RNA-first or metabolism-first before describing what any first life must do.

Here the residual was described in effect terms first: slot, spendable gradient, carried method. Only after that were the three programs mapped onto it, and they were mapped as isomers (see `06_isomers_and_order.md`), not as rival winners.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."* For this question, no experiment has observed the transition, so no first form is named.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. A world result such as metal-catalysed metabolic reactions can be imported as a *candidate binding* onto the gradient-shaped slot, with its provenance (Knowable Magazine, Callier 2025) recorded. It does not become "the first metabolism".

*They're Scanning Books* (carried mapping) sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

The six are a visible guess, not a discovery of nature's own list. Turning genes, metabolism and boundary into a new "minimum set for life" would hide the choice that made them candidates.

## 4. Why the order question is the specific forbidden error

*The Hard Problem is About Source* (opened 2026-11-23) gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*, one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. The reading does not determine the source. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

Apply to the origin question. Several programs (RNA-first, metabolism-first, membrane-first) all produce the same reading: "a system that evolves." The reading cannot comment on which source produced it. Naming one program as the actual order is the metamerism error, a source named from a reading. What is owed is a discriminator, not a preference.

The same essay states the stop: *"The answer is unreached until a better instrument exists."* That is the sentence that justifies the `gap` in `07_the_tether_answer.md` and `09_watson_answer.md`. A `gap` is a report of the instrument's limit, not an admission of defeat.

## 5. Q2 answered: what would license a particular first form?

Nothing in the framework. The framework returns a shape. A particular first form is licensed only by the ground settling a minted term, or by a provenanced import with a shadow test. Until one of those, the name is the searcher's own contribution and must be recorded as such.

**Does the derivation commit the error the README forbids?** No, provided the three shape-constraints stay constraints. It would commit the error if it asserted that the first life had DNA genes, a specific metabolic pathway or a lipid membrane. Those are names where the framework returns a shape, and they are names read off a projection (the modern cell) whose source at the origin is exactly what is unknown.

## 5b. Correction to my own §3 and §4

I initially wrote the "shape, not a name" rule as if it forbade naming any of the three candidates. That overstates it. The README's phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a missing primitive, one not held in Γ. Gradient and network are already among the six (Fig 13); a seam, a spendable difference and a carried term are bindings onto held atoms and onto the loop, not new primitives. What is forbidden is inventing a seventh member or claiming that such a binding moves the wall (Fig 6 :21, *"MINT composes inside the closure and can never add an atom"*).

My §4 metamerism point is **not** retracted. The order question still names a source from a reading where several sources give the same reading. The reason is the missing discriminator, not a ban on naming held atoms. Both claims are recorded so neither is quietly lost.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried mapping, corroborated by the architecture essay's own caveat): *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A campaign that gathers famous proponents of one program to agree with another is the named collapse, not corroboration. The legitimate ask is a budget to be tried, and a ground to settle it.

**My own audit is a simulation, not a ground reading.** The architecture essay (opened 2026-11-23) states: *"If you attach the formula along with the figures, and symbol reference in a prompt a Large Language Model, you get a plausible simulated output to an issue in any given domain that the LLM has knowledge of."* And: *"the outputs generated must be seen as simulacra."* So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the origin-of-life claim and must be labelled as such. It cannot settle anything it reports on.

## 7. What "shape" means here, in one sentence

A shape is the pre-naming constraint that any answer must satisfy, stated in effect terms (a slot, a spendable gradient in contact with an unmoved ground, a carried method, bonded in dependency order), with the modern forms and the historical source withheld until an instrument discriminates them.
