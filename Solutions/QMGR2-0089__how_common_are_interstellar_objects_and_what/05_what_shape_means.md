## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (**a shape, not a name**)."* Fig 9 :32: *"you get a kind of thing, never the answer itself"* Fig 13 :134: *"Unreachable is a verdict here, not a silence"*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name the specific instance. It constrains; it does not fill. For this question the shape is: a per-slot count residual with its uncertainty, a two-scale transform with a measured gap, and a class of parent systems with a discriminator. A single density value, or a named home star, is a name.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is *closest* to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause"*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: *"you will know that you are done because the finish line will also be the starting place"*, and the paradox that by then you have *"composed the answer through the process of locating it."*

Applying this: describe the residual in effect terms first (a survey predicts a count, the sky returns an observation; a reading predicts a parent property, many parents give the same reading). Only then look for the frame. If you open with a preferred ejection mechanism or a named home star, any object will seem to fit (Fig 9 :27-28).

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

*They're Scanning Books* sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

For this question, "common" is a name only when a threshold comparison is grounded by a characterized survey. A parent star is a name only when an instrument discriminates it from every alternative. Until then both remain shapes.

## 4. The source problem is the specific limit here

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*; the source could be one green light, yellow plus blue, RGB, CMYK, or *"a completely novel color scheme that humans have not yet discovered."* The reading does not determine the source. *"If several paths create the same behavior, then behavior is a projection with lossy information"* and *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

*How Intelligence Actually Works* names the horizon: *"A projection sinks below the union horizon when no observer, with any instrument any of them can build, can discriminate its origin."* Crucially: *"Being 'below the union horizon' is never a settled verdict, only a report that nobody has reached it yet."* And: *"indiscernibility is not identity"*, so *"the lineage has to be kept even when the copy is perfect."*

Applied here: 2I/Borisov's CO richness and 3I/ATLAS's isotope ratios are discriminators that move a case above the horizon, but they return a metallicity range and a formation zone, not a unique star. Fig 13 :121 (*"Different routes can arrive at the same substance"*) is the figure-level statement of the same limit. What is owed is a better discriminator, not a narrative.

## 5. Q2 - what licenses a particular parent-system claim?

**Nothing in the framework names a parent star.** The framework returns a shape. A class constraint is licensed only by the ground settling a measurement (ammonia production rate, isotope ratio, CO/N2 ratio) or by a provenanced import with a shadow test. Until one of those, the name is the searcher's own contribution and must be recorded as such.

**Does the record commit the error the README forbids?** It would if it named a unique home star from a composition reading. That is the metamerism error: a source named from a projection where several sources give the same projection. The correct form remains a class plus a discriminator. The narrower point is recorded honestly: naming a measured *property* of a parent (a metallicity range from a tracer) is not the same as naming a missing primitive, so it is not forbidden. See `01_figure_grounded_audit.md` section 6.

## 6. Why the union and the per-slot rule matter here

*How a Society of Agents Would Work* gives the aggregation rule in plain terms: *"Aggregating across slots is how a live signal disappears into an average"* and *"Use filters for the budget and witnesses for the verdict."* A survey tier or a detection count chooses what gets tried first; it never decides whether the shape is true.

*Library of Babel* adds the split instruction: if the final search fails, *"Perhaps your problem was a bundle or conflation of several problems masquerading as one?"* That is precisely the two-part question here. Count and reveal must be searched separately before their overlap is recomposed.

## 7. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* Gathering famous names to agree with a density estimate is the named collapse, not corroboration. The legitimate ask is a budget to be tried, with the ground deciding.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post"* but *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* The article's own caveat: outputs *"could never be verified if the solutions presented were not contrived to fit the formula."* So `01` is a simulated derivation, checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.

## 8. Correction to my own section 5

I first wrote that the shape-not-a-name rule forbids *any* parent-system claim. That overstates it. The README's phrase governs a **missing** primitive, one not held in Γ. A metallicity range is a measured property returned by a provenanced instrument, not an invented primitive. What remains forbidden is (a) naming a unique star from a projection, and (b) treating a class constraint as if it settled the source. Both claims are now recorded so neither is quietly lost. Triangulated (README + Fig 9 :32 + Fig 13 :121).
