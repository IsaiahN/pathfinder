## What an answer would look like (bound as an ordinary term)

An answer is not a name of one rock. It is a rule that admits a candidate medium if and only if: (1) the medium is in contact with the residual, (2) it has held a source-discriminating trace through the alteration cascade, and (3) an instrument already returning a reading can be sharpened to separate a prebiotic source from an abiotic source. This rule is bound before the run so it can accrue a residual and be refused like any other claim (`THE_FORMULA.md`, Direction; Fig 5 :62-63: *"a frame searching for an answer of a particular shape holds that shape as a PREFERENCE rather than as a term"*).

## Question as an effect

Which material candidates, if any, can carry a readable distinction between a prebiotic chemical pathway and abiotic chemistry across billions of years. Option A lists rocks by name and treats presence of a signature as evidence. Option B describes the shape an admissible record must have, keeps candidate media in separate slots, and reports `unreachable` where no instrument can discriminate. Option A risks naming a source from a reading; Option B yields a checkable shape with a pre-registered refuter and an honest stop.
