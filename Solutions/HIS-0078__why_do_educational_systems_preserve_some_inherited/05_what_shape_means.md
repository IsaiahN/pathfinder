## 1. A shape is a constraint, not a filler

The canonical usage rule states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134 to :135: *"It can say the answer is out of reach with the library as it stands... It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** here is the narrowed form of an answer that can be stated before the allocation is measured. For this question the shape is: two conditions with different currencies and anchors, a per-slot selector, and a refusal operation. It does not say which idea in which curriculum is preserved for which reason. That allocation needs a ground reading.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary closest to the thing, then recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 9 :30 to :31: *"your words are borrowed too, so describe the effect rather than the cause."* Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- The residual was described in effect terms in `01` section 0 before any frame was chosen, per Fig 9 :27 to :28.

## 3. What licenses a name

Only two things, both outside the shape:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50 to :52), with a source gate and a shadow test.

*They're Scanning Books When They Should Be Studying Nature*: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

A curriculum declares primitives. That declaration is a visible choice, not a discovery of nature's list. Naming one inherited idea as *the* correct one turns a visible choice into an invisible one. So the answer stays at the level of functions: head start, convention, refusal, independent ground.

## 4. Why outputs are not generators matters here

*How Intelligence Actually Works*: *"It can be inherited or taught, so the recipient need not pay the bill themselves, but something, somewhere, already paid it."* This is Fig 4 :24 in prose. The inherited idea is a head start because a bill was already paid against the ground.

*They're Scanning Books*: *"A written sentence is a lossy compression of the reasoning that produced it."* And *"the engine that improves human reasoning, discovery under real consequence, was never in the text."* A textbook is an output. If the system teaches only the output, it inherits the compression and not the generator. Fig 4 :25 to :26 names what follows: *"A recording carried upward looks like knowledge and is a description of one occasion. Replayed downward, it produces a system that repeats a past success and cannot produce a new one."*

*The Hard Problem is About Source* gives the discriminator: an instrument that reads green *"cannot comment on the source."* It was *"proven wrong not by argument, but by the arrival of a better instrument."* In education, a student's correct recitation cannot tell you whether the student has the method or the recording. That needs a different instrument, a novel problem the student has not seen. This is a `grounded` requirement, not a rhetorical one.

## 5. Why education needs both preservation and questioning

*How a Society of Agents Would Work* is the essay closest to this question. It states directly that a group *"shares methods, never recordings"*, that what comes down to a newcomer is *"a head start: candidates that make its search cheaper. It still has to test each one in its own world"*, that verdicts must come *"from outcomes, not popularity"*, that *"things fade, so they can be tried again"* while *"the record is never deleted"*, and that bad news *"travels in the same lane as good news."* It also warns that frames whose weighting drifts to the average lose the spread needed to adapt. All of it is tagged to figures 2, 4, 6, 7, 10, 11, and 12.

*The Recursive Self-Improvement Trap* gives the engineering version from the author's own system: *"The youth bonus. I built in a fitness bonus for young agents that learned quickly, and a decay on old knowledge so the system did not calcify around what worked in the past."* The same paragraph notes that failed patterns were *"marked for avoidance, with a decay so that innovation could still happen. If a group avoided an idea forever after one bad result, it would never learn that the idea was fine."* So refusal must be kept revisable, which matches Fig 6 :45: *"a refused term cannot cycle in and out, because the refusal never leaves the record: it becomes reachable again only if something new is minted."*

## 6. Prestige is not action, and this audit is a simulation

*The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* An inherited idea preserved because a famous source held it is the named collapse, not a reason.

The same essay: *"LLMs can quickly simulate an approximate answer/output"* and *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* LLM output is *"simulacra."* So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the claim and is labelled as such everywhere. It cannot settle anything it reports on.
