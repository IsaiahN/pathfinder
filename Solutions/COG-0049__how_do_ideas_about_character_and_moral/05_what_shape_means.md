## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32 *"you get a kind of thing, never the answer itself"*. Fig 13 :138-139 *"you get a kind of thing, never the answer itself, and narrowing gets you close while the ground decides."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

A **shape** is the narrowed form of an answer you can state before you can name the thing that fills it. It constrains; it does not fill. For this question:

- A shape: *the gap is per slot; the character ideas enter the prediction as a weighted mixture of history and prior; the vocabulary supplies bonds that make an act into a route; the worth metric can refuse an attribution.*
- A name: *moral identity is the mechanism, and it is the internalization subscale of the SMI-Q.*

The first is derivable from figures and refutable. The second is an import with provenance that has not been supplied here.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is *"closest to the words that you wish to describe and grasp the shape of"*, then look for recurring new terms that overlap or correlate. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- *They're Scanning Books*: *"The real import is not a new term in the existing space. It is a new dimension of the space."* Importing a dimension, not a synonym, is what extends perception.
- Fig 9 :30-31 *"your words are borrowed too, so describe the effect rather than the cause."* Fig 6 :30 *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is why `02_outreach_email.md` leads with expected observations and a refuter, not with theory.
- *Library of Babel* on stopping: *"you will know that you are done because the finish line will also be the starting place"*, and the paradox that by then you have *"composed the answer through the process of locating it."*

## 3. What licenses a name

Two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* For a question constitutively about people, Fig 2 :36-38 makes human judgment a legitimate anchor: *"An anchor is legitimate when the question is constitutively about it. Human judgment is the right anchor for is this a good answer for a person, because the question is about people."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and shadow test. Fig 8 :50-52: *"Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them."*

*They're Scanning Books* sharpens the second: *"Declaring the primitives does not make them neutral. It makes the choice visible, which is worth a great deal, because a visible choice can be revised and an emergent one cannot."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* The six-term substrate is a visible guess, not nature's own list. Naming a moral-psychology construct as one of its slots would turn a visible choice into an invisible one.

## 4. The source-discrimination error, applied here

*The Hard Problem is About Source*: an instrument reads green and *"cannot comment on the source"*; the same reading could come from several distinct sources. *"If several paths create the same behavior, then behavior is a projection with lossy information."* The color case was resolved *"not by argument, but by the arrival of a better instrument."*

Applied to this question: a person's observed self-report ("I see myself as honest") is a reading, not a source. It is compatible with an inherited character prior, a private behavioral history, a public-symbolization motive, a refusal of a specific attribution, and a cultural template, or any mixture. A scale cannot tell which source produced it. So the interpretation of one's own behavior is a metamerism problem: several internal sources give one outward reading. What is owed is an instrument that discriminates sources (a per-slot design plus a manipulation of the prior and the refusal vocabulary), not a larger correlation.

*The Recursive Self-Improvement Trap*: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* This derivation cannot validate its own shape.

## 5. The question answered: what shape does the framework return here?

**Nothing in the framework names the mechanism.** It returns four constraints and a gap:

1. The residual is per slot, so the interpretation is local, not a global worth score (Fig 1 :19, :22).
2. The belief is a mixture of private history and inherited prior under a learnable weighting (Symbols table, `b` and `w`).
3. The vocabulary supplies bonds, so an act becomes a route and can be refused as a self-attribution (Fig 12 :111-112; Fig 5 :53).
4. The valence of any character idea is relative to the current residual, so there is no standing list of good or bad ideas (Fig 11 :49-51).
5. The magnitude and the specific construct are a `gap`: no figure line governs them, and the world sources conflict in a way that is itself predicted by Fig 9's union rule.

The framework returns *a kind of thing* (a slot-indexed, prior-weighted, bond-routed, valence-relative interpreter), not the name of the psychological construct that fills it.

## 6. Correction to my own §3 (kept visible)

I first wrote that *"shape, not a name"* forbids naming any moral-psychology construct at all. That is too broad. The canonical README's phrase is *"what a **missing** thing would have to look like"*; the subject is a primitive not held in Γ. Character and worth concepts are not candidate primitives here at all. They are bindings imported from the psychology frame onto quantities the framework already has (`b`, `w`, bonds, `¬`, residual slots). Naming them is permitted **as a provenanced binding**, with a source gate and a shadow test (Fig 8 :50-52), and forbidden **as a derivation from the six-term set**. My §4 metamerism point is not retracted: the scale still reads a source off a projection. What is wrong was the blanket ban, not the instrument argument. Both readings are recorded so neither disappears.

## 7. Two consequences for outreach

**Prestige is not action.** *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* Gathering respected moral psychologists to agree with the shape is the named collapse, not corroboration. The legitimate ask is a budget to try the four-part output against a ground.

**This is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output"*, while *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01_figure_grounded_audit.md` and `09_watson_answer.md` are simulated derivations checked for internal consistency against the figures. They cannot settle the question they report on, and no part of them is `grounded`.
