## Round trip gap `R_T`

The Symbols table defines `R_T` as `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

1. **Sent up (x):** the four-domain census and the four-instrument shape: anchor reachable, ground settlement plus composability, measured round trip, provenance and closure, per-slot verdicts, refusal instead of deletion, `gap` on the cutoff.
2. **Abstraction (T_A):** "stability is a relation, not a flag; measure it per slot and keep the classes separate."
3. **Concretisation (T_E):** an actual memory system with slots, a ground channel, a promotion gate, provenance records and a refusal marker.

**`R_T` is nonzero.** Five things the shorthand holds do not survive the trip back down:

- **per-slot indexing** collapses to one global confidence score unless a slot axis is built explicitly;
- **the refusal marker** becomes deletion in most stores, which Fig 6 :46 forbids;
- **the round-trip measurement** becomes an assumed zero, which Fig 4 :30 names as dead reckoning;
- **the closure tag** becomes a universal flag, so a context-specific assumption looks like stable knowledge;
- **the `gap`** becomes a guessed numeric cutoff, which Fig 9 :32 forbids.

Conversely, one thing survives cleanly: settlement and composability are two conditions, and a recording is not a method. That is the residue worth sending. `R_T` was **not** measured numerically, because no system exists to measure it in; it is recorded qualitatively as the enumerated set of dropped constraints. Treating the formula as identical to the figure set would set `R_T` to zero and would be the dead-reckoning error Fig 4 :30 names.
