## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :134: "So the system can report that it lacks something rather than producing an answer anyway. Unreachable is a verdict here, not a silence,"

From *The Library of Babel* (carried quote): "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For CMP-0019 a **shape** is therefore the narrowed form of the answer that can be stated before an exponent is available. The shape has four parts, one per finding F1 to F4 in `01`:

1. the rule is scale-invariant, the cast is not;
2. size is bounded by the enumerated habitat and the closure, so within a closure the shape is growth then saturation;
3. persistence is channel and ground contact, with residual-relative valence;
4. size and persistence are two quantities in two currencies and cannot be averaged.

A statement such as `ell -> S` with a filled exponent is a **name** for the numerical slot. `ell -> S ???` is the shape. This is why the outreach material leaves the slot open.

## 2. How the shape is obtained

- *The Library of Babel* (carried quote): use the vocabulary already held that is *closest* to the thing, look for recurring new terms that overlap or correlate with it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge* (carried quote): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- The residual was described in effect terms before any field was chosen (`01`, section 0). This matters because "spatial complex systems" is a broad field; choosing it first and mapping figures onto it would be the apophenia Fig 9 :27-28 warns about: "describe it before you go looking, or any frame you pick will seem to fit."

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** THE_FORMULA step 5: "SETTLE the ground settles it. Verified only by what pays. A gate is not the ground." The canonical README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :50-52). This is the route by which a numeric exponent from percolation or reaction-diffusion theory could enter a *particular model*, but it would be a model-bound import, not a framework verdict, and it would be debited against independence.

*They're Scanning Books* (carried quote): "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Also: "Declaring the primitives does not make them neutral. It makes the choice visible."

For CMP-0019 this matters because "space" is one of the six terms (Fig 13 :9-10). The choice to describe interaction scale as a property of the space state is a visible choice, not nature's own list. Calling an exponent universal across all emergent structures would hide that choice.

## 4. The specific error this question invites

The question's grammar invites a source-naming error of the kind *The Hard Problem is About Source* describes. A reading of a structure's size "cannot comment on the source" (carried quote). Several different interaction mechanisms can produce the same observed size, so a size reading does not determine which contact produced it. The appropriate response is a better instrument that discriminates sources, not a name for the source.

Here the analogue is concrete: observing a pattern wavelength does not distinguish "range set it inside this closure" from "an atom was imported that expanded the closure". Both can produce a larger structure. Fig 8 :50-52: "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them, and the surplus lives only where the closures differ." The shape therefore demands provenance of the scale change, not just an observed size before and after.

*The Recursive Self-Improvement Trap* (carried quote): "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." This is why this audit is labelled a simulation and why a pre-registered refuter was written before the conclusion.

## 5. Q: does the framework name the structure or the exponent?

**No.** What licenses a particular numerical law is either the ground settling it for a declared model, or a provenanced import with a shadow test. Until one of those, the exponent is the searcher's own contribution and must be recorded as such. The framework returns four constraints (section 1 above) and an open slot.

**Does this folder commit the error the README forbids?** No, with one caveat that is kept visible. The folder does not name an exponent, and it does not name a single mechanism as the source of size or persistence. The caveat: F2 does say a wider habitat *allows* larger structures, and that is a directional claim. Its mode is `specified` and its refuter is written, so it is a candidate, not a verdict. The claim is about what composes inside a closure (Fig 6 :21), not about which primitive is missing, so the "shape, not a name" limit is not breached.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried quote): "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A campaign that gathers famous names to agree that range matters is the named collapse, not corroboration. The legitimate ask is to give the claim a budget to be tried and let an instrument settle it.

**This audit is a simulation, not a ground reading.** Same essay (carried quote): "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." LLM output is "simulacra." So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the question and must be labelled as such. It cannot settle anything it reports on.

## 7. Correction kept visible

An earlier draft of this file stated the "shape, not a name" rule as if it forbade *any* directional claim about scale. That was overstated. The canonical README's phrase governs "what a **missing** thing would have to look like". Interaction scale is not a missing primitive in the six-term set; it is a parameter of the held space and network atoms (Fig 13 :10, :24). Naming its role is a binding, not the invention of a seventh term. The correction is recorded here rather than silently applied, consistent with the rule that retractions stay visible. The stronger claim, that the framework returns an exponent, remains refused.
