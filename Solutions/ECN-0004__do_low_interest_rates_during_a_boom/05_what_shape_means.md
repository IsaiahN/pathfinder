## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :134: "Unreachable is a verdict here, not a silence".

From *The Library of Babel*, opened this session: "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

A **shape** is therefore the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- **Shape:** "per-slot residual, non-updating comparator, channel distinct from ground, verdicts kept separate, gap where the instrument is missing."
- **Name (not supplied by the framework):** "the natural rate was 1.2 percent in 2004, therefore these specific projects were malinvestments."

The first is what this solution returns. The second requires a measurement nobody in this run took.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause".
- *Decoding Tacit Knowledge*, opened this session: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." Applied here: instead of sending "malinvestment", send "projects that clear the actual rate but would not clear a rate fixed independently of the policy decision". Anyone can check that against a dataset.
- *Library of Babel* on malformed questions: "Perhaps your problem was a bundle or conflation of several problems masquerading as one?" This is the precise diagnosis of the either/or in ECN-0004.
- *Library of Babel* on stopping: "the finish line will also be the starting place", and by then "you have composed the answer through the process of locating it". Here the finish line is the separation, which is also the starting description of the residual.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The canonical README says the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

*They're Scanning Books*, opened this session, sharpens the second: "The real import is not a new term in the existing space. It is a new dimension of the space." A natural-rate estimate is not an import of a new term into macroeconomics; it is an attempt to extend what the frame can perceive, so it must carry provenance and a shadow test. The shadow test here is: does the estimate explain a gap that was previously unstatable? It does. The source gate is: which model, which data vintage, which revision history? Without those, the estimate is a name presented as a fact.

The same essay adds: "Declaring the primitives does not make them neutral. It makes the choice visible." The chosen comparator is a visible choice, not nature's own list.

## 4. The comparator is a source-discrimination problem

*The Hard Problem is About Source*, opened this session, gives the governing mechanism. Metamerism: an instrument reads green and "cannot comment on the source". One green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered can produce the same reading. "If several paths create the same behavior, then behavior is a projection with lossy information." It was the spectrometer, not an argument, that resolved the case: "The answer is unreached until a better instrument exists."

The same structure appears here. A policy rate near a model's estimate of the natural rate is a "green" reading. It is compatible with at least three sources: saving and investment genuinely in balance; a distorted signal with real overinvestment; a demand shortfall being offset by policy. The reading does not determine the source. What is owed is a discriminator that separates these, not another argument about which school owns the reading. The essay's warning applies: "An instrument that can't distinguish these cases demonstrates its own inadequacy."

This is why the verdict in `01` is a gap rather than a choice between schools. It is also why the gap is `unreachable at this budget` rather than `underivable in principle`: the neutral-rate page records estimates that already return something, so there is an edge to extend from (Fig 6 :34-35).

## 5. Why this run cannot settle the question it reports on

*The Recursive Self-Improvement Trap*, opened this session: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." And explicitly: "LLMs can quickly simulate an approximate answer/output with the formula" but "the truly testable output would need to be derived from the real architecture or working the formula yourself." The essay's term for the simulated product is "simulacra".

So `01`, `06` and `09` are simulations checked for internal consistency against the figures. They are not a test of the economic claim. The same essay supplies the outreach discipline: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

## 6. Correction to my own section 3 (kept visible)

I initially read "shape, not a name" as forbidding the use of any named comparator. That overstates it. The canonical README's phrase governs "a **missing** thing", a primitive not held in the frame. A saving-determined rate, a hurdle rate and a natural-rate estimate are already available terms in the economic frame, so selecting one is a **binding with provenance**, not the invention of a new primitive. What remains wrong is presenting that binding as if the framework derived it, or as if it moved the wall. Fig 6 :22: "IMPORT adds an atom, and the added atom is what expands the closure." A binding onto a held term adds none.

Both readings are recorded so the correction is visible: the shape limit rules out inventing a comparator to order the case; it does not rule out declaring which comparator is being used and recording where it came from.

## 7. Consequences for ECN-0004

1. The framework returns the shape of an adequate answer, not the answer. The shape is: separate conditions, per-slot indexing, a non-updating comparator, a channel distinct from the ground, and a declared gap.
2. Naming a comparator requires provenance (model, vintage, revision history) and a shadow test. Neither is supplied here.
3. A verdict that one school wins would be a name where the framework returns a shape, and would spend the independence of the people checking it.
4. The whole folder is a simulated derivation, checked for internal consistency against the figures. It cannot settle whether low rates during a boom create harmful malinvestment, and it does not claim to.
