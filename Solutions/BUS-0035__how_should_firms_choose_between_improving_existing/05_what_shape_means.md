## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence,"*

From *The Library of Babel*: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For BUS-0035 a **shape** is the form a decision procedure must have before we can name a winning technology or a universal budget split. The shape is: two loops with separate grounds, run as two tracks, never averaged, with a per-slot live signal and a convention-authoring allocator. A specific split such as 70/20/10 is a name, not a shape. A named winning technology is a name, not a shape.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary you already have that is *closest* to the thing, then look for recurring new terms that overlap or correlate with it, and recurse. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: *"the finish line will also be the starting place"*, that is, the shape is recognised when there is nothing left to search that would describe the answer better.
- *Library of Babel* on bundling, directly relevant here: *"Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually to find their answers and then combine them in a satisfactory way."* This is the essay-level source for the union reading in F2 and Fig 9 :54-57.

## 3. What licenses a name

Two things only, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* For firms, the ground is a paying market, a real experiment, a customer outcome. A board that pays or does not.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. The firm must be able to say where the atom came from and which gap it explains.

*They're Scanning Books* sharpens the second: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."* A firm's chosen technology frame is a visible choice, not nature's list, so naming it as *the* answer turns a visible choice into an invisible one.

## 4. Why the two-currency claim survives the essays

*The Hard Problem is About Source* gives the instrument argument. An instrument reads green and *"cannot comment on the source"*; a reading does not determine which mixture produced it. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"The answer is unreached until a better instrument exists."* It was the spectrometer, not an argument, that resolved it.

Applied here: an ROI number reads one projection of a bet and cannot comment on its source. Several different frames can produce the same forecast. Naming the winning frame from the ROI reading is the metamerism error. What is owed is a source-discriminating instrument (a paying experiment, a lead-user test, a foothold market), not a better ratio.

*How Intelligence Actually Works* adds: *"indiscernibility is not identity."* A projection that no current instrument distinguishes from the thing is still a projection, which is why the lineage must be recorded. For a firm, a radical bet that looks exactly like a good incremental bet on the current dashboard is still a different object.

## 5. Two consequences for the allocation question

**Prestige is not action.** *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* The same essay names the firm-scale failure directly: *"If prestige could buy actions, the system would collapse into a monoculture. The highest-prestige agent would monopolize compute and repeat its past success, and the system would stop exploring."* A senior sponsor's reputation can give a radical bet a budget, but it cannot make the bet right. This is a strong corroboration of Fig 10 :47 (a convention that decides an outcome has stopped being one).

**The group is a magnifier only while frames differ.** *How a Society of Agents Would Work*: *"capability is a property of agent-and-habitat, never of the agent alone"* and *"Ten copies watching the same thing are one opinion said ten times."* A committee of executives who all read the same market report is one frame wearing many names (Fig 8 :48-49). Independence must be bought in proportion to the cost of being wrong (Fig 2 :42).

## 5b. Correction to my own §3 and §4

I initially read the canonical limit as banning the allocation question entirely. That was too strong. The README's phrase governs *"what a **missing** thing would have to look like"*, that is, a primitive not held in Γ. In BUS-0035 both operators (mint and import) are already in the framework. What is forbidden is inventing a third operator or naming a universal ratio, not stating the shape of the two we hold. So:

- **Retained:** the source-discriminating point in §4. Naming a winning frame from a single ROI reading is the metamerism error, because several sources can give the same reading.
- **Corrected:** the claim that the framework cannot say anything about allocation. It can say the shape (two tracks, separate grounds, no single currency, per-slot signal, convention-authoring allocator) and it refuses the name (which technology, which ratio). Both claims are now recorded so neither is quietly lost.

Triangulated (README + Fig 9 :32 + Fig 13 :134).

## 6. Standing of this document

*The Recursive Self-Improvement Trap*: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* And: *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* Output is *"simulacra."*

So `01_figure_grounded_audit.md` is a **simulated derivation**, checked for internal consistency against the figures. It is not a test of any firm and cannot settle anything it reports on. The same essay: *"Because it is a metatheory, it cannot be validated, nor can it validate itself."* This is why the verdict in `09_watson_answer.md` carries mode `specified` and an explicit cost, undoability and reversal condition.
