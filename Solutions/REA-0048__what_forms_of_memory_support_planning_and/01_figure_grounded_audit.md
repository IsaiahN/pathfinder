## 0. The residual, stated in effect terms

The question asks which *forms of memory* support two capacities (*planning*, *learning*) over a long temporal horizon. Stated as a decision:

> **Option A:** There is one memory faculty, and what supports planning and learning is simply more of it (a bigger or longer store).
> **Option B:** There are non-interchangeable memory forms with distinct roles, and which forms are required is decidable from what each must do in the loop.

What each leads to. A collapses the record into the reach and the method into the recording, and cannot explain why a stored episode does not by itself yield a novel plan. B gives a shape with separate roles, separate refuters, and an answer to the temporal qualifier ("across long periods") that does not require inventing a seventh memory kind.

**R by arity, symmetry, scale** (Fig 9 :21-22: *"R, described / arity · symmetry · scale"*):

- **Arity:** a mapping from memory form to two capacities over a time axis. Two capacities are named, so this is at least a **union compound**, not one question. Fig 9 :57: *"a case in two conditions is not a harder case of either"*. It must be unbundled before search (Fig 9 :54: *"when the split lands on a union rather than a partition, unbundle before you search again"*).
- **Symmetry:** the forms are **not interchangeable**. A recording cannot substitute for a method (Fig 4 :25-26). A state cannot substitute for a structure (Fig 13 :29-30). So the answer is an ordered set of roles, not a symmetric bag of ingredients.
- **Scale:** within one run versus across scales and agents (Fig 4 membrane), and across many loop cycles (the "long periods" qualifier). Time is already a state in the substrate (Fig 13 :11-12: *"time / the ordered succession of differences"*), so duration is a scale on an axis already held, not a new kind.

## 3. Findings F1 to F8

### F1 — The record and the reach are two different memory quantities (decisive against Option A)

Fig 6 :42-43:

> **"What is recorded only grows. What is reachable is derived, and it can fall."**
> **"So the closure and the reach are two quantities: one monotone, one not."**

THE_FORMULA, "The record and the reach":

> **"What is recorded only grows; what is reachable is derived and can fall."**

And step 5: *"a library that grows is not a reach that grows."*

So a memory answer that treats storage and availability as one faculty is answered by the framework's own accounting: the store is monotone, the usable set is not. Any account of "across long periods" must say which of the two it is describing. **Mode: `general` (structural).** **Triangulated:** Fig 6 and THE_FORMULA state the same distinction in different words and different contexts.

**Refuter:** exhibit a functioning system in which the store and the currently usable set are the same monotone quantity, so that nothing ever becomes unavailable without being deleted. If such a system plans and learns, F1 fails.

**World corroboration (secondary, not a witness):** Working memory is *"a cognitive system with a limited capacity that can hold information temporarily"* (Working memory, Wikipedia, 2026), and Cowan's version holds that *"Representations in working memory are a subset of representations in long-term memory"* (same source). Semantic memory is *"general world knowledge that humans have accumulated throughout their lives"* (Semantic memory, Wikipedia, 2026). The reach/record split is visible in the literature, but the literature shares no ground with the figures on this point, so it is corroboration only.

### F2 — What persists usefully across long periods is a method or head start, not a recording

Fig 4 :22-26:

> **"Only methods cross up. Only head starts come down."**
> **"upward: a method that can be reapplied. Never the recording of a particular success."**
> **"A recording carried upward looks like knowledge and is a description of one occasion. Replayed downward, it produces a system that repeats a past success and cannot produce a new one."**

The long-period qualifier is answered by this membrane rule, not by a new memory kind. A form that stores only occasion-specific traces, and whose only mode of reuse is replay, supports repetition. A form that has been compressed into a reapplicable method, or that arrives as a head start making the next search cheaper, supports new planning. Note the asymmetry: *"The membrane is the boundary between the sizes, and the rule about what may cross it. Not a wall: a filter with a direction"* (Fig 4 :21).

**Mode: `specified` (falsifiable about what a memory form must do).** **Single-source** for the figure rule (Fig 4), with independent world corroboration from two fields: procedural skill acquisition, where *"with practice, procedural knowledge develops, which operates largely outside of working memory, and thus allows for skills to be executed more automatically"* (Procedural memory, Wikipedia, 2026); and the generative-agents architecture, which *"store[s] a complete record of the agent's experiences using natural language, synthesize[s] those memories over time into higher-level reflections, and retrieve[s] them dynamically to plan behavior"* (Park et al., 2023, arXiv:2304.03442). The two world fields do not draw on the figures, so they are low-overlap corroboration.

**Refuter:** show a system that reliably produces a *novel* successful plan from occasion-specific recordings replayed verbatim, with no compression into a reapplicable method and no head start reducing the next search. By Fig 4 :25-26 that should be impossible; a single demonstrated case would break the claim.

### F3 — Planning requires memory that carries bonds, not just atoms

Fig 12 :111-113:

> **"A vocabulary without bonds can name a state and cannot name a route to one."**
> **"A plan is a sequence. A goal is a comparison. Progress is a subtraction. A refutation is a negation, and that one is not a bond."**

Fig 3 :13: *"a route to that objective, chosen under incomplete information"* (link 4, planning).

So the form of memory that supports planning is not the form that holds the most items. It is the form that retains the typed relations between items: sequence for the plan, comparison for the goal, subtraction for progress. Fig 12 :94: *"The arrangement is the substance."* An ingredient list is not a route. THE_FORMULA, Composition: *"a vocabulary with only ingredients can name a state and not a route to one: a plan is a sequence, a goal is a comparison, progress is a subtraction."*

**Mode: `general` (structural for the bond claim), `specified` for its application to planning.** **Single-source** in the figures (Fig 12) but the claim is corroborated at low overlap by the prospective-memory literature: *"Prospective memory is a form of memory that involves remembering to perform a planned action or recall a planned intention at some future point in time"*, and *"prospective memory focuses on when to act, rather than focusing on informational content"* (Prospective memory, Wikipedia, 2026). That is a bond (a trigger relation carrying a route), not an ingredient.

**Refuter:** demonstrate genuine planning in a system whose memory holds only unconnected atoms with no sequence, comparison or subtraction structure, and whose plan is not supplied from outside. If that works, Fig 12 does not govern planning here and F3 falls.

### F4 — Long periods make channel maintenance the binding constraint

Fig 10 :24-28:

> **"the ground does not decay, the channel does"**
> **"stale percepts, dropped transients, saturated metrics, pooled readings"**
> **"the output is not a verdict, it is you have lost touch"**

Fig 11 :40: *"An improvement that does not change contact changes nothing, however much it improves."*

So "across long periods" is not just a storage-duration question. It is a maintenance question: the channel between the frame and the ground decays, and the failure looks exactly like a working system until contact is lost. A memory form that is never re-checked against the ground will drift even if its record grows. Fig 2 :33-34: *"everything drifts together, and the drift is coherent, which is why nobody notices."*

**Mode: `specified` (predicts where long-horizon failure occurs).** **Triangulated** across Fig 10 (channel), Fig 2 (coherent drift) and Fig 11 (contact), three figures with different quantities.

**Refuter:** exhibit a memory system operating over a long horizon whose ground channel does not degrade without active maintenance, or where growth of the store guarantees continued contact. Either would falsify the maintenance requirement.

**World corroboration (secondary):** consolidation is *"a process in the brain that stabilizes newly learned information, allowing the memory to be stored long-term"*, and systems consolidation involves *"gradual reorganization and reduced reliance on the hippocampus and increased involvement of cortical networks over a period of weeks to years"* (Memory consolidation, Wikipedia, 2026). Reconsolidation means recalled memories *"can become unstable again after retrieval and may need to be updated before being re-stabilized"* (same source). These are maintenance operations at long timescales, arrived at independently of the figures.

### F5 — Learning and carrying is the last link of a dependency chain

Fig 3 :15: *"name what worked, verify it, and carry it to the next problem"*. Fig 3 :20-21:

> **"The chain is ordered by dependency, not by importance. Each link consumes what the one above produces, so effort spent above the break arrives at a step that cannot use it."**

So a memory form that supports "learn and carry" presupposes vocabulary (link 2), an objective (link 3) and planning (link 4). Optimising the store cannot rescue a broken objective. Fig 3 :26: *"having terms for what a situation offers and being able to say what would count as progress, has neither, so it attracts the least attention and the fewest instruments"* (middle links).

**Mode: `general` (ordering), `specified` for the prediction that store-size interventions fail below a broken link.** **Single-source** (Fig 3), corroborated at low overlap by the generative-agents ablation result that *"the components of our agent architecture -- observation, planning, and reflection -- each contribute critically to the believability of agent behavior"* (Park et al., 2023).

**Refuter:** show learning-and-carry succeeding while the objective and planning links are demonstrably absent, so that the chain is not ordered by dependency in this case.

### F6 — The figures return a shape, not a name

Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 9 :27-28: *"describe it before you go looking, or any frame you pick will seem to fit"*. Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause"*.

The canonical figures README states the limit as *"what a missing thing would have to look like (a shape, not a name)"*. So the figures can license the four role constraints F1 to F4, but they cannot license the sentence "episodic memory is the method form". That is a binding from the cognitive-science frame, and by Fig 8 :50-52 *"Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them."* The binding is recorded as a world import with a source gate, not promoted to a figure line.

The Library of Babel essay (read 2026-11-23) gives the positive account of a shape: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."* A shape *"narrows; it does not fill"*.

**Mode: `general` (limit).** **Triangulated** across Fig 9 and the canonical figures README.

**Refuter:** derive the name of a specific cognitive-science memory form from the figures alone, without importing from a world frame. If that succeeds, F6 is false.

### F7 — Agreement among memory researchers is not the ground

Fig 2 :35: *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* Fig 2 :40: *"agreement about the world is worthless when the agreeing frames share an evidence pool"*. Fig 2 :42: *"Buy independence in proportion to the cost of being wrong."*

So a consensus taxonomy of memory forms is a convention, not corroboration (Fig 2 :41: *"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"*). The WATSON WORLD section records overlap for every source rather than counting heads. This package's simulated second seat shares the primary's pool, so by Fig 2 :40 its agreement is one pool talking (declared in `11_audit.md`).

**Mode: `general` (verification rule).** **Triangulated** across Fig 2, Fig 7 :13 (*"same closure, handed along; agreement compounds, evidence does not"*) and Fig 10 :42.

**Refuter:** produce a case where a consensus list of memory forms was settled by a ground that each researcher checked separately, with no shared evidence pool, and show that this is what the verdict rested on. Consensus alone does not do it.

### F8 — "Long periods" is not a seventh memory kind (strain test and re-census)

Fig 13 :43-44: *"A continuum was the seventh and was removed for failing exactly this: it is a spectrum without gaps, or smoothness over space and time. A generating set must not contain what its own members produce."* And :11-12: *"time / the ordered succession of differences"*.

A first reading strains Fig 13 by treating "long-term memory" as a new primitive to add beside the others. Re-census: time is already a state in the substrate, and duration is a scale on that axis. Cognitive-science "long-term memory" is a timescale label for a store, not a claim about a new irreducible kind. Different objects, so there is no strain after re-census, matching the canonical rule that a reading which makes figures contradict one another has misidentified its domain.

**Mode: `specified` (anti-new-kind prediction).** **Triangulated** across Fig 13 and Fig 3 (the chain already contains "learn and carry" without a new link).

**Refuter:** exhibit a memory form that is indivisible (not derivable from the held terms and bonds) and that is distinguished solely by duration rather than by role or structure. That would be a genuine seventh and would break the re-census.

## 4. Pre-registered refuter (written before the conclusion)

Required before any outreach: *"a falsifier written before the run is a design instrument, not only an honesty device"* (Seat Map, amended guide). The shape claim is refuted if any of the following holds:

1. A functioning system has a single monotone memory quantity with no separate fallible reach (breaks F1).
2. A system reliably produces a novel successful plan from verbatim replayed occasion-specific recordings, with no method compression and no head start (breaks F2).
3. Genuine planning is demonstrated from unconnected atoms with no sequence, comparison or subtraction structure (breaks F3).
4. A long-horizon system's ground channel does not require maintenance, or store growth guarantees continued contact (breaks F4).
5. A cognitive-science memory form is derived from the figures alone, with no world import (breaks F6).
6. A duration-only, indivisible memory form is exhibited that is not derivable from held terms and bonds (breaks F8).

If any fires, the relevant role is withdrawn. Until one is run, nothing here is `grounded`.
