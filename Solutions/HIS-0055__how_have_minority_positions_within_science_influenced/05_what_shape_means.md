## 2. A shape is a constraint, not a filler

The canonical figures README gives the limit: the framework reports "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence," and :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel* (opened this session): "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question." And: "With each new term gained, you narrow the space and deepen your vocabulary."

For this question, a **shape** is the form of the mechanism you can state before you can name which case instantiates it. The shape is: *rejection is an agreement effect or a reachability failure; uptake is an import or a refusal from a differing closure; influence is a ground-settled surplus that later research composes over.* Naming Wegener, Semmelweis, Mendel or McClintock is a provenanced binding onto that shape, not the shape itself.

## 3. How the shape is obtained

- *Library of Babel*: use the vocabulary already held that is closest to the thing, look for recurring terms that overlap with it, and recurse (opened this session).
- Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." - *Decoding Tacit Knowledge* (opened this session): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." This is why the outreach email in `02` leads with a checkable description, not a reading list.
- *Library of Babel* on stopping: the answer is reached when the search space is small and descriptive enough. Here that point arrives at the four-part mechanism in `01` section 0, not at a named hero.

## 4. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: the ground settles a term; verified only by what pays. The README says the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :12-13, Fig 8 :51). Fig 8 :50: "Two frames can hold the same atom by convergence, reaching it separately, which is corroboration at maximum independence." Convergence and import look the same in the contents; only the record separates them.

*The Hard Problem is About Source* (opened this session) gives the discriminator: "If several paths create the same behavior, then behavior is a projection with lossy information," and the instrument "cannot comment on the source." Reading a later consensus and inferring *why* the claim was accepted is the metamerism error. The histories in `04` show that the settlement came from instruments (palaeomagnetism, germ theory), not from a vote.

*They're Scanning Books When They Should* (opened this session) sharpens this: "It is a built discoverer, and a way to import not new terms but new axes." A minority frame matters when it changes the representational axes of the receiving field, not merely when it adds one more fact inside the existing axes.

## 5. Q: Does "shape, not a name" forbid naming a historical case?

**No.** This is a correction to my own first reading, kept visible.

The README's phrase is about "a **missing** thing." Fig 13 :135 makes the subject explicit: "It cannot say which primitive is missing, because naming it would mean already holding it." A documented historical frame, atom, or instrument is already held in the record. Naming it is a binding with provenance, recorded in `10_source_ledger.csv`, not the invention of a new primitive and not a wall-moving import (Fig 6 :25: "An import adds no atom to the world").

What is still forbidden is treating the named case as the answer rather than as an instance of the shape, and using the authority of the case to settle the framework question. The framework returns the mechanism, not the identity of the vindicated dissenter.

## 6. Two consequences for this question

**Prestige is not action.** *The Recursive Self-Improvement Trap* (opened this session): "If prestige could buy actions, the system would collapse into a monoculture." And: "The highest-prestige agent would monopolize compute and repeat its past success, and the system would stop exploring." A narrative in which the famous dissenter eventually wins is a story about prestige and monoculture, not a verdict about how influence works. Prestige can give a claim a hearing; it cannot settle it. Fig 10 :61: "And standing is a stake that survives the outcome it was earned on."

**My derivation is a simulation.** Same essay: LLM output can "simulate an approximate answer/output," while the testable version must be derived from the working mechanism. So `01`, `06`, `07` and this file are simulated derivations checked for internal consistency against the figures. They are **not** a test of the historical claim and must be labelled as such. They cannot settle anything they report on.

## 7. The shape in one sentence

For this question, "shape" means the four-part constraint (differing closure, reception without anchor, import or refusal, ground settlement) that any account of minority influence must have, stated before a single historical case is named and left open at the point where an instrument, not an argument, is required.
