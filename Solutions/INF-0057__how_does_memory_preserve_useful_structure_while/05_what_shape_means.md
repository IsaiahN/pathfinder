## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name the mechanism. It constrains; it does not fill. For this question the shape is the set of properties any adequate memory cut must have: lossy and non-invertible, per slot, bond-preserving rather than item-preserving, ground-anchored, and measured by a round-trip gap. That is a shape. "The hippocampus does it" is a name.

## 2. How the shape is obtained here

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse: *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* So the residual was described as an effect (a lossy, selective, ground-anchored cut) before any field was chosen.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* A shape is exactly that kind of description.
- *Library of Babel* on stopping: *"you will know that you are done because the finish line will also be the starting place."* The paradox: *"By the time you learn the EXACT search terms to find the CORRECT book, you won't need to read it anymore, because you have already composed the answer through the process of locating it."*

It is not the answer the framework produced, and it must be recorded as an import, not a derivation. The framework returns the shape of the cut; which brain structure implements it is a world question with a world ground.

## 4. Why the trace cannot recover its own source

This is the deepest essay-level point for this question, and it explains why "discarding detail" is not recoverable by inspection.

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*; one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered can all give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* What resolved the case was *"not by argument, but by the arrival of a better instrument."*

*How Intelligence Actually Works* gives the memory-specific version: a frame extracted from video and a photograph taken at the same moment are *"indistinguishable as artifacts, and they carry different warrants. One was taken; one was extracted. And nothing in the image records which."* This is provenance loss. And: *"The recursion converges toward indiscernibility, and indiscernibility is not identity."*

*They're Scanning Books* gives the general law: *"A written sentence is a lossy compression of the reasoning that produced it"* and *"outputs do not contain their generator."*

So a stored trace is an output. Looking at it cannot tell you which details were discarded or how, because many cuts produce the same trace. The lineage has to be kept. That is a second reason, besides Fig 4's round trip, to report `R_T` rather than only the recalled content.

## 5. The compressed trace needs the receiving history

This is a world-level insight from *Decoding Tacit Knowledge* and it bears directly on "useful structure." A compressed message unpacks only for a listener with the right pretext: *"Without the right one, a compressed message can't be unpacked, however clearly it was said."* And: *"When knowledge gets packed into a few words, the work that built it stays behind"*, since *"Settling compresses the description and not what it cost to establish"* (Fig 12 :107).

For memory this means the useful structure is not only the bond inside the trace. It also includes the conditions that let the trace be unpacked later. A trace that is perfectly compact but whose unpacking history is gone is a video frame with the video deleted. This does not change the figure verdict; it sharpens F2 by adding that the kept structure is relational between trace and receiver. It is a `specified` reading, sourced from an essay, not a figure line.

## 8. One-paragraph version of the shape

> Any memory that crosses scales must lose information, because loss is what makes a trace reusable. What is worth keeping is not the list of things present but the typed relations among them, and a detail is retained only when stating it plus what remains unexplained costs less than what was unexplained before. "Useful" cannot be decided by the memory's own bookkeeping; it is settled by a relevance variable external to the frame, a later retrieval, inference, action or outcome. The cut must be described per slot, not as an average, and the discarded detail returns as noise above the crossing, so the round-trip gap is the honest report of what was given up. That is the shape. The framework does not name a brain region or a synapse, and a stored trace cannot recover its own source by inspection, so the lineage must be recorded rather than reconstructed.
