# The Tether's answer: uncertainty that stays calibrated across unfamiliar tasks

**Mode: `specified` — not `grounded`.** This is a shape and a route, not a result. Simulated derivation checked against the figures (`05_what_shape_means.md` section 7), not a ground reading.

## 1. The residual it answers

The system predicts Γ(b,a) from belief b (private history mixed with inherited prior by w), observes o′, and forms R = |Γ(b,a) − o′| per slot s (Symbols table :36-43; THE_FORMULA step 1). A confidence is a second-order term that predicts R before o′ arrives. A confidence that tracks outcomes on known tasks stops tracking them when the slot moves into a new closure. Why? The question is a **union compound**, not one hard problem: the contact can fail while the reach is intact, or the reach can fail while the contact is intact (Fig 9 :55, :57). It has its own loop and its own ground.

## 2. The shape

1. **Report the residual per slot, not as one average.** Fig 1 :19: *"The residual is indexed by object slot, not aggregated."* Fig 1 :22: *"Aggregating across slots is how a live signal disappears into an average."* A global score near zero with one live slot is a legal state (Fig 1 :13). Support must be positive somewhere before any method is sought (THE_FORMULA step 3, SUPPORT gate).
2. **Calibration is a relation to an anchor, not a property of a number or an agreement between frames.** Fig 2 :29: *"An anchor is whatever settles the question and does not change its answer because of what any frame thinks."* Fig 2 :35: *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* A frame cannot score itself with a quantity it also produces (Fig 1 :27). A confidence is an ordered ⋛ comparison between a stated value and a realised frequency, not a self-grounding magnitude (Fig 13 :20, :29-30; Operators table :48-52).
3. **Treat a saturated metric as a channel alarm, not a verdict.** Fig 10 :24: *"the ground does not decay, the channel does"*; :26: *"stale percepts, dropped transients, saturated metrics, pooled readings"*; :27-28: *"the output is not a verdict, it is you have lost touch."* The ground may be unchanged while the instrument has lost touch.
4. **An unfamiliar task is a new closure, so import is the only operator that moves the wall.** Fig 8 :32: *"Closure is idempotent. Composing inside a closed set never leaves it, so no search, however long, adds an atom."* Fig 6 :23: *"No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs."* Run SEARCHED first, then INWARD, then OUTWARD (THE_FORMULA step 7). The inward and outward instruments are opposed and must never be read against each other (Fig 6 :29-31).
5. **Transfer a method, not a recording.** Fig 4 :22: *"Only methods cross up. Only head starts come down."* Fig 4 :25: *"A recording carried upward looks like knowledge and is a description of one occasion."* A benchmark score is a substituted habitat: *"a synthetic solve proves wiring and never capability"* (Fig 11 :70). Carry the round-trip gap R_T, do not assume the method survived (Fig 4 :30).
6. **A vocabulary that cannot refuse can only accumulate.** Fig 12 :140: *"A vocabulary that cannot refuse can only accumulate."* Operators table :58: *"a refutation is a negation, which is why a vocabulary without it can only accumulate."* A confidently false confidence is a held term to be refused (unary negation), not a novel gap to be explained by another scalar (Fig 5 :50-55).
7. **Name no algorithm.** The framework returns a shape, not a name (Fig 9 :32; Fig 13 :134-135). Which calibration method wins is a `gap`. A named method is a binding from another frame, licensed only by a ground reading or a provenanced import with a source gate and shadow test (Fig 8 :50-52).

## 3. What it explicitly does not say

- Not a single calibration algorithm, not temperature scaling, not conformal prediction, not a Bayesian or evidential head.
- Not that a benchmark score is the ground. It is an instrument, and instruments *"can be wrong on axes they do not measure"* (Fig 2 :37).
- Not that averaging is forbidden. A low global average is a legal state; the claim is that it can hide a live slot.
- Not that the question is one hard problem. It is a union of contact failure and reach failure (Fig 9 :54-57).
- Not `grounded`. No measurement settles the binding of any method to the figure atoms.

## 4. What would settle it — the ground

A source-discriminating instrument, not a further argument. *The Hard Problem is About Source*: an instrument that reads green *"cannot comment on the source"*; the spectrometer resolved it. Here:

- **Slot test:** does a live positive residual remain invisible after the system is given per-slot measurement? If yes, F1 fires.
- **Anchor test:** can the frame move the reading by pushing on it? If yes, F2 fires.
- **Channel test:** does the confidence distribution saturate or pool on the unfamiliar task while the ground is unchanged? If yes, F3 fires and the remedy is to restore contact, not to retune the scalar.
- **Closure test:** is the governing term in closure(Γ) and merely unfound, or absent? More search versus import (Fig 8 :42). Importing against a budget limit adds an unneeded atom.
- **Refusal test:** can the system remove the standing of a held confidence without negation? If yes, F6 fires.
- **Standing falsifiers:** derive one of the six from the other five; show that averaging preserves per-slot support; show reach renewed with no new atom and no differing closure.

## 5. The honest stop

**Unreached, not unreachable.** The six-term set is *"a human's careful guess at reality's compression axes"* (*They're Scanning Books*); declaring it makes the choice visible, not neutral. Another sensorium's minimum set need not be these six. The answer stops at the limit of available instruments and records the lineage so the stop is checkable. *"Indiscernibility is not identity."* A search that finds no governing figure line is never a proof of absence (Fig 8 :39); it is a `gap` reported plainly.

## 6. One-paragraph version for outreach

> The Tether does not name a winning calibration algorithm. It says that a residual must be read per slot, because a global average can hide the live signal; that calibration is a relation to an anchor that does not move when the graded system pushes on it, not an agreement among frames or a score the model produces about itself; that a saturated confidence metric is a channel alarm, not a verdict; that an unfamiliar task is a new closure, so import from a differing frame is the only way to move the wall, and search inside the old closure comes first; that what transfers is a method, not a recorded benchmark result; and that a vocabulary without negation can only accumulate, so a confidently false confidence must be refused, not merely outweighed. What it offers is the shape any calibrated representation must have, five falsifiers written in advance, and an open method slot until a ground settles it.
