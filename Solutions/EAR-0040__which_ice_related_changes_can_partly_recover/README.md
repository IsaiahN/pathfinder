## What an answer would look like, bound as an ordinary term

An answer is a partition of ice-related changes into three classes under a stated counterfactual (temperature stabilizes after a warm perturbation, and in some cases cools back toward the prior value):

1. **Partly recoverable on human timescales** (years to decades). The quantity returns toward its prior value without a new import, because the loss path and the return path use the same thin, fast exchange surface.
2. **Committed and slow** (decades to centuries). The quantity keeps moving after stabilization, may reach a smaller new steady state, and regrows only if forcing is reduced further, on the order of a lifetime or more.
3. **Effectively irreversible on human timescales** (centuries to millennia). A crossing-sensitive feedback or a spent, non-regenerating stock prevents return to the prior configuration even if temperature returns to its prior value.

Binding this shape before the run is the formula's "Direction" discipline: a frame cannot check the direction of its own question unless the sought-for shape is made an ordinary term that accrues a residual.

## Residual in effect terms

For each ice subsystem the residual asks: given stabilization, does the subsystem (a) retrace its loss, (b) continue to a smaller equilibrium over decades to centuries, or (c) stay on a one-way path because a threshold was crossed or a stock was spent? The decision is not a single number. It is a classification with two quantities per subsystem: a response timescale and the presence or absence of a crossing-sensitive feedback.
