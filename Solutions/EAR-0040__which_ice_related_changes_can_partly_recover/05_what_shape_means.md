## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*.

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."* And on method: *"With each new term gained, you narrow the space and deepen your vocabulary."*

For this question a **shape** is the narrowed form of the answer we can state before we have measured anything: an ice question is a union of four conditions; there are three outcome classes; recovery is not the loss path run backwards where a crossing or a spent stock exists; the numbers are imports. A specific value such as "1500 to 3000 years" is a name with a source, not a shape.

## 2. How the shape was obtained here

- *Library of Babel* proximity method: start with the vocabulary closest to the thing (response time, lag, threshold, hysteresis, commitment) and let recurring new terms narrow the space. The residual determines relevance; the question is the tether.
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* The outreach claim is written in effect terms (does the extent come back, does the grounding line return, does the carbon return), not in framework jargon.
- Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause"*.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is why the refuter is an observation, not an argument.

## 3. What licenses a number

Only the ground settles a number. Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The canonical README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*

Fig 6 :14: *"the only operator that moves the wall"*. Numerical relaxation times come from measurements imported from a frame whose closure differs (satellite records, mass-balance stakes, boreholes), with a source gate and a shadow test in `10_source_ledger.csv`. They are not derived from the six-term substrate. This is the central honesty constraint on this solution: the figures decide the shape, the instruments decide the numbers.

## 4. The metamerism check on this question

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and *"cannot comment on the source"*. Several sources can produce the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information"* and *"An instrument that can't distinguish these cases demonstrates its own inadequacy"*.

Applied here: a single observation of "ice extent is lower" does not discriminate among (a) a fast seasonal fluctuation, (b) a committed glacier adjustment, (c) a crossing into self-sustained grounding-line retreat, or (d) a spent carbon stock. All four can produce the same headline reading. What is owed is a better instrument and an unbundling, not a single verdict. This is Fig 9 :54 applied to a measurement: unbundle before searching.

## 5. Prestige is not action

*The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly."* And: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."*

A list of famous cryosphere groups who agree that "ice recovers slowly" would be the named collapse, not corroboration. The legitimate ask is the opposite: give the shape a budget to be tried, and let a measurement (extent, mass balance, altimetry, borehole temperature) settle it. The contact list in file 03 is built from public institutional venues, not from prestige or likely agreement.

## 6. My audit is a simulation, not a ground reading

Same essay: *"LLMs can quickly simulate an approximate answer/output"* and *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* Also: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself. An external validator, or ground, is always needed."*

So `01_figure_grounded_audit.md` and this file are simulated derivations checked for internal consistency against the figures. They are **not** tests of the ice claim and cannot settle anything they report on. The world sources supply physical content, but reading them is not the same as measuring the ice.

## 7. What would make the shape a name

Two things, both outside the shape itself:

1. The ground pays. Formula step 5. A specific domain's class assignment is then `grounded`, and must be recorded as such with the instrument named.
2. A provenanced import with a shadow test (Fig 6 :23, Fig 8 :50-52). The numerical timescales are such imports. Their agreement with the shape does not make the shape a measurement.

## 8. Correction to my own §4 (kept visible)

I first read the metamerism point as forbidding any single statement about "ice recovery." That overstates it. The error is not in saying that some ice changes recover; it is in letting one reading (extent) stand in for four different sources of change. The three-class shape is a discrimination device, not a ban on classification. Both readings are recorded so neither is quietly lost.
