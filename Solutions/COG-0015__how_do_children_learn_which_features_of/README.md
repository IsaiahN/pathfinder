## The question restated as an effect

"Which features are worth attending to" can mean two different things. It can mean a standing list of features (a name), or it can mean the process by which a feature acquires valence for a child at a time (a shape and a route). The first reading is structurally refused by Fig 11 :51 ("No standing list of good actors survives a change of residual."). The second is answerable as a separator: attention is a per-slot residual, the valence of a feature is relative to that residual and to the habitat, the child inherits a head start and imports pointers from differing closures, and a ground settles whether the attentional bet paid. What an answer would look like is written down and bound as an ordinary term in `01` section 0, then left to accrue a residual like anything else (formula step "Direction").
