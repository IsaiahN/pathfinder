## 1. A shape is a constraint you can state before you can name the item

The canonical figures README says the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself." From *The Library of Babel*: "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For COG-0015 this means the answer is the four-condition separator, not the feature list. The shape says that worth-attending is per-slot, residual-relative, head-started and ground-settled. It does not say "faces", "motion", "sound" or "caregivers" as the answer. Those are bindings, not derivations.

A shape constrains; it does not fill. An empty slot `FEATURE(???)` is a shape. `FEATURE(faces)` is a name.

## 2. How the shape is obtained

- *Library of Babel*: start with the vocabulary already closest to the residual, look for recurring new terms that overlap with it, recurse: "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause". So describe the effect "the child reallocates a limited budget toward a slot whose prediction failed", not the cause "the child has a novelty module".
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." For this question: expect looking to return when a habituated stimulus changes, expect the return to be per object rather than uniform, expect it to fail when the change is uncompressable noise.
- *Library of Babel* on stopping: the answer is reached when "the finish line will also be the starting place", because the search composes the answer through locating it. Here that means the selector's quantity (large and compressible gap) and the acceptance test's quantity (description length saved) are the same quantity, Fig 5 :47.

## 3. What licenses a name

Only two things, both outside the shape:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." A specific feature becomes licensed when a measurement shows the child's allocation paying at the ground in that habitat.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51-52), with a source gate and a shadow test. Caregiver gaze is licensed this way: it is an imported pointer that explains a live gap the child already had.

*They're Scanning Books* sharpens the second: "The real import is not a new term in the existing space. It is a new dimension of the space." And: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Also: "Declaring the primitives does not make them neutral. It makes the choice visible." So the habituation and affordance vocabularies we use are visible guesses about the child's compression axes, not nature's own list.

## 4. Metamerism is the error this question is prone to

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and "cannot comment on the source": one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

For COG-0015 the looking-time reading is green. Several sources can produce the same looking time: prediction error, novelty, low-level salience, fatigue release, or a social cue. Naming one as "the feature the child attended to" from the looking-time reading alone is the metamerism error. What is owed is a discriminator (a per-slot model plus an independent ground), not a name. This is F8 in `01`.

## 5. Q: what licenses a particular feature in the slot? ANSWERED

Nothing in the framework. The framework returns a shape. A particular feature is licensed only when the ground settles a term or when a provenanced import with a shadow test crosses from a differing closure. Until then, the name is the searcher's own contribution and must be recorded as such.

**Correction to my own §3 (kept visible).** The phrase "shape, not a name" governs a **missing primitive**, one not held in the library. It does not forbid naming an already held binding. Caregiver gaze, familiar object, prior and affordance are all bindings onto terms or relations the framework already has (the network atom, the held library, the habitat actors). What is forbidden is inventing a seventh feature kind and claiming that the binding moves the wall (Fig 6 :21: "MINT composes inside the closure and can never add an atom."). My first pass overstated this; the narrowed form is what `01` section 6 records and what this file now uses.

## 6. Two consequences for this question

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A list of famous developmental psychologists who agree with the separator is the named collapse, not corroboration. The legitimate ask is a budget to try the instrument and a ground to settle it.

**This reading is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." LLM output is simulacra. So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle anything it reports on.
