## Independent domain census

I redid the census from the residual line alone, before reading the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

Symmetry: "worth attending to" is ordered toward a goal, while a feature-outcome correlation is symmetric, so a pooled effect size cannot choose the arrow. Scale: first order within a stage, second order when a settled habit becomes an atom for the next stage.
- **Domain 1, internal loop.** Actors: library, priors, slots, bonds. Currency: bits and actions, per-slot residual. Anchor: the ground. Question type: partition of slots by live residual.

- **Domain 4, measurement.** Actors: experimenters and instruments. Currency: readings. Anchor: the ground, which must not update on the reading. Question type: downstream broken link.

Order by dependency: perception, affordances, objective, boundary diff, learn and carry (Fig 3 :20); refuse before mint (formula step 2); describe R before choosing a frame (Fig 9).

## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, and Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

2. **Abstraction (T_A):** the shorthand in `07` and `09`: four conditions per slot, head start plus import, non-updating ground, list is a gap.
3. **Concretisation (T_E):** a concrete research programme, a within-child per-feature model, a social-pointer condition, a salience control, and a pre-registered failure set.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- the **per-slot indexing** tends to collapse into a pooled looking-time average the moment an experiment reports one number per condition;
- the **non-updating anchor** tends to become the experimenter's own expectation when the same person designs the stimulus and reads the looking;
- the **provenance and shadow test** on social pointers tend to disappear when gaze-following is scored as a main effect rather than as an import attached to a live gap.

Conversely, one thing survives cleanly: a feature's valence is relative to the current residual and habitat, so a standing list is not the answer. That is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating the formula as identical to the figure set would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a measured gap, which is what `09_watson_answer.md` states.
