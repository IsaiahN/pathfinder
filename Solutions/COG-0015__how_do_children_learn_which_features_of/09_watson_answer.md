## QUESTION

Decide, in effect terms, what the Tether says about "which features are worth attending to". Option A: read the question as asking for a standing list of features and produce one. Option B: read "worth attending to" as a relation between a feature, the child's current residual and a habitat, and return the separator that any answer must satisfy. What each leads to: A produces a name where the figures return a shape, averages per-slot residuals into a signal that cannot say where to look, and gives the measurement frame a list that will not survive a change of residual; B produces four checkable conditions, a six-condition refuter written in advance, and a declared `gap` where the list would be.

## DOMAIN CENSUS

R by arity, symmetry and scale, then one line per domain with actors / currency / anchor, partition or union, and order by dependency.

- **R (the residual).** The gap, per feature slot, between the child's predicted observation and the actual observation. Arity: four overlapping conditions, so a union compound, not a partition (Fig 9: a bundled problem is usually a union of overlapping conditions, not a list of separate ones). Symmetry: "worth attending to for a goal" is ordered, while a feature-outcome correlation is symmetric, so an averaged effect size cannot choose the arrow. Scale: first order within one stage, second order when a settled attentional habit becomes an atom for the next stage (Fig 12).
- **Domain 1, internal attentional loop.** Actors: the child's library, priors, slots, bonds. Currency: bits and actions, residual per slot. Anchor: the ground, does the bet pay? Partition question: which slots carry live residual.
- **Domain 2, habitat.** Actors: caregivers, objects, conditions, relations. Currency: contact and cascade, enumerated outward. Anchor: the ground. Enumeration, never composition. Overlaps D3 at the caregiver.
- **Domain 3, social import.** Actors: adults and peers as differing closures, gaze, pointing, speech. Currency: imported pointers with provenance and a shadow test. Anchor: the ground; the child ranges the pointer against its own residual. Overlaps D2 and D1.
- **Domain 4, measurement.** Actors: experimenters, looking-time and eye-tracking instruments. Currency: readings of attention. Anchor: the ground, which must not update on the reading. Downstream of D1 to D3; its objective link is broken.
- **Order by dependency.** Perception, then terms for affordances, then the objective in the child's own terms, then the boundary diff, then learn and carry (Fig 3). Refuse before mint (formula step 2). Describe R before choosing a frame (Fig 9).

Strain test applied: the per-slot residual of Fig 1 governs where to look; a global looking-time average is a budget filter, not a witness (Fig 9 :60). ## VERDICT (from the figures)

"Which features are worth attending to" is not a request the figures can answer with a list. A feature's valence is relative to the child's current residual and habitat, so no standing list survives a change of residual. What survives is a four-condition separator: per-slot residual allocation, intermediate large-and-compressible discrepancy, inherited head start plus provenanced imports from differing closures, and a non-updating ground that settles which commitments pay. Two attentional regimes over the same feature set are isomers, so the arrangement, not the ingredient list, carries the difference. The literal list and timetable are a `gap`. The four domain verdicts are `specified`, the structural shape is `general`, and nothing is `grounded`.

- **cost if wrong:** bounded and locatable. The shape claim carries six refuters and a named instrument, so an error is findable rather than invisible. The real cost is spending the independence of outside readers by sending a feature list or a pooled average instead of a generator, which Fig 2 :42 prices ("Buy independence in proportion to the cost of being wrong."). That cost is avoidable by leading with the separator and its refuters.
- **undoable:** yes. The feature list was never asserted, so nothing concrete has to be withdrawn. The four conditions can be refined or refused one at a time, and the measurement protocol in `08` can be superseded without touching the derivation. A refused term is added to the record; it is not deleted.
- **reversed by:** a ground reading, not agreement. A within-child, per-feature model showing that a global average predicts looking as well as the per-slot residual would break D1; a systematic preference for noise or the fully familiar over the intermediate compressible gap would break Fig 5 :18; an improvement to the child in isolation that changes contact-free capability at the ground would break Fig 11 :40; zero surplus from a differing-closure pointer would break D3; and a figure re-census admitting a standing list across residual changes would break D2. Until one of these fires, the verdict stands as `candidate`.
