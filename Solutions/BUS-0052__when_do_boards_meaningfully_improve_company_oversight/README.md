## What is being decided, in effect terms

A board is a checking arrangement. For each decision slot s (a budget, an acquisition, an executive hire, a restatement), the residual is R_s = |Gamma_board(b,a) - o'|: what the board expects the decision to return against what the ground returns. "Meaningfully improve" means the board keeps R_s live and reduces it. "Ratify" means the board's reading is management's own report, so no residual is ever registered. The two are not ends of one scale; they are two different arrangements, and the question is a union of conditions, not one hard question.

An answer would look like a set of conditions that are individually necessary and jointly sufficient for a board to occupy a checking seat rather than join the frame it checks. That shape is bound as an ordinary term in `01_figure_grounded_audit.md` and its refuter is written before the conclusion.
