## What the derivation concludes, in one line

Yes, conditionally: membership in one universality class is fixed by the coarse structure (symmetry, dimensionality, interaction range, the figure's "arity · symmetry · scale"), not by the identity of the components, so very different components can share a class. The condition is load bearing: if the difference changes the coarse arrangement (the bond, not the atoms), the systems are different classes. Both halves are figure-derived and both are marked by mode.
