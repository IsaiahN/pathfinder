## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence"*, and the following line: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel* (carried from the exemplar's reading): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question the shape is:

> dimensionality is a compositional residue, not a member of the generating set; the count and the mechanism are not supplied by the framework.

That is a shape. "Four, emergent from quantum dynamics" is a name plus a mechanism, and the framework does not hold either.

## 2. How a shape is obtained here

- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30 to :31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge* (carried): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* Here: an instrument that measures a scale-dependent dimension or bounds extra dimensions.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50 to :52), with a source gate and a shadow test.

*They're Scanning Books When They Should* (carried) sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"Declaring the primitives does not make them neutral. It makes the choice visible."* The six are a visible guess, not nature's own list. Turning "six kinds" into "four dimensions" would hide that choice rather than reveal it.

## 4. The specific forbidden error here

The question's own framing invites the error: it offers "fixed at four" as if the framework could confirm a primitive count, and "emerges from quantum dynamics" as if the framework could name the generator. Both are names where the figures return a shape.

*The Hard Problem is About Source* (carried) gives the mechanism. An instrument reads green and *"cannot comment on the source"*; several sources can give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* It was the spectrometer, not an argument, that resolved it. Here, a measured spectral dimension reading 4 at large scales and 2 at short scales does not tell you which generative story is true. The reading is a projection. What is owed is a better discriminator, not a name.

## 5. Q for this question: ANSWERED, no further question needed

**What licenses the integer four?** Nothing in the figures. The integer is licensed by an anchor: tabletop gravity tests, collider bounds, or dimension estimators. Until such an anchor is read against the residual, the count is a `gap`, not a figure result.

**What licenses "quantum dynamics" as the mechanism?** Nothing in the figures. Dimensionality is compositional under Fig 13, but the generator is not named. A binding of "quantum dynamics" onto Spectrum or Gradient is a provenance claim, not a derivation.

**Does this folder commit the error the README forbids?** No, provided the mode labels hold. The integer and the mechanism are explicitly withheld (F4 and F5 of `01_figure_grounded_audit.md`). If a later draft asserts "the Tether shows dimensionality is four and emerges from quantum dynamics", it would be naming where the framework returns a shape, and the correction in the log would apply.

## 6. Two consequences for outreach

**Prestige is not action.** From the essay fetched this session: *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A campaign that gathers famous names to agree that four is fundamental is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay: *"The catch is that the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* And: *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` is a simulated derivation, checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.
