## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence," and the line continues that the system cannot say which primitive is missing, because naming it would mean already holding it.

From *The Library of Babel*, opened this session: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- The shape is: *a signed cycle with a state-carrying joint, a per-slot remainder that compounds, a union of conditions, and a channel that can still read the ground.*
- A name would be: *the 400 kV Lukmanier line arcing to a tree at 03:00 on 28 September 2003 started the Italy cascade*, or *interbank exposure X is the coupling*. Those are instances in the world, not what the framework returns.

## 2. How a shape is obtained

- *Library of Babel*, opened this session: use the vocabulary you already have that is closest to the thing, look for recurring new terms that "overlap or correlate" with it, and recurse. "With each new term gained, you narrow the space by definition and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."
- The exemplar's *Decoding Tacit Knowledge* entry (quote recorded there, not re-opened this session): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." This is exactly the outreach order in `02_outreach_email.md`: send the effect first, let the recipient check it against the world.
- *Library of Babel* on stopping: "you will know that you are done because the finish line will also be the starting place," and by the time you have the exact terms you have "composed the answer through the process of locating it."

Applied here: the terms "feedback", "amplification", "cascade", "interdependency" are the borrowed vocabulary. The figure lines narrow them into a signed cycle, a cross-kind joint and a compounding remainder. That narrowing is the shape; it is not a named crisis mechanism.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays." Here the ground is an outage-and-settlement record with per-slot timing.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

The exemplar's *They're Scanning Books* entry (quote recorded there, not re-opened this session) sharpens this: "The real import is not a new term in the existing space. It is a new dimension of the space." It also warns that "Declaring the primitives does not make them neutral. It makes the choice visible." So naming a coupling as *the* amplification channel would turn a visible choice into an invisible one unless it pays at the ground.

The world sources make the same demand in their own vocabulary. The Interdependent networks page describes dependency links as "a need for support from one node to another", which is an effect description. Turning that into a named link in a particular grid is an import from the engineering frame and needs provenance, as F3 in the audit records.

## 4. Why the "no advanced warning" claim is a source problem

The exemplar's *The Hard Problem is About Source* entry (quote recorded there, not re-opened this session) gives the mechanism: an instrument that reads green "cannot comment on the source"; several paths can create the same behaviour, so "behavior is a projection with lossy information"; and "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

The parallel here is direct. A saturated alert reads "all normal" just as a healthy grid reads "all normal": one reading, several sources. The Cascading failure page records the engineering version: "the speed of the control signal is no faster than the speed of the propagating power overload", so no warning can be sent ahead. The Italy blackout record says the operator "was not aware of the urgency". The source of the missing warning is in the channel (Fig 10 :24), not in an absent residual. What is owed is a better per-slot instrument, not a new name for the crisis.

## 5. Q: Does the framework return the specific coupling that amplified a crisis?

**Answer: no.** Nothing in the six-term set or the operator set selects which dependency link closes a positive loop in a given event. Fig 12 :121 gives the cycle and its sign; Fig 13 :32 gives compounding; Fig 11 :49 gives valence relative to the residual. None names a link. By the canonical README the missing thing is characterised in effect terms: a reading that discriminates a positive-feedback dependency from a merely correlated one. The answer is `gap` in F10 of the audit, held open in the shape, and "unreachable is a verdict here, not a silence."

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*, opened this session: "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A list of famous network scientists assembled to agree with the shape is the named collapse, not corroboration. The legitimate ask gives the claim a budget to be tried, then lets an outage record settle it.

**My own audit is a simulation, not a ground reading.** Same essay, opened this session: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is not a test of the claim, it cannot settle anything it reports on, and it must be labelled as such everywhere.
