A wrong answer to (1) sends the search down one lever when two are needed. A wrong answer to (2) measures a link below the break. A wrong answer to (3) overstates the isomer claim.

## DERIVATION

### Q1 - Union or partition? UNION

- Fig 9 :4-5: *"Disagreements that do not shrink with effort, where each rule keeps working well on a different subset, are not one hard question but several well-formed ones. Split it rather than search."*
- Fig 9 :54-59: *"And when the split lands on a union rather than a partition, unbundle before you search again. A bundled problem is usually a union of overlapping conditions, not a list of separate ones. A single lever clears the region where only one condition holds and leaves the intersections standing, because the second condition still binds."*
- Applied here: the rule "information is a read-out" works when the context is fixed. The rule "information is invariant" works across contexts. The intersection is a system measured in a fixed context but claimed to have a context-independent information content. That is exactly where the second condition still binds.
- ⇒ The question is a **union**. The definition loop and the context loop have separate grounds. `triangulated` (Fig 9 :4-5 and :54-59, two passages in the same figure with different predicates, plus the Kochen-Specker constraint from a different field).
- **Falsifier, written before the run:** if a single rule resolves both the fixed-context subset and the cross-context subset with no remainder, the compound is a partition and this finding fails.

### Q2 - What order do the loops run? DESCRIBE, REFUSE, SETTLE, COMPOSE

- Fig 9 :27-28: *"describe it before you go looking, or any frame you pick will seem to fit."* The residual is described in effect terms first: "does not move when the context moves".
- Fig 3 :20-21: *"The chain is ordered by dependency, not by importance. Each link consumes what the one above produces."* Fig 3 :22-23: *"A step whose input never arrives cannot be diagnosed, only its predecessor can. Which is why a reading taken below the break is not a weak reading. It is a reading of nothing."*
- Formula step 2: a term held that is false owes a refusal, not an explanation. The term refused is "information = context-dependent read-out" (FORMULA step 2 REFUTED). ¬ is the operator, not one of the seven bonds (Operators table :70-78).
- Fig 12 :104: *"A settled molecule becomes an atom for whatever composes over it. So irreducible is a fact about a level and never about the world."* Each first-order read-out, once settled against the ground, becomes an atom for a second-order state estimate. Tomography is that second-order composition, not a new primitive.
- ⇒ Order: describe R, refuse the read-out definition, settle the invariant, then compose settled read-outs into the state estimate. `triangulated` for the order (Fig 3 plus Fig 12 :104, plus the formula's route step).
- **Falsifier:** show a composition of contexts into a state estimate that succeeds before the individual read-outs are settled against a ground. Then the dependency order is wrong.

### Q3 - Are two measurement contexts isomers?

- Fig 12 :117: *"isomer. Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."*
- Fig 12 :124: *"functional group. A substructure whose presence fixes the outcome. The group says what kind; the qualifier says which member."*
- Two contexts applied to the same prepared state share the state atom. They differ in which compatible observables are jointly measured. If the observable atoms are the same set and only the grouping into a context changes, then by Fig 12 they are **isomers**: same atoms, different arrangement, different outcome distribution. The difference is decisive in behaviour and invisible in a formula that lists only the observables.
- As the question is usually phrased, context A and context B share only the prepared state and use different observables. Then they are not isomers; they are two members of the same **functional group** (pose applied to a state), differing in which atoms fill the slots.
- Stronger, testable form: write both contexts over the full shared atom set of preparation, observables and pose, differing only in which observables are bound into which compatible set. That is a real isomer claim with a stated falsifier.
- **Falsifier, written before the run:** if either context can be written without an atom the other requires (for example a context with no prepared state, or one with no compatible-measurement set), the isomer claim fails and the functional-group reading stands instead. `single-source` for the figure definition, with the physics check unmeasured.

### Q4 - What is the order of the union, and where is the strain?

- Each settled first-order read-out becomes an atom for the next level (Fig 12 :104). The second-order object is the state estimate assembled from several contexts. That is the recursion, not an import.
- **Strain, named:** the seven bonds include ⋛ comparison, → sequence and the symmetric three, but none is "apply a context". The Symbols table places `F`, the frame transform, *"Distinct from T_A and T_E, which run between scales. Cannot be run without a pose."* So the pose is an operator outside the bond set, structurally like negation is outside the seven (Operators table :70-78: *"Negation is the one operator here that acts on a single operand."*). Whether `F` should be priced as an atom slot, as nothing, or as the choice of what to measure is **open**, exactly as the price of negation is open (Operators table :77-78). I record this as a strain, not a correction: the figures describe bonds and unary operators, and a pose-parameterised transform is a third kind they do not price.
- **Falsifier for the strain:** show that applying a context is just a ⋛ comparison or a → sequence at the relevant level. Then `F` is a bond after all and the strain dissolves.

## CONCLUSION

The question is a **union**, so the definition loop and the context loop must be run separately before their intersection is searched. The order is describe, refuse the read-out definition, settle the invariant, then compose settled read-outs into a state estimate. Two contexts over the same atom set, differing only in which compatible observables are grouped, are Fig 12's **isomers**; as ordinarily phrased they are members of a **functional group**. The second-order state estimate is licensed by the settled-molecule rule, not by a new primitive. One strain remains open and named: applying a context is a pose-parameterised transform that the seven bonds and the single unary operator do not price.

This framing keeps the figure-derived structure without asserting which functional of the state is the definition. `metric-independent` is not claimed; `S(ρ)` is a provenanced binding. `two contexts are isomers over a shared atom set` is a checkable structural claim.
