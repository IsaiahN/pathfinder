## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself" Fig 13 says the system "can report that it lacks something rather than producing an answer anyway. Unreachable is a verdict here, not a silence" and "cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*: "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question, *a directional, lossy, redundant encoding with local recoverability and an area-like cost* is a shape. *The HaPPY code on a {5,4} hyperbolic tiling is the mechanism of AdS/CFT* is a name.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary." And: "you will have to use the existing vocabulary you do know that is closest to the words that you wish to describe and grasp the shape of."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *Library of Babel* on stopping: "you will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better."

For this question the shape was obtained by describing the residual first: radial commutativity, subregion duality, the area law, the erasure threshold. Only then was QEC considered as the frame whose closure predicts that shape (Fig 8 :53: "Residual first, frame second."). Naming QEC first and looking for a place to put it would have been the projection error Fig 9 :27-28 names.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The canonical README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51), with a source gate and a shadow test.

*How Intelligence Actually Works* sharpens the second: "The framework if applied effectively provides us a tool that cuts down to the shape of a thing, problem or question based on the given information available at this point in time." It also states the limit directly: "The recursion converges toward indiscernibility, and indiscernibility is not identity. The projection that no instrument distinguishes from the thing is still a projection, which is why the lineage has to be kept even when the copy is perfect."

So a tensor network that reproduces an area law is indiscernible from a discretized geometry at the resolution of the area law. That does not make them identical. The lineage (which frame supplied the perfect tensor, which theorem supplied the reconstruction, who proved what and when) is what keeps the claim checkable.

## 4. Why the identity reading is the specific forbidden error

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and "it cannot comment on the source." One green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered can give the same reading. "If several paths create the same behavior, then behavior is a projection with lossy information". What resolved it was "not by argument, but by the arrival of a better instrument."

Applied here: the area law and subregion reconstruction are the reading. "The code is the mechanism of quantum gravity" names a source from that reading. Several very different microscopic accounts could give the same area law. What is owed is a source-discriminating instrument or a provenance chain, not a name. *How Intelligence Actually Works* records the same distinction with different cases: provenance is recoverable for lab-grown versus mined diamonds because isotope ratios genuinely differ, but lost in the green-light case because no trace survives. For the code-to-bulk map, which case we are in is not yet decided, and the honest word is `unreached`.

*The Recursive Self-Improvement Trap*: "The catch is that the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself. An external validator, or ground, is always needed to tether the veracity of the output to reality."

## 5. Q1 answered: what does "model" license here?

**What licenses saying a QEC code is a *model* of bulk-boundary correspondence?** The figure-licensed reading is: the code is a provenanced import from a frame whose closure differs, whose encoding and recovery maps instantiate the membrane rule of Fig 4 and pass a shadow test on radial commutativity, subregion duality and the area law. That is a `specified` shape claim. It licenses neither identity, nor uniqueness, nor the derivation of bulk dynamics.

**Does the literature commit the forbidden error?** The papers are careful. The HaPPY title says "Toy models", and Harlow's theorem is stated as "a version of the quantum-corrected Ryu-Takayanagi formula holds in any quantum error-correcting code", which is a conditional result about codes, not a claim that gravity is a code. The forbidden reading is a later commentary layer that turns the model into the mechanism. That layer is what this package refuses.

**Does the framework name a structure it cannot?** Not here. In QMGR-0037 the temptation was to name *the* structure between space and time. Here the code is not a new primitive of the six-term set; it is a binding from the information frame onto an existing arrangement. The README's "shape, not a name" governs a **missing** primitive. A code is not missing from Γ; it is imported. So the error to watch is not naming a seventh term but claiming the import moves the wall without a source gate (Fig 6 :23-24).

## 6. Two consequences for outreach

**Prestige is not action.** *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof. Someone let reputation substitute for result." And: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A campaign that gathers famous names to agree that the code is holography is the named collapse. The legitimate ask is the opposite: give the claim a budget to be tried and let a ground, an instrument, a proof checker or an independent frame settle it.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." The essay calls such output "simulacra." So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle anything it reports on.
