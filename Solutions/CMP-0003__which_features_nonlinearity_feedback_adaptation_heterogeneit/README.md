**Source:** complexity science.txt line 6

**Section:** 1. Foundations, definitions, and explanation

## The question restated as an effect

The question asks for a set of necessary conditions. "Necessary" here means: remove the feature and complex behavior fails to emerge. Each option leads to a different downstream claim. If nonlinearity is necessary, then linearity forbids complexity. If feedback is necessary, then an open loop forbids it. If adaptation is necessary, then a fixed rule set forbids it. If heterogeneity is necessary, then identical components forbid it. If network structure is necessary, then an unconnected collection forbids it. An answer would therefore be a *shape*: a constraint on what any candidate complex system must contain, stated before we can name a single empirical feature that always does the work. Per Formula step "Direction", that sought-for shape is bound here as an ordinary term (call it S) so it can accrue a residual and be refused.

## What is deliberately not here

- No personal emails of named individuals.
- No ranking of people by how likely they are to believe the answer.
- No bulk-send plan.

Three reasons, in the figures' own words:

1. **A room does not upgrade the label.** Fig 7 :35 says *"A room's agreement is variation, not a verdict. Selection between rooms is where the ground votes."* Adding readers raises the vocabulary and does not add an anchor.
2. **Selecting for receptiveness manufactures the disqualifying correlation.** Fig 2 :40 says *"agreement about the world is worthless when the agreeing frames share an evidence pool."* A list ranked by likely agreement is a list selected to agree.
3. **Asking for trust before a check spends independence.** Fig 10 :42 says *"A verifier that can reconstruct the claim cannot verify it."* The recipient must see the residual and its refuter before any source.

Legally: scraping personal emails for unsolicited bulk outreach breaches GDPR and CAN-SPAM style rules in many jurisdictions. Public opt-in submission and contact venues avoid that failure as well as the structural one.
