# What "shape" means for this question

**Mode: `general` on the definition, `specified` on its application to QMGR2-0030.** Sources read 2026-11-23: the two essays listed in `10_source_ledger.csv`, the canonical figures README, and the verbatim figure text. This is a simulated derivation checked for internal consistency against the figures, not a ground reading.

## 1. Definition

The canonical usage rule (`FRAMEWORK\reference\FIGURES_README_canonical.md`, local) says the framework says "what a missing thing would have to look like (**a shape, not a name**)", stops "at the limit of what the available instruments can distinguish", and records the lineage so the stop is honest. It adds: "Indiscernibility is not identity."

Fig 9 :32: "you get a kind of thing, never the answer itself"

So a **shape** is the narrowed form of an answer you can state before you can name the thing that fills it. It constrains; it does not fill. For this question the shape is a set of properties the measurement combination must have, not a list of survey names and not a value of H0.

## 2. How the shape is obtained here

- Fig 9 :22 requires describing R first by "arity · symmetry · scale". For this R: at least two conditions, ordered rather than symmetric, first order inside each regime and second order at their comparison (see `01` section 0).
- Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause." We describe the effect (a reading compatible with two sources) before choosing a frame (a null test, a survey).
- Fig 8 :53: "Residual first, frame second." The measurement set is summoned by the residual, not picked for familiarity.
- From *The Hard Problem is About Source* (2026-08-28): "If several paths create the same behavior, then behavior is a projection with lossy information." The single H0 reading is a projection; the shape is what a source-discriminating instrument must be able to do. The essay's resolution is historical: "It was proven wrong not by argument, but by the arrival of a better instrument." That is the model for answering this question, and a warning that an argument alone cannot answer it.

## 3. The shape for QMGR2-0030

Stated as properties, each with its figure ground:

1. **Low evidence overlap.** Fig 2 :31, "Independence, between two frames, is how little they draw on the same evidence." D3 and D6 of the census must not share the ladder calibration or the sound-horizon prior with D1 and D2.
2. **A statistic that does not contain the disputed quantity.** Fig 10 :18-19, "a declared meaning is not a grounded one" and "→ install what can be violated". The lensing-plus-siren dimensionless ratio is the published instance because H0 cancels out of it.
3. **A ground that does not move with the frames.** Fig 2 :29-30, "An anchor is whatever settles the question and does not change its answer because of what any frame thinks." The measured distances and times are the anchor. The model inference is not.
4. **Per-slot residuals.** Fig 1 :19, "The residual is indexed by object slot, not aggregated." Each method is its own slot.
5. **Ranked, reversible cuts.** Fig 9 :41, "so keep every cut ranked and reversible". A cut that removes the answer removes it cheaply, so keep the ordering on record.
6. **A stop that is honest about instruments.** Fig 6 :34-35, "The question is not whether a sensor could exist. It is whether anything, at any resolution, is already returning something that fails to resolve." The lensed-siren version does not yet return data. Say so.

That is the full shape. It does not include "use DESI", "use Rubin", "use LIGO", "wait for LISA", or "the answer is early-time new physics". Those are bindings from the cosmology frame, recorded as imports in `10_source_ledger.csv`.

## 4. What licenses a name in this question

Only two things, both outside the shape:

1. **The ground settles it**, by the `THE_FORMULA.md` rule "the ground settles it. Verified only by what pays. A gate is not the ground." Here that means an actual null-test result from lensed sirens, or a blind reanalysis whose single changed assumption removes the offset.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 import operator; Fig 8 :50, "Two frames can hold the same atom by convergence, reaching it separately, which is corroboration at maximum independence"). Citing Kouniatalis and Saridakis (2026) is an import with provenance; it is not a derivation from the figures.

*The Recursive Self-Improvement Trap* (2026-11-19) sharpens the limit: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." This document cannot certify its own shape. An outside frame must check it against the ground.

## 5. A correction I made while writing this folder

I first wrote that "the framework returns a shape, not a name" forbids naming any instrument at all. That is too broad. The README qualifies the phrase: it concerns "a **missing** thing". An instrument already in the world is not a missing primitive, so naming one is a binding from the world frame, not the invention of a seventh term. What remains forbidden is claiming that a figure line selects that instrument, or that naming it moves the wall. Both earlier and corrected readings are preserved here. This mirrors the correction recorded in the exemplar's `05_what_shape_means.md` section 5b.

## 6. Two consequences for this question

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly" and "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A list of famous cosmologists who agree with the shape is the named collapse. The legitimate ask gives the shape a budget to be tried and lets a measurement settle it.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output with the formula" but "the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of any cosmological model and must be labelled as such. It cannot settle anything it reports on.
