# What "shape" means for this question: canonical reading from the eight essays

All eight essays were opened and read on 2026-11-22. All are by Isaiah N (2026, adventuresinml Substack) and share an evidence pool with the figures, so their agreement with the figures is expected and carries little independent weight. Full URLs are in `10_source_ledger.csv` and `04_links_and_distribution.md`.

## 1. A shape is a constraint you can state before you can name the thing

The canonical figures README says the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32 "you get a kind of thing, never the answer itself". From *The Library of Babel*: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For EAR-0007, the shape is: the pressure channel changes the cast; the feedback channel changes the arrangement; a feedback is a signed cycle; valence is relative to the residual; the residual that matters may be steps out; a claim needs a non-updating anchor; particular feedbacks are not named by the framework. That is a constraint set. "Ice-albedo feedback is what changed" is a name.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that correlate with it, recurse. "With each new term gained, you narrow the space by definition and deepen your vocabulary."
- From *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." The question's shape is written in effect terms so an Earth scientist can check it without adopting the framework.
- Fig 6 :30 "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31 "your words are borrowed too, so describe the effect rather than the cause." So this file describes "adding an actor" and "changing a bond" in effect terms, not in framework jargon alone.
- *Library of Babel* on stopping: "You will know that you are done because the finish line will also be the starting place." The loop stops when nothing further registers against the residual.

## 3. What licenses a name

Only two things, both outside the shape:

1. **The ground settles it.** *The Hard Problem is About Source*: "If several paths create the same behavior, then behavior is a projection with lossy information." The essay's green-light case is resolved "not by argument, but by the arrival of a better instrument." Applied here: which feedback changed is settled by a measurement that discriminates among sources, not by reading the outcome off a model.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :50-52). Naming a specific Earth-system feedback is a binding from the Earth-science frame onto held atoms, recorded as provenance.

*They're Scanning Books When They Should Be Studying Nature*: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." And: "Declaring the primitives does not make them neutral. It makes the choice visible." The six are a visible guess, not nature's own list. Naming one as *the* mechanism turns a visible choice into an invisible one.

## 4. Why this audit is a simulation, not a ground reading

*The Recursive Self-Improvement Trap*: "the truly testable output would need to be derived from the real architecture or working the formula yourself." And *Arrival of the Fittest*: outputs "could never be verified if the solutions presented were not contrived to fit the formula." So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is not a test of the Earth-system claim and must be labelled as such.

The trap essay also gives the validator rule: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." That is Fig 2 in prose: a claim about a feedback cannot be settled by the model that made the claim.

## 5. Prestige is not action

*The Recursive Self-Improvement Trap*: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A campaign that gathers famous names to agree that a feedback changed is the named collapse, not corroboration. The legitimate ask is a budget to test the shape against a measurement, with the refuter written first. This is why `03_public_contact_points.csv` has no personal emails and no receptiveness rank.

Fig 10 :59 "an interest in the outcome is unavoidable, an interest in the reading is disqualifying". An Earth scientist studying a system they work on has an interest in the outcome; that is normal and declared. An interest in whether this particular derivation comes out right is disqualifying for checking it.

## 6. Capability, habitat, and the maintainer

*How a Society of Agents Would Work* quotes Fig 11: "capability is a property of agent-and-habitat, never of the agent alone." For this question: the human activity is not a pressure by kind; it is a lever whose effect is a property of the activity and the habitat it contacts (Fig 11 :39-40). *How Intelligence Actually Works* adds "indiscernibility is not identity", so a model that reproduces the observed response is not thereby the changed feedback; the lineage and the instrument still have to be recorded.

## 7. Correction to my own reading

I first wrote that the shape-not-a-name rule forbids naming any feedback. That was too broad. The canonical phrase governs a **missing** primitive, one not held in Γ. Ice-albedo, moisture recycling and nutrient retention are not framework primitives at all; they are Earth-science bindings onto the held atoms (gradient, network, energy, state). Naming them is **not** forbidden, but it is a binding with provenance, not a figure derivation, and it does not move the wall (Fig 6 :25-26 "The world does not gain primitives; a frame gains access"). Both claims are kept: naming is allowed with provenance, and the framework still returns only a shape.

A second correction: I first treated "another sensorium's minimum set need not be those six" as if it made the six irrelevant to Earth systems. It does not. The six are load-bearing for the shape (what can be spent, what relates, sign of loop); they are not a substitute for the measurements that name a particular feedback. The mapping in `06_isomers_and_order.md` is marked `specified`, not `grounded`.

## 8. Summary for this question

"Shape" here means the checkable constraint set that separates an added pressure from an altered feedback, before either is named for a particular ecosystem. The essays supply the discipline: describe in effect terms, bind the sought-for shape so it can be refused, do not ask for trust or agreement, require a validator outside the frame, and record the lineage so an indiscernible copy is not mistaken for the thing itself.
