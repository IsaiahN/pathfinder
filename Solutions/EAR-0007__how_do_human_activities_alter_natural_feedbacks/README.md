## The residual in effect terms

Observed: the same external forcing can produce a different system response after human activity, because the system's own feedback structure has changed. What is unexplained is the mechanism by which an added actor re-wires the loop, not merely the size of the push. The question contrasts two channels: (a) adding a pressure, an actor or forcing applied to an existing loop; (b) altering a feedback, a change to the loop's bonds, sign, or closure. Many real interventions do both, so the channels overlap. What an answer would look like: a shape that separates the two channels, states which one governs which observation, names the anchor that would settle a claim about each, and records what cannot be named at this budget. That sought-for shape is bound here as an ordinary term so it can accrue a residual like anything else (Formula, "Direction").
