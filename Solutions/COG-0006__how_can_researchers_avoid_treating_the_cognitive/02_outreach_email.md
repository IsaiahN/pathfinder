# Outreach draft - check the output before you decide about the theory

**Use:** one-to-one, or as a cover note attached to a submission through the public venues in `03_public_contact_points.csv`. **Not** for bulk send.

**Hard precondition:** do not send until the refuter in `01_figure_grounded_audit.md` §4 is in the recipient's hands before any theory. The two-stage offer collapses if the recipient has already absorbed the framework.

**Subject:** One check on a cross-cultural "universal baseline" claim

> Hello,
>
> I have one specific methodological output I would like you to check against what you already know about cross-cultural research. I am not asking you to read a theory first, and I am not asking you to agree with anything. If the output does not survive, there is nothing else to look at.
>
> **The output (`general` on the shape, `specified` on each condition, not `grounded`):** "treat the cognitive norms of industrialized societies as a universal baseline" fails an anchor test. An anchor is whatever settles the question and does not change its answer because of what any frame thinks. A baseline drawn from one population changes its answer when the population changes, so it is a frame that has been promoted into the anchor position, not an anchor. What follows is a separator, not a list:
>
> 1. describe the gap in effect terms for each population-and-task slot before choosing a frame;
> 2. keep the gap indexed per slot, never averaged into one culture effect;
> 3. name the industrialization prior as a choice with provenance, not as a neutral zero point;
> 4. buy independence from genuinely different closures and evidence pools;
> 5. keep a ground in each habitat that does not update on what the researchers think;
> 6. enumerate the habitat outward rather than composing a universal from one item set;
> 7. measure the round trip between the local reading and the universal claim instead of assuming it is lossless;
> 8. write a refuter before the run and keep an operator that can say "this is false".
>
> **What I am not claiming:** that no cognitive capacity is shared across societies; that any particular norm is or is not universal; that a larger or more diverse WEIRD sample settles the question; or that measurement invariance, by itself, proves a construct is universal. The framework this comes from returns a shape, not a name. Agreement on a shared meaning is useful for a convention; it is not a verdict about the world.
>
> **What would refute the output.** I wrote these down before sending this:
> 1. a single-population sample is shown to be a non-updating anchor for a cross-population claim;
> 2. agreement among frames sharing an evidence pool is shown to carry verdict weight;
> 3. a cognitive performance is shown to be invariant across habitats that differ in contact, using a discriminating instrument;
> 4. a task's meaning is shown to be invariant across populations without instrument work;
> 5. increasing N within one population is shown to remove the cross-population residual;
> 6. a figure line is found that returns the standing list of universal norms.
>
> If any holds, I withdraw the corresponding condition. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** the sources are below. The figures are the authority, not my summary of them.
> - The figures and formula for direct download, branch `general-agent`: https://github.com/IsaiahN/tether/tree/general-agent/figures
> - "How Intelligence Actually Works" (worked narrative, six-term derivation): https://adventuresinml.substack.com/p/how-intelligence-actually-works
> - "Arrival of the Fittest: The Tether Architecture" (all 13 figures): https://medium.com/@IsaiahNwukor/arrival-of-the-fittest-the-tether-architecture-1de7edf641ec
>
> **If you want to use the machinery:** the formula is in the figures link. Run it on a problem you know well and can check against a ground. Write down what would refute your result *before* you run it, and state the mode of what you get. A reported failure is more useful to me than a reported success.

## Two-stage record

- **Stage 1:** send the separator, the anchor test and the six refuters. Ask what the recipient would count as a failure. **Record the verdict here before any theory is shown.**
- **Stage 2, opt-in only:** if they are curious, send the three links. Later agreement is never pooled as corroboration (Fig 2 :40).
- **Stage 3:** offer the formula as a method, with the instruction that each user states a mode and writes a refuter before running it.
