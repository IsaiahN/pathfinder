## The residual in effect terms

Given a contact network, a model predicts an infection outcome; an instrument returns what actually happened, per cluster and per time. The residual is the gap between those two, indexed per cluster, never averaged into one global epidemic curve (Fig 1 :19, :22). The question asks for a **separator**: the conditions under which the same structural feature, clustering (triangles, transitivity, cliques, communities), has opposite effects on two different quantities, (i) the speed and size of an outbreak and (ii) the persistence of infection in a reservoir. The sought-for shape is bound as an ordinary term before the run (Formula, "Direction"), so the pre-registered refuter in `01` can fire on it.

## Key verdict

The two outcomes are a **union of overlapping conditions with different anchors**, not opposite ends of one dial and not a single scalar with a universal sign. Clustering slows transmission when triangles spend a contact on a neighbour the infection has already reached (local depletion of susceptible slots), and it creates a reservoir when the same closed triangle becomes a cycle that re-enters infection through reinfection or waning immunity. The structural distinction is arrangement (bond), not the ingredient count; the clustering coefficient is a flat formula. The flip is a threshold comparison, and the operand type of that comparison is a live strain. No figure line returns a numerical flip point, and no instrument here discriminates which arrangement produced a measured coefficient: that is a declared `gap`, not a silence.
