## The residual in effect terms

The same class of bodily events (a racing heart, a churning stomach, flushed skin) is bound to different emotional experiences and different explanations in different cultures. What fails to resolve is the mapping: which bodily signal becomes which emotion, and which account is offered for it. If the relation were a fixed universal triple, cross-cultural variation would be noise. If it were arbitrary, there would be no shared shape. The residual is the stable-yet-variable covariation of (bodily sensation, emotion, explanation) with culture.

An answer would look like a described arrangement: which relatum is ground-facing, which is a binding, which is a composition above it, and what culture changes without changing the underlying capacity. That description is bound here as an ordinary term so it can accrue a residual and be refused (Fig 5 :65, "make the sought-for shape an ORDINARY TERM").
