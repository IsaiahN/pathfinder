## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

1. **Sent up (x):** the verbatim figure set, chiefly Fig 6 :28-34 (two tracks, proto-instrument), Fig 9 :60 (filter versus witness), Fig 2 :29 (anchor), Fig 13 :133-139 (shape, honest stop).
2. **Abstraction (T_A):** the shorthand in `07`: unpushable thresholds are a reachability problem; run inward and outward separately; EWS rank but do not settle; deliver a shape; report unreachable rather than absent.
3. **Concretisation (T_E):** a researcher's concrete output for a named system, for example an interval for a freshwater tipping element with a stated lag-1 autocorrelation threshold.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- the **sampling relation** between the indicator window and the system's return rate (Dakos 2012 shows preprocessing can reverse a variance trend);
- the **mechanism type** (a noise-induced transition can occur before the saddle-node signature appears, so the indicator-to-mechanism map is lossy);
- the **ground identity** of the donor frame when an analogue method is imported, which the shorthand compresses into "transfer the method".

Conversely, one thing survives cleanly: a structure must be found in effect terms and the two tracks must be kept apart. That is the residue worth sending. R_T was **not** measured numerically, because no common ground exists across the systems; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is a condensed version of the metalaws" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
