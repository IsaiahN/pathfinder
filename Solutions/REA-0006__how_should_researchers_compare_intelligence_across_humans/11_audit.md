## Independent domain census

I redid the census from the residual line alone before relying on the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors, currency and anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the gap between a comparison score and what it claims to be about. Arity: many capacities per subject, so a vector indexed by slot, not a scalar. Symmetry: false. ⋛ is "a threshold relation between two quantities" (Operators :49), an ordered threshold, so swapping subjects across habitats changes the term. Scale: three, the agent, the habitat and channel, and the membrane between scales. A scalar rank is a symmetric collapse of this residual.
- **Domain 1, the measurement frame.** Actors: designer, test-taker, benchmark, judge. Currency: score and skill. Anchor: none that does not update unless imported from outside the test. Question type: a channel and anchor failure, not a measurement failure.
- **Domain 2, the capability and contact frame.** Actors: agent, habitat, ground, seat. Currency: contact and settlement. Anchor: the ground, which does not update. Question type: the contact question that replaces the substrate question.
- **Domain 3, the cross-scale comparison frame.** Actors: kernel, actors, currency, anchor at each scale. Currency: methods up, head starts down, per-slot residuals. Anchor: the ground at that scale plus the lossy transform. Question type: union of overlapping conditions, not a partition.
- **Order by dependency.** Describe the residual before choosing a frame; install an anchor and check the channel before scoring; refuse the scalar before minting a method; build instruments from worse instruments already returning something.
