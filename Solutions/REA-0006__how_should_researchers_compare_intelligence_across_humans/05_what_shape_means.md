## 1. A shape is a constraint, not a filler

The canonical README says the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel* (carried): "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. For this question the shape is: a per-slot comparison against a non-updating ground in a reproduced habitat, with the kernel fixed and the actors, currency and anchor named per domain. The thing the question asks for, one universal currency or scalar, is **not** filled by that shape. It is refused.

## 2. How the shape is obtained

Applied here: describe the comparison failure in effect terms first (a score that does not say where to look), then look across low-overlap fields. Comparative cognition supplies "kernel cognitive capabilities" (Colombo and Scarf, quoting D'Amato and Salmon); machine-intelligence evaluation supplies "skill-acquisition efficiency" (Chollet). These are shapes from frames whose closures differ, not imports that add a primitive to the framework.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51), with a source gate and a shadow test.

*They're Scanning Books* (carried): "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Also: "Declaring the primitives does not make them neutral. It makes the choice visible."

So naming a shared currency for humans, animals and machines would turn a visible choice into an invisible one. The six-term set is a guess; declaring a seventh for the sake of a rank is not licensed.

## 4. Why the record's usual move is the forbidden error

*The Hard Problem is About Source* (carried) gives the mechanism. Metamerism: an instrument reads green and "cannot comment on the source". One green light, yellow plus blue, RGB, CMYK, or a scheme not yet discovered all give the same reading. "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

A comparison score is the same kind of reading. Human judgment, a primate cognition battery, an ARC score and a chess rating can all return "high", while the sources differ: bought priors, a motivated subject, a reproduced habitat, or genuine contact with the ground. Naming "intelligence" as the source of the reading is the metamerism error. What is owed is a source-discriminating instrument, not a name.

*The Recursive Self-Improvement Trap* (opened this session): "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." This is why the protocol in `01` §5 demands separate anchors and low-overlap instruments rather than one pooled score.

## 5. Q: Does "shape, not a name" forbid naming capabilities at all? ANSWERED, with a correction to my own first pass

**First pass, now corrected.** I initially read the README's rule as a ban on naming any capacity in the comparison. That is wrong.

**Correction (kept visible).** The README's phrase governs a **missing** primitive, one not held in Γ. Naming a capacity that is already available in the frame, such as reflexivity, symmetry, transitivity, episodic memory or skill-acquisition efficiency, is a **binding from another frame** onto an atom the inquirer already holds. It is provenance work, not the invention of a new primitive, and it is not an import that moves the wall (Fig 6 :22: "IMPORT adds an atom, and the added atom is what expands the closure": a binding adds none). What remains forbidden is inventing a seventh kind, or presenting the binding as a derivation.

So Colombo and Scarf's "kernel cognitive capabilities" and Chollet's "skill-acquisition efficiency" may be named as bindings, with source and date recorded. What may not be named is *the* universal currency that ranks all three kinds, because no such primitive is held and Fig 13 :115 says "The set is closed. The arrangements are not. That gap is why import exists."

## 6. Consequence for the outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (opened this session): "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

A list of famous comparative psychologists, or of systems that already agree with the protocol, is the named collapse. The legitimate ask is the opposite: give the claim a budget to be tried, let the ground settle it, and ask what would refute it.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of any species or system and must be labelled as such. It cannot settle anything it reports on.

## 7. One-paragraph version

> "Shape" is the narrowed form of an answer you can state before you can name it. Here it is a protocol, not a rank: per-slot capability, a non-updating ground per domain, a reproduced habitat, low-overlap instruments, and a kernel that stays fixed while actors, currency and anchor change. The universal currency the question seems to ask for is a shape-not-a-name gap, reported as unreachable rather than filled. Naming a capacity already available in another frame is a binding with provenance; inventing a seventh primitive is forbidden. What would turn the shape into a name is a ground reading, never agreement or prestige.
