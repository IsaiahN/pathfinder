# Outreach draft: check the separator first, then decide whether the shape is worth reading

**Use:** one-to-one, or as a cover note attached to a submission through a public venue in `03_public_contact_points.csv`. **Not** for bulk send.

**Hard precondition:** do not send until the live type strains S3 and S4 in `01_figure_grounded_audit.md` §7 are stated plainly in your own words. If you cannot say them back, the offer collapses on contact.

---

**Subject:** One checkable separator for cross-species and cross-machine comparison

> Hi [name],
>
> I have one specific output I would like you to check against what you already know. I am not asking you to read the framework first, and I am not asking you to agree with it. If the output does not survive, there is nothing else to look at.
>
> **The output (`specified`, not `grounded`):** "how intelligent is this system?" is the wrong object of comparison. The framework's habitat figure replaces it with a different question: what makes a system capable, in which habitat, against which ground. Capability is a property of agent and habitat together, never of the agent alone. A test harness is a substituted habitat, so a synthetic solve proves wiring and never capability. What this yields is a protocol: describe the residual per capacity in effect terms first; enumerate the habitat for each subject; install a ground that does not move when a frame pushes on it; use two or more instruments that draw on disjoint evidence; compare the invariant loop and the per-domain actors, currency and anchor; keep verdicts per slot and never average them.
>
> **What I am not claiming:** that any one number ranks humans, animals and machines; that a shared benchmark gives a fair comparison; that human judgment is a legitimate anchor for a machine. A shared test is a shared meaning, which is efficient as a convention and disqualified as a verdict about the world. Human judgment is the right anchor for a question constitutively about people and only an instrument for a question about code, and instruments can be wrong on axes they do not measure. I am not claiming a common currency exists. The framework returns a shape here, not a name, and I record the absence rather than invent the currency.
>
> **What would refute the separator:**
> 1. One measure that ranks all three kinds on one scale, stays per-slot rather than averaged, has an anchor that does not move when a test designer pushes on it, and predicts a held-out ground reading at each slot.
> 2. A ground reading in which cross-kind differences persist after habitat, priors, sensory and motor access, motivation and attention are reproduced, with the difference attributable to the agent alone.
> 3. An instrument that reads intelligence off an agent independently of habitat and ground, and the ground pays for the reading.
>
> I wrote these down before sending this. If any one holds, I will retract the protocol. A one-line "this fails because..." is more useful to me than agreement. What would you count as a failure here? If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** the sources are below. The figures are the authority, not my summary of them.
> - Figures as verbatim text with line numbers (local extract): `FRAMEWORK/reference/03-FIGURES_TEXT.md`
> - Canonical usage rule and figures repository: https://github.com/IsaiahN/tether/tree/general-agent/figures
> - The eight-step loop and mode rule (local): `FRAMEWORK/figures/THE_FORMULA.md`
>
> **If you want to use the machinery:** the loop is in the figures link. Run it on a comparison you know well and can check against a ground. Write down what would refute your result *before* you run it, and label the mode of what you get. A reported failure is more useful to me than a reported success.

## Why this order

| the move | figure-grounded reason |
|---|---|
| Output first, theory second | Fig 10 :52: "Bring a characterised residual, never the source." Frames range against the ground separately (Fig 2 :45). |
| Do not ask for agreement | Fig 2 :35: "Alignment is triangulation, not negotiation. A mirror cannot correct you." |
| Pre-registered refuter | Written before the run, as a design instrument, not an honesty device. |
| Mode on every claim | `THE_FORMULA.md`: "Mode. general · specified · grounded. State which." |
| Shared test withheld as evidence | Fig 2 :41: agreement about a shared meaning is efficient for a convention, not a verdict. |
| No common currency asserted | Fig 9 :32: "you get a kind of thing, never the answer itself"; Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it." |
| Harness caveat stated before the claim | Fig 11 :70: "A test harness is a substituted habitat. Which is why a synthetic solve proves wiring and never capability." |
| No request for trust or prestige | *The Recursive Self-Improvement Trap*: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." |
| Offer the loop as a method, not an answer | Fig 4 :22: "Only methods cross up. Only head starts come down." |
| Ask the reader to state their own ground and refuter | Fig 5 :48: "Its own output is never a measure of success." |

## Note on receiving a reply

A reply is a conversation, never corroboration. If a reader returns a refutation, copy it into `11_audit.md` with provenance and re-evaluate it as if it came from any other source. Do not pool later agreement as evidence. Fig 2 :40: "agreement about the world is worthless when the agreeing frames share an evidence pool".
