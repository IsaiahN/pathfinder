## QUESTION

Decide, in effect terms, what the Tether says about the question: can emergent patterns be predicted from interaction rules when the components themselves are changing? Option A: answer yes, a macro pattern follows from the rules even as the cast changes. Option B: answer no, nothing is predictable once the cast changes. What each leads to: A commits to a rule-to-configuration shortcut the figures forbid and ignores that the reach can fall; B ignores the kernel and the closed set of kinds that survive component change. The figure-governed third option is a split: predict-kind is licensed, predict-name is not, and the report on failure is `unreachable`, not silence.

## VERDICT (from the figures)

The question is a union and must be split. Prediction of the **kind** of emergent pattern is licensed under component change, because the kernel does not change with size and the set of kinds is closed while arrangements are not. Prediction of the **exact macro configuration** is not licensed from interaction rules alone, because a compounding residual gives chaos, composition never adds an atom, and the reach can fall when the habitat updates. A macro prediction tied to one cast does not transfer unchanged to another. The framework returns a shape, not a name, and reports `unreachable` rather than silence when a search fails. Per-domain verdicts: reachability `specified` and triangulated; changing components `specified` and triangulated; verification `general` on the anchor rule and triangulated. This is a `specified`, ungrounded result; the two unqualified answers, yes and no, are both refused.

- **cost if wrong:** bounded and locatable. The answer is a shape with refuters, not a specific number, and each sub-claim names the figure line that would break it. The real cost is presenting a rule-to-name shortcut and spending the independence of outside readers by sending a recording instead of a generator, which Fig 2 :42 prices ("Buy independence in proportion to the cost of being wrong."). That cost is avoidable by leading with the split question and its refuter.
- **undoable:** yes. The unqualified readings are removable without touching the derivation; `07_the_tether_answer.md` and `08_expert_verification_packet.md` already remove them. No primitive has to be withdrawn and no claim is irrevocable.
- **reversed by:** a ground reading, not agreement. A general closed-form derivation from rules to exact configuration in a positive, amplifying residual regime would break the predict-name limit; a macro prediction that transfers unchanged across a changed cast would break the reach-falling claim; a system where the loop and naming rule change when only size or cast changes would break Fig 4; a source-discriminating instrument that names several rule/cast pairs giving the same macro reading would settle the source question. Until one of these fires, the verdict stands as `candidate`.
