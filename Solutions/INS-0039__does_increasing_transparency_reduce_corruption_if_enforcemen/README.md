**Question:** Does increasing transparency reduce corruption if enforcement remains weak?

**Source:** institutional questions.txt line 48 (scaffold record; question text verified in the source file as question 39, section 4).

**Mode:** `specified` on the substantive verdict, `general` on the structural shape. No measurement settles the magnitude, so nothing here is `grounded`.

**Status:** done

## What this package answers, in effect terms

The question is not one lever. It is a compound: a disclosure operation (transparency), an action operation (enforcement or sanction), and an outcome (corruption). The structural result is that disclosure extends perception and raises the live residual, but reduction requires the residual to be settled against an anchor that can act. Where enforcement is weak, the anchor is decoupled or captured, the dependency chain breaks below the perception link, and disclosure cannot pay the action bill. Expected effect on objective corruption is approximately zero or small; any measured effect is expected to concentrate in subjective (perception) measures. This is a simulated derivation, not a ground reading, and it cannot settle the empirical question it reports on.
