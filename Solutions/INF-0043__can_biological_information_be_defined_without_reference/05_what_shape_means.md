## 1. A shape is a constraint, not a filler

The canonical rule: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For INF-0043 the shape is not "information is mutual information" and not "information is selected-effect information." It is:

> any definition that closes the semantic slot must supply asymmetry, normativity, and non-ubiquity over a correlational base, and it must say whether the atom that does this depends on selection history.

That is a set of constraints. It does not pick a winner among teleosemantic theories.

## 2. How the shape is obtained here

- *Library of Babel*: "With each new term gained, you narrow the space by definition and deepen your vocabulary." Applied: starting from the word "information" as held in the statistical frame, the terms "function", "selected effect", "aboutness", and "normativity" arrive from an adjacent frame and narrow the space.
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30: "your words are borrowed too, so describe the effect rather than the cause." Applied: describe the missing atom by what it does (supply asymmetry and accuracy conditions), not by which philosopher's name it carries.
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." Applied: the first contact asks what a checker would expect to see if the three-slot claim were true.
- *Library of Babel* on stopping: "you will know that you are done because the finish line will also be the starting place." Applied: the loop stops when the semantic slot's residual stops registering against the discriminating cases, not when the bibliography looks complete.

## 3. The bundle passage is the direct analogue of Fig 9

*The Library of Babel* contains the sentence that most directly governs this question: "Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually to find their answers and then combine them in a satisfactory way."

Fig 9 :54: "And when the split lands on a union rather than a partition, unbundle before you search again." Fig 9 :55: "A bundled problem is usually a union of overlapping conditions, not a list of separate ones."

These are two descriptions of the same move from very different starting points. The split in INF-0043 is not an avoidance tactic. It is the shape of the answer: three slots with three verdicts. A single "yes" would aggregate away the live signal (Fig 1 :22).

**Falsifier for this reading:** show that the correlational and semantic senses share one set of necessary and sufficient conditions, so the split leaves no residue and a single definition clears every case. Then §1 of `01_figure_grounded_audit.md` falls.

## 4. What licenses a name, and the narrowing I owe my own earlier reading

Two things license a name, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." Here the ground would be a discriminating case (a signal with the right statistics but no function, or a function without information), not a vote among definitions.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51), with a source gate and a shadow test.

**Correction to my own §1 as first drafted.** I initially wrote that "shape, not a name" forbids naming function as part of the answer. That overstates the rule. The canonical phrase governs a *missing* primitive, one not held in the frame that is searching. Function is not missing from biology; it is missing from the statistical frame. Naming it as an import is a provenance record, not the invention of a new primitive. What is forbidden is claiming that the statistical frame could have composed it, or pretending the import needs no source gate. Both the limit and this narrowing are kept visible so neither is quietly lost. Triangulated (canonical README + Fig 6 :23).

## 5. Why the metamerism passage matters for a definition of information

*The Hard Problem is About Source* gives the mechanism: "If several paths create the same behavior, then behavior is a projection with lossy information (it cannot define consciousness in full)." An instrument reads green and "cannot comment on the source" (one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered). "An instrument that can't distinguish these cases demonstrates its own inadequacy, it cannot claim anything substantial about what is being measured or what causes it." It was the spectrometer, not an argument, that resolved the source.

Applied here: a correlational measure reads a sequence and cannot comment on whether the pattern is a message, an accident, or a function. Naming the source from that reading is the metamerism error. What is owed is a discriminator, not a name. Artiga (2024) supplies the biological instance: correlational information is symmetric, non-normative, and ubiquitous, so it cannot by itself distinguish a signal from an accident. The Swampman case is another discriminator: same molecule-by-molecule structure, different selection history.

**Falsifier:** produce an instrument or measure that discriminates message from accident from function on the same correlational reading, with no added atom. That would make the metamerism point inapplicable and change the semantic slot's verdict.

## 6. Two consequences for this folder

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A definition accepted because a famous philosopher proposed it is the named collapse. The legitimate ask is a discriminating case that can refuse it. The same essay adds that "evolution is... an instance of the underlying code, not the code itself", which supports keeping "evolution" as a slot separate from the general loop rather than treating it as the definition of information. That is a framework-author claim and carries high overlap, so it corroborates but does not decide.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post" and "the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01_figure_grounded_audit.md`, this file, and `11_audit.md` are simulated derivations checked for internal consistency against the figures. They are **not** tests of a definition and must be labelled as such. None of them can settle the question it reports on.

## 7. Summary of the canonical reading

For INF-0043, "shape" means: a per-slot constraint set that a definition must satisfy, obtained by splitting a conflated question, described in effect terms so any checker can test it, with no name for the winning theory until a discriminating case settles it. The three slots, the metamerism warning, and the prestige rule are all parts of that shape. The stop is honest: where the discriminating cases run out, the answer stops and records the lineage.
