## VERDICT (from the figures)

The question is a union and the answer is per slot. A correlational definition of information over sequences and signals is reachable inside the statistical closure with no appeal to evolution, function, or survival. A semantic definition carrying aboutness, asymmetry, normativity, and accuracy conditions is not reachable there: mint composes inside the closure and never adds an atom, so the function atom must be imported from the biological frame with provenance recorded. Once function is required, the three references in the question are not one condition: organizational function accounts make no appeal to selection history, etiological accounts do, and survival or fitness is a currency inside one frame. The framework returns this shape and refuses to name a winning theory. This is a `specified`, ungrounded, candidate result.

- **cost if wrong:** bounded and locatable, because every slot has a written refuter and the figure lines are quoted verbatim. The avoidable cost is averaging the three slots into one word, which discards the live signal (Fig 1 :22), or importing a function atom without provenance, which spends an outside frame's independence (Fig 2 :42 "Buy independence in proportion to the cost of being wrong.").
- **undoable:** yes. A failing slot can be withdrawn without touching the others or the framework. The import can be recorded or removed, the dependency order can be re-censused, and no primitive needs to be discarded. `07_the_tether_answer.md` and `08_expert_verification_packet.md` already state the separable pieces.
- **reversed by:** a ground reading, not agreement. A derivation of normativity and asymmetry from correlation alone with no added atom would make S2 reachable; a proof that the two senses have identical necessary and sufficient conditions would collapse the union; a single non-evolutionary, non-selection-based function account that still yields normativity would merge the S3 readings; a re-census admitting normativity as a substrate primitive would make the import vacuous; and a discriminating case (Swampman, function without information, signal without function, functional indeterminacy) that all definitions fail equally would show no ground can settle the choice. Until one of these fires, the verdict stays `candidate`.
