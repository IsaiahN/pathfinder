## 1. A shape is a constraint on a missing thing, not a filler and not a name

`FIGURES_README_canonical.md` states the limit: the framework reports *"what a missing thing would
have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer
itself"*. Fig 13 :134-135: *"Unreachable is a verdict here, not a silence,"* and *"It cannot say which
primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel* (fetched 2026-11-23): *"You can cut your search short if the set of books
returned is small and descriptive enough that it provides a general shape of the answer that
satisfies your question."* And: *"The books that you are returning in your searches need to be tested
or ranged against the problem you want answered in order to steer the direction of the next search."*

So a **shape** here is the form a missing principle must have before anyone can name it. For this
question the shape is:

> A term P such that (i) P reproduces every quantum prediction already settled at accessible
> complexity, (ii) P predicts a quantitative deviation at the untested complexity frontier, with a
> stated circuit depth, fidelity and noise model, and (iii) P composes over the settled quantum
> closure rather than deleting it.

That is a constraint set. It is not a candidate theory. Naming a specific replacement for QM would
be a name where the framework returns a shape, and it would violate Fig 13 :135.

## 2. How the shape is obtained here

- *Library of Babel*: bootstrap vocabulary from what is closest, then recurse. *"With each new term
  gained, you are able to narrow the space by definition and deepen your vocabulary."* Here the
  closest held vocabulary is "deviation from a prediction", which is already an instrument concept,
  not "new principle".
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it
  in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than
  the cause"*. The effect is a fidelity curve that departs from the QM prediction; the cause
  ("new principle") is what is in question, so it cannot be used as the search term.
- *Decoding Tacit Knowledge* (quoted via the local exemplar, not re-fetched this session): *"When
  contact isn't possible, the best you can send is a plain description of what you'd expect to see,
  because anyone can check that against the world."* That is why section 1 states the shape as an
  expectation anyone could test.
- *Library of Babel* on stopping: *"You will know that you are done because the finish line will also
  be the starting place, as there is nowhere else to search and nothing else that can describe the
  answer better."* Here we are not done, because the deviation has not registered. The honest stop
  is a recorded open residual, not a filled slot.

## 3. What would license a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A
   gate is not the ground."* `FIGURES_README_canonical.md`: the framework *"stops at the limit of what
   the available instruments can distinguish, and records the lineage so the stop is honest."* For
   this question the instrument is an echo or verification protocol at the complexity frontier.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a
   source gate and a shadow test. A new physical principle is exactly such an import.

*They're Scanning Books When They Should Be Studying Nature* (fetched 2026-11-23) sharpens the second
route: *"The real import is not a new term in the existing space. It is a new dimension of the space."*
And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes;
another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not
make them neutral. It makes the choice visible."* This matters here: a claimed "new physical
principle" is a new axis, not a new arrangement of the existing ones. Quantum advantage is an
arrangement, so it cannot by itself be that import.

## 4. Why "new principle" must be bound before the run

*The Recursive Self-Improvement Trap* (fetched 2026-11-23): *"the output is only as good as the
validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* Formula
step 2 names the exact failure:

> *"AND THE LIMIT: a frame searching for an answer of a given SHAPE holds that shape as a PREFERENCE,
> not a term. Unbound, predicting nothing, no residual - so nothing above can see it."*

If we leave "new physical principles" as a preference, the loop cannot refuse it: it predicts
nothing, so it accrues no residual, so it can never be checked against the ground. Writing the shape
in section 1 as an ordinary term is the remedy. Its residual is currently zero mass on the device
slot, because no deviation has been registered. By Fig 5's SUPPORT guard, *"the gap has real mass
somewhere"*, nothing can be minted on that basis.

## 5. Correction to my own earlier framing

I initially wrote this section as if "shape, not a name" forbade all naming in the solution. That
overstates the rule. The README says *"what a **missing** thing would have to look like (a shape, not
a name)"*, so it governs a primitive not held in Γ. Naming the six held terms is not forbidden; naming
a seventh as if the framework derived it is. Here the distinction cuts the other way from the
exemplar: the new principle is by definition *not* among the held terms, so the ban applies in full.
What remains legitimate is naming the **shape**, which is a constraint on the missing term, and
naming the **instrument** that would register it (echo test, verification protocol). Both are
recorded above. The earlier overstatement is preserved here rather than silently erased.

## 6. Two consequences for this answer

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (fetched 2026-11-23): *"Prestige
must never be allowed to validate an action directly... Prestige can fund an action. It can give an
action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground
Maintainer must be blind to prestige."* A list of famous advocates for "new physics" spends the
independence of the people asked to check it. The legitimate ask is for a refuter and a measurement.

**My audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an
approximate answer/output with the formula found in the architecture post... However, the truly
testable output would need to be derived from the real architecture or working the formula yourself."*
So `01_figure_grounded_audit.md`, this file and `09_watson_answer.md` are simulated derivations
checked for internal consistency against the figures. They are not tests of quantum mechanics and
cannot settle whether new principles are needed.
