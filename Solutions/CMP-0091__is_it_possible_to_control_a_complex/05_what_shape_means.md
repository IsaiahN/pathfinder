## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13 :134: *"Unreachable is a verdict here, not a silence"*, and it *"cannot say which primitive is missing, because naming it would mean already holding it"*.

From *The Library of Babel*, read this session: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For this question, the shape is the four-condition structure from `01_figure_grounded_audit.md` §0: an anchor, a lever, a channel, and an import path when needed. That structure constrains any acceptable answer about controlling a networked system. It does not name a specific controller, algorithm, or driver-node set. "Anchor + lever + channel + import" is a shape. "Control the system with pinning control at nodes 7 and 12" is a name, and the framework does not supply it.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary already held that is closest to the thing, look for recurring new terms that overlap with it, recurse. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."* Applied here: the held vocabulary is residual, anchor, habitat, import; the recurring new terms from the control literature are driver nodes, input-output data, observability, model-free control.
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* So the question is cast in effect terms: "drive the target reading to a value that does not depend on the controller's model," not "construct a full state observer."
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is why the outreach item leads with an expected observation (the lever changes a per-node reading) rather than with the framework.
- *Library of Babel* on stopping: the answer is reached when *"the finish line will also be the starting place"*, and the paradox is that by then you have *"composed the answer through the process of locating it."*
- The question is also a **union**, so *Library of Babel* applies its own split rule: *"Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually"*, which matches Fig 9 :55-57.

## 3. What licenses a name

Only two things, both outside the shape:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

In this question, a specific lever (say, pin a small set of low-degree nodes) is licensed only if a measurement at the ground shows that it drives the target when applied. The network-science literature supplies candidates, but importing one carries a provenance record: which frame it came from, what residual it explains, and what independence was spent. Convergence from two fields is one witness if they share an evidence pool (Fig 2 :40).

## 4. Why "full internal understanding" is the specific forbidden error

*The Hard Problem is About Source*, read this session, gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*. Several paths can create the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information (it cannot define consciousness in full)."* *"An instrument that can't distinguish these cases demonstrates its own inadequacy, it cannot claim anything substantial about what is being measured or what causes it."* And the resolution: *"The answer is unreached until a better instrument exists"*, proven *"not by argument, but by the arrival of a better instrument."*

Applied here: demanding the full internal structure before controlling is demanding that the projection disclose its source. A controller's readings (node states, outputs) do not determine the internal mechanism. Several internal structures can give the same input-output behavior. The requirement to "understand fully first" is therefore a demand for a source-discriminating instrument, not a logical prerequisite for action. What is owed is the instrument, or an import from a frame that already discriminates; it is not a ban on intervening.

*The Recursive Self-Improvement Trap*: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* A claim that control succeeds because the model says so is self-validation. The ground must pay.

## 5. Shape, contact and correction

*Decoding Tacit Knowledge* supplies the third term. It says understanding is rebuilt through contact: *"trying, being corrected, and trying again, in both directions."* It cites Fig 11 :40: *"An improvement that does not change contact changes nothing, however much it improves."* It explains drift: two frames that only check each other *"drift, and they drift together, so neither notices"*, and cites Fig 2 :35: *"Alignment is triangulation, not negotiation. A mirror cannot correct you."*

For control, this means a controller that updates only against its own model is a mirror. Correctness requires a reference neither the controller nor the model can move, which is exactly C1 in the audit. The round trip matters: *"An understanding that's never checked feels exactly as certain as one that has been"* (from the essay's reading of Fig 4 :30). So a model that has never been corrected against the ground is not evidence of control.

## 6. Prestige is not action, and this audit is a simulation

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of well-known control researchers who agree with the shape is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* It calls such output *"simulacra."* So `01` is a simulated derivation, checked for internal consistency against the figures. It is **not** a test of the claim and cannot settle anything it reports on. The world sources in `09_watson_answer.md` are real and were read, but they corroborate a shape; they do not settle whether a particular networked system is controllable.

## 7. The one-paragraph version

A shape is the narrowed form of an answer you can state before you can name it. Here it is the four conditions: a ground anchor that does not move with the model, a lever introduced into the habitat that changes a per-node residual, a channel that keeps readings unpooled, and an import path when the lever is not derivable locally. The framework does not name the lever, because naming it would mean already holding it; which lever works is a `gap` to be closed by measurement. The specific error the question invites is treating full internal understanding as a prerequisite, which is a demand that a lossy projection disclose its source. What is owed is a better instrument or a provenanced import, not a complete model first.
