## Independent domain census (written from the residual line alone)

I redid the census before relying on the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the gap between the controller's prediction and what the networked system does, `R = |Γ(b,a) - o'|`, indexed per node. Arity: controller, action, observation, plus a structure operand, so four places rather than three. Symmetry: the target is a threshold comparison, not a symmetric join; interventions are ordered, and a feedback-controlled system is a cycle rather than a chain. Scale: node loop, network collective, membrane between controller and system. I derived these from Fig 12 :70, :76, :85, :121 and Fig 1 :19, not from the primary's table.
- **Domain 1, controller loop and model.** Actors: controller, `Γ`, `b`, action, per-slot `R`. Currency: residual reduction at the ground. Anchor: the measured target variable. Question type: what may count as the metric for control.
- **Domain 2, system as habitat.** Actors: nodes, edges, conditions, relations, introduced levers. Currency: contact, cascade, introduction. Anchor: what the ground returns when the system runs. Question type: where the controller's power actually sits.
- **Domain 3, reach and knowledge limit.** Actors: frames, atoms, closure, imports. Currency: reach versus library. Anchor: ground verification of an imported lever. Question type: what a missing lever is and where it can come from.
- **Domain 4, verification channel.** Actors: instruments, metrics, percepts, seats. Currency: maintained contact. Anchor: the ground, which does not decay. Question type: how control is lost.
- **X1, full internal understanding as prerequisite.** No actors, no currency, no anchor. A preference, not a term. Not a domain.
- **X2, negotiation with the model.** Absorbed into Domains 1 and 4.
- **X3, sealed room.** Refused; no frame is a sealed room.

**Union, not partition.** C1 AND C2 AND C3, plus C4 when a lever is imported, with overlaps at the C2/C3 intersection. **Order by dependency:** measure, state objective, plan lever, carry method (Fig 3); refuse the completeness preference before minting (formula step 2).

My census matches the primary's four domains and its union reading. Where the primary derived Domain 2 from Fig 11 and Fig 13, I derived it from Fig 12's cycle and bond typing plus Fig 1's per-slot indexing. Different starting figures, same domain boundaries: low overlap between routes within the framework, so the agreement is weak but not circular in structure. It is still one evidence pool.

## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, and Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

2. **Abstraction (T_A):** the shorthand carried in `07_the_tether_answer.md`: "anchor + lever + channel + import; completeness is a filter; control is a cycle."
3. **Concretisation (T_E):** a concrete claim about a network, for example "pin a small set of driver nodes and the target will follow."

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- the **identity of the anchor**, which the shorthand leaves as "the target" but which must be a specific unmoving measurement at the ground;
- the **source gate and shadow test for the lever**, which the shorthand compresses into "import" and which a concrete claim must supply with provenance;
- the **per-slot indexing**, which a flattened shorthand easily turns into a global control score, exactly the aggregation Fig 1 :22 warns about.

Conversely, one thing survives cleanly: full internal understanding is not the metric, and enlarging a model without changing contact does nothing. That is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating the formula as identical to the figure set would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a recorded gap, which is what `09_watson_answer.md` states.
