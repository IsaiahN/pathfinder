## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E o T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

2. **Abstraction (T_A):** the shorthand carried in `07_the_tether_answer.md`: no symbol atoms needed, no central processor, attribution settled by an instrument, existence is a gap.
3. **Concretisation (T_E):** a concrete claim such as "a continuous chemical reaction network is a computation without symbols or a central processor".

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- the **status of a specific substrate**. The figure claim is structural; calling a chemical network a computation is an import requiring a source gate and a shadow test (Fig 6, Fig 8). The shorthand can look like a name when it is only a shape.
- the **finite-precision constraint** from the physics source. The shorthand "no discrete symbols" can be heard as "infinite precision", which the Landauer-bound result forbids. The distinction (primitive versus instrument constraint) must be re-stated explicitly or it is lost.
- the **rank/sequence distinction**. "No central processor" can be heard as "no ordering at all", which would contradict Fig 12 :111. The round trip must restore: sequence required, rank forbidden.

One thing survives cleanly: discreteness is a derivative and there is no top rung. That is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the figures and the formula are the same thing in fewer words" would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
