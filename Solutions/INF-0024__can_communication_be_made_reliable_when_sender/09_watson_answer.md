## QUESTION

Decide, in effect terms, what the Tether says about the question: can sender and receiver communicate reliably when they do not share a stable code or common context? Option A: answer "yes" by pointing to Shannon's coding theorem. Option B: answer "no" by pointing at the absent code. Option C: split the residual into a fact-bearing layer and a meaning-bearing layer and answer each separately. What each leads to: A silently answers a different question, where the code is fixed in advance; B is a verdict from absence, which the figures forbid without a search; C gives a checkable scope boundary, a mechanism shape and four written refuters. The figures decide C.

## DOMAIN CENSUS

R by arity, symmetry and scale, then one line per domain giving actors / currency / anchor, partition or union, and order by dependency.

- **R (the residual).** A signal arrives; the receiver's prediction from it does not match the sender's meaning, and the residual on the live slot stays positive as more of the same signal is sent. Arity: two frames plus a reference. Symmetry: the exchange is asymmetric, sender selects and receiver reconstructs. Scale: one exchange is a step, a vocabulary-changing conversation is a cycle, and the checking arrangement is a seat. Fig 9 :22 gives the descriptors *"arity · symmetry · scale"*. Fig 9 :4-5 requires the split: *"Disagreements that do not shrink with effort, where each rule keeps working well on a different subset, are not one hard question but several well-formed ones. Split it rather than search."*
- **Domain A, the physical channel.** Actors: signal, noise, transmitter, receiver. Currency: bits per second, error probability. Anchor: measured channel output against a fixed codeword. Nameable anchor, so this is a domain.
- **Domain B, the fixed-code fact layer.** Actors: encoding, decoding, world state. Currency: reproduced message, equivocation. Anchor: the world state the message denotes, which neither frame moves. Nameable anchor, so this is a domain.
- **Domain C, the no-shared-code seam.** Actors: frame A with library Γ_A, frame B with Γ_B, the signal. Currency: agreement or disagreement on meaning. Anchor: none until an invariant is built. Not a domain until an anchor exists; it is the defect the question is about.
- **Domain D, the convention layer.** Actors: the two frames coordinating. Currency: mutual expectation, common ground. Anchor: consistency of the convention, not truth. Nameable in its own terms and legitimate for a convention, because Fig 2 :36 says *"An anchor is legitimate when the question is constitutively about it."*
- **Domain E, the checking seat.** Actors: the ground, two frames, an outside reader. Currency: residuals and refutations. Anchor: the ground. Nameable by construction.
- **Partition or union.** A union. B and D overlap in every real exchange, and the overlap is a compound with its own loop. Fig 9 :54-57: *"a case in two conditions is not a harder case of either. It stops being a mixture and becomes a specific compound."* Unbundle before search.
- **Order by dependency (Fig 3).** Seat E first, then seam C, then fact B and convention D separately. Within a single exchange, the chain breaks at the vocabulary link: Fig 3 :27 *"A link with no instrument is not a link that works. It is a link nobody has looked at."*

Strain test applied. An earlier reading treated the fact and meaning questions as one domain and strained Fig 2 :40 to cover both. Re-census shows :40 governs verdicts and :41 governs conventions, different quantities, so no contradiction remains. Shannon's scope statement was re-censused into B rather than read as a verdict on C. Matches the canonical rule that an apparent contradiction means the domain was misidentified.

## VERDICT (from the figures)

The bundled question does not receive one verdict. Where a code and channel statistics are fixed in advance, reliable reproduction of a selected message is available; Shannon's result governs that domain and is not disputed here. Where the code itself is missing, no frame can derive the other's vocabulary from its own library. What crosses is an effect description checked against something outside both frames, carried by a two-way round trip in which the receiver shows what it took the message to mean. The resulting shared meaning is a convention, a legitimate product that cannot be promoted to a fact anchor. The answer is therefore a shape and a scope boundary, not a protocol: a shared invariant built by contact, checked against a reference neither frame can move, with four written refuters and named discriminators. The claim is `specified`, ungrounded, candidate. Whether a specific pair of disjoint frames converges at a given budget is a gap, not a silence: *"Unreachable is a verdict, not a silence"* is honoured by recording it as unreached rather than inventing a protocol.

- **cost if wrong:** bounded and locatable. The verdict keeps its mode, names the domains and states refuters before the conclusion, so an error is findable rather than invisible. The real cost is spending the independence of an outside reader by sending a conclusion instead of a characterised residual. Fig 2 :42 says *"Buy independence in proportion to the cost of being wrong."* That cost is avoidable by leading with the split claim and the four refuters. A second cost is practical: treating a convention as a fact anchor would let a pair of frames drift together without noticing (Fig 2 :34).
- **undoable:** yes. The scope boundary is removable without touching the derivation: if a discriminator fires, the affected domain verdict is withdrawn and the shape is rewritten. No primitive is withdrawn, no data is deleted, and a sent claim can be superseded by a corrected packet. The refuters in `01` §4 are written so the reversal is mechanical rather than rhetorical.
- **reversed by:** a ground reading, not agreement. The one-way derivation test, the repetition test, the self-anchoring convention test or the echo test in `07` §4 would each reverse the corresponding sub-claim. A source-discriminating instrument showing that a correct decode identifies the mechanism would remove the metamerism objection. A figure re-census that admits a revisable convention as a legitimate fact anchor would reverse the domain split. Until one of these fires, the verdict stands as `candidate`.
