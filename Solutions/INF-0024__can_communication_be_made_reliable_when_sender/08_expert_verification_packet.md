# Expert verification packet : the Tether on communication without a shared code

**What this is:** a claim in a form a communication theorist, cognitive scientist or coordination theorist can check. Mode, derivation and refuters are stated before the conclusion, so a reader knows what to look for and what would settle it.

**Mode: `specified` on the verdict, `general` on the shape. Not `grounded`.** This is a scope boundary and a mechanism shape, not a measurement or a protocol. Simulated derivation checked for internal consistency against the figures, not a ground reading (`05_what_shape_means.md` §6).

## 1. The claim, in one paragraph

"Can sender and receiver communicate reliably without a shared code or common context?" is two questions with different anchors and must not be averaged. Where a code and channel statistics are fixed in advance, Shannon's result supplies reliability for reproducing a selected message. Where the code itself is missing, neither frame can derive the other's vocabulary from its own library. What crosses between them is an effect description that both can check against something outside themselves, carried by a two-way round trip; the result is a convention, a legitimate product that is not a truth verdict. Only a reference neither frame can move decides facts. The claim is the shape and the scope boundary, four written refuters and the instruments that would fire them. No protocol is named.

## 2. Three checkable sub-claims

### C1 : The split is required; the yes/no form is a category error

- **Statement:** the fact-bearing question and the meaning-bearing question have different anchors and cannot receive one verdict.
- **Source, verbatim:** Fig 9 :4-5 : *"Disagreements that do not shrink with effort, where each rule keeps working well on a different subset, are not one hard question but several well-formed ones. Split it rather than search."* Fig 2 :29 : *"An anchor is whatever settles the question and does not change its answer because of what any frame thinks."* Fig 2 :41 : *"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"*; :40 : *"disqualifying for a verdict: agreement about the world is worthless when the agreeing frames share an evidence pool"*.
- **Outside check:** Claude Shannon, "A Mathematical Theory of Communication", 1948: *"These semantic aspects of communication are irrelevant to the engineering problem."* This is a scope statement, not a dismissal of meaning.
- **Refuter:** exhibit a single instrument and a single residual that measures both fact reproduction and meaning coordination on the same slot, such that a verdict on one is a verdict on the other.

### C2 : Repetition and redundancy cannot close a vocabulary gap

- **Statement:** repeating or re-encoding a signal inside a fixed code reduces channel error but cannot install a missing term in the receiver, because contact is unchanged.
- **Source, verbatim:** Fig 11 :40 : *"An improvement that does not change contact changes nothing, however much it improves."* Fig 8 :32 : *"no search, however long, adds an atom."* Fig 3 :27 : *"A link with no instrument is not a link that works. It is a link nobody has looked at."*
- **Refuter:** a case where a meaning residual that is open on the first transmission closes after repetitions within the same fixed code and with no change in the receiver's library. This is testable; it is the second discriminator in `07` §4.

### C3 : Two-way contact with effect descriptions is the cross-frame path, and it builds a convention

- **Statement:** what travels is a description in effects, not a private vocabulary; the receiver must show what it took the message to mean; the resulting shared meaning is a convention and cannot serve as the fact anchor.
- **Source, verbatim:** Fig 6 :30 : *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 4 :30 : *"So take the round trip and measure the gap. Without it you are navigating by dead reckoning: confident about a position nobody checked."* Fig 10 :18 : *"a declared meaning is not a grounded one"* and :19 : *"→ install what can be violated"*. Fig 2 :43 : *"a convention that decides an outcome has stopped being one."*
- **Outside check:** Clark and Brennan's grounding account (1991, via the entry opened this session) makes a contribution complete only when the addressee gives evidence of understanding. Vanderschraaf and Sillari (SEP 2023) report that Lewis himself later said "common knowledge" was unfortunate because there is no assurance the proposition is true.
- **Refuter:** two frames with disjoint vocabularies derive a shared mapping for a novel domain from a one-way signal alone, with no round trip and no external reference; or a pair with no separate experience builds a shared vocabulary that still predicts a measurement neither had seen.

## 3. What is explicitly not claimed

- Not that reliable communication is impossible; no search for a universal code was run (*"a search that finds nothing is never a proof of absence"*, Fig 8 :39).
- Not that Shannon's coding theorem is wrong; it governs the fixed-code domain and is silent on the missing-code domain.
- Not that redundancy never helps; it helps inside a fixed code.
- Not that any code, alphabet, grammar or protocol is the answer (Fig 9 :32: *"you get a kind of thing, never the answer itself"*).
- Not that agreement between two frames is corroboration (Fig 2 :40).
- Not `grounded`. No experiment or channel measurement in this folder settles convergence for a specific pair of frames.
- Not that the simulated second seat in `11_audit.md` is an independent witness. It shares this folder's evidence pool.

## 5. What would settle it

A discriminator, not more agreement. The four in `07` §4 are: one-way derivation test, repetition test, self-anchoring convention test, echo test. The structural reason is the metamerism argument in the Hard Problem is About Source essay: *"If several paths create the same behavior, then behavior is a projection with lossy information."* A correct decode does not identify the mechanism. An instrument that separates the mechanisms is owed.

## 6. What an expert can check in twenty minutes

1. Read Fig 9 :4-5, Fig 2 :29 and :40-41, and Fig 11 :40. Four short passages. Decide whether the split is a real distinction in your field or an artifact of this framework.
2. Check C2 against what you know about error correction: does any fixed-code mechanism install meaning in a receiver that lacks the term? If yes, the refuter has fired.
3. Check C3 against the grounding and coordination literature: is a shared invariant built by two-way contact, or is one-way transmission at a fixed code sufficient in the cases you know?
4. Name one instrument that would distinguish a shared-code decode from a contact-built convention, or say why none is possible. This is the discriminator the packet is asking for.
5. Send the refutation. A failure is more useful than an endorsement. If you are curious about the source after recording a verdict, the links in `02_outreach_email.md` are there; the figures, not the summary, are the authority.
