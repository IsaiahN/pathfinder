## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :136: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From the Library of Babel essay: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For INF-0024 the shape is: *a shared invariant, built by contact, that both frames can range against separately and that can be violated*. A particular protocol, alphabet, error-correcting code or "universal grammar" would be a name, not a shape.

## 2. How a shape is obtained here

- **Library of Babel**, proximity method: use the vocabulary you already have that is *"closest to the thing"*, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- **Fig 6 :30**: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* **Fig 9 :30-31**: *"your words are borrowed too, so describe the effect rather than the cause."*
- **Decoding Tacit Knowledge**: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is the shape as a checkable effect statement, not a definition.
- **Library of Babel** on stopping: the answer is reached when *"the finish line will also be the starting place"*, with the paradox that by then you have *"composed the answer through the process of locating it."* For this question that is exactly the convergence of a convention: the shared terms are built during the search, so finding them and making them are one process.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The canonical README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23: *"No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs"*), with a source gate and a shadow test.

For INF-0024 this means: neither "Morse code" nor "common knowledge" nor "Shannon coding" is licensed as *the* answer to the no-shared-code case. Each is a name drawn from a frame with a fixed code. A name would be licensed only by an experiment showing that a concrete mechanism closes the residual for two specific frames with disjoint libraries, with the provenance of the mechanism recorded.

## 4. Why the bundled yes/no is the specific forbidden error

The Hard Problem is About Source essay gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*; one green light, yellow plus blue, RGB, CMYK, or a scheme not yet discovered can give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* The reading does not determine the source. *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

Applied here: "the receiver decoded the message correctly" is a reading. It does not tell you whether the message was decoded from a shared code, from a convention built by contact, or from a lucky guess. Several sources give the same observable behavior. Asking the single observable to settle which mechanism operated is the metamerism error. What is owed is a discriminator (a ground test that separates the mechanisms), not a verdict from the reading. The four refuters in `01` §4 are written as exactly such discriminators.

The Recursive Self-Improvement Trap essay: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."*

## 5. Q: does "shape, not a name" forbid naming the mechanism here? ANSWERED

**No, with a boundary.** The canonical phrase is *"what a missing thing would have to look like (a shape, not a name)."* Its subject is a missing primitive, one not held in Γ. The mechanism this solution names, two-way contact with effect descriptions, is not a new primitive: it is a composition of terms already in the framework (closure, contact, round trip, ground, independence). Naming it is a binding onto held atoms, not the invention of a seventh term, and claiming it would "move the wall" would be wrong (Fig 6 :22: *"IMPORT adds an atom, and the added atom is what expands the closure"*; this one adds none).

What remains forbidden is claiming the shape selects a unique protocol. Fig 13 :75 requires *"a structure, time"* between states but does not select among the three structures it holds; analogously, Fig 6 :23 requires contact with a differing closure but does not select a particular code or grammar. The slot stays open until a ground settles it.
