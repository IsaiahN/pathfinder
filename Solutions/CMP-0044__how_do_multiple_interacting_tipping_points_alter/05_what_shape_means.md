## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns `what a missing thing would have to look like (a shape, not a name)`. Fig 9 :32 `you get a kind of thing, never the answer itself`. The figures text at Fig 13 says the system can report that an answer is out of reach with the library as it stands, and `It cannot say which primitive is missing, because naming it would mean already holding it.`

From *The Library of Babel* (carried quote): `You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question.`

For this question a **shape** is therefore the answer form you can state before you can name the coupling strength or the dominant topology: coupled thresholds form a union compound, coupling is a signed bond, the sign of the loop decides cascade closure, consequences are indexed per slot and can be third order, and the universal number is not returned. A shape is not a probability. `Risk rises when tipping points interact` is a name-shaped claim masquerading as a shape; `a union of overlapping threshold conditions whose coupling signs decide loop closure` is a shape.

## 2. How the shape is obtained

- *Library of Babel* (carried): use the vocabulary already closest to the thing, look for recurring new terms that overlap with it, recurse. `With each new term gained, you narrow the space and deepen your vocabulary.`
- Fig 6 :30 `The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms.` Fig 9 :30-31 `your words are borrowed too, so describe the effect rather than the cause.`
- *Decoding Tacit Knowledge* (carried): `When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world.`
- Applied here: describe the effect (a lever clearing one condition leaves intersections standing; a cascade closes only for one sign; the live slot hides in the average), then look for the frame. Do not start by naming climate tipping elements and then mapping them onto bonds. That inversion is the apophenia named in *They're Scanning Books* and refused in F6 of the exemplar's audit.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: `the ground settles it. Verified only by what pays. A gate is not the ground.` The README says the framework `stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest.`
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

For this question, a named coupling strength, a named initiator element, or a named critical coupling value would need one of those. The world literature supplies candidate names (ice sheets as initiators, AMOC as mediator, in Wunderling et al. 2021), but those are bindings from the earth-system frame, not derivations from the six-term set. They carry provenance and nothing more.

*They're Scanning Books* (carried): `The real import is not a new term in the existing space. It is a new dimension of the space.` Also: `A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six.` And: `Declaring the primitives does not make them neutral. It makes the choice visible.` So the six-term substrate is a visible guess, not nature's own roster, and no particular tipping element is privileged by it.

## 4. Why the "universal number" is the specific forbidden error here

*The Hard Problem is About Source* (carried) gives the mechanism. Metamerism: an instrument reads green and `cannot comment on the source`. One green light, yellow plus blue, RGB, CMYK, or a scheme not yet discovered can give the same reading. `If several paths create the same behavior, then behavior is a projection with lossy information.` And: `An instrument that can't distinguish these cases demonstrates its own inadequacy.` It was the spectrometer, not an argument, that resolved it.

A single systemic risk index is the same metamerism error. Additive accumulation, a single reinforcing loop, a clustered synchronous crossing, and a three-step contact cascade can all produce the same elevated index. The index cannot comment on the source. What is owed is a discriminator instrument (one that separates sign, arrangement and order), not a more precise number.

*The Recursive Self-Improvement Trap* (carried): `the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself.`

## 5. Q: does "shape, not a name" forbid naming a coupling topology? Answered with a correction

**Short answer: no, with a boundary.**

- The figures README's phrase is `what a missing thing would have to look like (a shape, not a name)`. The subject is a primitive not held in `Γ`.
- Network, cycle, threshold comparison and gradient are already held: network is one of the six structures (Fig 13 :24), cycle is one of Fig 12's four structures (Fig 12 :121), and `⋛` is in the operator set. Naming them is selecting held atoms.
- What remains forbidden is (i) inventing a seventh primitive from a coupling strength, (ii) claiming the framework fixes which topology dominates in a named system, and (iii) claiming a universal multiplier follows from the set. Findings F8 and F11 in `01_figure_grounded_audit.md` record these as a `gap`, not an oversight.
- **Correction to my own first pass.** I initially wrote that the framework cannot name a coupling topology at all. That overstated the rule in the same way the exemplar's §5 overstated it for Gradient. The narrowing is kept visible here and in `01` §6 rather than erased.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried): `Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige.` A list of well known tipping-point researchers assembled to agree with the compound shape is the named collapse. The legitimate ask is the opposite: give the claim a budget to be tried, then let a measurement settle it.

**My own audit is a simulation, not a ground reading.** Same essay (carried): `LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself.` LLM output is `simulacra`. So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.
