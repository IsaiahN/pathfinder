## Independent domain census

I redid the census from the residual line before aligning with the primary, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** Several thresholds with coupling. Arity: each crossing is a binary comparison, but the coupling set is quadratic in the number of elements, so the object is the arrangement, not the list. Symmetry: the comparison is ordered and couplings carry sign, so operands are not interchangeable and different orders are different terms. Scale: first order inside an element, second order at the cascade, because a settled molecule becomes an atom for what composes over it. Type: union, not partition.
- **Domain 1, threshold and crossing.** Actors: control quantity, state variable, critical value. Currency: comparison. Anchor: a measured bifurcation. Partition. First in dependency order.
- **Domain 2, coupling.** Actors: elements, directed couplings, sign. Currency: influence travelling. Anchor: an observed cascade. Union with possible cycle. Second; baseline elements do not transmit.
- **Domain 3, consequences.** Actors: all slots, habitat, aftermath. Currency: per-slot residual and reach. Anchor: measured aftermath. Union, per-slot, third-order. Third.
- **Domain 4, verification.** Actors: modellers, models, observations. Currency: agreement and residual. Anchor: the ground, never agreement. Independence zero in this simulated run.

Order by dependency: describe the residual before choosing a frame (Fig 9 :27); refuse before mint (Formula step 2); settle each crossing before composing over it (Fig 12 :104).

## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed zero. I ran the round trip on the condensation the folder actually uses.

1. **Sent up (x):** the verbatim figure set, chiefly Fig 9 :55-57 (union compound), Fig 12 :121 and :117 (signed cycle, isomer), Fig 1 :19 and :22 (per-slot residual), Fig 11 :52 (contact cascade).
2. **Abstraction (T_A):** the shorthand carried in `07` and `09`: interacting tipping points raise the likelihood and change the consequences of systemic change; coupling is a signed bond; arrangements are isomers; consequences are per slot; the number is a gap.
3. **Concretisation (T_E):** a specific network model, for example Wunderling et al. (2021) with four named elements, a coupling strength `d`, initiators and mediators, and a stabilising or destabilising tendency.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- the **sign of each coupling** and whether a return path exists. The shorthand says "coupling changes likelihood"; the model must specify which link has which sign, and the figure does not supply it;
- the **per-slot indexing of consequences**. The model reports expected numbers of tipped elements and cascade frequencies, which are aggregates; the live-slot asymmetry is dropped unless deliberately retained;
- the **verdict/witness distinction**. The shorthand says the climate cluster is one witness; the concrete literature reads as several independent papers and invites the reader to pool them.

Conversely, one thing survives cleanly: a case in two conditions is categorically different from a harder case of either, so a count-only risk multiplier is not licensed. That is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating the formula as identical to the figure set would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a recorded gap, which is what `09_watson_answer.md` states.
