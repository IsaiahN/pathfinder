## Restatement as an effect

The question decides whether the thing we call evolution can run before a specific substrate, the modern gene (a template-based hereditary record with the modern replication machinery), exists. Option A: the gene is a precondition. Before it there is chemistry, repetition or drift, and calling it evolution is a category mistake. Option B: selection is unmaintained ground contact that runs wherever there is variation inside, differential persistence, and some minimal continuity; the gene is a later, level-relative record composed over that process, not its floor. A leads to a hard boundary between chemistry and biology drawn at the gene. B leads to a dependency order with the gene downstream, and to an open question about which carrier actually did the work first.

What an answer would look like: a shape plus a dependency order, not a date and not a named molecule. Bound as an ordinary term: "a process in which what persists is settled by differential contact, with a carrier that need not yet be a modern gene." That term is bound here and carries a residual, so it can be refused by the same test as any other claim.

## Headline verdict

Yes in the structural sense, with the carrier left open. Selection is unmaintained ground contact and needs no gene to run (Fig 11 :36, Fig 7 :35); a modern gene is a later hereditary record, a generator that crosses levels (Fig 10 :68, Fig 4 :34-35), and it adds no atom to the world (Fig 6 :25-26). The question also bundles a definition dispute, which is a gap: no figure selects which definition of "evolution" or "gene" to adopt. Verdicts are kept separate per domain and are never averaged.
