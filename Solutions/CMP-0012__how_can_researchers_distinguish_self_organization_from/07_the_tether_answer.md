# The Tether's answer: how to distinguish self-organization from imposed order and hidden coordination

**Mode: `specified` on the diagnostics, `general` on the structural shape, not `grounded`.** This is a shape and a route, not a result. Simulated derivation checked against the figures (`05_what_shape_means.md` §6), not a ground reading.

## 1. The residual it answers

A researcher observes one stable large-scale order and must attribute it to local interactions alone, an external constraint, or a hidden shared source. The three are a union compound, not one hard problem: energy and contact are present in all of them, and indirect coordination through an environmental trace can be self-organized. Fig 9 :55-57: "A bundled problem is usually a union of overlapping conditions, not a list of separate ones."

## 2. The shape

1. **The order alone cannot attribute the cause.** Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 8 :50-52: "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them, and the surplus lives only where the closures differ." *How Intelligence Actually Works*: "nothing in the image records which." Attribution is a source question, and the observation is a lossy projection of that source.
2. **Self-organization versus imposed order is the seat axis.** Fig 11 :56: "Unmaintained. No maintainer and no live frame in the seat. The habitat is pure contact, nothing selects, and what survives is what the ground kept." Fig 11 :58-59: "Maintained. A seat exists and can act: choose the instruments, distil the impactful actors, introduce what was not there." The diagnostic is removal of the seat. If the order persists, it is unmaintained; if it collapses, a maintainer was authoring it. *The Recursive Self-Improvement Trap*: "The same code runs when there is a Ground Maintainer. It runs in cultivation, when humans select which plants to breed."
3. **Hidden coordination is the independence axis.** Fig 2 panel 2: "they never talk, and still agree so the agreement is the pool talking, not two frames confirming each other". Fig 2 :31-32: "Independence, between two frames, is how little they draw on the same evidence." Cut the shared source and range each part separately against an anchor that does not update (Fig 2 :29: "An anchor is whatever settles the question and does not change its answer because of what any frame thinks."). *Confounding* (Wikipedia) corroborates from statistics: "Confounding is a causal concept rather than a purely statistical one, and therefore cannot be fully described by correlations or associations alone," and offers the intervention `P(y|do(x))` as the discriminator.
4. **Read per slot, not as one global order parameter.** Fig 1 :19: "The residual is indexed by object slot, not aggregated." A hidden coordinator often lives in one slot while the global average looks smooth.
5. **A source-discriminating instrument closes the case if a trace exists; otherwise only provenance does.** Fig 6 :34-35: "Where nothing is, there is no edge to extend from, and the search for a proto-instrument is a search for one that is already there." The gemstone case (*How Intelligence Actually Works*) is resolvable because isotope ratios are a real trace; color metamerism is not resolvable from the reading because no trace survives. Fig 8 :39: "So a search that finds nothing is never a proof of absence."
6. **Keep the verdicts separate.** The seat test, independence test and trace test are three domains in a union. Do not average them (Fig 9 :54-55).

## 3. What it explicitly does not say

- Not that the pattern identifies its own cause. That is the metamerism error.
- Not that self-organization means no external input. Every such system needs energy and contact; the discriminator is the authored template, not the absence of flux.
- Not that hidden coordination requires direct communication. Stigmergy is indirect, trace based, and self-organized (audit F7).
- Not that a constraint is a neutral background if it decides the outcome. Fig 10 :47: "a convention that decides an outcome has stopped being one".
- Not a name for the cause in any particular system. The framework returns a shape, not a name.
- Not `grounded`. No intervention has been run in this derivation.

## 4. What would settle it, the ground

Interventions, not further description of the pattern:

1. **Seat removal.** Withdraw the suspected maintainer or constraint. Does the order persist? Refuter: order persists while the template is shown to have been authored by the withdrawn maintainer.
2. **Source cut.** Remove the suspected shared signal and range each part against a pinned anchor. Refuter: agreement survives with no residual shared evidence.
3. **Per-slot scan.** Locate which slot carries the attribution signal. Refuter: the signal is provably uniform across slots.
4. **Trace instrument.** Find a source-discriminating trace and read it. Refuter: such a trace exists, is readable, and still fails to separate the causes.
5. **Standing structural falsifiers:** an order-only invariant that separates the three causes; a new primitive that makes A, B and C non-isomeric.

## 5. The honest stop

**Unreached, not unreachable.** *How Intelligence Actually Works* defines the union horizon: "A projection sinks below the union horizon when no observer, with any instrument any of them can build, can discriminate its origin," and "Being 'below the union horizon' is never a settled verdict, only a report that nobody has reached it yet." The six-term substrate and the three-cause census are visible guesses at the compression axes, not nature's own list: "Declaring the primitives does not make them neutral. It makes the choice visible." The answer stops where the available instruments stop, and records the lineage so the stop is checkable. "Indiscernibility is not identity."

## 6. One-paragraph version for outreach

> The Tether does not read the cause off a pattern. It says that self-organization, imposed order and hidden coordination can produce the same observable order, so the order alone cannot decide between them; they are isomers, same visible substance, different causal bond. What can decide is a set of interventions ordered by dependency: remove the suspected maintainer and see whether the order persists, cut the suspected shared source and range each part against an anchor that does not update, read the residual per part rather than as one global average, and look for a source-discriminating trace before looking for a better argument. If no trace exists, only provenance can settle the case, and the framework says so rather than inventing an answer. This is a `specified` shape with refuters written in advance, not a `grounded` verdict, and it stops honestly at the limit of the available instruments.
