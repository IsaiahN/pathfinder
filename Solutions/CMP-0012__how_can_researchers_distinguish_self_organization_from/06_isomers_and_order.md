# Isomers, order and analogues: the structure of the attribution problem

**Mode: `specified`.** Simulated derivation checked against the figures, not a ground reading (see `05_what_shape_means.md` §6).

## RESIDUAL

Given one observable order O and three causes A (self-organization), B (imposed order), C (hidden coordination), what is the structural relation among A, B and C, and what ordering of tests follows from it? Fig 9 :54-55: "when the split lands on a union rather than a partition, unbundle before you search again."

## DERIVATION

### Q1. Are A, B and C isomers?

Fig 12 :117: "isomer. Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."

- If A, B and C are written over the same component set (the same parts, the same observable order O) and differ only in the bond, that is: components `+` each other locally (A), components `+` a template authored outside them (B), components `+` a hidden shared source (C), then they satisfy the figure's definition: same atoms, different arrangement, different substance. The difference is invisible in O, which is exactly why O cannot attribute the cause.
- Fig 12 :5: "A set of ingredients is not one. The bond is the rest of the information, and it is the half nothing was recording." A report that lists the components and the order but not the causal bond has recorded half of itself.
- This is a real isomer claim, not a metaphor: the world sources make the same structural point. *Metamerism (color)* reports "a perceived matching of colors with different (nonmatching) spectral power distributions"; *How Intelligence Actually Works* reports the video-frame versus photograph case where "nothing in the image records which."

**Falsifier, written before the run:** if one cause can be written with an atom the others do not require (for example, hidden coordination always leaves a trace that self-organization never leaves), the isomer claim fails and the three causes are a functional-group family rather than isomers. Recorded, not hidden.

### Q2. Are they a functional group instead?

Fig 12 :124: "functional group. A substructure whose presence fixes the outcome. The group says what kind; the qualifier says which member."

If the stronger isomer form fails, the weaker claim stands: A, B and C share the substructure "local parts producing a stable global order" and differ in the qualifier (who authored the template / where the shared signal came from). The group fixes the kind of thing to look for; the qualifier would have to be settled by an instrument.

### Q3. What is the order of the tests?

Fig 3 :20-21: "The chain is ordered by dependency, not by importance. Each link consumes what the one above produces, so effort spent above the break arrives at a step that cannot use it."

The dependency order is:

1. **Instrument link.** Can anything at any resolution return a difference between the causes? Fig 3 :27: "A link with no instrument is not a link that works. It is a link nobody has looked at." Fig 6 :34-35: "Where nothing is, there is no edge to extend from, and the search for a proto-instrument is a search for one that is already there."
2. **Description link.** Describe the residual in effect terms before choosing a frame (Fig 9 :27-28: "describe it before you go looking, or any frame you pick will seem to fit").
3. **Seat link.** Remove the maintainer; observe persistence (Fig 11 :56, :58-59).
4. **Independence link.** Cut the shared source; range each part against an anchor that does not update (Fig 2 :29, :31-32).
5. **Trace link.** If a source-discriminating trace exists, read it; if none, record provenance and stop (gemstone versus color cases in *How Intelligence Actually Works*).

This is a sequence, not a menu: link 3 presupposes 2, which presupposes 1. Fig 12 :111: "A vocabulary without bonds can name a state and cannot name a route to one." A list of three causes without this order states what the situation contains, not how to get somewhere from it.

**Falsifier:** if the seat link returns its answer without the instrument link (that is, if the maintainer is visible in the pattern alone), then links 1 and 2 are not prerequisites and the ordering claim is false.

### Q4. Is the union a partition we can average over?

No. Fig 9 :55-57: "A bundled problem is usually a union of overlapping conditions, not a list of separate ones. A single lever clears the region where only one condition holds and leaves the intersections standing, because the second condition still binds."

World support: *Self-organization* lists "availability of energy" as an ingredient of every self-organizing system, and *Dissipative system* says a reproducible steady state "may be reached by natural evolution of the system, by artifice, or by a combination of these two." *Stigmergy* shows a shared environmental trace inside a self-organized process. So A and C overlap, and A and B overlap. A verdict must be per domain, never an average.

**Falsifier:** a case set in which exactly one cause is ever present and no two overlap. Then the union claim is unnecessary.

## CONCLUSION

A, B and C stand to one another as Fig 12 isomers over a shared component set: same observable substance, different causal bond, difference invisible in the pattern and decisive in what an intervention returns. The weaker functional-group reading is the fallback if the isomer falsifier fires. The tests are strictly ordered by dependency, with the instrument link first, and the whole is a union that must be unbundled rather than averaged. This rescues the three-way distinction without inventing a new primitive: no seventh cause, no import that moves a wall, and no claim that the pattern names its own source. What stays open is which cause holds in any particular system, pending a ground reading.
