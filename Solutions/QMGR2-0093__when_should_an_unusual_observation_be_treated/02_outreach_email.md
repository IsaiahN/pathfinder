# Outreach draft - check the decision rule before you decide about the framework

**Use:** one-to-one, or as a cover letter attached to a submission through a public venue in `03_public_contact_points.csv`. **Not** for bulk send.

**Hard precondition:** the shape claim and its refuter below must survive the reader's own check before any framework material is shown. If stage 1 fails, there is nothing else to look at.

---

**Subject:** One checkable claim about when an anomaly becomes a discovery

> Hi [name],
>
> I have one specific methodological output I would like you to check against what you already know. I am not asking you to read the framework first, I am not asking you to agree with it, and I am not asking you to trust anything. If the output does not survive, stop there.
>
> **The output (`specified`, not `grounded`):** the question "discovery or fluctuation?" is the wrong partition. It bundles at least five different kinds of residual. Written in effect terms, an unusual observation is a live per-slot residual: something happened in one tracked slot that the prediction missed. The five bins are: the model was right and nothing is owed; the gap is new, so extend perception and aim the probe; the gap is mis-attached, so refit what you have and do not invent; the mechanism is broken, so a new term is owed; and a term we hold is wrong, so a refusal is owed rather than an explanation.
>
> The rule I would like checked is this. Do not use a significance threshold as the verdict. Use it only to decide how much independent follow-up to buy. Promote to a candidate discovery only when, in addition, (a) the residual stays per-slot and the full scan and stopping rule are recorded, (b) a candidate term under a declared code costs less to state plus what it leaves unexplained than the confusion it removes, (c) the residual persists and does not trend down as data accumulate, (d) an independent instrument with low overlap confirms it, and (e) a channel audit has failed to make the reading disappear. If the candidate is already composable from what the field holds, the remedy is more independent search, not a new atom. If the persistent residual points at a held term that is false, the right move is to refuse that term, not to add another explanation.
>
> **What I am not claiming:** that this is a new significance test, that any number settles it, that a famous name on a claim helps decide it, or that the framework can prove its own rule. The figures return a shape of a decision, not a cutoff and not a verdict on any particular anomaly. A reported failure is more useful to me than agreement.
>
> **What would refute it, written down before this message:** (1) a closed two-way criterion that correctly handles all five bins including the refusal bin; (2) a controlled benchmark where cost plus leftover separates known injected signals from null fluctuations worse than a fixed threshold at the same budget; (3) a documented case where the residual trends down under accumulation and a real discovery is being missed under a declared stopping rule; (4) a domain where a threshold with no independent ground contact sets the truth of the decision; (5) a frame that computes an unbiased external measure of its own post-hoc selection effect from the same data that selected it; (6) a case where importing a new atom beat search inside a closure that already contained the answer. If any holds, I withdraw the corresponding part.
>
> **Stage 1, the only question for now:** what would you count as a failure of this rule? A one-line "this fails because..." is enough. If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** I will send the source links. The figures are the authority, not my summary of them.
>
> **If you want the method:** the eight-step formula is public in the source links. Run it on a problem you know well and can check against a ground. Write down what would refute your result *before* you run it and state the mode of what you get. A reported failure is more useful to me than a reported success.
>
> Thanks,
> [name]

## Why this version is ordered this way

| the move | figure-grounded reason |
|---|---|
| Residual first, verdict second, framework last | Fig 10 :52 "Bring a characterised residual, never the source." The recipient checks the rule without holding the framework's interior. |
| Do not ask for agreement or trust | Fig 2 :35 "Alignment is triangulation, not negotiation. A mirror cannot correct you." Asking for agreement selects the correlation that disqualifies a verdict. |
| Pre-registered refuter | Fig 5 :66 "residual like anything else. Then the preference is refusable by the same test as everything else. Committing a prediction before a run is this, already working." |
| Mode stated on every claim | `THE_FORMULA.md`: "Mode. general · specified · grounded. State which." |
| Threshold demoted to a filter | Fig 9 :60 "Use filters for the budget and witnesses for the verdict. Never let a filter hand you a verdict." |
| The five-bin sort before the binary | Fig 5 :51 "The four kinds sort a gap by what is missing. None of them sorts a gap by what is wrong." |
| Compressibility, not magnitude | Fig 5 :44 "fails this, and so does a term that explains one occasion perfectly." |
| Independence named as part of the rule | Fig 2 :31 "Two people reading the same report are not two frames; two instruments pointed at the same thing are." |
| Search before import | Fig 6 :24 "A wrong atom costs more than starting from primitives." |
| Refusal included | Fig 5 :53 "refuted: a term we hold is wrong; a term is owed that says so" |
| No request for prestige | *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly." The ask gives the rule a budget to be tried; it does not ask for endorsement. |
| Links only after a recorded verdict | Fig 1 :27 "They are frame-internal. A frame cannot score itself with a quantity it also produces." A reader who has absorbed the framework before judging it has joined the frame being checked. |
| Offer the formula as a reusable method | Fig 4 :22 "Only methods cross up. Only head starts come down." |

## Distribution constraint

One-to-one only. No bulk send, no list of people ranked by likelihood of agreement, no personal emails harvested from private posts. Institutional and opt-in venues only (see `03_public_contact_points.csv`). Legally, unsolicited bulk outreach breaches GDPR and CAN-SPAM style rules in many jurisdictions; that is a practical failure on top of the structural one named in Fig 2 :40.
