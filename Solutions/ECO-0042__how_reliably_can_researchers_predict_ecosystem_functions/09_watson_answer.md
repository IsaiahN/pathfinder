## QUESTION

Decide, in effect terms, what the Tether says about the claim that ecosystem functions can be
predicted reliably from species counts alone. Option A: report one global reliability coefficient for
count-only prediction. Option B: refuse the scalar, unbundle the union, and report per-function,
per-habitat residuals with the worst live slot shown, naming the missing discriminator as a shape
rather than a variable. What each leads to: A produces a number that can hide a live slot residual and
lets a cheap filter hand the verdict; B produces a checkable shape, four pre-registered refuters and
an explicit stop where the ground has not been read.

## DOMAIN CENSUS

R by arity, symmetry and scale, then one line per domain with actors, currency and anchor; partition
or union; order by dependency.

- **R (the residual).** Arity: one scalar predictor `S` against a vector of functions, so a many-to-one
  map. Symmetry: `S` is invariant under permutation and identity substitution, so it is a symmetric
  projection. Scale: `S` is a site-level aggregate; `F` is a process rate at a slot, so a transform
  between scales is involved. Indexing: per slot, never a global average. The figure set calls the
  compound a union, not one hard question (Fig 9 :57).
- **D1 Taxonomic counting.** Actors: species as interchangeable tokens and the observer counting them.
  Currency: the integer `S`. Anchor: a plot census or reference collection, a checkable count.
  Nameable, so a domain.
- **D2 Trait and composition.** Actors: species identities, traits, relative abundances, functional
  groups. Currency: trait distributions, identity, dominance, complementarity, bonds. Anchor: the
  function measured in an experiment or survey. Nameable, so a domain.
- **D3 Habitat and context.** Actors: light, water, temperature, season, terrain, and relations of
  pollination, predation, competition, dependency. Currency: contact and context, cascades. Anchor:
  the ground, the function measured in that habitat. Nameable, so a domain.
- **D4 Verification.** Actors: ecologists and referees, the claim and its refuter. Currency: residuals
  and agreement. Anchor: the ground, never agreement. Nameable, so a domain.
- **Partition or union.** Union compound. Identity at fixed count, trait and abundance arrangement,
  and habitat context overlap; a lever on `S` leaves the intersections standing (Fig 9 :54, :57, :59).
- **Order by dependency (Fig 3).** Perception, then vocabulary, then the objective of reducing
  per-slot `R`, then planning, then carrying what worked. A count-only protocol that optimises a
  global fit while one function slot carries positive mass is working above a break it cannot see.

Strain test: Fig 11 says enumerate the habitat; Fig 12 says compose inside a library. Re-census shows
different objects, habitat read from the world versus library composed inside a frame, so no strain
remains. This is the same re-census pattern as the exemplar's Fig 13 versus Rule 2 case.

## VERDICT (from the figures)

The shape survives. A species count is a symmetric, lossy, many-to-one aggregation, and reliability
must be reported per function and per habitat with the worst live slot shown, never as one global
coefficient. Identity-dependent information is discarded before prediction; trait identity, dominance
and complementarity and habitat conditions and relations are load-bearing; more count data cannot
close the union. The missing discriminator is a slot-indexed, cross-kind, habitat-embedded shape,
settled per function against measured data, and the framework refuses to nominate one universally
sufficient variable. Counts are a legitimate budget filter and not a witness. The four
pre-registered falsifiers are standing. This verdict is `general` on structure and `specified` on the
empirical reading, ungrounded and candidate. The numeric answer to "how reliably" is a `gap` in this
run, not an omitted result.

- **cost if wrong:** bounded and locatable. If the shape is wrong, the four falsifiers name exactly
  how: a permutation-invariant function, a small per-slot residual on held-out data, a zero surplus
  from trait and habitat variables, or count sufficiency. The avoidable cost is spending an outside
  reader's independence by sending the full framework before the residual and refuter, which
  Fig 2 :42 prices: *"Buy independence in proportion to the cost of being wrong."* Leading with the
  packet's claim and refuter avoids it.
- **undoable:** yes. The scalar coefficient is withdrawn without touching the figure derivation; the
  per-slot, per-habitat matrix is a reporting change, and the imported trait and habitat atoms are
  provenanced bindings that can be revised source by source. No primitive has to be withdrawn. A
  sent packet can be superseded by a corrected one.
- **reversed by:** a ground reading, not agreement. A named function, site set, habitat, model and
  error metric measured against the ground, with one of the four falsifiers firing, would reverse the
  shape claim. A source-discriminating instrument that shows identity substitution cannot change the
  target functions would make the symmetry harmless. A measured round trip with zero gap would
  remove the loss claim. Prestige, consensus or more count samples are not such instruments.
