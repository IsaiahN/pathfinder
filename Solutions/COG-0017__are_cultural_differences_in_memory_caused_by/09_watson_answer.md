## QUESTION

Are cultural differences in memory caused by different strategies, different social goals, or different forms of experience? In effect terms: given a memory reading and a cultural contrast, what instrument would tell us which of three candidate sources produced the reading? Source: `cognitive science.txt` line 22, section 2. Option A: choose one cause and generalise it. Option B: keep the figure-derived shape, refuse the partition, and record the source attribution as a gap until an instrument pays for it. A returns a pooled verdict that cannot discriminate among sources. B returns a checkable separator, written refuters and an open source column.

## VERDICT (from the figures)

The figures decide the shape and refuse the source name. The answer has this form: a cross-cultural memory difference is a reading whose source is underdetermined; the three candidates form a union of overlapping conditions; verdicts stay indexed per memory phenomenon and group; the difference must clear a non-updating anchor before attribution; readings must be independent; and a discriminating instrument is owed. Across groups the memory machinery is a functional group with variable members and bonds, and experience is the habitat rather than a fourth primitive. Which cause produced a given difference is a declared `gap`, not silence and not an invitation to choose. The whole result is `general` on shape and `specified` on the domain requirements, ungrounded, candidate.

- **cost if wrong.** If a variable source is named as universal, interventions built for one population are exported to others and misdiagnose cases, the error Henrich et al. document. If a real source is declared a gap and it was actually settled, effort is spent building an instrument that was not needed. The shape claim itself costs little to be wrong because it withdraws cleanly: stating the separator does not assert a source.
- **undoable.** Yes. The shape is a generator plus a refuter, not a settled source list. Withdrawing a domain verdict removes its standing to be composed over, not a term from the record. Each domain verdict can be rewritten independently, and the gap can close when an instrument pays for it.
- **reversed by.** (1) A clean partition with no overlapping candidate defeats the union. (2) A single reading that uniquely identifies a source across independent frames, with no intervention, defeats source underdetermination. (3) An alleged anchor that moves when frames push on it removes the domain's ground. (4) A variation that requires a new cognitive primitive defeats the functional-group claim. (5) Two frames marked independent and found to share participants, tests and frame lose the triangulation mark. (6) A verbatim figure line that assigns a specific difference to a source closes the gap. Until one of these fires, the verdict stands as `candidate`.
