## 1. A shape is a constraint, not a filler

The canonical rule: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*, then stops *"at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."* Fig 9 :32: *"→ you get a kind of thing, never the answer itself"*. Fig 13 :135: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

So for this question a shape is the narrowed form of an answer we can state before we can name the cause. **"A union of three overlapping sources, attributed only with a non-updating anchor, independent readings and a discriminating instrument"** is a shape. **"Cultural memory differences are caused by strategies"** is a name, and no figure line supplies it. The shape constrains: it rules out a clean partition, rules out a pooled verdict, rules out reading a source off a single measurement, and rules out treating experience as a fourth cognitive primitive. It does not fill the source column for any particular case.

## 2. How the shape is obtained

- *The Library of Babel* (carried from the exemplar's canonical mapping): *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."* Applied here, the residual is described in effect terms first: a memory reading whose source is unassigned.
- Fig 6 :30: *"outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* The residual is described as a source-attribution problem, not in framework jargon, before the low-overlap animal-behaviour fields are searched.
- Fig 8 :53: *"Residual first, frame second."* If the frames (strategy, goal, experience) are named before the residual, any frame will seem to fit. This is the inversion the question as posed invites: it lists the three candidates and asks which one, without first asking what an instrument would return if each were true.
- *The Library of Babel* on stopping (carried): the answer is reached when *"the finish line will also be the starting place"*, and the paradox is that by then you have *"composed the answer through the process of locating it."* Here the question we can answer ends where the empirical question begins. That is the honest stop, not a failure.

## 3. What licenses a name

Only two things license naming a source, both outside the shape:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* A discriminating instrument that returns a source and survives the anchor test of Fig 2 :29 would name it.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23 and Fig 8 :50), with a source gate and a shadow test: *"Two frames can hold the same atom by convergence, reaching it separately, which is corroboration at maximum independence."*

*The Hard Problem is About Source* (fetched 2026-11-22) gives the reason a reading cannot do this job. An instrument reads green but *"the instrument is speaking only about what it measured, it cannot comment on the source."* Several sources can produce one reading: one green light, a yellow and blue mix, RGB, or CMYK. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* Applied here, recalling more perceptual detail in one cultural group could be a feature-analysis strategy, a goal that rewards detail, a history of practice with detail-heavy materials, or several of these at once. The recall score does not discriminate. What is owed is a better instrument, not a longer argument. The essay's own resolution is instructive: the colour case *"was proven wrong not by argument, but by the arrival of a better instrument."*

**Correction to the blanket reading.** The "shape, not a name" rule governs a *missing* primitive. Strategy, goal and experience are not proposed as new cognitive primitives; they are bindings from the empirical frame onto memory machinery that already exists. Naming them as candidate sources is legitimate provenance. What remains forbidden is naming one as *the* cause before an instrument pays for it. Both claims are recorded so neither is quietly lost.

## 4. What "shape" means specifically for the three candidates

Four constraints, all figure-derived, form the shape:

1. **Per slot.** Fig 1 :19: *"The residual is indexed by object slot, not aggregated."* A memory-phenomenon by cultural-group by candidate-source verdict, never a species-wide or culture-wide score.
2. **Union.** Fig 9 :54: *"And when the split lands on a union rather than a partition, unbundle before you search again."* Presence and form are separate axes; a goal can bind a strategy; experience can supply both.
3. **Functional group, not a new kind.** Fig 12 :123: *"functional group. A substructure whose presence fixes the outcome. The group says what kind; the qualifier says which member."* The invariant group is the memory machinery; the member and the bond vary.
4. **Source underdetermination.** Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause"*, and Fig 6 :32: *"An instrument is not built from a description. It is improved from a worse instrument already returning something."* A discriminating instrument is owed.

A correct answer in this shape would read: for each memory phenomenon and group, confirm the difference against a non-updating anchor; record which source conditions are present, alone or in combination; name an instrument that would discriminate among them; and state what would refute the attribution. An incorrect answer reads: a single cause selected from the three and generalised across groups.

## 5. Prestige, agreement and the simulation limit

*The Recursive Self-Improvement Trap* (carried from the exemplar's canonical mapping): *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* A claim backed by a famous reviewer or a large literature gets a hearing; it does not get settled. Fig 7 :35: *"A room’s agreement is variation, not a verdict. Selection between rooms is where the ground votes."*

From the same essay on the status of this work: *"LLMs can quickly simulate an approximate answer/output"*, but *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* And: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* From *How Intelligence Actually Works* (carried): *"the recursion converges toward indiscernibility, and indiscernibility is not identity."* A shape that fits the known studies is still not proof that the source list is complete.
