**Subject:** One checkable claim about cross-cultural memory differences, before any theory

> Hi [name],
>
> I have one specific claim I would like you to check against what you already know. I am not asking you to read a framework first, and I am not asking you to agree with it. If the claim does not survive, there is nothing else to look at.
>
> **The claim (`general` on shape, `specified` per domain, not `grounded`):** an observed cross-cultural difference in memory is a reading, and a reading cannot tell you which of three candidate sources produced it: a different encoding strategy, a different social goal, or a different history of experience. Those three are not alternatives. They overlap: a goal can recruit a strategy, and experience can supply both. So a single lever, such as giving everyone the same strategy instructions, clears only the cases where strategy is the sole binding condition and leaves the overlapping cases standing.
>
> What I am asking you to check is the separator, not the answer. The claim is that any source attribution for a given difference needs four things: the difference indexed per memory phenomenon and group rather than pooled; a check that the test measures the same thing in both groups and does not move when you change the group; independent readings that do not all come from the same participants, test and theoretical frame; and an instrument that discriminates among the three sources. Without the last one, the source remains unread, not absent.
>
> **What I am not claiming:** that all cross-cultural memory differences come from one of the three, that the three form a clean partition, that any particular cultural group uses a particular strategy, or that the framework can name the source of an observed difference. It cannot. It returns the shape such an answer must have and a refuter that would break it.
>
> **What would refute it:**
> 1. a clean partition in which a difference is attributable to exactly one candidate, with the other two demonstrably absent, across independent slots and groups;
> 2. a single memory reading that uniquely identifies one source across independent frames, with no intervention;
> 3. an alleged anchor that moves when the researcher changes the group, so the difference is an artifact of the test;
> 4. a variation that needs a new cognitive primitive rather than a different member or bond of shared memory machinery.
>
> I wrote these down before sending this. If any one holds, I will narrow or withdraw the claim. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** the sources and the full derivation are below. The figures, not my summary of them, are the authority.
> - Figure text with line numbers (local framework extract): `FRAMEWORK/reference/03-FIGURES_TEXT.md`
> - Canonical figures README, branch `general-agent`: https://github.com/IsaiahN/tether/tree/general-agent/figures
> - Public cross-cultural psychology association and its journal: https://www.iaccp.org/
>
> **If you want to use the method:** the formula is in the figures link. Run it on a memory contrast you know well and can check against a ground. Write down what would refute your result *before* you run it, and state the mode of what you get. A reported failure is more useful to me than a reported success.
>
