# What "shape" means for this question

**Mode: `general`.** A shape is a constraint stated before the term that fills it is named. This is a simulated derivation checked against the figures, not a ground reading (see §6).

Sources read 2026-11-23: the canonical figures README (local), the verbatim figure extract (local), and three essays by Isaiah N, *The Library of Babel: Locating The Book of Books*, *The Recursive Self-Improvement Trap*, and *The Hard Problem is About Source* (linked in `10_source_ledger.csv`).

## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :134: "Unreachable is a verdict here, not a silence," and :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. For this question the shape is not a single sentence defining life. It is a template with four slots:

1. the question the definition is for;
2. the actors and scale it ranges over;
3. the ground that could settle that question;
4. the guard that stops it deciding an outcome it was not authored to decide.

Any candidate answer that fills those four slots is a reasonable definition. A candidate that refuses to state them has not answered the question.

## 2. How the shape is obtained here

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring terms that overlap or correlate with it, and recurse. "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."
- The same essay names the failure mode this question exhibits: "Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually to find their answers and then combine them in a satisfactory way." That is Fig 9 :4-5 and Fig 9 :54-55 in narrative form.
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30: "your words are borrowed too, so describe the effect rather than the cause". So the shape is stated as "a definition for a question with a guard", not as a favoured technical term.
- *Library of Babel* on stopping: "the finish line will also be the starting place". Here that means the answer stops when the four slots are filled for each sub-question and no slot is left to be filled by a final definition.

## 3. What licenses a particular definition

Two things, both outside the shape itself:

1. **The question it is for is fixed and its anchor named.** Fig 2 :36: "An anchor is legitimate when the question is constitutively about it." For an empirical origin question the anchor is experiment; for a conventional question there is no ground and a declared meaning is legitimate.
2. **It pays the MDL bargain.** Fig 5 :43: "A new term is worth having when stating it, plus what remains unexplained after it, costs less than what was unexplained before." A definition that explains everything by saying nothing fails; one that explains one occasion perfectly fails.

Neither licenses a *final* definition. Fig 7 :6: "the limit: no last room". Fig 7 :30-31: "every room closes some of the gap;" / "no finite number of them ever arrives".

## 4. Why "which definition is true?" is the wrong question

*The Hard Problem is About Source* gives the mechanism. An instrument that reads green "cannot comment on the source"; yellow plus blue, RGB, CMYK and an undiscovered scheme can all produce the same reading. "If several paths create the same behavior, then behavior is a projection with lossy information." What was needed was a spectrometer, not an argument.

Applied here: asking "which definition of life is true?" treats a definition as a reading whose source can be recovered. But several different criteria (replication, metabolism, containment, information, thermodynamics) produce the same classification on extant Earth life. The classification does not determine the source. What is owed is a discriminator for the question actually being asked, not a single name for the concept.

This is also why the guard matters. A definition is a declared meaning, and Fig 10 :18 says "a declared meaning is not a grounded one". If a declared meaning is used to settle an empirical outcome, the instrument has been replaced by a label.

## 5. Answer

**What would a scientifically reasonable definition of life look like?** It is a convention with four stated slots and one guard, paying the bargain in Fig 5 for a specific question, ranging against a named anchor if that question is empirical, and never deciding an outcome on its own.

**Does this amount to "anything goes"?** No. Fig 5 :43-44 excludes the vacuous and the ad hoc. Fig 10 :47 excludes the definition that decides an outcome. Fig 2 :40 excludes consensus as a substitute for a ground. Pluralism here is disciplined pluralism.

## 6. My own audit is a simulation, not a ground reading

*The Recursive Self-Improvement Trap*: "LLMs can quickly simulate an approximate answer/output with the formula"; "the truly testable output would need to be derived from the real architecture or working the formula yourself." The same essay says "Metatheories cannot validate themselves."

So `01_figure_grounded_audit.md` is a simulated derivation, checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle anything it reports on. Prestige is not a substitute: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."
