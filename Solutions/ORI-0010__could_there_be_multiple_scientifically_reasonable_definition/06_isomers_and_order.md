# Union, order and the species-concept analogue

**Mode: `specified`.** This is a simulated derivation checked against the figures, not a ground reading (see `05_what_shape_means.md` §6).

## RESIDUAL

The question asks whether several definitions can all be reasonable. Two supporting questions are owed: (1) is the residual a union or a partition, and in what dependency order should it be handled; (2) is there a precedented scientific case where a plurality of definitions is normal rather than pathological? A third question, whether competing definitions are Fig 12 **isomers**, is tested and largely refused below.

## DERIVATION

### Q1 — Union or partition?

- Fig 9 :54: "And when the split lands on a union rather than a partition, unbundle before you search again."
- Fig 9 :55: "A bundled problem is usually a union of overlapping conditions, not a list of separate ones. A single lever clears the region where only one condition holds and leaves the intersections standing, because the second condition still binds."
- The source file says the RNA-first, metabolism-first and protocell-first programs "are not always mutually exclusive." A definition that requires only replication clears the RNA-first region and leaves containment standing. A definition that requires only containment clears the protocell region and leaves replication standing.
- **Conclusion:** union. The right move is unbundling, not a single lever. Fig 9 :57: "What remains is smaller and it is also categorically different: a case in two conditions is not a harder case of either."
- **Falsifier:** if the candidates turned out to be mutually exclusive conditions such that one lever cleared all cases, the union reading fails and a single definition could be correct.

### Q2 — Dependency order

- Fig 3 :20: "The chain is ordered by dependency, not by importance. Each link consumes what the one above produces, so effort spent above the break arrives at a step that cannot use it."
- Ordered chain for this question: (1) fix the question; (2) name the anchor for that question (Fig 2 :29); (3) author the convention if the question is conventional (Fig 10 :45); (4) check the definition against the ground if the question is empirical (Fig 2 :45).
- Fig 3 :19: "Optimising a link that already works cannot rescue one that does not." Arguing about which definition is best before fixing the question spends effort above the break.
- **Falsifier:** a demonstration that the anchor can be named only after the definition is fixed. Then the order reverses and this derivation is wrong.

### Q3 — The species-concept analogue

- Abbott and Persson (2026) explicitly compare the life case with "the plurality of species concepts" and note that in biology "different definitions are used in different contexts, because it is difficult to develop a definition that works in all contexts."
- The Stanford Encyclopedia of Philosophy entry lists "Specify: divide the concept into distinct types and label them" as one of the available moves under definitional disagreement, and says of species that a category scheme is "the beginning of a conversation rather than the end."
- Fig 2 :41: "efficient for a convention: agreement about a shared meaning is the product, not a corruption of it." A plurality of species concepts is not treated as a scandal in biology; it is a set of conventions each with a domain. This is the low-overlap analogue that corroborates the figure verdict.
- **Status:** `specified`, single-source for the figure rule, with the species-concept literature as secondary corroboration. Shared evidence pool with the rest of this folder, so not an independent witness.
- **Falsifier:** if the species-concept case turned out to be a temporary mess that was later resolved by one definition, the analogue would no longer support the shape.

### Q4 — Are the definitions isomers? (largely refused)

- Fig 12 :117: "isomer. Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."
- As communities actually write them, the Darwinian definition `{evolvability, information}`, the metabolic definition `{metabolism, energy}` and the protocell definition `{containment, replication}` do **not** share the same atom set. By Fig 12's definition they are not isomers. They are closer to Fig 12's **functional group**: :123, "a substructure whose presence fixes the outcome. The group says what kind; the qualifier says which member." They are all "a criterion plus a scope" with different criteria in the slots.
- The stronger form is available but unproven: if all definitions were rewritten over the full shared atom set `{replication, metabolism, containment, information, thermodynamic directedness, evolvability}`, differing only in which bond composes which criterion for which question, then they would be isomers in Fig 12's sense. No community does this, and forcing it would itself be a convention that decides an outcome.
- **Falsifier, written before the run:** if a definition can be written without an atom another requires and still pays its question, the isomer claim fails and the functional-group reading stands. This is already the observed case, so the isomer claim is not the load-bearing part of the answer.

### Q5 — Settling and composition

- Fig 12 :104: "A settled molecule becomes an atom for whatever composes over it. So irreducible is a fact about a level and never about the world."
- A definition that has been settled for its own question can become an atom for a higher-order question, for example "which definition should this paper use?" That higher-order question is a convention, not a discovery, and is answered by the same four-slot template. This is recursion, not a new primitive (Fig 6 :25: "An import adds no atom to the world.").
- **Falsifier:** show that a settled definition cannot serve as an atom for a higher-order convention. Then the recursion fails.

## CONCLUSION

The residual is a union, and the dependency order is question, anchor, convention, ground. The species-concept case is a real scientific precedent for disciplined pluralism. The competing definitions are best described as members of a functional group, not isomers, and that weaker reading is all the answer needs. The order here is a route through a union, not a claim that one definition wins.
