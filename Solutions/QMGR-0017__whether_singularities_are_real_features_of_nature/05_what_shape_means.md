## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :134: "So the system can report that it lacks something rather than producing an answer anyway. Unreachable is a verdict here, not a silence,".

From The Library of Babel: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question." And: "you will have to use the existing vocabulary you do know that is closest to the words that you wish to describe and grasp the shape of."

So a **shape** is the narrowed form an answer can take before the answer itself is available. It constrains; it does not fill. For this question a shape is: the classical term is closure-internal; no instrument registers it; two kinds of artifact are distinct; the literal reality verdict is unreached and reported. A name would be "singularities are real" or "singularities are artifacts". Neither is licensed.

## 2. How the shape is obtained

- The residual is described in effect terms before any frame is chosen. Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :27-28: "describe it before you go looking, or any frame you pick will seem to fit".
- Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause". For this question: describe the boundary the theorems return, not the noun "singularity", and describe what an instrument would have to read.
- Decoding Tacit Knowledge: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." This is the outreach rule in `02_outreach_email.md`.

Disagreements that do not shrink with effort, where each rule keeps working well on a different subset, are not one hard question but several well-formed ones. Split it rather than search." This is the source of the union split in `01_figure_grounded_audit.md` F1.

## 3. What licenses a name

Only two things, neither of which is held here:

1. **The ground settles it.** THE_FORMULA step 5 says the ground settles a term, verified only by what pays, and that a gate is not the ground. The canonical README says the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest". For this question no instrument distinguishes SIG, so no name is licensed.
2. **A provenanced import from a frame whose closure differs.** Fig 6 :23: "No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs." Fig 8 :51: "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them, and the surplus lives only where the closures differ." Naming loop quantum gravity or regular black holes is a binding from the physics frame onto candidate closures, provenanced as such. It is not a derivation from the figures and it does not move the wall.

They're Scanning Books When They Should Be Studying Nature sharpens the limit: "The real import is not a new term in the existing space. It is a new dimension of the space." And: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Declaring primitives makes a choice visible, not neutral. This matters because the question asks about the referential status of a term inside one particular frame's closure.

## 4. Why "real or artifact" is the specific error the shape refuses

The Hard Problem is About Source gives the mechanism. A color instrument reads green and "cannot comment on the source"; yellow plus blue, RGB, CMYK, or an undiscovered scheme can all produce the same reading. "If several paths create the same behavior, then behavior is a projection with lossy information" and "An instrument that can't distinguish these cases demonstrates its own inadequacy". It was the spectrometer, not an argument, that resolved the case.

Apply that to this question. The classical theorems return a boundary. That reading is compatible with at least three sources: a real feature of the world, a limit of the classical representation, or a residue a different closure would remove. The reading does not discriminate among them. Answering "real" from the theorem is naming a source off a projection. Answering "artifact" from the same theorem is the same error with the opposite sign. What is owed is a discriminator, and the SEP entry records why none is at hand: there is no conceivable observational data about the interior of black holes.

How Intelligence Actually Works makes the same point in its own vocabulary: the projection that no instrument distinguishes from the thing is still a projection, which is why the lineage has to be kept even when the copy is perfect. Fig 4 :30: "So take the round trip and measure the gap. Without it you are navigating by dead reckoning: confident about a position nobody checked."

## 5. The shape returned for this question

1. **Union, not binary.** Three conditions with different anchors are bundled as one either/or. Fig 9 :54: "And when the split lands on a union rather than a partition, unbundle before you search again." Fig 8 :39: "So a search that finds nothing is never a proof of absence." Verdicts stay per domain and are never averaged.
2. **The classical term is closure-internal.** Fig 2 :36: "An anchor is legitimate when the question is constitutively about it." Fig 6 :21: "MINT composes inside the closure and can never add an atom." The theorems are a legitimate anchor for what GR licenses, and nothing more.
3. **No instrument returns the term.** Fig 6 :40: "What is unavailable is a sensor for something that has never registered anywhere, at any resolution. That is the whole of it." Fig 3 :27: "A link with no instrument is not a link that works. It is a link nobody has looked at." This is `unreached`, not `unreached in principle` and not silence. Fig 8 :40-41: "Underivable-in-principle and unreachable-at-this-budget are different facts, and they issue different instructions."
4. **Two artifacts, not one.** A chart artifact is removed by re-description inside the closure. A theory-limit artifact needs a new closure. Fig 8 :32: "Closure is idempotent. Composing inside a closed set never leaves it, so no search, however long, adds an atom. This one is definitional: it is what closure means."
5. **The adjective irreducible is refused.** Fig 12 :104: "A settled molecule becomes an atom for whatever composes over it. So irreducible is a fact about a level and never about the world, and there is no bottom". Irreducible inside GR says nothing about nature. This line does not decide existence; that would be a strain, re-censused in `01` F4.
6. **A replacement would be an import with a described effect.** Fig 6 :14: "the only operator that moves the wall". Fig 11 :32: "introduce, never subtract". The classical term is not deleted when a replacement arrives; the reach of the classical frame falls because something was added. No import has passed a source gate and shadow test for this residual.
7. **The literal verdict is a reported gap.** Fig 13 :134 applies: unreachable is a verdict, not a silence. The shape is a boundary whose removal, if it happens, will be an import with a described effect, not a re-description and not more search inside GR.

## 6. Correction kept visible

The phrase governs a **missing** primitive, one not held in the library. Loop quantization, fuzzballs and regular black holes are bindings from the physics literature onto candidate closures. They are already named in the world sources and are recorded with provenance, not presented as an invention of a new primitive or as an import that has moved the wall.
