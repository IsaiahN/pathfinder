## What an answer would look like (binding the sought-for shape as an ordinary term)

Per `THE_FORMULA.md` "Direction": write down what an answer would look like before running the search, so the preference accrues a residual like any other term. For this question a satisfactory answer is a rule that (1) says per object slot which source said what, (2) decides whether the sources bear on a common state before combining them, (3) ranges each source separately against something that does not move when the sources disagree, (4) weights redundant readings by measured reliability with a correction for shared evidence, (5) can refuse a source, and (6) records provenance so convergent derivation is not confused with adopted import. That is a shape, not a number. The numeric weights are a measurement question, not derivable from the figures; this is stated as a gap in `07_the_tether_answer.md`.

## What is deliberately not here

- No personal emails of named individuals.
- No ranking of people by how likely they are to agree with the shape claim.
- No bulk-send plan.

Reason, in the figures' own words: Fig 2 :35 "Alignment is triangulation, not negotiation. A mirror cannot correct you." Selecting recipients for receptiveness manufactures the correlation that disqualifies their agreement as a verdict (Fig 2 :40). A Track B reply, if one ever happens, is a conversation and never corroboration.
