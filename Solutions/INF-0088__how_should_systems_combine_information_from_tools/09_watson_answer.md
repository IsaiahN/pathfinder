## QUESTION

Decide, in effect terms, what the Tether says about combining conflicting readings from tools, users and learned parameters. Option A: blend the three into one weighted score. Option B: keep residuals per slot, infer the source relation, range each source against a ground that does not update, fuse only redundant independent readings with a refusal and a provenance record. What each leads to: A gives a smooth number, destroys the signal of which source failed, and treats agreement from a shared evidence pool as corroboration; B gives a checkable shape, named failure classes, an open numeric gap, and a route to closing it with an instrument.

## DOMAIN CENSUS

R by arity, symmetry and scale, then one line per domain with actors / currency / anchor, partition or union, and order by dependency.

- **R (the residual).** Three sources disagree about one object slot. Arity: three source kinds plus a slot, so a multi-source conflict. Symmetry: the sources are not interchangeable, so a symmetric combine commits the flat-formula error. Scale: a local tool reading, a compressed parameter prior over many episodes, and a user judgment possibly about a goal, with a lossy transform between. Fig 9 names this a union compound: a case in overlapping conditions is not a harder case of one condition.
- **Domain 1, tool / instrument frame.** Actors: tools and the measured object. Currency: readings and observations. Anchor: the measurement, only when the question is constitutively about what the tool measures. Otherwise it is an instrument. Union member.
- **Domain 2, user / judgment frame.** Actors: users and feedback providers. Currency: judgments and corrections. Anchor: human judgment only for questions about people; otherwise an instrument that can be wrong on axes it does not measure. Union member.
- **Domain 3, parameter / prior frame.** Actors: the library, belief and weighting w. Currency: priors compressed from history. Anchor: none. This is a frame inside closure(Gamma), not a ground. Union member. That it has no nameable anchor is a finding, not a defect.
- **Domain 4, causal-structure frame.** Actors: the relation among sources, common cause versus separate causes versus hidden shared pool. Currency: whether readings bear on the same state. Anchor: borrowed from Domain 5. This is a relation, not a source, and it is where unbundling happens.
- **Domain 5, ground / verification frame.** Actors: experiment, counter, benchmark, market, outcome. Currency: settlement, what pays. Anchor: itself, and it does not update on any frame's opinion. Anchor for all four above.
- **Order by dependency.** Perceive each source separately, build the vocabulary including negation, state the objective as a ground-ranged residual, plan probes, then learn and carry a method (Fig 3 :20). Describe the residual before choosing a frame (Fig 9 :27-28). Refuse before minting (Formula step 2).

Strain test applied: the ban on aggregation governs residual accounting across slots; the world literature's reliability weighting governs an estimator applied only after common-cause has been established. Different quantities, so no strain after re-census. The numeric weights remain a live gap, not a strain.

## VERDICT (from the figures)

The shape survives, the coefficient does not. Keep the residual per slot; infer the source relation before fusing; range each source separately against a ground that cannot be moved; delegate the user's role to the question; treat parameters as a prior inside the frame, never as ground; fuse only redundant, low-overlap readings with reliability weights discounted for correlation; keep a negation operator and a provenance record; and order the operations by dependency before tuning anything. The numeric weights are a `gap`, not a hidden answer. A single symmetric blend is the named failure: it destroys the where-to-look signal and counts one evidence pool as two witnesses. Two later results are scope-narrowed rather than asserted: averaging is efficient for a convention scored by an outcome, and source classes map to figure bonds only as a functional group, not as isomers.

- **cost if wrong:** bounded and locatable. The packet is mode-labelled, states refuters before the conclusion and records provenance, so an error is findable rather than invisible. The real cost is spending the independence of outside readers by sending a fused conclusion instead of a rule and its refuter, which Fig 2 :42 prices: "Buy independence in proportion to the cost of being wrong." That cost is avoidable by leading with the shape claim and its refuters.
- **undoable:** yes. The defective readings are removable without touching the derivation: a fixed user weight, a claimed numeric coefficient, and any treatment of parameter confidence as ground are all detachable. A published rule can be superseded by a corrected one, and no primitive has to be withdrawn.
- **reversed by:** a ground reading, not agreement. A controlled experiment showing that unconditional fusion matches per-slot, causal-structure-first ranging on a task with independent sources and a settled ground would break the core finding; a demonstration that identical evidence adds accuracy when counted twice would break the independence correction; user feedback matching a direct ground test on a non-people question would break the anchor rule; a rule with no negation recovering as fast as one with refusal would break the refusal requirement; and a derivation of the numeric weights from the figures alone would close the gap in the direction of a stronger claim. Until one of these fires, the verdict stands as `candidate`.
