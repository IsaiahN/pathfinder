## The question restated as an effect

We hold a set of small molecules (amino acids, hydroxy acids, nucleotides) and we want long bonded chains. The residual is the gap between the inventory of monomers and the population of long, sequence-specific polymers that life requires. The effect at issue is whether alternating hydration and dehydration supplies the conditions under which bonds form, persist and accumulate across cycles.

Two options are on the table:

- **Option A:** wet–dry cycles help, because drying removes water (a condensation product) and concentrates reactants, while rewetting restores mobility.
- **Option B:** wet–dry cycles do not help, because rewetting hydrolyses what drying built, so the net loop is zero or negative.

The figures return a third, more informative answer. The question is a **union of overlapping conditions**, not one question with two opposite answers (Fig 9 :54). Wet–dry cycles bear directly on some conditions and not at all on others. Verdicts are kept separate per domain and never averaged.

## What an answer would look like (bound as an ordinary term)

An answer is a shape plus a separator: (1) polymerisation is composition by typed bonds, so a cycle can only rearrange what is already present; (2) a cycle is a loop whose output re-enters as input, and the sign of that loop decides whether length accumulates; (3) the cycle's valence is relative to the residual and to the habitat conditions, so the same cycle can help in one setting and destroy in another; (4) length alone is not function, because the bond arrangement carries information the ingredient list does not. The literal list of which sequences become functional is a declared `gap`, not silence.
