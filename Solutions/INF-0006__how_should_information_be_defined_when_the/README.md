## The question restated as an effect

Decide between options that lead to different consequences. Option A: keep the Shannon requirement of a known distribution and declare information undefined when the distribution is missing. Leads to: an honest silence at exactly the cases of interest, and no guidance about what to measure instead. Option B: adopt a distribution-free substitute (algorithmic complexity, MDL, credal sets, predictive surprise) and assert it as *the* definition. Leads to: a name where the figures return a shape, frame-internal self-scoring, and imported atoms with no source gate. Option C (the one derived here): treat the question as a union of conditions, define information operationally as a per-slot, ground-anchored reduction of residual, require any candidate term to pass the support/reach/novelty guards and the description-length bargain, price bits and actions separately, and refuse to name a single formula until an instrument settles it. Leads to: a checkable shape, written refuters, and an honest `gap` where the distribution would have been.

**Direction (formula step, made an ordinary term before the run):** a definition of information is a rule that maps a slot's prediction/observation pair to a quantity that (i) does not move when a frame is pushed, (ii) is indexed per slot and never averaged, (iii) prices the description and the test actions in separate currencies, (iv) carries provenance for any imported primitive, and (v) stays a candidate until the ground pays. This is bound before the derivation so it can accrue a residual like anything else.
