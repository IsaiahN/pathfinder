## 3. What it explicitly does not say

- Not "a bounce happened". That names a slot the framework leaves open.
- Not "there was definitely something before". The existence of a prior *frame* is a structural requirement of the metatheory; the existence of a prior *physical universe* is an empirical question not yet settled.
- Not "there was nothing before". Fig 8 :39 and Fig 9 :44 forbid turning non-detection into a negative result.
- Not "the singularity theorems prove a beginning". They prove a boundary inside classical general relativity, which is a frame (see the re-census in `01_figure_grounded_audit.md` §7).
- Not a theory of everything. No last room applies here too.
- Not `grounded`. No instrument currently settles `left(R,φ)` for any specific prior model.

## 4. What would settle it, the ground

A discriminating instrument, not a further argument. From *The Hard Problem is About Source*: an instrument that reads green "cannot comment on the source"; the spectrometer resolved it. Here the corresponding questions are:

1. **Tensor discriminant.** Do primordial B-mode measurements return a tensor spectrum that selects one prior-frame prediction (for example the strongly blue spectrum predicted by the ekpyrotic scenario) and excludes the others? BICEP/Keck currently returns a limit, not a detection.
2. **Non-Gaussianity discriminant.** Does a future CMB or large-scale-structure analysis return a bispectrum shape that only one prior frame predicts? Planck currently returns consistency with zero.
3. **Quantum-geometry signature.** Does any observation return a relic of a phase in which classical spacetime broke down, with a signature no purely classical prior frame can reproduce?
4. **Standing refuters from `01_figure_grounded_audit.md` §4:** a composable last room, a derivation that names the prior phase without import or measurement, an instrument that already discriminates, a single-ground proof that the question was not a union, or a demonstration that the frame-level rule has no bearing on physical time.
