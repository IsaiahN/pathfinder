## Independent domain census

I redid the census from the residual line alone before comparing it to the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** For one candidate, the gap between what belief plus action predicted and what the trustee did. Arity: many, one slot per candidate, so the object of study is a set of parallel decisions. Symmetry: directed; the trustor/trustee swap changes the slot. Scale: first order within one encounter, second order when outcomes settle into reputation. Because it has two conditions (network difference and institutional difference) it is a **union compound** (Fig 9 :54-58), not one hard question.
- **Domain 1, per-slot learning.** Actors: learner and each candidate. Currency: the per-slot residual, with w mixing private history and inherited prior. Anchor: revealed behaviour. Question type: partition.
- **Domain 2, reputation.** Actors: peers, their peers, observers. Currency: reputation as a second-order atom. Anchor: the behaviour the reputation is a reading of. Question type: union.
- **Domain 3, institutions.** Actors: courts, norms, enforcement, kinship. Currency: consequences and instrument availability. Anchor: an enforcement record that does not move with frame opinion. Question type: habitat.
- **Domain 4, verification.** Actors: outside reader. Currency: agreement and residual. Anchor: the figures and the ground. In this simulated run independence is zero.

Order by dependency: perceive, have terms for what the trustee affords, state what counts as progress, choose, carry. Refuse before mint (Formula step 2); describe before frame (Fig 9 :27-28).

My boundary lines match the primary's four domains. Where the primary derived them from Fig 1 (slots) and Fig 11 (habitat), I derived them from Fig 9's union/partition split and Fig 3's dependency order. Different starting figures, same boundaries: low overlap between routes within the framework, so the agreement is weak but not simply circular. It is still one evidence pool.

## Round trip gap R_T

The Symbols table defines R_T as `gap(x, (T_E ∘ T_A)(x))`, what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

3. **Concretisation (T_E):** a concrete research design, for example "give subjects a generalized trust scale and compare cultures."

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- the **valence of correlation**: a design that counts agreement without asking whether the frames share a pool collapses convention into verdict (Fig 2 :39-41);
- the **ordered bonds**: sequence, production, subtraction, comparison and negation are lost if the result is written as one additive score (`06_isomers_and_order.md` restores them);
- the **import cost against independence**: cross-institutional contact supplies new atoms but is debited against independence (Fig 6 :24), which a simple "more diversity helps" design omits.

Conversely, two things survive cleanly: the per-slot rule and the habitat-relative valence. That is the residue worth sending. R_T was **not** measured numerically because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating the formula as identical to the full figure set would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
