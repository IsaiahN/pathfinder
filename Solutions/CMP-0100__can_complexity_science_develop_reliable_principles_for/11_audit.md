## Independent domain census

I redid the census from the question alone before reading the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the gap between a model's prediction and what the ground returns on a tracked slot. Arity: a vector over slots, so the decision is per slot and a global switch is the wrong object (Fig 1 :19). Symmetry: not symmetric between "new" and "refuted"; a refusal branch exists. Scale: within-scale gap plus the cross-scale round trip gap R_T (Fig 4 :30), so the stance can flip when the scale changes.
- **Domain 1, prediction frame.** Actors: agent, slots, library Γ, per-step loop. Currency: per-slot residual. Anchor: the ground as only metric. Question type: partition.
- **Domain 2, model-plurality frame.** Actors: frames with differing closures, candidate scenarios. Currency: independence and union surplus. Anchor: the ground, where elimination compounds. Question type: union.
- **Domain 3, habitat / ground-maintenance frame.** Actors: the seat, the habitat, the channel. Currency: contact, agent-and-habitat capability. Anchor: the ground, which does not decay while the channel does. Question type: enumeration.
- **Partition or union.** The trichotomy is a partition of the per-slot decision only after a union check; before that it can be a union compound needing all three at once.
- **Order by dependency.** Channel integrity, then per-slot residual, then union check, then stance selection; refuse before mint; SEARCHED before INWARD before OUTWARD.

My census matches the primary's three domains, per-slot reading, union-after-check rule and dependency order. ## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

1. **Sent up (x):** the verbatim figure set, chiefly Fig 1 :19/:22 (per-slot residual), Fig 9 :4/:54-57 (split unions), Fig 10 :24 and Fig 11 :39-40 (channel and capability), Fig 12 :126 (two currencies), Fig 7 :6 (no last room).
2. **Abstraction (T_A):** the three-row decision table in `07` and the claim, "refine, split, or restore contact, with the switch left to the ground."
3. **Concretisation (T_E):** a working decision rule for a real organisation, for example a scenario exercise on a supply network with a stale monitoring channel.

**R_T is nonzero.** Four things the shorthand holds do not survive the trip back down:

- the **source discriminator** for a flat residual (depth versus absence versus degraded channel), which Fig 6 :27 says look alike from inside;
- the **independence test** for scenarios, which Fig 8 :47 requires but which a three-row table does not enforce;
- the **union check** (Fig 9 :54-57), which a three-row table can silently skip by treating a compound as a single slot;
- the **two currencies** (Fig 12 :126), which a table invites a reader to sum into one score.

Conversely, one thing survives cleanly: a live shrinking residual is predicted to close, a non-shrinking union should be split, and a degraded channel blocks both. That is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the three-row rule is the figures in fewer words" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a measured gap, which is what `07` and `08` now state.
