## The answer in one line

Yes, conditionally. A species loss can trigger a cascade where its contact slot carries live residual. The scale is set by the contact structure enumerated outward from the loss (direct contact first, then what contacts those, until the residual stops mattering), by the bond type of each interaction, and by which roles are live relative to the residual being tracked. It is not set by an aggregate diversity count. The framework returns that shape, not a cascade number and not a species name.
