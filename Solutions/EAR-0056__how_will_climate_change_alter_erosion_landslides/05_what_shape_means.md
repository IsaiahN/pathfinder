## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence"*, and the same figure notes that the system *"cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question the shape is: a union of overlapping conditions, per-slot residuals, conditions in a contact cascade, directed flows with thresholds, feedback cycles, and a ground that settles each slot. A single global percentage is a name, and it is a name the figures do not license.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary already held that is closest to the thing, then recurse on recurring new terms that overlap with it. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* So the residual was described as a gap between predicted and returned sediment behaviour, not as "a climate problem", before any discipline was chosen.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is the reason the outreach email asks what the recipient would expect to see per slot.
- *Library of Babel* on stopping: *"you will know that you are done because the finish line will also be the starting place"*; the paradox is that by then you have *"composed the answer through the process of locating it."* Here the finish line is not a number but a set of checkable constraints.
- The same essay adds the union warning: *"Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually"*. That is the essay-level corroboration of Fig 9 :54-57.

## 3. What licenses a name

Two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"SETTLE the ground settles it. Verified only by what pays. A gate is not the ground."* Here that means gauges, repeat topography, inventories and sediment budgets, not a model vote.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. The earth-science sources are such frames, but they corroborate the shape; they do not supply a magnitude for a named slope.

*They're Scanning Books When They Should* sharpens the point: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"Declaring the primitives does not make them neutral. It makes the choice visible."* The six-term substrate and the habitat list are a visible guess at compression axes, not nature's own list.

## 4. The ground and the source problem

*The Hard Problem is About Source* gives the mechanism that matters here. An instrument reads green and *"it cannot comment on the source."* One green light, yellow plus blue, RGB, CMYK, or a scheme not yet discovered all give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* It was the spectrometer, not an argument, that resolved the case: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."*

Applied here: a regional sediment-yield trend is a reading that cannot name its source. Climate forcing, fire, land-use change, sediment exhaustion and channel storage can produce overlapping readings. What is owed is a source-discriminating instrument per slot (paired catchments, pore-pressure loggers, repeat topography, sediment budgets), not a confident attribution in a headline. This is also why the figures' *"a shape, not a name"* limit is not a rhetorical modesty: it is an instrument claim.

## 5. Answer to the shape question

**What does "shape" mean for "how will climate change alter erosion, landslides and sediment flows"?**

It means the form of an answer that can be checked before the answer itself is known: a union compound to be unbundled; residuals indexed by slope, reach and catchment; climate treated as conditions in a cascade whose valence is relative to the residual; flows that are directed, thresholded and nonlinear; feedback loops whose sign must be measured; and a ground that must be reached through instruments whose own decay is monitored. It explicitly does **not** mean a global percentage, a sign attached to all regions, or a date. Those would be names where the framework returns a shape, and the instrument situation does not license them.

**Does this folder commit the forbidden error?** No. `01_figure_grounded_audit.md` F8 records the sign and magnitude as a `gap`; `07_the_tether_answer.md` and `09_watson_answer.md` keep the slot open and name the instruments that would close it. The one place where a name is used is the *classification* of the problem as a union compound, which is a shape claim, not the name of a missing primitive.

## 6. Correction to my own §3 (kept visible)

I first wrote that "shape, not a name" forbids naming any quantity at all in this answer. That overstates it. The README phrase governs a **missing** primitive, one not held in the library. Here the missing quantity is a measured magnitude for a specified slot, and the rule applies because no instrument currently returns it, not because quantities are in principle forbidden. What the framework can and does name is the arrangement: union, per-slot, cascade, flow, threshold, cycle. Both statements are kept so neither error is quietly lost. The correction does not restore the global percentage: that is still refused by Fig 1 :22.

## 7. Consequences for contact

**Prestige is not action.** *The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous geomorphologists who agree that hazards will worsen is the named collapse. The legitimate ask is a budget to try the shape against their own data.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the claim and cannot settle anything it reports on.
