## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32 *"you get a kind of thing, never the answer itself."* Fig 13 :134 *"Unreachable is a verdict here, not a silence"* and :135 *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel* (opened this session): *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For the strong CP problem: *"theta_bar is small and the solving mechanism must relax it dynamically, coexist with the weak CP phase, and be ground-testable"* is a shape. *"The axion with decay constant f_a in this window"* is a name.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 6 :30 *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31 *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge* (opened this session): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: *"You will know that you are done because the finish line will also be the starting place"*, and the paradox is that by then you have *"composed the answer through the process of locating it."*

Applied here: the effect description is not "PQ symmetry breaking" but "a neutron EDM bounded at `10^-26 e cm` while a weak CP phase is order one." Anyone with the experiment paper can check that. Only after that should a frame be chosen.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** THE_FORMULA.md step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* For strong CP that means an axion detection with the predicted coupling, or a nonzero EDM with theta_bar extracted and alternatives excluded. Neither exists.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. The PQ import has provenance and a shadow test (it explains the tiny EDM), but no detection, so the source gate is incomplete.

*They're Scanning Books When They Should* (read in the exemplar session): *"The real import is not a new term in the existing space. It is a new dimension of the space."* Also *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* And *"Declaring the primitives does not make them neutral. It makes the choice visible."* The QCD parameter list, including theta_bar, is such a visible choice.

## 4. Why "theta_bar equals zero" is a source error, not an answer

*The Hard Problem is About Source* (opened this session) gives the mechanism. Metamerism: an instrument reads green and *"it cannot comment on the source"*, because one green light, or yellow plus blue, or RGB, or CMYK could give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it: *"The answer is unreached until a better instrument exists."*

The strong CP analogue: the EDM reading is a null at `10^-26 e cm`. Several sources could produce that reading, theta_bar near zero, a PQ relaxation, Nelson-Barr high-scale CP, an up quark mass effect, or an anthropic selection. The reading does not determine the source. Naming "theta_bar = 0" from the reading is the metamerism error. What is owed is a discriminating instrument, not a name.

## 5. Q2 answered: what licenses a particular mechanism?

Nothing in the framework. It returns a shape. A particular mechanism is licensed only by the ground settling a minted term, or by a provenanced import with a completed source gate. Until one of those, the name is the searcher's own contribution and must be recorded as such.

Does the solution commit the error the README forbids? It would if it asserted the axion as the answer. It does not: `01` F6 and F7 keep the slot open, and `07_the_tether_answer.md` states the three constraints instead of a name. This is the corrected form.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (opened this session): *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous names who agree with the shape is the named collapse, not corroboration. The legitimate ask gives the claim a budget to be tried and lets an EDM experiment or axion detector settle it.

**This audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the strong CP problem and must be labelled as such. The only ground fact it uses is the published EDM bound, quoted from the experiment paper.
