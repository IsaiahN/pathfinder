# Outreach draft: check a per-parameter residual table before deciding about the theory

**Use:** one-to-one, or as a cover letter attached to a submission through the public venues in `03_public_contact_points.csv`. **Not** for bulk send.

**Hard precondition:** do not send until the residual table described below exists and has been checked against published likelihoods. If the table is wrong, the two-stage offer collapses on contact.

**Mode of the claim in the email: `specified`, not `grounded`.** It states what would have to be measured. This is a simulated derivation checked against the figures, not a ground reading.

---

**Subject:** One check on the Hubble tension scope before any theory discussion

> Hi [name],
>
> I have one specific output I would like you to check against what you already know. I am not asking you to agree with it and I am not asking you to read any theory first. If the output does not survive, there is nothing else to look at.
>
> **The output (`specified`, not `grounded`):** the question "are other cosmological parameters also in tension, or is the problem confined to the expansion rate?" should be answered as a table with one row per fitted parameter, not as a single yes or no. In particular:
>
> 1. state the residual for each slot separately (H0, structure growth S8 or sigma8, Omega_m, the sound horizon r_d, the inferred age);
> 2. state which frames constrain each slot and which calibration atoms those frames share, because two collaborations using the same sound horizon are one evidence source, not two;
> 3. rank the slots by a residual that persists and does not trend down as data accumulate, and treat significance thresholds as a budget filter rather than the verdict;
> 4. judge any proposed new physics by what it does to the whole table, not by whether it moves H0 alone.
>
> That is a shape, not a mechanism. It does not claim to know which new physics is responsible, and it does not say a mechanism can be named before an instrument distinguishes the candidates.
>
> **What would refute it:**
> 1. a per-slot table from published likelihoods in which every non-H0 slot has zero persistent residual once H0 is fixed, with shared atoms accounted for;
> 2. a single import that closes H0 while every other slot stays strictly inside its previous error budget;
> 3. a ground measurement that determines H0, S8 and r_d at once without model priors and shows all slots agree.
>
> I wrote these down before sending this. If any holds, I retract the shape claim. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **If it survives, and only then:** here are the sources. The figures are the authority, not my summary of them.

> - Canonical figures README (local copy): `FRAMEWORK/reference/FIGURES_README_canonical.md`
