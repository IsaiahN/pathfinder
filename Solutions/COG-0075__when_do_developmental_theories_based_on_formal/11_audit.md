## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

1. **Sent up (x):** the four conditions in `01` §3, the union reading, and the per-slot residual rule.
2. **Abstraction (T_A):** "a schooled-child theory generalizes when a kernel transfers into a reproduced habitat, in effect terms, against an independent per-setting ground."
3. **Concretization (T_E):** a claim about a named theory in a named setting, for example "theory X generalizes to children in setting Y at age Z."

**R_T is nonzero.** Four things the shorthand holds do not survive the trip back down:

- which part of a named theory is a kernel and which part is a recording of one occasion (Fig 4 :22-25);

- the independence of the checking frame, which is debited by any import (Fig 8 :50-52);
- the per-slot residual, which is erased by any pooled universality rate (Fig 1 :19, :22).

One thing survives cleanly: the ordered union separator itself, kernel then habitat then effect term then independent per-setting ground. That is the residue worth sending. R_T was **not** measured numerically, since no target measurement exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the figures" as identity would set R_T to zero and commit the dead-reckoning error Fig 4 :30 names.
