## Independent domain census

I worked from the residual alone: what is the gap between what a resilience measure predicts about recovery and what the ground returns, per slot? Arity, symmetry, scale. Then one line per domain with actors, currency and anchor.

- **R (arity / symmetry / scale).** Arity: several slots (system, function, disturbance, scale), so the residual is a vector, not a scalar. Symmetry: asymmetric, since a reading is relative to a function and a disturbance; the same actor changes sign when the residual changes (Fig 11 :50-51). Scale: first order within a system, second order across scales. Question type: not one question but a union, because the intersections between systems are themselves cases (Fig 9 :54).
- **Domain 1, measurement.** Actors: index, instrument, slot, disturbance. Currency: residuals, bits, field actions. Anchor: the recovery outcome. Question type: partition within a system, union across systems.
- **Domain 2, habitat.** Actors: species, functions, conditions, relations, manager where present. Currency: survival of the function. Anchor: what recovery actually happened. Question type: enumerated, never composed (Fig 11 :43-44); valence relative to the residual.
- **Domain 3, transfer.** Actors: forest, ocean, grassland, their intersections. Currency: comparability and transfer loss. Anchor: none shared, so a cross-system scalar would have to invent one. Question type: union.

Order by dependency: perceive the recovery trajectory before naming it; state what counts as progress before choosing a metric; refuse the scalar before minting a new index (Formula step 2); describe the residual before choosing a frame (Fig 9 :27-28).

## Round trip gap R_T

R_T is "gap(x, (T_E ∘ T_A)(x))" (Symbols table :75-77), and Fig 4 :30 requires it to be measured. I ran the round trip on the condensation this folder actually uses.

1. **Sent up (x):** the verbatim figure set, chiefly Fig 1 :19-28 (per-slot residual), Fig 4 :19-22 (kernel transfers), Fig 9 :54 (union), Fig 11 :50-51 (valence relative to residual).
2. **Abstraction (T_A):** the shorthand carried in `07_the_tether_answer.md`: no universal scalar, method transfers, union not partition, anchor must not update, report R_T.
3. **Concretisation (T_E):** a working measurement protocol for a real forest, ocean and grassland, with named slots, an instrument for each, a disturbance regime, and a reported transfer gap.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- which **slot** is live in a given system is not named by the shorthand, and different enumerations produce different residuals even with the same protocol;
- what counts as an **anchor** in each system is not supplied: "the recovery outcome" is a role, not an instrument, and Fig 6 :34-35 warns that where nothing is already returning something there is no edge to extend from;
- the **two currencies** of Fig 12 :125-126 are collapsed by the shorthand into "report R_T," while the bits cost of a full habitat enumeration and the action cost of field measurement remain separate and unadded.

Conversely, two things survive cleanly: a single scalar is an aggregate that hides the live slot, and the method rather than the value is the transferable object. That is the residue worth sending. R_T was **not** measured numerically, because no field run exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set R_T to zero and commit the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a measured gap.
