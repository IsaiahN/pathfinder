## 0. The claim under audit

> The Standard Model's roughly 19 free parameters, which are not predicted by the theory.

The question is not a request for the measured values. Those are tabulated and precise. The question is why they take the values they do, given that the theory neither produces nor relates them. In effect terms:

- The theory is a closure Γ built from a gauge symmetry and a field content. Once the symmetry and field content are fixed, a Lagrangian of that form still contains numerical constants that must be supplied from outside the derivation. Donoghue 2007 puts the physics plainly: *"None of these parameters are predicted by the theory."* Cahn 1996: *"depends on eighteen parameters, which are a priori arbitrary."* Wikipedia's reference table lists 19 and says their *"numerical values are established by experiment."*
- Each value is therefore an **atom imported from the ground** (measurement) into Γ, not a molecule composed inside Γ. The import has provenance (a measured number with an uncertainty) and a shadow test (it explains the observed cross sections and spectra). What it does **not** have is a derivation from the other atoms.
- The residual that persists is the absence of such a derivation. It has not trended down after decades of work inside the closure. Donoghue again: *"attempts to do so with symmetries or a dynamical mechanism have been unsuccessful."* This is the positive-support condition for a mint attempt, and it is also the reason a mint inside this closure fails reachability.

Two readings were tried and one was retracted during this audit. The retracted reading is preserved in section 6: I first tried to map the ~19 parameters onto the framework's six-term substrate and to look for a structure that would predict them. Re-census showed this is a strain (Fig 13 governs the framework's own primitives, not the Standard Model's constants), so the mapping was withdrawn.

## 1. The derivation, before any figure line is chosen

### 1a. Residual R by arity, symmetry and scale

- **Arity.** R is indexed by parameter slot s, not by the theory as a whole. The electron Yukawa, the strong coupling, the CKM phase, and the QCD vacuum angle are different slots. Fig 1 :19: *"The residual is indexed by object slot, not aggregated."* Aggregating them into one question, "why 19 numbers", discards the only signal that says where to look. Fig 1 :22: *"Aggregating across slots is how a live signal disappears into an average."*
- **Symmetry.** The slots are heterogeneous. Some are dimensionless (gauge couplings, mixing angles, the QCD angle), some are dimensionful (fermion masses, the Higgs vacuum expectation value). The theory supplies no symmetry that exchanges them. The three gauge couplings run and nearly meet, but near-meeting is a hint, not a derivation. Where the literature reports a pattern (Donoghue's scale-invariant distribution of quark and lepton masses in log m), it is a statistical pattern over an ensemble, not a relation among the slots.
- **Scale.** The values are defined at a renormalization scale and run with energy. A value at one scale is a head start for a calculation at another (Fig 4), but the running does not generate the value. This is a union across scales, not a single number.

## 2. Findings F1 to F9

### F1 - The values are atoms in Γ, not molecules composed inside Γ (D1, decisive for Option A)

Fig 6 :21: **"MINT composes inside the closure and can never add an atom."**
Fig 8 :32: **"Closure is idempotent. Composing inside a closed set never leaves it, so no search, however long, adds an atom. This one is definitional: it is what closure means."**

The parameters are supplied before the prediction is made. No amount of perturbative calculation inside the Standard Model converts an input into an output; the Lagrangian still has to be handed the numbers. Donoghue 2007, read this session: *"To really specify the theory we need not only the Lagrangian above, but also have to give a set of 28 numbers which are the parameters of the theory."* Cahn 1996 uses 18, Wikipedia uses 19. The count itself is a convention (F5); the status of the numbers as inputs is not.

- Mode: `general` for the closure law, `specified` for its application to the Standard Model.
- Status: **triangulated** (Fig 6 wall mechanics and Fig 8 idempotence are two distinct arguments with low overlap).
- Refuter: a parameter value derived inside the Standard Model from the symmetry and the other parameters, with no measured number inserted. This would break the atom claim outright.

### F2 - The measured values are imports from the ground, with provenance and a shadow test (D2)

Fig 6 :14: **"the only operator that moves the wall"**
Fig 2 :29: **"An anchor is whatever settles the question and does not change its answer because of what any frame thinks. A measurement, an experiment, a counter, a market, a patient outcome."**

Each number enters the theory through the ground. It has provenance (which experiment, which fit, which uncertainty) and it passes a shadow test (it explains a gap in the observed data). That is a legitimate import. What it does not do is derive the number from other terms. Fig 8 :51-52: *"Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them."* The record matters: without it, a fitted parameter can be mistaken for a prediction.

- Mode: `specified`. Status: **triangulated** (Fig 6 import rule and Fig 2 anchor rule).
- Refuter: a parameter value shown to be fixed by internal consistency of the theory alone, with the experimental fit merely confirming it.

### F3 - Explaining the values requires a frame with a differing closure, and no such frame has a nameable anchor (D3, the gap)

Fig 6 :23: **"No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs."**
Fig 8 :27: **"describe R, then find the frame that already predicts its shape"**
Fig 13 :115: **"The set is closed. The arrangements are not. That gap is why import exists."**

The shape of the missing frame can be stated in effect terms: a closure in which the parameter values are derived terms, contacting the same experimental ground. It cannot be named from inside this derivation. Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :133: *"what it returns is a shape rather than a name."*

Candidate frames exist in the world (grand unification relates couplings; flavour symmetries relate masses and mixings; the string landscape supplies an ensemble), but none supplies a confirmed prediction of the observed set. Donoghue 2007: *"attempts to do so with symmetries or a dynamical mechanism have been unsuccessful"*, and of the landscape: *"Without a unique ground state, we cannot use the prediction of the parameters as a proof of string theory."* SEP Fine-Tuning 2026 lists two reactions to exactly this situation, that fine-tuning is *"a lucky coincidence which we have to accept as a primitive given"* or that *"it will be avoided by future best theories of fundamental physics."* Both are recorded; neither is selected by the figures. That is the honest gap.

- Mode: `specified` for the shape, `gap` for the specific values. Status: **triangulated** for the shape (Fig 6, Fig 9, Fig 13, distinct mechanisms); **gap** for the numbers (no figure line governs them).
- Refuter: a candidate frame whose closure yields a parameter value or a relation among values, stated before measurement and confirmed at the ground. That would close D3 and erase this gap for that slot.

### F4 - Work the slots separately; do not average them (D1, method)

Fig 1 :19: **"The residual is indexed by object slot, not aggregated."**
Fig 1 :22: **"Aggregating across slots is how a live signal disappears into an average."**

The electron mass, the strong coupling, the CKM phase, and the QCD vacuum angle have different histories and different candidate explanations. The QCD angle is constrained to be near zero (the strong CP problem); the quark masses are scattered over orders of magnitude; the gauge couplings nearly meet. Treating them as one residual hides these differences. The Formula's step 1 independently states R per slot s.

- Mode: `general`. Status: **single-source** (Fig 1; the Formula is the same framework, different document).
- Refuter: a demonstration that a single mechanism with one parameter explains all slots with equal residual reduction; aggregation would then be licensed.

### F5 - "Roughly 19" is a convention, not a fact about the world (D4)

Fig 10 :18: **"a declared meaning is not a grounded one"**

Cahn 1996 counts eighteen; Wikipedia counts nineteen; Donoghue 2007 counts twenty-eight when neutrinos, the cosmological constant, and Newton's constant are included. The differences come from choices about what to count and how to parametrize (pole mass versus MS-bar mass, Higgs mass versus quartic coupling, vacuum expectation value versus Fermi constant). The number of independent physical directions is not arbitrary, but the labelling and the count are bookkeeping. The seat map adds the operational rule: a convention that decides an outcome has stopped being one. If someone argues that the number 19 itself is a clue requiring explanation, they have promoted a convention to a verdict.

- Mode: `specified`. Status: **single-source** (Fig 10; seat map corroborates but shares the evidence pool).
- Refuter: a ground measurement that distinguishes two counting conventions, showing one count to be false rather than merely different.

### F6 - SEARCHED fails, INWARD fails, OUTWARD is owed (method, formula step 7)

Fig 8 :40: **"Underivable-in-principle and unreachable-at-this-budget are different facts"**
Fig 6 :29: **"inward: is our representation adequate to hold it? The instrument extends access."**
Fig 6 :30: **"outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."**

- SEARCHED: are the values in the closure and merely unfound? No. They are atoms of the closure by construction, so higher-order calculations do not derive them. This is not a budget limit.
- INWARD: more precise measurements sharpen o′ but do not derive the values from Γ. The representation is already adequate to hold them.
- OUTWARD: the description, cast in effect terms, travels to a frame whose closure differs. Source gate and shadow test apply; import from a live peer is debited against that frame's independence, and Fig 6 :24 warns that *"a wrong atom costs more than starting from primitives."*

- Mode: `general`. Status: **triangulated** (Fig 6 and Fig 8 ask different questions).
- Refuter: a route inside the closure that derives a value after all, which would make the deficit a search deficit.

### F8 - No last room: a final theory of the parameters is not available by construction

Fig 7 :13: **"agreement compounds, evidence does not"**

This does not forbid a deeper theory; it forbids treating any theory as the last one. Cahn 1996 states the aspiration in physics terms: *"Until we can explain the origin of these parameters, we cannot say we truly understand why our everyday world is as it is."* The Tether agrees with the aspiration and refuses the finality.

## 3. Pre-registered refuter

Written before the conclusion, per the seat map's rule that *"a falsifier written before the run is a design instrument, not only an honesty device."*

The shape claim is refuted if any of the following holds:

1. A Standard Model parameter value is derived inside the closure from the symmetry and the other parameters, with no measured number inserted. This breaks F1.
2. A candidate frame yields a parameter value or a relation among values in a prediction stated before measurement, and the ground settles it. This closes D3 and erases the `gap` for that slot.
3. A single mechanism is shown to explain all slots with equal residual reduction, so per-slot indexing is unnecessary. This breaks F4.
4. A measurement distinguishes two counting conventions and makes one count false rather than merely different. This breaks F5.
5. A frame is certified from inside as deriving the full parameter set with no outside left. This breaks F8 (and, under the figures, such a certification is itself the failure).

If any fires, the corresponding finding is withdrawn. Until one is run, no part of this may be labelled `grounded`.
