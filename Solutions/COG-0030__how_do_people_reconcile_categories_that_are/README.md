## What is being decided, in effect terms

A person holds two category systems that put the same object in different places. Using the everyday term makes the scientific or bureaucratic term fail in a particular setting, and using the official term makes the everyday term fail in another. The question asks what operation makes those per-object failures stop registering without throwing either system away. What an answer would look like, written down before the run: a rule that assigns each object to a frame by context, keeps the anchor of each frame distinct, and records which frame was used. That description is bound as a term here so it can accrue a residual like anything else.

## What is deliberately not here

- No personal emails of named individuals.
- No ranking of people by how likely they are to agree with the shape claim.
- No bulk-send plan.

Three reasons, in the figures' own terms:

1. Fig 2 :35 *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* A contact list selected for agreement is a mirror.
2. Seat Map :163 *"High correlation is disqualifying for a verdict and efficient for a convention."* Selecting recipients for receptiveness manufactures the correlation that would make their agreement worthless.
3. Fig 10 :42 *"A verifier that can reconstruct the claim cannot verify it."* Sending the full framework before the stage-one verdict spends the reader's independence.
