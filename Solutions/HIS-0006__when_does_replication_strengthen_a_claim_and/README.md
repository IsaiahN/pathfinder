## The question restated as an effect

What is being decided is what repeated observation buys. Option A: repetition itself is evidence, so more replications make a claim stronger. Option B: repetition is evidence only when the repeated attempts are independent frames ranging against a fixed anchor, and when methods differ the direct form of repetition (same procedure, same instrument, same quantity) can be unavailable, leaving only indirect triangulation through effect terms. Option A licenses "number of replications" as a verdict proxy and spends the independence of the people checking it. Option B yields a checkable set of conditions and an honest stop where no common frame exists. An answer would look like a set of necessary conditions with stated falsifiers, not a list of famous successful replications. That set of conditions is bound here as an ordinary term so it can accrue a residual.
