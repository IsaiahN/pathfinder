## The residual in effect terms

The question asks for the size and the conditions of a mapping from a speaker's language (a vocabulary and its grammatical bonds) to the contents of perceptual slots. Option A (determinism) says the mapping fixes perception, so different languages yield incommensurable worlds. Option B (zero effect) says perception is language-independent and language only labels a ready-made world. Option C (conditional modulation) says language changes what a frame can reach, discriminate and recall, with the ground unchanged, and that the effect is strongest where the perceptual slot has no instrument and weakest where a measurement pins the anchor. What an answer would look like is a rule predicting which slots shift under a language change, plus a named instrument that would settle each shift. That sought-for shape is written down and bound here as an ordinary term so it can accrue a residual and be refused.
