## The residual in effect terms

The question asks for the **combined** effect of five conditions on major crops. The effect to be decided is not whether any one stressor lowers yield, but what the five stressors compose into: one global number, or a per-crop, per-region, per-stage union of overlapping conditions with typed bonds. An answer that returns a single percentage has already decided the composition question without deriving it. We bind that sought-for shape as an ordinary term before the run, so it can accrue a residual and be refused (*THE_FORMULA.md* "Direction").

## What an answer would look like

A checkable answer would (1) name the actors, currency and anchor for each domain; (2) state the bond type that joins the five, with a falsifier for the additive reading; (3) keep verdicts per domain rather than average them; (4) say what the framework cannot return; and (5) name the instrument that would close the residual. That shape is the deliverable of `07_the_tether_answer.md` and `09_watson_answer.md`.
