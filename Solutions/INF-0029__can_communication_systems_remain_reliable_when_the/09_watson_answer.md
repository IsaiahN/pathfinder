## QUESTION

Can communication systems remain reliable when the channel is shaped by an adversary who adapts to the code? Restated as an effect: can R = |Γ(b,a) − o′| stay near zero per message slot s when the channel statistics are a function of Γ itself? R is indexed per slot, never aggregated (Fig 1 :19). Option A: treat the adversary as larger noise and design a better code in the same frame, which reaches a step that cannot use the effort (Fig 3 :19). Option B: re-census the channel as a frame, split the union, and import a resource outside that frame's reading. What each leads to: A spends a budget on the condition that already works; B produces a checkable shape, a stated refuter, and a gap where the ground has not settled the member.

## VERDICT (from the figures)

Reliability is possible, but not as a property of the code alone. A channel that adapts to the code is a frame, not an anchor, and a code-aware adversary overlaps the sender's closure. Report reliability per message slot at a receiver counter, never as a pooled average. Where the adversary can mirror the code, the code alone gives a zero worst-case ceiling; what moves the wall is an import from a differing closure the adversary cannot read, brought in with provenance and a shadow test and debited against independence. Against an adversary that cannot mirror the code, a code-only rate is possible. Which specific resource, code or rate wins is a `gap` after re-census, settled only at a declared channel and threshold. The figure verdict is `specified`, not `grounded`; this is a simulated derivation.

- **cost if wrong:** bounded and locatable. If D2 or D4 is wrong, one of the five pre-registered refuters fires and the failure is findable rather than invisible. The larger cost is deploying a code scored by a pooled average while a targeted slot fails, which Fig 1 :22 names and Fig 2 :42 prices: *"Buy independence in proportion to the cost of being wrong."* That cost is avoidable by reporting per-slot residuals and asking for an independent check before release.
- **undoable:** yes. The import is added without withdrawing the code, and the shape is narrowed without discarding the derivation. `07_the_tether_answer.md` and `08_expert_verification_packet.md` already remove the overstatements. Nothing in the six-term substrate is withdrawn, so the reach falls only by what a refusal adds.
- **reversed by:** a ground reading, not agreement. A declared experiment showing the channel distribution invariant under code changes would break D2; a deterministic code with positive worst-case rate against a symmetrizing, fully code-aware adversary and no private resource would break D4; a sustained measurement showing no targeted slot would break D1; a proof that a code-only improvement changes contact against a code-aware adversary would break the habitat application in D4; a figure re-census treating a worst-case over states as a quantity for ⋛ would clear the live strain. Until one fires, the verdict stands as candidate. Prestige and agreement are not such instruments.
