## What an answer would look like (the bound ordinary term)

An answer is a rule that takes an ordered list of species removals and returns a prediction for ecosystem functioning and stability. Two candidate shapes are bound before the run:

- **A, order is bookkeeping.** The outcome factors through the unordered set of species lost. All k! orders over the same set are one term, and the bond governing loss is symmetric.
- **B, order is a live variable.** The outcome depends on the sequence, because the removals are joined by ordered bonds (dependency, production, subtraction over a contact network). Two orders over the same set are different terms, an isomer pair, and the route is recoverable only from the lineage.

The derivation returns a conditional separator, not a single winner: B holds in dependency-structured communities, A holds where the lost species are functionally interchangeable at fixed richness, and a universal ranking of worst orders is a `gap` that needs an instrument.
