**Question:** Which network structures most effectively limit cascading failures without blocking beneficial diffusion?

**Source:** complexity science.txt line 66

**Section:** 6. Cascades, contagion, and systemic risk

**Status:** done

## The question restated as an effect

One network carries two different things at once: a local failure that should die out, and a beneficial signal, resource or practice that should travel. Every link that can carry the second can carry the first. Cutting links to contain the failure also cuts the diffusion. What is being decided is whether there is a structural arrangement that discriminates between the two flows, and what an answer to that would even look like. An answer would be a shape: a set of constraints any candidate topology must satisfy, plus the instrument that would settle which topology actually satisfies them. It would not be a single named "best" network, because the valence of a link is relative to the flow, not a property the link carries.

## What is deliberately not here

- No personal emails of named individuals.
- No ranking of people by how likely they are to agree that modularity, or any other topology, is best.
- No bulk-send plan.

Three reasons, in the figures' own words:

1. **A room does not replace a measurement.** Fig 2 :35, *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* A poll of researchers who already like a topology is a convention, not a verdict.
2. **Selecting for agreement manufactures the disqualifying correlation.** Fig 2 :40, *"disqualifying for a verdict: agreement about the world is worthless when the agreeing frames share an evidence pool"*.
3. **Independence has to be bought deliberately.** Fig 2 :42, *"Buy independence in proportion to the cost of being wrong."*
