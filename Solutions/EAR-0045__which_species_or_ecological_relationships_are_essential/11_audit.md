## Independent domain census

I redid the census from the residual line alone before reading the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors, currency and anchor; partition or union; order by dependency.

Arity: plural slots, because the question says "functions," so a per-slot residual (Fig 1 :19). Symmetry: the key failure. - **Domain 2, the habitat.** Actors: species, conditions, relations. Currency: contact. Anchor: the world enumerated (Fig 11 :42). Union of overlapping conditions.
- **Domain 3, the cascade.** Actors: higher-order effects. Currency: influence through relations. Anchor: the same function ground reached indirectly. Dependency outward (Fig 3).
- **Domain 4, the intervention.** Actors: managers. Currency: introduction, not exclusion. Anchor: the ground still decides (Fig 11 :20-22). Asymmetric (Fig 11 :61-62).
- **Order by dependency.** Anchor the function before enumerating the habitat; enumerate before tracing the cascade; trace before choosing an intervention. The objective link is the one without an instrument (Fig 3 :27).

My four domains match the primary's four domains. ## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

3. **Concretisation (T_E):** the concrete claim an ecologist would want, namely a named species in a named reserve that must be protected to keep a function.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- the **per-slot indexing**, which collapses readily into a single "ecosystem health" score in practice;

- the **valence-relative and habitat-indexed condition**, which collapses into a universal "this species is essential" phrase that survives retelling.

Conversely, one thing survives cleanly: you must name the function before you can say what is essential for it, and the candidate set comes from enumerating the habitat. That is the residue worth sending. R_T was not measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
