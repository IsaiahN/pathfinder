## Question restated as an effect

Two frames return two values for one quantity, the energy density of the vacuum. The quantum field theory frame sums per-mode zero-point energies up to a cutoff and returns a number of order the cutoff scale to the fourth power. The cosmological observation frame returns a number of order (2 meV) to the fourth power. The residual is about 10^120 in energy density. What is being decided is whether that residual is (a) a live per-slot signal that has been hidden by aggregation, (b) a saturated channel that has lost contact with the ground, (c) a genuine absence of a primitive in the held closure, or (d) a union compound that must be split before it is searched. An answer would look like a shape: a rule for indexing the residual, a ground that does not move, a term that does not merely fit one occasion, and a provenance gate for anything imported. That shape is bound as an ordinary term below so it can accrue a residual and be refused.

## What an answer would not be

Not the number 10^120 explained by a tuned counterterm, which is a curve fit to one occasion. Not a name for a new particle or symmetry, because the framework returns a shape, not a name. Not `grounded`: no measurement of a mechanism was made here.
