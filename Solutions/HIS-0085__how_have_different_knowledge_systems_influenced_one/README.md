## What an answer would look like (bind the sought-for shape as an ordinary term)

The shape claim this folder tests is: influence between knowledge systems is **import**, the crossing of an atom from a frame whose closure differs into a frame whose closure differs from it. An unequal relationship is not a kind of system; it is a relation in which the checking arrangement loses its anchor and converges toward the more influential frame, or in which one frame can introduce an atom into another's habitat but cannot subtract that habitat. Written down before the run so it can accrue a residual and be refused (Formula step "Direction"; Fig 5 :65-66): if either clause fails, the whole package is withdrawn.

## What is deliberately not here

- No personal emails of named individuals, and no scraped contact list.
- No ranking of people by how likely they are to agree with the claim.
- No bulk-send plan, and no request for trust, endorsement, or prestige.

Three reasons in the figures' own words:

1. **A room does not upgrade the label.** Seat Map :283: *"A room does not upgrade the label."* Adding agreeable readers raises the vocabulary and does not add an anchor.
2. **Correlation disqualifies a verdict.** Seat Map :163: *"High correlation is disqualifying for a verdict and efficient for a convention."* Selecting correspondents for receptiveness manufactures exactly the correlation that makes their agreement worthless.
3. **Prestige cannot settle an action.** *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* (The Recursive Self-Improvement Trap). In this field that rule bears directly on the usual habit of letting the dominant system's prestige decide which knowledge counts.
