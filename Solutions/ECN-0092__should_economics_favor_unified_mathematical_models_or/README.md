## The question restated as an effect

A discipline is choosing a modelling regime. Option U, one unified mathematical framework intended to cover all economic questions, promises compression and cross-domain inference but requires a final closure and averages residuals across object slots. Option P, many models each tailored to a question, preserves per-slot residuals and independent grounding but can decay into a pile of overlapping models whose union adds nothing. What an answer would look like is a rule for choosing between these regimes that (a) says what would have to be true for either to win, (b) keeps verdicts per domain rather than averaging them, and (c) names the instrument that would settle it. The answer is bound as an ordinary term in `01` section 0 and carried through every file.
