## Independent domain census

I redid the census before reading the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the set of live per-question prediction gaps in economic modelling. Arity: many, not one. Symmetry: ordered, because models answer different questions and cannot be swapped without changing the question. Scale: first order inside a model, second order when settled models are compared. Because the problems overlap in phenomena and evidence, this is a **union compound**, not a single hard question.
- **Domain 1, model and question.** Actors: models as bounded closures, variables, assumptions, phenomena. Currency: prediction and description length. Anchor: data, markets, experiments, outcomes. Question type: union.

Question type: partition of criteria into budget filters and verdict witnesses. The preference for unity has no anchor and is not yet a domain.
- **Domain 3, verification.** Actors: independent groups, replications, comparison exercises. Currency: agreement versus residual. Anchor: the real economy, never agreement among modellers. Question type: union only at low overlap.
- **Order by dependency.** Refuse the terminal frame before minting; settle each first-order model before the second-order comparison; describe the residual before naming a frame.
