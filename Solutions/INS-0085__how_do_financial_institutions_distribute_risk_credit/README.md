## What an answer would look like (Direction, bound as an ordinary term)

Before the run, the sought-for shape is written down so it can accrue a residual like any other term. An acceptable answer here would state: (a) which primitive claims are minted inside a bank's library and which arrangements over them are composed, (b) how a loss at one slot reaches slots three steps out, (c) which instrument is treated as the ground and whether it updates when the rated party pushes on it, and (d) how the resulting allocation is indexed per social slot rather than per aggregate. It would state a mode on each part and a refuter written in advance. A verdict that merely names a policy (deregulation, financialization, a particular administration) is a binding from the world frame, not a derivation, and is refused as the answer.

## Restatement as an effect

The neutral-intermediary picture predicts that banks pass savers' funds to borrowers and that risk stays with the saver. What arrives at society's slots does not match that: credit is created by the lending act, losses concentrate through interlinkages, and the capacity to set terms concentrates in a few institutions. R is the gap between the neutral-pipe prediction and the observed allocation, indexed by household, firm, neighbourhood and nation, never averaged across them.
