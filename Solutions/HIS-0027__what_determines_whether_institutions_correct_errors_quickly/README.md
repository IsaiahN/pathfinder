## The question restated as an effect

An institution holds a library of claims Γ about its domain. An error is a claim in Γ that the
ground does not pay. Correction is the process by which that claim loses its standing to be
composed over and the library changes. The question asks what sets the **lag** between the error
arriving and the library being corrected.

- Option A: the lag is set by the quality of the people in the institution, by prestige, or by how
  much review volume it generates.
- Option B: the lag is set by whether the institution keeps a non-updating anchor reachable,
  whether its checking frames are independent, whether it has an operator for refusal, and whether
  it measures the residual per slot rather than as an average.

What an answer would look like: a list of determinants in dependency order, each with a verbatim
figure line, a refuter written in advance, and a clear statement of what would settle it at the
ground. The sought-for shape is bound as an ordinary term before the run, per `THE_FORMULA.md`
"Direction", so it can be refused by the same test as everything else.
