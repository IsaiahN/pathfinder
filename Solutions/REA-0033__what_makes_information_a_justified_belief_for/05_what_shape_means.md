## 1. A shape is a constraint, not a filler

The canonical usage rule states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*: "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question the shape is the four-part relation (anchor, settlement, refusability, lineage) with confidence demoted to budget. Naming conformal prediction, calibration, a Bayesian posterior, or a particular verification protocol as *the* answer is a name, not a shape. The shape says what any candidate must look like.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary already closest to the thing, look for recurring new terms that overlap with it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *Library of Babel* on stopping: the answer is reached when "the finish line will also be the starting place", and the paradox is that by then you have "composed the answer through the process of locating it."

For this residual, the effect description is not "what is belief?" but "what would have to be true of an output for a checker to be able to break it?" That is already the refuter in `01` section 4.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** The formula's step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The canonical rule: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :50-52).

*They're Scanning Books* sharpens this: "The real import is not a new term in the existing space. It is a new dimension of the space." And: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Also: "Declaring the primitives does not make them neutral. It makes the choice visible."

So naming a particular uncertainty method as *the* mechanism turns a visible choice into an invisible one. The machine-learning vocabulary (confidence, calibration, coverage, posterior) is a frame with its own closure. Binding one of its terms onto a held atom in the shape is legitimate, but the binding must be recorded as a binding. Fig 8 :50-52: "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them."

## 4. Why the direct answer commits the source error

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and "cannot comment on the source" (one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered). The reading does not determine the source. "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

The proposed direct answer reads the confidence value (the artifact) and names its source as warranted belief. That is exactly the metamerism error: a source named from a reading where several sources could give the same reading. A confident output can come from a reliable process in contact with the ground, from fluent memorisation, from a distribution-shifted heuristic, or from a self-consistent but wrong internal sample. The reading cannot discriminate. What is owed is a better instrument, not a name. Fig 10 :24: "the ground does not decay, the channel does."

## 5. Q: does the framework name what makes a belief justified?

**No.** It returns the shape. Any particular mechanism is licensed only by the ground settling a minted term, or by a provenanced import with a shadow test. Until one of those, the name is the searcher's own contribution and must be recorded as such. Fig 9 :32 again: "you get a kind of thing, never the answer itself."

The correct form is the four-part relation with an open slot for the specific discriminator. The honest report is: this is what a justified belief must look like; this is what would refute the shape; this is what an instrument would have to distinguish; we stop here.

## 5b. Correction to my own section 3

I overstated the "shape, not a name" rule in the first pass. The canonical phrase is "what a **missing** thing would have to look like (a shape, not a name)." It governs a primitive not held in Γ. "Settlement", "anchor" and "residual" are already in the framework's vocabulary (Symbols table, Fig 2, formula step 5). Naming them is not inventing a new primitive; it is binding the question onto terms already held. What remains forbidden is naming the specific machine mechanism that occupies the discriminator slot, because that primitive is not held and would have to be imported. Both statements are now recorded so neither is quietly lost. This matches the exemplar's own correction in `QMGR-0037/05_what_shape_means.md` section 5b.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

A campaign that gathers impressive names to agree with the shape is the named collapse, not corroboration (Fig 2 :35, Fig 7 :35). The legitimate ask is the opposite: give the claim a budget to be tried, and let an instrument, an experiment, or a public review settle it.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." The canonical architecture article calls such output "simulacra" because the library behind it is unknown. So `01_figure_grounded_audit.md` is a simulated derivation, checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.
