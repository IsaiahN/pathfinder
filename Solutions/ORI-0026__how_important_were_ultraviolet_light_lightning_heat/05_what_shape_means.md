## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32 "you get a kind of thing, never the answer itself". Fig 13 :134 "Unreachable is a verdict here, not a silence".

From *The Library of Babel*, opened this session: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For this question a shape is therefore the narrowed form of the answer we can state before we can name a winner. "Importance is per slot, per habitat, energy plus gradient compose a flow, flux is a filter" is a shape. "UV was the most important" is a name, and the figures do not return it. The shape constrains what any defensible answer must look like; it does not fill the slot with a source.

## 2. How the shape is obtained

- *The Library of Babel*: use the vocabulary you already have that is closest to the thing, then "connect and correlate combinations of the existence of your known words and their relative proximity to commonly recurring new terms that you are unfamiliar with." Recurse. "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."
- Fig 9 :27-28 "describe it before you go looking, or any frame you pick will seem to fit". The question named four frames before it described the residual, so this run re-described the residual first.
- Fig 9 :30 "your words are borrowed too, so describe the effect rather than the cause". "Energy source" is a borrowed phrase; "difference that can be spent on this slot" is the effect description.
- *The Hard Problem is About Source*: "An instrument that can't distinguish these cases demonstrates its own inadequacy". Applied here, a total flux meter cannot distinguish which source drove which transition, so the instrument for importance is per-slot, not planetary.

## 3. The bundle is part of the shape

*The Library of Babel* names the exact failure this question commits: "Perhaps your problem was a bundle or conflation of several problems masquerading as one?" Fig 9 :55 "A bundled problem is usually a union of overlapping conditions, not a list of separate ones." Fig 9 :54 "when the split lands on a union rather than a partition, unbundle before you search again."

So the shape includes the instruction to split. UV, lightning, heat and gradients are not four boxes to be weighed against one another; they are overlapping conditions on different transitions in different settings. The shape says: split by transition and setting first, then ask which input reduces which slot residual.

## 4. What licenses a name

Only two things, both outside the shape itself.

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." Here that means a per-slot measurement or a discriminating field observation, not a larger flux table.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6, Fig 8). A vent-chemistry result imported into a photochemistry account must be recorded as an import, not silently absorbed.

*The Hard Problem is About Source* gives the reason. An instrument reads one value while several sources could have produced it: "If several paths create the same behavior, then behavior is a projection with lossy information". A single yield number from a Miller-Urey discharge does not tell you lightning was the dominant source, because several energy histories can give the same yield. What is owed is a discriminating instrument, not a name.

## 5. Why "importance" is not a property a source carries

Fig 11 :49 "An actor's valence is relative to the residual, not a property it carries." Fig 11 :51 "No standing list of good actors survives a change of residual."

This is the central reading of "shape" for this question. The shape is a relation: input to slot to setting, with a measured residual. It is not an attribute of UV or of a gradient. When the residual changes, from monomer synthesis to polymer survival, the same input changes valence. Todd et al. (2021), opened this session, show UV doing exactly this: it drives synthesis and it destroys intermediates. A shape must be able to hold both valences; a league table cannot.

## 6. Why this document is a simulation, not a ground reading

From *The Recursive Self-Improvement Trap*, opened this session: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too (intelligence is essentially arrangement). However, the truly testable output would need to be derived from the real architecture or working the formula yourself."

And: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."

So `01_figure_grounded_audit.md` and this file are internal-consistency checks against the figures. They cannot settle which energy source mattered on the early Earth. They state the shape a settled answer must have and the refuter that would withdraw it.

## 7. Prestige is not action

From *The Recursive Self-Improvement Trap*: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

In this field the prestige trap is the famous experiment and the famous hypothesis. Miller-Urey and alkaline vents both carry enormous reputation. Neither reputation is evidence for a per-slot importance claim. The legitimate request is a budget to try the shape against the ground: a lab run, a field measurement, a discriminating instrument.

## 8. Correction to my own §4

I initially wrote that the framework's "shape, not a name" rule forbids naming any of the four candidates. That overstates it. The README's phrase governs "a **missing** thing", a primitive not held in the library. UV, lightning, heat and gradients are world inputs, not candidate primitives of the six-term set, and the scientific literature already names them. What the rule forbids here is promoting a named input into a cross-slot verdict before the ground settles the per-slot residuals. The correction narrows the claim; it does not withdraw the shape. Both readings are recorded so neither is quietly lost.
