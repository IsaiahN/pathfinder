## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence"*.

From *The Library of Babel* (carried from exemplar mapping): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For ECN-0035 the shape is: **a union of three conditions with different anchors, a per-slot threshold comparison, and a dependency order that puts real command before external obligation.** It is not a debt ratio, an inflation number, or a reserve threshold. "A currency issuer cannot run out" is a name masquerading as a shape, because it fills a slot the question left open.

## 2. How the shape is obtained

- *Library of Babel* (carried): use the vocabulary closest to the thing, look for recurring new terms that overlap with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 6 :30: *"outward: does another frame already hold it? The description travels."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge* (carried): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- Applied here: describe the effect ("a promise cannot be kept when the specific resource it commands is already fully spoken for") before picking a frame (MMT, original sin, carrying capacity). Fig 8 :53: *"Residual first, frame second."*

## 3. What licenses a name

Two things only, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"SETTLE — the ground settles it. Verified only by what pays."* A per-slot measurement that pays for the constraint claim would license naming it.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50), with a source gate and a shadow test.

*They're Scanning Books* (carried): *"The real import is not a new term in the existing space. It is a new dimension of the space."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

**Correction to my own reading (kept visible, mirroring the exemplar's section 5b).** The phrase "shape, not a name" governs a *missing* primitive, one not held in the library. In this question, real resources, inflation and foreign currency are not missing primitives. Naming them as the binding constraints is a **binding from the world frame onto things already in the library**, provenanced as such, not the invention of a seventh term. What remains forbidden is deriving a universal numerical capacity bound from the figures, because no figure line governs that number.

## 4. Why the single-stock reading is the specific forbidden error

*The Hard Problem is About Source* (opened this session) gives the mechanism. An instrument reads green and *"cannot comment on the source."* Several sources can produce the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information"* and an instrument that cannot distinguish these cases *"demonstrates its own inadequacy."* The spectrometer, not an argument, resolved it.

Transferred to this question: a low debt ratio and a high debt ratio can each accompany a real-resource breakout, depending on which slot is full. The aggregate fiscal reading cannot comment on which source produced the stress. The correct response is a per-slot discriminator, not a sharper slogan about solvency. Fig 3 :27: *"A link with no instrument is not a link that works. It is a link nobody has looked at."*

## 5. Q: can a name be given to the binding constraint here?

**Partly. With mode and provenance attached.** The figures can name the *kind* of thing that binds: a finite real resource at a slot (Fig 13 :68), or an atom outside the issuer's closure (Fig 6 :23). That is a shape-level name, not a ground reading. Which specific slot (skilled labour in a region, energy import cover, a particular foreign-currency maturity) is a world fact that needs an instrument. Fig 9 :32: *"you get a kind of thing, never the answer itself."*

What is not licensed: taking "the constraint is inflation" and turning it into a universal verdict without a per-slot ground, or taking "the constraint is foreign currency" and applying it to a floating-rate issuer with no external debt. Both are unions being flattened into partitions.

## 6. Prestige is not action

*The Recursive Self-Improvement Trap* (opened this session): *"Prestige must never be allowed to validate an action directly"* and *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."*

In this field that rules out three familiar moves: citing the most famous economist on MMT as a verdict; citing the survey count as a verdict; and treating an institution's reputation as evidence that its fiscal-capacity claim survived contact. Each can fund a hearing. None can settle a claim. The same essay says *"You may all agree and be wrong,"* which is the reason the outreach packet asks for a refutation before any theory is shown.

## 7. My own audit is a simulation, not a ground reading

Same essay: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* And: LLMs *"can quickly simulate an approximate answer/output with the formula"*, but *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* So the entire folder, including this file, is a simulated derivation checked for internal consistency against the figures. It is not a measurement, not a policy recommendation, and it cannot settle the question it reports on.

## 8. Consequence for the outreach

The one-paragraph version in `07_the_tether_answer.md` gives the three-condition separator and its refuters. It does not give a verdict on any country's fiscal space. The correct ask to an expert is "which condition is binding at which slot, and what would discriminate it?", not "do you agree that governments can print money?". The latter is a request for a convention. The former is a request for a ground reading.
