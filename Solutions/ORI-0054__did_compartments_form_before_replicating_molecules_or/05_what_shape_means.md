## 1. A shape is a constraint you can state before you can name it

The canonical figures README: the framework reports *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13 :134: *"Unreachable is a verdict here, not a silence."*

From *The Library of Babel* (as mapped in the exemplar): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For this question a **shape** is the narrowed form of an answer that can be stated before a chemical name or a date is available. The shape is:

- a maintained boundary that filters exchange and creates a contained inside (Fig 4 :21, Fig 13 :10);
- a copying cycle that closes, with a part that survives its own use (Fig 12 :121, :119);
- a coupling in which the capability belongs to the pair and its habitat, not to either component (Fig 11 :39-40).

A chemical name (fatty acid vesicle, coacervate, montmorillonite pore, RNA, PNA) is a **binding** from a world frame onto that shape. A date (compartments first, replicators first) is a **temporal index** the framework does not carry. `COMPARTMENT(???) then REPLICATOR(???)` is a shape with an open index; `FATTY ACID VESICLE first, RNA afterward` is a name with a date. Only the first is figure-licensed.

## 2. How the shape is obtained here

- **Describe the effect, not the cause.** Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* The effect is the absence of a unit of selection; we describe that, not "early life".
- **Split before choosing a frame.** Fig 9 :27-28: *"describe it before you go looking, or any frame you pick will seem to fit."* Picking "lipid world" or "RNA world" before describing the residual makes either seem to fit (echo without shadow, the exemplar's apophenia finding).
- **Cast to travel.** Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* The split is stated in terms of conditions and coupling, not in terms of nucleotides or amphiphiles, so it can be checked by geologists and chemists alike.
- **Plain description of what you would expect to see.** From *Decoding Tacit Knowledge* (exemplar mapping): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* Hence the five refuters in `01_figure_grounded_audit.md` §4 are stated as observations, not as preferences.
- **Stop at the instrument limit.** Fig 6 :40: *"What is unavailable is a sensor for something that has never registered anywhere, at any resolution."* The prebiotic sequence has not registered anywhere at any resolution, so the search for a proto-instrument is a search for one already returning something. None was found.

## 3. What would license a name or a date

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* Here that means a dated measurement: a rock record, an isotopic clock, or a laboratory reconstruction with an observed order.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. A geochemical scenario can be imported, but only with its provenance and only if it explains the gap.

From *They're Scanning Books* (exemplar mapping): *"The real import is not a new term in the existing space. It is a new dimension of the space."* and *"Declaring the primitives does not make them neutral. It makes the choice visible."* The six-term substrate is a visible guess, not nature's own list. Declaring that a compartment is a space state (contained) and a replicator is a cycle makes a choice visible; it does not discover a chemical.

## 4. The source-discrimination point, applied to this question

*The Hard Problem is About Source* (exemplar mapping) gives the mechanism. A spectrometer reads green and *"cannot comment on the source"*: one green light, or yellow plus blue, or RGB, or CMYK. The reading does not determine the source. *"If several paths create the same behavior, then behavior is a projection with lossy information."* and *"An instrument that can't distinguish these cases demonstrates its own inadequacy."*

Applied here: observing a vesicle containing RNA does not tell us which came first. The same endpoint (a compartment with a replicator inside) is reachable from a boundary-first path (vesicle concentrates monomers, then copying starts), a replicator-first path (RNA arises in solution, then is encapsulated), and a co-emergence path (mineral surface catalyzes both, as Fine and Pearlman (2023) report for montmorillonite). The observation is a projection with lossy information. What is owed is an instrument that discriminates sources, not a name for the endpoint.

## 5. Q: does "shape, not a name" forbid saying which came first?

**Yes, and for a stronger reason than the chemical case.** The chemical case concerns a missing primitive; naming a world-frame chemical is a binding onto an atom already held (see the exemplar's correction at `06_isomers_and_order.md` Q1). The temporal case concerns an index the framework does not carry at all. The six states are space, time and energy; "time" here is *"the ordered succession of differences"* (Fig 13 :12), not a date assigned to an external chemical event. There is no `when` slot in the bond vocabulary. The Operators table has sequence (`A then B; B needs A to have happened`) and production (`A produces B; B did not exist before`), but these order **composition steps inside a closure**, not historical events in a habitat. Using them to date prebiotic chemistry is a category error, which is the strain retracted in `01_figure_grounded_audit.md` F5.

So the honest form is `COMPARTMENT(???) / REPLICATOR(???) coupled`, with the question mark on the order held open. The framework returns a shape and stops.

## 6. Two consequences for outreach

**Prestige is not action.** *The Recursive Self-Improvement Trap* (exemplar mapping): *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous origin-of-life researchers who lean one way is the named collapse, not corroboration. The legitimate ask is a budget to try the split and the refuters.

**My own audit is a simulation.** Same essay: *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* LLM output is *"simulacra."* So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is not a ground reading, and it cannot settle which came first.
