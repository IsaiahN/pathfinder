## Independent domain census

I redid the census before comparing my conclusions with the primary's, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors, currency and anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the discrepancy between an expected recovery and the measured state of an ice body after a perturbation. Arity: one per basin, glacier or ice-stream reach, so a set of slots, not one global number. Symmetry: the memory and spread statistics do not care about the sign of the perturbation, while skewness and flickering do. Scale: forcing at seasonal to decadal scale, recovery at decadal to centennial scale; first order local, second order the cascade. This makes the question a **union compound** in the sense of Fig 9 :54, because the diagnostic frame and the ice frame must both be present and neither alone carries the warning.
- **Domain 1, ice-body dynamics.** Actors: ice, meltwater, basal water, shelf, grounding line, ocean heat, snow. Currency: mass, elevation, velocity, flux. Anchor: the measured ice. Partition by slot.
- **Domain 2, transition theory.** Actors: state, control parameter, noise, feedbacks. Currency: recovery rate, AC1, variance, skewness, detrending choices. Anchor: bifurcation checks in simulation and model runs. Union with Domain 1.
- **Domain 3, instruments.** Actors: altimetry, gravimetry, InSAR, ice cores, SAR, imagery. Currency: measurements with error and coverage. Anchor: the ground. Partition by instrument, union by site.
- **Domain 4, verification.** Actors: reviewers and monitoring networks. Currency: residuals and agreement. Anchor: the ground, never agreement. Independence zero here.

Order by dependency: instrument already returning something -> residual at named slot -> describe before choosing frame -> settle first order before second -> range each frame against ground separately.

- the **refusal step**, which a recipe can omit if it only accumulates alarms. Operators table negation has to be reinstated explicitly.

Conversely, two things survive cleanly: per-slot indexing and the persistence test. Those are the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a recorded gap, which is what `09_watson_answer.md` states.
