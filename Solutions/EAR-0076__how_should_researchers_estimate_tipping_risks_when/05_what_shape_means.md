## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 (line 134): *"Unreachable is a verdict here, not a silence"* and what is missing cannot be named, *"because naming it would mean already holding it."*

From *The Library of Babel*, read this session: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For EAR-0076 the answer sought is not a probability. The shape is: a defensible estimate must be per component, mode-labelled, triangulated across low-overlap evidence, refuter-bearing, budget-aware, and silent where the ground has not settled. That is a constraint any acceptable answer must satisfy. A specific number for the AMOC is a name, not a shape.

## 2. How the shape is obtained

- *The Library of Babel*: use the vocabulary already held that is *closest* to the thing, then look for new terms that overlap or correlate with it. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."* For this question the closest held vocabulary is the figure language of residual, slot, anchor, reachability and round trip.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* Translated here: describe what a short record would look like if a component were genuinely near a threshold, before naming an indicator.
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* Say "a 40-year record cannot resolve a 1,000-year response", not "the estimator is underpowered" in jargon only a specialist can read.
- *The Library of Babel* on stopping: *"you will know that you are done because the finish line will also be the starting place"*, and the paradox that by then you have *"composed the answer through the process of locating it."* For this question the stop is the honest one: no single probability, but a method whose refuter is written down.

## 3. What licenses a name

Ground settlement, or a provenanced import from a frame whose closure differs. Formula step 5: *"the ground settles it. Verified only by what pays."* The canonical README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*

*The Hard Problem is About Source*, read this session, gives the mechanism for why an instrument is owed rather than a name. Metamerism: an instrument reads green and *"cannot comment on the source"*. Several paths create the same reading, so *"if several paths create the same behavior, then behavior is a projection with lossy information."* It was *"proven wrong not by argument, but by the arrival of a better instrument."* Applied here: a rising autocorrelation in a 40-year record is a reading, not a source. Non-tipping resilience loss (documented by Rietkerk et al. 2025 and Lenton et al. 2024, both opened this session) is another path to the same reading. The honest request is for a source-discriminating instrument, not a name for the reading.

## 4. Why this question returns a shape and not a number

The question asks "how should researchers estimate", which is a request for a method, not a measurement. The figures make the returns explicit:

- Fig 8 :39 *"So a search that finds nothing is never a proof of absence."* A number derived from a short record cannot carry the absence claim.
- Fig 6 :27 *"Which is why some unreachability is depth and some is genuine absence, and from inside the frame the two look the same."* A number cannot say which it is.
- Fig 1 :19 *"The residual is indexed by object slot, not aggregated."* A single global number is the aggregation the figure forbids.
- Fig 4 :31 *"The gap is not an error to eliminate. It is the measurement of what the coarser description cannot hold"*. A headline number is the coarser description; the gap is the honest report.

So the shape is a constraint set with a recorded stop. This is not a failure to answer. Per the canonical README, *"Indiscernibility is not identity"* and the lineage is what keeps the result checkable.

## 5. The mistake this folder refuses

Adding a seventh "tipping risk score" as if it were a primitive would be the flat-formula error: recording ingredients and not arrangement (Fig 12 :14 *"the ingredients are recorded and the arrangement is not"*). The six-term substrate and the Figures do not yield a risk number by arrangement alone; contact with the ground is required. The essays' *They're Scanning Books When They Should* argument (not re-read this session, so not quoted) is the canonical warning against treating a new term in the existing space as a new dimension. This folder therefore does not mint a score.

## 6. Prestige is not action, and this derivation is not a ground reading

*The Recursive Self-Improvement Trap*, read this session: *"Prestige must never be allowed to validate an action directly."* And: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* Gathering well-known names to agree with an estimation rule is the named collapse, not corroboration. The legitimate ask gives the rule a budget to be tried against data.

Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself"*, and LLM output is *"simulacra."* Therefore `01_figure_grounded_audit.md` and this file are simulated derivations checked for internal consistency against the figures. They are **not** tests of the question and cannot settle it. No measurement was taken.
