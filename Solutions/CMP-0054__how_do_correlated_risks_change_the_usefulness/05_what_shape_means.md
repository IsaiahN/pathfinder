# What "shape" means for this question

**Sources read this session:** the canonical local figures README (`FRAMEWORK/reference/FIGURES_README_canonical.md`), the verbatim figure extract (`03-FIGURES_TEXT.md`), and `THE_FORMULA.md`. I also read the completed exemplar's `05_what_shape_means.md` and `06_isomers_and_order.md` as an already-validated mapping of the eight essays; that is a same-pool secondary record, not an independent reading of the essays, and I do not cite the essay URLs as sources I opened this session.

## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)", and adds "Indiscernibility is not identity." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence."

So a **shape** is the narrowed form of an answer that can be stated before it can be named. It constrains; it does not fill. For this question:

- **A shape:** diversification usefulness falls as slot overlap rises; it is counted in effective independent slots, not named slots; it has a valence that depends on whether the union serves a verdict or a convention; and the shared source that correlates the slots stays marked `???` until an instrument names it.
- **A name (not delivered by the framework):** "in this credit portfolio the correlating source is the common exposure to a single rating model"; "in this grassland the correlating source is soil moisture"; "in this grid the correlating source is a shared control software version."

The first list is what this solution derives. The second is what a ground reading would have to supply.

## 2. How the shape is obtained

- Residual first, frame second. Fig 9 :27-28: "describe it before you go looking, or any frame you pick will seem to fit." I described the residual as a per-slot gap before choosing finance, ecology or infrastructure as casts.
- Describe the effect, not the cause. Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause." So the question is stated as "usefulness changes with correlation", an effect, not as "covariance matrices determine risk", a cause from one field's vocabulary. This is why one law can serve three domains.
- Cast the description so it travels. Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." The shape term in `01` section 0 is written in effect terms for this reason.
- Stop at the limit. The canonical README says the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest." That is why F7 of `01` records a `gap` for the numeric rate and threshold rather than guessing one.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." For this question, a stress test, a field experiment or an outage record in which the shared source is instrumented would name the source.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23: "No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs."). The survey-statistics effective-sample-size correction and the portfolio-theory covariance limit are such imports in F3 of `01`. They are recorded as imports, not as figure derivations.

The effective-sample-size import is the sharpest case. Fig 2 :44 says the correction "is standard in survey statistics and meta-analysis; the collapse is the same arithmetic read as a warning." The figures do not derive it; they read it as a warning. Treating the borrowed arithmetic as figure-derived would be precisely the confusing of convergent derivation with adopted import that Fig 8 warns about: "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them."

## 4. The specific error this question invites

The error is **counting names instead of sources**. A portfolio of fifty holdings sharing one factor, a grassland of fifty species sharing one stressor, and a grid of fifty substations sharing one control system all look diversified at the level of names. The reading "fifty" is a projection with lossy information. Several different source structures can produce the same name count. Naming the source from the count is the metamerism error recorded in the exemplar's mapping of the source essay (a same-pool secondary record): one reading, many possible sources, and what is owed is a discriminating instrument, not a confident label.

Fig 8 :49 gives the structural form of the error: "Two frames that overlap almost completely are one frame wearing two names." Extend k names under full overlap and you still have one frame. Fig 13 :39: "Six members that overlapped would be fewer members wearing six names."

The second specific error is **stripping the valence**. Fig 2 :39: "Correlation has valence." A single-line reading of Fig 2 :40 produces "correlation always destroys diversification", which is wrong for a convention and wrong for the middle range of connectivity described in the fetched systemic-risk source. Both errors are recorded and corrected in `01` section 7.

## 5. Q: What does "shape" mean here, concretely?

**Answer:** For this question, a shape is a four-part constraint plus an open slot.

1. **Monotone direction:** usefulness falls as overlap rises. (Fig 2 :31-32, Fig 8 :47-49, Fig 13 :38-39.)
2. **Currency:** the count is effective independent slots, not named slots. (Fig 2 :44, Fig 1 :19, :22.)
3. **Valence:** disqualifying for a verdict about independent exposure, efficient for a convention about shared meaning. (Fig 2 :39-41.)
4. **Budget:** independence is purchased in proportion to the cost of being wrong, and that price is a filter, not a witness. (Fig 2 :42, Fig 9 :60.)
5. **Open slot:** the identity of the correlating source in a given network stays `???` until a source-discriminating instrument names it. Fig 9 :32: "you get a kind of thing, never the answer itself."

Nothing in that list is a number, and that is the honest stop, not an omission.

## 6. Prestige is not action, and this audit is a simulation

The exemplar's already-validated mapping records the rule from *The Recursive Self-Improvement Trap*: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A list of agreeable systemic-risk researchers would give this claim a budget to be tried; it would not make the claim true. Asking for trust would convert potential outside frames into believers, which is the structural failure Fig 10 :42 names: "A verifier that can reconstruct the claim cannot verify it."

**My own audit is a simulation, not a ground reading.** The same essay record says LLMs "simulate an approximate answer/output" and that "the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is not a test of the claim. It cannot settle anything it reports on.

## 7. Correction recorded against my own Section 3

I initially wrote that the framework "forbids naming the correlating source" as if the rule applied everywhere. That overstates it. The "shape, not a name" limit governs a primitive not held in the library. Here the correlating source is not a framework primitive at all; it is a fact about a particular world system, and the framework has no instrument that reads it. The correct statement is the one in Section 5: the slot stays open *because no source-discriminating instrument was applied in this derivation*, not because naming it is categorically forbidden. Both readings are recorded so the correction is visible rather than silently applied. Triangulated (canonical README + Fig 9 :32 + Fig 8 :39).
