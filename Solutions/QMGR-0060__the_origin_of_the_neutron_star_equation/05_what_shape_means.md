## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* `Fig 9 :32: "you get a kind of thing, never the answer itself"` `Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."`

*The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For this question a shape is the narrowed form of `P(ε)` that can be stated before the phase occupying `2 to 10 n_sat` can be named. It constrains: the curve must join the low-density band to the high-density boundary and pass through the observational corridor. It does not fill: it does not say "deconfined quark matter" or any other phase. The empty slot is part of the shape, not a defect in it.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary already held that is closest to the thing, then look for recurring new terms that overlap or correlate with it. *"With each new term gained, you narrow the space by definition and deepen your vocabulary."* Here the held vocabulary is the χEFT band, the pQCD boundary and the NICER/GW posteriors; the proximate new terms are sound speed, latent heat, pairing gap and transition order.
- `Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."` Describe the effect (a pressure band that fails to resolve at a density slot) rather than the cause (a named phase).
- `Fig 9 :27-28: "your words are borrowed too, so describe the effect rather than the cause."` The words "quark matter" and "hyperon" are borrowed from the physics frame; carrying them into the shape without provenance is an adopted import, not a derivation.
- *Library of Babel* on stopping: *"The answer is unreached until a better instrument exists"* is the Hard Problem essay's phrasing; the Library essay says the searcher is done when *"the finish line will also be the starting place"*, because the answer has been composed while locating it. Here the stop is at the density where no instrument returns anything that fails to resolve.

## 3. What would license a name

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* A measurement or a sign-problem-free calculation with a controlled error would settle the phase.
2. **A provenanced import from a frame whose closure differs**, with a source gate and shadow test (`Fig 6 :23`, `Fig 8 :51-52`). pQCD is such a frame, but its import is a boundary condition at high chemical potential, not a name for `5 n_sat`.

*The Hard Problem is About Source* gives the failure mode: *"If several paths create the same behavior, then behavior is a projection with lossy information"*, and the instrument *"cannot comment on the source."* An M-R posterior is a projection; several phase sources could produce the same reading. The remedy is the spectrometer, not an argument. *"The answer is unreached until a better instrument exists."*

So naming a phase from a posterior is the metamerism error. The correct form is an empty slot with a stated discriminator.

## 4. The "shape, not a name" rule is narrower than it first appears

Correction to a first-pass reading, kept visible. The README says *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a primitive or atom not held in `Γ`. The degrees of freedom used in EOS models (nucleons, quarks, pions, gaps) are already in the physics frame's library. Naming them is a **binding onto held atoms**, not the invention of a new primitive. What remains forbidden is:

- inventing a seventh substrate term to make the EOS fit;
- claiming that binding a held atom moves the wall (`Fig 6 :21: "MINT composes inside the closure and can never add an atom."`);
- naming the *source* of a many-to-one projection without a discriminator (the metamerism point, not retracted).

Both the narrowed rule and the metamerism point are recorded so neither is quietly lost. This is the same correction the QMGR-0037 exemplar made in its `05` section 5b, applied to dense matter.

## 5. Prestige is not action

*The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof. Someone let reputation substitute for result."* And: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."*

For this question, the tempting prestige shortcut is to cite a famous review or a large collaboration as if the name settled which phase is present. It does not. The name can fund the observation time; the measurement settles.

## 6. This audit is a simulation, not a ground reading

Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... the truly testable output would need to be derived from the real architecture or working the formula yourself."* And: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."*

So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of which EOS is real and must be labelled as such. It cannot settle anything it reports on. A real expert check, recorded before any theory is shown, is the validator this folder can only ask for.

## 7. What shape means here, in one paragraph

A shape is the empty slot plus its constraints. For the neutron star EOS it is: a low-density band that returns something, a high-density pressure boundary that returns something, a non-updating observational corridor between them, and an open slot at `2 to 10 n_sat` marked `???`. The figure discipline refuses to fill that slot with a phase name, because the framework returns a kind of thing, never the answer itself, and because several sources can produce the same reading. The shape is checkable now: an expert can say what would refute it. The phase name is owed, not silence, and waits for an instrument.
