## 1. A shape is a constraint you can state before you can name the answer

The figures README says the framework reports *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32 says *"you get a kind of thing, never the answer itself."* Fig 13 :134 says *"Unreachable is a verdict here, not a silence"* and immediately adds that the framework cannot say which primitive is missing, because *"naming it would mean already holding it"* (Fig 13 :135).

From *The Library of Babel*, opened this session: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."* And on stopping: *"the finish line will also be the starting place"*, with the paradox that by the time you have the exact search terms you have *"composed the answer through the process of locating it."*

For INF-0066 a **shape** is therefore the following constraint set, stated before any number:

- classify by effect on the reach, not by subject matter;
- hold two currencies, bits and actions, with no asserted exchange rate;
- report per slot, not as one aggregate;
- run SEARCHED before INWARD and OUTWARD;
- count refusal as an action-changing item with a negative sign on the reach.

A single "correct value of information" number would be a **name**, and more specifically a name for a thing the framework says it does not hold. The honest form leaves the common scale marked `???`, the way the exemplar leaves `SPACE(???)TIME`.

## 2. How the shape is obtained

- *Library of Babel*: *"use the existing vocabulary you do know that is closest to the words that you wish to describe and grasp the shape of"*, then *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."* Here the close vocabulary is the field's own EVPI, EVSI and real-options language; the narrower terms are "wall", "reach", "atom", "contact" and "standing to be composed over".
- Fig 6 :30: *"outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*, as recorded in the exemplar: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is why the outreach email asks what the recipient would count as a failure rather than sending the framework.

## 3. What would license a name (a common currency, a single number)

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :12-13, Fig 6 :23, Fig 8 :50-52).

From *The Hard Problem is About Source*, opened this session: *"If several paths create the same behavior, then behavior is a projection with lossy information"*, and *"The answer is unreached until a better instrument exists."* The analogy for this question is exact. A single VoI number is a reading of a projection. It cannot comment on the source, that is, on which action space and which ground produced it. Several different action spaces can yield the same expected value. What is owed is a source-discriminating instrument, not a cleverer averaging rule.

*They're Scanning Books*, as recorded in the exemplar: *"The real import is not a new term in the existing space. It is a new dimension of the space."* A common scalar would be a new dimension only if an instrument actually discriminated sources. Declaring one does not make it neutral: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

## 4. A correction to the "shape, not a name" rule, applied here

The README's phrase governs a **missing** primitive. In this question, the two currencies are already named by the figures themselves: Fig 12 :126 says *"Bits price the description. Actions price finding out whether it holds."* Neither bits nor actions is missing. So saying "bits" and "actions" is not forbidden, and "shape, not a name" cannot be used to dodge the two-currency finding.

What **is** forbidden is inventing a third, unifying currency by declaration, or claiming a provenanced import where none exists. The exemplar made the same correction for Gradient and Spectrum (`06_isomers_and_order.md` Q1), and it applies here with the same force: naming held atoms is a binding; naming a missing primitive is a claim that must be refused until an instrument pays for it.

## 5. Prestige is not action, and the field's number is a budget

From *The Recursive Self-Improvement Trap*, opened this session: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* And: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."*

A computed EVPI gives an information-gathering action a budget. It does not settle which action is right, and a survey of practitioners who all trust the same textbook is a prestige loop, not a ground (Fig 2 :35, Fig 2 :40, Fig 7 :13). This is also why the package never asks a recipient to agree with the shape.

## 6. My own audit is a simulation, not a ground reading

Same essay, verbatim from the text opened this session: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post"*, but *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* The essay calls such output *"simulacra"* in the exemplar's wording.

So `01_figure_grounded_audit.md`, `06_isomers_and_order.md`, `07_the_tether_answer.md`, `08_expert_verification_packet.md`, `09_watson_answer.md` and `11_audit.md` are simulated derivations checked for internal consistency against the figures. They are **not** tests of the claim and are labelled `general` or `specified`, never `grounded`. They cannot settle the question they report on.

## 7. Q answered: what is the shape of the answer to INF-0066?

**The shape is a classifier and two ledgers, not a number.** It says what any acceptable answer must look like: effect-based classification by reach, bits and actions held apart, per-slot reporting, SEARCHED before INWARD and OUTWARD, refusal included, and an open `???` where a common scale would go. It does not say what the exchange rate is, does not rank specific information sources, and does not declare one field's VoI method the winner. The missing thing is characterized in effect terms: an instrument that discriminates among the sources that produce the same expected-value reading. Until one exists, naming it would mean already holding it (Fig 13 :135).
