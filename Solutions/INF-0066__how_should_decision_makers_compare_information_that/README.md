**Question:** How should decision-makers compare information that reduces uncertainty with information that changes what actions are possible?

**Source:** Information Theory.txt line 81

**Section:** 7. Learning, inference, and decision-making

**Mode:** `general` on the structural shape (two currencies, wall-moving versus within-closure search), `specified` on its application to decision-makers and value-of-information practice. **Status:** done

**Registry status:** pending

## What the question is asking, in effect terms

A decision-maker holds a library Γ, a belief b, a set of actions, and a residual `R = |Γ(b,a) − o'|` indexed per slot `s` (Fig 1 :11, Symbols table). Two kinds of information are offered:

- **Kind U (reduces uncertainty):** information that lowers `R` while leaving `closure(Γ)` and the set of composable actions unchanged. It is a better reading of the same wall.
- **Kind A (changes what actions are possible):** information that moves the wall, adds an atom, extends an instrument, changes contact, or refuses a held term. It changes which actions can be composed at all.

The residual under audit is the comparison itself: decision-makers price both kinds in one scalar and add them. The figures say the two are in different units and do not add (Fig 12 :125-130). The answer is a classification rule and two ledgers, not a single number.

## What an answer would look like (Direction bound as an ordinary term)

A checkable answer would (1) classify an item by its effect on the reach, not by its topic, (2) price it in both bits and actions without summing, (3) order SEARCHED before INWARD and OUTWARD, and (4) name the instrument that would collapse the two ledgers if one exists. This is written down before the derivation so it can accrue a residual like any other term (Formula step "Direction").
