## 1. Independent domain census

I redid the census from the residual line alone, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency. Symmetry: a threshold comparison of two quantities (Operators table :46-52), not a symmetric join. Scale: node, community, whole cascade, with the governing effect three steps out (Fig 11 :52).
- **Domain 1, topology.** Actors: nodes, edges, communities, bridges. Currency: adjacency. Anchor: measured adjacency. Partition question (which paths exist).
- **Domain 2, diffusion.** Actors: cascades, adopters, handoffs. Currency: transmissions. Anchor: observed cascade measurements. Union with content.
- **Domain 3, correction.** Actors: claims, fact-checkers, ground truth. Currency: corrections. Anchor: truth, which does not move when frames push on it. Partition question (anchor versus frame).
- **Domain 4, verification.** Actors: expert readers. Currency: agreement and residual. Anchor: the ground, never agreement. Independence zero in this simulated run.

Order by dependency: enumerate adjacency, then handoff, then anchor, then differential (Fig 3 :20-21). Describe the residual before picking a frame (Fig 9 :27-28).
