## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13: "Unreachable is a verdict here, not a silence,".

From *The Library of Babel*: "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So for this question a **shape** is:

> Recovery is a route whose regime is selected by the sign of the closing feedback loop and by whether the system's closure has changed; the disturbance does not carry its own outcome, the enumerated conditions do; a crossing back requires an import; and which basin a given ecosystem reaches is not named by the framework.

That shape constrains. It does not tell you that a particular lake will stay turbid, or that a particular forest will return. Naming those is ground work.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary closest to the thing, look for recurring terms that overlap with it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause".
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." For this question, the checkable description is: reversing the driver will not reverse the state, and the return path will differ from the outgoing path.
- *Library of Babel* on stopping: the finish line is also the starting place; by then you have "composed the answer through the process of locating it." Here that means the shape is only finished when the hysteresis test is stated in ordinary terms.

## 3. What would license a name

Only two things, both outside the shape:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." For this question: a hysteresis measurement in a named ecosystem.
2. **A provenanced import from a frame whose closure differs**, with a source gate and shadow test (Fig 6 :23, Fig 8 :50-52). The alternative-stable-state literature is such a frame; it is recorded with overlap in `10_source_ledger.csv` and corroborates, it does not overrule.

*They're Scanning Books* sharpens this: "The real import is not a new term in the existing space. It is a new dimension of the space." And: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." So even the six-term substrate is a visible guess, not nature's own list.

## 4. The specific forbidden error: naming a basin from a reading

*The Hard Problem is About Source* gives the mechanism. A spectrometer reads green and "cannot comment on the source": one green light, or yellow plus blue, or RGB, or CMYK. "If several paths create the same behavior, then behavior is a projection with lossy information." "An instrument that can't distinguish these cases demonstrates its own inadequacy." The spectrometer, not an argument, resolved it.

For this question the same error would be reading a recovering vegetation index and naming the basin ("it is returning to the clear state") when several basins could produce the same index reading. What is owed is a source-discriminating instrument (a hysteresis test plus the per-slot residual), not a name.

## 5. Q: does the framework return a regime name?

**No.** It returns the decision rule and the discriminating instrument. Which attractor is occupied is licensed only by the ground or by a provenanced import with a shadow test. Until then the slot stays open. This is the same limit the exemplar calls "shape, not a name", narrowed correctly: Fig 9 :32 and Fig 13 :134 govern what the framework can return, not what a measurement can discover.

## 6. Two consequences for this solution

**Prestige is not action.** From *The Recursive Self-Improvement Trap*, carried in the exemplar: "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A list of well-known ecologists gathered to agree with the regime claim is the named collapse, not corroboration. The legitimate ask is a budget to run the hysteresis test.

**This audit is a simulation, not a ground reading.** Same essay: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself"; LLM output is "simulacra". So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is not a test of any ecosystem and must be labelled as such. It cannot settle anything it reports on.
