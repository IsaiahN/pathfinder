## Independent domain census

I redid the census from the residual line alone, before relying on the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The gap between an endpoint held and a route wanted. Arity: four slots, so a dependency chain. Symmetry: routes are ordered, so `→` not `+`; the artifact-to-route map is many-to-one, so routes can be isomers (Fig 13 :121). Scale: first order inside a stage, second order at the membranes.
- **Domain 1, observation / ground contact.** Actors: instruments, readings, the ground. Currency: per-slot residuals. Anchor: the ground that does not move when pushed. Question type: is there a live reading and a stable anchor.
- **Domain 2, theory / composition.** Actors: frames, Γ, terms, bonds, imports. Currency: composition and settlement. Anchor: the ground via settlement. Question type: minting, import provenance, refusal.
- **Domain 3, institution / room chain.** Actors: institutions, peer frames, prestige. Currency: selection between rooms. Anchor: should be ground, often agreement. Question type: did the next room differ and match the residual it surfaced.
- **Domain 4, policy / convention / habitat.** Actors: policymakers, seats, habitat actors. Currency: conventions and outcomes. Anchor: consequences. Question type: the convention-to-outcome crossing and the far cascade.
- **Domain 5, verification frame.** Actors: archivists, independent frames. Currency: credibility and independence. Anchor: ground, never agreement. In this simulated run independence is zero because all seats share the evidence pool.

Order by dependency: settle the reading before the term, the term before the room, the room before the policy (Fig 3 :20). Describe the residual before selecting a frame (Fig 9 :27-28). Refuse before mint (Formula step 2). Measure the round trip at each membrane (Fig 4 :30).

My census matches the primary's five domains and its chain reading. Where the primary derived from Fig 13 and Fig 12, I derived from Fig 9's union/partition split and Fig 3's dependency order. Different starting figures, same boundaries: low overlap between routes, so the agreement is weak but not circular within the framework. It is still one evidence pool.
