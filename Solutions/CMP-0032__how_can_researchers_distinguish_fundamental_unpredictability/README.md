## The residual in effect terms

A forecast is made: `Γ(b,a)` against observation `o′`, and on some slot `s` the live residual `R⁺_s > 0`. Two explanations are on offer.

- **Fundamental unpredictability:** no composition in the current `closure(Γ)` reaches the target. The atom is absent. More data and better models inside this frame will not close the residual. (The figures call this *underivable in principle*.)
- **Incomplete data or imperfect models:** the term is already in the closure but was not found, or the channel to the ground is lossy, or the instrument is too coarse. More search, better data, or a sharper instrument would close it. (The figures call this *unreachable at this budget*.)

The residual is the question of which explanation the failure licenses and what would operationally discriminate them. Arity: two conditions. Symmetry: the failure is symmetric under cause (the same `R_s`), but the discriminator is a threshold comparison on where the wall sits, not a symmetric join. Scale: first order within one frame, second order across frames. Verdicts are kept per domain and never averaged.
