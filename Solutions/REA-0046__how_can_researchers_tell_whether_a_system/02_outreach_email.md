# Outreach draft: check the test before you decide about the framework

**Use:** one to one, or as a cover letter attached to a submission through the public venues in `03_public_contact_points.csv`. **Not** for bulk send.

**Hard precondition:** do not send until the shape claim in `01_figure_grounded_audit.md` is stated as `specified` and the refuter below is written down. The first contact carries the residual and the refuter, never the source (Fig 10 :52: "Bring a characterised residual, never the source.").

---

**Subject:** One checkable test for "does an internal representation mean something in the world?"

> Hi [name],
>
> I am working on a narrow question in representation meaning research and have one specific output I would like you to check against what you already know. I am not asking you to read the theory first, and I am not asking you to agree with it. If the output does not survive, there is nothing else to look at.
>
> **The output (`specified`, not `grounded`).** A claim that an internal representation X corresponds to a world structure W is a union of three conditions, not one question:
>
> 1. **Information:** X carries a decodable signal about W. Necessary, not sufficient, because a probe can learn the task itself.
> 2. **Causal role:** intervening on X changes the system's world-tracking behaviour with specificity, and intervening on W changes X as predicted.
> 3. **Structure:** X preserves the arrangement or relation, not merely the feature list. Two representations with the same features under different relations are different things.
>
> The shape of the test is: push on the world, not on the frame. A label such as "the W unit" is a declared meaning and does not become grounded by declaration. Convergence across independent seeds or laboratories is the strongest available corroboration, but only when a record shows the frames were actually independent. Agreement alone is a budget filter, not a witness. This is a prediction of the shape any checkable test must have, not a measurement and not a claim about any named unit in any named model.
>
> **What I am not claiming:** that any particular activation *is* a particular world structure; that high probe accuracy establishes meaning; that a crowd of agreeing researchers settles it; that a search which finds no correspondence proves none exists. The framework returns a shape, not a name.
>
> **What would refute the shape claim:**
> 1. a frame-internal quantity (probe accuracy, activation magnitude, output fluency) shown to settle correspondence with no anchor reading;
> 2. a representation that passes the anchor, independence and structure tests and then fails under a new intervention on the world;
> 3. a result showing that decoding W from X is sufficient for correspondence, with no causal or structural condition needed.
>
> I wrote these down before sending this. If any one holds, I will narrow or withdraw the claim. A one-line "this fails because..." is more useful to me than agreement. If you would rather not engage, no reply is needed.
>
> **What I would value from you:** tell me which of the three conditions your own work would treat as already settled, and what you would count as a failure of the other two. Please record that verdict before reading any framework material.
>
> **If it survives, and only then:** the sources are below. The figures, not my summary of them, are the authority.
> - Local figure text extract, verbatim with line numbers: `FRAMEWORK/reference/03-FIGURES_TEXT.md` in this project.
> - Canonical usage rule: `FRAMEWORK/reference/FIGURES_README_canonical.md`.
> - Public figures folder (SVG, branch `general-agent`): https://github.com/IsaiahN/tether/tree/general-agent/figures
>
> **If you want to use the machinery:** the formula is in the figures link. Run it on a problem you know well and can check against a ground. Write down what would refute your result *before* you run it, and state the mode of what you get. A reported failure is more useful to me than a reported success.
>
> [your name]

## Why this version is ordered this way

| the move | figure-grounded reason |
|---|---|
| Output first, theory second | Fig 10 :52 "Bring a characterised residual, never the source." The recipient checks the shape without holding the framework's interior. |
| Do not ask for agreement | Fig 2 :35 "Alignment is triangulation, not negotiation. A mirror cannot correct you." |
| Pre-registered refuter before conclusion | Seat rule: a falsifier written before the run is a design instrument, not only an honesty device. |
| Mode stated on every claim | `THE_FORMULA.md` mode rule: "Mode. general · specified · grounded. State which." |
| No claim that a named unit is a named structure | Fig 10 :49 "Declaring a meaning does not ground it." Fig 9 :32 "you get a kind of thing, never the answer itself." |
| Three conditions kept separate, never averaged | Fig 9 :54 "And when the split lands on a union rather than a partition, unbundle before you search again." Fig 9 :60 "Use filters for the budget and witnesses for the verdict. Never let a filter hand you a verdict." |
| Independence requires a record | Fig 8 :51 "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them". |
| Push on the world, not the frame | Fig 2 :29 "An anchor is whatever settles the question and does not change its answer because of what any frame thinks." |
| No request for trust or prestige | From *The Recursive Self-Improvement Trap*: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." |
| Offer the formula as a method to reuse | Fig 4 :22 "Only methods cross up. Only head starts come down." |
| Ask each user for their own ground and refuter | Formula "Direction": a frame cannot check the direction of its own question, so the sought-for shape must be bound as an ordinary term. |
| One-to-one, no bulk send | Fig 2 :40 "agreement about the world is worthless when the agreeing frames share an evidence pool." A mass send selected for receptiveness manufactures that pool. |
