# Solution CMP-0082

**Question:** Which network measurements remain reliable when data are incomplete, sampled unevenly, or collected through biased platforms?

**Source:** complexity science.txt line 101

**Section:** 9. Modeling, measurement, and reproducibility

**Mode:** `specified` on the structural claims, `general` on the refusal to rank named measures in the abstract, not `grounded`. No network was measured in this derivation.

**Status:** done

**Registry status:** pending

## Question as an effect

The question decides what follows for a network measure when the data feeding it are damaged in one of three ways. Option A: treat reliability as a property of a named measure and produce a ranked list. Option B: treat reliability as a property of a measure, a collection channel, and an independent ground, and refuse the list until per-slot residuals are measured. A leads to a ranking that a global average can make look stable while individual slots are wrong and that a platform can score itself. B leads to a shape that any reliable measurement must have, written refuters, and an open ranking until a ground settles it. The derivation takes B.
