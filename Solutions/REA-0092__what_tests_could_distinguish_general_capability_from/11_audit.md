## Independent domain census, written from the residual line alone

I redid the census before comparing it with the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** Two hypotheses produce one reading; what is missing is a separating observation. Arity: at least two conditions plus a comparison, so this is a **union compound** (Fig 9 :54-57), not one hard question. Symmetry: the comparison is ordered: familiar to novel is not novel to familiar, so → and ⋛ govern it, not +. Scale: one task loop, one family, the membrane between a training closure and a substituted habitat.
- **D1 Instrument.** Actors: items, generator, scoring rule, slots. Currency: per-slot residual. Anchor: the ground reading, not the score. Question type: partition, which items are inside the closure.
- **D2 Agent.** Actors: Γ, atoms, bonds, belief, reach. Currency: prediction error. Anchor: none in isolation. Admitted only with the habitat.
- **D3 Habitat.** Actors: novel tasks, conditions, consequences. Currency: contact. Anchor: the ground, which does not update.
- **D4 Provenance.** Actors: corpus, dates, item lineage. Currency: exposure, independence. Anchor: a dated public record.
- **D5 Checker.** Actors: outside frame, instrument, refuter. Currency: residual, not agreement. Anchor: ground; agreement disqualified.
- **X1 Agent-only general intelligence.** No nameable anchor. Not a domain yet.
- **X2 Score as verdict.** Absorbed into D1 as a filter.

Order by dependency: perception, vocabulary and objective, planning, learn and carry (Fig 3). I reached the same boundary as the primary but by a different route: I started from Fig 9's union/partition split and Fig 3's middle-link warning, whereas the primary started from the arity of the two hypotheses and Fig 11's capability claim. ## Round trip gap R_T

The Symbols table defines R_T as `gap(x, (T_E ∘ T_A)(x))`: what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

1. **Sent up (x):** the verbatim figure set, chiefly Fig 11 :39-40 and :66-70 (capability and habitat), Fig 1 :19-22 (per-slot indexing), Fig 8 :50-52 (provenance), Fig 10 :42-43 (non-access), Fig 6 :27 (depth versus absence), Fig 3 :25-27 (middle link).
2. **Abstraction (T_A):** the shorthand in `07`, namely "substitute the habitat, report per-slot curves, date exposure, use independent anchors, separate depth from absence, instrument vocabulary."
3. **Concretisation (T_E):** a practical test protocol someone could implement tomorrow: a novel-task suite, a scoring script, a cutoff date, two evaluators and a failure threshold.

**R_T is nonzero.** Four things the shorthand holds do not survive the trip back down without explicit extra decisions:

- **What counts as a substituted habitat.** Fig 11 says isolation is substitution, but it does not say which actors must be reproduced. A test designer must decide this from the habitat enumeration in Fig 11 :43-48, and that decision is not in the shorthand.
- **Who sets the threshold in the ⋛ comparison.** Operators table defines comparison as a threshold relation, but the threshold itself is a convention. Fig 10 :47-48 warns that a convention that decides an outcome has stopped being one. The shorthand does not record who fixed it or when.
- **How independent is independent.** Fig 2 :31 gives the quantity, not a measurement procedure. Two evaluators using the same generator are one frame wearing two names; the shorthand "independent anchors" does not by itself prevent that.
- **How the vocabulary link is instrumented.** Fig 3 :27 says the link needs an instrument and provides none. Any concrete probe is an import from psychometrics or cognitive science and must be sourced as such.

Conversely, one thing survives cleanly: capability is agent-and-habitat, so a held score cannot be the discriminator. That is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the six test properties are the figure set in fewer words" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
