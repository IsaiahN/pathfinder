# Solution REA-0092: figure-grounded package

**Question:** What tests could distinguish general capability from competence limited to a narrow set of familiar tasks?

**Source:** reasoning.txt line 113
**Section:** 10. Evaluation, safety, and social consequences
**Field for public contact points:** general capability tests research

**Mode:** `specified` on every substantive claim about what a test must do; `general` on the structural shape of the discriminator. Nothing here is `grounded`, because no test described in this folder has been run against a system.

**Status:** done

**Boundary.** All work happened inside this folder. The registry, the question files and every other solution folder were read only. Figure citations come from `FRAMEWORK/reference/03-FIGURES_TEXT.md` and are checked verbatim. World sources were opened on 2026-11-24 and are recorded in `10_source_ledger.csv`.

**What an answer would look like (bound as an ordinary term before the run).** A test is discriminating when, holding the system fixed, it can return two different outcomes for a genuine general capability and for a specialist whose competence is confined to familiar tasks, where both outcomes are measured against an anchor that neither the system nor the test designer can move. The sought-for shape is therefore a *differential instrument*, not a score. This is the "Direction" discipline from `THE_FORMULA.md`: write down what an answer would look like, bind it, and let it accrue a residual like anything else.

## What is deliberately not here

- No personal emails of named individuals.
- No ranking of people by how likely they are to agree with the derivation.
- No bulk-send plan.
- No claim that any named system is or is not generally capable. That would be a ground verdict, and no ground reading was taken.
- No claim that the framework returns a number for a capability quotient. It returns a shape, that is, a constraint on what a discriminating observation must look like.

Three reasons from the figures for the outreach refusals:

1. **Agreement is not a verdict.** Fig 2 :35: *"Alignment is triangulation, not negotiation. A mirror cannot correct you."*
2. **Correlation disqualifies a verdict.** Fig 2 :40: *"agreement about the world is worthless when the agreeing frames share an evidence pool"*. Selecting recipients for receptiveness manufactures exactly the shared pool that makes their agreement worthless.
3. **A checker that can rebuild the claim cannot check it.** Fig 10 :42: *"A verifier that can reconstruct the claim cannot verify it."* The first contact therefore carries only the residual and its refuter.
