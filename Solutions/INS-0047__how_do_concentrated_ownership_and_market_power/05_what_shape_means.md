## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns 'what a missing thing would have to look like (a shape, not a name)'. Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :134: "Unreachable is a verdict here, not a silence,"

From *The Library of Babel*: 'You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question.'

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question, the shape is: the rule changes kind, the anchor that should settle competition moves, ownership reaches labor through an unnamed structure, the change is second order and recursive, provenance decides, and the signal is per slot. Naming a captured agency or a concentration threshold would be a name.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. 'With each new term gained, you narrow the space and deepen your vocabulary.'
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: describe the effect rather than the cause.
- *Decoding Tacit Knowledge*: 'When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world.'
- *The Library of Babel* on stopping: the answer is reached when the finish line is also the starting place, and the paradox is that the answer was composed through the process of locating it.

Applied here, the effect terms are wages, prices, entry, enforcement record, and rule provenance. The question itself supplies the vocabulary of competition and labor; the figures supply the rule about what may compose with what.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: 'the ground settles it. Verified only by what pays. A gate is not the ground.' The README: the framework stops at the limit of what the available instruments can distinguish and records the lineage so the stop is honest.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

*They're Scanning Books* sharpens this: 'The real import is not a new term in the existing space. It is a new dimension of the space.' And: 'A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six.' Also: 'Declaring the primitives does not make them neutral. It makes the choice visible.'

The six are a visible guess, not a discovery of nature's own list. In this question, binding a firm to a state role and a rule to a structure role is a visible choice. Naming that rule as the captured one turns a visible choice into an invisible one.

## 4. Why a name read off a projection is the forbidden error

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and 'cannot comment on the source', one green light, or yellow and blue, or RGB, or CMYK, or a scheme not yet discovered. The reading does not determine the source. 'If several paths create the same behavior, then behavior is a projection with lossy information.' And: 'An instrument that can't distinguish these cases demonstrates its own inadequacy.' It was the spectrometer, not an argument, that resolved it.

Here the corresponding error is reading a rule's wording and naming its source as capture. A captured rule and an independently derived rule read the same on the page. Fig 8 :51: "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them, and the surplus lives only where the closures" differ. What is owed is a better instrument, meaning provenance and enforcement records, not a name.

*The Recursive Self-Improvement Trap*: 'the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself.'

## 5. Correction to an overstatement of the shape-not-a-name rule

The README's phrase is 'what a **missing** thing would have to look like (a shape, not a name)'. The subject is a missing primitive, one not held in the library. In `01_figure_grounded_audit.md` F3, the binding of institutional actors to state and structure roles uses atoms the framework already holds. That binding is not the invention of a new primitive and is not an import that moves the wall (Fig 6 :21, 'MINT composes inside the closure and can never add an atom').

What remains forbidden here is naming which rule in which market is the captured one, and deriving a threshold from the figures. That is a name where the framework returns a shape, and it is also a metamerism error: a source named from a reading that several sources could produce. Both claims are recorded so neither is quietly lost.

## 6. Two consequences for this question

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: 'Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige.' A campaign that gathers prestigious economists to agree that concentration is harmful is the named collapse, not corroboration. The legitimate ask gives the claim a budget to be tried and lets an enforcement record, a wage series, or a provenance chain settle it.

**This audit is a simulation, not a ground reading.** Same essay: 'LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself.' LLM output is 'simulacra'. So `01` is a simulated derivation, checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle anything it reports on.
