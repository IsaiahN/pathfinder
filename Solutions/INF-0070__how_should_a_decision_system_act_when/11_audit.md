## Round trip gap `R_T`

The Symbols table defines `R_T` as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

2. **Abstraction (T_A):** the shorthand carried in `07` §2 and `09` VERDICT: split first, search where search can pay, keep the live slot, refuse false premises, keep contact, report unreachable as a verdict.
3. **Concretisation (T_E):** a working decision procedure in a risk-analysis setting, for example "adopt maximin with a fixed payoff matrix and stop."

**`R_T` is nonzero.** Five things the shorthand holds do not survive the trip back down:

- the **union split** (budget-limited versus genuine absence), which a single fixed criterion erases;
- the **no-proof-of-absence rule**, which a stop rule that treats "not found" as "impossible" breaches;
- the **per-slot residual**, which a single expected value aggregates away;
- the **refusal rule**, which a payoff matrix cannot express because it has no negation operator over its premises;
- the **channel and independence rules**, which a one-shot criterion has no place for.

Conversely, one thing survives cleanly: the need to act without manufacturing a discriminator and to report what would reverse the stop. That is the residue worth sending. `R_T` was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set `R_T` to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a measured gap, which is what `09_watson_answer.md` states.
