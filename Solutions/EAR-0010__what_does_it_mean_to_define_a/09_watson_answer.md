## QUESTION

Decide, in effect terms, what it means to define a "safe" or "stable" Earth system when natural conditions have always varied. Option A: define both as one global value or band relative to a fixed reference period. Option B: define them as violable, per-slot, per-disturbance relations to a ground that does not move when the definition is renegotiated, with the comparison and persistence senses kept apart. What each leads to: A gives one announceable number whose baseline can be renegotiated and which can hide a live slot; B gives no single comforting number but yields checkable claims, written refuters and an honest `gap` where numbers are owed.

## VERDICT (from the figures)

The shape survives; a single global definition and a number do not. A non-arbitrary "safe" or "stable" label is a violable, per-slot, per-disturbance relation to a ground that does not move when the definition is renegotiated. "Safe" is a threshold comparison, "stable" is a maintained cycle whose sign matters, and they are two conditions that must be checked separately. Stability is permanent work, not a solved state, and variability stays in the signal. Smoothness and "climate states" are derivatives, not primitives. Numeric thresholds are `gap`: the figures return a shape, never a name. This is `general` plus `specified`, ungrounded, candidate.

- **cost if wrong:** bounded and locatable. The packet states mode, sub-claims and refuters before the conclusion, so an error is findable rather than invisible. The real cost is spending an outside reader's independence by sending a finished definition instead of a generator, which Fig 2 :42 prices: "Buy independence in proportion to the cost of being wrong." That cost is avoidable by leading with the shape claim and its refuter.
- **undoable:** yes. A defective global definition can be replaced by the per-slot version without withdrawing the derivation; `07_the_tether_answer.md` and `08_expert_verification_packet.md` already do this. No primitive has to be removed from the six, and no number has to be retracted because none was asserted.
- **reversed by:** a ground reading, not agreement. An instrument that shows a global aggregate preserves every per-slot live residual would break the aggregation verdict; a definition shown to be grounded by declaration with a non-updating anchor would break the grounding verdict; a state shown to be a solved point requiring no maintenance would break the stability verdict; a demonstration that comparison and cycle reduce to one bond would break the two-bond verdict; a figure line governing a numeric climate threshold would close the `gap`. Until one of these fires, the verdict stands as `candidate`.
