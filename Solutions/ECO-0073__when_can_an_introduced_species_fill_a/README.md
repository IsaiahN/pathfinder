## Restating the question as an effect

An ecosystem has lost a function (pollination, seed dispersal, predation, nutrient cycling). A manager adds an organism that was not there. Two outcomes are possible from the same act: the lost function returns, or new residuals appear that the frame did not predict. The decision is which conditions produce which outcome, and whether one act can produce both at once.

What an answer would look like, bound as an ordinary term before the run (Formula step "Direction"): a set of conditions on the habitat and the introduced actor, stated per residual, such that the outcome is determinable at the ground. The sought shape is *a relation plus a set of conditions*, not a species name. It is written down here so it can accrue a residual like anything else.
