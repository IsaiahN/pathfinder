## 1. A shape is a constraint, not a filler

The canonical usage rule states the limit: the framework returns *"what a missing thing would have
to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13: *"It can say the answer is out of reach with the library as it stands... It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- **A shape:** scrambling is a rate at which a remainder compounds across crossings, and any limit on it is a budget filter whose domain of validity must be named.
- **A name (not supplied):** one numeric constant, one exponent formula, one Hilbert-space dimension, asserted as *the* universal speed limit.

## 2. How a shape is obtained

- *The Library of Babel* on vocabulary: *"If you don't know the right terms to search for, you will have to use the existing vocabulary you do know that is closest to the words that you wish to describe and grasp the shape of."* And: *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* So the residual is described as an effect (information delocalizes; a correlator grows then saturates; a bound prices the budget) before any frame (black holes, strange metals, cold atoms) is chosen.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is exactly the outreach order in `02_outreach_email.md`.
- *The Library of Babel* on stopping: *"You will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better."* And the paradox: *"you have already composed the answer through the process of locating it."*

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* For scrambling, that means an OTOC measurement or an experiment that distinguishes the regimes, not a further argument.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test. The specific bounds (2πT/ħ, the entropy/temperature minimum time, Lieb-Robinson velocity) are imports of this kind. They are recorded with provenance in `10_source_ledger.csv`; they are not framework outputs.

*They're Scanning Books When They Should Be Studying Nature* sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

## 4. Why a single "universal speed limit" is the specific forbidden error

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*; the same reading can come from several different compositions. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the **spectrometer**, not an argument, that resolved it.

Applied here: a measured saturation time or exponent is a projection. Several different mechanisms (local interactions, all-to-all couplings, near-extremal geometry, finite entropy) can produce the same reading. Naming the source as "one universal bound" from the reading alone is the metamerism error. What is owed is a source-discriminating instrument, not a name.

*The Recursive Self-Improvement Trap*: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* This package cannot certify its own universality claim.

## 5. Correction to my own §3 (important)

I initially read the "shape, not a name" rule as forbidding the use of any specific bound. That was an overstatement. The canonical phrase governs **a missing primitive**, a thing not held in the library. The bound quantities here are not missing primitives of the framework: chaos and finiteness are already available as derived and substrate terms (Fig 13 :32, :14). Naming a specific physical bound is a **binding from the physics frame** onto an available description, not the invention of a seventh term.

What remains wrong is different: presenting that binding as a framework derivation, or as moving the wall. Fig 6 says *"IMPORT adds an atom"*, and this binding adds none to the framework's primitives. Both readings are now recorded so neither is quietly lost. Triangulated (canonical rule + Fig 13 + Fig 6), `specified`.

## 6. Two consequences for this question

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous names agreeing that the limit is universal is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* And the architecture article: outputs *"could never be verified if the solutions presented were not contrived to fit the formula."* So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It cannot settle whether scrambling sets a universal speed limit.
