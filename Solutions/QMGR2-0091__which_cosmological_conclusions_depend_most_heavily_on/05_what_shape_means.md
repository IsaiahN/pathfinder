## 1. A shape is a constraint, not a filler

The local figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32 "you get a kind of thing, never the answer itself". Fig 13 :134 "Unreachable is a verdict here, not a silence".

From *The Library of Babel* (carried): "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

For this question a **shape** is the narrowed form of the answer we can state before we can measure it. "Dependence is distance from a non-updating anchor, amplified by chain length and evidence-pool overlap" is a shape. "H0 is 73.04 km/s/Mpc and that is the most model-dependent number by X sigma" is a name, and the figures do not return it. The shape constrains, it does not fill.

## 2. How the shape is obtained here

- *Library of Babel* (carried): use the vocabulary closest to the thing, look for recurring new terms that overlap with it, recurse; "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause." So the residual is described as **movement under swap of calibration or model**, not as a theoretical defect called "model dependence". The phrase "model dependence" is a borrowed label; the effect is what can be checked.
- *Decoding Tacit Knowledge* (carried): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." Hence the outreach email asks what the recipient would expect to see if the separator were true.
- *Library of Babel* on stopping (carried): the finish line is also the starting place, because the answer is composed through locating it. Here the stop is the instrument owed in F9, not a claim that the ranking is known.

## 3. What would license a name (a numeric ranking)

Two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: the ground settles, verified only by what pays. Here that means a real cross-model, cross-calibration sensitivity analysis with the overlap matrix recorded. No such analysis is performed in this folder.
2. **A provenanced import from a differing closure.** Fig 6 :23 "No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs." A published sensitivity table could be imported, but only with a source gate and a shadow test: does it explain a gap we already described?

*They're Scanning Books* (carried): "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "Declaring the primitives does not make them neutral. It makes the choice visible." Applying this: choosing which conclusions to rank is already a visible choice, and the ledger records it.

## 4. Why the ranking cannot be forced from the shape

*The Hard Problem is About Source* (carried) gives the mechanism. A spectrometer reads green but "cannot comment on the source": one reading, many possible sources. "If several paths create the same behavior, then behavior is a projection with lossy information." In cosmology, the same observed H0 posterior can be produced by a Cepheid-calibrated ladder, a TRGB-calibrated ladder, or a ΛCDM extrapolation from the CMB. The reading does not determine the source. What is owed is a discriminator that can tell which leg contributed how much, not an argument about which name to attach.

*The Recursive Self-Improvement Trap* (carried): "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." That is why this document calls itself a simulation.

## 5. What "shape" does and does not govern here

The phrase "shape, not a name" governs a primitive **not held** in the library. It does not forbid naming quantities we already hold: H0, the sound horizon, the acoustic scale and the base parameters are all already in the physics library. Naming them is a binding from the physics frame onto held terms, not the invention of a new primitive. What remains forbidden is inventing a seventh sensitivity primitive or claiming that a binding moves the wall (Fig 6 :21 "MINT composes inside the closure and can never add an atom").

So, precisely:

- allowed and done: name the conclusions, name their anchors, rank the mechanisms;
- not done and declared: return the numeric per-conclusion sensitivity ordering (F9);
- refused: claim that the simulated derivation has settled which conclusion actually depends most heavily.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried): "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." Counting how many famous cosmologists agree with a ranking is the named collapse, not corroboration. The legitimate ask is a budget to try the separator.

**My own audit is a simulation, not a ground reading.** Same essay (carried): "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." LLM output is simulacra. So `01` and this file are simulated derivations checked for internal consistency against the figures. They are not tests of the ranking and must be labelled as such.

## 7. Low-overlap corroboration opened this session

The Stanford Encyclopedia entries supply an external version of the same shape limit, from philosophy of science rather than from the framework author:

- *Measurement in Science* (opened): "This threat is especially clear when the theoretical hypothesis being tested is already presupposed as part of the model of the measuring instrument." This is the general form of the sound-horizon case.
- *Theory and Observation in Science* (opened via search index, reduced weight): "it is usually impossible for investigators to draw conclusions to test theories against observational data without explicit or implicit reliance on theoretical resources."
- *Underdetermination of Scientific Theory* (opened via search index, reduced weight): Duhem's point that a failed prediction does not reveal which background hypothesis was at fault. This is why a tension does not by itself name the model that must change.

These entries corroborate the mechanism shape only. They carry no information about which cosmological conclusion actually has the largest sensitivity coefficient. Overlap with the eight essays is low in subject matter but high in the fact that all are secondary readings; none is a ground measurement.
