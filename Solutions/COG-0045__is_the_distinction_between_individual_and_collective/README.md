## Restating the question as an effect

Two options must be separated before either is tested.

- **Option U (universal):** the individual/collective distinction is a fixed feature of personhood. It should register with the same form and the same weight in every social organization. One instrument should travel unchanged, and theory may assume the distinction everywhere.
- **Option C (contingent):** the distinction's form recurs but its importance is a property of a person in a habitat. It should register with different weight as social organization changes. An instrument must be re-validated per context, and a single universal scale will read the same value for different sources.

What each leads to is the point. U licenses a universal measure and a universal theory of identity. C licenses a measure with an explicit habitat term and a refusal to read source off a single score.
