## Independent domain census

I redid the census from the residual line before relying on the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is present configuration versus reference configuration after rewiring by an introduced actor. Arity: two configurations compared over a network of relations, not one scalar. Symmetry: ordered, a comparison rather than a symmetric join, so return and flip are distinct. Scale: first order direct contact, second and third order cascade, per slot. Because two conditions bind (selection without a seat, and a seat that cannot subtract), this is a **union compound** and must be unbundled (Fig 9 :54).
- **Domain 1, unmaintained habitat.** Actors: species, pathogen, resources, conditions. Currency: survival and contact. Anchor: what the ground kept. No seat; selection runs.
- **Domain 2, maintained habitat.** Actors: managers, control tools, introductions, engineers. Currency: introduction only. Anchor: the field outcome. The seat adds to a habitat it did not author, so D1 and D2 overlap. Union, not partition.
- **Domain 3, measurement.** Actors: ecologists, plots, time series, interaction estimates. Currency: residuals. Anchor: a field measurement. In this simulated run its independence is zero, since all three domains draw on one evidence pool.

Order by dependency: enumerate the habitat to the order where the cascade stops mattering, state the objective as a comparison, then plan, then learn and carry (Fig 3, Fig 11 :44). The objective link has no dedicated instrument, so effort above it cannot rescue it.

My census matches the primary's three domains and its union reading. Where the primary derived from Fig 11 and Fig 12, I derived from Fig 9's union/partition split and Fig 3's dependency chain. Different starting figures, same domain boundaries: low overlap between routes, so the agreement is weak but not circular within the framework. It is still one evidence pool.

## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

1. **Sent up (x):** the verbatim figure set, chiefly Fig 11 :43-44, :52-53, :61, :63, :66; Fig 12 :5, :117, :121, :125-126; Fig 1 :19 and Fig 3 :10.
2. **Abstraction (T_A):** the shorthand in `07_the_tether_answer.md`: recovery is a per-slot, bond-level comparison against a stated reference, over an enumerated cascade, with loop sign and a seat statement; the universal yes/no is a gap.
3. **Concretisation (T_E):** a field claim that a given invaded lake has recovered after eradication.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down:

- the **choice of reference configuration**, which the abstraction marks as declared but which a concrete report tends to smuggle in as the pre-invasion baseline;
- the **cascade cutoff**, which the abstraction says is "where the cascade stops mattering" but which a field programme must fix in advance with a stated order and instrument;
- the **substitution obligation**, which the abstraction records but a concrete eradication report routinely drops, treating removal as restoration.

Two things survive cleanly: the species list is not the state variable, and the seat's work is permanent. That is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
