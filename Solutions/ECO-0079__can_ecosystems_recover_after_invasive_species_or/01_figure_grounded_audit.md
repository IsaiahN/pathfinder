## 0. The residual in effect terms

The question asks for a prediction of whether a changed interaction network returns to a stated reference after an introduced actor (invasive species or pathogen) rewires it.

- **Option A.** Recovery is a property of the ecosystem. If the species list returns to baseline, the system has recovered. Management aims to remove the invader and then stop.
- **Option B.** Recovery is an ordered comparison against a reference configuration, measured per object slot, at the level of bonds (who interacts with whom, with what strength and sign), with cascades reaching beyond direct contact, and with an explicit seat (if any) doing the work.

What each leads to:

| option | leads to |
|---|---|
| A | species counts stand in for interaction structure, removal is read as restoration, live slot residuals disappear into an average, management is treated as a solved state |
| B | the reference must be named, the habitat enumerated outward, bonds measured rather than inferred from presence, the loop sign tested, and the permanence of any seat's work priced |

The sought-for shape, written down and bound before the run (Formula "Direction"): *a named reference configuration, a per-slot interaction-strength comparison, a contact cascade enumerated to the order where the residual stops mattering, the sign of the feedback loop that either recloses or flips the web, and an explicit seat statement.* A frame cannot check the direction of its own question, so the shape must be made an ordinary term that can accrue a residual and be refused.

## 1. Domain census (before any figure line was chosen)

R by arity, symmetry, scale:

- **Arity:** two configurations are compared (present state against reference), and the comparison sits over a network of relations among actors, not over a single scalar.
- **Symmetry:** ordered. A comparison bond is ordered (Fig 12 :85-89, "is it about which is larger, rather than both being present? Yes."). Present against reference is not interchangeable with reference against present; a return and a flip are different results.
- **Scale:** first order is direct contact, second order is the cascade, and the meaningful residual can be three steps out (Fig 11 :52-53). Per-slot, never aggregate (Fig 1 :19).

One line per domain (actors / currency / anchor). A domain without a nameable anchor is not yet a domain:

| domain | actors | currency | anchor | status |
|---|---|---|---|---|
| D1 unmaintained habitat | native species, invader or pathogen, resources, light, water, season, terrain | survival and contact; what persists | what the ground kept (Fig 11 :14-15) | domain, no seat |
| D2 maintained habitat | managers, control tools, reintroductions, engineers | introduction (never subtraction) | the field outcome, which does not update when a frame changes its mind | domain, with seat |
| D3 measurement / verification | ecologists, plots, time series, interaction-strength estimates | residuals | a field measurement, not agreement | domain, anchor is the ground |

**Partition or union?** A **union compound**, not a partition. A managed ecosystem still runs unmaintained selection beneath the seat; "In neither mode is the habitat composed: unmaintained nothing composes it, maintained the seat adds to a habitat it still did not author" (Fig 11 :63-64). Fig 9 :54: "And when the split lands on a union rather than a partition, unbundle before you search again." A case in two conditions is not a harder case of either. So the question must be split into D1 and D2 before any search, and each gets its own verdict.

**Dependency order (Fig 3):** enumerate the habitat (Fig 11 :43-44) → have terms for what a situation affords (Fig 3 :7) → be able to say what would count as progress (Fig 3 :10) → plan under incomplete information → learn and carry. The middle link, having terms for what affords recovery and stating the objective, is the one with no instrument (Fig 3 :25-27: "A link with no instrument is not a link that works. It is a link nobody has looked at."). Effort spent above the break cannot rescue a link below it.

**Strain test applied before concluding.** An early reading tried to make Fig 12's comparison bond ⋛ carry the whole "recovery" comparison. Strain: the Operators table defines ⋛ as "a threshold relation between two quantities", while a food-web comparison is over a network of many slots. Re-census: Fig 3 :10 governs the objective (what counts as progress), ⋛ governs a threshold between two quantities. Different quantities, so no strained reading is kept. Recorded in §7.

## 3. Findings

### F1: Recovery is a comparison, not a property (D3, `specified`, triangulated)

Fig 3 :10: "it can say what would count as progress here, in its own terms"

Operators table :49: "a threshold relation between two quantities"

World corroboration: Carpenter, Walker, Anderies and Abel 2001, "To assess a system's resilience, one must specify which system configuration and which disturbances are of interest."

The word "recover" is incomplete until the reference configuration and the disturbance are named. Without them the sought-for shape is a preference, not a term: Formula "Direction" says a frame "cannot check the direction of its own question, because the shape a frame is searching for is not a term it holds." Binding the reference as an ordinary term is what makes the claim refusable.

**Refuter:** a case where recovery is established, reproduced, and agreed without any stated reference configuration or disturbance, as an intrinsic scale-free property of the system. If that holds, the comparison claim fails.

### F2: The species list is not the substance; the bonds are (D1/D2, `specified`, triangulated)

Fig 12 :5: "A set of ingredients is not one. The bond is the rest of the information, and it is the half nothing was recording."

Fig 12 :117: "isomer. Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."

Fig 12 :95: "Two entries with an identical ingredient set are not variants of one thing."

World corroboration, independent evidence pools: Holling 1973, "Resilience determines the persistence of relationships within a system and is a measure of the ability of these systems to absorb changes of state variables, driving variables, and parameters, and still persist." Ings et al. 2009, "it is increasingly evident that it is the distribution of interaction strengths and the configuration of complexity, rather than just its magnitude, that governs network stability and structure."

Two webs with the same species can be different substances. A census that records which species are present has recorded half of itself. Return of the list is not return of the web.

**Refuter:** a controlled case in which the species list returns to the reference, all measured interaction strengths and signs are identical to the reference, and the system nevertheless behaves as a different substance on every response variable. If that holds, the bond claim adds nothing and fails.

### F3: Per-slot residual, never an aggregate index (D3, `specified`, triangulated)

Fig 1 :19: "The residual is indexed by object slot, not aggregated."

Fig 1 :22: "Aggregating across slots is how a live signal disappears into an average."

World corroboration: Dakos and Kéfi 2022, "engineering resilience, that is the rate with which a system returns to a reference state after a disturbance". Their review also reports that engineering metrics were measured empirically far more often than ecological ones, and that "measuring ecological resilience has remained elusive".

A single ecosystem-health index can near zero while one interaction slot carries a live residual. "a global R near zero with one live slot residual is a legal state" (Fig 1 :13).

**Refuter:** a demonstrated case where an aggregate index predicts every per-slot failure as well as the per-slot time series does. If so, the per-slot requirement is unnecessary and is withdrawn as a requirement, though it remains as a check.

### F4: Contact cascades beyond direct contact (D1/D2, `specified`, triangulated)

Fig 11 :43: "The habitat is enumerated, never composed."

Fig 11 :52-53: "And contact cascades. Scoping the habitat to direct contact is how DDT reached the eagles: first-order enumeration, second-order effect, and the residual that mattered was three steps out."

Fig 11 :44: "List everything in contact with the residual, then what is in contact with those, and outward until the cascade stops mattering."

World corroboration: May 1972, "too rich a web connectance (too large a C) or too large an average interaction strength (too large an a) leads to instability." The figure's own citation record names Carson 1962 for the cascade case.

A pathogen or invader changes first-order contacts, and the residual that matters can be three steps out. Short-horizon monitoring scoped to direct contact is first-order enumeration with a second-order surprise.

**Refuter:** a case where enumeration to first order predicts the third-order outcome as well as full enumeration, across repeated events. If so, the cascade requirement is relaxed for that class.

### F5: "Invasive" is a relation, not a kind with fixed valence (D1/D2, `specified`, triangulated)

Fig 11 :49: "An actor's valence is relative to the residual, not a property it carries."

Fig 11 :50: "The same actor is a benefactor to one residual and a malfactor to another, so mutualism and parasitism are relations rather than kinds."

World corroboration: Simberloff et al. 2013, "Species are neither and, furthermore, invasion pertains to the population level, not the species level."

The question cannot be settled by labelling the actor. The relation between the actor and the chosen reference decides the valence. The same introduced species can restore one interaction and break another, which is why a single "recovered, yes or no" verdict averaged over slots is a category error.

**Refuter:** an actor whose valence is invariant across every reference configuration and every slot tested, such that the relation adds nothing over the kind label. If found, the valence claim fails for that actor class.

### F6: Removal is substitution; introduction is available, exclusion is not (D2, `specified`, triangulated)

Fig 11 :61: "The seat's power is asymmetric. Introduction is available; exclusion is not."

Fig 11 :66: "Isolation is not removal of the habitat. It is substitution of one habitat for another."

Fig 11 :68-69: "is invisible until the goal fails" and "is invisible until it acts" (the two silent failure modes: what you failed to reproduce, and what you brought with you).

World corroboration: Jones, Lawton and Shachak 1994, "Ecosystem engineers are organisms that directly or indirectly modulate the availability of resources to other species, by causing physical state changes in biotic or abiotic materials." The figure itself cites this paper at Fig 11 :65.

Eradicating an invader does not subtract its interaction from the world. It substitutes a habitat. The failed reproduction is invisible until the goal fails, and the accidental introduction is invisible until it acts. The correct operator is substitution (isolation), not subtraction.

**Refuter:** a case where removal of an actor genuinely removes a contact with no substituted habitat and no introduced replacement, and the reference is regained without any further introduction. If that holds, the asymmetry law fails.

### F7: Managed recovery is permanent work; unmaintained recovery is a label applied afterwards (union, `specified`, triangulated)

Fig 11 :63: "Which is why a managed ecosystem is permanent work rather than a solved state."

Fig 11 :14-15: "nothing selects; what survives is what the ground kept"

Fig 11 :36: "Where nothing maintains anything, intelligence is a label applied afterwards to a lineage that met its ground."

World corroboration, engineering field: Hollnagel via the Resilience Engineering Association 2019, "A system is resilient if it can adjust its functioning prior to, during, or following events (changes, disturbances, and opportunities), and thereby sustain required operations under both expected and unexpected conditions." World corroboration, business field: Su and Junge 2023, "Organizational resilience refers to a firm's ability to cope with and recover from adversity by adjusting and preserving (or improving) its functions."

In D1 no one chooses and what survives is what the ground kept; "recovery" is a retrospective label. In D2 a seat acts, and the work does not terminate at a solved state. Both halves matter and they are a union, so neither verdict is averaged into the other.

**Refuter:** a maintained system that reaches the stated reference and stays there with zero further seat action across the full disturbance regime, or an unmaintained system where a planner's reference is met by selection with systematic regularity that the label cannot explain. Either would break the asymmetry of this finding.

### F8: The loop sign decides whether the web recloses or flips (D1/D2, `specified`, single-source for the figure, corroborated by two independent fields)

Fig 12 :121: "cycle. The output re-enters as input. The sign of the loop decides whether it closes, and a chain cannot close by construction."

World corroboration: Scheffer et al. 2009, "work in different scientific fields is now suggesting the existence of generic early-warning signals that may indicate for a wide class of systems if a critical threshold is approaching." May 1972 confirms "a very sharp transition from stable to unstable behaviour as the complexity (as measured by the connectance and the average interaction strength) exceeds a critical value."

This is the real ground question. Food webs are cycles, and recovery is a question about feedback sign and basin of attraction, not about counts. The figure supplies the shape (sign decides closure); the threshold itself is ground-only.

**Refuter:** a system whose feedback sign is unchanged after the perturbation but which nevertheless flips to a different basin, or one whose sign reverses and still recloses. Either would break the sign-to-closure claim.

### F9: Two currencies: a cheap inventory and an expensive intervention do not add (D2/D3, `specified`, triangulated)

Fig 12 :125: "A composition costs in two currencies, and they do not add."

Fig 12 :126: "Bits price the description. Actions price finding out whether it holds."

World corroboration: Dakos and Kéfi 2022, "quantifying resilience in practice remains for some a struggle and for others an abstract metaphor."

A species inventory is cheap in bits and may cost one action to refute. A three-step cascade measurement over interaction strengths is expensive in actions. Neither figure predicts the other; summing them into one index is the named error, not the fix.

**Refuter:** a demonstrated conversion that trades description bits for field actions at a fixed rate across systems, such that the two readings genuinely add. If found, this finding is withdrawn.

Fig 13 :134: "Unreachable is a verdict here, not a silence,"

Fig 8 :39: "So a search that finds nothing is never a proof of absence."

Fig 9 :32: "you get a kind of thing, never the answer itself"

2. **INWARD:** extend the instrument from one already returning something. The recovery-rate time series is already returning a signal (Scheffer 2009; Dakos and Kéfi 2022). Sharpen it per slot and per bond. Do not read this against OUTWARD (Fig 6 :31).
3. **OUTWARD:** import from the frame whose closure predicts the shape. This is `gap` in the precise sense: the framework has a decidable answer to the shape of any answer, and no answer to the universal instance. "Unreachable is a verdict, not a silence."

**Refuter for the gap verdict:** a figure line, checked verbatim, that states a universal condition under which an altered interaction network returns to its reference. If one is found, this finding is retracted and the line governs.

## 5. Pre-registered refuter

Written before the conclusion and before outreach, per the standing rule that a falsifier written before the run is a design instrument. The shape claim is refuted if any of the following holds:

1. **Reference-free recovery:** recovery is established and reproduced with no stated reference configuration or disturbance, as an intrinsic property.
2. **Substance-free recovery:** the species list and all measured interaction strengths return to the reference, yet the system behaves as a different substance on every response variable, so the bond requirement buys nothing.
3. **Aggregate sufficiency:** an aggregate index predicts all per-slot failures as well as the per-slot time series, so per-slot decomposition is unnecessary.
4. **True subtraction:** removal of an actor removes a contact with no substituted habitat and no introduction, and the reference is regained with no further seat action.
5. **Signless flip:** the feedback sign is unchanged and the web flips, or the sign reverses and the web recloses, so the sign-to-closure claim fails.

If any fires, the corresponding finding is withdrawn and the union verdict is recomputed. Until one is run, no part of this is labelled `grounded`.
