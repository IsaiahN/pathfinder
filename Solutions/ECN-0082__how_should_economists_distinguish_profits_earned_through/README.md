## The question restated as an effect

An economist observes an above-normal return at one firm-slot. That single reading is consistent with at least two different sources: value newly created (innovation, a temporary Schumpeterian lead that diffuses) and surplus transferred (market power, a maintained position that restricts output). The question asks what would let the economist tell them apart. Option A: treat the profit or markup number itself as the discriminator. Option B: require a source-discriminating instrument, indexed per slot, resting on a non-updating anchor, with the two candidate mechanisms described before the discriminator is chosen. A gives a number that cannot comment on its own source. B gives a checkable separation and a stated failure condition, and stops at a gap where no figure line returns the firm-specific split.
