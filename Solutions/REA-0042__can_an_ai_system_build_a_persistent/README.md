## The question restated as an effect

The question joins two conditions. (1) Persistence: a model is held across time and across changes of circumstance. (2) Updating: the model changes so that it tracks the world when the world changes. An answer that only shows persistence is an answer to a different question, and an answer that only shows updating has no model to update. The two pull in opposite directions, so the residual is a union compound and not one hard question (Fig 9 :57, *"a case in two conditions is not a harder case of either"*). What an answer would look like, bound as an ordinary term before the run: a record that grows together with a reach that can fall, kept in contact with a ground by an office outside the loop.
