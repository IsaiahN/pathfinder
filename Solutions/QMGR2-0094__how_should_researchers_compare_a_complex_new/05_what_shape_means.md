## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence"*, followed by the statement that the framework cannot say which primitive is missing, because naming it would mean already holding it.

From *The Library of Babel* (fetched this session): *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question the shape is not "the simpler model wins" or "the complex theory wins". It is the form any defensible comparison must have: route the residual, split the union, pay the description bargain, price the testing actions separately, demand a ground discriminator, and record where the candidate came from.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary already held that is closest to the thing, then recurse on newly found terms that overlap or correlate with it. *"With each new term gained, you narrow the space and deepen your vocabulary."* (fetched this session)
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* In practice this means describing the residual as a per-slot prediction failure, not as "the old model is too simple".
- *Decoding Tacit Knowledge* (exemplar, 2026-11-22): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: the answer is reached when *"the finish line will also be the starting place"*, and the paradox is that by then you have *"composed the answer through the process of locating it."*
- The same essay warns that a problem may be *"a bundle or conflation of several problems masquerading as one"*. This is the essay analogue of Fig 9 :4-5 and is the reason the theory-comparison question is split rather than averaged.

## 3. What licenses a name, and why it matters here

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The figures README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

*They're Scanning Books* sharpens this (exemplar, 2026-11-22): *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

**Consequence for this question:** "simplicity" is not a name the framework returns. It is a visible choice of code. Calling a theory "simpler" declares a description language; it does not settle which theory is closer to the ground. A comparison that says "choose the simpler one" has mistaken a filter for a verdict (Fig 9 :60).

## 4. The source-discrimination point

*The Hard Problem is About Source* (fetched this session): an instrument reads green and *"cannot comment on the source"*. Several underlying causes create the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* It was the spectrometer, not an argument, that resolved the case. An instrument that cannot distinguish the cases *"demonstrates its own inadequacy"*.

Applied here: two theories that fit the same observations are observationally equivalent at that instrument. That does not mean they are the same theory, and it does not mean an argument about elegance will separate them. What is owed is a discriminating reading, or an honest `unreachable-at-this-budget`. This corroborates F6 and F8 in `01_figure_grounded_audit.md`.

## 5. Q: does the framework name a winner?

**No, and no further question is needed.** The framework returns the shape any winner must have. A particular winner is licensed only by the ground settling a minted term, or by a provenanced import with a shadow test. Until one of those, the name is the searcher's own contribution and must be recorded as such.

A claim of the form "the simple model is correct and the complex theory is unnecessary" is a verdict in `general` mode with no ground reading. The honest form is: *"under the declared code, the complex theory does not pay its bargain, and no live slot is currently failing to resolve; this is a `specified`, ungrounded result at this budget."*

## 5b. Correction to my own reading

I initially wrote the shape limit as if it forbade naming any term already in the library. That overstates it. The README's phrase governs a **missing** primitive, one not held in the library. Description length, residual and the comparison bond are all already in the framework's vocabulary here, so naming them is not inventing a new primitive. What remains forbidden is presenting a chosen code or a chosen winner as something the framework derived. Both readings are recorded so neither is quietly lost.

A second correction: I initially treated the world "crucial experiment" ideal as if it settled theory choice. *Experimentum crucis* itself records the Duhem-Quine objection, and Fig 6 :32 requires an instrument already returning a failing reading. The strong claim is retracted; the budgeted form stands.

## 6. Two consequences for outreach

**Prestige is not action.** *The Recursive Self-Improvement Trap* (exemplar, 2026-11-22): *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous methodologists who agree is the named collapse, not corroboration.

**This audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01_figure_grounded_audit.md` is a simulated derivation, checked for internal consistency against the figures. It is not a test of any real theory comparison and must be labelled as such. It cannot settle anything it reports on.
