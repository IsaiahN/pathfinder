# Solution ORI-0089

**Question:** How should researchers compare theories when each explains some stages but not others?

**Source:** origins of life.txt line 121

**Section:** 9. Evidence, experiments, and competing explanations

**Mode:** `specified` on the substantive claims, `general` on the structural shape. No measurement settles which origin-of-life theory is correct, so nothing here is `grounded`.

**Status:** done

**Registry status:** pending

## Restatement as an effect

The decision is not "which theory wins." It is: given several partial explanations, each covering a different subset of the stages from prebiotic chemistry to life, does the comparison (A) rank them by one aggregate score as if they were rival answers to one question, or (B) unbundle the shared stage chain, index the residual per stage, range each theory against the ground separately, and compose only where the closures genuinely differ? A leads to averaged scores that hide a live signal on one stage, a false partition of a union, and agreement mistaken for evidence. B leads to a per-stage coverage map, a named unreachable where no theory covers a stage, and a checkable import path. The answer is bound as an ordinary term: "a per-stage, ground-ranged comparison with an open slot", so it can accrue a residual and be refused.

**What an answer would look like:** a table with one row per stage and one column per theory, each cell stating the prediction, the residual, and the instrument that would settle it, with the ordering between stages fixed by dependency rather than importance.
