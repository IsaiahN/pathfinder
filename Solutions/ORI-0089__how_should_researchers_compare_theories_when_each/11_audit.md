## 1. Independent domain census

I redid this from the residual line alone before reading the primary's census in `01` §1, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency. A nameable anchor is required; where there is none, the item is not a domain yet.

- **R (the residual).** The pattern that each partial account explains some stages from prebiotic chemistry to an evolving system and not others. Arity: N stage slots, plus a comparison at each slot, so not one scalar. Symmetry: stage links are ordered bonds, `→` sequence and `⇒` production, and the inter-theory comparison is `⋛`, an ordered threshold rather than a symmetric join. Scale: first order within a stage, second order across the chain once a settled stage becomes an atom for the next. The shape is a union compound, because each rule keeps working well on a different subset, not one hard question.
- **Domain 1, framework-internal composition.** Actors: stage slots, the six-term set, the bonds and negation. Currency: residual per slot, description cost and leftover. Anchor: the figures as metalaws, plus the ground for any measurement. Question type: partition boundary, what composes inside a closure.
- **Domain 2, theory frames.** Actors: RNA-first, metabolism-first, lipid-first and coevolutionary accounts, with their models, experiments and instruments. Currency: predictions and the residual each leaves on a stage. Anchor: experiment, the ground for this domain. Question type: union, each frame covering a different subset of stages.
- **Domain 3, comparison and verification frame.** Actors: expert readers, reviewers, rival closures. Currency: agreement and residual. Anchor: the ground, never agreement. Question type: triangulation, but in this simulated run all seats draw on one evidence pool, so independence is zero and agreement here is one pool talking.
- **Not a domain yet.** A single true theory of life's origin has no nameable anchor in this derivation. Prestige and citation counts are absorbed into Domain 3 as contact-cost proxies and excluded from verdict weight.

Order by dependency: describe the residual before choosing a frame; refuse before mint; settle each first-order stage before composing the second-order comparison. Fig 3 :20 "The chain is ordered by dependency, not by importance." My census matches the primary's three domains and its union reading. I arrived at the union from Fig 9's split rule and the ordered-bond claim from Fig 12, while the primary reached them through Fig 9 and the Fig 3 dependency chain. Different starting figures, same boundaries: low overlap between routes within the framework, so the agreement is weak but not circular sentence by sentence. It is still one evidence pool.

## 4. Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

1. **Sent up (x).** The verbatim figure set, chiefly Fig 9 :4-5 and :55 (split a union), Fig 1 :19 and :22 (per-slot residual), Fig 3 :20 (dependency order), Fig 8 :14 and :45 (union surplus), Fig 12 :87 (threshold comparison) and Fig 13 :134 and :135 (unreachable is a verdict, no name).
2. **Abstraction (T_A).** The shorthand carried in `07` and `09`: split the stage union, index the residual per stage, order by dependency, range each theory against the ground, compare as a threshold, leave the winner slot open.
3. **Concretisation (T_E).** The artifact a reader would actually build: a stage-by-theory table with prediction, residual and instrument per cell, plus an import path for the uncovered stage.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip back down unchanged:

- the **operand type of `⋛` at second order**. The Operators table defines it as a threshold between two quantities; once settled stages become atoms, whether an atom counts as a quantity at that level needs an instrument, not an argument (see §5);
- the **order of refusal before mint**, which the outreach material must keep explicit or it reads as a advice to accumulate combinations;
- the **shape-not-a-name limit**, which a reader can breach by treating the dependency-ordered table as if it had selected a winner.

Conversely, one thing survives cleanly: the union split and the per-slot residual survive as the checkable core of the table, which is the residue worth sending. R_T was **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating the condensed shape as identical to the figures would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names. The honest form is a lossy condensation with a recorded gap, which is what `09_watson_answer.md` states.
