# What "shape" means for this question

**Mode: `general`.** This is a reading of a constraint, not a measurement.

**Provenance note, kept visible.** The eight essays are the project's canonical grounding for the word "shape": *How Intelligence Actually Works*, *The Recursive Self-Improvement Trap*, *Decoding Tacit Knowledge*, *How a Society of Agents Would Work*, *The Library of Babel*, *They're Scanning Books When They Should*, *The Hard Problem is About Source*, and *Arrival of the Fittest* (all by Isaiah N, adventuresinml Substack / Medium, 2026). I did **not** re-fetch those eight URLs in this session. The essay quotations below are carried from the completed exemplar's `05_what_shape_means.md`, which I did read, and are used here as the project's inherited reading. They are not counted as world sources in `10_source_ledger.csv`. The figure text and the canonical figures README were opened directly and are the authority for the reading I actually derive.

## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32 "you get a kind of thing, never the answer itself" Fig 13 :133 "A system with a closure can answer that before it searches, and what it returns is a shape rather than a name."

From *The Library of Babel* (carried quotation): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer that can be stated before it can be filled. It constrains; it does not supply the value. For ECO-0010 the shape is:

> any acceptable answer must (i) name an ecosystem function and an instrument reading it, (ii) name the change scenario, (iii) enumerate actors, conditions and relations in contact with that function outward until the cascade stops mattering, and (iv) state what would reverse the requirement.

A bare species count is a filler. It satisfies none of the four tests.

## 2. How the shape was obtained here

- The residual was restated in effect terms before any figure line: not "how many species" but "which function fails, where, under which change, and what is in contact with that failure" (Fig 9 :27 "describe it before you go looking, or any frame you pick will seem to fit").
- The figure set was censed before concluding, and lines were quoted verbatim (§2 of `01_figure_grounded_audit.md`).
- The domain census named three anchors and refused one. The refused anchor was the cross-context universal number (Fig 1 :27 "They are frame-internal. A frame cannot score itself with a quantity it also produces.").
- The result is a narrowed form, not a value: a procedure with four tests. Fig 13 :134 "Unreachable is a verdict here, not a silence" licenses recording the missing universal number as a verdict rather than as an omission.

## 3. What licenses a name or a number

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* For this question that means a measurement of the named function under the named change. No such measurement was taken here.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 8). A diversity index imported from ecology is a recording of a measurement, not an anchor.

*They're Scanning Books When They Should* (carried quotation): *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"Declaring the primitives does not make them neutral. It makes the choice visible."* The choice of which functions count as "essential" is such a declaration. It must be recorded, not hidden inside a count.

## 4. The specific error this question invites

*The Hard Problem is About Source* (carried quotation) gives the mechanism. A spectrometer reads green and *"cannot comment on the source"*: one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. The reading does not determine the source. *"If several paths create the same behavior, then behavior is a projection with lossy information."*

Here the analogous error is reading a diversity index (the projection) and naming its source as "the amount required". Several configurations can yield the same index while differing in which functions are buffered and which cascades are covered. Fig 1 :22 "Aggregating across slots is how a live signal disappears into an average." What is owed is a better discrimination, not a name.

*The Recursive Self-Improvement Trap* (carried quotation): *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* This audit validates its own shape only for internal consistency; it cannot validate the shape at the ground.

## 5. Correction to my own §3 (kept visible)

I first wrote that "shape, not a name" forbids naming any number in this domain. That was an overstatement. The README's phrase governs *"what a missing thing would have to look like"*, that is, a primitive or quantity not held in the library. A measured, per-function, per-change number is not a missing primitive being named by a frame; it is a ground result that can be composed over once settled. So:

- **Forbidden:** a universal number asserted before functions and changes are named, or a roster whose signs are asserted to survive a change of residual.
- **Allowed:** a number measured for a named function under a named change, with provenance and a reversal condition.

This correction does not change the verdict on option A. It removes an over-broad reading of the rule and is recorded here rather than silently erased.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried quotation): *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* Gathering respected names to agree with a universal target is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay (carried quotation): *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is not a test of any ecological claim and must be labelled as such. It cannot settle anything it reports on.
