## QUESTION

Decide, in effect terms, what the Tether says about the demand for a quantity of biodiversity sufficient to maintain essential ecosystem functions under rapid environmental change. Option A: a universal number, stated before functions, places and change scenarios are named. Option B: a per-function, per-place, per-change enumeration whose requirement is reversible as the residual moves. What each leads to: A gives a portable figure that cannot be checked against a ground, because the number is produced by the frame that scores it; B gives a checkable four-part shape that must be renewed when the function or the change changes. The residual is not "how many species?" It is "which function fails, where, under which change, and what is in contact with that failure?"

## DOMAIN CENSUS

R by arity, symmetry and scale, then one line per domain giving actors, currency and anchor; partition or union; order by dependency.

- **R (the residual).** Arity: multiple functions crossed with multiple places crossed with multiple change scenarios, so a union of overlapping conditions rather than one hard question. Symmetry: not symmetric, since "essential" selects a subset and an actor's sign changes with the residual. Scale: local contact first, cascade out to the third order, then a lossy transform to a policy number one scale above the measurement.
- **Domain 1, ecological ground.** Actors: populations, functional groups, conditions (light, water, temperature, season), relations (pollination, predation, competition). Currency: measured delivery of a named function. Anchor: the instrument reading of that function, which settles the question. Nameable anchor, so this is a domain.
- **Domain 2, management seat.** Actors: managers, monitors, introduced actors. Currency: actions and their cost. Anchor: the same function reading, which does not move when the manager changes plan. Nameable anchor, so this is a domain.
- **Domain 3, the "how much" measurement frame.** Actors: counts, richness indices, diversity scores. Currency: a single number. Anchor: none for a cross-context universal threshold, because the number is produced by the frame that reports it. Filter, not witness. This domain is kept only to audit its claim to anchorhood, and that claim is refused.
- **Domain 4, verification frame.** Actors: expert readers and peer frames. Currency: agreement and residual. Anchor: the ground, never agreement. In this simulated run all seats draw on one evidence pool, so this domain's independence is zero.
- **Partition or union.** D1 and D2 form a union compound: the manager acts on a habitat it did not author. The functions bundled under "essential ecosystem functions" are also a union. Unbundle before searching.
- **Order by dependency.** Measure the function before setting a target; refuse before mint; run SEARCHED first, then INWARD, then OUTWARD.

Strain test applied: saturating diversity curves were the only apparent conflict. Re-census shows they are per-function thresholds computed under a declared response distribution, not cross-context numbers. No strain remains (see `01_figure_grounded_audit.md` §7).

Prediction: diversity buffers a named process, and the richness at saturation depends on response variance. Corroborates the per-slot shape. - **Ecology / review.** Loreau et al., "Biodiversity as insurance: from concept to measurement and application", Biological Reviews 2021. - **Ecology / synthesis.** Eisenhauer et al., "Reconsidering functional redundancy in biodiversity research", npj Biodiversity 2023. - **Ecology / conservation.** Schwartz et al., "Linking biodiversity to ecosystem function: Implications for conservation ecology", Oecologia 2000 (USGS record). - **Human cognition / statistics.** Kievit et al., "Simpson's paradox in psychological science: a practical guide", Frontiers in Psychology 2013. ## VERDICT (from the figures)

For the quantity as asked, **gap**: no figure line, after a genuine re-census, governs a universal biodiversity minimum that transfers across functions, places and change scenarios. For the reframed question, the verdict is **triangulated**: an acceptable answer must name a function and its instrument, name the change scenario, enumerate contact outward until the cascade stops mattering, and state a reversal condition. An actor's sign is residual-relative, so a roster is not portable; management is permanent work, so there is no reached-and-left threshold. The figure set returns a shape, not a number. This is a `general` result on shape and `specified` on the domain predictions. It is a `candidate`, not `grounded`. The strongest single point is canonical: the framework reports an unreachable quantity as a verdict, not as a silence.

- **cost if wrong:** bounded and locatable. The packet states its mode, writes four refuters before the conclusion and records the lineage, so an error is findable rather than invisible. The real cost is spending the independence of outside readers by sending a universal number instead of a checkable shape; Fig 2 :42 "Buy independence in proportion to the cost of being wrong." That cost is avoidable by leading with the shape and its refuter.
- **undoable:** yes. The universal-number framing is refused without withdrawing anything about ecology, and no figure line has to be rewritten. A published four-part requirement can be superseded by a better ground measurement. The correction is a change of frame, not a retraction of a primitive.
- **reversed by:** a ground reading, not agreement. A measurement showing one number predicts every named function under every change (refuter 1); a controlled sign-change test showing a fixed roster maintains the function (refuters 2 and 3); a universal target computed before measurement predicting the outcome (refuter 4); or a figure re-census admitting a cross-context threshold (refuter 5). Until one fires, the verdict stands as `candidate`. Prestige or agreement is not such an instrument.
