## 0. The residual, in effect terms

A manager must decide what diversity to retain or restore so that functions judged essential keep being delivered while the environment changes. Two options were held open until the figure lines had been read.

- **A, the quantity framing:** a portable number, stated once, that is sufficient for every essential function under every rapid change. It is a single slot in a policy document. It needs no new measurement once published.
- **B, the per-residual framing:** for each named function, at each place, under each specified change, enumerate what is in contact with that function, widen until the cascade stops mattering, and keep the resulting requirement reversible as the residual moves. It needs re-measurement when the function or the change changes.

What each leads to: A is cheap to state and cannot be checked against a ground, because the quantity is produced by the frame that scores it. B is expensive to state and can be checked, because each requirement is tied to a measurement of the function. The residual itself is not "how many species?" It is "which function fails, for which place, under which change, and what is in contact with that failure?" Restating it was the first derivation step, done before any figure line was chosen.

**Direction bound as an ordinary term (Formula, "Direction").** *"Write down what an answer would look like, bind it, and let it accrue a residual like anything else."* The sought-for shape is written here: an answer is acceptable only if it (i) names a function and its measure, (ii) names a change scenario, (iii) enumerates actors, conditions and relations in contact out to the cascade limit, and (iv) states what would reverse it. A bare number fails this test and is therefore refusable before any comparison with the literature.

## 1. Domain census (done before any figure line was quoted)

**R by arity, symmetry, scale.**

- **Arity:** multiple functions crossed with multiple places crossed with multiple change scenarios. More than one condition is live at once, so this is a candidate **union**, not a single hard question.
- **Symmetry:** not symmetric. "Essential" selects a subset of functions, and an actor's sign depends on which residual is tracked. Swapping functions or change scenarios changes the answer.
- **Scale:** local contact first, then second-order and third-order cascade, then a cross-scale transform between the local measurement and the policy number. The number lives one scale above the function measurement, so a round-trip gap is expected (Fig 4).

**One line per domain: actors / currency / anchor.** A domain is admitted only if it has a nameable anchor.

| domain | actors | currency | anchor (nameable?) |
|---|---|---|---|
| D1 ecological ground | populations, functional groups, conditions (light, water, season), relations (pollination, predation, competition) | delivery of the named function, measured | yes: the instrument reading of the function (Fig 1 :23 *"The ground enters as the only metric."*) |
| D2 management seat | managers, monitors, introduced actors, restoration actions | actions and their cost | yes: the same function reading, which does not move when the manager changes its plan (Fig 2 :25) |
| D3 the "how much" measurement frame | counts, richness indices, diversity scores | a single number | **no** for a cross-context universal threshold. The number is produced by the frame that reports it, so it is frame-internal (Fig 1 :27). This is not yet a domain that can settle the question; it is a filter. It is kept as a domain only to audit its claim to anchorhood, and is refused. |
| D4 verification frame | expert readers, peer frames | agreement and residual | yes: the ground, never agreement (Fig 2 :45) |

**Partition or union.** D1 and D2 are a **union compound**, not a partition: the manager acts on a habitat it did not author, and the function is delivered by contact that crosses the boundary between them. The functions themselves are also a union when they are bundled into one "essential ecosystem functions" phrase. Fig 9 :54 says "And when the split lands on a union rather than a partition, unbundle before you search again." So the requested single number is an attempt to compose a union into a partition. That attempt is audited as finding F8.

**Order by dependency (Fig 3).** (1) perceive and measure the function; (2) acquire terms for what the habitat affords; (3) state what would count as progress for that function; (4) plan an intervention; (5) carry and verify. A universal number is step 4 output produced before step 1 input exists. Fig 3 :19 says "Optimising a link that already works cannot rescue one that does not." Order is by dependency, not by policy convenience.

## 3. Findings

Each finding is a loop over one domain. Verdicts are kept separate and are never averaged. Mode is stated on each.

### F1: The aggregation in "how much" discards the live signal (decisive against option A)

Fig 1 :19 "The residual is indexed by object slot, not aggregated." Fig 1 :22 "Aggregating across slots is how a live signal disappears into an average." Fig 1 :27 "They are frame-internal. A frame cannot score itself with a quantity it also produces."

A global diversity number is one number over many object slots (functions, places, change scenarios). The figure says the residual lives in the slots, and that averaging is exactly how a live signal disappears. The number is also produced inside the measurement frame that would be used to validate it, so Fig 1 :27 disqualifies it as its own metric.

This is **not** a claim that biodiversity is unimportant. It is a claim about which quantity can carry the residual. Option A fails the anchor test at D3: no anchor was named for the cross-context threshold.

- Mode: `general` (structural).
- Status: **triangulated**, low overlap between Fig 1 (slot-indexed residual) and Fig 2 (anchor test). The two figures are independent routes to the same refusal.
- Secondary corroboration only: SEP, *Simpson's Paradox*, and Kievit et al. 2013, *Frontiers in Psychology*, both describe aggregate-to-subgroup reversal. They are not witnesses for the figure verdict.

### F2: Valence is relative to the residual, so the roster does not survive change

Fig 11 :49 "An actor's valence is relative to the residual, not a property it carries." Fig 11 :50 "The same actor is a benefactor to one residual and a malfactor to another, so mutualism and parasitism are relations rather than kinds." Fig 11 :51 "No standing list of good actors survives a change of residual."

The question explicitly contains "under rapid environmental change". That is a change of residual. By Fig 11 :51 the list of species that counted as essential before the change does not carry over. Therefore "how much" cannot be answered by naming a fixed set and counting it. The unit that persists is a relation in contact with a function, not a species name with a permanent sign.

Re-census note: this finding does not say species identity is irrelevant. Fig 13 keeps the six structures distinct, and the ecology literature reports strong species identity effects under multifunctionality. The claim is narrower: the *sign* of an actor is residual-relative, so a roster cannot be portable across a change of residual.

- Mode: `specified`, falsifiable at the ground.
- Status: **triangulated**, low overlap between Fig 11 (habitat, valence) and Fig 9 :27 ("describe it before you go looking, or any frame you pick will seem to fit"): picking a roster before describing the new residual is the named inversion.

### F3: The operation the figures license is enumeration, not computation of a minimum

Fig 11 :43 "The habitat is enumerated, never composed." Fig 11 :44 "List everything in contact with the residual, then what is in contact with those, and outward until the cascade stops mattering." Fig 11 :48 "You do not invent the list. You read it off the world, and what you cannot perceive or measure yet is the residual."

When the request is "how much", the figure returns a procedure instead of a number: read the habitat off the world. The list is authored by contact, not composed from a theory. A number computed from the list is a second-order artifact and inherits the list's scope.

- Mode: `general` (procedural shape).
- Status: **triangulated**, Fig 11 (enumeration) with Fig 9 :53 ("Nobody chooses. The gap does, and the gap is only as good as its description"). Secondary corroboration: Eisenhauer et al. 2023 ask "the question 'redundancy for what?' should always be asked", the same demand that the function be named before the count.

### F4: A count restricted to direct contact misses the residual

Fig 11 :52 "contact cascades. Scoping the habitat to direct contact is how DDT reached the eagles: first-order enumeration, second-order effect, and the residual that mattered was three steps out."

A diversity target computed only from species directly performing a function omits the indirect actors and conditions that determine whether the function survives a change. The figure's own case is biomagnification, where the residual was three steps away from the apparent actor. Under rapid change, the cascade length is part of the answer.

- Mode: `specified`.
- Status: **single-source** (Fig 11 only), with the Carson/Silent Spring lineage as its recorded anchor. Named as single-source, not upgraded.

### F5: Managed diversity is permanent work, not a solved state

Fig 11 :61 "Introduction is available; exclusion is not. You can add an actor and you cannot subtract the habitat, because contact is a fact about the world and does not consult you." Fig 11 :63 "Which is why a managed ecosystem is permanent work rather than a solved state." Fig 10 :24 "the ground does not decay, the channel does"

Option A has a terminal form: reach the number, then stop. The figures deny both halves. Exclusion of the habitat is unavailable, so a manager cannot subtract their way to a clean target; and the channel decays, so the reading must be renewed. Management is a loop, not a threshold achievement.

Strain test and re-census: culling an invasive species looks like "subtraction" and would appear to strain Fig 11 :61. Re-census resolves it: the figure forbids subtracting the *habitat* (the field of contact), not removing an actor. A cull changes contact by adding a controlling action and is still within "introduction is available". The figure governs the habitat, the cull governs an actor, so there is no strain after re-census. Recorded here rather than smoothed.

- Mode: `specified`.
- Status: **triangulated**, low overlap between Fig 11 (asymmetry of introduction/exclusion) and Fig 10 (channel decay).

### F6: Agreement about a number is not settlement of a number

Fig 2 :29 "An anchor is whatever settles the question and does not change its answer because of what any frame thinks." Fig 2 :35 "Alignment is triangulation, not negotiation. A mirror cannot correct you." Fig 2 :45 "Frames range against the ground. They do not negotiate with it."

A panel of experts converging on "X species" is panel 1 of Fig 2 if the anchor is one of the panel, or panel 2 if they share an evidence pool. Neither is panel 3. The only admissible anchor is the measured function under the stated change.

- Mode: `general`.
- Status: **triangulated**, Fig 2 (anchor, correlation valence) with Fig 1 :23 ("The ground enters as the only metric.").

### F7: The figures return a shape and an honest stop, not a universal number

Fig 13 :133 "A system with a closure can answer that before it searches, and what it returns is a shape rather than a name." After the census, no figure line closes the residual with a number that transfers across functions, places and changes. That is a `gap` for the quantity as asked, not a silence. The honest report is: a single universal minimum is **not reachable from the figure set**, and an unreached per-context number is **not yet measured at the ground**. Those two facts have different instructions and are not to be read against each other (Formula step 7).

- Mode: `general`.

## 4. Pre-registered refuter (written before the conclusion)

Required before any outreach: a falsifier written before the run is a design instrument. The shape claim in this folder is refuted if any of the following holds.

1. A single diversity number is shown to predict maintenance of every named ecosystem function across every rapid-change scenario with the same threshold, independent of which actors are present. This breaks slot-indexing (Fig 1 :19) and residual-relative valence (Fig 11 :49-51).
2. The habitat can be composed from a fixed actor list whose signs survive a change of residual. This breaks Fig 11 :43 and :51.
3. A ground measurement under change shows that a fixed roster, not response diversity and asynchrony in contact, maintained the function. This breaks the mechanism prediction that the ecology sources support and the figures leave to the ground.
4. The dependency chain can be reversed: a universal target computed before any function measurement predicts the outcome at the ground. This breaks Fig 3 :19-23.
5. A figure re-census admits a cross-context universal threshold as a direct figure conclusion. Until one of these fires, the verdict stands as `candidate`.

These were written before the recommendation and before `07_the_tether_answer.md`. They are not reconstructed after the result.

## 5. Recommendation

1. Do not publish a universal species number. Publish the shape: function, place, change, enumerated contact out to the cascade limit, and the reversal condition (F1, F3, F4, F7).
2. Name the function and its instrument before naming any diversity metric (F9). "Essential ecosystem functions" is a bundle until unbundled (F8).
3. Treat the roster as residual-relative and re-enumerate after each change scenario (F2).
4. Present management as a maintained channel, not a reached threshold (F5).
5. Route verification through public institutional venues and ask for a refutation, not agreement (F6). The first contact carries the residual and the refuter, never the framework.
