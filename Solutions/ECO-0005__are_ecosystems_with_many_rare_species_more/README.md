## Why this question is not answered by a count

The figures do not license a verdict from a species-abundance count alone. Fig 11 :49 says *"An actor’s valence is relative to the residual, not a property it carries."* Rarity is a position in a distribution, not a kind with a fixed sign. Fig 9 :54-57 requires a union to be unbundled before it is searched: the "more resilient or more vulnerable" pair is two overlapping conditions whose intersection depends on which function and which perturbation are named as the anchor. Until an anchor is named, the residual has no slot to range against. That is a `gap` verdict, not a silence (Fig 13 :134, *"Unreachable is a verdict here, not a silence,"*).
