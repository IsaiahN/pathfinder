**Question in effect terms.** What observation, obtainable at a tabletop scale, would decide whether the gravitational interaction can carry quantum information? Option A: two initially separable quantum systems become entangled through gravity alone, with every classical channel excluded; this imports the atom "gravity is a quantum-capable channel" into the physics frame. Option B: no entanglement is observed; this leaves the classical frame standing without proving it, because a null result is not an absence proof. What an answer would look like: a threshold witness on two spins, a written list of excluded classical channels, and a stated mode for the inference. Bind that description as an ordinary term before searching, per the formula's "Direction" section.
