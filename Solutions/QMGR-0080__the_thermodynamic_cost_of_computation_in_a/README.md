## Residual, stated as an effect

What is being decided is whether there is a single thermodynamic price for carrying out a computation when gravity is part of the setting, or whether the request bundles several conditions that must be priced separately. Option A: assert one universal number or law, for example a gravitational correction to `kT ln 2`. Option B: keep the figure-derived shape, split the union, state what any candidate answer must have, and leave the numerical slot open until an instrument settles it. A sends an unmeasured `general` verdict with two different currencies added together. B sends a checkable shape, written refuters, and a named instrument.

## What an answer would look like (bound as an ordinary term)

A candidate answer must state, for a named device, reservoir and gravitational background: (i) which currency the price is paid in, (ii) which object slot it is priced against, (iii) whether it is paid once or on every lineage, and (iv) what ground reading would settle it. Anything that returns a single context-free number without those four fields has not answered the question as posed.
