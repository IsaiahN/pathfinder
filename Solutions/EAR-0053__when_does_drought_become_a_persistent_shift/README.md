## What is being decided, in effect terms

Option A: a drought is called persistent when a chosen index stays beyond a chosen threshold for a chosen duration. This makes the index the anchor, so the verdict can be changed by changing the index or the reference period. Option B: a drought is called persistent when the water system's recovery relation changes at a place, so the same forcing no longer returns the store to its prior range because a feedback has closed across slow variables, and independent ground readings agree that the new state has held. Option A gives a portable number and a fragile anchor. Option B gives a ground-anchored shape and defers the number to measurement.

What an answer would look like is written down and bound as an ordinary term in `01_figure_grounded_audit.md` §0, following the formula's "Direction" rule: a persistent shift is a per-slot, ground-anchored, comparison-based, cycle-maintained transition whose numeric boundary is owed from the ground. Binding it makes the sought-for shape refusable rather than a preference.
