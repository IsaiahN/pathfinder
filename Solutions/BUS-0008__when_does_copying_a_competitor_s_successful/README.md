## Restatement as an effect

The decision is: a firm observes a competitor's success and must choose between copying the visible artifact of that success and acquiring the generative method behind it. Option A (copy the artifact) is cheap and fast, but the artifact is a description of one occasion whose binding arrangement is invisible, so the firm can end as a second name for the same closure, which the market does not pay for. Option B (acquire the method, reproduce the habitat, keep a differing room) costs more up front but the generator crosses and is remade by the new level. What an answer would look like: a boundary stated in effect terms, namely a set of conditions under which residual reduction survives the transplant and a set under which distinctiveness collapses. That boundary is bound as an ordinary term in `01_figure_grounded_audit.md` and allowed to accrue a residual, per the formula step "Direction".
