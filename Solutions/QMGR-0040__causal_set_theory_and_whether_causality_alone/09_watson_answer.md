## VERDICT (from the figures)

Causality alone cannot generate the structure of spacetime. Ordering does not produce adjacency, there is no route from one primitive to another, and a structure with no states is empty. What causality does supply is the conformal geometry, and only over event-states and for a restricted class of spacetimes. The volume magnitude that completes the metric is an import from a frame whose closure differs, assigned per region and provenanced; composition inside the order never adds it. What the framework *does* endorse is discrete-first emergence: the continuum was rejected as a seventh member. So the verdict is a partition, not a compromise: the emergence half of causal set theory is figure-supported, and the strong "alone" reading is refused. This is `specified`, ungrounded, candidate. The shape any candidate answer must have is fourfold (event-states, order as cross-kind structure, imported per-region magnitude, provenance), and the framework returns a shape, not a name.

- **undoable:** yes. No primitive has to be withdrawn to do so, and the file keeps every earlier reading visible in its retraction table.
