## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence"*; the next line adds that it *"cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- **Shape:** a magnitude that assigns volume to the order, region by region, supplied from outside the order.
- **Name (withheld):** "the number of causet elements" as a primitive the order produces. That is the field's own binding, provenanced as such, not something the framework derives.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is *closest* to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* So the missing item is described as "that which supplies magnitude/volume where the order leaves a gap", not as a new primitive called Number.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is exactly why the outreach email leads with a checkable description, not the architecture.
- *Library of Babel* on stopping: the answer is reached when *"the finish line will also be the starting place"*, and the paradox is that by then you have *"composed the answer through the process of locating it."*

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."* Here the ground would be a Planck-scale or continuum-limit measurement that discriminates the conformal factor, or a proof of the manifold-like reconstruction.
2. **A provenanced import** from a frame whose closure differs (Fig 6 :23, Fig 8 :50-52), with a source gate and shadow test. The counting measure is such an import from the causal set physics frame.

*They're Scanning Books* sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."* The six are a visible guess, not nature's own list.

## 4. The ground and the source problem

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*; one green light, or yellow plus blue, or RGB, or CMYK can give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the **spectrometer**, not an argument, that resolved it.

Applied here: the causal order returns a conformal reading (9/10 in Sorkin's phrase). The conformal metric is a projection that cannot comment on the source of the volume factor. Several micro-distributions can give the same coarse reading; F-JAKSLAND reports that *"the same continuum spacetime will be approximated by many different causets."* What is owed is a discriminating instrument (the source gate), not a name read off the projection. This is why F4 and F7 in `01` are stated as instrument debts.

## 5. Answer to the shape question

**What licenses a particular magnitude in the gap?** Nothing in the six-term framework. The framework returns a shape. The magnitude is licensed only by the ground settling a term, or by a provenanced import with a shadow test. Until one of those, the identification "number equals the missing tenth" is the physics frame's own contribution and is recorded as such.

**Does the record commit the error the README forbids?** Not as written in this folder. An earlier draft of this section said the framework forbids naming the quantity at all. That was overstated, and the narrower form is in §5b.

## 5b. Correction to my own §3 and §5

I initially treated *"a shape, not a name"* as a blanket ban on stating what the missing item is. The README's phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* It governs a primitive not held in Γ. Number/volume is not one of the six, so stating it *is* a missing item is legitimate in effect terms; what is forbidden is claiming the framework has derived or named a seventh primitive. Both claims are now recorded so neither is quietly lost. Triangulated (figures README + Fig 13 :115 + Fig 6 :21).

## 6. Consequences for contact

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A campaign that gathers famous names to agree with the claim is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* LLM output is *"simulacra."* So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of causal set theory and must be labelled as such. It cannot settle anything it reports on.
