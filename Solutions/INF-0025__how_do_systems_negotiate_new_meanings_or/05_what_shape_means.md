## 1. A shape is a constraint, not a filler

The canonical limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13 :134: *"Unreachable is a verdict here, not a silence"*.

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question"*.

For this question a **shape** is the narrowed form of a first code that can be stated before any particular code is named. It says what a code must be built from, what relation must hold among its terms, what guard must keep it revisable, and what would refute it. It does not say which code a given pair will arrive at. The shape is `contact-enumerated / bonded / violable / imported / pre-characterized`; a specific protocol is a name, and a name is out of reach here.

## 2. How the shape is obtained

- *Library of Babel*: *"use the existing vocabulary you do know that is closest to the words that you wish to describe and grasp the shape of"*. Then recurse on overlapping new terms: *"With each new term gained, you narrow the space by definition and deepen your vocabulary."*
- *Library of Babel* on the anchor: *"This anchor is provided by your own question: If the question is answered by your present collection of books from your search you know whether to stop or continue and which direction to turn next."* For INF-0025 the question itself is the tether, and the written residual in `01` §0 is its bound form.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is exactly the two-stage outreach order: send the effect description first, never the private shorthand.
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause"*.
- *Library of Babel* on stopping: *"you will know that you are done because the finish line will also be the starting place"*, and the paradox, *"you have already composed the answer through the process of locating it"*. For a first code, this is the point at which the written characterization and the observed protocol coincide. Until then the slot stays open.

## 3. Why this question is unusually sensitive to shared pretext

*Decoding Tacit Knowledge* is the essay that bears most directly here. It splits what a listener brings into context (what is going on around the words), subtext (what the words are for) and pretext (the history and assumptions before the words arrived). It states: *"Writing carries the context well and the subtext partly, but it almost never carries the pretext, the 'you had to be there' part."*

That is the reason a "starting code" cannot be a written specification alone. The pretext is rebuilt only by *"trying, being corrected, and trying again, in both directions"*. The essay adds: *"Understanding is joint work. Neither side can finish it alone"*, and *"A conversation only moves forward once the listener shows they've understood, with a nod, a fitting reply or their attention. A puzzled look is the correction, and the speaker tries again."*

This is Fig 8 :45 *"Two frames together reach what neither reaches alone"* at the level of a single exchange. It also gives the failure mode: *"Long, close contact pulls the frames together, so the process that makes communication easy slowly uses up that extra reach."* So the very contact that stabilizes a code consumes the independence that made it informative. That is the reason F7 demotes repetition to a budget filter and why `11_audit.md` records the round-trip gap.

## 4. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."* For a code, that means the protocol actually coordinates action against the contact it claims to track. *The Hard Problem is About Source*: *"The answer is unreached until a better instrument exists."* The instrument here is a trace or experiment that discriminates among candidate first terms, not more agreement.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-51), with a source gate and a shadow test. Pidgin contact, animal signal systems, and the DHCP lower layer are candidate frames, but each must be recorded as an import, not a derivation.

*The Hard Problem is About Source* gives the mechanism that forbids naming from a reading: *"If several paths create the same behavior, then behavior is a projection with lossy information"*. A shared signal can be produced by several different histories; the reading does not determine the source. *"An instrument that can't distinguish these cases demonstrates its own inadequacy"*. So the first code stays named `???` until a discriminating instrument exists.

## 5. Agreement is the product here, but it is still not a verdict

This is the point where the essays and the figures are exactly aligned. Fig 2 :41: *"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"*. Fig 2 :40: *"disqualifying for a verdict: agreement about the world is worthless when the agreeing frames share an evidence pool"*.

*Decoding Tacit Knowledge* restates both in plain language: *"Agreement is the whole point when you're settling what words mean. It's worthless for settling what's true when both sides learned from the same sources"*. And: *"Two people who only check against each other drift, and they drift together, so neither notices."*

So the outreach email can legitimately seek agreement about the *convention*. It must never present agreement as evidence that the code tracks the ground. The guard in Fig 10 :47, *"a convention that decides an outcome has stopped being one"*, is the formal statement of that limit.

## 6. Two consequences for this solution

**Prestige is not action.** *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* A list of famous people selected for likely agreement is the named collapse; it gives the claim a hearing, not a verdict. The same essay: *"You may all agree and be wrong."*

**My own audit is a simulation, not a ground reading.** Same essay: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* And: *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the question and must be labelled as such. It cannot settle anything it reports on.

## 7. Correction carried forward from §4

I initially wrote that "shape, not a name" forbids naming any first code at all. Narrowed after re-census: the canonical phrase governs a **missing** primitive, one not held in Γ. A first protocol is not a framework primitive; it is a composition over held atoms, and the framework says it returns a shape for the composition as well (Fig 9 :32). The honest statement is therefore: the framework can constrain the form of the first code but cannot select the particular code without a ground reading. Both the broad and the narrow readings are recorded here so neither is quietly lost.
