## Wider literature that bears on the question

These are the same sources read as witnesses in `09_watson_answer.md`. Overlap is declared: they are different fields but several are encyclopedia syntheses, so they are not independent experiments.

- **Coordination without communication.** Schelling's focal points and Lewis's signaling game both show that a shared regularity can solve a coordination problem without a prior exchange of definitions. Neither derives the regularity from nothing; both rely on salience, payoff symmetry, or a shared situation. This corroborates F1 and F2, and it refuses the literal "agreement from nothing" premise.
- **A first code is inherited or contact-shaped, not invented.** Bouba/kiki mappings across cultures, infants, chickens and dogs, plus pidgin formation under sustained contact, corroborate D1's enumerated habitat. The specific first terms are read off what both parties already contact.
- **A code that decides an outcome stops being a convention.** Voluntary standards as coordination solutions, and Wittgenstein's requirement of an independent criterion of correctness, corroborate F5: the first protocol must remain violable and publicly checkable.
- **Bootstrapping happens on a lower shared layer.** DHCP negotiates configuration only because IP, UDP, fixed ports and broadcast already exist on both sides. This is a clean engineering instance of Fig 6 :23: no frame escapes its own closure; the bound moves only on contact with a frame whose closure differs. It also shows why "no starting code" is the wrong description: there is always a lower substrate already returning something.
- **Coding theory assumes the code.** Shannon's framing in `Information_theory` is about reproducing a selected message at another point. It does not derive the shared codebook; that is exactly the residual this question names.

No world source was found that supports a code manufactured purely by mutual agreement with no anchor, no shared contact and no differing closure. That absence is not a proof (Fig 8 :39: *"So a search that finds nothing is never a proof of absence."*); it is a reason to keep F1's refuter live.
