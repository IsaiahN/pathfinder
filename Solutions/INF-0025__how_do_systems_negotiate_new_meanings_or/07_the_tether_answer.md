# The Tether's answer: how a first code gets off the ground

**Mode: `general` for the structural shape, `specified` for the protocol-emergence application, not `grounded`.** This is a shape and a route, not a result. Simulated derivation checked against the figures (`05_what_shape_means.md` §6), not a ground reading.

## 1. The residual it answers

Two frames need a shared code to coordinate, but any negotiation of a code seems to presuppose a code in which to negotiate. The question is what supplies the first shared term. It is a **union compound**, not one hard problem: a convention question (agreement is the product) and a ground question (agreement is not a witness). Fig 9 :57: *"What remains is smaller and it is also categorically different: a case in two conditions is not a harder case of either."*

## 2. The shape

1. **"Negotiation from no code" is a named collapse, not a mechanism.** Mutual updating with no anchor converges on whoever had the most influence; it is a mirror chain (Fig 2 :13-15; Fig 2 :35: *"Alignment is triangulation, not negotiation. A mirror cannot correct you."*). What actually happens is that each frame ranges against a contact it did not author. Fig 2 :45: *"Frames range against the ground. They do not negotiate with it."*
2. **The first terms are enumerated from the habitat, not invented.** Fig 11 :43: *"The habitat is enumerated, never composed."* Fig 11 :48: *"You do not invent the list. You read it off the world, and what you cannot perceive or measure yet is the residual."* Shared regularities, affordances and hard-to-fake signals are the first vocabulary.
3. **The code is a molecule: the bond carries the meaning.** Fig 12 :5: *"A set of ingredients is not one. The bond is the rest of the information, and it is the half nothing was recording."* Identical inventories under different bonds are different protocols (Fig 12 :117: *"isomer. Same atoms, different bond, different substance."*).
4. **New meaning enters as an import from a differing closure, found by describing R first.** Fig 6 :23: *"No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs."* Fig 8 :53: *"Residual first, frame second."* Fig 9 :27-28: *"describe it before you go looking, or any frame you pick will seem to fit"*.
5. **The first protocol is a violable convention, not a verdict.** Fig 2 :41: *"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"*. But Fig 10 :47: *"a convention that decides an outcome has stopped being one"*, and Fig 10 :18 *"a declared meaning is not a grounded one"*, then Fig 10 :19 *"install what can be violated"*. A code that cannot be violated has stopped being a protocol and has become a constant the frames authored.
6. **Repetition stabilizes; it does not certify.** Fig 9 :60: *"Use filters for the budget and witnesses for the verdict. Never let a filter hand you a verdict."* More rounds and more agreeing frames are budget filters (Fig 7 :12-13: *"same closure, handed along; agreement compounds, evidence does not"*).
7. **The first code is not named by the framework.** Fig 9 :32: *"you get a kind of thing, never the answer itself"*. Fig 13 :134: *"Unreachable is a verdict here, not a silence"*. The specific code is a `gap`, owed to a ground reading, not filled by a guess.

## 3. What it explicitly does not say

- Not that a code can be manufactured from nothing. There is always a lower substrate already returning something (Fig 6 :34).
- Not that a shared symbol is a shared meaning. The bond and the provenance carry what the symbol does not.
- Not that agreement settles truth. Agreement is the product for conventions and disqualifying for verdicts (Fig 2 :40-41).
- Not a universal protocol or a final code. There is no last room (Fig 7 :6).
- Not `grounded`. No protocol trace or experiment was run.

## 4. What would settle it - the ground

A discriminating instrument, not more agreement. The questions a ground must answer:

- **Source test:** can a trace distinguish terms inherited from shared contact from terms adopted by import? If several histories produce the same signal, the reading cannot name the source (Hard Problem is About Source: *"If several paths create the same behavior, then behavior is a projection with lossy information"*).
- **Bond test:** do two protocols with the same inventory but different bonds produce different behaviour with adequate instrumentation? If not, F3 fails.
- **Guard test:** can either frame violate the installed convention, and does the code still track the contact after the violation? If not, it has stopped being a convention.
- **Standing falsifiers** from `01` §3: convergence with no anchor and no import; first terms independent of any shared contact; no behavioural difference from different arrangements; a convention that decides an outcome counted as a convention; recognition of a correct code with no prior characterization.

## 5. The honest stop

`Unreached, not unreachable`. The shape is triangulated across Fig 2, Fig 6, Fig 8, Fig 9, Fig 10, Fig 11 and Fig 12. The specific first code is a declared `gap`. What remains outside is a seat's office, not the loop's: the discipline of writing down the sought shape before searching (Fig 5 :65) and the refusal to name what the ground has not settled. *"Indiscernibility is not identity"* (figures README).

## 6. One-paragraph version for outreach

> The Tether does not derive a first code from nothing. It says that the phrase is a false alternative: systems do not negotiate a code in the void, they find it at a contact neither authored. The first terms are read off a shared habitat, arranged by typed bonds so that the relation carries what the symbols do not, installed as a convention that can be violated, and carried across when one frame meets another whose vocabulary differs. Agreement is the product for the convention, but it is never a witness that the code tracks the ground; repetition only stabilizes it. The framework returns the shape any first code must have, the five refuters written in advance, and the instruments that would name the particular code. The slot stays `???` until a ground settles it.
