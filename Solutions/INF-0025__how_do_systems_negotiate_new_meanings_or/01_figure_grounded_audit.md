## 0. The residual, stated in effect terms

Two frames, A and B, each hold a library Γ. A message or protocol is a composition that must be admitted by both so each can predict the other's observable action. Per the Symbols table, R is *"The gap between prediction and observation. The central quantity: everything the system does is driven by it."* It is per slot, never aggregated (Fig 1 :19: *"The residual is indexed by object slot, not aggregated."*).

The bootstrapping puzzle is this: to range against a shared anchor you need a code in which to read it; to negotiate a code you need a shared code in which to negotiate. If the code is what is missing, what settles the first term, and what makes it stick? Stated as options:

- **Option A (literal reading):** a code is created from nothing by mutual agreement before any anchor exists.
- **Option B:** the first code is not agreed into existence. It is found at a contact both frames can register without a code, then installed as a violable convention, then carried across by import from a frame whose closure differs.

What each leads to: A leads to coherent drift, because the only thing being updated is the frames' mutual expectations (Fig 2 collapse 1). B leads to a checkable shape, written refuters, and an open slot for the specific code until a ground settles it.

**Direction bound as an ordinary term.** Before searching I write down what an answer would look like, per Fig 5 :65: *"make the sought-for shape an ORDINARY TERM. Write down what an answer would look like, bind it, and let it accrue a residual like anything else."* The sought-for shape is: a first shared term that (i) is traceable to a contact neither frame authored, (ii) is a molecule whose bond carries information the bare symbols do not, (iii) is a convention that can be violated and does not decide a world-verdict, and (iv) is recognizable only after its shape was written down. If no such shape is reachable, the answer is `gap`, not a silence.

## 1. Domain census (before choosing any figure line)

**R by arity, symmetry and scale.**

- **Arity:** at least two frames plus one ground. R is a two-place relation indexed per slot, with a third position (the seat that keeps the anchor reachable) available but optional.
- **Symmetry:** mixed. Agreement about a shared meaning is symmetric and is the product of a convention (Fig 2 :41). Agreement about the world is not settled by symmetry at all; it is asymmetric because the anchor does not update (Fig 2 :33: *"The anchor must not update."*). This mixed symmetry is the signal that the residual is a union, not one hard question.
- **Scale:** a single exchange (per slot), repeated interaction (protocol stabilization), and a population of pairs (convention spread). The membrane between scales is lossy (Fig 4 :22: *"Only methods cross up. Only head starts come down."*).

**One line per domain: actors / currency / anchor. A domain with no nameable anchor is not a domain yet.**

| domain | actors | currency | anchor | question type | status |
|---|---|---|---|---|---|
| D1 Contact / habitat | both frames plus the world | residual per slot | the ground, a shared contact neither frame authors (Fig 2 :29; Fig 11 :43) | partition boundary | admitted, triangulated |
| D2 Convention / protocol | the two frames | agreement and revisability | the convention as a public, violable practice (Fig 10 :45-49) | convention, not verdict | admitted, triangulated |
| D3 Code as molecule | atoms and bonds | cost(φ), |φ|, number of bonds | settlement against the ground (Fig 12 :5, :46) | composition | admitted, single-source for the price rule |
| D4 Closure / import | two frames with differing closures | an atom crossing the boundary | provenance and shadow test (Fig 6 :23; Fig 8 :50-51) | union surplus | admitted, triangulated |
| D5 Direction / discipline | the searcher | the pre-bound shape | the written-down prediction (Fig 5 :65; Fig 9 :27-28) | limit on self-certification | admitted, single-source |
| X1 A code created from nothing by mutual agreement | the frames only | mutual expectation | none nameable; agreement is generated by the frames, so the anchor updates with them (Fig 2 :13-15) | would be a verdict | **not a domain yet**, rejected by anchor test |

**Partition or union?** D1 and D4 form the ground-contact compound (the bootstrap). D2 and D3 form the convention-composition compound (the code). The whole is a **union**, not a partition: a code that decides a world-verdict is a category error, not a harder version of the same question. Fig 9 :55: *"A bundled problem is usually a union of overlapping conditions, not a list of separate ones."* Fig 9 :57: *"What remains is smaller and it is also categorically different: a case in two conditions is not a harder case of either."* So unbundle before searching again (Fig 9 :54).

**Dependency order (Fig 3).** perception of an anchor that is already returning something (Fig 3 :5, Fig 6 :34) → vocabulary for the residual (what the signal affords) → objective (what would count as coordination, in each frame's own terms) → planning (which differing closure to import from) → learn and carry (settle the convention, rank it, keep it reversible). Effort spent above the break cannot rescue a missing link below it (Fig 3 :19-23). In this question the middle link, having a term for what a shared contact affords, is the one with the fewest instruments (Fig 3 :27: *"A link with no instrument is not a link that works. It is a link nobody has looked at."*).

**Strain test applied before concluding.** Two candidate readings strained and were re-censused:

1. Reading "negotiate" as bargaining over world-verdicts strains Fig 2 :45 and Fig 2 :43. Re-census moves that reading to X1 and splits D2 from D4. It governs a different quantity, so it is not forced.
2. Reading "no starting code" as "no shared contact at all" strains Fig 6 :34 (*"Where nothing is, there is no edge to extend from"*). Re-census shows the residual is about the absence of a *code*, not the absence of any registered contact. That is why D1 has an anchor and X1 does not.

## 2. Findings

### F1 - The premise is a false alternative; negotiation from no code is a named collapse, not a domain (decisive for the frame)

Fig 2 :13-15 describes collapse 1: *"no anchor; each updates on the others they converge, and what they converge on is whoever had the most influence"*. Fig 2 :34: *"If it does, panel 3 turns into panel 1: the anchor becomes another frame, everything drifts together, and the drift is coherent, which is why nobody notices."*

A code produced only by mutual updating has no anchor that does not move when the frames push on it. By the anchor test (Fig 2 :29: *"An anchor is whatever settles the question and does not change its answer because of what any frame thinks. A measurement, an experiment, a counter, a market, a patient outcome."*), it is not a domain. X1 is rejected.

What actually plays the role the question assigns to "agreement" is triangulation: Fig 2 :35 *"Alignment is triangulation, not negotiation. A mirror cannot correct you."* and Fig 2 :45 *"Frames range against the ground. They do not negotiate with it."*

**Verdict: `general`, triangulated** (Fig 2 anchor rule plus Fig 11 habitat enumeration, low overlap: one is a checking rule, the other a source rule). **Refuter:** two frames with no shared anchor and no differing-closure import reliably converge on a stable shared code across independent pairs. If that holds, F1 fails and X1 must be re-admitted as a domain.

### F2 - The first terms are enumerated from the habitat, not composed or invented

Fig 11 :43: *"The habitat is enumerated, never composed."* Fig 11 :44: *"List everything in contact with the residual, then what is in contact with those, and outward until the cascade stops mattering."* Fig 11 :48: *"You do not invent the list. You read it off the world, and what you cannot perceive or measure yet is the residual."*

The first code is built from what both frames already contact: shared regularities, shared affordances, hard-to-fake indices, onomatopoeia, cross-modal correspondences. That is why the title's "agreed-upon starting code" is the wrong object. There is a starting *contact*, and it is not authored by either frame. Fig 8 :53: *"Residual first, frame second."*

**Verdict: `general` for enumeration, `specified` for communication protocols, triangulated** (Fig 11 plus Fig 8 plus the world sources on pidgins, focal points and cross-modal mappings). **Refuter:** a stable protocol whose first terms are demonstrably uninfluenced by any shared contact, replicated across independent pairs. F2 also fails if a first code can be enumerated from a habitat in which nothing has ever registered at any resolution, which Fig 6 :34 forbids.

### F3 - A code is a molecule: the bond carries the meaning, not the ingredient list

Fig 12 :5: *"A set of ingredients is not one. The bond is the rest of the information, and it is the half nothing was recording."* Fig 12 :46: *"A bond is the typed relation between two operands. There are seven, they are not interchangeable, and which one holds is not recoverable from the operands."* Fig 12 :47: *"A recipe that names only its ingredients has recorded half of itself."*

Two frames can hold the same atom by convergence, which is corroboration at maximum independence: Fig 8 :50 *"Convergent derivation and adopted import look identical in the contents."* So a shared symbol is not yet a shared meaning. What is shared is the typed relation plus the record of where it came from (Fig 8 :51: *"Only the record of where each came from separates them, and the surplus lives only where the closures differ."*).

**Verdict: `general`, single-source for the bond price (Fig 12), triangulated for "bond carries information the operands do not" (Fig 12 plus the Operators table).** **Refuter:** a case where identical symbol sets under different arrangements produce no behavioural difference in either frame, with adequate instrumentation. Chemistry's isomers are the standing counterexample that makes the bond necessary (Fig 12 :117: *"isomer. Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."*).

### F4 - New meaning enters as an import from a differing closure, found by describing R first

Fig 6 :23: *"No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs."* Fig 6 :14 names import as *"the only operator that moves the wall"*. Fig 8 :54: *"The atom cannot be derived from inside A. But the union is searchable from contact, so underivable is not unknowable."*

The lookup discipline is Fig 9 :27-28: *"describe it before you go looking, or any frame you pick will seem to fit"*, and Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause"*. The output is a shape: Fig 9 :32 *"you get a kind of thing, never the answer itself"*. Fig 13 :115: *"The set is closed. The arrangements are not. That gap is why import exists."*

**Verdict: `general`, triangulated** (Fig 6 closure operator, Fig 8 union surplus, Fig 9 leave-and-arrive; three figures, low overlap). **Refuter:** a new shared term derived purely inside both frames' existing closures with no new atom and no contact with a differing closure, where the term demonstrably changes what either frame can predict. Fig 8 :32: *"Closure is idempotent. Composing inside a closed set never leaves it, so no search, however long, adds an atom. This one is definitional: it is what closure means."*

### F5 - The first protocol is a convention that must be violable and must not decide an outcome

This is where "negotiation" is legitimate. Fig 2 :41: *"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"*. Agreement is the product here, not a corruption. But the guard is Fig 2 :43: *"Guard, from Figure 10: a convention that decides an outcome has stopped being one."*

Fig 10 authorizes the seat to write this: Fig 10 :45 *"It does author conventions, because nothing else can see across a seam."* Fig 10 :16-17: *"the convention does not fix the bug it makes the bug statable"*. Fig 10 :18-19: *"a declared meaning is not a grounded one"*, then *"install what can be violated"*. Fig 10 :46: *"A convention makes no claim about the world; a verdict and an atom both do."*

So the first code is installed so it can be violated. Declaring it does not ground it (Fig 10 :49: *"Declaring a meaning does not ground it."*). Its authority comes from continued contact, not from the seat that wrote it.

**Verdict: `general` for the guard, `specified` for protocols, triangulated** (Fig 10 plus Fig 2). **Refuter:** a convention neither frame can violate, which also settles a world-verdict, and which the framework still counts as a convention. That would collapse D2 into D4 and require a re-census.

### F6 - The first code cannot be recognized without a pre-bound shape

A frame searching for an answer of a given shape holds that shape as a preference, not a term, so nothing in the mechanism can see it (Fig 5 :65). Fig 9 :27-28 gives the same discipline from the lookup side. The remedy in this folder is §0's written-down shape and §3's pre-registered refuter, written before the conclusion.

**Verdict: `general`, single-source** (formula step "Direction" and Fig 5, with Fig 9 as a corroborating but overlapping figure). **Refuter:** a frame that reliably recognizes a correct first code without any prior characterization of what a code would look like. That would falsify the direction limit.

### F7 - Repetition and more frames are filters for the budget, never witnesses for the verdict

Fig 9 :60: *"Use filters for the budget and witnesses for the verdict. Never let a filter hand you a verdict."* Fig 7 :12-13: *"same closure, handed along; agreement compounds, evidence does not"*. Fig 7 :35: *"A room's agreement is variation, not a verdict. Selection between rooms is where the ground votes."* Fig 1 :27: *"A frame cannot score itself with a quantity it also produces."*

Repeated interaction stabilizes a protocol (budget filter). It does not certify that the protocol tracks the anchor. The next pair must differ from the last and match the residual it surfaced (Fig 7 :36: *"A chain of mirrors is one long room. The next room must differ from the last, and match the residual it surfaced."*).

**Verdict: `general`, triangulated** (Fig 9, Fig 7, Fig 1). **Refuter:** agreement among high-overlap frames that changes the ground's verdict on whether the code works. Fig 2 :31: *"Independence, between two frames, is how little they draw on the same evidence."*

### F8 - The specific first code is a gap, not a hidden answer

No figure line names which code a given pair will arrive at. Fig 9 :32 gives a kind of thing, never the answer. Fig 13 :134-135: *"Unreachable is a verdict here, not a silence, It cannot say which primitive is missing, because naming it would mean already holding it."* Fig 8 :39: *"So a search that finds nothing is never a proof of absence."*

Status `gap` for the specific name, after a genuine re-census across all five admitted domains. What is owed is a ground reading: an actual protocol trace or an experiment that discriminates among candidate first terms. This solution does not fill the slot with a guess.

**Money where the mouth is, per the formula's step 7.** SEARCHED: is a first-code term already in the pair's closure and merely unfound? The closure is idempotent, so more interaction at the same reach only sweeps the same space; distribute the search and keep the searchers independent (Fig 6 amendment on the third question, :49-50). INWARD: extend an instrument already returning something, for example a higher-resolution trace of an existing handshake; sharpen in our own terms. OUTWARD: characterize R in effect terms and find the frame whose closure predicts its shape, for example pidgin contact or animal signal systems; cast the description in effect terms so it travels (Fig 6 :30). These are three distinct questions. INWARD and OUTWARD are opposed and were never read against one another. Underivable-in-principle and unreachable-at-this-budget are different facts with different instructions (formula step 7).

## 3. Pre-registered refuter

Required before any outreach; the shape claim is refuted if any of the following holds. These were written before the conclusion above was completed.

1. Two frames with no shared anchor and no differing-closure import nevertheless converge on a stable shared code across independent pairs (breaks F1, F2 and F4: no anchor or import needed).
2. A stable protocol's first terms are shown to be uninfluenced by any shared contact, across independent pairs (breaks F2: habitat enumeration).
3. Identical symbol sets under different arrangements produce no behavioural difference anywhere with adequate instrumentation (breaks F3: the bond carries meaning).
4. A convention that decides a world-verdict is still counted as a convention by the framework (breaks F5: the convention guard).
5. A frame reliably recognizes a correct first code with no written characterization of what a code would look like (breaks F6: the direction limit).

If any fires, the shape is withdrawn and the census is redone. Until one is run, no part of this is labelled `grounded`.
