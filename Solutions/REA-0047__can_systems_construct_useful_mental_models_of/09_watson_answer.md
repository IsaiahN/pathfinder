## QUESTION

Decide, in effect terms, what the Tether says about constructing a useful model of a situation X with which a system has had no direct contact. A system holds library Γ and closure(Γ); no reading of X is held. Option A: construction suffices for usefulness. Option B: only direct contact with X can produce such a model. Option C: construction is reachable in shape through composition and through contact with a frame whose closure differs, but usefulness additionally requires settlement at the ground. What each leads to: A promotes a fluent composition into a verdict; B forbids prediction that precedes its instrument, which Fig 6 licenses; C keeps constructibility and usefulness as separate verdicts and states what would close the gap. The answer shape was bound before the run in `01` section 0.

- **D2, import between frames.** Actors: frame A with the residual, peer frame B with different closure, the effect description. Currency: atoms crossing back, provenance, shadow test, independence debit. Anchor: the ground, and the difference of closures. Type: union surplus.

- **D4, habitat and capability.** Actors: actors, conditions, relations, seat, inherited methods. Currency: contact cascades. Anchor: the ground settles, the habitat updates. Type: enumeration, never composition.

## VERDICT (from the figures)

Yes to constructibility, conditional on a different-closure source when the parts are not held. Not yet to usefulness, which requires a ground settlement event that neither construction nor agreement can supply. A system can describe a never-encountered situation's residual in effect terms, compose held atoms, or import a shape from a frame whose closure differs; the result is a candidate. It becomes useful only when an instrument, experiment or outcome pays for it. Indirect contact through a habitat cascade counts as contact; a synthetic same-environment model does not count as capability. The answer is `specified` on conditions and `general` on the structural shape, and it is a candidate, not a verdict. The pre-registered refuters are in `01` section 4.

- **cost if wrong:** if the shape is too strict, it forbids genuine zero-contact generalization that exists in nature and would send us looking for a source frame where none is needed. If it is too loose, it lets a fluent confabulation be called useful, which is the more expensive error because it spends the independence of the people checking it. Fig 2 :42: "Buy independence in proportion to the cost of being wrong." The cost is bounded and locatable because the three conditions and the refuter are written before the run.
- **undoable:** yes. Each condition is removable without touching the others. A single transfer-to-novel-ground experiment can narrow or withdraw D2 or D3. No primitive has to be abandoned and nothing in this folder has been sent anywhere.
- **reversed by:** a ground reading, not agreement. A model built with no direct contact, no different-closure lineage and no held predicting atom that nevertheless pays on first contact would break Fig 6 :23; a model that pays with no settlement event would break Fig 5 :70; a sensor for something that never registered would break Fig 6 :40; two frames sharing all their evidence settling the model would break Fig 2 :40. Until one of these fires, the verdict stands as `candidate`.
