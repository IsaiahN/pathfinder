## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence,"

From *The Library of Babel* (verified this session): "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question, "divergence is structural and the mapping is non-invertible" is a shape. "The cause is disk mass" is a name.

## 2. How a shape is obtained

- *Library of Babel* (verified this session): use the vocabulary you already have that is closest to the thing, then "With each new term gained, you narrow the space and deepen your vocabulary." Also: "Perhaps your problem was a bundle or conflation of several problems masquerading as one?" This is the union-compound instruction in F4 of `01_figure_grounded_audit.md`.
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge* (recorded reading): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *Library of Babel* (verified this session) on stopping: "the finish line will also be the starting place"; the paradox is that "you have already composed the answer through the process of locating it."

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

*They're Scanning Books* (recorded reading): "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." And: "Declaring the primitives does not make them neutral. It makes the choice visible."

For this question the six terms are not the answer; they are the compression axes the framework uses. Naming a physical mechanism (core accretion, migration, giant impacts) is a binding from the astronomy frame onto a residual description, not a derivation from those axes.

## 4. The source-discrimination error to avoid

*The Hard Problem is About Source* (recorded reading) gives the mechanism. Metamerism: an instrument reads green and "cannot comment on the source" (one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered). The reading does not determine the source. "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

Applied here: a mature architecture is a projection with lossy information. Several disk histories can produce the same architecture, so the architecture cannot name its source (F2 in `01`). What is owed is a source-discriminating instrument, not a cause asserted from the reading.

*The Recursive Self-Improvement Trap* (recorded reading): "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."

## 5. Q2  -  what licenses a particular physical mechanism?

**Nothing in the framework.** The framework returns a shape. A physical mechanism is licensed only by the ground settling a minted term, or by a provenanced import with a shadow test. Until one of those, the name is the searcher's own contribution and must be recorded as such.

Does this solution commit the forbidden error? No, provided the astronomy mechanisms stay in `09_watson_answer.md` WORLD and are never promoted into TETHER. The moment "the cause is X" is written as a figure verdict, the shape-not-a-name limit is breached and the mode becomes a `general` verdict with no measurement, which the framework names as an output-layer defect.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (recorded reading): "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A campaign that gathers prestigious names to agree with the shape is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay (recorded reading): "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." LLM output is "simulacra." So `01` is a simulated derivation, checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle anything it reports on.
