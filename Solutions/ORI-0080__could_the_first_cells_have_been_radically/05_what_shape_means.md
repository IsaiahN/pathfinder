## 1. A shape is a constraint, not a filler

The canonical rule states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134-135: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

For ORI-0080 this means the figures can return the following shape and nothing more:

> Any first cell must hold a boundary that distinguishes inside from outside, must compose a loop in which an output re-enters as input, and must stand in a comparison against a ground that does not move when a frame thinks about it. Fig 12 :121: *"cycle. The output re-enters as input. The sign of the loop decides whether it closes, and a chain cannot close by construction."* Fig 11 :39: *"capability is a property of agent-and-habitat, never of the agent alone."*

That shape is satisfied by a modern bacterium. It is also satisfied, as far as the figures are concerned, by an arrangement with a different informational polymer, a different chirality or a different solvent, provided a boundary, a cycle and a ground-contact relation can be composed. So a shape **constrains** the space of first cells and does **not fill** it. The specific chemistry is a `gap`, which is a verdict and not silence (Fig 13 :134).

## 3. What licenses a name, and why this question must withhold one

Only two things license a name under the framework:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* No reading of a first cell exists, so no chemistry is settled.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :50-52). A laboratory synthesis of an alternative polymer is a result from the chemistry frame. It licenses the statement "this arrangement is composable." It does not license "the first cell used it."

The relevant failure mode is named in the essay I opened this session. Isaiah N, *The Hard Problem is About Source* (2026):

> "If several paths create the same behavior, then behavior is a projection with lossy information"

and

> "an instrument that can't distinguish these cases demonstrates its own inadequacy."

Applied here: the shared molecular core is a reading taken from living organisms. That reading cannot comment on its source. Green could be one green light, a yellow-blue mix, RGB, CMYK, or a scheme not yet discovered; the paper notes that *"the full set of ways to produce a reading is not known to be closed or determined."* Likewise, a universal code and a lipid bilayer in survivors are compatible with several origin histories, including ones with no living representative. Naming DNA or RNA as *the* original substrate from that reading is the metamerism error. What is owed is a discriminator, not a name. Fig 6 :32: *"An instrument is not built from a description. It is improved from a worse instrument already returning something."*

## 4. The survivor set is one evidence pool, not a census of possibilities

The figures give two independent reasons, recorded in `01` F1 and F7:

- Fig 8 :39: *"So a search that finds nothing is never a proof of absence."*
- Fig 11 :68-69: *"what you failed to reproduce is invisible until the goal fails"*, *"what you unintentionally introduced is invisible until it acts."*

The world literature agrees at low overlap. NASA's own public FAQ says: *"we can only compare the DNA of organisms that exist today. Anything that went extinct in the past is not going to contribute to the DNA sequence data banks that we generate now. The information is simply lost from history."* Budd and Mann 2018 show mathematically that conditioning on survival creates apparent rate patterns in homogeneous models, so survivor-derived patterns cannot be generalized to the historical process. These are secondary corroborations; the verdict is figure-side.

## 5. Q: Does "shape, not a name" forbid talking about alternative biochemistries at all?

**No.** The rule governs a *missing primitive*, not the arrangement of primitives already held. Silicon, mirror chirality and hachimoji base pairs are bindings or imports discussed in the chemistry frame; the figures neither forbid nor select them. What is forbidden is presenting a binding as a derivation from the six-term set and presenting an import as an atom that moves the wall (Fig 6 :21: *"MINT composes inside the closure and can never add an atom."*).

Earlier in this run I considered the stronger sentence "the framework cannot name any first-cell chemistry, so alternative biochemistries are outside what can be discussed." That was an overstatement, retracted here and kept visible. The correct form: the framework cannot *select* a chemistry; it can constrain the shape a chemistry must realize, and the chemistry frame can supply bindings that are provenanced as such.

## 6. Correction to my own §3 (carried forward from a re-census)

The metamerism point in §3 is retained, but its scope is narrowed. The error is not "naming an atom already held." It is **naming the source of a reading without an instrument that discriminates sources**. So:

- Saying "a boundary, a cycle and a ground comparison are required" is a shape claim. Legal.
- Saying "this lab polymer is composable" is a provenanced binding from the chemistry frame. Legal.
- Saying "the first cell used this polymer because all survivors use it" is the metamerism error. Refused.

Both the shape limit and the binding distinction are recorded so neither is quietly lost.
