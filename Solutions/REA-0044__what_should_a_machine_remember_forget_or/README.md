## Restatement as an effect

A machine holds a library Γ and must decide, per object slot s, which terms stay available for composition, which lose their standing to be composed over, and which are compressed into reusable methods. The clause "according to whose interests" asks which seat's criterion settles those three decisions. Stated in effect terms: R = |Γ(b,a) − o′| per slot (Fig 1 :11, :19; Symbols table :38-40). Remembering keeps a composable atom with provenance. Forgetting adds a refusal rather than deleting a record. Compressing carries a method across the membrane with a measured round-trip gap. The ground, not the machine's own accounting, decides which of these pays. An answer would look like a three-part policy with a named decision seat, five pre-registered falsifiers, and a declared stop where no instrument discriminates.
