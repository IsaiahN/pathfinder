## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence,"

From *The Library of Babel*: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question the shape is: *two readings of one area law, related by a lossy cross-scale transform, coincident only after renormalization in a restricted regime, with the bond between them typed and the union unbundled.* The microscopic source stays marked `???`.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is *closest* to the thing, look for recurring new terms that overlap or correlate with it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause." So describe the residual as *same units, same scaling, different dependencies*, not as "entropy" alone, because the word is borrowed from two frames.
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *Library of Babel* on stopping: "the finish line will also be the starting place," and the paradox is that by then you have "composed the answer through the process of locating it."

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** THE_FORMULA step 5: "the ground settles it. Verified only by what pays." Here that would be an instrument that discriminates sources for the same area reading. None exists.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50), with a source gate and a shadow test. "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them."

*They're Scanning Books* sharpens the limit: "The real import is not a new term in the existing space. It is a new dimension of the space." And: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Also: "Declaring the primitives does not make them neutral. It makes the choice visible."

## 4. Why the source question is the specific forbidden error here

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and "it cannot comment on the source." One green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the **spectrometer**, not an argument, that resolved it.

Here the area-law reading is the green. Entanglement across a horizon and horizon geometry are two candidate sources. Frolov and Fursaev document that the divergence can be absorbed into a renormalized Newton constant while requiring an infinite negative bare geometrical entropy with no statistical origin. That is exactly the metamerism warning: the reading does not determine the source, and the renormalization is a bookkeeping move, not a discriminator. What is owed is a better instrument, not a name.

*The Recursive Self-Improvement Trap*: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."

## 5. Correction to my own reading of "shape, not a name"

I initially treated the rule as a ban on naming either entropy. That was too broad. The figures README phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a primitive not held in the library.

- Entanglement entropy and gravitational entropy are **both already in the physics library**. Naming them is not inventing a missing primitive; it is using terms from a frame that already holds them.
- What is missing is the **source-discriminating instrument**, and the framework can say only what it would have to do: separate sources that give the same area reading. That is a shape, not a name.
- So the rule is not "do not name the entropies." It is "do not present a binding between two held quantities as a derivation, and do not name the missing discriminator as if you held it."

Both claims are recorded: the narrow rule governs here, and the metamerism point in §4 is **not** retracted. The reason the source cannot be named is the missing discriminator, not a ban on using the words.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A list of famous names who agree with the shape claim is the named collapse, not corroboration. The legitimate ask is a budget to try the refuter.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post" but "the truly testable output would need to be derived from the real architecture or working the formula yourself." LLM output is "simulacra." So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.

## 7. What shape means, in one paragraph

A shape is the constraint you can state before you can name the missing thing. Here it is the typed bond between two held quantities and the unbundled union of three questions about them, plus the specification of an instrument that would name the source. The framework does not produce the microscopic degrees of freedom. It says what any acceptable answer must look like, records the round-trip gap, and stops where the instruments stop, with the lineage visible so the stop is checkable. Indiscernibility is not identity.
