# The Tether's answer on representing changing, heterogeneous agents

**Mode: `specified` on the four requirements, `general` on the structural shape, `gap` on the identity of the live rule. Not `grounded`.** This is a shape and a route, not a result. Simulated derivation checked against the figures (`05_what_shape_means.md` §8), not a ground reading.

## 1. The residual it answers

A model whose agents differ and keep changing loses the live per-agent signal whenever it pools them into one type or one average, and it cannot say which rule, goal or information set is actually governing at a slot and a step. The loss is compounded: the question is a **union** of within-agent time change (D1), between-agent difference (D2) and across-context change (D3), with the representation itself (D4) as the encoding layer. Fig 9 :57 "What remains is smaller and it is also categorically different: a case in two conditions is not a harder case of either." One lever leaves the intersections standing. Verdicts are kept separate per domain and never averaged into one modeling prescription.

## 2. The shape

1. **Index the residual per agent-slot and per step; never aggregate it into the reported score.** Fig 1 :19 "The residual is indexed by object slot, not aggregated." Fig 1 :22 "Aggregating across slots is how a live signal disappears into an average." A global score near zero with one live slot is a legal state (Fig 1 :13), so a pooled score can report success while the change goes unread. **Verdict D1: `specified`, triangulated.**
2. **Represent heterogeneity as a typed signature over a shared library, not as opaque type labels.** Fig 4 :20 "Only the actors, the currency and the anchor change." Fig 12 :46 "A bond is the typed relation between two operands." A rule is `→` sequence, a goal is `⋛` comparison, an information limit is `−` subtraction, progress is a subtraction, and a replaced rule is `¬` negation, which is unary and open-priced (Operators :51, :46, :58, :77). Under Fig 12 :5 "A set of ingredients is not one. The bond is the rest of the information, and it is the half nothing was recording.", a feature list is half a description. Two agents with the same atoms and different bonds are isomers (Fig 12 :117). **Verdict D2 and D4: `specified` on the bond mapping, `general` on the structure, single-source on the figure side with low-overlap world corroboration.**
3. **Across time and context, carry a reapplicable method and its purchase conditions, not a recording of the rule that worked.** Fig 4 :25 "A recording carried upward looks like knowledge and is a description of one occasion." Fig 10 :72 "When the question changes, the room should change. A room that stays fixed while the question moves is the failure; the correlation is only its symptom." Measure the round-trip gap when compressing a rule into a summary (Fig 4 :30). **Verdict D3: `specified`, triangulated.**
4. **Re-enumerate which agents matter for each new residual.** Fig 11 :51 "No standing list of good actors survives a change of residual." Valence is relative to the residual (Fig 11 :49), and capability is a property of agent and habitat, never of the agent alone (Fig 11 :39). A test harness is a substituted habitat, so a synthetic solve proves wiring and never capability (Fig 11 :70). **Verdict D3 second claim: `specified`, triangulated.**
5. **Hold bits and actions in two columns.** Fig 12 :126 "Bits price the description. Actions price finding out whether it holds." They are in different units and do not add (Fig 12 :125, :130). Complexity scores are filters for the budget, not witnesses for the verdict (Fig 9 :60). **Verdict D4 second claim: `general`, single-source.**
6. **Declare the `gap` on which rule is live.** Several rule histories can produce the same behavior, so outputs cannot discriminate the source (*The Hard Problem is About Source*: "If several paths create the same behavior, then behavior is a projection with lossy information"). Fig 13 :135 "It cannot say which primitive is missing, because naming it would mean already holding it." The model can return the shape of an adequate rule representation and state that a source-discriminating instrument is owed. It cannot name the rule without one. This is unreachable-at-this-budget, not proven underivable (Fig 6 :27). **Verdict: `gap`, triangulated on the limit.**

## 3. What it explicitly does not say

- Not a modeling language, not an architecture, not a parameter count, not a "best" formalism. Those are names the framework does not return.
- Not a representative agent, and not approval of pooling as a harmless approximation (F1).
- Not a fixed agent taxonomy. Atom roles in Fig 13 are structural roles, not agent kinds (`01` S1).
- Not a rule-identification procedure. The operator set has no such operator; `¬` refuses a rule but does not identify its source.
- Not a single objective that merges description cost and ground-check cost.
- Not grounded. No model was built, run or measured, and no target-system measurement was taken.

## 4. What would settle it : the ground

A source-discriminating instrument, not a further argument. From *The Hard Problem is About Source*: an instrument that reads green "cannot comment on the source"; the spectrometer resolved it, not a debate. Here:

- **Per-slot probe:** intervene on one agent's rule at one step and check whether the per-slot residual registers while the population average does not. If it registers, F1 is confirmed at the ground.
- **Bond test:** swap two agents with identical ingredients but different bond arrangements and check whether the target system distinguishes them. If it does, the isomer claim pays (Fig 12 :117).
- **Context shift:** pre-register a context change and test whether the carried method still pays without replaying the recorded rule. If it does not, F3 pays.
- **Reaction-norm test:** examine the same agent across an environmental gradient. If an apparent stable difference collapses into plasticity, the standing-type reading is refuted (animal-behaviour corroboration).
- **Rule-source instrument:** perturb internal state or apply an intervention that separates candidate rule histories producing the same output. This is what would close F7. Until it exists, the `gap` stands.
- **Standing falsifiers from `01` §4:** seven pre-registered conditions. Any one firing withdraws the corresponding requirement.

## 5. The honest stop

**Unreached, not unreachable in principle.** The four requirements are structural constraints any adequate representation must satisfy; they stop at the limit of what the available instruments can distinguish. The specific live rule is not named, because naming it would mean already holding a source-discriminating instrument. The lineage is recorded so the stop is checkable. Fig 13 :134 "So the system can report that it lacks something rather than producing an answer anyway. Unreachable is a verdict here, not a silence," and "Indiscernibility is not identity" (canonical README). Agreement among modelers is not such an instrument; Fig 2 :35 "Alignment is triangulation, not negotiation. A mirror cannot correct you."

## 6. One-paragraph version for outreach

> The Tether does not pick a modeling formalism, and it does not name the rule inside any agent. It says that a model of changing, heterogeneous agents must keep the residual indexed per agent and per step, because a pooled score can sit at zero while one live slot carries all the signal; that an agent's rule, goal and information access are different typed relations, so two agents with the same ingredients but different bonds are different things that an ingredient list cannot tell apart; that when the context changes a reapplicable method must cross, not a recording of the rule that worked last time, with the compression gap measured; and that which agents matter must be re-enumerated for each new residual because no standing importance list survives a change of residual. It keeps description cost and ground-check cost in separate columns, and it refuses to name the live rule from behavior alone: several rule histories can produce the same reading, so a source-discriminating instrument is owed. What it offers is the shape any candidate representation must have, seven refuters written in advance, and the instruments that would close the gap. The slot stays open until the ground settles it.
