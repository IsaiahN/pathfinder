## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence"*; the framework *"cannot say which primitive is missing, because naming it would mean already holding it"* (Fig 13 :135).

From *The Library of Babel*, opened this session: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For ORI-0061:

- `a sustained, spendable difference delivered as a flow through a closed catalytic cycle, in a habitat that renews it` is a shape.
- `alkaline hydrothermal redox gradients`, `UVC photons`, `serpentinization`, `wet-dry cycling` are names.

The shape is what the figures license. Each name is a binding from a research frame and carries zero evidentiary weight until a source gate and shadow test are supplied (Fig 6 :23; Fig 8 :50-52).

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary already held that is *closest* to the thing, then look for new terms that overlap or correlate with it. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*, opened this session: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This governs the two-stage offer in `02_outreach_email.md`: describe what a flow-through experiment would show, then ask for a verdict.
- *Library of Babel* on stopping: *"You will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better."*

Applied here: start from the ordinary words already held ("energy," "source"), notice they fail the direction test (Fig 13 :14), move to "gradient," then "flow," then "cycle," then "habitat." Each step narrows the search space without naming a site.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README says the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23; Fig 8 :50-52), with a source gate and a shadow test.

*The Hard Problem is About Source*, opened this session, gives the mechanism for why a name needs a discriminator. Metamerism: an instrument reads green and *"cannot comment on the source"*; one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. The reading does not determine the source. *"If several paths create the same behavior, then behavior is a projection with lossy information."* It was the **spectrometer**, not an argument, that resolved it: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."*

For ORI-0061 the analogue is direct. A surviving self-maintaining network is a reading. It does not tell you whether the source was a proton gradient, a redox couple, or a photon flux, because several sources can produce the same survival. What is owed is a discriminator, not a name. The claim that a particular gradient powered the earliest system is the metamerism error: a source named from a reading without an instrument that discriminates among sources.

## 4. Why the question is a bundle, not one question

*The Library of Babel*: *"Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually to find their answers and then combine them in a satisfactory way."* This corroborates Fig 9 :54-57 and the three conditions C1 (supply), C2 (closure), C3 (habitat renewal) in `01_figure_grounded_audit.md` section 1.3. The word "energy source" hides all three. Asking for one name clears at most one region.

## 5. Correction to my own §3: names of held atoms versus names of missing primitives

I initially wrote the shape-not-a-name rule as if it forbade every particular source name. It does not. The README's phrase governs a **missing** primitive, one not held in Γ. Gradient is already among the six (Fig 13 :22); energy is already among the six (Fig 13 :14). So a binding such as "a pH gradient across a vent membrane" is not the invention of a seventh primitive. It is a composition from held atoms, plus a site description from the geochemistry frame.

What remains wrong in such a binding is different and still real:

- calling it an import that moves the wall (Fig 6 :21, *"MINT composes inside the closure and can never add an atom"*);
- presenting it as the framework's answer rather than as a hypothesis from another frame (Fig 8 :50-52);
- skipping the instrument that would discriminate among sources (§3 above).

Both the original overstatement and this narrowing are recorded, so neither is quietly lost. The verdict is unchanged: the specific source is still a `gap`, now for the sharper reason that the discriminator is missing, not that naming is forbidden.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*, opened this session: *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A campaign that gathers famous names to agree with the shape is the named collapse. The legitimate ask is a budget to be tried against a flow-through experiment.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too (intelligence is essentially arrangement). However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* The essay also warns that *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle ORI-0061.
