## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134-135: "Unreachable is a verdict here, not a silence," and "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel* (opened 2026-11-23): "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question the shape is:

- two maps must be distinguished before either is answered (a within-scale dynamics map and a cross-scale description map);
- for the description map, loss is definitional and a round-trip gap `R_T` is owed;
- for the substrate, conservation attaches to energy, not to information;
- for the dynamics map including quantum gravity, no figure line governs, so the shape includes an honest `gap`.

"Information is conserved in all processes" is a name (a filled slot). The shape is "which map, and what gap is recorded." The preferred shape was bound as an ordinary term in `01_figure_grounded_audit.md` §0 before the run, per Fig 5 :65-66: "make the sought-for shape an ORDINARY TERM. Write down what an answer would look like, bind it, and let it accrue a residual like anything else."

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary already available that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. "With each new term gained, you narrow the space by definition and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause." Hence the question was restated as "can the earlier description be reconstructed from the later one?", not as "is information conserved?", because "information" is the borrowed word causing the bundle.
- Fig 9 :54-58: unbundle before searching. "What remains is smaller and it is also categorically different: a case in two conditions is not a harder case of either."
- *Library of Babel* on stopping: "you know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better." The paradox: "By the time you learn the EXACT search terms to find the CORRECT book, you won't need to read it anymore, because you have already composed the answer through the process of locating it."

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The figures README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

In this question the world literature supplies names for the physics domain ("unitarity", "Page curve", "islands"), but those names come from a frame with its own ground and are not figure derivations. They are recorded as `specified` world corroboration. For the quantum-gravity case the ground is unreached, so naming a verdict about conservation would be the forbidden move: a name where only a shape (and a `gap`) is available.

## 4. The metamerism check: why an instrument, not an argument, settles D3

*The Hard Problem is About Source* (opened 2026-11-23) gives the mechanism. Metamerism: an instrument reads green and "cannot comment on the source." Several underlying causes can produce the same reading. "If several paths create the same behavior, then behavior is a projection with lossy information". "An instrument that can't distinguish these cases demonstrates its own inadequacy". It was the spectrometer, not an argument, that resolved the case.

Applied here: a claim that "information is conserved in all processes" reads a single outcome (fine-grained entropy follows a Page curve, or it does not) and names a source (unitary dynamics, or objective collapse, or a remnant). The reading does not determine the source. Several mechanisms yield the same curve-ish reading. What is owed for D3 is a source-discriminating instrument, not a further argument. Since none exists at the Planck scale, D3 stays `gap`. This is the same structure as the exemplar's metric-to-Gradient metamerism finding, applied to a different residual.

## 5. What the framework can and cannot license here

**Can license:** a shape for the split (two maps), a structural no for cross-scale conservation (Fig 4 :27), a structural no for an information conserved-primitive (Fig 13), and a reported `gap` for the dynamics question (Fig 13 :134).

**Cannot license:** the name of a physical mechanism for quantum-gravity information flow; a claim that the field's consensus settles the physics question; a single averaged answer; an import that adds a seventh primitive. "what a missing thing would have to look like (a shape, not a name)" governs missing primitives, and conservatism about names is what keeps the record checkable.

Correction carried forward from the exemplar: the "shape, not a name" rule governs a *missing* primitive, not the selection of atoms already in Γ. Here no atom named "information" is in the six, so there is no held atom to bind. The rule applies with full force. This correction is kept visible rather than silently applied.

## 6. Prestige is not action, and this audit is a simulation

*The Recursive Self-Improvement Trap* (opened 2026-11-23): "Prestige must never be allowed to validate an action directly." and "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

A campaign that gathers famous names to agree that information is conserved (or that it is not) is the named collapse, not corroboration. The legitimate ask is the opposite: give the claim a budget to be tried and let a ground, an instrument or a measured round trip settle it.

Same essay: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post." and "the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01_figure_grounded_audit.md` is a simulated derivation, checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.
