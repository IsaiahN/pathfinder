## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence," and Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel* (fetched): "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- A shape: "the anchor that settles 'earned trust' must not move when the institution pushes on it, and each harmed group's residual must be read separately."
- A name: "hold a truth commission, pay reparations, and publish a report." That is a policy chosen from the world literature, not derived from the figures.

The distinction matters politically as well as methodologically. Naming a single mechanism invites the failure the transitional justice literature records: a mechanism that becomes "a political slogan, a 'feel good' label" while "the actions taken ... do little to convey the semantics of the concept" (*Truth commission*, opened 2026-11-23).

## 2. How a shape is obtained

- *Library of Babel* (fetched): "With each new term gained, you narrow the space and deepen your vocabulary." The method is proximity: use the vocabulary you already have that is closest to the thing, find recurring new terms that overlap or correlate with it, and recurse.
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge* (title in the eight-essay set; not fetched this session, quoted as recorded in the imported exemplar): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." For this question the plain description is: if repair is real, each harmed group's own outcome measure should move, and an independent verifier should confirm it without the institution being able to predict the finding.
- *Library of Babel* on stopping (fetched): "you will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better." For this question the loop stops when the residual stops arriving per group, which is either a genuine repair or a closed channel. From inside, those look the same (Fig 4 :89 in the formula's closure note), which is why the record matters.

Applied here, the bootstrapping ran: "trust" (held) → "trust is a relation, not a property" → "anchor" → "does it move when pushed" → "per-group residual" → "reachable and correctable channel" → "verifier the institution cannot reconstruct". Each term narrowed the space. The last term is still a shape, because the figures do not name which verifier.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The README says the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. Here the importing frames are procedural justice, transitional justice, restorative justice and legitimacy studies. Each candidate mechanism is licensed by its own literature, not by the figures, and is debited against independence.

*They're Scanning Books When They Should* (title in the eight-essay set; not fetched this session, quoted as recorded in the exemplar): "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." So the vocabulary used to describe repair is a visible choice, not nature's list.

## 4. The ground and the source problem

*The Hard Problem is About Source* (fetched) gives the mechanism that governs this question. Metamerism: an instrument reads green and "the instrument is speaking only about what it measured, it cannot comment on the source." Several underlying causes can create one reading. "If several paths create the same behavior, then behavior is a projection with lossy information." "An instrument that can't distinguish these cases demonstrates its own inadequacy." "The answer is unreached until a better instrument exists."

An institution's trust reading (high satisfaction, few complaints, good standing) can come from genuine repair, from a silenced group, from a pooled metric, or from a survey that excludes the harmed. The reading does not determine the source. What is owed is a discriminator that ranges against each harmed group separately and an independent check, not a second argument about sincerity. Fig 11 :70: "A test harness is a substituted habitat. Which is why a synthetic solve proves wiring and never capability." An internal culture survey is a substituted habitat; it proves the survey works, not that trust was earned.

*The Recursive Self-Improvement Trap* (fetched) adds: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." An institution cannot validate its own repair. And: "You may all agree and be wrong. You may set your clock to someone else's, who was setting your clock to yours, and be off by many deviations over time. You need ground truth to define where you stand."

## 5. Answer to the shape question

**What shape must an answer to INS-0024 have?**

1. It must name the anchor that settles "is trust earned" and show that the institution cannot move it. Here that anchor is the observed experience and judgment of the harmed people, read per group (Fig 2 :29, :36-38; Fig 1 :19).
2. It must state what change in contact would lower each group's residual, not merely what change inside the institution (Fig 11 :39-40; Fig 6 :23).
3. It must keep the channel reachable: voice, correctability, disaggregated reporting (Fig 10 :24-26; procedural justice research).
4. It must put the verdict in a seat the institution cannot reconstruct and whose reputation does not depend on the finding (Fig 10 :42, :93; Fig 2 :42).
5. It must treat repair mechanisms as a union, with provenance, and expect a categorically different residue after each lever (Fig 9 :55-57).
6. It must refuse to name a single mechanism as the answer. The specific mechanism is a `gap`: Fig 13 :134, "Unreachable is a verdict here, not a silence."

**Does the derivation commit the forbidden error?** It does not name a policy. It does name the anchor (harmed people's judgment), but that is not the "shape, not a name" error: the anchor is licensed by Fig 2 :36 because the question is constitutively about people. Naming the anchor is deriving it; naming a repair policy would be importing one. Both claims are recorded so neither is quietly lost.

## 6. Consequences for contact

**Prestige is not action.** *The Recursive Self-Improvement Trap* (fetched): "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A respected institution or a famous auditor gives a repair attempt a budget to be tried; it does not show that the repair worked. A list of checkers selected for receptiveness is the named collapse (Seat Map :163). The legitimate ask gives the claim a budget to be tried and lets the ground, an affected group's outcome measure and an independent verifier, settle it.

**This audit is a simulation, not a ground reading.** Same essay (fetched): "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too (intelligence is essentially arrangement). However, the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of any institution and must be labelled as such. It cannot settle anything it reports on.
