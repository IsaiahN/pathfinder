## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence". Fig 13: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel* (opened): "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- Shape: *a structure mediates the relation between a spin system and a gauge description; the bond carries topological information the spin list does not; the gauge group is a binding to be provenanced, not a derivation.*
- Name: *herbertsmithite is a Z2 spin liquid.* That is a physics-frame binding, and it is earned only by a ground reading.

## 3. What licenses a name

Only two things, both outside the shape:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest." Semeghini and Karch are such settlements, but only for their simulator habitats.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51), with a source gate and a shadow test. Installing QCD apparatus into a spin model is this kind of move; it must say what gap it explains.

*They're Scanning Books* (carried) sharpens the first: "The real import is not a new term in the existing space. It is a new dimension of the space." And: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." And: "Declaring the primitives does not make them neutral. It makes the choice visible."

The six are a visible guess, not a discovery of nature's own list. Naming a gauge group as *the* answer to a material slot turns a visible choice into an invisible one.

## 4. Why "metric tensor equals Gradient" is the wrong analogy for this question

The exemplar's GR/QM case named Gradient from the metric reading and called that a metamerism error. *The Hard Problem is About Source* (opened) gives the mechanism: an instrument reads green and "cannot comment on the source." "If several paths create the same behavior, then behavior is a projection with lossy information." It was the spectrometer, not an argument, that resolved it.

For quantum spin liquids the analogous error would be: read a pinch point or a neutron continuum and name its source (a specific gauge group) without an instrument that discriminates among sources. Kitaev's exact solution is not that error, because the gauge structure is derived from the Hamiltonian, not read off a projection. A material candidate is that error if a name is assigned from one signature alone. What is owed is a source-discriminating instrument (Yang/Shannon/Lee's daughter-phase analysis, Linsel et al.'s percolation order parameters), not a name.

## 5. Q: does "shape, not a name" forbid naming Z2 or U(1)? CORRECTION TO MY OWN FIRST PASS

1. The README's phrase is "what a **missing** thing would have to look like (a shape, not a name)." The subject is a primitive not held in Γ.

## 6. Two consequences for this solution

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (opened): "Prestige must never be allowed to validate an action directly" and "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A campaign that gathers famous spin-liquid researchers to agree with the shape claim is the named collapse, not corroboration. The legitimate ask gives the claim a budget to be tried and lets a ground settle it.

**This audit is a simulation, not a ground reading.** Same essay (opened): "LLMs can quickly simulate an approximate answer/output" while "the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01` and every other file here are simulated derivations checked for internal consistency against the figures. They are not tests of the question and must be labelled as such. They cannot settle anything they report on.
