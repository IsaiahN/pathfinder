## QUESTION

Decide, in effect terms, whether "reliably" can be satisfied for the discrimination between anthropogenic forcing and natural internal variability in extreme events. Option A: answer yes as one global verdict, treating the observed record and the counterfactual world as equally anchored, and treating a single event as attributable in the same sense as a class. Option B: answer per regime, with an anchor only where an instrument returns one, an open source slot where no discriminator exists, and a class-versus-singleton split. What each leads to: A overclaims at the single-event scale, aggregates the live per-slot signal away, and spends the independence of anyone asked to endorse it. B returns a checkable shape, four written refuters, and an honest `unreached` where the instrument is missing.

## DOMAIN CENSUS

R by arity, symmetry and scale, then one line per domain with actors, currency and anchor; partition or union; order by dependency.

- **R (the residual).** The gap between the observed event statistics and the statistics predicted under a natural-only hypothesis, per slot s: `R_s = |P_obs(s) - P_nat(s)|`. Arity: three terms, of which the counterfactual is never observed. Symmetry: ordered comparison, not a symmetric join; swapping factual and counterfactual changes the claim. Scale: one event versus a class, local versus global, hours to decades for the event and decades to centuries for the baseline.
- **Domain 1, observed record.** Actors: thermometers, satellites, reanalyses, event catalogues. Currency: measured magnitude and frequency of the class. Anchor: the measurement, nameable and non-updating. Question type: part of a union.
- **Domain 2, counterfactual model frame.** Actors: GCMs, large ensembles, ALL and NAT experiments, statistical attribution methods. Currency: `P_ALL`, `P_NAT`, risk ratio, FAR. Anchor: none nameable for the NAT world; the observed anchor is borrowed only for evaluation. Question type: a frame, not anchor-bearing ground, part of a union.
- **Domain 3, internal variability.** Actors: ENSO, NAO, PDO, chaotic weather. Currency: unforced variance and mode amplitude. Anchor: partial (control runs, paleo), too short for rare-event tails. Part of a union.
- **Domain 4, verification and outreach.** Actors: expert readers, reviewers, editors. Currency: agreement and residual. Anchor: the ground, never agreement. In this simulated run all seats share one evidence pool, so independence is zero.
- **Partition or union.** Union. A compound of forced signal, internal variability, measurement error and model representation error. One lever clears only one condition. Fig 9 :54 "And when the split lands on a union rather than a partition, unbundle before you search again." Split before searching into observed change, counterfactual baseline, and class-versus-singleton scale.
- **Order by dependency (Fig 3).** Perception, then event-definition vocabulary, then the comparison, then the verdict. A reading taken below the break is a reading of nothing.

Strain test applied: the anchor line fits Domain 1 without strain. Applied to Domain 2 it strains, because a model-generated counterfactual moves when the model changes. Per the strain rule the line governs another quantity, so Domain 2 was re-censused as a frame. No strain remains after re-census.

## VERDICT (from the figures)

Reliability is a per-slot, per-regime property, never one yes or no. Against the observed record, a class of events can be reliably shown to have changed where the measurement is an anchor and the residual is per slot; the observation-only step is grounded, the attribution step added on top is specified. The natural-only counterfactual has no observed anchor, so that step is conditional on independence between framings and on recorded provenance. One specific event is unreached: its magnitude is one reading with several sources and no instrument at that resolution returns the source. The framework returns the shape, four written refuters and an open slot, not a new climate result. Confidence labels are filters, and agreement among frames sharing evidence is not a witness.

- **cost if wrong:** bounded and locatable, because the claim is mode-labelled and split by regime. The real cost is a false claim of single-event reliability, which spends the independence of outside readers and can mislead decisions that use the claim. Fig 2 :42 "Buy independence in proportion to the cost of being wrong." That cost is avoidable by leading with the shape claim and the refuters and by keeping the source slot open.
- **undoable:** yes. The overclaim is removable without touching the figure derivation: restate the result per regime, keep the class-versus-singleton bond distinction, and record provenance for every counterfactual import. No primitive is withdrawn and no published assessment is overwritten.
- **reversed by:** a ground reading, not agreement. A source-discriminating instrument returning the same source for one event under two low-overlap framings with matched observed frequencies would settle the single-event case; convergent low-overlap class attribution with non-overlapping uncertainty and a provenance record would strengthen D2; a natural-only baseline observed at the event's resolution would dissolve the anchor split; a dependency check showing event definition does not change per-slot attribution would reverse `06_isomers_and_order.md` Q3. Until one fires, the verdict stands as `candidate`.
