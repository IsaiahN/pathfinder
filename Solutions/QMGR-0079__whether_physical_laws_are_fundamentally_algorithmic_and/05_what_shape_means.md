## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32 (verbatim figure text): **"you get a kind of thing, never the answer itself"**. Fig 13 :133: **"what it returns is a shape rather than a name"**.

From *The Library of Babel* (opened 2026-11-23): *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question:

- A shape: *an algorithmic description is a generator with finite kinds, unbounded arrangements, an import-only wall, a self-limit no internal proof crosses, and a settlement only the ground can give.*
- A name: *the correct algorithm is cellular automaton rule 110 / the universe is a quantum computer / the law is a specific program.*

The first is defensible from the figures. The second is a binding from the physics frame and is provenance, not derivation.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary already closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."* Applied here: start from "description length," "closure" and "residual," which the figures already hold, and let the barrier lines narrow the space rather than starting from a favoured physical theory.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* So the outreach first contact is an effect description (what you would see if the shape were true), not a theory.
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Library of Babel* on stopping: *"you will know that you are done because the finish line will also be the starting place"*, and the paradox: *"by the time you learn the EXACT search terms to find the CORRECT book, you won't need to read it anymore, because you have already composed the answer through the process of locating it."*

## 3. What licenses a name here

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

For this question, neither has fired. The claim "physical law is a quantum computer" is a world-source proposal (Lloyd 2013), not a figure derivation. It is recorded as a corroborating candidate in `09_watson_answer.md`, never promoted to the verdict.

## 4. Why naming an algorithm from a compact description is the forbidden error

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and *"it cannot comment on the source"*. Several underlying causes yield the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information (it cannot define consciousness in full)."* And *"An instrument that can't distinguish these cases demonstrates its own inadequacy, it cannot claim anything substantial about what is being measured or what causes it."* It was the **spectrometer**, not an argument, that resolved the case.

Applied here: a compact, predictive algorithm is a reading. It does not determine the source. Several source stories (discrete substrate, continuum limit, information-theoretic reconstruction) could yield the same predictions. Naming one as *the* algorithm from the reading alone is the metamerism error. What is owed is a discriminating instrument, not a name. This is the same point `01` F7 makes as a round-trip gap.

## 5. The specific correction for this question

The exemplar records a useful correction, and this question needs its own version.

The README's phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a primitive not held in `Γ`. Here, "algorithmic" and "discrete" are **not missing primitives**. Fig 13 :43 says the continuum was removed as a seventh member, and Fig 13 :124-125 says *"Smoothness, symmetry, chaos and discreteness are each what a particular composition leaves behind, and none is a seventh member."* So algorithmic character is a **derivative** of composition, which is a stronger reason to refuse the name than the simple "shape, not a name" rule.

My §1 above is therefore refined, not retracted: "shape, not a name" applies here with extra force because the sought object is a level-relative remainder, not merely an unheld atom. Both statements are kept so neither is quietly lost.

## 6. Prestige is not action

From *The Recursive Self-Improvement Trap* (opened 2026-11-23): *"Prestige must never be allowed to validate an action directly."* And: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."*

A well known advocate of digital physics, or a well known critic, is a source of a budget to try a claim, not a source of its truth. The public venues in `03_public_contact_points.csv` are chosen for ground visibility and opt-in contact, not for the prestige of the names on their editorial boards.

## 7. My own audit is a simulation, not a ground reading

Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post."* And: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself. An external validator, or ground, is always needed."* Also: *"Metatheories cannot validate themselves. This is Godel's insight, and it still holds here."*

So `01_figure_grounded_audit.md` is a simulated derivation checked for internal consistency against the figures. It is not a test of whether physical law is algorithmic and cannot settle anything it reports on. This is stated on every substantive file.

## Falsifier for this reading

This reading of "shape" is refuted if the figures are shown to license naming a specific algorithm as the primitive of physical law, or if discreteness is established as an indivisible, load-bearing seventh member rather than a composition remainder. Both would break §5 and would require a new census.
