# Solution ECO-0046

**Question:** How should conservation balance measurable human benefits against ecological values that are difficult to quantify?

**Source:** ecology.txt line 57

**Section:** 5. Ecosystem functions and services

**Mode:** `general` on the structural shape (incommensurable currencies, per-slot residual, anchor), `specified` on the decision procedure. Nothing here is `grounded`: no single measurement settles a normative 'how should'.

**Status:** done

**Registry status:** pending

**Boundary.** Everything in this folder is a simulated derivation checked for internal consistency against the figures, not a ground reading. The framework's own rule applies: LLM output is 'simulacra' and 'the truly testable output would need to be derived from the real architecture or working the formula yourself' (The Recursive Self-Improvement Trap, cited in `05_what_shape_means.md`). This package cannot settle the question it reports on. No files outside this folder were modified.

**Question restated as an effect.** A conservation choice selects an action (protect, restore, manage, allow use, convert). Each action yields a vector of outcomes. Some outcomes register in one market-denominated accounting (measurable human benefits: timber, catch, carbon, willingness to pay). Others do not register in that accounting at all (values difficult to quantify: existence of a species, ecological integrity, cultural identity, bequest, intrinsic value). The residual is this: a decision procedure that holds only one accounting produces an answer that is self-consistent yet systematically wrong, because the unpriced side cannot generate a signal inside the priced frame. An answer would look like a rule for composing both sides into a decision without pretending they share a unit.

**Field for public contact points:** conservation priority research.

## What is deliberately not here

Reason, in the figures' own words: "High correlation is disqualifying for a verdict and efficient for a convention" (Seat Map :163) and "A verifier that can reconstruct the claim cannot verify it" (Fig 10 :42).
