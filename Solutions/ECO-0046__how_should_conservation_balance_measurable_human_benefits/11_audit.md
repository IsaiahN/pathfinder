## Round trip gap R_T

The Symbols table defines R_T as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

1. **Sent up (x):** the heterogeneous value set, with per-slot residuals, protected values, habitat cascades, and the order of actions.
2. **Abstraction (T_A):** the shorthand carried in `07_the_tether_answer.md`, namely 'different currencies, keep them apart, enumerate habitat, two anchors, visible conventions, thresholds, publish the gap'.
3. **Concretisation (T_E):** a concrete decision, for example 'protect the core, restore the corridor, price the carbon, compensate the community'.

**R_T is nonzero.** Four things the shorthand holds do not survive the trip back down:

- which specific slot carries the live residual (Fig 1); the shorthand says 'keep per-slot' but the concrete decision must name the slot, and naming it is new work;
- which value is protected rather than merely unpriced (F7), because the shorthand says 'threshold' but the concrete case must identify the threshold holder;
- the order of actions, which the shorthand records as sequence but the concrete case must license with evidence (06 Q3);
- the identity of the second anchor, since 'documented human judgment' is a type, not a named, checkable record.

Conversely, one thing survives cleanly: the refusal to add the two currencies and the requirement to publish what an index drops. R_T is **not** measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating the shorthand as identical to the figures would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
