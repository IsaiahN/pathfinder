## Independent domain census (written from the residual line alone)

I redid the census before relying on the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors, currency and anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the difference between acceptance or propagation and what the ground returns for a claim. Arity: claim times source times receiver, so per slot, never aggregated (Fig 1 :19). Symmetry: belief and sharing are different operations; one changes an internal state, the other changes a network. Scale: cognition, dyad, group, network, institution, with the cast and anchor re-censused at each size (Fig 4 :19-20).
- **D1, claim and ground.** Actors: proposition, evidence, instrument. Currency: residual between prediction and observation. Anchor: the ground, which does not update. Question type: a truth verdict, constitutively about the ground.
- **D2, source trust.** Actors: speaker, audience, trust relation. Currency: credibility and standing. Anchor: conditional. A predictive track record is a valid anchor; in-group repetition is not. Question type: a union of two conditions with different anchors.
- **D3, identity and convention.** Actors: in-group, out-group, standards. Currency: shared meaning and belonging. Anchor: the group for questions about people, nothing for truth. Question type: convention, not epistemic.
- **D4, propagation.** Actors: routers, bridges, feeds. Currency: attention and reachability. Anchor: the ground via a decaying channel. Question type: crossing and import.
- **D5, verification.** Actors: checker, anchor, seat. Currency: residual and provenance. Anchor: the ground, never agreement. In this run independence is zero.

Order by dependency: perceive the claim, acquire terms for what a source affords, state the objective separately for truth and belonging, then route, then carry and update. The middle link lacks an instrument in most of the literature (Fig 3 :27).

## Round trip gap R_T

3. **Concretisation (T_E):** a concrete claim about a given community, for example "in-group credentials raise belief in this community," which is what a reader will actually take away.

**R_T is nonzero.** Three things the shorthand holds do not survive the trip down:

- the **valence split** between convention and verdict is dropped when agreement is counted as support (Fig 2 :39-41).

One thing survives cleanly: a cue that moves the inherited weighting can change confidence without changing observation. That is the residue worth sending. R_T was not measured numerically, because no ground reading exists; it is recorded qualitatively as the enumerated set of dropped constraints. Treating the shorthand as identical to the figure set would set R_T to zero and would be the dead-reckoning error Fig 4 :30 names.
