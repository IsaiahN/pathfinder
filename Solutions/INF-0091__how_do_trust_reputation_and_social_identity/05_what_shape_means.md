## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 says the system "can say the answer is out of reach with the library as it stands" and "cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel* (carried): "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

A **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question, the shape is a *separator*: it says which kind of quantity each cue is, in which domain, against which anchor, and under what failure condition, without saying a universal coefficient or a ranking.

## 2. How a shape is obtained

- *Library of Babel* (carried): use the vocabulary already closest to the thing, look for recurring new terms that overlap with it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge* (carried): "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- For INF-0091 the effect terms are deliberately behavioural: what changes confidence, what changes ground accuracy, what changes propagation, and what would make us withdraw the claim. We do not start by naming "trust" as a primitive; we describe what a trust-like effect would look like if it were a prior versus if it were a record.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "SETTLE - the ground settles it. Verified only by what pays. A gate is not the ground." The canonical README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test.

*They're Scanning Books* (carried): "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." And: "Declaring the primitives does not make them neutral. It makes the choice visible."

Applied here: saying "trust raises belief" names a source of a reading without an instrument that discriminates the prior from the observation. What is owed is a discriminator, not a name.

## 4. The source-of-a-reading problem applied to reputation

*The Hard Problem is About Source* (carried) gives the mechanism. Metamerism: an instrument reads green and "cannot comment on the source" - one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. "If several paths create the same behavior, then behavior is a projection with lossy information." "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

For INF-0091: a high reputation score and a well-calibrated source produce the same reading (agreement with the claim). The score cannot comment on which source produced it. Naming the source as "trustworthy" from the agreement is the metamerism error. What is owed is a discriminator, for example an out-of-sample track record against a non-updating anchor, not a name and not a scolding about bias.

*The Recursive Self-Improvement Trap* (carried): "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."

## 5. Q - What does "shape" mean specifically here?

**Answer.** The shape is a per-claim separator with four parts, not a coefficient:

1. a prior-versus-observation split (where the cue enters the belief);
2. an anchor test (whether the cue's standing pays against something that does not update);
3. a valence split (the same agreement is a convention and a corruption, depending on the question);
4. a closure test (whether the transmission brings a new atom from a differing frame or is a recording inside one closure).

That is a kind of thing, not an answer. Fig 9 :32. It stays per slot (Fig 1 :19), and the verdicts stay per domain and unaveraged.

## 6. Correction to my own reading (kept visible)

I initially wrote section 3 as if "shape, not a name" forbade naming any of the three cues. That overstates the rule. The README's phrase governs a **missing** primitive, one not held in the library. Trust, reputation and identity are not candidate primitives of the six-term set at all; they are bindings and standing relations onto the held network and belief machinery. Naming them as bindings is provenance, not the invention of a seventh primitive. What remains forbidden is:

- claiming the binding moves the wall (Fig 6: an import adds an atom; this binding adds none);
- calling a standing accrued inside the frame a ground metric (Fig 1 :26-27);
- converting a shared meaning into a truth verdict (Fig 2 :39-41).

The metamerism point in section 4 is **not** retracted: the source of a credibility reading still cannot be identified from the reading alone. The reason is the missing discriminator, not a ban on naming held relations. Both readings are recorded so neither is quietly lost.

## 7. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried): "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A campaign that gathers well-known names to agree with the separator is the named collapse, not corroboration. This is doubly relevant to a question about reputation: using reputation to validate a claim about reputation would be the very error the claim identifies.

**My own audit is a simulation, not a ground reading.** Same essay (carried): "LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." LLM output is a simulacra. So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle anything it reports on.
