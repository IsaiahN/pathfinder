## 0. The residual, in effect terms

The question asks how an inherited representation of a past conflict or displacement changes two present-day quantities: reasoning (what is taken as evidence, what is expected, how a current actor's intention is read) and trust (whether another person, group, or institution can be relied on).

Two readings, bound here as ordinary terms before any figure is consulted (Formula "Direction": write down what an answer would look like, bind it, let it accrue a residual):

- **Option A, the content reading.** The memory is information about the past. Its effect is the effect of its contents. Predictions: which events are recalled should predict which inferences are drawn; correcting the factual content should change the reasoning and the trust; two people with the same remembered facts should reason alike for the same reason.
- **Option B, the structural reading.** The memory is an inherited prior and a shared evidence pool. Its effect is not its truth but its position in the checking arrangement: it supplies the terms in which present events are read, it correlates the frames that hold it, and it replaces contact with an anchor by agreement inside a closure. Predictions: frame independence, not memory content, should predict whether trust judgments corroborate; repeating the memory should increase agreement without increasing evidence; contact with a frame whose closure differs should move trust where more repetition of the memory does not.

**The shape we are looking for** (bound in advance): a constraint on what any answer must look like, namely which of these quantities the memory can occupy (prior, anchor, convention, method, or recording), and what would have to be present for either reasoning or trust to be corrected. If the figures cannot place the memory in that list, the verdict is `gap`, not a silence.

**What an answer would not be:** a measured effect size, a named psychological mechanism, a claim that all conflict memory is harmful, or a recommendation to forget.

## 1. Domain census

Done before choosing any figure line. The Symbols table defines a *frame* as "any bounded system with a library: an agent, a person, a discipline, a model", and a *seat* as a checking position. A domain needs actors, a currency, and a nameable anchor. Where no anchor is nameable, it is not yet a domain.

### R by arity, symmetry, scale

- **Arity:** at least three conditions are bundled: transmission across people and generations; an inference in a present frame; a stance toward another frame or institution. The question does not say "the memory effect" in the singular, and the world literature itself splits into antecedents, contents, institutional transmission, and present-day correlates (Figueiredo et al., 2017/2018). This is a **union compound**, not one hard question.
- **Symmetry:** the relations are ordered. Transmission is stronger from an in-group demonstrator than an out-group one (Debiec and Olsson, 2017); comparison ⋛ is "a threshold relation between two quantities" and is not symmetric (Fig 12 :85-89). A memory is not swapped with the present as though the two were interchangeable operands.
- **Scale:** the memory crosses a membrane, from population to person and from one generation to the next (Fig 4 :19-25). The kernel, the loop and the rule for naming what worked, stays the same; only actors, currency, and anchor change.

### Partition or union

**Union, not partition.** Fig 9 :4-5: "Disagreements that do not shrink with effort, where each rule keeps working well on a different subset, are not one hard question but several well-formed ones. Split it rather than search." Fig 9 :57: "a case in two conditions is not a harder case of either". Fig 9 :54: "And when the split lands on a union rather than a partition, unbundle before you search again." Each condition below gets its own loop and its own verdict. They are never averaged.

### One line per domain: actors / currency / anchor

| domain | actors | currency | anchor | question type |
|---|---|---|---|---|
| **D1 Belief inheritance** | individual frames as group members; inherited prior `w`; belief `b` (Symbols :19-26) | belief weight and residual `R` | the ground for whatever the belief is about | can a belief be inherited and still be corrected? The memory itself is not an anchor (F1). |
| **D2 Present-day reasoning** | the recalling frame; present actors and events | evidence, comparison ⋛, and the frame's closure | the ground, separately for each frame | which quantity does the memory occupy in the inference: prior, anchor, or term? |
| **D3 Trust between frames** | in-group frames, out-group frames, institutions | agreement and independence (Fig 2 :31-32) | the ground, never the agreement (Fig 2 :35) | is trust a verdict about another frame's ranging, or just the pool talking? |
| **D4 Intergenerational and displacement carry** | a population, a generation, a displaced group, the new habitat's actors | methods versus recordings (Fig 4 :22-25); contact (Fig 11 :39-40) | the ground, reached through a channel that decays (Fig 10 :24) | what crosses the membrane, and is displacement a removal or a substitution? |

D1 to D4 all have nameable anchors, so all four are domains. A proposed fifth domain, "the collective mind as a remembering subject", is **rejected at census**: no anchor is nameable for it, and the world literature explicitly declines the strong reading of a group mind (Figueiredo et al., quoting Wertsch: "some sort of collective mind or consciousness"; Orianne and Eustache, 2023: "Collective memory is not the memory of a collective, but that of its individual members"). If someone insists on that domain, the figures have no line for it and it would be a `gap`; the honest census drops it rather than forcing a figure to fit.

### Dependency order (Fig 3)

Fig 3 :20-21: "The chain is ordered by dependency, not by importance. Each link consumes what the one above produces." Fig 3 :22: "A step whose input never arrives cannot be diagnosed, only its predecessor can."

1. **Enumerate the habitat** (Fig 11 :43-48) before naming actors: who is in contact with the residual, including second-order contacts. Displacement makes this step non-optional.
2. **Describe the residual in effect terms** (Fig 9 :27-28) before choosing a frame. "describe it before you go looking, or any frame you pick will seem to fit."
3. **Check the anchor** (Fig 2 :29, :33) before judging reasoning or trust. An anchor that updates is not an anchor.
4. **Then** judge D2 (reasoning) and D3 (trust). D4 governs what can be carried between 1 and 4.

Trust is not a free-floating attitude in this order. It is the downstream result of whether frames can still range separately against an anchor. Optimising a trust intervention before the anchor question is settled is effort above the break (Fig 3 :19: "Optimising a link that already works cannot rescue one that does not.").

## 3. Findings F1 to F10

### F1: A collective memory is a belief and a channel, not an anchor (decisive for D1)

Fig 2 :29: "An anchor is whatever settles the question and does not change its answer because of what any frame thinks."
Fig 10 :24: "the ground does not decay, the channel does"

A collective memory of a conflict changes with the present social context. Rimé et al. (2015/2016), studying three generations in Belgium, concluded: "the current social context has decisive consequences for collective remembrances, which, in turn, impact intergroup relations as well as political attitudes and choices." Figueiredo et al. report the same constructive and flexible notion: the same past event is framed differently by different political actors, so remembering "cannot be conceived of as an objective recollection of historical events". A thing that changes with what frames think fails the anchor test at Fig 2 :29. It is therefore a belief held in individual systems (Symbols :19-20: "Formed from its own history and from what it inherited, mixed by w") and a channel that can go stale (Fig 10 :24).

**What this licenses:** the structural claim that an inherited memory occupies the *prior* slot, not the *ground* slot. It does **not** license calling the memory false. A prior can be true and still be a bad anchor.

**Refuter:** show a case where the shared memory does not move with present context and where frames are separately corrected by it rather than adjusting it, satisfying Fig 2 :29 and :33 ("The anchor must not update."). If that holds for the memory itself and not for an external record it points at, F1 is refuted.

### F2: The effect is a shared evidence pool, so agreement is not corroboration (decisive for D3)

Fig 2 :40: "agreement about the world is worthless when the agreeing frames share an evidence pool"
Fig 2 :35: "Alignment is triangulation, not negotiation. A mirror cannot correct you."
Fig 2 :19: "they never talk, and still agree"

People who inherit the same conflict narrative are not two witnesses. They are two frames drawing on one evidence pool. Fig 2 :31-32 defines independence as how little frames draw on the same evidence, and says it is what makes agreement mean something. So a population's uniform mistrust after a remembered conflict is not evidence that the mistrust is correct; it is the predicted shape of correlated frames.

Fig 2 :39-41 adds the crucial split. "Correlation has valence." Fig 2 :40 disqualifies shared evidence "for a verdict"; Fig 2 :41 says it is "efficient for a convention: agreement about a shared meaning is the product, not a corruption of it". This resolves the apparently conflicting findings in Li et al. (2023), who report "both adaptive and maladaptive consequences" of historical trauma. For a question constitutively about group identity ("what does this group stand for?"), the shared memory is a convention and is load-bearing; Fig 2 :36: "An anchor is legitimate when the question is constitutively about it." For a question about the world ("is this out-group member trustworthy?"), the same memory is a shared pool and is disqualifying. Same memory, different valence, different question type. This is a falsifiable prediction, not a rhetorical distinction.

**Refuter:** show two groups with demonstrably high inherited narrative overlap whose trust judgments are independently corrected by a separate anchor, with low residual after that correction. Then Fig 2 :40 does not apply and the agreement is corroboration.

### F3: Memory supplies terms, so reasoning is biased at the level of what counts as evidence (D2)

Fig 12 :111: "A vocabulary without bonds can name a state and cannot name a route to one."
Fig 12 :112: "A plan is a sequence. A goal is a comparison. Progress is a subtraction. A refutation is a negation, and that one is not a bond."
Fig 9 :27-28: "describe it before you go looking, or any frame you pick will seem to fit"

A remembered conflict is a record of a state (what happened), not a route (what would count as progress now). Fig 12 :111 says a vocabulary that holds only the record cannot write the route. When the memory is used as though it were a route, the frame reads the present under a pre-fixed comparison: the current actor is sorted as the old actor. Paez and Liu (2009) state this in the field's own words: collective memory of past conflict "plays a cognitive-perceptual role by shaping the perception of interest, threat and others intentions", and "makes the current situation appear as a repetition of previous violent conflicts". The 9/11 commemoration experiments reported by Figueiredo et al. are the cleanest instance: participants who engaged with commemoration "reported significantly more suspicion towards the Iranian nuclear deal in the present day and misattributed responsibility to Iran for this terrorist attack", although Iran was not involved.

This is a *shape* claim: the mechanism is a pre-fixed comparison with no independent bracket, not a particular bias. It does not say that every inference from a memory is wrong. Fig 9 :28 explains why any present actor can be made to fit once the frame is chosen first.

**Refuter:** show a case where the memory changes only the factual premise of an inference (Option A) and leaves the frame's comparison, its evidence rule, and its anchor unchanged, with the residual fully explained by content. Then F3 collapses into the content reading.

### F4: Trust is a comparison that must reach an anchor, not an echo of the memory (D3)

Fig 12 :85-89: the bond ⋛ is "a threshold relation between two quantities" and is ordered.
Fig 2 :45: "Frames range against the ground. They do not negotiate with it."
Fig 8 :50: "Two frames can hold the same atom by convergence, reaching it separately, which is corroboration at maximum independence."

Trust is a threshold judgment about another frame: does its behavior cross what I require? Under Fig 12 :112, "A goal is a comparison", so the vocabulary must contain ⋛ to state a trust goal at all. But a comparison whose operands are both supplied by the shared memory is a closed comparison. Fig 2 :45 requires frames to range against the ground separately. The positive result in Figueiredo et al. fits exactly: when "a relevant, rival out-group member ... acknowledges the past suffering of the in-group, this acknowledgment can lead to higher levels of trust towards the whole out-group." Acknowledgment is an atom crossing from a frame whose closure differs. It is an import (Fig 6 :23: "No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs."), not a change in the in-group's memory. Fig 8 :50 distinguishes that from mere agreement: convergence from separate ranging is corroboration at maximum independence; inherited agreement is not.

**Refuter:** show trust increasing from within the same closure with no new atom crossing, no out-group signal, and no change in the anchor, and show that the increase survives an independence test. Then Fig 6 :23 does not govern this quantity.

### F5: What crosses generations is usually a recording, not a method (D4)

Fig 4 :22: "Only methods cross up. Only head starts come down."
Fig 4 :25: "A recording carried upward looks like knowledge and is a description of one occasion."
Fig 4 :12: a head start "makes the next agent's search cheaper"
Fig 7 :13: "agreement compounds, evidence does not"

A conflict narrative passed from grandparents to grandchildren is a description of one occasion carried downward. Fig 4 :25 says such a recording "looks like knowledge", which is precisely why it is not detectably a loss in the telling. Replayed downward, the figure continues, "it produces a system that repeats a past success" (Fig 4 :25) and cannot produce a new one. Li et al. and Figueiredo et al. document the transmission channels (family conversation, textbooks, media, commemoration); Cordonnier (2026) finds that family war memories serve "directive functions, providing guidance for future behaviour", especially at the collective level. A directive function is a *route* claim made from a *state* record, which is the exact mismatch Fig 12 :111 names.

Fig 7 :13 supplies the intergenerational prediction: in a chain of rooms sharing a closure, "agreement compounds, evidence does not". More generations retelling the memory produce more uniformity, not more contact with the ground.

**Refuter:** show a transmitted memory that makes the next generation's search cheaper in the figure's sense (Fig 4 :28), that is, demonstrably increases its ability to discriminate present actors and to revise when the ground disagrees, rather than only increasing agreement. Then F5 is narrowed.

### F6: Displacement is habitat substitution, not removal (D4)

Fig 11 :39: "capability is a property of agent-and-habitat, never of the agent alone."
Fig 11 :40: "An improvement that does not change contact changes nothing, however much it improves."
Fig 11 :67: "Move the residual and you must reproduce everything its goal required, and you inherit the new habitat's actors, which you did not choose."

Displacement moves a residual into a substituted habitat. Fig 11 :66: "Isolation is not removal of the habitat. It is substitution of one habitat for another." The two silent failure modes are named at Fig 11 :68-69: what you failed to reproduce, and what you unintentionally introduced. Both are invisible until the goal fails. So a policy that moves a population but leaves the memory intact has not kept the habitat constant; it has changed the actors and kept the recording. Fig 11 :40 says the improvement that does not change contact changes nothing. The animal literature gives this an independent mechanism: social fear learning depends on relatedness, familiarity, and group belonging, with fear information "more efficiently transmitted between individuals belonging to the same racial/ethnic (in-group) as compared to a different (out-group)" (Debiec and Olsson, 2017), while social buffering, immunization, and vicarious extinction show that a conspecific's presence can also block or reverse acquisition.

**Refuter:** show a displaced group whose contact with the relevant ground is unchanged after the move (actors, conditions, and relations reproduced) and whose reasoning and trust are unchanged. Then Fig 11 :67 does not govern this case.

### F7: The label "collective memory effect" is not yet a mint (method check)

Fig 5 :19-25: three guards, "is there anything to explain?", "can we even build this term?", "is it actually new?", all of which must pass.
Fig 5 :33: "The three guards are a product, not a checklist."
Fig 13 :134: "Unreachable is a verdict here, not a silence"

The question asks "how", which invites a new causal term. The figures do not hand one over. SUPPORT is present (a residual exists: present reasoning and trust do not follow from present evidence alone). REACHABILITY is present only if the effect is built from held atoms (prior, closure, comparison, import, habitat). NOVELTY fails: "inherited prior", "shared pool", and "recording not method" are already in Γ. So no new term should be minted. What is owed is a binding of the field's observations onto held atoms, with the binding provenanced as a binding (Fig 8 :51-52: "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them.").

**Refuter:** produce a case that requires a seventh primitive or a new operator to describe, with the existing atoms shown insufficient. Then a mint is owed and this finding is withdrawn.

### F8: Per-group verdicts, never a population average

Fig 1 :19: "The residual is indexed by object slot, not aggregated."
Fig 1 :22: "Aggregating across slots is how a live signal disappears into an average."

The world literature is explicit that groups hold different memories: Halbwachs's publisher summary says "various groups of people have different collective memories, which in turn give rise to different modes of behavior"; Figueiredo et al. define collective memory as a shared set of representations "based on a common identity to a group", so out-group members need not share it. A single "effect of collective memory on trust" number would aggregate across slots and throw away the only signal that says where to intervene. Verdicts are therefore kept per domain and per group, and never averaged into one population effect.

**Refuter:** show that the same mechanism, with the same residual sign and the same anchor relation, governs all groups in the population, so that per-slot reporting adds no information. This is unlikely a priori but is testable.

### F9: The framework returns a shape, not a named mechanism

Fig 9 :32: "you get a kind of thing, never the answer itself"
Fig 13 :138: "you get a kind of thing, never the answer itself" (the same limit restated at the stop)
Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

The answers above constrain the *kind* of thing an explanation must be: a prior, a shared pool, a recording, a comparison needing a separate anchor, and a habitat contact. The framework does not name a specific neural, social, or institutional mechanism as *the* cause, and does not select among trauma narratives, commemoration, schooling, or the media as the operative carrier. Selecting one is a binding from the world frame, provenanced as such.

**Refuter:** produce a figure line that selects a specific carrier or mechanism, or show that the six-term set plus the operators genuinely derives one. None was found in a full reading of `03-FIGURES_TEXT.md` this session.

### F10: "Memory distorts reasoning" is a refusal, not a mint (negative result)

Fig 5 :50-56: the fifth kind of gap is "refuted: a term we hold is wrong; a term is owed that says so", and "What it removes is not a term but a term's standing to be composed over."
Operators table :58: "a refutation is a negation, which is why a vocabulary without it can only accumulate"

Option A's stronger form, that the memory is simply information that conditions judgment, is not just incomplete; it is refused as an *anchor* by F1 and as *corroboration* by F2. The refusal adds a term to the record (a refusal of the anchor standing) and lowers the reach, per Fig 6 :42-43: "What is recorded only grows. What is reachable is derived, and it can fall." The content reading is not erased; it loses its standing to be composed over as a verdict. This is the correct figure move when the residual's content is that a regularity held is false, and it is why ¬ is needed (Formula step 2: refuse before mint).

**Refuter:** show that Option A, with no structural addition, predicts the observed dependence on frame independence and on out-group acknowledgment. Then the refusal is withdrawn.

## 4. Strain test and re-census

Two apparent strains were found. Both were resolved by re-census, not by softening a reading.

1. **"The anchor must not update" versus a memory that changes with context.** If collective memory were an anchor, Rimé et al.'s result that "the current social context has decisive consequences for collective remembrances" would conflict with Fig 2 :33. Re-census: the memory is a belief/channel (D1), not an anchor. The ground for the question about the past event is an external record or measurement, not the shared remembrance. No strain remains.
2. **"All agreement from a shared pool is worthless" versus the adaptive functions reported by Li et al.** Re-census: Fig 2 :39-41 makes valence depend on question type. For a convention question the shared memory is the product; for a world verdict it is a corruption. Different quantities, no strain.

A third item was checked and is **not** a strain: the finding that collective memory is "held within individuals" (Orianne and Eustache, quoting Roediger) does not contradict treating it as population-level pool. A pool is a relation between individual frames, not a group mind. The census rejected the group-mind domain for the same reason.

After re-census: **no live strain**. One item is explicitly left open, not smoothed: the operand type of ⋛ in a trust judgment at the population scale. Fig 12 :87 defines it as a threshold relation between "two quantities"; when the operands are collective representations held by frames, whether they count as quantities at that level needs an instrument, not an argument. Named, not hidden.

## 6. Pre-registered refuter

Written before the conclusion, per Seat Map :287: "a falsifier written before the run is a design instrument, not only an honesty device." The shape claim is refuted if any of the following holds:

1. **Anchor test fires.** A collective memory of conflict is shown to satisfy Fig 2 :29 and :33: it does not move with present context and frames are separately corrected by it. (Rimé et al.'s result would currently fire this against the anchor reading.)
2. **Independence test fires.** Two groups with the same inherited narrative are shown to be low-overlap frames by Fig 2 :31-32, so their agreement is corroboration rather than the pool talking.
3. **Contact test fires.** Repeating the memory across generations is shown to change contact with the ground in the sense of Fig 11 :40, increasing discrimination of present actors rather than only agreement.
4. **Content test fires.** The entire reasoning and trust effect is captured by the memory's factual content, with no residual left for frame closure, shared evidence, or import.
5. **Bond test fires.** Trust is shown not to be an ordered threshold comparison, or ⋛'s operands at this scale are shown to be ill-typed in a way that breaks F4.

If any fires, the affected domain verdict is withdrawn, not reworded. Until one is run, no part of this may be labelled `grounded`.

## 7. Recommendation

1. Lead with the union split (§1) and the per-domain verdicts (§5). Do not send a single "effect of collective memory" claim.
2. State the mode on every substantive claim. `specified` for the structural predictions, `general` for the shape, never `grounded`.
3. Send the refuter before the theory (§6). Ask what would count as a failure. Record the verdict before showing any framework material.
4. For interventions, target frame independence and contact with a separate anchor (F2, F4, F6), not the amount of memory content. The figures predict that adding more of the same memory increases agreement, not evidence (Fig 7 :13).
5. Keep the positive convention use (Fig 2 :41) beside the verdict use. Shared memory is legitimate for identity questions; the framework's own rule requires saying which question is being asked.
6. Provenance every binding from the world frame to a held atom (Fig 8 :51-52). Do not present a figure-derived shape as if it were a finding of the memory literature, or a finding of the memory literature as if it were derived from the figures.
