## VERDICT (from the figures)

The binary question is refused as posed. The figures return a shape: the question is a union of overlapping conditions that must be unbundled; the anchor is the measured return of target state and function, not the habitat's appearance and not agreement; a return to the same reading has a non-invertible round trip whose gap must be measured; restoration is an import and the seat's power is asymmetric, so a managed system is permanent work and an unenumerated cascade is a hazard; a crossed state held by a feedback is a cycle that a chain cannot close; and same species list does not mean same system. Irreversibility is a reachability verdict under what is held, not an absolute property of the world. Which particular ecosystem is restorable is `gap` from the figures and is settled by measurement. This is a `specified`, ungrounded, candidate result. The strongest single figure-grounded point is Fig 11 :63, because the habitat figure is the one figure written explicitly about ecosystems.

- **cost if wrong:** bounded but real in both directions. If a restorable system is called irretrievable, a recoverable system is abandoned. If an irretrievable system is called restorable, budget is spent on repeated interventions and new actors with unenumerated cascades (Fig 11 :65, :69). The framework limits the cost by keeping every cut ranked and reversible (Fig 9 :41 "so keep every cut ranked and reversible") and by distinguishing the habitat from the ground, so an error is locatable in a measurement rather than hidden in a consensus.
- **undoable:** asymmetric. The decision to intervene is undoable in the record, because cuts are kept ranked and reversible (Fig 9 :41). The ecological intervention is not simply undone: introduction is available and exclusion is not (Fig 11 :61), so an added actor cannot be recalled, only superseded, and a managed system stays work. A sent claim can be superseded by a corrected packet with no primitive withdrawn.
- **reversed by:** a ground reading, not agreement. A source-discriminating instrument showing a zero round-trip gap for a return would refute the non-invertibility finding for that case. Disjoint conditions with empty intersections would refute the union finding. Coincident crossing and return points would refute the ordered-threshold reading. A restoration that expands the reachable set without importing an atom, or a cleanly subtracted introduced actor, would refute the asymmetry finding. A persistent state with no re-entrant loop would refute the cycle finding. Prestige or agreement is not such an instrument (Fig 2 :35). Until one fires, the verdict stands as `candidate`.
