## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 says it can report that a term is out of reach "with the library as it stands" but "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*: "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the form of an answer you can state before you can name its content. It constrains; it does not fill. For this question, the shape is the *measure shape*: any admissible complexity report must keep at least two currencies separate, keep readings per slot, treat two readings as two measures only at independence, and range each against a ground. The shape does **not** name which four measures every system must use.

A scalar such as `C = a bits + b actions` is a name with no shape: it asserts a quantity before it has been checked against the constraints.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :31: "your words are borrowed too, so describe the effect rather than the cause."
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- For this question, the effect description is the four refuters in `08_expert_verification_packet.md`, not the word "complexity." Each refuter says what you would expect to see if the multi-axis shape were false.

## 3. What licenses a name

Two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays." The README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51), with a source gate and a shadow test.

*They're Scanning Books* sharpens both. "The real import is not a new term in the existing space. It is a new dimension of the space." And: "Declaring the primitives does not make them neutral. It makes the choice visible." The six-term minimum set is "a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."

That is the crucial correction for this question. The figures license a *closed set of primitive kinds* for any system that composes anything, but they do not license the claim that this set is nature's own list of complexity variables. Declaring the axes makes the choice visible; it does not make them neutral. So the per-system binding must be provenanced as a choice and left open.

## 4. Why a single number is the specific forbidden error

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and "cannot comment on the source": one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. "If several paths create the same behavior, then behavior is a projection with lossy information." "An instrument that can't distinguish these cases demonstrates its own inadequacy." It was the spectrometer, not an argument, that resolved it.

A complexity scalar is exactly a reading that cannot comment on its source. Two systems with the same score can have the same bits/actions/arrangement projection from very different sources. What is owed is a source-discriminating instrument, not a better argument about which scalar to prefer.

*The Recursive Self-Improvement Trap*: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." A complexity measure produced by the frame it measures cannot validate itself.

## 5. Q: what licenses a particular set of complexity measures for a system? ANSWERED at shape level, open at name level

**What the figures license:** a closed set of primitive kinds, a requirement that composition cross kinds, a two-currency price, per-slot residuals, and an independence criterion for treating two readings as two measures. These are `general` and checkable.

**What the figures do not license:** a universal index, a fixed list of measures for all systems, or the placement of entropy, Kolmogorov complexity, Φ or any other named measure into a slot. Those require a ground reading or a provenanced import with a shadow test. Until one exists, the binding is the searcher's own contribution and must be recorded as such.

**Does the record commit the error the README forbids?** It would if it named one scalar as *the* definition of complexity. This folder does not. It returns the measure shape and declares a `gap` for the universal index.

## 5b. Correction to my own §3 and §4

I initially wrote "shape, not a name" as if it forbade naming any measure at all. The README's phrase is "what a **missing** thing would have to look like (a shape, not a name)." It governs a primitive not held in Γ. Entropy, description length and variety are already held in the scientific library; naming one as a candidate axis is a **binding from a world frame**, not the invention of a new primitive. What remains wrong is claiming that the binding is derived by the framework, or that it moves the wall (Fig 6: "IMPORT adds an atom" - this one adds none when the atom is already held). Both claims are now recorded so neither is quietly lost.

My §4 metamerism point is **not** retracted: the scalar still names the source of a reading without an instrument that discriminates among sources. The reason is the missing discriminator, not a ban on naming held measures.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

A campaign that gathers famous complexity researchers to agree with the measure shape is the named collapse, not corroboration. The legitimate ask is the opposite: give the shape a budget to be tried by someone in a different closure, and let the ground decide.

**This audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output with the formula... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01` is a simulated derivation, checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.
