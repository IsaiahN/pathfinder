## 1. The claim, in one paragraph

The question bundles three conditions with different answers. Source weights can be learned from outcomes. But the weight is not the bias removed: when sources share an evidence pool, their agreement is the pool talking, so trust cannot be settled by consensus. To avoid inheriting bias, a system must range each source separately against a ground that does not update, buy independence in proportion to the cost of being wrong, record provenance so convergence can be told from adopted import, and carry a negation operator so a frame can be refused rather than only downweighted. There is no permanent trusted-source list, because a source's trust is relative to the residual. The system cannot certify from inside that it has zero inherited bias; that is an underivability limit, and the way past it is a discriminating instrument or outside frame.
