## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :135: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*, read 2026-11-22: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is a narrowed form of an answer you can state before you can name it. For this question, the shape is: *two frames, two legitimate anchors, two habitat relations, one shared loop, and a difference in residual direction that must be bound to be checked.* The concrete evidence list for a given domain is not the shape; it is the habitat enumeration.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary already held that is *closest* to the thing, then recurse. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*, read 2026-11-22: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."* This is the reason the outreach email carries an effect description and a refuter, not a definition.
- *Library of Babel* on stopping: *"You will know that you are done because the finish line will also be the starting place"*, and the paradox is that by then you have *"composed the answer through the process of locating it."*

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* The README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51), with a source gate and a shadow test.

*Decoding Tacit Knowledge* sharpens this in a way directly relevant to local expertise: *"we can know more than we can tell"* (Polanyi, The Tacit Dimension, 1966, as quoted there), and *"A highly compressed message only unpacks for someone with the right history. That history is on the speaker's side, built from years of hands-on experience with the problem."* Writing carries context and subtext but almost never pretext, the "you had to be there" part. So the transmission failure between expert and novice, or between frames, is a lossy-channel failure, not proof that one frame lacks knowledge.

Naming a specific local practice as *the* evidence for all local expertise would be a name where the framework returns a shape. It would also be a metamerism error (section 4).

## 4. Source, not reading: why a name from a projection is refused

*The Hard Problem is About Source*, read 2026-11-22, gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"*. One green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered can give the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

Applied here: a community's stated preference or an instrument's reading does not by itself identify which anchor is doing the settling. Several different sources can give the same observed compliance. What is owed is a source-discriminating observation, not a name. This is why F1 is `specified` and why the refuter asks for an instrument that discriminates the axes.

## 5. Q: Does "shape, not a name" forbid describing the difference at all?

**No.** The README's phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* Both expert frames are already held as frames; neither is a missing primitive. Describing the constraint on their difference is a shape statement, which is exactly what the framework permits. What is forbidden is naming the specific missing evidence protocol for a specific domain as if it had been derived.

**Correction to an earlier over-reading (kept visible).** An early draft of this section applied the "shape, not a name" rule to the words *local* and *scientific* themselves and concluded the framework could say nothing about the difference. That was wrong: the rule governs a missing primitive, not a relation between two held frames. The draft also tried to call the two frames *isomers*; see `06_isomers_and_order.md` for the downgrade to a functional-group analogue. Both the over-reading and its correction are recorded so neither is silently lost.

## 6. Direction: the question each frame asks is exactly the invisible preference

Fig 5 :62-63: *"A frame searching for an answer of a particular shape holds that shape as a PREFERENCE rather than as a term. It is not bound, it predicts nothing, and it accrues no residual, so nothing here can see it."*

*Decoding Tacit Knowledge* restates the discipline in plain language: *"a frame holds its preferred answer 'as a PREFERENCE rather than as a term', so 'nothing here can see it'."* So when the question asks how the two kinds of expertise differ in the questions they ask, the honest answer is: **they differ in the direction of the residual, and that direction must be written down as an ordinary term before it can be checked.** This is not an extra philosophical comment; it is the method used in `01` section 0 and in `08`.

## 7. Consequences for the answer and for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*, read 2026-11-22: *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous experts who agree with the shape is the named collapse, not corroboration. The legitimate ask gives the claim a budget to be tried and lets a ground settle it.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too (intelligence is essentially arrangement). However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* So `01`, `06`, `07`, `09` and `11` are simulated derivations checked for internal consistency against the figures. They are not tests of the claim and must be labelled as such. They cannot settle COG-0039.

**A shared pool is not two witnesses.** *Decoding Tacit Knowledge* on drift: two people who only check against each other drift together, and neither notices. *"Shared pretext is good for one thing and ruins another. Agreement is the whole point when you're settling what words mean. It's worthless for settling what's true when both sides learned from the same sources"* (Fig 2 :40). This is also why the world sources in `09` are grouped by evidence pool.
