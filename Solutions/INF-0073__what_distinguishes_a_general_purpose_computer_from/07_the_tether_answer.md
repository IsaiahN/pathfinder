# The Tether's answer on general-purpose computation versus interpretation-only imitation

**Mode: `general` on the structural separator, `specified` on the per-domain verdicts, not `grounded`.** This is a shape and a route, not a result. Simulated derivation checked against the figures (`05_what_shape_means.md` section 6), not a ground reading.

## 1. The residual it answers

The question asks for a separator, not for a list of devices. Option A (interpretation suffices) makes computation a mapping any open system satisfies, so "general-purpose computer" has no discriminating power. Option B (generated and ground-settled) keeps a narrow, checkable class. The effect is per system-slot (Fig 1 :19: "The residual is indexed by object slot, not aggregated.") and the two conditions have different anchors, so this is a **union compound**, not one hard problem (Fig 9 :57: "A case in two conditions is not a harder case of either").

## 2. The shape

1. **Universality: a closed set with unbounded arrangements.** Fig 13 :115: "The set is closed. The arrangements are not. That gap is why import exists." A general-purpose computer holds a finite instruction set and an unbounded space of programs over it, with the program stored as data so the same hardware generates many functions. An interpretation-only imitation has a fixed arrangement; its variety is in the observer's description. Fig 12 :111: "A vocabulary without bonds can name a state and cannot name a route to one." A lookup table names states; a program names a route. Over the same alphabet they are Fig 12 :117 isomers: "Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."

2. **Generator, not recording.** Fig 4 :22: "Only methods cross up. Only head starts come down." Fig 4 :25: "A recording carried upward looks like knowledge and is a description of one occasion." The general-purpose machine keeps the kernel and varies the program, so the method is reapplicable. The interpreted system plays back one trace under one description. Chalmers 1996 names the defect: the weak mapping ensures only that a particular trace is reflected, not the structure of the automaton.

3. **The anchor must not move with the interpretation.** Fig 2 :29: "An anchor is whatever settles the question and does not change its answer because of what any frame thinks." If the verdict flips when the observer changes the mapping, the mapping is doing the settling and is a frame, not a ground. A chosen interpretation is an adopted import with no source gate or shadow test (Fig 6 :12, :13; Fig 8 :51: "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them, and the surplus lives only where the closures differ.").

4. **Capability is machine and habitat, not machine alone.** Fig 11 :39: "So the answerable question is not what intelligence is, but what makes a system capable. And capability is a property of agent-and-habitat, never of the agent alone." Fig 11 :70: "A test harness is a substituted habitat. Which is why a synthetic solve proves wiring and never capability." An interpreted rock has no internal program channel, clock or memory; the interpreter supplies them from outside. That is substitution, not the system's own reach.

5. **The bond type differs.** The observer's mapping is an identity, "two names, one referent" (Operators :25), symmetric and route-free. The machine's transition is a sequence, "A then B; B needs A to have happened" (Fig 12 :71), ordered. They are not the same relation, so interpretation cannot borrow the standing of generation by degree.

6. **"Everything computes" is refused, not re-explained.** Formula step 2: "REFUTED a term held is false; what is owed is a refusal, not an explanation." Operators :58: "a refutation is a negation, which is why a vocabulary without it can only accumulate." The mapping's residual persists and does not trend down: it fits every system equally well and predicts nothing.

7. **No universal classifier is returned.** Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134: "Unreachable is a verdict here, not a silence." What is owed is a source-discriminating instrument for the implementation relation, not another checklist. Correction kept visible in `05`: "shape, not a name" governs a missing primitive, so naming the properties is a binding onto held loop and ground properties; what stays unnamed is which physical systems compute.

8. **Two currencies, not one.** Fig 12 :125: "A composition costs in two currencies, and they do not add." A short program is cheap to state and expensive to settle; a giant lookup table is expensive to state and cheap to settle. "Use filters for the budget and witnesses for the verdict. Never let a filter hand you a verdict" (Fig 9 :60).

## 3. What it explicitly does not say

- Not a decision procedure that labels an arbitrary physical system a general-purpose computer. That is the declared gap.
- Not that a system which fails a task is not computing. Failure is a residual, not a refusal.
- Not that only silicon computes. The separator is substrate-neutral; an ASIC is customized and not reprogrammable, an FPGA is programmable, and neither verdict depends on the material.
- Not that a lookup table is not a computation of a kind. It is a computation of one occasion, and it fails the two-condition separator, not the word "compute" in every sense.
- Not that a fixed arrangement cannot be clever. It can be very clever on its listed cases. The claim is about reach, not about performance on a benchmark.
- Not grounded. No measurement of a physical system was taken, and the stage-1 claim is a candidate.

## 4. What would settle it — the ground

An observer-independent instrument, not a further argument. In *The Hard Problem is About Source*, an instrument that reads green "cannot comment on the source"; the spectrometer resolved it. Here the corresponding questions are:

- **Counterfactual-input test.** Does the system produce the correct output for an input it was never mapped to, with no interpreter changing the mapping? This is Chalmers's strong conditional and Fig 4 :25's one-occasion failure test.
- **Program-as-data test.** Is the description of the computation an operand inside the system's closure, so that changing it changes the function without changing the hardware (Fig 13 :115)?
- **Anchor test.** Does the verdict stay fixed under two different observer descriptions (Fig 2 :29)? If it moves, the description is the frame.
- **Provenance test.** Can the system's own record distinguish convergent derivation from an adopted mapping (Fig 8 :51)?
- **Standing falsifiers:** the five conditions in `01` section 4 and `08` section 3, written before this conclusion.

## 5. The honest stop

**Unreached, not unreachable in principle.** The separator is a shape. *They're Scanning Books*: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six." Declaring the conditions makes the choice visible, not neutral. The answer stops at the limit of the available instruments and records the lineage so the stop is checkable. "The recursion converges toward indiscernibility, and indiscernibility is not identity" (*How Intelligence Actually Works*). A CPU and a rock-with-a-mapping may be indiscernible at the level of a single trace; they are not therefore identical, and the record is what keeps that checkable.

## 6. One-paragraph version for outreach

> The figures do not name a device and do not claim a decision procedure. They return a shape. A general-purpose computer is a generator: a fixed, finite instruction set over an unbounded space of programs, with the program stored as data so the same kernel yields new functions. Its outputs settle against a ground that does not move when an observer changes the description. A system that imitates a computation only under a chosen interpretation has a fixed arrangement, a trace rather than a structure, a symmetric identity mapping where a route is needed, a lookup table where a program is needed, and a habitat supplied by the interpreter. It proves wiring, not capability. The two conditions are a union with different anchors, so their verdicts are kept separate. Over the same alphabet, a program and a lookup table are isomers: same atoms, different bond, different substance. What is not returned is a test that labels an arbitrary physical system. That is a declared gap, and the missing thing is a source-discriminating instrument for the implementation relation, not another checklist. The falsifiers were written before this paragraph.
