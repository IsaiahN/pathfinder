# Expert verification packet — the Tether on general-purpose computation

**What this is:** a claim in a form a theoretical computer scientist, philosopher of computation or cognitive scientist can check. Mode, derivation and refuters are stated before the conclusion so a reader knows what to look for and what would settle it.

**Mode: `general` on the shape, `specified` on the per-domain verdicts, not `grounded`.** No measurement of a physical system is claimed. This is a simulated derivation checked for internal consistency against the figures, not a ground reading. It cannot settle the question it reports on.

## 1. The claim, in one paragraph

The question is a union of two conditions with different anchors, not one property. A general-purpose computer (1) is a generator over a closed instruction set with an unbounded space of programs, with the program stored as data, and (2) produces outputs that settle against a ground that does not move when an observer changes the description. A system that imitates a computation only under a chosen interpretation has a fixed arrangement, a trace rather than a structure, a symmetric identity mapping where a route is needed, and a habitat substituted by the interpreter. Over the same alphabet, the program and the lookup table are isomers: same atoms, different bond, different substance. The framework returns this shape and refuses to name which physical systems compute; a source-discriminating instrument for the implementation relation is owed.

## 2. Three checkable sub-claims

### C1 — framework-internal; checkable by reading Figures 13 and 12
- **Statement:** universality is a closed primitive set with unbounded arrangements, and a route requires a bond that a flat table does not have.
- **Source, verbatim:** Fig 13 :115 "The set is closed. The arrangements are not. That gap is why import exists." Fig 12 :111 "A vocabulary without bonds can name a state and cannot name a route to one." Fig 12 :117 "Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."
- **What to check:** does a universal instruction set plus stored programs have the structure the figure describes, and does a lookup table over the same alphabet lack the route bond?
- **Refuter:** exhibit a fixed-arrangement system that reaches the universal closure without reading a program as data and without an imported mapping; or show that program and table are related by a behavior-preserving symmetry so the bond difference carries no consequence.

### C2 — the anchor condition; checkable by anyone who can run a system
- **Statement:** if the compute verdict flips when the observer changes the mapping, the mapping is the frame, not the ground. A chosen interpretation is an adopted import with no source gate or shadow test.
- **Source, verbatim:** Fig 2 :29 "An anchor is whatever settles the question and does not change its answer because of what any frame thinks." Fig 8 :51 "Convergent derivation and adopted import look identical in the contents. Only the record of where each came from separates them, and the surplus lives only where the closures differ." Fig 6 :12 "source gate: provenance." Fig 6 :13 "shadow test: explains a gap."
- **What to check:** apply two different reasonable state mappings to one system and one function. Does the verdict track the system or the mapping? If it tracks the mapping, no ground has been reached.
- **Refuter:** produce an observer-independent instrument that returns the same compute or not-compute verdict for one system and function under two different interpretations, and show the verdict tracks the system.

### C3 — the capability and trace condition; checkable against the implementation literature
- **Statement:** capability belongs to machine and habitat, and a single trace is not the structure of the automaton. A harness proves wiring, not capability.
- **Source, verbatim:** Fig 11 :39 "capability is a property of agent-and-habitat, never of the agent alone." Fig 11 :70 "A test harness is a substituted habitat. Which is why a synthetic solve proves wiring and never capability." Fig 4 :25 "A recording carried upward looks like knowledge and is a description of one occasion." Fig 5 :44 "A term that explains everything by saying nothing fails this, and so does a term that explains one occasion perfectly."
- **What to check:** does the traced-behavior account of implementation distinguish a universal machine from a clock plus dial under counterfactual input? Chalmers 1996 argues it does not, and this is the world-side version of the figure claim.
- **Refuter:** show a single fixed trace, with no program and no counterfactual variation, streaming a new correct output for every new input without an imported mapping.

## 3. The five failure conditions, written before the run

1. A fixed-arrangement system with no program-as-data kernel generates the full range of a universal machine's outputs across arbitrary inputs, with no interpreter importing the mapping.
2. A system whose causal structure does not mirror the automaton still settles every output against an independent ground across counterfactual inputs.
3. An observer-independent instrument returns the same compute or not-compute verdict for one system and function under two different interpretations.
4. Universality and ground settlement are one condition measured by one instrument, so the union collapses to a partition.
5. One scalar (bits alone or actions alone) decides the separator in both directions, breaking the two-currency rule of `01` F7.

If any fires, the shape claim is withdrawn. A failure is more useful than an endorsement.

## 4. What is explicitly not claimed

- Not a decision procedure for arbitrary physical systems. That is a declared `gap`, Fig 9 :32 "you get a kind of thing, never the answer itself" and Fig 13 :134 "Unreachable is a verdict here, not a silence."
- Not that a programmability test over a finite alphabet settles mind or consciousness. This packet is about computation, not mentality.
- Not that a system failing a task is not computing, or that lookup tables are not computations of one occasion.
- Not that only silicon computes. The separator is substrate-neutral.
- Not a claim that the observer's mapping is always wrong. It is often legitimate; what is refused is its standing as a ground for the verdict.
- Not `grounded`. Every claim is `general` or `specified` and a candidate.

## 6. What an expert can check in twenty minutes

1. Read Fig 13 :115, Fig 12 :111 and :117, Fig 2 :29, Fig 8 :51, Fig 11 :39 and :70. Seven short passages.
2. Check C1 against what a universal machine actually does with stored programs and what a lookup table actually contains.

4. Check the clock-plus-dial construction in Chalmers 1996 against C3: does it produce structure or only a trace?
