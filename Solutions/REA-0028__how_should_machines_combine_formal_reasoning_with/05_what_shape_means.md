## 1. A shape is a constraint, not a filler

A shape is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. From the Library of Babel essay as quoted in the exemplar: *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For this question the shape is not an architecture. It is a set of constraints on any architecture that could survive the ground:

- two frames held independent, not blended;
- both ranged against one immovable ground, not against each other;
- the fast frame proposing terms as provenanced imports;
- the slow frame verifying what it did not produce;
- the coupling measured by a round trip;
- the sought-for form bound as a refutable term before the run.

"Neural plus symbolic" is a name. "Two independent frames coupled to one ground with a provenanced import path" is a shape.

## 2. How a shape is obtained

- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."* The residual was stated as a REACHABILITY failure and a source problem, not as "the system lacks a symbolic layer."
- Fig 8 :53: *"Residual first, frame second."* The frame census came before any architecture was named. Naming "neuro-symbolic" first would make any residual seem to fit (Fig 9 :28: *"any frame you pick will seem to fit"*).
- *Decoding Tacit Knowledge*: *"When contact isn’t possible, the best you can send is a plain description of what you’d expect to see, because anyone can check that against the world."* This is why the shape is stated as checkable effects, the five refuters, rather than as design principles anyone can endorse.
- Fig 4 :31: *"The gap is not an error to eliminate. It is the measurement of what the coarser description cannot hold"* — the one-paragraph version in `07` is deliberately lossy and is labelled as such.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"SETTLE — the ground settles it. Verified only by what pays. A gate is not the ground."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50), with a source gate and a shadow test, debited against independence (Fig 6 :24).

*The Hard Problem is About Source*: an instrument that detects green *"cannot comment on the source."* Several paths can produce the same reading, so *"If several paths create the same behavior, then behavior is a projection with lossy information."* It was *"proven wrong not by argument, but by the arrival of a better instrument."* For this question the corresponding claim is: a fluent, context-sensitive answer does not tell you whether the machine composed a genuine new term or merely bound an old one fast. The missing thing is an instrument that discriminates those sources. That is the `gap` in F12, characterized in effect terms and not named.

## 4. Why the record's tempting answer is the forbidden error

The tempting answer to "how should machines combine the two" is a name: a particular hybrid architecture. That would commit three errors:

1. **Naming a missing thing.** Fig 13 :135: *"It cannot say which primitive is missing, because naming it would mean already holding it."* The source-discriminating instrument is not held.
2. **Confusing binding with import.** A fast binding of an atom already in Γ adds no atom (Fig 6 :21: *"MINT composes inside the closure and can never add an atom."*). Calling it an import would overstate the gain.
3. **Letting a frame certify its own limit.** Fig 8 :34: *"A frame cannot reach its own metaframe."* An architecture that declares itself the correct combination is a frame certifying itself.

## 5. ANSWERED: what does "shape" license here?

Nothing in the figures names a hybrid architecture. What is licensed is the constraint set in section 1 and the honest `gap` about the discriminating instrument. Any specific architecture (neuro-symbolic routing, dual-process gating, chain-of-thought plus verifier) is a binding from the engineering frame, provenanced as such, and carries zero verdict weight until the ground pays for it.

## 5b. Correction to my own section 3 (carried from the exemplar's discipline)

I initially overstated the "shape, not a name" rule as a ban on naming anything the framework does not output. The README's phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* The subject is a missing primitive. Naming an atom already held in Γ is a binding, not the invention of a missing primitive. So the rule does **not** forbid saying "the fast frame supplies a prior over atoms already in the library." It forbids saying "the framework has derived that the missing primitive is X." Both readings are now recorded so neither is quietly lost. Triangulated (README + Fig 6 :21).

## 6. Two consequences for outreach

**Prestige is not action.** *The Recursive Self-Improvement Trap*: *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A campaign that gathers famous names to agree with the shape is the named collapse, not corroboration. The legitimate ask is a budget to test the shape against a ground.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* And: *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."* So `01`, `06`, `07`, `09` and `11` are simulated derivations checked for internal consistency against the figures. They are **not** tests of the claim and must be labelled as such. They cannot settle anything they report on.

## 7. The stop

Fig 13 :134: *"Unreachable is a verdict here, not a silence,"* and Fig 8 :39: *"So a search that finds nothing is never a proof of absence."* The shape is reached; the instrument is owed; the lineage is recorded. *"Indiscernibility is not identity."*
