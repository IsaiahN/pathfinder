I then applied the WATSON order: R by arity, symmetry and scale; one line per domain with actors, currency and anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the source slot of the observation, not the composition. Arity: two candidate sources plus sources not yet conceived. Symmetry: many-to-one from source to reading, so the reading is a lossy projection and cannot be inverted. Scale: molecule, sample, site, environment, time. Because the slot is source and the reading averages over molecules, this is a per-slot quantity.

- **Domain 2, the source-discrimination domain.** Actors: biology frame, abiotic-geochemistry frame, anchor instrument. Currency: independent bearings. Anchor: an experiment neither frame can move. Question type: union, because both production conditions can hold at one reading.
- **Domain 3, the habitat domain.** Actors: light, water, minerals, radiation, delivery, decay, contamination, diagenesis. Currency: contact and cascades. Anchor: the enumerated world. Question type: union with Domain 2; conditions co-bind.
- **Domain 4, the name-binding domain.** Actors: oxygen, methane, isotopologues, enantiomeric excess, morphology. Currency: provenance. Anchor: ground settlement or a provenanced import with a shadow test. Question type: partition of shape versus name.
- **Domain 5, the time and channel domain.** Actors: racemization, cosmic rays, instrument drift, degradation. Currency: degraded contact. Anchor: the ground does not decay. Question type: partition of unreached-at-budget versus no-source.

Order by dependency: describe the residual before naming a frame; write the objective and refuter before the search; settle each bearing against the anchor before combining frames; import a name last, behind a source gate and shadow test. All five domains name an anchor, so none is a gap.
