## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :134: "Unreachable is a verdict here, not a silence,".

From The Library of Babel: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So for INF-0002 a **shape** is the four-part form any definition of semantic information must have before we can name one: a signal; a typed bond to what it is about; a ground that settles which bond holds; and a level at which the settling occurs. It constrains. It does not supply the definition. Shannon's entropy is a shape with only the first part filled; that is exactly why it is not semantic information.

## 2. How the shape is obtained

- The Library of Babel: "you will find these new terms that overlap, correlate, or are even used interchangeably with your known terms." Bootstrap from the vocabulary you already hold, narrow the space, recurse.
- Fig 6 :30: "outward: does another frame already hold it? The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :31: "your words are borrowed too, so describe the effect rather than the cause."
- Decoding Tacit Knowledge: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- The Library of Babel on stopping: "you will know that you are done because the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better."

## 3. What licenses a name, or a definition

Two things, both outside the shape:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "SETTLE — the ground settles it. Verified only by what pays." The figures README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest." For semantic information, the analogue of a source-discriminating instrument is an instrument that distinguishes "signal is about X" from "signal is correlated with X." No such instrument is supplied in this folder.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50-52), with a source gate and a shadow test. A definition borrowed from engineering (classification labels) or from biology (organism-level sign relations) must be recorded as a binding, not presented as a derivation.

The Hard Problem is About Source sharpens this. An instrument that reads green "cannot comment on the source." The essay continues: "If several paths create the same behavior, then behavior is a projection with lossy information (it cannot define consciousness in full)." Applied here: mutual information reads a correlation and cannot comment on whether the correlation is aboutness. The answer is "unreached until a better instrument exists," not "there is no such thing as aboutness."

## 4. Why the unqualified question is the specific forbidden error

The Library of Babel names it: "Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually to find their answers and then combine them in a satisfactory way." This is Fig 9 :54-58 in plain language and is the main finding F7 in `01_figure_grounded_audit.md`.

Decoding Tacit Knowledge gives the positive version of the same point: "Meaning doesn't live in the words. It lives in what the listener brings: the situation, the point and the history behind it." This is not a general ban on agent-free definitions; it is a claim about human message understanding. Fig 2 :36 decides when it governs: "An anchor is legitimate when the question is constitutively about it."

The same essay also records the valence rule directly: "Agreement is the whole point when you're settling what words mean. It's worthless for settling what's true when both sides learned from the same sources." That is Fig 2 :39-41, and it is why the convention domain (D3) and the aboutness domain (D2) must not be averaged.

## 5. Q: Does "shape, not a name" forbid defining semantic information?

**No, and the scope matters.** The README's phrase governs a *missing* thing, one not held in the library Γ. Shannon's bits, bonds and the six-term substrate are already held; what is missing is the ground that settles which bond holds and the level at which it settles. So the framework can return the four-part shape and refuse to fill the slot. It cannot, from its own resources, say "semantic information is X" where X is a specific definition requiring an instrument or a provenanced import. That would name a missing ground as if it were held.

This is a **correction to my own first reading** in section 1, where I wrote "before we can name one" without qualification. The correct claim is: the shape is returned; the particular definition requires a ground reading or an import, and until then the slot stays open. Recorded here rather than silently repaired.

## 6. Two consequences for outreach and for this derivation

**Prestige is not action.** The Recursive Self-Improvement Trap: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A list of famous information theorists who agree with a definition is the named collapse, not corroboration.

**My own audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too (intelligence is essentially arrangement). However, the truly testable output would need to be derived from the real architecture or working the formula yourself." Also: "Metatheories cannot validate themselves." So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the question and cannot settle it.
