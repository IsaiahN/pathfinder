## 1. Independent domain census, written from the residual line alone

I redid the census before relying on the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors, currency and anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the gap between an observed answer and what would be observed if a ground-ranging process had produced it. Arity: one artefact with several overlapping possible causes, so a **union compound**, not a partition. Symmetry: "genuine" is an ordered relation to an anchor, a threshold and production question, not a symmetric property of the text. Scale: the loop runs inside one frame; verification runs between seats; capability lives in agent-and-habitat. The artifact cannot carry the verdict across that lossy crossing.
- **Domain 1, output.** Actors: answer, confidence, step count. Currency: fluency, coherence, compression, credibility. Anchor: none nameable from inside. No verdict power.
- **Domain 2, loop.** Actors: Γ, the operators, the per-slot residual. Currency: residuals, MDL bargain, settlement. Anchor: ground as the only metric.
- **Domain 3, checking arrangement.** Actors: maker, auditor, maintainer, outside frame. Currency: independence, provenance, refuters. Anchor: a non-updating anchor.
- **Domain 4, habitat.** Actors: agent and habitat. Currency: contact and cascade. Anchor: the ground.
- **Domain 5, lineage.** Actors: record, origin stamps, seq, refusal. Currency: derivability and decidability. Anchor: whether the route was available and settled.

Order by dependency: describe R before naming a frame; establish the anchor and the channel before scoring a process; settle a first-order term before composing over it; allow refusal before mint; read the output last. Probe order: SEARCHED first, then INWARD channel break, then OUTWARD provenanced import, then elimination at the ground.
