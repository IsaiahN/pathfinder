## The residual in effect terms

A model Γ predicts a system's collective state from a set of local interaction rules. One rule is perturbed by a small amount δ, small in description length and in parameter magnitude. The observation o' then departs sharply from the prediction Γ(b,a): an order parameter jumps, a cascade spans the system, or the attractor switches. R = |Γ(b,a) − o'| is concentrated in a few object slots (Fig 1 :19), not spread evenly. The question asks for the condition C under which that residual is large and discontinuous rather than small and smooth. Option A: C is the size of δ. Option B: C is where δ lands in the composition, the sign of the feedback around it, and whether the remainder compounds. A sends us looking for a universal magnitude threshold that the figures do not supply. B yields a checkable shape with an instrument per clause. The files below derive B, keep the numerical part as `gap`, and state the refuter before the conclusion.
