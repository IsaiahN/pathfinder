The Symbols table defines R_T as `gap(x, (T_E ∘ T_A)(x))`, and Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation the folder actually uses.

**R_T is nonzero.** Four things the shorthand holds do not survive the trip back down:

- **The union structure.** The shorthand names four conditions; the concrete case must keep their anchors separate. A single vent setting can satisfy D2 and D3 while D4 remains unmeasured.
- **The import price.** The shorthand says a template is an import if it is a new kind; the concrete case must establish whether RNA monomers are already in the network's closure. That is a database-and-experiment question, not a figure question.
- **The gap itself.** Concretising the shape into a named first network erases the `gap` and turns a candidate into a verdict. Fig 13 :134 forbids treating that as silence, and Fig 4 :25 warns that a recording carried upward looks like knowledge.

What survives cleanly: a catalyst must survive its use, a cycle must close, a compartment maintains contact, selection can run without a genetic author, and a settled network can be an operand at the next level.
