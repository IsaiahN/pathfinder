## 1. A shape is a constraint you can state before you can name the instance

The canonical README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13: "It can say the answer is out of reach with the library as it stands... It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

Applied here: the shape is **selectivity by differential ground contact, with the mixture as the default and the valuation as retrospective**. A name would be "2-aminothiazole sequesters glyceraldehyde on a mineral surface." The framework cannot derive that name. It can constrain any answer to have the shape: a closed atom set, an unbounded arrangement space, no planner, per-species persistence, and a valuation that only appears with life.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. "With each new term gained, you narrow the space by definition and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30 to :31: "your words are borrowed too, so describe the effect rather than the cause."
- The question was described in effect terms before any figure line was chosen (audit section 0): the gap between an unselective product distribution and a narrow functional subset, with no planner and no pre-life standard of harm.
- *Library of Babel* on steering: "The books that you are returning in your searches need to be tested or ranged against the problem you want answered in order to steer the direction of the next search." And on stopping: "the finish line will also be the starting place."

## 3. What licenses a name

Only two things, both outside the shape:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." The README: the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50 to :52), with a source gate and a shadow test.

Here, the world sources do supply names, but as imports from the chemistry frame: the glyceraldehyde aminal, borate complexing, surface thermochemical oscillation, recursive dilution. Each is marked as an import with a source and a quote in `10_source_ledger.csv`. None is promoted into the figure-derived answer. This is why F6 in the audit is a `gap` rather than a filled slot.

## 4. The source-discrimination limit matters for this question

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and "the instrument is speaking only about what it measured, it cannot comment on the source." Several sources can create the same reading. "If several paths create the same behavior, then behavior is a projection with lossy information." It was the spectrometer, not an argument, that resolved it. "An instrument that can't distinguish these cases demonstrates its own inadequacy."

Applied here: observing that a mixture is dominated by tars does not identify which selective process produced the useful minority. Several mechanisms (isomer separation, catalytic survival, cycling, concentration) can yield the same endpoint distribution. What is owed is a source-discriminating measurement between mechanisms, not a name chosen from a reading.

## 5. Q: does "harmful" name something the framework can return?

No. Fig 11 :49: "An actor's valence is relative to the residual, not a property it carries." Fig 11 :51: "No standing list of good actors survives a change of residual." "Harmful" is a valence assigned by a later frame (a living system) to a molecular species. The framework's own valuation rule makes the question's term frame-dependent, so the honest answer begins by refusing the term as written. This is the *Library of Babel* case where "the problem was a bundle or conflation of several problems masquerading as one": a molecular fact bundled with a later valuation.

**Answer:** the framework returns the shape (differential persistence, mixture default, retrospective valuation) and refuses the name. The specific chemistry is recorded as a `gap`.

## 6. Two consequences for the package

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly." And: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige." A campaign that gathers famous names to agree with the shape claim is the named collapse, not corroboration. The legitimate ask is a budget to try the claim against a ground.

**This audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post... However, the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the claim and must be labelled as such. It cannot settle anything it reports on.
