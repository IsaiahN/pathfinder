## 1. A shape is a constraint, not a filler

Fig 9 :32: *"you get a kind of thing, never the answer itself."* Fig 13 :134: *"Unreachable is a verdict here, not a silence"*. The canonical README adds that the framework returns a shape, not a name, and cannot say which primitive is missing because naming it would mean already holding it.

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

For this question a **shape** is therefore the multi-part constraint:

> a continuous ordering being compared with a value, a comparison that fires at that value, a residual indexed by slot, a cascade that carries the impact outward several steps, and a lossy bridge to any scale where the impact is read.

A **name** would be a threshold value, a lag in years, or the name of a tipping element. The framework does not supply those.

## 2. How the shape is obtained

- *Library of Babel*: bootstrap vocabulary by proximity, *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 9 :27-28: *"describe it before you go looking, or any frame you pick will seem to fit."* Fig 9 :30-31: *"your words are borrowed too, so describe the effect rather than the cause."*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on the bundle: *"Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually to find their answers and then combine them in a satisfactory way."* This is why the question is split before any figure line is chosen.

## 3. What licenses a name here

Only two things, both outside the shape:

1. **The ground settles it.** A measured bifurcation, a palaeorecord, a source-discriminating instrument. `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays."* The canonical README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, :26). Fig 6 :23: *"No frame escapes its own closure. The bound moves only on contact with a frame whose closure differs."*

An effect description travels; a name smuggled in from another field does not. Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."*

## 4. Why a source-discriminating instrument matters for this question

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and *"cannot comment on the source"*: one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. *"If several paths create the same behavior, then behavior is a projection with lossy information."* It was the **spectrometer**, not an argument, that resolved it.

Applied here: a smooth approach to a critical value can be produced by several different mechanisms (a saddle-node ghost, a rate-induced threshold, noise-induced tipping). Reading only the smooth curve does not name the mechanism. What is owed is an instrument that discriminates among sources, not a name chosen from the curve. This is the world-facing reason for keeping the shape open rather than declaring a tipping element.

## 5. The question's own answer is a shape, not a threshold

**What licenses a particular threshold value or lag?** Nothing in the framework. Those are licensed only by the ground settling a minted term, or by a provenanced import with a shadow test. Until one of those, a number is the searcher's own contribution and must be recorded as such.

**Does the question's phrasing commit the forbidden error?** It does if "cross a threshold gradually" is treated as one event with one duration. The figures separate the ordered comparison (Fig 12), the derived smoothness (Fig 13 :43-44), and the per-slot residual with its cascade (Fig 1, Fig 11). The honest form is the split shape in §1, not a merged noun phrase.

## 6. Consequence for what this package can claim

*The Recursive Self-Improvement Trap* is explicit: *"the truly testable output would need to be derived from the real architecture or working the formula yourself"*; LLM output can *"simulate an approximate answer/output"*. So `01_figure_grounded_audit.md` and this file are **simulated derivations**, checked for internal consistency against the figures. They are not a test of the claim and cannot settle anything they report on. Every substantive claim in the folder is labelled `general`, `specified` or `grounded`, and none is `grounded`.

## 7. Prestige is not a witness

From the same essay: *"Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous tipping-point researchers who agree with the shape is a budget to be tried, not a verdict. The ask in `02_outreach_email.md` is for a refutation, which is the opposite move.

## 8. Falsifier for this reading

This reading fails if a figure line or a properly provenanced import supplies a threshold value, a lag or a named tipping element as part of the shape the framework returns for this question. It also fails if the three conditions turn out to be governed by one figure term rather than a union of three. Both are checked in `06_isomers_and_order.md` and in the second-seat audit.
