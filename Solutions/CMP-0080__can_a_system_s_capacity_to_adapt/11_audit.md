## Independent domain census (written from the residual line alone)

I redid the census before reading the primary's conclusions, using the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The mismatch between a pre-crisis structural reading and a crisis outcome, per slot. Arity: three terms, a structure `S`, an outcome `C`, and a ground `g` that settles `C`. Symmetry: ordered, `S` before `g`, so a symmetric correlation cannot decide the arrow (Operators table, sequence vs conjunction). Scale: structure is a state at a moment; the response is a cycle through the crisis and back. So the object is a **union compound**, not a two-option partition: `S ∩ habitat ∩ g`, with an unassignable shared fraction.
- **Domain 1, structural frame.** Actors: atoms, bonds, agents, network. Currency: bits to describe, actions to test. Anchor: none internal; its anchor is borrowed from domain 3 via domain 2.
- **Domain 2, habitat and contact.** Actors: actors, conditions, relations. Currency: contact and cascade. Anchor: the ground, which settles; the habitat updates. Union with domain 1.
- **Domain 3, prediction and verification.** Actors: predictor, checker, crisis. Currency: prediction residual per slot. Anchor: the realized outcome, valid only if it does not update on the prediction.

Order by dependency (Fig 3): perceive per slot, acquire affordance vocabulary, bind the goal as a comparison, then judge; refuse before mint (formula step 2); describe the residual before naming a frame (Fig 9 :27-28).
