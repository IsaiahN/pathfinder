## 1. A shape is a constraint, not a filler

The canonical local figures README says the framework returns "what a missing thing would have to look like (a shape, not a name)." Fig 9 :32 "you get a kind of thing, never the answer itself." Fig 13 :134 "Unreachable is a verdict here, not a silence."

From *The Library of Babel*, as recorded in the exemplar's `05`: "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So for this question a **shape** is the form any mechanism must have if it is to produce reliability under noise and turnover. It constrains; it does not identify a molecule. "A system that can refuse a wrong term," "a channel kept reachable while it decays," and "independent paths ranging against one ground" are shapes. "Kinase cascade," "Hsp70," and "integral feedback" are names.

## 3. What licenses a name

Two things, both outside the shape:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." A measurement of error rates, turnover intervals, or energy cost moves a binding toward grounded.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :50-52). Naming kinetic proofreading is an import from molecular biophysics; it is legitimate only with provenance, which `10_source_ledger.csv` supplies.

*They're Scanning Books*, as recorded in the exemplar: "The real import is not a new term in the existing space. It is a new dimension of the space." Also: "Declaring the primitives does not make them neutral. It makes the choice visible." The three shapes are a visible choice of description axes, not nature's own list.

## 4. Why the instrument question is the source question

*The Hard Problem is About Source* (opened this run): "If several paths create the same behavior, then behavior is a projection with lossy information." And: "An instrument that can't distinguish these cases demonstrates its own inadequacy." The essay's spectrometer example is the precedent: the projection read "green" while several different sources could produce it, and it was the instrument, not an argument, that discriminated the source.

Applied here: a measured error rate does not by itself name the mechanism that produced it. Kinetic proofreading, equilibrium binding with a very favourable ΔG, and spatial compartmentalisation could in principle yield the same fidelity reading. What is owed is a discriminating experiment, not a name. This is why F3's refuter asks for the *absence* of an energy-dissipating delay, and why the figure answer stops at the shape.

## 5. The shape for this specific question

The binding written down at the start of the run (and therefore refusable) is:

> Reliability under noise and turnover has the shape of a union of three constraints: a refusal operation for wrong near-matches, an active maintenance process that keeps a decaying channel in contact with an unchanging ground, and a set of structurally different paths that are independent enough that their agreement is triangulation rather than a shared error. Population-level reliability is the same loop repeated, with selection between rooms.

Each clause is a shape. None names a molecule. The molecular names appear only in F9's last row of `01`, marked `specified` and ungrounded.

### Correction visible in the record

I initially wanted to write the shape as one mechanism with three properties. The re-census in `01` §6 changed that to a union of three conditions, because Fig 9 :55 says a bundled problem is usually a union. The earlier reading is retained here rather than erased: a single-mechanism reading would let one lever "fix reliability," which is exactly the error Fig 9 names.

## 6. Two consequences for this package

**Prestige is not action.** *The Recursive Self-Improvement Trap* (opened this run): "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A list of eminent people who agree with the shapes is a convention, not corroboration (Fig 2 :40).

**This audit is a simulation, not a ground reading.** Same essay: "LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post." The same essay says "the truly testable output would need to be derived from the real architecture or working the formula yourself." So `01`, `06`, `07` and `09` are simulated derivations checked for internal consistency against the figures. They cannot settle the biological question. They can only state the shape, the lineage, and what would reverse it.
