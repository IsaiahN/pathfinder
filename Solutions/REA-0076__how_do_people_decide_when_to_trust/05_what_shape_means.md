## 1. A shape is a constraint, not a filler

The canonical README states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* Fig 9 :32: *"you get a kind of thing, never the answer itself"*. The figures add (local reading from Fig 13): *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question, *"a well-calibrated trust judgment is per-slot and ranged against a legitimate ground"* is a shape. *"Trust when confidence is above 0.8"* is a name, and an unearned one.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* Fig 9 :30-31 (local reading): *"your words are borrowed too, so describe the effect rather than the cause"*.
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: the answer is reached when *"the finish line will also be the starting place, as there is nowhere else to search and nothing else that can describe the answer better."* The paradox is that by then you have *"composed the answer through the process of locating it."*

Applied here: the effect description is not "the system is trustworthy" but "in this slot, against this ground, this reading would come back different if the system were wrong." Anyone can check that, whatever their vocabulary.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** local `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays."* The canonical README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, local reading), with a source gate and a shadow test.

*The Hard Problem is About Source* sharpens this. Metamerism: an instrument reads green and *"the instrument is speaking only about what it measured, it cannot comment on the source."* One green light, or yellow plus blue, or red plus green plus blue, or a novel scheme not yet discovered, can produce the same reading. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy, it cannot claim anything substantial about what is being measured or what causes it."* It was the spectrometer, not an argument, that resolved it: *"The answer is unreached until a better instrument exists."*

A confidence display, an explanation, and a fluent answer are readings of the same kind. They do not comment on the source. Naming a trust level from them is the metamerism error. What is owed is a source-discriminating instrument, not a number.

## 4. Why the world literature's calibration number is not the answer

Guo and colleagues (PMLR 2017) measure model confidence calibration and find modern networks *"poorly calibrated"*. Rehman (2026) measures *"trust calibration"* by self-report and explicitly says the results do not establish *"independently verified calibration, or objectively appropriate reliance"*. These two uses of the same word are a projection with lossy information: one is a property of a model's output distribution, the other is a person's judgement about their own judgement. Neither is the figure's per-slot residual against a legitimate ground.

The figures do not forbid either measurement. They forbid treating a frame-internal score as the anchor. Fig 1 :27 (local reading): *"They are frame-internal. A frame cannot score itself with a quantity it also produces."*

## 5. Q: Does the framework license a universal trust threshold? ANSWERED, no

**Nothing in the framework licenses one.** A threshold would be a name where the framework returns a shape, and there is no ground reading in this folder that settles it. The correct form is the shape plus an instrument owed:

- per-slot residuals, not an aggregate;
- an anchor type decided by what the question is about;
- low-overlap checks, not agreement;
- a maintained channel with fresh readings;
- capability in the deployment habitat;
- a vocabulary and objective established before any display;
- a refusal when the anchor is illegitimate.

The threshold slot stays open. If someone derives it from the figures alone, refuter 6 in `01_figure_grounded_audit.md` fires and this answer is withdrawn.

## 6. Two consequences for outreach and for this derivation

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige must* **never** *be allowed to validate an action* **directly*** ... *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A campaign that gathers famous names to agree that the shape is right is the named collapse, not corroboration. The legitimate ask gives the claim a budget to be tried and lets the ground settle it.

**This audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an approximate answer/output with the formula found in the architecture post. It will often be better than the generic outputs that you will usually get otherwise too"*, but *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* LLM output is *"simulacra."* So `01` is a simulated derivation checked for internal consistency against the figures. It is **not** a test of the claim and must be labelled as such. It cannot settle anything it reports on.

## 7. A correction to my own reading

I initially wrote that *"the framework returns a shape, not a name"* forbids naming any threshold or quantity at all. That is too strong. The README phrase governs a **missing** thing, one not held in the library. Per-slot residuals, anchors, independence and channels are all held in the figures; naming them is ordinary derivation, not invention. What remains forbidden is naming the missing discriminator or the universal threshold as if the framework had produced it. Both the held shape and the open slot are now recorded so neither is quietly lost. Triangulated (canonical README + Fig 9 :32 + The Library of Babel).
