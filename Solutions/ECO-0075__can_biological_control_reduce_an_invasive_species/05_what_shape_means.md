## 1. A shape is a constraint, not a filler

The canonical limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself." Fig 13 :134-135: the system can report that it lacks something rather than producing an answer anyway, but "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*: "You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For ECO-0075 the shape is: two conditions in one union, an import with provenance, enumeration to the order where the cascade stops mattering, relational valence, asymmetric power, and the ground as the only settlement. The name of the agent that works in a given habitat is not part of the shape.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. "With each new term gained, you are able to narrow the space by definition and deepen your vocabulary."
- Fig 6 :30: "The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms." Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause."
- The exemplar's reading of *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world." For this question the plain description is: if the shape is right, a release that ignores third-order contacts should fail in ways that were not in the pre-release test list, and a major specialist should still be able to harm a non-target by apparent competition.
- *Library of Babel* on stopping: the answer is reached when "the finish line will also be the starting place" and the paradox is that by then you have "composed the answer through the process of locating it."
- The same essay on malformed questions: "Perhaps your problem was a bundle or conflation of several problems masquerading as one? You will need to search all of those problems individually." This is the essay-level source for F1 (the union compound) and it was fetched this session.

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: "the ground settles it. Verified only by what pays." The canonical README says the framework "stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :51), with a source gate and a shadow test.

For biological control, a candidate agent is licensed by field outcomes against the target and non-target slots after release, and by a recorded provenance stating where the agent came from and which gap it was chosen to explain. A laboratory host-range result is a substituted habitat (Fig 11 :70), so it licenses a budget to try, not a verdict.

## 4. Source discrimination is the instrument owed

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and "cannot comment on the source." Several underlying causes can create the same reading, so "If several paths create the same behavior, then behavior is a projection with lossy information." It was the spectrometer, not an argument, that resolved it. "An instrument that can't distinguish these cases demonstrates its own inadequacy."

Applied here: a drop in target abundance is a reading. It cannot comment on the source. The target may have been suppressed by the agent, or the target may have moved, or the measurement method may have changed. Several non-target outcomes (no effect, apparent competition, trophic cascade) can produce a similar "successful control" reading. What is owed is a source-discriminating instrument, meaning post-release field readings that separate target suppression from non-target contact. This is F6 and F7 at the essay level.

## 5. Prestige is not action

From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly." And: "Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."

A programme with many endorsements or a respected reviewer is a funded action, not a settled one. The legitimate ask is the opposite of a consensus: give the claim a budget to be tried and let the field settle it. This governs the outreach files: `02` and `03` never ask for agreement and never rank contacts by receptiveness.

The same essay gives the simulation limit: LLMs "can quickly simulate an approximate answer/output with the formula" but "the truly testable output would need to be derived from the real architecture or working the formula yourself." This solution is a simulation checked for internal consistency, not a test, and is labelled as such everywhere.

## 5b. Correction to an over-reading

An earlier draft of this file applied "shape, not a name" as a ban on naming any specific agent. That was too broad. The canonical sentence is about a **missing** thing, a primitive not held in the library. For ECO-0075, the missing things are the actual contact cascade and the field readings. Naming a candidate agent is a binding from the biological-control frame onto terms the habitat already holds; it is not the invention of a new primitive. What remains forbidden is claiming the framework itself names the agent, or treating a binding as if it moved the wall (Fig 6 :23). Both the original claim and the correction are kept so neither is silently lost.

## 6. Consequence for this question

**The figures return a shape, not a verdict on biological control.** They say what a defensible release must look like. They do not say whether any particular release is safe, and the canonical rule forbids them from naming the agent that would settle it. The honest report stops at the limit of the available instruments: the contact list is partially enumerable, the third-order residual is real, valence is relational, and the ground, not agreement, decides each case.

Fig 13 :134: "Unreachable is a verdict here, not a silence." The unreachable part is the name of the safe agent for a specific habitat, and that is a ground task, not a silence in this derivation.
