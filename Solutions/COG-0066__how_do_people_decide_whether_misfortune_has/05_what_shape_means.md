# What "shape" means for this question

Sources opened directly this session: the canonical figures README (local), Fig 9 and Fig 6 of `03-FIGURES_TEXT.md` (local), Isaiah N, *The Recursive Self-Improvement Trap* (2026-11-19), and Isaiah N, *The Hard Problem is About Source* (2026-08-28). The remaining six of the eight essays are listed with URLs below because the exemplar's local `05_what_shape_means.md` records them, but they were **not opened in this run** and are not quoted here as evidence. Their status is "listed, not read this session".

## 1. A shape is a constraint, not a filler

The figures README gives the canonical limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)"*. Fig 9 :32 *"you get a kind of thing, never the answer itself"*. Fig 13 :134 *"Unreachable is a verdict here, not a silence"*.

So a **shape** for COG-0066 is the narrowed form of the answer that can be stated before anyone can name which term a particular observer bound. It constrains: it says the decision routes a slot-indexed residual, that the four labels overlap, that labels are habitat-relative, and that one case needs an import. It does not fill: it does not say which culture, which person, or which term.

The distinction matters here because the question invites a name. "They chose a supernatural cause" is a name applied after the fact. The shape is the set of constraints on how that name could have become payable.

## 2. How the shape is obtained

- Fig 9 :31 *"your words are borrowed too, so describe the effect rather than the cause"*. The words "social, natural, moral, supernatural" are the questioner's, not terms the framework holds. The effect is a positive residual at a slot.
- Fig 6 :30 *"Cast it in effect terms."* The description has to travel to a frame whose closure differs; a description in borrowed nouns will not travel.
- Fig 9 :27-28 *"describe it before you go looking, or any frame you pick will seem to fit"*. The census in `01` §2 was written before the world search. Had the field been picked first, any of attribution theory, cognitive science of religion or anthropology would have seemed to fit.

## 3. What licenses a name

Only two things, both outside the shape:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* Here the question is constitutively about people, so Fig 2 :37 *"Human judgment is the right anchor for is this a good answer for a person, because the question is about people."* Measured attribution is the anchor; agreement between theories is not.
2. **A provenanced import from a closure that differs**, with source gate and shadow test (Fig 6, Fig 8). This is exactly the license question for the supernatural case. An agent term is nameable once its provenance and its gap-explaining role are recorded, not before.

*The Hard Problem is About Source* sharpens point 1: *"If several paths create the same behavior, then behavior is a projection with lossy information"*. Several cause structures can produce the same observed attribution ("they said witchcraft"), so the observed label cannot by itself name the source. The essay continues: *"The answer is unreached until a better instrument exists."* What this question needs is an instrument that discriminates among the routing bins at the moment of attribution, not a better argument about the four words.

## 4. The shape for COG-0066, stated

> The decision is a routing of a slot-indexed prediction failure by what is missing or wrong in the observer's library; the four everyday labels are overlapping bindings onto those routes, not a partition; their valence is relative to the observer's residual and habitat; and the supernatural case differs in kind because it imports an atom from a closure that differs, while the moral case differs because a refusal is owed where a character term is usually minted.

That is a shape. It is checkable at four points: per-slot routing, union overlap, habitat relativity, import provenance. It refuses to name which term any individual bound. The pre-registered refuter in `01` §4 is the discipline that keeps this refusal honest.

## 5. Why the four-category framing is the wrong shape

The question's own vocabulary describes an *output* (a label) and asks for the *mechanism*. The figures distinguish outputs from generators. A vocabulary that only holds the four labels can say what a situation was called and cannot say what the observer was doing when the residual changed. Fig 12 :111-113: *"A vocabulary without bonds can name a state and cannot name a route to one."* The four words are states of a report; the loop is the route to one.

This is not a claim that the four words are false. Fig 2 :41 *"efficient for a convention: agreement about a shared meaning is the product, not a corruption of it"*. They are a functioning convention. The error is to promote a convention to a verdict.

## 6. Two standing admissions

**Prestige is not action.** *The Recursive Self-Improvement Trap*: *"Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it."* A list of distinguished attribution researchers who agree with the re-description is a funded action, not a settlement.

**This audit is a simulation, not a ground reading.** Same essay: *"the truly testable output would need to be derived from the real architecture or working the formula yourself."* Also: *"Metatheories cannot validate themselves."* So `01` is a simulated derivation checked for internal consistency against the figures, not a test of the claim. It cannot settle anything it reports on. Every substantive claim in this folder carries `general` or `specified` mode for that reason.

## 7. Falsifier for the shape reading

This reading is refuted if a ground instrument shows that people select among four mutually exclusive cause types by a rule that is invariant across slots and habitats, with no probe stage, no re-fitting, no refusal deficit, and no frame-boundary crossing. In that case the shape would be a name after all, and the re-description should be withdrawn.
