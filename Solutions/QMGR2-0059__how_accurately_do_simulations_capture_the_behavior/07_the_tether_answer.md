# The Tether's answer on simulation accuracy

**Mode: `specified` - not `grounded`.** This is a shape and a route, not a measurement. Simulated derivation checked against the figures (`05_what_shape_means.md` section 6), not a ground reading.

## 1. The residual it answers

"How accurately do simulations capture gas, stars and dust?" is a bundle, not one question. In effect terms the residual is R = |Γ(b,a) - o′| per slot: the gap between what a model predicts for ordinary baryons and what a telescope returns, indexed by component, object, scale and redshift. Fig 9 :54: *"And when the split lands on a union rather than a partition, unbundle before you search again."* The two conditions to unbundle are numerical fidelity, are the equations solved right, and physical fidelity, are the subgrid bonds right. They have different anchors and different instruments (Fig 2 :29).

## 2. The shape

1. **Accuracy is a per-slot residual, never one number.** Fig 1 :19: *"The residual is indexed by object slot, not aggregated."* Fig 1 :22: *"Aggregating across slots is how a live signal disappears into an average."* A code can match the stellar mass function while carrying a live residual in circumgalactic gas or dust attenuation. A global accuracy percentage is a pooled reading, and a frame cannot score itself with a quantity it produces (Fig 1 :27).
2. **The sky is the anchor; code agreement is not a witness.** Fig 2 :29: *"An anchor is whatever settles the question and does not change its answer because of what any frame thinks. A measurement, an experiment, a counter, a market, a patient outcome."* Fig 2 :40: *"disqualifying for a verdict: agreement about the world is worthless when the agreeing frames share an evidence pool"*. The major suites calibrate to overlapping observables, so their agreement on those targets is one pool talking.
3. **Convergence is a gate, not the ground.** Formula step 5: *"the ground settles it. Verified only by what pays. A gate is not the ground."* Resolution and particle count are quantities the model produces; they cannot score the model. Verification and validation are structurally different questions (Section 1 of `06`).
4. **Subgrid physics is the bond, so same ingredients give different substances.** Fig 12 :117: *"isomer. Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."* Two suites with the same particles but different feedback are isomers: they can match the same galaxy population yet predict markedly different gas flows. Refinement inside a closure cannot add the missing bond (Fig 6 :21).
5. **The live residual sits where there is no instrument.** Fig 3 :27: *"A link with no instrument is not a link that works. It is a link nobody has looked at."* Star formation and feedback act below the resolution element; the calibration link has the fewest instruments (Fig 3 :24). Chaos caps what can be claimed for individual objects: Fig 13 :32: *"a remainder compounding through a chain that amplifies is chaos, and the detail a crossing discards reappears above it as noise."* Accuracy is an ensemble statement.
6. **What is owed is a source-discriminating instrument, not another tuning.** Fig 6 :32: *"An instrument is not built from a description. It is improved from a worse instrument already returning something."* Fig 8 :39: *"So a search that finds nothing is never a proof of absence."* Circumgalactic absorption and dust attenuation are candidate axes because different bonds that match the population predict different values there.
7. **Calibration carries a round-trip gap that must be reported.** Fig 4 :30: *"So take the round trip and measure the gap. Without it you are navigating by dead reckoning: confident about a position nobody checked."* A match to the calibration statistic is not a match to the galaxy.

## 3. What it explicitly does not say

- Not one accuracy number, and not "simulations are accurate" or "simulations are inaccurate" as a verdict.
- Not that any named code is best. That is a name where the framework returns a shape, and it is a prestige proxy, not a ground (Seat Map :163).
- Not that convergence proves validation, or that agreement between suites proves anything about the world.
- Not a derivation of a feedback prescription, and no new primitive or imported atom.
- Not `grounded`. No independent measurement here settles left(R,φ) for any code.

## 4. What would settle it - the ground

An independent, source-discriminating observation, not a further argument. *The Hard Problem is About Source*: an instrument that reads green *"cannot comment on the source"*; the spectrometer resolved it. Here:

- Does a held-out observable (CGM absorption, dust attenuation, resolved kinematics) discriminate two feedback bonds that both match the stellar mass function? A measurement that does would name the live slot.
- **Per-slot residual:** does a single global accuracy number predict, prospectively and per slot, which component diverges next? If it does, F1 is false.
- **Independence test:** do two suites with different solvers, subgrid physics and calibration data agree on a held-out observable and survive an independent measurement? If they do, F2 weakens.
- **Gate test:** does convergence alone settle a held-out observable with no observational comparison? If it does, F3 is false.
- **Round trip:** is a calibration statistic lossless over all other observables, so R_T is zero? If it is, F9 fails.

## 5. The honest stop

**Unreached, not unreachable.** The set of instruments available here cannot return a single accuracy number for any named code, and the essay record warns that a result could *"never be verified"* if it were *"contrived to fit the formula."* The framework stops where instruments can no longer distinguish and records the lineage so the stop is checkable. *How Intelligence Actually Works*: *"The recursion converges toward indiscernibility, and indiscernibility is not identity."* Being below the union horizon is *"never a settled verdict, only a report that nobody has reached it yet."*

## 6. One-paragraph version for outreach

> The Tether does not give an accuracy percentage for any simulation code. It says that accuracy is a per-slot residual between a model's prediction and an observation, indexed by gas, stars, dust, object and regime, so one averaged number throws away the only signal that says where to look. Convergence is a gate, not a ground; the sky is the ground, and suites that calibrate to the same observables are one evidence pool, not two confirmations. Two codes with the same ingredients but different subgrid feedback are isomers: invisible in the ingredient list, decisive in gas flows. The live residual sits at the uninstrumented middle link, chaos limits object-level claims to ensemble statements, and calibration carries a round-trip gap that has to be reported. What the Tether offers is the shape any answer must have, a set of falsifiers written in advance, and the class of source-discriminating instrument that would close it. The number stays open until the ground settles it.
