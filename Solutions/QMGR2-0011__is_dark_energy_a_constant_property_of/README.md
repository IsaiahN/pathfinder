## What this solution does

It does not take a side on whether the universe's dark-energy density is exactly constant (a cosmological constant, w = -1) or evolves. It re-censuses the question first. "A constant property of space" tries to bind energy (a state) directly to space (a state), which the six-term substrate forbids at first order (Fig 13 :74-75). What the figures can return is a shape: dark energy, if it composes at all, is a cross-kind composition with an unnamed structure between the states, and "constant" is a symmetry of that composed term. Whether the symmetry holds is a question for the ground, that is, precision cosmology, and the figures explicitly hand it there (Fig 9 :42). So the honest verdict is a figure-grounded category correction plus a `gap` on the empirical claim. The world reading is itself strained and internally conflicting, which is recorded rather than smoothed.
