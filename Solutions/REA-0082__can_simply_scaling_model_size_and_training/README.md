## Restated as an effect

The question asks whether raising a scale parameter k (parameters, tokens, compute) can turn a task slot s whose per-slot residual stays positive into a slot whose residual goes near zero in a way that is a new *kind* of term, or whether a new atom, bond, or contact with a different habitat must be imported. Option A (scale only) leads to more search inside the same closure. Option B (new principles) leads to an import that changes the closure or the contact. What an answer would look like is bound in ordinary terms in `01_figure_grounded_audit.md` §0, per the formula's "Direction" rule, so the sought-after shape is refusable.

## Headline result

A false dichotomy. Scaling is the correct and sufficient remedy for the "unreachable-at-this-budget" branch (a capability already in the closure and not yet found). Scaling cannot close the "underivable-in-principle" branch (a capability that needs a new atom or a new bond), because composition inside a closed set never adds an atom. Which branch an observed capability belongs to is a `gap`: it needs a per-slot ground measurement and a source-discriminating instrument, not an argument. The framework returns the shape of the required principle, not its name.
