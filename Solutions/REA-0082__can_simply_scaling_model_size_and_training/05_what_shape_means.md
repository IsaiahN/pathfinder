## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :135: "It cannot say which primitive is missing, because naming it would mean already holding it."

From *The Library of Babel*: "you can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains; it does not fill. For this question the shape is a **branch-assignment rule**: given a per-slot residual history, say whether the remedy is more search at the same reach or an import that changes the reach. A specific principle (a new optimizer, active learning, a world model) is a name, not a shape.

## 2. How the shape is obtained

- *Library of Babel*: use the vocabulary you already have that is closest to the thing, then look for recurring new terms that overlap or correlate with it, and recurse. "With each new term gained, you narrow the space and deepen your vocabulary."
- Fig 9 :30-31: "your words are borrowed too, so describe the effect rather than the cause". So describe the capability as an effect on a held-out slot, not as a mechanism like "reasoning" or "planning".
- *Decoding Tacit Knowledge*: "When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."
- *Library of Babel* on stopping: you know you are done because "the finish line will also be the starting place", and the paradox is that by then you have "composed the answer through the process of locating it."

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Fig 10 :24: "the ground does not decay, the channel does". *The Hard Problem is About Source*: "the answer is unreached until a better instrument exists." The spectrometer, not an argument, resolved the metamerism case.
2. **A provenanced import from a frame whose closure differs**, with a source gate and a shadow test (Fig 6 :23, Fig 8 :9-13).

*They're Scanning Books When They Should Be Studying Nature* sharpens this for exactly this question: "The real import is not a new term in the existing space. It is a new dimension of the space." Its central claim is that "You cannot accumulate your way from the category of outputs to the category of generators; they are different kinds of thing, and no quantity of the first sums to the second." That essay is a `general` frame-side argument, not a measurement, and it is recorded as such, not promoted to a verdict.

The same essay adds: "A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six", and "Declaring the primitives does not make them neutral. It makes the choice visible." So declaring a new set of primitives for an AI system makes a choice visible; it does not prove the choice matches the ground.

## 4. Why the aggregate curve is the specific forbidden reading

*The Hard Problem is About Source* gives the mechanism. An instrument reads green and "cannot comment on the source": one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. "If several paths create the same behavior, then behavior is a projection with lossy information." The reading does not determine the source.

Applied here: a smooth loss curve reads one value for many underlying causes. It is compatible with more search finding an already-reachable term, and equally compatible with a metric change manufacturing a flip. What is owed is a source-discriminating instrument, not a curve interpretation. Schaeffer et al. (read 2026-11-24) supply the world-side version of the same warning.

*The Recursive Self-Improvement Trap*: "the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself." A scaling law computed by the same loop it describes is such an output.

## 5. Q for this question - ANSWERED

**What shape does the answer have?** A two-branch rule, with per-slot residuals and an independent ground as the inputs, and with the branch remedies held apart. That is a shape: it constrains any acceptable answer without naming the missing principle.

**What is refused?** A single number answer ("scale is enough" or "scale is never enough"). Both collapse a union into one condition, which Fig 9 :55-57 forbids. Also refused: naming the new principle. "It cannot say which primitive is missing, because naming it would mean already holding it" (Fig 13 :135).

## 5b. Correction to my own §3

I initially wrote that the framework forbids naming any new principle. That overstates it. The README's phrase is about a **missing** thing, a primitive not held in `Γ`. Naming a principle already present in the AI library (a new objective, a new data source) is a **binding from the AI frame**, not the invention of a missing primitive. What remains forbidden is claiming that such a binding moves the wall by itself (Fig 6 :21: "MINT composes inside the closure and can never add an atom"), or that the framework derived what it merely recognised. Both claims are now recorded so neither is quietly lost. My §4 metamerism point is **not** retracted: the reason the curve cannot name the source is the missing discriminator, not a blanket ban on names.

## 6. Two consequences for the answer

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: "Prestige must never be allowed to validate an action directly... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it." A list of famous labs whose researchers agree that scaling is enough is the named collapse, not corroboration. The legitimate ask is a budget to try the claim against a ground.

**My audit is a simulation, not a ground reading.** Same essay: "the truly testable output would need to be derived from the real architecture or working the formula yourself." *Arrival of the Fittest* adds the operational warning: "could never be verified if the solutions presented were not contrived to fit the formula." So `01` is a simulated derivation checked for internal consistency against the figures. It is not a test of the scaling question and must be labelled as such.
