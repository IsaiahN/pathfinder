## 1. A shape is a constraint, not a filler

The canonical usage rule (local file, read this session) states the limit: the framework returns *"what a missing thing would have to look like (a shape, not a name)."* `Fig 9 :32` says *"you get a kind of thing, never the answer itself."* `Fig 13 :135`: *"It cannot say which primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel* (carried quote): *"You can cut your search short if the set of books returned is small and descriptive enough that it provides a general shape of the answer that satisfies your question."*

So a **shape** is the narrowed form of an answer that can be stated before it can be named. It constrains; it does not fill. For this question, *"a per-slot, settlement-based, refutable separator"* is a shape. *"Use a 0.05 significance level with a 30-observation window"* is a name and is not returned by the figures.

## 2. How a shape is obtained

- *Library of Babel* (carried): use the vocabulary already closest to the thing, look for recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you narrow the space and deepen your vocabulary."*
- `Fig 6 :30`: *"The description travels. Fails by being sharpened into terms only we can read. Cast it in effect terms."* `Fig 9 :31`: *"your words are borrowed too, so describe the effect rather than the cause"*.
- *Decoding Tacit Knowledge* (carried): *"When contact isn't possible, the best you can send is a plain description of what you'd expect to see, because anyone can check that against the world."*
- `Fig 9 :27`: *"describe it before you go looking, or any frame you pick will seem to fit"* - for this question, describe the per-slot failure to shrink before picking a drift detector.
- *Library of Babel* (carried) on stopping: the answer is reached when *"the finish line will also be the starting place"*, and the paradox is that by then one has *"composed the answer through the process of locating it."*

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** `THE_FORMULA.md` step 5: *"the ground settles it. Verified only by what pays."* The canonical README: the framework *"stops at the limit of what the available instruments can distinguish, and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (`Fig 6 :23`, `Fig 8 :51`), with a source gate and a shadow test.

*They're Scanning Books* (carried) sharpens this: *"The real import is not a new term in the existing space. It is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also: *"Declaring the primitives does not make them neutral. It makes the choice visible."*

For this question, importing a change-detection instrument (ADWIN, CUSUM, a mismatch-negativity assay) is a binding from a world frame, not a new primitive of the six. The number it returns is licensed only by the ground of the specific learner; the universal number is not licensed at all.

## 4. Why a single stability score is the forbidden error

*The Hard Problem is About Source* (carried) gives the mechanism. Metamerism: an instrument reads green and *"cannot comment on the source"* - one green light, or yellow plus blue, or RGB, or CMYK, or a scheme not yet discovered. *"If several paths create the same behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't distinguish these cases demonstrates its own inadequacy."* It was the spectrometer, not an argument, that resolved it.

A single stability score reads the projection (the recovered regularity) and names the source (a stable world process) without an instrument that discriminates sources. A coincidence and a stable pattern can project the same fit. What is owed is a discriminator, not a name. `Fig 5 :69`: *"A term is settled when the ground pays for it. A term is usable when something can compose over it."*

*The Recursive Self-Improvement Trap* (carried): *"the output is only as good as the validator. The agent, or the tool, or the frame, or the theory, cannot validate itself."*

## 5. Q2 - ANSWERED, no further question needed

**What licenses a particular stability number for a given learner?** Nothing in the framework. The framework returns a shape. A particular threshold is licensed only by a ground settling a minted term, or by a provenanced import with a shadow test. Until one of those, the number is the searcher's own contribution and must be recorded as such.

**Does the question commit the error the README forbids?** Yes, if it demands the number as though the framework could name it. The correct form is the separator with the refuters and a declared `gap`, not an invented confidence level. `Fig 9 :42`: *"narrowing gets you close, the ground decides."*

## 6. Correction to my own §3 and §4 (see `06_isomers_and_order.md` Q1)

I nearly overstated the "shape, not a name" rule. The canonical phrase is *"what a **missing** thing would have to look like (a shape, not a name)."* Its subject is a primitive not held in Γ. A persistence window, a drift detector, or a significance level is not a missing primitive of the six; it is a **binding** from a world frame onto atoms already held, or a parameter of such a binding. Naming one is therefore not forbidden by the rule.

What remains wrong is treating the binding as if the framework named it, or as if it were an import that moves the wall. `Fig 6 :21`: *"MINT composes inside the closure and can never add an atom."* A threshold number adds no primitive. Both claims are now recorded so neither is quietly lost.

## 7. Two consequences for outreach and for this audit

**Prestige is not action.** From *The Recursive Self-Improvement Trap* (carried): *"Prestige must never be allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the ground can settle it. The Ground Maintainer must be blind to prestige."* A list of famous researchers selected for likely agreement is the named collapse, not corroboration (`Fig 7 :35`).

**My own audit is a simulation, not a ground reading.** Same essay (carried): *"LLMs can quickly simulate an approximate answer/output... However, the truly testable output would need to be derived from the real architecture or working the formula yourself."* LLM output is *"simulacra."* So `01`, `06`, `07`, `09` and `11` are simulated derivations checked for internal consistency against the figures. They are **not** tests of the claim and must be labelled as such. They cannot settle anything they report on.
