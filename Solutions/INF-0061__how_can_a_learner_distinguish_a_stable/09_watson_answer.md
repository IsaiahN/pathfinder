## QUESTION

Decide, in effect terms, what the Tether says about distinguishing a stable pattern from a coincidence when the environment changes. Option A: return a single score or threshold that sorts observations into two boxes. Option B: return a per-slot, settlement-based, refutable separator with a declared gap for the number. What each leads to: A averages two conditions with different anchors, lets the learner's own output score the learner, and hides a one-occasion fit as a regularity; B keeps the residual where it can be read, binds the sought-for shape as an ordinary term, and records which instrument would close the threshold. The question is a union of conditions, not a partition, so per-domain verdicts are kept separate and never averaged.

## DOMAIN CENSUS

R by arity, symmetry and scale, then one line per domain with actors / currency / anchor, partition or union, and order by dependency.

- **R (the residual).** The learner's per-slot gap between prediction and observation, `R = |Γ(b,a) − o'|` per slot s. Arity: one residual per candidate regularity, never aggregated. Symmetry: the deciding relation is an ordered comparison (a threshold between persistence and chance rate), not a symmetric correlation; coincidence as a false held claim is a negation, not an absence. Scale: first order inside one regime, second order at a regime crossing with a round-trip gap R_T.
- **Domain 1, the learning frame (term management).** Actors: the library Γ, its atoms and bonds, the slots s, the selector, the candidate φ, the refusal term. Currency: per-slot residual and description length in bits; actions price settlement. Anchor: the environment outcome, which does not change because the frame thinks so. This is a partition boundary inside one regime (what is owed a term, what is absorbed). Without a named ground this is not yet a domain.
- **Domain 2, the environment and habitat (regime change).** Actors: the generating process, its conditions and transitions, transient fluctuations. Currency: observations and contact with the ground. Anchor: the process that decides recurrence, which does not decay when the learner stops looking. This is a union when a regime mixes a stable component and a drifting component, and the habitat is enumerated, never composed.
- **Domain 3, the verification and outreach frame.** Actors: an outside reader or ground maintainer. Currency: agreement versus residual. Anchor: the ground, never agreement. In this simulated run all three domains draw on one evidence pool, so the independence here is zero and any agreement is internal consistency, not corroboration.
- **Order by dependency.** Perceive the per-slot departure, then have a vocabulary for regularity, then state an objective that counts a shrinking residual as progress, then choose when to sample, then settle and carry across scale. Refuse before mint; settle before composing; describe the residual before choosing a frame.

Strain test applied: the shrink test ranks which held term to refuse, while the acceptance test ranks a new term; different objects, same quantity read with opposite sign, so no contradiction after re-census. One live strain remains, the operand type of the second-order comparison (a comparison is defined over two quantities, and whether settled molecules count as quantities at that level needs an instrument). Both are recorded in `01` and `06`, not hidden.

## VERDICT (from the figures)

The question is a union of two conditions with different anchors, so one threshold cannot answer it. Inside one regime a candidate regularity is stable only if its per-slot residual trends down, its description-length bargain pays (so it is not a one-occasion fit), and the ground settles it against a contact that does not update, after which it can be composed over. The shrink test is opposite-signed: a held term whose residual persists and does not trend down is the refusal target. Across a changing environment there is no standing list of stable patterns, the ground does not decay while the channel does, and a regime crossing must be round-tripped. An outside reader's agreement is not a verdict. No figure line returns the numerical threshold; that is a declared `gap`, reported as unreached rather than silence. Verdicts per domain are kept separate: D1 `specified` triangulated, D2 `specified` triangulated, D3 `general` structural with single-source figure standing, number `gap`.

- **cost if wrong:** bounded and locatable if the separator is sent with its mode and refuters. The real cost is handing a learner one score that averages two anchors, which lets a one-occasion fit pass as a regularity and hides which slot is live. Fig 2 :42 says "Buy independence in proportion to the cost of being wrong." That cost is avoidable by keeping the residual per slot and leading with the refuter.
- **undoable:** yes. The number is not asserted, so nothing numerical has to be withdrawn. A failed refuter can be replaced in the relevant domain without touching the other two, and a source-discriminating instrument can be imported later with provenance and a shadow test. A claim that a single score sufficed would have to be withdrawn.
- **reversed by:** a ground reading, not agreement. A discriminator that does not update on the learner's own belief and separates a stable recurrence from a one-occasion fit would name the threshold; a standing list of patterns shown to keep its role across a change of residual would reverse the no-standing-list verdict; a sealed frame in which exhaustive search proved absence would reverse the stop; a single additive score that ordered both the bit-cost and the action-cost cases would reverse the two-currency claim. Until one of these fires, the verdict stands as candidate, `specified` on the shape and `gap` on the number.
