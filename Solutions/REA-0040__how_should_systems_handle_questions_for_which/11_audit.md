## 4. Round trip gap R_T

The Symbols table defines `R_T` as the gap between what was sent up and what came back down, `gap(x, (T_E ∘ T_A)(x))`, measuring what the coarser description cannot hold. Fig 4 :30 requires it to be measured rather than assumed. I ran the round trip on the condensation this folder actually uses.

1. **Sent up (x):** the verbatim figure set, chiefly Fig 9 :4-5 (split the union), Fig 8 :32 and :39 (idempotence and no proof of absence), Fig 6 :34-35 (no proto-instrument), Fig 5 :53 (refusal), Fig 13 :134 (unreachable is a verdict).
2. **Abstraction (T_A):** the shorthand carried in `07` and `08`: "split, search first, sharpen or import, refuse if false, report a status".
3. **Concretisation (T_E):** the operational protocol with bins, operations, mode labels and a lineage field.

**`R_T` is nonzero but small.** Three things the shorthand holds do not survive the trip back down:

- the distinction between unreachable-at-budget and underivable-in-principle, which collapses if the implementer reads "search first" as "search always";
- the requirement that refusal be a unary operator, which is lost if the output format has only a "status" enum and no way to withdraw a premise's standing;
- the channel-maintenance obligation (Fig 10 :24, "the ground does not decay, the channel does"), which is invisible if "unknown" is treated as a terminal state.

One thing survives cleanly: a no-answer question is a union, and its conditions must be handled by different operations. That is the residue worth sending. `R_T` was **not** measured numerically, because no ground reading of an implementation was taken; it is recorded qualitatively as the enumerated set of dropped constraints. Treating "the formula is the condensed version of the metalaws" as identity would set `R_T` to zero and would be the dead-reckoning error Fig 4 :30 names.
