## QUESTION

Decide, in effect terms, how a system should respond when no available evidence supports a definite answer to Q. Option A: emit a definite-looking answer, or a bare "unknown", and stop. Option B: split the no-answer condition into its distinct states, run the cheapest discriminator first, owe a refusal when the premise is false, and report a mode-labelled status with a refuter and a lineage. What each leads to: A spends the ground-contact channel and destroys the distinction that selects the next operation, while B returns a checkable status and names the instrument or import that would close it.

## VERDICT (from the figures)

The protocol shape survives. A no-answer question is a union and must be split; SEARCHED runs first because closure is idempotent; unreachable-at-budget and underivable-in-principle get different instructions; INWARD needs a proto-instrument already returning a failing reading while OUTWARD needs effect terms, a source gate and a shadow test; a false premise is owed a refusal; and the output is a mode-labelled status with a refuter and a lineage rather than a filler name. The two refused options are "say something plausible" and "collapse everything to unknown". All five domains returned a verdict (none `gap`); D2 and the proto-instrument rule are single-source within the framework and remain candidate until an instrument-level check. This is a `specified`, ungrounded result.

- **cost if wrong:** bounded and locatable if the packet is sent as designed. It states its mode, writes four refuters before the conclusion and records the lineage, so an error is findable rather than invisible. The real cost is a silent one: an implementation with a single "unknown" slot destroys the distinction that selects the next operation, and a campaign that gathers agreeing frames spends the independence of the checkers by Fig 2 :42, "Buy independence in proportion to the cost of being wrong." Both are avoidable by leading with the split, the refuter and the instrument question.
- **undoable:** yes. The protocol is a set of operations, not a primitive. A defective output format can be replaced without withdrawing any figure line; `07_the_tether_answer.md` and `08_expert_verification_packet.md` already carry the corrected form. No imported atom is required to reverse a wrong choice here.
- **reversed by:** a ground reading, not agreement. A ground that settles the supposedly evidence-free question and does not move when frames change would show there was an anchor all along; a closure that changes under repeated search with the same atoms would break idempotence; an instrument built from a description with no prior failing reading would break the proto-instrument rule; a system that withdraws a false premise with no negation operator would break the refusal claim; and agreement among overlapping frames that predicts the ground as well as an anchored instrument would break the anchor rule. Until one of these fires, the verdict stands as `candidate`.
