## RESIDUAL

The world offers several named responses to the same observed excess: higher star-formation efficiency (Ceverino 2024), bursty histories (Sun, quoted in O'Callaghan 2024), a top-heavy IMF (Carniani 2024's list of candidates), earlier black holes (Silk, quoted in O'Callaghan 2024), lower or redistributed dust (Carniani 2024), non-evolving efficiency plus younger ages (Donnan 2025), early dark energy (Shen 2024), and accelerated structure formation (McGaugh 2024). Two questions are owed: (1) are these isomers under Fig 12, and (2) in what order should they be tried?

## DERIVATION

### Q1: Are the named responses isomers?

Fig 12 :117 "isomer. Same atoms, different bond, different substance. The difference is invisible in the formula and decisive in the behaviour."
Fig 12 :123 "functional group. A substructure whose presence fixes the outcome. The group says what kind; the qualifier says which member."

Take three candidates:

- **High efficiency:** halo + baryons + (gas density to stellar mass) + time + light. The bond is a production arrow, `gas ⇒ stars ⇒ light`, with a rate that rises with redshift.
- **Bursty star formation:** the same atoms, but the rate is bonded to time by a duty cycle rather than a monotonic rise. Same ingredients, different arrangement, different predicted luminosity function shape (a bright-end tail from short-lived bursts).
- **Top-heavy IMF:** the same atoms, but the bond between stellar mass and light is re-weighted so each unit of mass emits more UV. The production arrow is unchanged; the mass-to-light mapping changes.

Over that fixed atom set these are **isomers**: same atoms, different bonds, different observable behaviour. They are not three versions of one explanation with different parameter values, because a duty cycle and a mass-to-light reweighting cannot be reduced to a single rate without losing the behaviour each predicts. Under the symmetric-bond analysis of Fig 12, the order in which the atoms are listed does not create new candidates; the bond does.

The **functional group** they share is `halo -> conversion -> light`, a `state -> structure -> state` first-order molecule in the Fig 13 sense if the atom set is mapped onto the six-term substrate. The qualifier (efficiency versus duty cycle versus IMF) says which member.

**Falsifier, written before the run:** if two responses require atoms the other does not (early dark energy adds a cosmological component absent from the ΛCDM atom set; accelerated structure formation changes the growth rule itself), the isomer claim does not apply to that pair. They are composition plus import (Fig 6 :22 "IMPORT adds an atom, and the added atom is what expands the closure."), not isomers. This is the live boundary of the claim, not a footnote.

### Q2: Which comparisons are symmetric and which are ordered?

Operators table :15 "swap the operands. Does the meaning change? No." for `+` (conjunction). Operators table :33 "swap them. Does it become a different thing? Yes." for `->` (sequence). Operators table :49 "a threshold relation between two quantities" for `⋛`.

- A correlation between halo mass and UV luminosity is `+`: it does not choose an arrow. It cannot by itself decide whether halos make bright galaxies or bright galaxies select rare halos.
- An efficiency history is `->`: high gas density at earlier times precedes the stars it produces.
- "Brighter than predicted" is `⋛`: a threshold, ordered, not an identity.

So the world's population correlations are filters for the budget (Fig 9 :60 "Use filters for the budget and witnesses for the verdict. Never let a filter hand you a verdict."), while the mechanism claims are ordered and therefore checkable in time. A derivation that treats them as the same kind of statement commits the flat-formula error Fig 12 :5 names: "A set of ingredients is not one. The bond is the rest of the information, and it is the half nothing was recording."

### Q3: What is the order of the union? Not "which cause first", but "which test first"

Fig 3 :19 "Optimising a link that already works cannot rescue one that does not."
Fig 3 :27 "A link with no instrument is not a link that works. It is a link nobody has looked at."
Fig 6 :32 "An instrument is not built from a description. It is improved from a worse instrument already returning something."

Dependency order for a given slot:

1. **Perception** (D1): obtain a spectrum. Photometry is the worse instrument already returning something. A candidate without a spectrum is a bet, not a perception. Arrabal Haro 2023 and Carniani 2024 show the spectrum changes the slot's identity in both directions.
2. **Vocabulary** (D2): check whether the model has terms for AGN contamination, dust geometry, IMF variation, burstiness and efficiency. If it does not, the failure is a missing term, not a wrong constant. Fig 3 :7 "it has terms for what things afford: what can be moved, opened, joined, blocked".
3. **Objective** (D2): state what would count as a match, a UV luminosity function and a stellar mass function at the same redshift, not a single object's mass. Fig 3 :10 "it can say what would count as progress here, in its own terms".
4. **Ground test** (D3): apply the baryon bound and a source discriminator (UV slope, morphology, ALMA dust, emission lines). This is where Fig 11 :49 applies: "An actor's valence is relative to the residual, not a property it carries."
5. **Import, only if 1 to 4 leave a residual** (D2/D3): characterise what is missing in effect terms, find a frame whose closure differs, apply the source gate and shadow test, debit the import against that frame's independence (Fig 6 :23, :24).

A step whose input never arrives cannot be diagnosed, only its predecessor can (Fig 3 :22-23). Applying an efficiency adjustment before a redshift is settled is effort spent above a break.

### Q4: Is there a seventh candidate to mint?

Fig 5 :41 "Any one of them at zero stops the mint entirely. Which is why a system that is minting nothing may have nothing wrong with its minting."
Fig 5 :48 "Its own output is never a measure of success. A system can be enthusiastically curious and produce nothing."
Fig 8 :32 "Closure is idempotent. Composing inside a closed set never leaves it, so no search, however long, adds an atom."

The three guards applied to a new cause for this residual:

- **Support:** is there a live per-slot residual after spectroscopy and the baryon-bound test? For some slots, yes (Carniani 2024); for others, no (Arrabal Haro 2023). Support is per slot, not global.
- **Reachability:** can the term compose from held atoms? Efficiency, dust, IMF and burstiness: yes. Early dark energy: no, it comes from a differing cosmology closure and is an import, not a mint.
- **Novelty:** is it already in the library? All eight named responses already exist in the astronomy literature. None is novel relative to atoms(Γ). So the honest result is **no mint is owed by this derivation**. What is owed is a decision among held terms at the ground, or a provenanced import.

This is not a failure of the machinery. Fig 5 :41 says a system minting nothing may have nothing wrong with its minting.

## CONCLUSION

The named responses are **isomers over an abstract atom set** where they share atoms, with a shared functional group `halo -> conversion -> light` and different bonds (efficiency rate, burst duty cycle, mass-to-light reweighting). The genuinely different cosmological proposals are not isomers; they are imports from a differing closure with a price and a provenance requirement. The order of the union is a dependency order of tests, not a ranking of mechanisms: spectrum, vocabulary, objective, ground discriminator, then import. The falsifier is the atom-set condition in Q1: if two explanations require different atoms, the isomer relation fails and the import reading stands.

Nothing here selects a cause for a slot. That remains the `gap` recorded in `01` §3 and `07` §5.
