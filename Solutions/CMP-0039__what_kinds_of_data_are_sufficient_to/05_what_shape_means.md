## 1. A shape is a constraint, not a filler

The canonical figures README states the limit: the framework returns "what a missing thing would have to look like (a shape, not a name)". Fig 9 :32: "you get a kind of thing, never the answer itself". Fig 13 :134: "Unreachable is a verdict here, not a silence". The README adds "Indiscernibility is not identity."

From *How Intelligence Actually Works*, the replicator passage: "At some point the recursion of the 'shape' will have carved away at so many aspects, that it will fall out of perceptible range and be indistinguishable, in your frame, from the answer." And the governing caution immediately after: "The recursion converges toward indiscernibility, and indiscernibility is not identity."

So a **shape** is the narrowed form of an answer you can state before you can name the thing that closes it. It constrains; it does not fill. For CMP-0039 the shape is the class of data properties that any identifying dataset must have, plus the kind of missing atom that would split the remaining class. It is not a named instrument, a named latent, or a universal protocol.

"Four-part sufficient set" is a shape, not a recipe. It says what the data must *do* (anchor, independence, loop resolution, imported latent), not which sensor to buy.

## 3. What licenses a name

Only two things, both outside the shape:

1. **The ground settles it.** `THE_FORMULA.md` step 5: "the ground settles it. Verified only by what pays. A gate is not the ground." In this question, that means an instrument or intervention makes a specific direction or a specific latent *pay*, not merely fit.
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23), with a source gate and a shadow test (Fig 6 :12-13).

For CMP-0039 this matters because the temptation is to name the hidden confounder from the pattern of residuals. The framework refuses that. It can say what the missing operand must be in contact with, and which properties would discriminate it; it cannot name it without an import that pays.

## 4. The ground and the source problem

*The Hard Problem is About Source* gives the mechanism, and it is exactly the confounding case. An instrument reads green and "the instrument is speaking only about what it measured, it cannot comment on the source." Several underlying causes can produce the same reading: "If several paths create the same behavior, then behavior is a projection with lossy information (it cannot define consciousness in full)." In the question's terms: several causal graphs can produce the same joint distribution.

The resolution is not a better argument but a better instrument: "It was proven wrong not by argument, but by the arrival of a better instrument." And the instrument's own limit is stated: "An instrument that can't distinguish these cases demonstrates its own inadequacy, it cannot claim anything substantial about what is being measured or what causes it."

*How Intelligence Actually Works* gives the same point in the colour case: "The projection of green can't tell you whether it was RGB, CMYK or something else that composed it." It also states the anchor requirement in the feedback case: "The ground must be immovable by persuasion and not bi-directional like the frames are. The ground doesn't update on anything that the frames do". An intervention that is itself driven by the feedback loop is not a ground.

## 5. Answer to the shape question for CMP-0039

**What shape does a sufficient dataset have?** It has four properties and one lineage property.

1. **An anchor.** Some variable is set from outside the system, and the setting mechanism does not change in response to the system's state. This is the figure's anchor test (Fig 2 :29) applied to data.
2. **Independent evidence.** The frames contributing data do not share the hidden source. Independence is "how little they draw on the same evidence" (Fig 2 :31), not how many rows they contain.
3. **Loop resolution.** The data separate the two passes of a feedback cycle, through time ordering or through an edge held severed. Otherwise the cycle collapses into one mutual-update state.
4. **An imported atom.** The unmeasured variable is either measured by a discriminating instrument or replaced by a design (multiple environments, instruments) in which its effect does not stay invariant.
5. **A lineage.** Provenance for every import, a pre-registered refuter, and a verifier that cannot reconstruct the claim (Fig 10 :42).

**What is not given by the shape:** which instrument, which latent, how many samples, which identification estimator, or whether a specific pair X,Y is identifiable in a specific system. The shape says what any sufficient dataset must be *like*; the ground decides each case. This is the canonical reading of "shape" applied honestly rather than inflated into a method that claims more than the figures allow.
