## 1. Independent domain census

I redid the census from the residual line alone, before reading the primary's conclusions, in the WATSON order: R by arity, symmetry and scale; one line per domain with actors / currency / anchor; partition or union; order by dependency.

- **R (arity / symmetry / scale).** The residual is the gap between a fitted joint distribution and a settled directional claim. Arity: binary relation embedded in a network. Symmetry: the data is invariant across observationally equivalent structures; the claim is ordered, so the two are different kinds of object. Scale: first order inside the system, second order when an outside setting is applied. This is a union compound, not one hard question (Fig 9 :55), because feedback, confounding and hidden variables overlap.
- **Domain 1, observational frame.** Actors: variables and their recorded joint behaviour. Currency: fit. Anchor: none inside the frame. This is the failure that generates R.
- **Domain 2, intervention frame.** Actors: experimenter, do-operation, instrument, environment. Currency: perturbation-anchored measurement. Anchor: a setting mechanism that does not update on the system.
- **Domain 3, latent frame.** Actors: unmeasured common causes. Currency: unexplained covariance. Anchor: a discriminating instrument or an independent environment.
- **Domain 4, verification frame.** Actors: analysts. Currency: agreement and residuals. Anchor: the ground, never agreement. Independence here is zero, since this seat reads the same pool.

Order by dependency: perceive variables -> have ordered bonds -> state what counts as identification -> plan the intervention -> carry invariance. The anchor and independence conditions precede loop resolution, which precedes the latent import.

My census matches the primary's four domains and its union reading. Where the primary derived from Fig 12's bond definition and Fig 2's anchor, I derived from Fig 9's union/partition split and Fig 3's dependency order. Different starting figures, same boundaries. Low overlap between routes, so the agreement is weak but not circular within the framework. It is still one evidence pool.

Conversely, one thing survives cleanly: a distribution without an anchor cannot select a member of an equivalence class. That is the residue worth sending.
