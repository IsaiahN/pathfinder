## Restating the question as an effect

The question is not "how do I fit a model better." It is: what must be true of the data for a claim of the form "X causally influences Y" to be *settled* rather than merely *fitted*? Option A treats more of the same observational data as sufficient; it leads to a narrowed equivalence class mistaken for a verdict. Option B requires data that crosses out of the observed closure; it leads to a shape of sufficient data with a stated refuter and an honest stop. The answer binds the term "sufficient data" as an ordinary term so it can accrue a residual (Fig 5 :65-66, formula step "Direction").
