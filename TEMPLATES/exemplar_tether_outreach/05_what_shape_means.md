## 1. A shape is a constraint, not a filler

The figures README states the limit: the framework returns *"what a missing thing would have to look
like (**a shape, not a name**)."* Fig 9 :32: *"you get a kind of thing, never the answer itself."*
Fig 13: *"It can say the answer is out of reach with the library as it stands... It cannot say which
primitive is missing, because naming it would mean already holding it."*

From *The Library of Babel*: *"You can cut your search short if the set of books returned is small
and descriptive enough that it provides a general shape of the answer that satisfies your
question."*

So a **shape** is the narrowed form of an answer you can state before you can name it. It constrains;
it does not fill. `SPACE(???)TIME` is a shape. `SPACE(Gradient)TIME` is a name.

## 2. How a shape is obtained

- *Library of Babel*: use the vocabulary you already have that is *closest* to the thing, look for
  recurring new terms that overlap or correlate with it, recurse. *"With each new term gained, you
  narrow the space and deepen your vocabulary."*
- Fig 6 :30: *"The description travels. Fails by being sharpened into terms only we can read. Cast it
  in effect terms."* Fig 9 :30–31: *"your words are borrowed too, so describe the effect rather than
  the cause."*
- *Decoding Tacit Knowledge*: *"When contact isn't possible, the best you can send is a plain
  description of what you'd expect to see, because anyone can check that against the world."*
- *Library of Babel* on stopping: the answer is reached when *"the finish line will also be the
  starting place"* — and the paradox is that by then you have *"composed the answer through the
  process of locating it."*

## 3. What licenses a name

Only two things, both outside the shape itself:

1. **The ground settles it.** Formula step 5: *"the ground settles it. Verified only by what pays."*
   The README: the framework *"stops at the limit of what the available instruments can distinguish,
   and records the lineage so the stop is honest."*
2. **A provenanced import from a frame whose closure differs** (Fig 6 :23, Fig 8 :50–52), with a
   source gate and a shadow test.

*They're Scanning Books* sharpens this: *"The real import is not a new term in the existing space. It
is a new dimension of the space."* And: *"A minimum viable set of six terms is a human's careful
guess at reality's compression axes; another sensorium's minimum set need not be those six."* Also:
*"Declaring the primitives does not make them neutral. It makes the choice visible."*

The six are a visible guess, not a discovery of nature's own list. Naming one as *the* answer to a
slot turns a visible choice into an invisible one.

## 4. Why the record's answer is the specific forbidden error

*The Hard Problem is About Source* gives the mechanism. Metamerism: an instrument reads green and
*"cannot comment on the source"* — one green light, or yellow+blue, or RGB, or CMYK, or a scheme not
yet discovered. The reading does not determine the source. *"If several paths create the same
behavior, then behavior is a projection with lossy information."* And: *"An instrument that can't
distinguish these cases demonstrates its own inadequacy."* It was the **spectrometer**, not an
argument, that resolved it.

The record reads the metric tensor (the artifact) and names its source as Gradient. That is exactly
the metamerism error: a source named from a reading, where several sources could give the same
reading. What is owed is a better instrument, not a name.

*The Recursive Self-Improvement Trap*: *"the output is only as good as the validator. The agent, or
the tool, or the frame, or the theory, cannot validate itself."*

## 5. Q2 — ANSWERED, no further question needed

**What licenses a particular structure in the slot?** Nothing in the framework. The framework
returns a shape. A particular structure is licensed only by the ground settling a minted term, or by
a provenanced import with a shadow test. Until one of those, the name is the searcher's own
contribution and must be recorded as such.

**Does the record commit the error the README forbids?** Yes. In a `Specified` record it names
Gradient — a name where the framework returns a shape — and it names it by reading the source off a
projection, which is the metamerism error. The correct form remains `SPACE(???)TIME`.

## 5b. Correction to my own §3–§4 (see `06_isomers_and_order.md` Q1)

I overstated the "shape, not a name" rule. The README's phrase is *"what a **missing** thing would
have to look like (a shape, not a name)."* It governs a primitive not held in Γ. Gradient and
Spectrum are **both already among the six**, so naming one is a **binding from the physics frame**,
not the invention of a new primitive. What remains wrong in the record is calling that binding an
import that moves the wall (Fig 6: *"IMPORT adds an atom"* — it adds none) and saying the Gradient was
*"smuggled in."*

My §4 metamerism point is **not** retracted: the record still names the source of a reading (metric
tensor → Gradient) without an instrument that discriminates among sources. But the reason is the
missing discriminator, not a ban on naming held atoms. Both claims are now recorded so neither is
quietly lost.

## 6. Two consequences for outreach

**Prestige is not action.** From *The Recursive Self-Improvement Trap*: *"Prestige must never be
allowed to validate an action directly... Someone let prestige stand in for proof... Prestige can
fund an action. It can give an action a budget to be tried. But it cannot settle an action. Only the
ground can settle it. The Ground Maintainer must be blind to prestige."*

A campaign that gathers prestigious names to agree with the claim is the named collapse, not
corroboration. The legitimate ask is the opposite: give the claim a budget to be tried, and let the
ground — an instrument, an experiment, a board — settle it.

**My own audit is a simulation, not a ground reading.** Same essay: *"LLMs can quickly simulate an
approximate answer/output... However, the truly testable output would need to be derived from the
real architecture or working the formula yourself."* LLM output is *"simulacra."* So `01` is a
simulated derivation, checked for internal consistency against the figures. It is **not** a test of
the claim and must be labelled as such. It cannot settle anything it reports on.
